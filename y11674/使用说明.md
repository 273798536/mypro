# 反欺诈客户关系网络3D可视化系统 - 使用说明

## 快速开始

### 1. 启动系统

```bash
# 安装依赖（首次使用）
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后访问 `http://localhost:5173` 即可进入系统。

### 2. 首次登录 - 自动造数

系统启动后会**自动生成模拟数据**，包含：
- 15个贷款客户（含1-2个黑名单客户）
- 20个手机号（部分共享）
- 18个设备（部分共享）
- 8个担保人
- 多笔贷款申请和调查结论
- 60+条关联关系

如需重新生成数据，点击顶部工具栏的「造数」按钮。

## 核心功能操作指南

### 3D关系图交互

| 操作 | 效果 |
|------|------|
| **鼠标左键拖动** | 旋转3D场景 |
| **鼠标滚轮** | 缩放视图 |
| **鼠标右键拖动** | 平移视图 |
| **点击节点** | 选中节点，右侧显示详情 |
| **拖动节点** | 调整节点位置（停止自动布局） |
| **悬停节点** | 高亮显示节点 |

### 节点类型说明

| 节点类型 | 颜色 | 说明 |
|---------|------|------|
| 客户 | 紫色 | 贷款申请人，黑名单标红闪烁 |
| 手机号 | 青色 | 客户使用的手机号码，共享号码风险更高 |
| 设备 | 橙色 | 客户使用的设备（手机/电脑），共享设备需关注 |
| 担保人 | 绿色 | 为客户提供担保的人员 |
| 贷款申请 | 蓝色 | 客户的贷款申请记录 |
| 调查结论 | 灰色 | 贷款申请的反欺诈调查结果 |

### 风险等级标记

- 🟢 **低风险 (绿色)** - 正常客户
- 🟡 **中风险 (黄色)** - 需要关注
- 🔴 **高风险 (红色)** - 较高欺诈嫌疑
- ⚫ **极高风险 (深红)** - 黑名单客户，持续闪烁

## 筛选与搜索

### 节点类型筛选
左侧控制面板 → 节点类型 → 勾选/取消勾选需要显示的节点类型

### 风险等级筛选
左侧控制面板 → 风险等级 → 只显示特定风险等级的节点

### 黑名单筛选
勾选「仅显示黑名单」可快速定位高风险客户

### 搜索功能
在搜索框输入节点名称或ID，实时过滤显示匹配的节点

## 路径分析功能

### 查找两节点间关联路径
1. 点击第一个节点查看详情
2. 点击「设为路径起点」按钮
3. 点击第二个节点
4. 系统自动高亮显示最短路径（黄色连线）

### 路径风险评估
路径上的高风险节点越多，整体风险等级越高

## 异常检测与告警

系统自动检测以下异常情况，在左侧「异常告警」面板显示：

### 🔴 重复关系 (Error)
- 检测到两个节点间存在多条相同类型的关系
- 红色虚线标记重复的关系线
- 点击告警可快速定位到相关节点

### 🟡 节点过密 (Warning)
- 某个节点连接数超过5个（阈值可配置）
- 可能存在团伙欺诈风险

### 🔴 黑名单节点 (Error)
- 检测到黑名单客户
- 节点持续红色闪烁，无法被忽略

### 🔴 高风险路径 (Error)
- 多个高风险/黑名单节点互联
- 可能存在欺诈团伙

> **重要**: 所有异常都会被记录到导出报告中，不会被忽略

## 参数保存与加载

### 保存当前配置
点击顶部「保存」按钮，将以下配置保存到本地存储：
- 节点类型筛选状态
- 风险等级筛选状态
- 视图参数（标签显示/动画等）

### 加载配置
点击顶部「加载」按钮，恢复上次保存的配置

- 导出时间

- 所有异常告警详情

- 最近20条操作历史

```json
    "totalAnomalies": 3,

  "anomalies": [...],
  "operationHistory": [...]
}
```

## 典型操作流程

### 流程1: 新客户风险评估
1. 点击「造数」生成新数据（或导入真实数据）
2. 查看左侧异常告警，优先处理红色告警
3. 点击黑名单客户查看关联关系
4. 设为路径起点，查找与其他高风险客户的关联
5. 点击「导出报告」保存分析结果

### 流程2: 团伙欺诈识别
1. 筛选仅显示「高风险」和「极高风险」节点
2. 观察是否存在多个高风险节点互联
3. 使用路径分析功能确认关联关系
4. 标记可疑团伙，导出证据报告

### 流程3: 日常监控
1. 加载上次保存的参数配置
2. 导入最新数据
3. 查看新增异常告警
4. 处理完毕后保存配置和报告

## 异常处理与FAQ

### Q: 3D场景太卡怎么办？
A: 点击顶部「暂停」按钮关闭动画，或减少显示的节点数量

### Q: 节点太多看不清？
A: 
1. 使用筛选功能隐藏不需要的节点类型
2. 滚动鼠标滚轮放大视图
3. 拖动节点调整位置

### Q: 如何清除当前选择？
A: 点击空白区域或点击信息面板的关闭按钮

### Q: 数据保存在哪里？
A: 参数配置保存在浏览器LocalStorage，刷新页面不会丢失。导出的报告下载为本地文件。

### Q: 支持导入真实数据吗？
A: 目前版本支持模拟数据生成。真实数据接入需要开发对应的API接口，数据格式参考 `src/types/index.ts` 中的类型定义。
