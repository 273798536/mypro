# 老街消防容量复核工具

街道消防点位数据复核工具，支持多源数据合并、异常高亮、来源追溯和CSV导出。

---

## 快速开始

### 第一步：安装依赖

```bash
npm install
```

### 第二步：启动开发服务

```bash
npm run dev
```

启动后在浏览器打开 `http://localhost:5173` 即可使用。

### 第三步：导出CSV明细

在页面右上角点击 **"导出CSV明细"** 按钮，导出当前筛选结果的完整明细文件。

导出的CSV文件包含：点位编号、名称、位置、坐标、状态、口径、来源数量、来源类型、原始说法汇总、备注。

## 功能说明

### 1. 统计总览

页面顶部展示4张统计卡片：
- **总点位**：当前所有消防点位数
- **异常点位**：多源数据有冲突的点位（红色）
- **待复核**：新增或只有单一来源的点位（黄色）
- **已确认**：复核无误的点位（绿色）

下方展示三类数据来源的数量分布：
- 🔵 GIS旧版
- 🟣 晚到附件
- 🟠 口头备注

### 2. GIS点位地图

左侧地图区域展示所有点位的空间位置：
- 不同颜色代表不同状态
- 异常点位（红色）和待复核点位（黄色）有呼吸动画
- 鼠标悬停可查看点位名称、状态、口径和来源
- 点击点位可查看详情

### 3. 点位列表

中间列表展示所有点位，支持筛选：
- 按状态筛选：全部 / 异常 / 待复核 / 正常 / 已确认
- 按来源筛选：全部 / GIS旧版 / 晚到附件 / 口头备注
- 点击列表项可查看点位详情

### 4. 点位详情（核心功能）

右侧详情面板，选中点位后显示：

#### 4.1 基本信息
- 点位名称、地址、当前口径
- 经纬度坐标
- 数据来源数量

#### 4.2 冲突检测
如果点位存在多源数据冲突，会高亮显示：
- 冲突字段（位置、口径等）
- 涉及的来源数量
- 冲突描述

#### 4.3 多源数据对比
表格形式并排展示各来源的数据：
- 口径对比（有差异的字段红色高亮）
- 位置坐标对比
- 记录人对比

#### 4.4 原始说法追溯（时间线）
按时间顺序展示每个来源的**原始说法**：
- 来源类型标签（GIS旧版/晚到附件/口头备注）
- 记录时间和记录人
- 原始描述（带引号，保留原始说法）
- 口径和坐标

#### 4.5 复核操作
- 编辑备注：记录复核意见
- 标记状态：可切换为 正常/异常/已确认/待复核

## 复核工作流程（周姐版）

1. **早晨打开工具** → 看顶部统计卡片，异常点位数一目了然
2. **先看异常点位** → 地图上红色呼吸灯的就是，优先处理
3. **点进详情看** → 冲突在哪、各来源怎么说、原始说法是什么
4. **追溯原始说法** → 时间线从上到下看，谁什么时候说的都清楚
5. **标记复核状态** → 确认无误就标"已确认"，有疑问就写备注
6. **导出CSV明细** → 右上角按钮一键导出，拿去和社区同事核点位
7. **CSV里也有原始说法** → 线下核对时也能看到每条数据的来龙去脉
