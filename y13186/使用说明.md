# 风洞烟线阈值预警系统

只讲三件事：**启动**、**重跑**、**查看 Markdown 报告**。

## 一、启动（首次处理）

```bash
cd /Users/mac/pro/solo/workspaces/y13186
python3 main.py start
```

- 默认使用内置示例数据（5条记录，覆盖正常、报警、阻塞、风向符号写反等场景）
- 如需用自己的数据：`python3 main.py start --input path/to/records.json`
- 如想模拟阿岑对 rec002 临时改过阈值（演示留痕）：`python3 main.py start --include-manual`
- 处理结果保存在 `data/` 目录，自动生成一份 Markdown 报告到 `data/reports/`

## 二、重跑（二次处理 / 合并晚到数据 / 人工修改）

```bash
# 全部重跑
python3 main.py rerun

# 只重跑指定记录
python3 main.py rerun --ids rec003,rec005

# 为某条记录合入晚到附件（自动触发跳变检测：晚到附件到达）
python3 main.py rerun --attach-late rec002

# 人工临时调整阈值（自动触发跳变检测：阈值变更；历史留痕【临时修改】标签）
python3 main.py rerun --set-threshold-high 80 --operator 阿岑 --reason "实验阶段放宽"
```

- 每次重跑都会对所有修改做历史留痕（谁、改了啥、原因、是否临时）
- 检测到结果跳变会自动归因：阈值变更 / 单位变更 / 晚到附件到达
- 生成新的 Markdown 报告（文件名带 `_重跑` 后缀）

## 三、查看 Markdown 报告

```bash
# 列出所有报告
python3 main.py report --list

# 用系统默认程序打开最新一份报告
python3 main.py report

# 在终端直接打印最新报告
python3 main.py report --cat

# 指定某份报告打开 / 打印
python3 main.py report --path data/reports/风洞烟线预警报告_XXXXXXXX_XXXXXX.md
python3 main.py report --path data/reports/风洞烟线预警报告_XXXXXXXX_XXXXXX.md --cat
```

报告结构固定为 6 节：
1. 处理概览（总表：状态 / 计算值 / 阈值 / 是否跳变）
2. 阻塞记录明细（算不出的，逐条说明卡公式 / 单位 / 阈值）
3. 报警与人工备注对齐情况（系统 vs 阿岑，不一致会写清原因 + 下一步）
4. 结果跳变与归因（阈值 / 单位 / 晚到附件 三类，逐条解释）
5. 人工修改历史（交接班用，带【临时】标记方便下一班复原）
6. 下一步处理清单（阻塞/报警的逐条可执行步骤）
