## 1. 产品概述

博物馆展柜灯光剖面讲解工具——解决现场巡检人员看二维表格缺乏空间感的问题，将展柜灯光数据以剖面可视化呈现，保证场景标注、侧边说明和CSV明细三处数据始终一致，支持从截图反向追溯到数据来源与筛选状态。

- 目标用户：博物馆巡检人员、教学老师（如林姐）、评审参会人员
- 核心价值：用剖面视角替代纯表格，减少现场解释成本；三处标注同源，杜绝"三套话"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 巡检人员 | 现场巡检录入、查看剖面 | 录入记录、查看标注、导出CSV |
| 教学老师 | 接班确认异常、导出结果 | 查看样例、定位异常、导出CSV |
| 评审人员 | 围绕截图讨论、追溯来源 | 截图追溯、筛选回放 |

### 2.2 功能模块

1. **剖面工作台页**：展柜灯光剖面可视化、场景标注、侧边说明面板、CSV明细面板
2. **巡检记录页**：巡检照片列表、筛选（楼层/单位/状态）、撤回记录标记、楼层单位混写确认

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 剖面工作台 | 剖面画布 | 展柜侧剖面图，灯光位置、色温、照度值标注在剖面图上，支持缩放平移 |
| 剖面工作台 | 侧边说明面板 | 右侧固定面板，显示当前选中标注的文字说明，与画布标注和CSV同源 |
| 剖面工作台 | CSV明细面板 | 底部可展开面板，显示完整灯光参数表格，字段与标注一致 |
| 剖面工作台 | 快捷操作栏 | 顶部工具栏：加载样例、重跑分析、导出CSV、截图追溯 |
| 剖面工作台 | 三步说明卡片 | 页面右上角折叠卡片，仅写三件事：样例在哪、怎么重跑、怎么导出CSV |
| 巡检记录 | 记录列表 | 巡检照片缩略图+元数据列表，含1条撤回记录（红色标记） |
| 巡检记录 | 筛选面板 | 按楼层/单位/状态筛选，楼层单位混写时弹出确认对话框并说明原因和下一步 |
| 巡检记录 | 异常标记 | 异常记录高亮，教学老师快速定位 |

## 3. 核心流程

### 3.1 巡检数据→剖面讲解流程

1. 巡检人员录入巡检照片和灯光参数（或加载样例数据）
2. 系统根据数据生成展柜剖面图，标注灯光位置和参数
3. 场景标注、侧边说明、CSV明细三处从同一数据源渲染，保证一致
4. 教学老师查看异常标记，确认后导出CSV

### 3.2 截图追溯流程

1. 用户点击"截图追溯"，系统记录当前画布状态、筛选条件、选中对象
2. 生成带追溯信息的截图（嵌入筛选状态和对象ID）
3. 从截图可还原到对象来源和当前筛选

### 3.3 楼层单位混写确认流程

1. 用户在筛选面板输入楼层/单位值，如"3F-A区"或"3楼A"
2. 系统检测到楼层和单位混写（非标准格式）
3. 弹出确认对话框：说明检测到混写、原因（格式不标准）、下一步（选择拆分为楼层+单位或原样保留）
4. 用户确认后继续筛选

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深炭灰(#1a1a2e) + 暖白(#faf9f6)，体现博物馆的沉稳专业感
- **强调色**：琥珀金(#d4a853)用于灯光标注、异常高亮用珊瑚红(#e74c3c)
- **字体**：标题用 Noto Serif SC（衬线，呼应博物馆气质），正文用 Noto Sans SC
- **布局**：左侧大画布 + 右侧说明面板 + 底部CSV面板（可折叠）
- **圆角**：小圆角(4px)，偏工业/制图风格
- **图标**：线性图标风格(Lucide)，简洁克制

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 剖面工作台 | 剖面画布 | 深色背景画布，灯光标注用琥珀金圆点+引线，hover显示详情 |
| 剖面工作台 | 侧边说明面板 | 半透明深色面板，文字白底黑字，异常项红色左边框 |
| 剖面工作台 | CSV明细面板 | 可拖拽分隔条展开，表头固定，选中行高亮 |
| 剖面工作台 | 三步说明卡片 | 折叠态仅显示图标，展开后3行文字 |
| 巡检记录 | 记录列表 | 卡片式列表，缩略图+元数据，撤回记录红色角标 |
| 巡检记录 | 筛选面板 | 顶部横排筛选器，混写确认用模态对话框 |

### 4.3 响应式

- 桌面优先（评审场景用大屏投影）
- 平板适配：侧边面板改为抽屉式
- 移动端：仅保留剖面画布+折叠面板

### 4.4 试跑数据要求

- 巡检记录混入1条撤回记录（状态=已撤回，红色标记）
- 数据贴近现场真实场景（非过度干净的演示包）
- 楼层单位混写示例："3F-A区"、"B1层B区"
