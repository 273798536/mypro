# 傅里叶厨房配方赛

## 启动方式

### 环境准备
```bash
pip install -r requirements.txt
```

### 启动服务
```bash
python app.py
```

### 访问应用
打开浏览器访问: http://localhost:5000

## 样例位置

样例数据文件位于 `examples/` 目录:
- `examples/sample_records.json` - 包含缺字段、晚补、备注修改的样例记录

## 频率混叠触发办法

### 触发条件
当食材频率超过波形锅奈奎斯特频率（采样率的一半）时，会触发频率混叠。

### 具体操作步骤
1. 选择"奈奎斯特挑战"配方
2. 选择"采样锅-8Hz"（采样率8Hz，奈奎斯特频率4Hz）
3. 添加"高频辣椒"（频率5Hz）
4. 点击"烹饪"

### 预期现象
- 界面显示红色警告："频率混叠! 频率5Hz超过奈奎斯特频率4Hz"
- 输出波形与目标波形严重不匹配
- 得分显著降低

## 过度滤波触发办法

### 触发条件
当低通滤波截止频率过低，导致滤波后损失超过50%信号能量时。

### 具体操作步骤
1. 选择任意配方
2. 选择"低通锅-2Hz"
3. 添加多种高频食材（如中频番茄、高频辣椒、噪音蘑菇）
4. 点击"烹饪"

### 预期现象
- 界面显示黄色警告："过度滤波：滤波损失超过50%信号能量"
- 输出波形能量显著降低

## 游戏玩法说明

1. **选择配方**: 从四个难度等级的配方中选择
2. **选择波形锅**: 不同采样率和滤波特性的锅会影响结果
3. **添加频率食材**: 点击左侧食材添加到锅中
4. **烹饪**: 查看波形对比和得分
5. **记录实验**: 在右侧添加实验记录，支持晚补标记

## 关键机制

### 相位反转
- "反相生姜"带有π相位偏移
- 与相同频率的正相食材同时使用会产生抵消效果
- 相位反转影响会在详情和导出文件中明确标注

### 暂停重开
- 点击"暂停"按钮可暂停游戏
- 继续时可选择是否清除当前状态
- 选择清除状态后，波形对比、步骤记录都会重置，无残影

## 导出功能

点击"导出"按钮可下载完整游戏记录JSON文件，包含：
- 游戏ID和配方信息
- 最终得分和状态
- 相位反转、频率混叠、过度滤波检测结果
- 完整操作步骤和实验记录
