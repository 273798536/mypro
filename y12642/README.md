# 生物食物网连线器

一个简单易用的工具，帮助文保讲解员快速建立生物食物网关系图，支持连线、标注、导出等功能。

## 功能特点

1. **统一数据管理** - 图表、明细、导出都来自同一数据源
2. **撤销重做** - 完整的操作历史记录
3. **批次管理** - 每次使用生成唯一批次号，方便区分
4. **轨迹追踪** - 记录所有操作步骤，可回溯
5. **友好导出** - 导出HTML格式，无需专业软件即可查看
6. **颜色检测** - 自动检测连线层级关系，提供处理意见
7. **多维度备注** - 支持标注草稿、讲解备注、图层遮挡记录

## 使用方法

### 1. 启动应用
直接在浏览器中打开 `index.html` 文件即可使用，无需安装任何依赖。

### 2. 导入素材
- 点击上传区域选择图片文件
- 或者直接拖拽图片到上传区域
- 支持多张图片同时导入

### 3. 建立连线
- 点击画布上的节点（从导入的图片生成）
- 再点击另一个节点建立捕食关系
- 连线会自动检测层级关系，颜色标识正常/警告状态

### 4. 添加备注
在右侧的文本框中填写：
- 标注草稿：记录标注过程中的想法
- 讲解备注：准备讲解时的要点
- 图层遮挡：记录图层关系和遮挡问题

### 5. 查看结果
- 左侧画布：可交互的连线图
- 右上方：食物网图谱（环形布局）
- 右下方：连线明细表格
- 底部：轨迹记录（所有操作步骤）

### 6. 撤销/重做
使用顶部工具栏的按钮：
- 撤销：恢复上一步
- 重做：恢复撤销的步骤
- 清空当前：清空整个批次，开始新的工作
- 导出结果：导出为HTML文件

### 7. 导出结果
点击「导出结果」按钮，会下载一个以批次号命名的HTML文件，包含：
- 批次信息
- 连线明细
- 所有备注内容
- 颜色状态和处理意见

## 颜色含义

节点颜色代表不同的营养级：
- 🔵 蓝色 - 生产者
- 🟢 绿色 - 初级消费者
- 🟠 橙色 - 次级消费者
- 🟣 紫色 - 三级消费者
- 🔴 红色 - 顶级捕食者
- 🔵 青色 - 分解者

连线颜色：
- 🟢 绿色 - 层级关系正常
- 🟠 橙色 - 跨层级连接（需要确认）
