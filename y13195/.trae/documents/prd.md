## 1. 产品概述

滑轮组张力实验复算系统——面向实验老师的轻量复核工具，解决设备铭牌数据与人工备注、系统报警之间不一致的问题。核心能力：把参数版本、异常点、晚到附件的影响、判断修改历史放在同一页面上，让接班人能追溯到原始说法，而不是只看到一个最终结论。

- 目标用户：实验老师、算法值班人
- 核心价值：将"报警 vs 人工备注"的分歧点可视化，让复核过程可追溯、可走通

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验老师 | 默认登录 | 浏览复算记录、修改判断、查看历史 |
| 算法值班人 | 默认登录 | 浏览复算记录、按流程走一遍顺利/补录/异常记录 |

### 2.2 功能模块

1. **复算主页面**：设备铭牌列表、参数版本对比、异常点标注、晚到附件影响说明
2. **判断历史页面**：每次判断修改的完整时间线，含修改人、修改原因、修改前后值
3. **设备追踪面板**：设备编号重复时，追踪到铭牌原始数据的弹窗/侧栏

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 复算主页面 | 铭牌记录列表 | 展示3-4条设备铭牌数据，区分顺利记录、补录记录、异常记录；每条显示设备编号、额定张力、实测张力、参数版本、附件状态 |
| 复算主页面 | 参数版本与异常点 | 同一页面内展开当前参数版本号、异常点清单（标注来源：报警/人工备注/晚到附件）、异常解释文本 |
| 复算主页面 | 晚到附件影响分析 | 对含晚到附件的记录，展开说明该附件为何影响结论（原始结论 vs 补录后结论，参数变化对照） |
| 复算主页面 | 设备编号追踪 | 设备编号重复时，点击可追踪到该编号在铭牌中的原始说法（额定值、校准日期、校准单位等） |
| 判断历史页面 | 修改时间线 | 按时间倒序展示所有判断修改记录：谁在什么时间将什么判断从A改为B，修改原因是什么 |
| 判断历史页面 | 判断快照对比 | 选定某次修改，可并排查看修改前后的判断快照 |

## 3. 核心流程

实验老师打开系统 → 看到设备铭牌记录列表（含顺利/补录/异常三种状态） → 点击某条记录 → 展开该记录的参数版本、异常点、附件状态 → 若有晚到附件，自动展示"原始结论 → 补录后结论"的影响说明 → 若设备编号有重复警告，点击追踪到铭牌原始数据 → 如需修改判断，填写修改原因，系统自动记录到历史 → 下一班打开同条记录，可查看完整判断历史

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰（#1a1a2e）为底，工业蓝（#0f3460）为主色，警示橙（#e94560）为异常强调色
- **辅助色**：补录状态用淡黄（#f5c542），顺利状态用冷灰蓝（#4a6fa5），晚到附件用紫（#7b2d8e）
- **按钮风格**：扁平、小圆角（4px），悬停时底部加深2px阴影
- **字体**：标题用 JetBrains Mono（等宽，适合数据/参数展示），正文用 Noto Sans SC
- **布局**：单栏为主，卡片式展开，工业仪表盘风格
- **图标**：Lucide 图标，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 复算主页面 | 铭牌记录列表 | 紧凑卡片列表，左侧状态色条，右侧设备编号+张力值，悬停展开详情 |
| 复算主页面 | 参数版本与异常点 | 展开区域：参数版本号用等宽字体高亮，异常点用警示橙标签+来源图标 |
| 复算主页面 | 晚到附件影响分析 | 对比面板：左"原始结论"右"补录后结论"，参数变化用箭头+颜色标注 |
| 复算主页面 | 设备编号追踪 | 侧边抽屉：从右侧滑出，显示铭牌原始数据表格 |
| 判断历史页面 | 修改时间线 | 垂直时间线，节点为时间戳+操作人，展开显示修改详情 |
| 判断历史页面 | 判断快照对比 | 双栏对比面板，差异部分高亮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 列表区域固定宽度，详情展开区自适应
- 侧边抽屉最大宽度 400px
