💡 一句话说明
本工具自动整理现场照片中的滑轮组张力记录，识别单位混写和方向符号写反两类常见问题，输出可直接引用的归因报告。
📂 三类记录状态
✅
已处理
已完成单位换算或方向修正，数值可直接引用。系统自动归因，无需人工干预。
例：原始值"11.8 kN" → 换算为 11800 N
⏳
待补材料
照片模糊或数据缺失，无法自动分析。需补拍照片或补充原始数据后重新跑。
例：数值写"待确认"、照片不清晰
✋
人工改判
数值偏离较大或存在多重问题，建议结合现场情况人工复核判断。
例：边界样本、同时存在单位+方向问题
🔍 两类常见问题归因
🏷️ 单位混写问题
现场记录单位不统一（N / kN / 公斤 / 吨），导致数量级差异。 系统自动识别原单位并换算为标准单位，标注置信度。
来源行 换算系数 置信度
↔️ 方向符号写反
标注方向与张力值符号不一致（如上行侧出现负值）。 系统标记疑似写反的记录，并给出影响范围评估。
来源行 影响范围 复核建议
📊 边界样本与参数调档
什么是边界样本？
偏离均值超过 boundary_sigma 倍标准差的记录，会被标记为边界样本， 归入"人工改判"区待复核。
|Fi - μ| > σ × boundary_sigma
参数调档效果：
  • sigma = 2.0 时：边界样本 0 个（较宽松）
  • sigma = 1.5 时：边界样本 2 个（较严格）
  • 调小 sigma → 更多记录进入人工改判
📐 核心计算公式
单位换算公式
Fstd = Fraw × Kunit
将不同单位的张力值统一换算为标准单位（默认 N）。 支持 N、kN、kgf、吨力 等多种单位。
方向符号判定
sign(F) 与 sign(方向约定) 一致性校验
上行/拉应力约定为正，下行/压应力约定为负。 符号不一致时判定为方向写反疑似项。
⚙️ 可调参数一览
standard_unit N
boundary_sigma 2.0
unit_confidence_threshold 0.4
direction_confidence_threshold 0.5
tension_tolerance 0.15
所有参数均可通过命令行调整，调档后重新运行即可生成新版报告。
📌 日常使用流程
  • 第一步：将现场照片整理的JSON数据放入 data/ 目录
  • 第二步：运行 python run_attribution.py --input xxx.json --html reports/xxx.html
  • 第三步：打开报告，查看"已处理"可直接引用，"待补材料"安排补拍，"人工改判"组织复核
  • 第四步：如需调整灵敏度，修改 --boundary-sigma 等参数后重跑即可
