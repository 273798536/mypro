# 资料归档审计卡牌 - 使用说明

## 快速开始

### 1. 启动项目

```bash
# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

启动后，终端会显示本地访问地址（通常是 `http://localhost:5173`），在浏览器中打开即可开始使用。

## 游戏流程

### 启动页

1. **选择难度**：
   - 简单：8张卡牌，5分钟，20%概率出现借阅请求
   - 普通：12张卡牌，6分钟，30%概率出现借阅请求
   - 困难：16张卡牌，7分钟，40%概率出现借阅请求

2. **查看规则**：点击"查看归档规则说明"展开详细规则

3. **开始游戏**：点击"开始游戏"按钮进入游戏界面

4. **历史记录**：点击"历史记录"查看过往游戏报告

### 游戏主界面

#### 顶部状态栏
- 左侧：暂停按钮、当前卡牌进度（第X张/共X张）
- 中间：倒计时计时器（剩余30秒时会变红闪烁）
- 右侧：当前得分、连击数

#### 左侧区域
- **卡牌展示**：显示当前待处理的档案卡牌
  - 卡牌来源标签（文件卡/档案盒/保密级别/保管期限/借阅请求/归档报告）
  - 卡牌标题和内容摘要
  - 借阅标识（右上角橙色标签）
  - 规则提示标签（底部灰色标签）

- **规则提示**：显示当前卡牌的归档要点和分类参考

#### 右侧操作区

1. **选择材料分类**（必选）：
   - 合同（蓝色）
   - 发票（绿色）
   - 保密材料（红色）

2. **设置保密级别**（必选）：
   - 公开、内部、秘密、机密、绝密

3. **设置保管期限**（必选）：
   - 永久、30年、10年

4. **借阅登记**（如有借阅请求时显示）：
   - 已登记 / 未登记

5. **提交归档**：
   - 所有必选项完成后按钮可用
   - 提交后显示结果反馈

#### 结果反馈
- 回答正确：显示绿色正确标识和得分
- 回答错误：显示红色错误标识、错误类型和正确答案
- 点击"下一张"继续处理下一张卡牌

#### 暂停菜单
- 继续游戏：返回游戏
- 返回首页：结束当前游戏并返回首页

## 核心规则

### 材料分类标准

| 类型 | 特征 | 保密级别范围 | 保管期限 |
|------|------|-------------|----------|
| 合同 | 双方签署、有法律效力、涉及经济往来 | 内部~机密 | 永久/30年 |
| 发票 | 财务凭证、有税号、涉及金额 | 内部~秘密 | 30年/10年 |
| 保密材料 | 标注保密、涉及商业/技术秘密 | 秘密~绝密 | 永久/30年 |

### 评分规则

| 操作 | 得分 |
|------|------|
| 正确分类 | +10分 |
| 保密级别正确 | +5分 |
| 保管期限正确 | +5分 |
| 借阅登记正确 | +5分 |
| 全部正确连击加成 | 每次+2分（最高+10分） |
| 分类错误 | -10分，中断连击 |
| 保密级别错误 | -5分 |
| 保管期限错误 | -5分 |
| 借阅未登记 | -5分 |

### 错误类型定义

1. **分类错误**：将材料归为错误的大类（合同/发票/保密材料）
2. **保密级别错误**：所选级别与材料实际密级不符
3. **保管期限错误**：所选期限与材料类型不匹配
4. **借阅未登记**：材料有借阅记录但玩家未登记

## 数据生成说明

### 卡牌生成机制

1. **材料类型分布**：
   - 合同类：占总数的1/3
   - 发票类：占总数的1/3
   - 保密材料：占总数的1/3

2. **卡牌来源**：
   - 文件卡、档案盒、保密级别、保管期限、借阅请求、归档报告
   - 每种来源有多个预设模板

3. **借阅请求**：
   - 根据难度设置随机分配借阅请求
   - 简单模式20%、普通30%、困难40%
   - 有借阅请求的卡牌会显示橙色"借阅"标签

4. **随机化**：
   - 卡牌内容从模板中随机选择
   - 借阅人从预设名单中随机选择
   - 借阅日期为过去30天内的随机日期
   - 所有卡牌随机打乱顺序

## 报告系统

### 报告内容

1. **得分概览**：
   - 评级（S/A/B/C/D）
   - 总分、正确率、用时、正确数、最高连击

2. **错误分析**：
   - 按错误类型统计次数
   - 针对性改进建议

3. **操作明细**：
   - 每张卡牌的处理记录
   - 玩家选择 vs 正确答案对比
   - 错误类型标识
   - 每次操作的得分变化

### 导出功能

- **JSON格式**：完整的结构化数据，可用于数据分析
- **Markdown格式**：易读的文档格式，可直接保存或打印

### 历史记录

- 自动保存最近50条游戏记录
- 按时间倒序排列
- 点击任意记录查看完整报告
- 支持一键清空所有记录

## 异常路径处理

### 1. 时间耗尽

- 倒计时结束时自动结束游戏
- 已处理的卡牌会计入最终得分
- 未处理的卡牌不计入统计
- 自动生成并保存报告

### 2. 主动退出

- 点击暂停菜单中的"返回首页"
- 当前游戏结束，已处理的卡牌会计入报告
- 未处理的卡牌不计入统计

### 3. 页面刷新/关闭

- 游戏进度不会保存
- 刷新后需要重新开始游戏
- 已完成的游戏报告不受影响

### 4. 浏览器本地存储

- 游戏报告保存在浏览器的LocalStorage中
- 清除浏览器数据会删除所有历史记录
- 数据不会上传到服务器，仅保存在本地

### 5. 操作错误提示

- 未完成所有必选项时"提交归档"按钮禁用
- 有借阅请求的卡牌会高亮显示借阅登记选项
- 提交后立即显示错误提示和正确答案

## 常见问题

**Q: 游戏数据会上传吗？**
A: 不会。所有数据都保存在浏览器本地，不上传任何服务器。

**Q: 如何重置游戏进度？**
A: 点击暂停菜单的"返回首页"或直接刷新页面。

**Q: 报告保存在哪里？**
A: 报告文件会下载到浏览器的默认下载目录。

**Q: 可以在手机上玩吗？**
A: 可以，但建议在电脑上操作以获得最佳体验。
