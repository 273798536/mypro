## 1. 产品概述

赤潮监测样本复核工具——面向海岛运维人员，围绕气象预报数据线，对赤潮监测样本进行系统性复核，解决重复上报返工、异常分类不清、浮标数据晚到时结论被静默覆盖等操作痛点。跑完样例后图、表、文字说明三者对齐可查，地图联动持续生效而非一次性判断，养殖日志补录后潮汐计算自动联动更新，导出报告自解释使课题组无需回溯系统即可理解拦截原因。

- 目标用户：海岛运维人员、课题组审核人员
- 核心价值：减少返工、异常可操作、结论可追溯、导出自解释

## 2. 核心功能

### 2.1 用户角色

| 角色 | 入口方式 | 核心权限 |
|------|----------|----------|
| 海岛运维 | 系统账号登录 | 导入数据、复核异常、补录日志、导出报告 |
| 课题组 | 仅查看导出报告 | 阅读报告、理解拦截原因 |

### 2.2 功能模块

1. **工作台页面**：总览待复核样本数、异常分布、浮标数据状态、气象预报摘要
2. **样本复核页面**：逐条复核样本数据，查看图/表/文字三栏对齐，异常分类标签
3. **地图联动页面**：监测站位地图与数据联动，持续响应而非一次性判断
4. **日志补录页面**：养殖日志补录表单，提交后触发潮汐计算联动更新
5. **导出报告页面**：生成含拦截说明的自解释报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 概览卡片 | 显示待复核样本数、异常分布（按类型分）、浮标到达状态 |
| 工作台 | 气象预报摘要 | 展示当前气象预报关键参数及对应样本覆盖范围 |
| 工作台 | 最近操作流水 | 展示最近的导入、补录、导出操作记录 |
| 样本复核 | 三栏对齐视图 | 左图（折线/散点）、中表（数值表格）、右文（文字说明）三者数据同源联动 |
| 样本复核 | 异常分类标签 | 异常分为"需补材料"和"需改口径"两类，红色数字不笼统呈现 |
| 样本复核 | 浮标晚到影响提示 | 浮标数据晚到时，明确标注哪些已有结论受影响，旧结果保留而非覆盖 |
| 样本复核 | 时区校验拦截 | 潮位时区错误自动拦截，并在三栏中同步显示拦截原因 |
| 地图联动 | 站位地图 | 各监测站位在地图上标注，点击站位联动刷新对应样本数据 |

| 导出报告 | 报告生成 | 生成包含所有复核结论、异常说明、拦截原因的完整报告 |
| 导出报告 | 拦截自解释 | 报告中每个拦截项附完整因果说明，课题组无需回看系统即可理解 |

## 3. 核心流程

### 3.1 日常复核流程

海岛运维登录系统 → 查看工作台概览 → 进入样本复核 → 逐条查看三栏对齐视图 → 遇异常查看分类标签（补材料/改口径）→ 浮标晚到时查看影响范围提示 → 补录养殖日志 → 系统自动联动更新潮汐计算 → 确认无误后导出报告

### 3.2 异常处理流程

发现异常 → 系统标记异常类型（补材料 / 改口径）→ 运维按标签操作 → 补材料：上传缺失文件后系统重新校验 → 改口径：修改采样参数后系统重新计算 → 校验通过后异常标签解除

### 3.3 浮标晚到流程

浮标数据晚到 → 系统提示"以下结论受影响"并列出受影响项 → 旧结论标记为"待更新"而非删除 → 运维确认后系统重新计算 → 新结论替换旧结论，旧结论归入历史记录

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 (#0C2D48)，辅色：警示琥珀 (#E8A838)，成功绿 (#2E8B57)
- 按钮风格：圆角微凸，主操作蓝色实心，次操作灰色描边，危险操作红色
- 字体：标题用 Source Han Sans / Noto Sans SC Medium，正文用 Noto Sans SC Regular
- 布局：顶部导航 + 左侧地图/站位树 + 右侧主内容区，卡片式模块
- 图标风格：线性图标，与 lucide-react 图标库一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 概览卡片 | 3 列卡片布局，每卡片含图标+数字+趋势小箭头，背景渐变 |
| 工作台 | 气象预报摘要 | 横向滚动卡片组，每卡片含气象参数名+数值+状态标签 |
| 工作台 | 操作流水 | 时间轴列表，每条含操作类型图标+描述+时间戳 |
| 样本复核 | 三栏对齐视图 | 三栏等宽布局：左折线图(Chart)、中数据表(Table)、右文字说明(Text) |
| 样本复核 | 异常分类标签 | 行内标签样式，补材料=琥珀色标签，改口径=红色标签 |
| 样本复核 | 浮标晚到提示 | 顶部横幅式提示条，列出受影响结论编号，点击可展开详情 |
| 地图联动 | 站位地图 | 左侧地图区域占 40%，站位标记可点击，选中高亮 |
| 地图联动 | 数据联动面板 | 右侧 60% 面板，随地图选站动态刷新内容 |
| 日志补录 | 补录表单 | 表单卡片，字段分组排列，底部提交+重置按钮 |
| 导出报告 | 报告预览 | A4 纸面预览样式，含目录、正文、附录，拦截说明框高亮 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1280px
- 三栏视图在小屏下折叠为标签页切换
- 地图联动面板在小屏下改为全屏覆盖

### 4.4 设计理念

- 海洋监测工具，整体色调深沉专业，信息密度高但不拥挤
- 异常信息层次分明：警告≠错误，提示≠拦截，运维一眼可判
- 地图是核心交互入口，非装饰元素
