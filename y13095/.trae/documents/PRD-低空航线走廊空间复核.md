## 1. 产品概述

低空航线走廊空间复核系统，解决现场手工核对点位坐标二维表缺乏空间感、效率低下的问题。为现场复核人员、接手同事、教学老师提供空间可视化、历史追溯、异常高亮的一体化复核工具。

- 核心价值：将二维坐标表转换为直观的空间视图，保留完整修改历史，异常快速定位
- 目标用户：现场复核人员、换班接手同事、教学老师林姐
- 设计目标：无需精细模型，只要空间位置、异常高亮、点位来源对得上

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心需求 |
|------|----------|----------|
| 现场复核人员 | 日常点位复核 | 空间可视化、快速标记异常、添加备注截图 |
| 接手同事 | 换班接手 | 快速定位异常、视图条件可复用、避免条件丢失截图混入 |
| 教学老师林姐 | 教学/复核把关 | 判断修改留痕、快速了解样例/异常/导出入口 |

### 2.2 功能模块

1. **空间复核主视图**：2D地图空间展示、点位坐标可视化、航线走廊范围
2. **点位详情面板**：坐标来源追踪、属性展示、异常标记
3. **历史记录系统**：备注历史、截图历史、修改判断历史（保留所有版本）
4. **异常管理**：异常高亮、条件丢失截图单独分类、异常快速定位
5. **视图条件保存**：视角、筛选条件、查询条件可保存复用
6. **结果导出**：复核结果导出、异常清单导出
7. **接班指引**：样例位置、异常位置、导出入口的快速指引

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空蓝 `#0a1628`（专业沉稳），配合航空蓝 `#1e40af` 作为强调色
- **异常高亮**：警示红 `#dc2626`（闪烁动画），待复核橙 `#d97706`
- **正常状态**：航空绿 `#059669`
- **字体**：显示字体用 `JetBrains Mono`（等宽专业感），正文字体用 `Inter`（清晰易读）
- **布局**：三栏式专业布局，地图居中，左右信息面板，底部时间线
- **图标**：Lucide 线性图标，保持简洁专业
- **风格定位**：航空管制/地图专业工具风格，深色主题，高对比度，数据密度适中

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 空间复核主页面 | 2D空间视图 | Canvas 地图背景、网格坐标系、航线走廊多边形、点位标记圆点（不同颜色表示状态）、悬停tooltip |
| 空间复核主页面 | 点位列表 | 树状结构、搜索框、状态筛选标签、异常红点闪烁 |
| 空间复核主页面 | 详情面板 | 坐标卡片（经纬度/高度/来源）、状态切换按钮、备注输入框、截图上传区、历史版本切换 |
| 空间复核主页面 | 历史时间线 | 垂直时间轴、操作人头像、修改前后对比、展开/收起 |
| 空间复核主页面 | 顶部操作栏 | 视图条件下拉、异常计数器、导出按钮、指引按钮 |
| 条件丢失分类页 | 列表卡片 | 红色边框警示、截图缩略图、丢失条件说明、重新关联按钮 |

### 4.3 交互动效

- 异常点位：脉冲呼吸动画，吸引注意力
- 点位选中：扩散圆环动画，明确选中状态
- 面板展开/收起：平滑过渡动画（0.25s ease）
- 历史记录加载：时间线从下往上渐入
- 截图预览：hover 放大效果

### 4.4 响应式

- 桌面端（≥1280px）：三栏完整布局
- 平板端（768-1280px）：左右面板可收起，地图占满
- 移动端（<768px）：单栏切换，地图优先

## 5. 数据模型核心

### 核心实体

1. **点位 Point**：id、名称、经纬度、高度、来源、状态、航线编号
2. **历史记录 History**：id、点位id、操作类型、操作人、时间、旧值、新值、备注、截图
3. **视图条件 ViewPreset**：id、名称、中心点、缩放级别、筛选条件、创建人
4. **条件丢失截图 OrphanScreenshot**：id、点位id、截图、丢失原因、关联状态
