# 材料晶格应力沙盒

用于教学和评审的晶格缺陷与应力可视化工具。

## 🚀 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:3000

## 📋 使用指南

### 第一步：准备晶格节点数据

**晶格节点格式：**
```json
{
  "nodes": [
    { "id": "node_0", "position": { "x": 0, "y": 0, "z": 0 }, "type": "lattice" },
    { "id": "node_1", "position": { "x": 1, "y": 0, "z": 0 }, "type": "lattice" }
  ],
  "defects": [
    { "id": "defect_1", "type": "VACANCY", "position": { "x": 2, "y": 0, "z": 0 }, "description": "空位缺陷" }
  ]
}
```

**快速测试：** 点击左侧「正常样例」或「含异常样例」按钮

### 第二步：导入应力值

**应力数据格式：**
```json
{
  "node_0": { "xx": 100, "yy": 120, "zz": 90, "xy": 5, "yz": 3, "xz": -2 },
  "node_1": { "xx": 150, "yy": 130, "zz": 110, "xy": 8, "yz": 6, "xz": -4 }
}
```

## ⚠️ 复现异常场景

### 1. 缺陷重叠
两个缺陷位置距离 < 0.5 时触发：
```json
{
  "defects": [
    { "id": "d1", "type": "IMPURITY", "position": { "x": 0, "y": 0, "z": 0 } },
    { "id": "d2", "type": "VACANCY", "position": { "x": 0.1, "y": 0.1, "z": 0.1 } }
  ]
}
```

### 2. 应力爆炸
任意节点应力大小 > 1000 时触发：
```json
{
  "node_0": { "xx": 2000, "yy": 1800, "zz": 1500, "xy": 0, "yz": 0, "xz": 0 }
}
```

### 3. 节点越界
节点位置超出 ±5 范围时触发：
```json
{
  "nodes": [
    { "id": "node_out", "position": { "x": 6, "y": 3, "z": 0 }, "type": "lattice" }
  ]
}
```

## 🎮 交互操作

| 操作 | 方式 |
|------|------|
| 旋转视角 | 鼠标左键拖动 |
| 平移视图 | 鼠标右键拖动 |
| 缩放 | 滚轮 |
| 查看详情 | 点击节点/缺陷/异常标记 |
| 取消选择 | 点击空白处 |

## 🎨 图例

### 缺陷类型
- 🔴 VACANCY - 空位缺陷
- 🟠 INTERSTITIAL - 间隙原子
- 🟡 DISLOCATION - 位错
- 🟢 GRAIN_BOUNDARY - 晶界
- 🟣 IMPURITY - 杂质原子

### 异常标记
- 🔴 应力爆炸 - 严重
- 🟠 节点越界 - 错误
- 🟡 缺陷重叠 - 警告

## 📊 应力色阶
蓝 → 青 → 绿 → 黄 → 红（低应力 → 高应力）
