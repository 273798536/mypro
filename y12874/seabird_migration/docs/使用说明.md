# 海鸟迁徙观测归并 - 使用说明

## 一、启动

1. 进入项目目录：`cd seabird_migration`
2. 安装依赖：`pip install -r requirements.txt`
3. 启动应用：`streamlit run app.py`
4. 浏览器会自动打开页面，地址一般是 `http://localhost:8501`

## 二、导入数据

左侧边栏操作：

1. **加载样例数据**：点击「📦 加载样例数据」按钮，可直接体验完整功能
   - 样例数据包含21条观测、96条潮汐、54条船舶轨迹、18张照片
   - 预置了潮位时区错误、照片晚到、船舶补录等典型场景

2. **导入自有数据**（开发中）：
   - 支持 Excel / CSV 格式
   - 分别导入海鸟观测、潮汐、船舶轨迹、照片记录四类数据
   - 导入后系统自动归并

3. **重新归并**：补录数据后，点击「🔄 重新归并计算」，地图和图表会同步更新

## 三、查看异常

打开应用后，异常记录不会藏在汇总里，会在多个位置显式提示：

### 1. 顶部概览区
- 直接显示「无效记录数」「潮位时区错误数」「照片晚到数」
- 红色提示条：潮位时区错误的记录数量和影响
- 橙色提示条：照片晚到的记录数量

### 2. 记录明细表格
- 🔴 **红色行**：无效记录（如潮位时区错误）
- 🟠 **橙色行**：照片晚到的记录
- 🔵 **蓝色行**：附近有船舶活动的记录

### 3. 「⚠️ 异常记录详情」区域
三个标签页分别查看：
- **🚫 无效记录**：为什么无效、受什么影响、怎么处理
- **📷 照片晚到**：哪些结论可能不准、需要重新核对什么
- **🚢 船舶干扰**：哪些观测时段附近有船

每条异常都能展开看详细说明，包括：
- 问题原因
- 受影响的结论
- 处理建议

## 四、导出结果

底部「📤 导出结果」区域，两种导出方式：

### 1. Excel 完整报告
- 包含5个工作表：汇总、全部记录、有效记录、无效记录、异常明细
- 适合留档和进一步分析

### 2. 不可用记录说明（文字版）
- 专门列出不能用的记录和原因
- 适合发给船队，让他们直接知道哪些记录不能用、为什么被拦下
- 重点说明：潮位时区错为什么会导致记录无效

## 五、月底转交提示

给船队交报告时，建议同时提供：
1. Excel 完整报告（留档用）
2. 不可用记录文字说明（船队重点看哪些记录不能用）

船队更关心的是**哪些记录不能用、为什么不能用**，而不是系统有多少菜单。
文字版说明就是为此准备的，直接发过去就能看懂。
