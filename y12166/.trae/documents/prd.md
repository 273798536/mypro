## 1. 产品概述

游泳池水循环仿真系统——面向场馆运维人员，将池水体积、泵流量、余氯衰减与电价时段纳入统一仿真，解决日常对账对齐难题，并在余氯偏低、泵停机、客流突增等异常场景下给出可追溯的排程建议与说明。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 场馆运维 | 直接使用 | 查看仿真、导出报告、调整参数 |
| 技术主管 | 直接使用 | 审核排程建议、确认异常说明 |

### 2.2 功能模块

1. **仿真总览页**：参数输入面板、仿真运行控制、关键指标卡片、时序图表
2. **排程建议页**：电价时段对齐排程、泵启停建议、余氯补给时机
3. **异常追溯页**：异常事件列表、事件→计算链路追踪、说明报告导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仿真总览页 | 参数面板 | 输入池体积、泵流量、初始余氯、客流曲线等 |
| 仿真总览页 | 仿真控制 | 选择场景(正常/余氯低/泵停机/客流突增)，一键运行 |
| 仿真总览页 | 指标卡片 | 实时显示循环周期、当前余氯、电费成本、异常计数 |
| 仿真总览页 | 时序图表 | 24h 余氯曲线 + 泵运行状态 + 电价时段叠加图 |
| 排程建议页 | 电价排程表 | 按24h时段展示峰/谷/平电价与建议泵启停 |
| 排程建议页 | 余氯补给建议 | 标注余氯低于阈值的时段及投加建议 |
| 排程建议页 | 成本对比 | 不同排程方案电费对比 |
| 异常追溯页 | 异常事件列表 | 按时间排列所有异常事件，含类型、时段、影响 |
| 异常追溯页 | 追溯链路 | 从异常事件可跳转查看对应的水循环计算、余氯预测、排程建议 |
| 异常追溯页 | 报告导出 | 导出 CSV，结论与界面/终端摘要完全一致 |

## 3. 核心流程

用户输入池体参数与场景 → 系统运行水循环仿真引擎 → 计算逐时段循环水量、余氯衰减与补给 → 叠加电价时段生成排程 → 检测异常(余氯低/泵停机/客流突增) → 展示图表与指标卡片 → 生成可追溯异常说明 → 导出一致性报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝(#0A2540) + 水蓝(#00D4FF) 辅助白/浅灰，营造专业水务监控氛围
- 按钮：圆角8px，主按钮水蓝填充，次按钮描边
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数字用 JetBrains Mono
- 布局：左侧固定导航栏 + 右侧内容区，卡片式分区
- 图标风格：线性图标，与水/泵/电相关

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仿真总览页 | 参数面板 | 表单输入框，分组排列，滑块调整泵流量 |
| 仿真总览页 | 指标卡片 | 4个横向卡片，数值突出，异常红色标记 |
| 仿真总览页 | 时序图表 | 三轴叠加：余氯(线)、泵状态(柱)、电价(背景色) |
| 排程建议页 | 电价排程表 | 24格时间轴，峰红/谷绿/平灰填色 |
| 排程建议页 | 余氯补给 | 虚线标注阈值，箭头标注投加点 |
| 异常追溯页 | 事件列表 | 时间轴左侧，事件卡片右侧，可点击展开追溯链 |
| 异常追溯页 | 追溯链路 | 树状链接：异常→计算参数→公式→结果 |

### 4.3 响应式

- 桌面优先，最小宽度1280px
- 表格和图表在窄屏下横向滚动

### 4.4 数据一致性约束

- 导出CSV中泵流量相关结论必须与界面指标卡片和终端摘要数值完全一致
- 异常说明中的时段引用必须与图表标注一致
- 同一仿真运行的所有输出共享同一份计算结果，不可二次计算导致偏差
