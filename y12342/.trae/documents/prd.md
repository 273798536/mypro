## 1. 产品概述

小球碰撞动量复盘工具是面向物理教师的实验数据处理平台，解决质量缺失、方向反号、能量损失等异常数据的分析与追溯问题。

- 核心用途：导入速度记录和质量表，自动计算动量与能量，可视化展示碰撞前后的数据变化
- 目标用户：物理教师、实验教研人员
- 产品价值：提升实验数据复盘效率，完整保留数据来源与计算链路，便于复核与追溯

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 物理教师 | 无需注册，本地使用 | 导入数据、查看分析、导出报告 |

### 2.2 功能模块
1. **数据导入页**：速度记录导入、质量表导入、视频备注上传
2. **分析概览页**：碰撞列表、动量趋势图、能量对比图
3. **详情追溯页**：单条碰撞记录的完整计算链路、异常标记、源数据关联
4. **报告导出页**：包含异常说明的完整实验报告生成

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|
| 数据导入页 | 文件上传区 | 支持CSV/Excel格式的速度记录和质量表导入 |
| 数据导入页 | 数据预览 | 展示导入的原始数据，区分来源文件 |
| 分析概览页 | 碰撞记录列表 | 展示所有碰撞事件，标记异常状态 |
| 分析概览页 | 动量趋势图 | 碰撞前后动量变化可视化 |
| 分析概览页 | 能量对比图 | 动能损失可视化展示 |
| 详情追溯页 | 计算链路 | 从原始数据到最终结果的完整计算过程 |
| 详情追溯页 | 异常解释 | 质量缺失、方向反号、能量损失的具体说明 |
| 详情追溯页 | 源数据关联 | 速度记录、质量表与计算结果的对应关系 |
| 报告导出页 | 报告预览 | 完整报告内容预览 |
| 报告导出页 | 导出配置 | 选择导出格式和包含内容 |

## 3. 核心流程

用户导入速度记录和质量表 → 系统自动匹配碰撞事件 → 计算动量与能量并检测异常 → 用户浏览分析概览 → 点击单条记录查看详细计算链路 → 确认后导出包含异常说明的完整报告

```mermaid
    C --> D["检测异常状态"]
    D --> E["分析概览展示"]
    E --> F["查看详情追溯"]
    F --> G["导出完整报告"]
```

## 4. 界面设计

### 4.1 设计风格
- 主色调：深蓝色 #1e3a5f（专业、稳重），辅助色：青色 #0ea5e9（数据可视化）
- 按钮风格：简约圆角按钮，悬停有轻微阴影
- 字体：思源宋体（标题）+ 等宽字体（数据展示）
- 布局：顶部导航 + 侧边数据面板 + 主内容区
- 图标：简洁线性图标，异常状态使用醒目的警示色

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|----------|--------|
| 数据导入页 | 文件上传区 | 拖拽区域、文件图标、上传进度条 |
| 分析概览页 | 碰撞列表 | 卡片式列表、异常标记徽章、状态颜色区分 |
| 分析概览页 | 图表区 | 双图表并排布局、交互式悬停提示 |
| 详情追溯页 | 计算链路 | 时间线布局、箭头连接、步骤高亮 |
| 详情追溯页 | 源数据区 | 表格展示、文件来源标记、可展开详情 |

### 4.3 响应式
- 桌面端优先设计，支持平板适配
- 数据表格支持横向滚动
- 图表在小屏幕自动堆叠

### 4.4 动画效果
- 页面加载：元素淡入+轻微上移动画
- 数据更新：数值变化有平滑过渡动画
- 异常提示：呼吸效果吸引注意力
