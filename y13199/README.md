# 滑轮组张力报告导出系统

> 给维修师傅阿岑和排班同事的一站式工具。  
> 不用再从维修备注里东拼西凑——公式、单位、边界值、后补备注，全在明处。

---

## 阿岑看这里：先跑哪条命令

### 第一步：启动系统

在项目根目录打开终端，按顺序执行：

```bash
# 1. 安装依赖（第一次用或有人更新了代码时才需要）
npm install

# 2. 启动开发服务器（日常使用从这步开始）
npm run dev
```

看到 `VITE ready` 和 `http://localhost:5173/` 后，用浏览器打开这个地址。

### 第二步：按场景看页面

| 你现在要做的事 | 打开的页面 | 页面路径（左侧导航栏） |
|---|---|---|
| **录入新设备的张力测量值，生成报告** | 报告生成页 | `/` （默认首页 / 报告生成） |
| **查今天哪些设备处理完了、哪些还缺材料、哪些需要人工改判** | 排班摘要页 | `/summary` （排班摘要） |
| **先看看某个设备编号是不是已经录过了（去重）** | 设备校验页 | `/verify` （设备校验） |

## 每个页面有什么材料（像现场会收到的一包材料）

### 1️⃣ 报告生成页（首页）

这页给阿岑录入数据时用，你会看到：

| 区块 | 内容说明 | 为什么需要 |
|---|---|---|
| **公式展示区**（左侧上方） | 公式 `F = (W × g) / n`，每个符号的含义与单位，三条边界判据（正常/临界/超限） | 不用记公式，每个数字从哪来都有出处，周一早会能讲给不看代码的人听 |
| **测量值输入区**（右侧上方） | 设备编号、载荷重量 W（kg）、滑轮组数 n（正整数）、重力加速度 g（m/s²，默认 9.81） | 输入框带单位后缀，不用自己换单位 |
| **计算结果区** | 大号张力值（kN）+ 彩色状态徽标（绿=正常 / 橙=临界 / 红=超限），展开能看到**逐行计算过程** | 数字不是凭空吐出来的，每一步都有线索 |
| **设备校验区**（左侧下方） | 输入设备编号后点击"校验编号重复"，如果重复了：显示**原因**、列出所有历史报告（点击可切换覆盖目标），必须二选一：「覆盖旧报告」或「新建子报告」，选择后会绿色确认栏显示最终要覆盖的编号 / 新子编号（如 `PUL-001-S1`），保存按钮才会解除锁定 | 防阿岑手滑重复录入同一条设备；且覆盖/子报告会真正写入，不再只是标记为人工改判 |
| **后补备注区** | 一个文本框填现场补充说明，下方自动生成"联动结论"——备注和结论之间有一根绿色联动条 | 不用备注拼在最后，改备注结论自动跟着变 |
| **页面摘要区** | 保存后生成一段话：`设备XXX｜张力 XX.XX kN｜判定：X｜已附备注`，外加四个关键信息卡片 | 给排班同事和早会汇报的"一句话总结" |
| **保存 / 打印 / 重置** 按钮 | 保存 = 生成报告入库存；打印 = 浏览器打印成 PDF；重置 = 清掉重填 | 一键导出，不用截图 |

### 2️⃣ 排班摘要页

这页给排班同事看，三栏分开，一眼看清状态：

| 栏位 | 颜色 | 什么意思 |
|---|---|---|
| **已处理** | 松石绿 | 计算正常 + 后补备注填了 + 不需要人工介入，可以归档 |
| **待补材料** | 琥珀橙 | 测量值可能填了，但**后补备注是空的**，等阿岑补完现场说明 |
| **人工改判** | 铁锈红 | 两种情况：① 设备编号被检测重复了 ② 张力超限（> 80 kN），得人工确认后才能处理 |

页面顶部还有三张数字卡片，显示每类有几条 + 占比条，不用数卡片。

### 3️⃣ 设备校验页

这页专门卡重复编号，给爱较真的人用：

1. 输入设备编号 → 点"校验"
2. **没重复**：绿色提示，直接去报告生成页录入
3. **重复了**：
   - 红色"原因"框：说明这个编号已有几条历史报告
   - "下一步"指引：该覆盖还是新建子报告
   - 历史报告表格：每条的录入时间、张力值、当前状态，点垃圾桶可以删错录的那条
4. 下方还有一份**全部报告列表**，方便整体清档

## 公式与边界值速查（早会提词）

> 讲给不看代码的人听的版本：

```
F = (W × g) / n
```

| 符号 | 中文 | 单位 |
|---|---|---|
| F | 滑轮组张力 | kN（千牛） |
| W | 载荷重量 | kg（公斤） |
| g | 重力加速度 | m/s²（默认 9.81，一般不用改） |
| n | 滑轮组数 | 正整数（1、2、3……不能是 0） |

**边界判据**：

- ✅ **正常**：F ≤ 50 kN → 绿色
- ⚠️ **临界**：50 kN < F ≤ 80 kN → 橙色，下次巡检重点关注
- ❌ **超限**：F > 80 kN → 红色，必须人工改判 + 复检

## 数据存在哪儿

所有报告存在**浏览器的 LocalStorage**里（叫 `tension-report-store`），关掉浏览器不会丢。要换电脑 / 把数据带出去：
- 打开「报告生成页」→ 点「打印/导出」下拉菜单
  - **导出 TXT 报告**：下载一份人能直接读的文本（含公式、计算过程、边界判定、备注、结论、状态）
  - **导出 JSON 报告**：下载结构化数据，可导入到别的系统
  - **复制文本到剪贴板**：直接粘到邮件 / 工单里
  - **打印为 PDF**：浏览器原生打印，选「另存为 PDF」即可
- 也可以打开「排班摘要页」把每张卡片截图或打印。
