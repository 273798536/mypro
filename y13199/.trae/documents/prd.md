## 1. 产品概述

滑轮组张力报告导出系统——面向维修班组的一站式张力报告生成与管理工具。将以往散落在维修备注中的张力数据、公式出处、边界判据整合为可追溯、可复盘的结构化报告，使非技术人员也能看懂数字从何而来。

- 目标用户：维修师傅（如阿岑）、排班同事、周一早会汇报者
- 核心价值：把"备注硬拼"升级为"公式可溯、单位可查、边界可判、结论可链"的专业报告链路

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 维修师傅 | 输入设备编号与测量值 | 录入数据、触发计算、导出报告 |
| 排班同事 | 查看排班摘要页面 | 查看已处理/待补材料/人工改判状态 |
| 早会汇报者 | 查看报告页面摘要 | 查看公式来源、单位说明、边界判定依据 |

### 2.2 功能模块

1. **报告生成页**：输入设备编号与张力测量值，自动计算并展示公式、单位、边界值，导出完整报告
2. **排班摘要页**：按状态分类展示所有报告——已处理、待补材料、人工改判，供排班同事快速浏览
3. **设备校验页**：设备编号重复时拦截，给出原因与下一步操作指引

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 报告生成页 | 公式展示区 | 展示张力计算公式 F = (W × g) / n，标注每个符号含义与单位 |
| 报告生成页 | 测量值输入区 | 输入设备编号、载荷重量W、滑轮组数n、重力加速度g |
| 报告生成页 | 计算结果区 | 展示计算过程与最终张力值，边界值高亮（超限红色、临界橙色、正常绿色） |
| 报告生成页 | 后补备注区 | 关联后补备注文本，与最终结论形成联动链路 |
| 报告生成页 | 页面摘要 | 一段话总结：设备编号、张力值、判定结果、备注状态 |
| 报告生成页 | 导出操作 | 一键导出 PDF/打印友好格式报告 |
| 排班摘要页 | 已处理列表 | 所有已完成计算且无需人工干预的报告卡片 |
| 排班摘要页 | 待补材料列表 | 缺少必要输入数据或后补备注未填的报告卡片 |
| 排班摘要页 | 人工改判列表 | 因设备编号重复或边界超限需人工确认的报告卡片 |
| 排班摘要页 | 统计概览 | 三类数量汇总与占比 |
| 设备校验页 | 重复检测 | 输入设备编号时实时校验是否重复 |
| 设备校验页 | 原因说明 | 重复时展示原因（已有报告编号、录入时间、录入人） |
| 设备校验页 | 下一步指引 | 提供"覆盖旧报告"或"新建子报告"选项 |

## 3. 核心流程

用户输入设备编号 → 系统校验是否重复 → 若重复，展示原因与操作选项 → 输入测量值 → 系统按公式计算张力 → 展示计算过程与边界判定 → 填写后补备注 → 系统关联备注与结论 → 生成页面摘要 → 导出报告 → 排班摘要页自动更新状态

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深钢蓝 (#1B3A5C)——工业/工程气质
- 辅助色：琥珀橙 (#E8A838) 用于警告/临界、铁锈红 (#C44D3F) 用于超限/错误、松石绿 (#2D9B83) 用于正常/已处理
- 按钮风格：圆角矩形、微阴影、hover 时颜色加深
- 字体：正文用 Noto Sans SC，数据/公式用 JetBrains Mono
- 布局风格：左侧导航栏 + 右侧内容区，卡片式布局，公式区用等宽字体背景板突出
- 图标风格：线性图标（lucide-react）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 报告生成页 | 公式展示区 | 等宽字体背景板、符号注释行、单位标签 |
| 报告生成页 | 测量值输入区 | 输入框组（带单位后缀）、设备编号实时校验徽标 |
| 报告生成页 | 计算结果区 | 大号数字 + 单位、彩色状态徽标、计算过程折叠面板 |
| 报告生成页 | 后补备注区 | 文本域 + 结论预览、联动标记线 |
| 报告生成页 | 页面摘要 | 卡片式摘要框、关键数字加粗、状态标签 |
| 排班摘要页 | 三栏列表 | 状态色块标签、卡片列表、数量统计条 |
| 设备校验页 | 重复提示 | 警告卡片、历史报告信息表、操作按钮组 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px，关键数据在窄屏下以堆叠卡片展示

### 4.4 动效

- 公式区加载时逐行淡入
- 边界判定结果出现时脉冲动画
- 页面摘要生成时从模糊到清晰的渐显效果
- 卡片状态变更时轻微弹跳
