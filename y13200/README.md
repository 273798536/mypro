# 巡演耳返版本复核系统

面向现场音频制作流程的专业协作工具，解决厂牌运营与现场老师在耳返音频版本复核过程中的效率痛点。

## 核心功能

- **文件名智能匹配**：自动解析文件名，与曲目表智能匹配，解决"文件名和曲目表对不上"的痛点
- **版本管理**：多版本保留不删除，后补材料覆盖前强制确认，不覆盖早先判断
- **时码偏差检测**：超过500ms自动挂起，宁可挂起也不给假稳定结论
- **备注历史**：字段级版本历史，改动进历史，不只是改当前页
- **全链路追溯**：图表 → 明细 → 材料 → 历史，异常点一路点回
- **状态看板**：待处理/处理中/已完成三栏布局，一目了然
- **CSV多模板导出**：现场沟通版、运营核对版、完整明细版、时码专项版

## 技术栈

- **前端**：React 18 + TypeScript + Vite + Ant Design 5.x + ECharts
- **后端**：NestJS + TypeScript + Prisma + SQLite
- **核心算法**：Jaro-Winkler字符串相似度、文件名解析引擎、时码偏差检测

## 快速开始

### 1. 安装依赖

```bash
npm run install:all
```

### 2. 初始化数据库

```bash
npm run db:init
```

### 3. 启动开发服务

```bash
npm run dev
```

- 前端地址：http://localhost:5173
- 后端API：http://localhost:3001/api
- API文档：http://localhost:3001/api/docs

### 4. 单独启动

```bash
# 只启动后端
npm run dev:server

# 只启动前端
npm run dev:client
```

## 核心流程

### 文件名匹配流程
1. 运营上传音频文件
2. 系统自动解析文件名（曲目号、曲名、艺人、版本）
3. 与曲目表多维度匹配（序号、名称相似度、艺人、时长）
4. 置信度≥90%自动匹配，70-90%建议匹配，<70%人工介入

### 时码挂起流程
1. 系统检测时码偏差
2. ≤100ms自动通过，100-500ms警告，>500ms自动挂起
3. 挂起项进入现场老师待办清单
4. 现场老师确认：接受偏差 / 驳回重录 / 继续挂起

### 版本管理流程
1. 新批次材料到达
2. 检查是否已有版本，有则计算diff
3. 弹框确认是否覆盖，必填覆盖原因
4. 旧版本保留在历史记录中，不删除
