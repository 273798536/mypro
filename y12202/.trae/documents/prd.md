## 1. 产品概述

小微贷款展期审批系统——面向信贷运营人员的展期全流程管理工具，解决重复展期、逾期遮盖、担保过期等风险路径不可见、审批留痕与日常状态口径不一致的问题。

- 目标用户：信贷运营人员、审批人员、风控复核人员
- 核心价值：让每一次展期的原始材料、处理结果、风险标记全程可追溯，导出报告与页面展示口径一致，重复展期失败路径清晰可见

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 信贷运营人员 | 系统分配 | 录入借款合同、发起展期申请、查看审批状态、导出报告 |
| 审批人员 | 系统分配 | 审批展期申请、添加审批意见、查看风险标记 |
| 风控复核人员 | 系统分配 | 复核风险项、查看审计轨迹、导出复核清单 |

### 2.2 功能模块

1. **工作台**：待办事项汇总、风险预警概览、近期展期动态
2. **借款合同管理**：合同录入与查询、关联担保资料、还款流水记录
3. **展期申请**：发起展期、材料归集（区分来源）、自动风险检测
4. **审批留痕**：审批流程记录、操作影响链路、审批意见归档
5. **风险检测中心**：重复展期识别、逾期遮盖标记、担保过期预警、风险路径可视化
6. **导出中心**：审批清单导出（含风险项）、复核报告导出、口径一致性校验

## 3. 核心流程

**展期申请与审批流程：**

信贷运营人员选择借款合同发起展期申请 → 系统自动检测风险项（重复展期/逾期遮盖/担保过期） → 风险项标记并通知审批人员 → 审批人员查看材料与风险标记，提交审批意见 → 系统记录审批留痕与影响链路 → 展期状态更新（日常处理与审批留痕同步） → 可导出含风险项的报告

```mermaid
flowchart TD
    "选择借款合同" --> "填写展期信息"
    "填写展期信息" --> "上传材料(标记来源)"
    "上传材料(标记来源)" --> "自动风险检测"
    "自动风险检测" --> "检测结果"
    "检测结果" --> "无风险: 提交审批"
    "检测结果" --> "有风险: 标记风险项"
    "有风险: 标记风险项" --> "提交审批(含风险标记)"
    "无风险: 提交审批" --> "审批人员审核"
    "提交审批(含风险标记)" --> "审批人员审核"
    "审批人员审核" --> "通过: 更新展期状态"
    "审批人员审核" --> "驳回: 记录驳回原因"
    "通过: 更新展期状态" --> "同步审批留痕"
    "驳回: 记录驳回原因" --> "同步审批留痕"
    "同步审批留痕" --> "可导出报告"
```

**重复展期检测流程：**

```mermaid
flowchart TD
    "发起展期申请" --> "查询该合同历史展期"
    "查询该合同历史展期" --> "展期次数 >= 2"
    "展期次数 >= 2" --> "是: 标记重复展期风险"
    "展期次数 >= 2" --> "否: 继续检测"

    "高亮失败路径" --> "风险项写入报告"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青灰(#1a2332)为底，琥珀色(#d4920b)为警示强调，翡翠绿(#0d9465)为通过状态
- **辅助色**：石板灰(#64748b)为次要文字，浅灰(#f1f5f9)为卡片背景，红色(#dc2626)为严重风险
- **按钮风格**：圆角(6px)，扁平化，主要操作使用实色填充，次要操作使用描边
- **字体**：标题使用 Noto Serif SC(衬线体，体现金融严肃感)，正文使用 Noto Sans SC(无衬线，清晰可读)
- **布局风格**：左侧固定导航(220px)，右侧内容区，卡片式模块，表格数据区使用斑马纹
- **图标风格**：线性图标(Lucide)，24px，与文字间距8px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 待办汇总 | 三列卡片(待审批/待复核/风险预警)，数字使用大字号，点击跳转对应列表 |
| 工作台 | 风险预警卡片 | 横向滚动卡片组，每张卡片含风险类型图标+数量+最近时间，红色边框标记严重风险 |
| 工作台 | 近期展期动态 | 垂直时间线，每节点含时间戳+操作人+操作摘要，风险节点使用琥珀色圆点 |
| 借款合同管理 | 合同列表 | 表格布局，支持多列排序与筛选，状态列使用彩色标签 |
| 借款合同管理 | 合同详情 | 上方基础信息区(两栏布局)，下方Tab切换(担保/还款/展期历史) |
| 借款合同管理 | 展期历史链路 | 横向时间线图，每个展期节点可展开详情，失败路径用红色虚线连接 |
| 展期申请 | 新建展期 | 分步表单(3步)，每步自动保存草稿(刷新不丢失)，右侧风险检测实时面板 |
| 展期申请 | 材料来源区分 | 左右分栏：左栏"原始材料"(合同/担保)，右栏"处理结果"(申请/审批)，来源人标签 |
| 审批留痕 | 审批时间线 | 垂直时间线，每步含操作人头像+姓名+操作时间+操作内容，支持展开详情 |
| 审批留痕 | 影响链路图 | 树状关联图，节点为操作人，连线标注影响类型，hover显示详情 |
| 风险检测中心 | 风险列表 | 三列看板(重复展期/逾期遮盖/担保过期)，卡片展示每个风险项详情 |
| 风险检测中心 | 风险路径可视化 | 交互式时间线，合同-展期-逾期-担保节点可点击，风险段高亮+背景色区分 |
| 导出中心 | 导出配置 | 表单选择导出类型+时间范围，预览区展示将要导出的数据摘要与风险项数量 |

### 4.3 响应式

- 桌面优先设计，最小宽度1280px
- 1280px-1440px：紧凑布局，侧边栏可折叠
- 1440px以上：完整布局，内容区最大宽度1400px居中

### 4.4 数据持久化策略

- 展期申请表单使用 localStorage 自动保存草稿，刷新页面不丢失
- 审批操作即时持久化到数据库，不做纯前端状态
- 展期状态与审批留痕在数据库层面通过事务保证一致性
