## 1. 产品概述

商票兑付优先队列管理系统——面向供应链金融运营团队的本地化工作台，解决票据重复、插队争议与现金缺口等场景下需同时翻阅商票登记、现金计划和队列报告却手工易漏的痛点。系统将商票登记、现金计划、兑付申请等线索自动归集为同一事件，支持新增、复核、状态推进与导出的全流程真实数据操作，并提供从结果追到队列排序、资金锁定与状态推进的全链路追溯能力。

- 目标用户：供应链金融运营团队（运营专员、复核岗、资金管理岗）
- 核心价值：消除重复票据漏检、插队争议无据、现金缺口无预警的运营风险，实现"一票一档、一事一链、一报直达"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 运营专员 | 工号登录 | 新增商票登记、提交兑付申请、查看队列与报告 |
| 复核岗 | 工号登录 | 复核商票登记、审批兑付申请、处理争议与异常 |
| 资金管理岗 | 工号登录 | 管理现金计划、资金锁定与释放、查看资金缺口预警 |

### 2.2 功能模块

1. **兑付队列看板**：优先队列总览、状态推进操作、重复票据预警、插队争议标记、资金锁定指示
2. **事件追踪**：商票登记/现金计划/兑付申请自动归集到同一事件、全链路追溯、异常诊断（触发材料→卡点→下一步补料）
3. **报告与导出**：队列报告生成（含资金锁定口径）、一键导出与转交同事、转交后无需回来追问口径

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 兑付队列看板 | 队列总览 | 按优先级排序的商票兑付队列，显示票号、金额、到期日、优先级分数、当前状态、资金锁定状态 |
| 兑付队列看板 | 状态推进栏 | 对选中票据执行新增→待复核→已复核→待兑付→已兑付的状态推进操作，需权限校验 |
| 兑付队列看板 | 重复票据预警 | 自动检测票号/金额/出票人重复，以醒目标记提示，点击跳转事件追踪 |
| 兑付队列看板 | 插队争议标记 | 对优先级异常的票据标记争议，记录争议原因与申诉材料 |
| 兑付队列看板 | 资金锁定指示 | 每条票据显示对应现金计划中的资金锁定状态（已锁定/待锁定/缺口） |
| 兑付队列看板 | 快速筛选 | 按状态、到期日范围、出票人、资金锁定状态筛选队列 |
| 事件追踪 | 事件时间线 | 将商票登记、现金计划、兑付申请按时间线归集到同一事件，显示触发材料与操作记录 |
| 事件追踪 | 异常诊断面板 | 针对重复/争议/缺口三类异常，显示：触发材料→当前卡点→下一步需补材料 |
| 事件追踪 | 全链路追溯 | 从任意结果（如"已兑付"或"被拒"）回溯到队列排序依据、资金锁定记录、每步状态推进的操作人与时间 |
| 事件追踪 | 关联线索搜索 | 输入商票登记号/现金计划号/兑付申请号任一线索，定位到同一事件 |
| 报告与导出 | 队列报告生成 | 生成包含队列排序、资金锁定口径、异常清单的结构化报告 |
| 报告与导出 | 一键导出 | 导出为 Excel / PDF 格式，含完整资金锁定口径说明 |
| 报告与导出 | 转交同事 | 选择接收人，附带资金锁定口径说明一键转交，接收人无需追问口径 |

## 3. 核心流程

### 3.1 商票兑付全流程

运营专员新增商票登记 → 系统自动检测重复 → 无重复则进入待复核 → 复核岗审核 → 审核通过则关联现金计划锁定资金 → 进入待兑付队列 → 兑付完成标记已兑付。若检测到重复或争议，系统自动创建异常事件，触发异常诊断流程。

```mermaid

    "新增商票登记" --> "重复检测"
    "重复检测" -->|"无重复"| "待复核"
    "重复检测" -->|"发现重复"| "创建异常事件"
    "待复核" --> "复核岗审核"
    "复核岗审核" -->|"通过"| "关联现金计划"
    "复核岗审核" -->|"驳回"| "退回补充材料"
    "关联现金计划" -->|"资金充足"| "锁定资金"
    "关联现金计划" -->|"资金缺口"| "创建缺口预警"
    "锁定资金" --> "待兑付"
    "待兑付" --> "兑付完成"
    "兑付完成" --> "释放资金锁定"
    "创建异常事件" --> "异常诊断"
    "异常诊断" --> "补充材料"
    "补充材料" --> "重复检测"
    "创建缺口预警" --> "调整现金计划"
    "调整现金计划" --> "关联现金计划"
    "退回补充材料" --> "新增商票登记"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1B2A4A）代表金融专业感，辅以琥珀金（#D4A843）标记关键状态与预警
- 次要色：石板灰（#4A5568）用于常规文本，翡翠绿（#38A169）用于成功/已兑付，珊瑚红（#E53E3E）用于异常/缺口
- 按钮风格：圆角矩形（8px），主要操作用实心深蓝灰底白字，次要操作用描边样式
- 字体：标题用 Noto Serif SC 衬线体传达稳重感，正文用 Noto Sans SC 无衬线体保证可读性
- 布局风格：左侧固定导航栏 + 右侧内容区，内容区采用卡片式布局，队列看板为全宽表格
- 图标风格：线性图标（Phosphor Icons 风格），1.5px 线宽，与字体搭配协调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 兑付队列看板 | 队列总览 | 全宽数据表格，行按优先级色带排序，状态列用彩色圆点标识，资金锁定列用锁图标+颜色（绿=已锁定、黄=待锁定、红=缺口） |
| 兑付队列看板 | 状态推进栏 | 选中行后右侧滑出操作面板，水平步骤条显示当前状态，可操作步骤用实心按钮 |
| 兑付队列看板 | 重复票据预警 | 顶部横向警示横幅，点击展开重复票据对比卡片（并排显示重复项高亮差异字段） |
| 兑付队列看板 | 插队争议标记 | 行内红色三角标记，hover 显示争议原因气泡卡片 |
| 兑付队列看板 | 资金锁定指示 | 列内锁图标+文字，hover 显示关联现金计划详情浮层 |
| 兑付队列看板 | 快速筛选 | 表头上方折叠式筛选栏，多选下拉+日期范围选择器 |
| 事件追踪 | 事件时间线 | 左侧垂直时间线，节点按类型用不同图标（登记=文件、计划=硬币、申请=箭头），右侧展开详情卡片 |
| 事件追踪 | 异常诊断面板 | 顶部三列卡片布局（触发材料→当前卡点→下一步补料），每列用不同底色区分，箭头连接 |
| 事件追踪 | 全链路追溯 | 右侧追溯路径面板，从当前状态向上回溯的面包屑式路径，每步显示操作人与时间 |
| 事件追踪 | 关联线索搜索 | 页面顶部搜索栏，输入任意线索号自动补全并跳转 |
| 报告与导出 | 队列报告生成 | 报告预览卡片，包含队列摘要统计、异常清单、资金锁定口径说明三大区块 |
| 报告与导出 | 一键导出 | 导出按钮组（Excel/PDF），点击后生成下载 |
| 报告与导出 | 转交同事 | 转交弹窗，选择接收人（下拉搜索），预填资金锁定口径说明，确认后生成转交记录 |

### 4.3 响应式设计

- 桌面优先设计（1440px 基准），表格在 1280px 以下横向可滚动
- 平板端（768-1024px）队列看板切换为卡片视图，事件时间线简化为列表
- 移动端（<768px）仅保留队列总览和关键操作入口
