## 1. 产品概述

**多声部节奏防线**是一款面向合唱指导老师和声部训练的节奏试玩原型。核心解决合唱排练中"延迟进入混入正常记录"导致的返工问题，同时提供音量失衡和休止误判的精确定位能力，让节奏判定、音量反馈和成绩导出在复盘中清晰可见、可直接转交同事。

- 目标用户：合唱指导老师、声部负责人、培训助教
- 核心价值：将多声部节奏训练中隐性的"延迟进入""音量失衡""休止误判"问题显性化、可追溯化，避免后期返工

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 指导老师 | 直接使用 | 配置关卡、查看成绩、导出报告 |
| 声部负责人 | 编辑声部轨 | 维护本声部节奏轨数据 |
| 节拍线维护者 | 编辑节拍线 | 维护全局节拍线数据 |

### 2.2 功能模块

1. **关卡选择页**：2-3个精简关卡，涵盖基础节拍、多声部进入、休止检测场景
2. **训练试玩页**：核心交互界面，多声部轨道、节拍线滚动、实时节奏判定与音量反馈
3. **成绩复盘页**：节奏判定详情、音量反馈记录、延迟进入/音量失衡/休止误判标记，含判定口径说明，支持导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 关卡选择页 | 关卡列表 | 展示2-3个关卡卡片，标注难度和训练重点 |
| 关卡选择页 | 合并冲突提示 | 若声部轨与节拍线有冲突，进入前弹窗展示冲突明细 |
| 训练试玩页 | 多声部轨道区 | 并排展示各声部节奏轨，实时滚动节拍线 |
| 训练试玩页 | 节奏判定区 | 每拍实时判定：精准/偏早/偏晚/遗漏，视觉反馈 |
| 训练试玩页 | 音量反馈区 | 实时音量柱状图，标注失衡区间 |
| 训练试玩页 | 延迟进入检测 | 声部未按时进入时实时标红警告 |
| 训练试玩页 | 休止误判检测 | 应休止但发声的区间实时标记 |
| 成绩复盘页 | 判定汇总表 | 按声部×节拍维度展示判定结果，异常项高亮 |
| 成绩复盘页 | 判定口径说明 | 附带节奏判定标准（偏早/偏晚窗口值、音量阈值等） |
| 成绩复盘页 | 导出功能 | 一键导出成绩单（JSON/CSV），含判定口径，可直接转交同事 |

## 3. 核心流程

用户选择关卡 → 系统加载声部轨与节拍线数据 → 若有合并冲突则展示冲突明细（不悄悄选一边） → 用户确认后进入训练 → 演唱/点击触发节奏输入 → 实时节奏判定与音量采集 → 延迟进入/音量失衡/休止误判实时标记 → 训练结束 → 进入成绩复盘 → 查看判定详情与口径 → 导出成绩单

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：深色音乐工作站风格，灵感来自 DAW（数字音频工作站）界面，专业感强
- **主色调**：深灰底（#1a1a2e），霓虹蓝绿强调色（#00f5d4），警告红（#ff4757），休止黄（#ffa502）
- **按钮风格**：圆角微凸，hover 时发光效果
- **字体**：标题用 `Outfit`（几何感现代字体），正文用 `IBM Plex Sans`（清晰可读）
- **布局风格**：顶部工具栏 + 左侧声部轨道面板 + 中间节拍线滚动区 + 底部音量反馈条
- **图标风格**：线性图标，lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 关卡选择页 | 关卡卡片 | 深色卡片，霓虹边框，hover 发光，显示关卡名/难度/训练重点标签 |
| 关卡选择页 | 冲突弹窗 | 双列对比布局，左侧声部轨数据，右侧节拍线数据，冲突行高亮红底 |
| 训练试玩页 | 多声部轨道 | 横向分轨，每轨独立颜色标识（S/A/T/B），音符块沿时间轴排列 |
| 训练试玩页 | 节拍线 | 垂直虚线从上到下贯穿所有轨道，随时间滚动 |
| 训练试玩页 | 判定标记 | 精准=绿圈、偏早=蓝左箭头、偏晚=橙右箭头、遗漏=红叉 |
| 训练试玩页 | 延迟进入警告 | 轨道左侧闪烁红框 + 文字"延迟进入" |
| 训练试玩页 | 音量柱 | 底部水平柱状图，实时波动，失衡区间背景变红 |
| 训练试玩页 | 休止标记 | 黄色×标记覆盖在休止区间 |
| 成绩复盘页 | 判定表格 | 声部行×节拍列矩阵，色块标记判定结果，异常单元格可点击查看详情 |
| 成绩复盘页 | 口径说明卡 | 灰底信息卡，列出判定窗口值、音量阈值等参数 |
| 成绩复盘页 | 导出按钮 | 霓虹发光按钮，点击后弹出格式选择（JSON/CSV） |

### 4.3 响应式设计

- 桌面优先设计，训练页面需要足够宽度展示多声部轨道
- 最小支持 1280px 宽度，窄屏时轨道区可横向滚动
- 触控优化：判定区域足够大，支持触屏点击输入

### 4.4 3D 场景

- 不适用，本项目为 2D 界面
