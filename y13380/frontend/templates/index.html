使用说明

  • 先跑哪条命令：项目根目录执行 python backend/app.py 启动服务，然后浏览器打开 http://localhost:9527
  • 再看哪份摘要：点击 Run ID 进入详情页，查看特征快照中被标记的异常样本(row_id)与小样本分桶
  • 改判溯源：每次人工改判都记录来源(created_by)、原结论、新结论、原因和下一步处理
  • 样本级定位：评审时不只看总体AUC，查看"可疑样本"和"小样本分桶"定位拉偏结论的具体行
