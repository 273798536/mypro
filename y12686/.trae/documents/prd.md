# 训练集嵌入空间巡检工具 - 产品需求文档

## 1. 产品概述

训练集嵌入空间巡检工具是专为水利工程师设计的专业数据质量检查平台，整合测量记录、点云切片和处理意见，提供完整的巡检工作流程。工具支持边界失败检测、撤销重开操作、结论对比分析，帮助工程师高效完成训练集质量复核工作。

**核心价值：**
- 统一工作平台：无需创建临时群，测量记录、点云切片和处理意见集中管理
- 完整操作流程：支持重复运行、补录、人工确认三大核心操作
- 可视化对比：新旧结论并排展示，清晰呈现影响范围
- 真实样例数据：包含典型的坏数据案例，贴近实际工作场景

## 2. 核心功能

| 角色 | 注册方式 | 核心权限 |

## 3. 核心流程

### 3.1 巡检工作流程

水利工程师登录系统后，选择待巡检的训练集，进入巡检工作台。系统自动加载测量记录和对应的点云切片数据，工程师可以查看3D点云可视化，并添加处理意见。

巡检流程采用关卡式设计，工程师按顺序完成各个检查关卡。如果检测到边界条件失败，系统会自动标记并提示。工程师可以选择撤销上一步操作或重新开始当前关卡。

完成所有关卡后，系统生成结算报告，展示巡检结果汇总、问题清单和统计数据。工程师可以导出报告用于评审会展示。

## 4. 用户界面设计

### 4.1 设计风格

**主题色彩：**
- 主色调：深蓝色 (#1E40AF) - 代表水利工程的专业性和可靠性
- 辅助色：青色 (#0891B2) - 代表水流和数据流动
- 警告色：橙色 (#F59E0B) - 用于标记问题和边界失败
- 成功色：绿色 (#10B981) - 表示检查通过
- 背景色：浅灰色 (#F3F4F6) - 提供舒适的阅读体验

**按钮风格：**
- 主要操作按钮：圆角矩形，深蓝色背景，白色文字
- 次要操作按钮：圆角矩形，白色背景，深蓝色边框和文字
- 危险操作按钮：圆角矩形，红色背景，白色文字
- 按钮悬停效果：轻微阴影和颜色加深

**字体和尺寸：**
- 标题字体：思源黑体 Bold，用于页面标题和重要信息
- 正文字体：思源黑体 Regular，用于内容展示
- 代码字体：JetBrains Mono，用于数据和技术信息
- 标题字号：24px - 32px
- 正文字号：14px - 16px
- 小字字号：12px

**布局风格：**
- 左侧导航栏：固定宽度240px，显示功能菜单
- 主内容区：自适应宽度，最小宽度800px
- 卡片式布局：圆角卡片，轻微阴影，模块化组织
- 顶部导航：包含用户信息、通知、帮助等

**图标风格：**
- 使用 Lucide React 图标库
- 线性图标风格，线条粗细一致
- 图标大小：16px - 24px
- 图标颜色与主题色保持一致

### 4.3 响应式设计

- 采用桌面优先设计原则，主要面向大屏幕工作站
- 最小支持宽度：1280px
- 适配常见分辨率：1920x1080, 2560x1440, 3840x2160
- 点云查看器支持全屏模式，充分利用屏幕空间

### 4.4 3D场景指导

**点云切片查看器：**
- 环境：使用深色背景，增强点云数据的对比度
- 光照：环境光 + 方向光，确保点云数据清晰可见
- 相机：透视相机，支持鼠标控制旋转和缩放
- 交互：鼠标左键旋转，右键平移，滚轮缩放
- 标注：支持在点云上添加标注点，显示详细信息
- 性能：使用点云压缩和LOD技术，确保大数据量流畅渲染

## 5. 数据需求

### 5.1 测量记录数据

每条测量记录包含：
- 记录ID：唯一标识符
- 时间戳：测量时间
- 位置信息：经纬度、高程
- 测量值：水位、流量、流速等
- 状态：正常、异常、待确认
- 关联点云：对应的点云切片ID

### 5.2 点云切片数据

每个点云切片包含：
- 切片ID：唯一标识符
- 点云数据：三维坐标点集合
- 颜色信息：RGB颜色值
- 分类信息：点云分类标签
- 边界信息：边界范围和条件

### 5.3 处理意见数据

每条处理意见包含：
- 意见ID：唯一标识符
- 关联记录：关联的测量记录ID
- 问题类型：数据异常、边界失败、质量问题等
- 意见内容：文字描述
- 附件：图片、文档等
- 创建时间：意见创建时间
- 创建人：意见创建者

### 5.4 样例数据

系统预置真实的样例数据，包含典型的坏数据案例：
- 边界条件失败案例：点云数据超出预设边界范围
- 数据缺失案例：测量记录中部分字段为空
- 数据异常案例：测量值超出合理范围
- 重复数据案例：同一位置多次测量结果不一致
- 格式错误案例：数据格式不符合规范要求

## 6. 非功能性需求

### 6.1 性能要求

- 页面加载时间：首屏加载 < 2秒
- 点云渲染：支持百万级点云数据流畅渲染（> 30 FPS）
- 数据查询：测量记录查询响应时间 < 500ms
- 操作响应：用户操作响应时间 < 200ms

### 6.2 可用性要求

- 系统可用性：99.5%
- 支持并发用户：50+
- 数据备份：每日自动备份

### 6.3 安全性要求

- 用户认证：工号 + 密码登录
- 权限控制：基于角色的访问控制
- 数据加密：敏感数据传输加密
- 操作日志：记录所有关键操作

### 6.4 兼容性要求

- 浏览器：Chrome 90+, Edge 90+, Firefox 88+
- 操作系统：Windows 10+, macOS 10.15+
- 显卡：支持 WebGL 2.0
