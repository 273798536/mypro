## 1. 产品概述

网络流瓶颈解释器是面向物流规划师的仓网优化分析工具，解决传统最大流算法只输出总数、无法定位具体瓶颈线路的问题。通过对齐仓库节点、线路容量和需求点，提供从结果追溯到求解过程、瓶颈解释和情景对比的完整链路。

核心价值：让物流规划师从"知道最大流是多少"进阶到"知道哪几条线路卡住、为什么卡住、怎么调整"，避免孤立节点遗漏和容量为零的配置错误。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 物流规划师 | 本地启动无需登录 | 查看网络流分析、追溯瓶颈、导出数据、情景对比 |
| 经理 | 本地启动无需登录 | 查看瓶颈线路汇总、导出报告 |

### 2.2 功能模块

1. **网络流总览**：最大流统计、瓶颈线路Top10、待确认异常区
2. **网络拓扑图**：交互式节点-边可视化，高亮瓶颈线路和孤立节点
3. **线路明细**：按容量利用率排序的线路列表，支持筛选和搜索
4. **瓶颈追溯**：从单条线路追溯到最大流求解过程、约束条件、相关节点
5. **情景对比**：多方案并行对比，支持调整容量后重算查看变化
6. **数据导出**：图表、明细、分析报告统一数据源导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分析看板 | 顶部统计区 | 显示最大流总量、已用容量、瓶颈线路数、待确认异常数 |
| 分析看板 | 待确认区 | 置顶显示孤立节点、容量为零、禁用未生效的线路，不与正常数据混放 |
| 分析看板 | 拓扑可视化 | SVG网络拓扑图，节点按类型着色，边粗细代表容量，红色高亮瓶颈 |
| 分析看板 | 瓶颈线路列表 | 按瓶颈严重程度排序，支持点击追溯详情 |
| 瓶颈追溯 | 求解过程 | 展示最大流算法每一步的增广路径、流量分配、剩余容量 |
| 瓶颈追溯 | 约束分析 | 列出影响该线路的上游节点容量、下游需求、跨仓依赖 |
| 情景对比 | 方案管理 | 保存多个调整方案，并排对比关键指标变化 |
| 情景对比 | 容量调整 | 滑动调整线路容量，实时重算最大流和瓶颈变化 |
| 数据导出 | 统一导出 | CSV/Excel导出，包含图表数据、线路明细、瓶颈分析，三部分来自同一数据源 |

## 3. 核心流程

```mermaid
flowchart LR
    A["加载仓网数据\n(节点/线路/需求)"] --> B["最大流求解\n(Edmonds-Karp算法)"]
    B --> C["识别瓶颈线路\n(容量利用率>90%)"]
    C --> D["检测异常\n(孤立节点/零容量/禁用未生效)"]
    D --> E["拓扑可视化\n高亮瓶颈和异常"]
    E --> F["物流规划师点击线路"]
    F --> G["瓶颈追溯面板\n求解过程 + 约束分析"]
    G --> H["情景对比\n调整容量重算"]
    H --> I["统一数据源导出\n图表+明细+报告"]
```

物流规划师核心操作路径：
1. 打开应用 → 自动加载样例仓网数据
2. 查看看板顶部待确认区 → 先处理孤立节点和零容量问题
3. 观察拓扑图红色瓶颈线路 → 点击最严重的线路
4. 追溯面板查看：该线路在最大流求解中的位置、上游约束、下游需求
5. 进入情景对比 → 调整该线路容量 → 查看最大流和瓶颈变化
6. 导出完整分析报告 → 用于汇报或后续跟进

## 4. 用户界面设计

### 4.1 设计风格

**美学方向：工业/ utilitarian 风格**
- 主色调：深海军蓝 `#0F172A` 作为底色，营造专业可靠感
- 强调色：警告橙 `#F97316` 用于瓶颈，危险红 `#EF4444` 用于待确认异常
- 辅助色：青色 `#06B6D4` 用于正常流量，琥珀黄 `#F59E0B` 用于中负载
- 按钮风格：直角、细边框、hover时轻微背景加深，无圆角无阴影
- 字体：展示字体用 `JetBrains Mono`（等宽字体，数据感强），正文用 `Inter`
- 布局：高密度信息布局，减少留白，用细边框分割区域
- 图标：Lucide线性图标，统一16px尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 分析看板 | 顶部统计区 | 4个等宽卡片，大数字+趋势箭头，底部小字标注环比变化 |
| 分析看板 | 待确认区 | 黄色警告边框置顶，每行异常带"确认"和"忽略"按钮 |
| 分析看板 | 拓扑图 | SVG绘制，节点hover显示详情，点击线路跳转追溯，边宽映射容量 |
| 分析看板 | 线路列表 | 斑马纹表格，利用率条填充，超过90%整行标红 |
| 瓶颈追溯 | 求解过程 | 时间轴样式，每步显示增广路径和流量，当前瓶颈高亮 |
| 瓶颈追溯 | 约束分析 | 上游/下游节点卡片，箭头连线表示依赖关系 |
| 情景对比 | 方案卡片 | 3列并排布局，每列独立图表和关键指标 |
| 情景对比 | 容量滑块 | 左侧线路列表，右侧滑块调整，数值实时更新 |

### 4.3 响应式

- 桌面优先设计，最小支持1280px宽度
- 平板端：拓扑图与列表上下布局
- 移动端：仅保留统计卡和线路列表，隐藏复杂拓扑图
- 所有表格支持横向滚动

### 4.4 动画与交互

- 页面加载：统计数字从0滚动到实际值，错开0.2s延迟
- 拓扑图：节点hover时有脉冲效果，瓶颈边有呼吸动画
- 待确认区：异常项滑入显示，确认后向上收起淡出
- 容量调整：滑块拖动时拓扑图实时重绘，线条粗细平滑过渡
