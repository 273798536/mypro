## 1. 产品概述

数据中心冷通道时序回放系统，用于回放冷通道内传感器（温度、湿度等）的时序数据，支持筛选、异常标注、截图溯源和导出。目标是让方案经理不再靠人工兜底，让复核人接手即用。

- 解决问题：传感器数据回放时筛选条件丢失、导出与屏幕不一致、异常记录表述模糊、截图无法溯源、历史修改被覆盖
- 目标用户：数据中心运维人员、方案经理、评审复核人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 运维人员 | 分配账号 | 浏览回放、筛选、导出 |
| 方案经理 | 分配账号 | 浏览回放、筛选、导出、标注异常、放样例 |
| 复核人 | 分配账号 | 浏览回放、查看异常队列、重新导出、确认处理结果 |

### 2.2 功能模块

1. **时序回放主页**：时序图表、筛选条件面板、播放控制、截图入口、导出入口
2. **异常队列页**：异常列表、筛选口径溯源、处理状态标注、材料放置区
3. **导出面板**（浮层）：导出预览、筛选口径锁定、一键导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 时序回放主页 | 时序图表区 | 冷通道传感器时序折线图，支持时间轴拖拽回放、点位高亮 |
| 时序回放主页 | 筛选条件面板 | 时间范围、通道/机柜、传感器类型、异常类型筛选，筛选口径可视化 |
| 时序回放主页 | 播放控制栏 | 播放/暂停、速度调节、逐帧前进/后退 |
| 时序回放主页 | 截图操作栏 | 截取当前画面，自动绑定筛选条件和来源对象 |
| 时序回放主页 | 导出按钮 | 触发导出面板，导出内容与屏幕展示一致 |
| 时序回放主页 | 历史备注区 | 展示传感器记录的历史备注和旧截图，保留完整历史而非仅最终值 |
| 异常队列页 | 异常列表 | 按时间排序的异常记录，含筛选口径、处理状态、处理结果 |
| 异常队列页 | 处理结果标注 | 相邻点位合错等异常的处理结果明确标注为"异常-XXX"，不可写成"正常通过" |
| 异常队列页 | 截图溯源 | 从异常记录中的截图可跳转回对象来源和当前筛选状态 |
| 异常队列页 | 材料放置区 | 复核人放置补充材料的区域 |
| 导出面板 | 导出预览 | 预览导出内容，确认筛选口径一致 |
| 导出面板 | 筛选口径锁定 | 导出时自动附带筛选条件，确保"导出=屏幕所见" |

## 3. 核心流程

**主流程**：运维人员打开时序回放 → 设置筛选条件 → 回放传感器数据 → 发现异常可截图或标注 → 截图自动绑定筛选口径 → 导出时筛选条件随行 → 异常进入异常队列 → 方案经理/复核人在异常队列中查看、溯源、处理

**截图溯源流程**：在时序回放中截图 → 截图保存至异常队列 → 点击截图可跳转回对应传感器来源和当时筛选条件 → 重新进入回放视角

**导出流程**：点击导出 → 导出面板展示预览（含筛选口径） → 确认导出 → 导出文件与屏幕展示完全一致

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：深色工业风——深灰/近黑背景，青绿色 (#00E5A0) 作为主要强调色，警示用琥珀色 (#F59E0B)，异常用红色 (#EF4444)
- **按钮风格**：小圆角 (rounded-md)，扁平化，hover 时微亮
- **字体**：JetBrains Mono 用于数据展示，Source Han Sans / Noto Sans SC 用于界面文字
- **布局风格**：左侧筛选面板 + 右侧主内容区，顶部工具栏
- **图标风格**：Lucide 线性图标，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 时序回放主页 | 时序图表区 | 深色折线图，青绿色温度线，蓝色湿度线，hover 显示数值气泡 |
| 时序回放主页 | 筛选条件面板 | 左侧固定面板，下拉选择器+日期范围选择器，筛选口径标签 |
| 时序回放主页 | 播放控制栏 | 底部固定栏，播放/暂停按钮，速度滑块，逐帧按钮 |
| 时序回放主页 | 截图操作栏 | 工具栏截图图标，点击后弹出截图确认浮层 |
| 时序回放主页 | 历史备注区 | 右侧抽屉，时间线形式展示历史备注和旧截图 |
| 异常队列页 | 异常列表 | 表格形式，状态列用颜色标签（红/琥珀/绿），筛选口径列为可点击链接 |
| 异常队列页 | 截图溯源 | 截图缩略图，hover 显示来源信息，点击跳转 |
| 异常队列页 | 材料放置区 | 拖拽上传区域，文件列表 |
| 导出面板 | 导出预览 | 右侧浮层，展示筛选口径摘要+数据预览 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 筛选面板可折叠适配中等屏幕

### 4.4 简洁说明规则

系统说明文字控制在 3 句话以内，只讲清三件事：
1. **放样例**：在异常记录中放置截图和补充材料
2. **重跑**：从截图或异常记录跳转回时序回放，重新运行筛选
3. **查看异常队列**：在异常队列页查看所有待处理异常
