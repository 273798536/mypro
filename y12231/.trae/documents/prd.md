## 1. 产品概述

宠物医院会员预存管理工具，面向宠物医院财务人员，解决日常运营中会员预存金、套餐扣次、宠物档案与消费流水口径不一致的问题。核心价值：确保筛选条件变动时图表与明细同步、补录材料不覆盖已有判断、异常场景进入待确认清单而非混入正常明细、人工修改可追溯、补录影响可标记。

- 目标用户：宠物医院财务、店长、前台收银
- 核心痛点：换主人、套餐过期、重复扣次导致口径混乱；补录流水覆盖前置判断；异常悄无声息混入正常数据
- 市场价值：减少财务对账差错，降低因口径不一致导致的资金损失和客诉

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 财务主管 | 管理员分配 | 全部功能，含审批、导出、人工修改追溯 |
| 收银员 | 管理员分配 | 日常录入、查看明细、提交异常确认 |
| 店长 | 管理员分配 | 查看报表、审批异常、导出清单 |

### 2.2 功能模块

1. **会员预存总览页**：账户余额概览、套餐剩余次数图表、筛选条件联动、异常/待确认计数徽标
2. **会员账户与宠物档案页**：会员账户管理、宠物档案关联、换主人记录追踪、补录标记
3. **消费流水与扣次明细页**：消费流水录入、扣次状态追踪、补录影响标记、人工修改痕迹
4. **待确认与异常清单页**：换主人待确认、套餐过期预警、重复扣次标记、异常处理流程
5. **退款试算与导出页**：退款试算计算、人工修改影响展示、多格式导出

## 3. 核心流程

### 3.1 日常消费录入与扣次流程

收银员录入消费流水 → 系统匹配会员账户与宠物档案 → 检查套餐剩余次数 → 正常扣次记入明细 / 异常（重复扣次、套餐过期）进入异常清单 → 明细与图表同步更新

### 3.2 补录流水流程

收银员补录历史消费流水 → 系统标记为"补录" → 自动识别受影响的明细 → 受影响明细行标注补录来源和影响说明 → 不覆盖已有判断结果 → 异常条目仍留在异常清单

### 3.3 换主人流程

宠物所有权变更请求 → 系统生成待确认条目 → 关联原主人剩余套餐与余额 → 财务主管/店长审批 → 审批通过后更新档案，记录变更历史 → 相关明细标注换主人影响

### 3.4 退款试算流程

输入退款会员与宠物 → 系统读取消费记录 → 检测人工修改记录 → 展示修改对退款金额的影响 → 生成退款试算报告 → 导出

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色(#0F766E)搭配暖橙强调色(#EA580C)，传达专业财务工具感
- 辅助色：浅灰底(#F8FAFC)、白色卡片、红色异常标记(#DC2626)、黄色待确认标记(#D97706)
- 按钮风格：圆角8px，主按钮实色填充，次按钮描边，危险操作红色
- 字体：标题用 Noto Serif SC 衬线体体现专业感，正文用 Noto Sans SC 保证可读性
- 布局风格：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- 图标风格：Lucide 线性图标，统一 20px 大小
- 异常/待确认标记：使用徽标(Badge)和标签(Tag)组件

### 4.2 页面设计概览

### 4.3 响应式设计

- 桌面端优先（1440px+），侧边导航+宽内容区
- 平板端（768px-1440px），侧边导航折叠为图标模式
- 移动端（<768px），底部Tab导航，卡片单列堆叠

### 4.4 动效设计

- 页面切换：淡入淡出 200ms
- 筛选条件变更：图表数据过渡动画 300ms
- 异常/待确认条目出现：从右侧滑入 250ms
- 卡片hover：轻微上浮 + 阴影加深
- 表格行hover：浅色背景高亮
