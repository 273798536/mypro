# 地下水监测井剖面讲解

面向现场调度与复核老师的剖面复核工具。让点位坐标有空间感，异常材料自动标记，筛选/备注/CSV 联动不丢失。

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5174

> 如无全局 Node/npm，可将任意 Node 加入 PATH 后执行。本项目使用 ESM + Vite + React + TypeScript + Tailwind。

## 三步操作

### 1. 放样例
点击顶栏「放样例」→ 载入 15 个内置点位，剖面图立即呈现。

### 2. 重跑
需要从头复核时，点「重跑」清空筛选和选中，材料原样重新加载。

### 3. 查看 CSV 明细
右侧面板切换到「CSV 明细」→ 异常行高亮 → 点「导出当前」下载带标记列的 CSV。

## 🔴 坏材料来了先看这里

| 标记 | 含义 | 怎么查 |
|------|------|--------|
| 📜 旧版坐标 | 点位使用了过期的 v1 坐标 | 详情面板可见新旧坐标偏差值 |
| 📝 后补备注 | 数据是后来补上的，非同期采集 | 备注面板以橙色标签区分 |
| 🗣 口头备注 | 来自现场口头反馈，无书面记录 | 备注面板以玫红色标签区分 |
| ⚠ 相邻合错 | 两个编号相邻的点位坐标几乎重合 | 剖面图用红色虚线圈出，注意成对出现 |

**排查顺序建议**：左侧筛选面板 → 勾选异常类型 → 剖面图定位 → 点进详情核对坐标偏差 → 看备注追溯来源 → 导出 CSV 留档。
