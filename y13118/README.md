# 组合计数图表解释

## 1. 启动

一条命令跑完完整样例：

```bash
python3 run_combo.py --clean
```

输出内容：
- 题目清单加载（含脏数据提示）
- 权重和出现次数设置（含变更历史）
- 组合计数计算
- 图表显示与口径一致性校验
- 外推越界错误提示（含卡壳点）
- CSV明细导出

退出提示会明确说明外推越界卡在哪。

## 2. 重跑

对上次结果复算一遍，验证图表和明细口径一致：

```bash
python3 run_combo.py --rerun
```

重跑会使用上次运行的题目清单、权重和原始数据，重新计算并生成新的运行ID，确保两次结果一致。

## 3. 查看CSV明细

运行后CSV文件输出到 `output/` 目录：

```
output/
├── combo_details_YYYYMMDD_HHMMSS.csv   # 组合明细
├── combo_summary_YYYYMMDD_HHMMSS.csv   # 运行汇总
└── weight_changes_YYYYMMDD_HHMMSS.csv  # 权重变更记录
```

明细CSV字段说明：

| 列名 | 说明 |
|------|------|
| 组合ID | 组合唯一标识 |
| 包含题目 | 组合内的题目ID列表 |
| 题目数量 | 组合大小 |
| 组合权重 | 权重合计 |
| 出现次数 | 组合出现次数 |
| 状态(页面显示) | 页面展示用：正常 / 异常-外推越界 |
| 状态(内部编码) | 系统编码：normal / error |

**状态一致性保证**："状态(页面显示)" 与 "状态(内部编码)" 严格一一对应，页面上看到的状态和文件里的说法完全一致。
