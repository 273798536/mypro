# 音乐课程续费预警系统 - 启动指南

## 怎么启动

### 1. 安装依赖

```bash
npm install
```

需要 Python 3.10+，scikit-learn 和 pandas：

```bash
pip3 install scikit-learn pandas numpy
```

### 2. 初始化数据库 + 生成样例数据

```bash
npm run seed
```

数据库文件在 `data/warning_system.db`，样例数据包含：
- 3 个测试账号
- 24 名学员（覆盖 7 种课程类型）
- 上课记录、练习打卡、家长反馈、跟进记录

### 3. 启动后端

```bash
# 后端 API（端口 3001）
npx tsx api/server.ts
```

### 4. 启动前端

```bash
# 前端开发服务器
npm run client:dev
```

浏览器打开终端输出的地址（通常是 http://localhost:5173）。

## 样例放哪

样例数据由 `api/scripts/generate-sample-data.ts` 生成，包含：

| 数据类型 | 表名 | 条数 |
|----------|------|------|
| 学员档案 | students | 24 |
| 上课记录 | attendance_records | ~200 |
| 练习打卡 | practice_records | ~160 |
| 家长反馈 | feedback_records | ~70 |
| 跟进记录 | follow_up_records | ~40 |

其中故意包含了：
- **缺字段的缺课记录**（`has_missing_fields = 1`）——模拟系统导入时字段不全
- **迟到的练习打卡**（`is_late = 1`）——模拟打卡延迟
- **学员备注**——模拟家长备注混入档案
- **无原因的缺课**（`absent_reason IS NULL`）——触发补录流程

如需重新生成，删除 `data/warning_system.db` 后重新 `npm run seed`。

## 怎样触发缺课补录

### 触发条件

上课记录中 `status = 'absent'` 且 `absent_reason IS NULL` 的记录会被标记为"待补录"。

### 操作步骤

1. 登录后点击左侧「缺课补录」
2. 系统列出所有待补录的缺课记录
3. 点击某条记录的「处理补录」按钮
4. 选择处理方式：
   - **已补课**：学生已补上缺的课
   - **请假**：家长已确认请假
   - **不计入**：系统导入错误，不应算缺课
5. 填写家长沟通情况和备注
6. 提交后系统会：
   - 更新缺课原因
   - 自动重新计算该学员的预警评分
   - 生成新版本
   - 给出**明确结论和行动建议**（不是模糊判断）

### 补录后结论示例

| 场景 | 结论 | 行动建议 |
|------|------|----------|
| 因病缺课 + 风险降低 | 因病缺课，已补课，风险降低 | 继续观察上课状态；提醒注意身体；提前30天沟通续费 |
| 厌学缺课 + 黄色预警 | 存在厌学情绪，需持续关注 | 1周内电话沟通；了解兴趣变化；考虑调整难度 |
| 原因不明 + 红色预警 | 缺课原因不明，存在高退费风险 | 立即联系家长；教学主管介入；准备替代方案 |

## 预警评分说明

### 评分维度（加权）

| 维度 | 权重 | 数据来源 |
|------|------|----------|
| 缺课 | 30% | 近30天上课记录 |
| 练习 | 30% | 近21天练习打卡 |
| 反馈 | 25% | 近30天家长反馈 |
| 课程进度 | 15% | 剩余课时 + 续费日期 |

### 预警级别

| 级别 | 评分 | 含义 |
|------|------|------|
| 🔴 红色 | ≥60 | 高风险，需立即介入 |
| 🟡 黄色 | 35-59 | 需关注，建议主动跟进 |
| 🟢 绿色 | <35 | 状态正常 |

### 评分不是一次性判断

- 每次重新计算都会生成新版本，保留历史
- 缺课归因变化后，老师跟进建议和历史对比会跟着变
- 在「版本追踪」页可以对比任意两个版本的变化差异
- 人工修正会记录修正原因和效果，可追溯

## 四维度联动

顶部标签栏有四个维度，可互相跳转：

| 维度 | 路径 | 含义 |
|------|------|------|
| 样本 | /students | 学员个体视角 |
| 版本 | /versions | 计算版本对比 |
| 修正 | /corrections | 人工修正记录 |
| 分组 | /groups | 按教师/课程/年龄/续费周期分组 |

点击任一维度的标签，会带上当前上下文参数跳转到对应页面。

## 常见问题

**Q: 端口 3001 被占用**

```bash
kill -9 $(lsof -ti:3001)
```

**Q: 前端页面空白**

确认后端已启动且 http://localhost:3001/api/health 返回正常。

**Q: 预警计算失败**

确认 Python 3 已安装且 scikit-learn/pandas 可用：
```bash
python3 -c "import sklearn, pandas; print('OK')"
```

**Q: 数据导入**

在「数据导入」页上传 Excel/CSV 文件，支持学员档案、上课记录、练习打卡、家长反馈四种类型。系统会自动预览脏数据问题（缺字段、格式不一致），确认后导入。
