# 学校接送方案比选

面向社区运营人员的方案筛选、统计与报告生成工具。

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 类型检查
npm run check

# 构建生产版本
npm run build
```

## 功能页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 方案比选 | `/` | 筛选条件面板 + 方案对比表格 + 统计摘要 + Markdown报告生成 |
| 审批台账 | `/ledger` | 审批记录列表 + 边界样本展示 + 后补说明 |
| 现场补录 | `/field` | 照片上传 + 地图点位标注 + 坐标偏移模拟 |
| 历史复盘 | `/history` | 人工确认前后变更对比 + 时间线 + 复盘报告导出 |

## 核心流程

1. 在**方案比选页**设置筛选条件，实时查看统计数字和明细
2. 点击右下角按钮生成 Markdown 报告（筛选条件、统计、明细同源）
3. 坐标偏移超过阈值时自动触发边界检查，进入**审批台账**待人工确认
4. 在**现场补录页**上传照片、应用坐标偏移，地图和报告自动同步
5. 所有变更记录进入**历史复盘**，支持前后对比和复盘报告导出
