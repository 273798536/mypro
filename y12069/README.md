# 粒子碰撞采矿场 · Particle Collision Mining Facility

一款面向物理科普教育的浏览器游戏，通过真实的物理碰撞模拟让玩家理解动量守恒和能量守恒定律。

## 🎮 游戏玩法

1. **选择粒子类型**：电子、质子、α粒子、中子，各有不同的质量和特性
2. **调整参数**：设置发射角度（-45° ~ +45°）和发射功率（10% ~ 100%）
3. **发射粒子**：点击发射按钮或按空格键发射粒子
4. **观察碰撞**：粒子与矿石碰撞，遵守动量守恒和能量守恒定律
5. **获得高分**：物理定律遵守得越好，得分越高。动量方向错误或能量超限会扣分！

## ⚛️ 核心物理概念

### 动量守恒定律
```
Σ p_before = Σ p_after
m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'
```
碰撞前后总动量保持不变，方向也应保持一致。

### 能量守恒定律
```
E_before ≥ E_after × (1 + 5%)
½m₁v₁² + ½m₂v₂² ≥ ½m₁v₁'² + ½m₂v₂'²
```
碰撞后能量不应超过碰撞前（允许5%的数值误差）。

### 弹性碰撞公式
```
v₁' = ((m₁-m₂)v₁ + 2m₂v₂) / (m₁+m₂)
v₂' = ((m₂-m₁)v₂ + 2m₁v₁) / (m₁+m₂)
```

## 🎯 游戏特性

- ✅ **真实物理引擎**：完整的2D弹性碰撞模拟
- ✅ **4种粒子类型**：电子、质子、α粒子、中子
- ✅ **5种矿石**：铁矿、铜矿、金矿、能量水晶、铀矿
- ✅ **能量系统**：总能量预算500J，每次发射消耗能量
- ✅ **错误提示**：动量方向错误、能量超限醒目提示，并标注问题材料
- ✅ **游戏控制**：暂停、继续、重新开始
- ✅ **复盘功能**：逐帧回放碰撞过程，支持变速播放
- ✅ **结算页面**：详细的能量结算、扣分原因、物理公式对照
- ✅ **键盘快捷键**：空格键发射/暂停，ESC暂停

## 🔍 常见问题

**Q: 为什么发射后提示动量方向错误？**
A: 碰撞后粒子或矿石的运动方向与入射方向偏差过大。尝试调整发射角度或选择不同质量的粒子。

**Q: 能量超限是什么意思？**
A: 碰撞后系统总能量不应超过碰撞前（考虑5%的数值误差）。降低发射功率或选择更重的粒子可以避免。

**Q: 为什么能量足够但矿石没有被采集？**
A: 矿石有能量阈值，碰撞能量必须达到阈值才能采集。检查矿石下方的阈值显示。
