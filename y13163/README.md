# 海浪浮标误差归因系统

海洋监测数据质量分析平台，用于海浪浮标数据的误差归因分析。

---

## 环境要求

- **Node.js**: >= 18.0.0
- **包管理器**: npm

---

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

启动后访问：**http://localhost:5173/**

### 3. 生产构建（可选）

```bash
npm run build
```

构建产物输出到 `dist/` 目录。

---

## 核心操作（三件事）

### 一、启动分析

点击页面顶部右上角的 **「启动分析」** 按钮：
- 按钮进入 disabled 状态，显示进度动画
- 系统将使用当前参数版本重新计算全部数据的误差值
- 运行完成后按钮恢复可用，数据自动更新

> 「启动分析」适用于首次加载或切换参数版本后，需要全量重新计算的场景。

### 二、重跑

点击页面顶部右上角的 **「重跑」** 按钮：
- 功能与「启动分析」一致，同样会触发全量数据重新计算
- 与「启动分析」的区别是语义上的：「重跑」用于对已有结果不满意，需要重新计算的场景
- 重跑过程中按钮同样进入 disabled 状态，完成后自动恢复

### 三、查看 Markdown 报告

点击页面顶部右上角的 **「查看 Markdown 报告」** 按钮：
- 弹出双栏预览窗口，左侧为 Markdown 源码，右侧为渲染预览
- 报告内容与页面当前状态**完全一致**，包括：
  - 当前使用的参数版本（公式、变量、边界值）
  - 当前筛选条件（异常类型、数据状态、处理状态、疑似噪声等）
  - 筛选后的异常点清单（与页面列表显示条数一致）
  - 当前选中异常点的完整详情（含相关维修备注及原始字段映射）
- 点击 **「复制到剪贴板」** 可复制源码
- 点击 **「下载 .md 文件」** 可导出为本地 Markdown 文件

---

## 关键特性说明

### 筛选与报告一致性

页面上应用的所有筛选条件（异常类型、数据状态、处理状态、仅显示疑似噪声、搜索关键词）都会同步反映到导出的 Markdown 报告中，确保"页面上看到的状态和文件里的说法一致"。

例如：页面开启「仅显示疑似噪声」后列表显示 4/14，导出的 Markdown 报告同样只包含这 4 条异常点。

### 维修备注字段映射

现场老师提交的维修备注可能字段名前后不一（如"提交人"与"报修人"、"提交时间"与"记录时间"），系统会：
1. 将不同字段名归一化为统一的内部字段
2. 在详情面板和 Markdown 报告中同时保留**原始字段映射**供溯源

### 参数版本管理

系统内置 3 个历史参数版本，点击顶部 **「参数版本 v2.1.0」** 下拉可切换：
- **v1.0.0**: 基础版本，简单线性加权
- **v2.0.0**: 引入误差阈值校正
- **v2.1.0**: 优化大浪区间拟合，新增标准差校正项（当前默认）

切换版本后数据会自动重新计算。

## 项目结构

```
src/
├── components/     # UI 组件
├── store/          # Zustand 状态管理
├── utils/          # 工具函数（归因计算、异常检测、Markdown 生成等）
├── data/           # 模拟数据
├── types/          # TypeScript 类型定义
└── pages/          # 页面组件
```
