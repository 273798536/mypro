## 1. 产品概述

振动台地震波回放系统——面向结构实验员的三源数据时序对齐与损伤关联分析工具。解决加速度序列、位移记录与损伤照片三者到达时间不一致、时序对齐反复解释的痛点，让实验员能导入样例、看图、点明细、带走结果，全程可溯源。

- 目标用户：结构实验室振动台操作人员、地震工程研究员
- 核心价值：一次对齐、三方留痕、结论可追溯，避免每次回放都重新解释时序

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 结构实验员 | 直接使用 | 导入数据、时序对齐、峰值提取、损伤关联、导出结果 |
| 复核人员 | 直接使用 | 查看对齐结果、冲突标注、溯源追踪 |

### 2.2 功能模块

1. **回放工作台**：数据导入、三源时序对齐可视化、波形回放控制
2. **明细溯源页**：单条结果逐级追溯至时序对齐→峰值提取→损伤关联，含冲突留痕

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 回放工作台 | 数据导入区 | 拖拽/选择导入加速度CSV、位移CSV、损伤照片ZIP/文件夹；自动解析时间戳列 |
| 回放工作台 | 时序对齐面板 | 三轨道时间轴（加速度/位移/照片），显示漂移标记与手动微调滑块 |
| 回放工作台 | 波形可视化区 | 加速度与位移波形叠加图，峰值自动提取与标注，传感器饱和区域高亮 |
| 回放工作台 | 损伤照片条 | 按时间戳排列的损伤照片缩略图条，缺失阶段标红，点击放大与阶段标注 |
| 回放工作台 | 冲突留痕区 | 三源冲突事件列表（时间戳漂移+照片缺失+饱和晚到），可标注优先级与判断理由 |
| 回放工作台 | 回放控制栏 | 播放/暂停/步进/速度调节，当前时间指针联动三轨道 |
| 明细溯源页 | 溯源链路图 | 从结果→峰值提取→时序对齐→原始数据的完整链路可视化 |
| 明细溯源页 | 冲突详情卡 | 单条冲突的展开卡片：冲突类型、涉及数据源、用户判断、留痕时间 |
| 明细溯源页 | 导出面板 | 导出JSON/CSV报告，位移结论与页面摘要一致性校验提示 |

## 3. 核心流程

用户导入加速度序列、位移记录和损伤照片三源数据，系统自动检测时间戳并尝试时序对齐。若存在漂移或缺失，标记冲突并提示实验员判断。实验员在波形可视化中确认峰值提取结果，关联损伤照片与关键阶段，冲突处留痕标注优先级和判断理由。最终导出报告，其中位移记录结论与页面摘要一致，且任何结果均可追溯到原始对齐和提取步骤。

```mermaid

    "A:导入三源数据" --> "B:自动解析时间戳"
    "B" --> "C:时序对齐检测"
    "C" --> "D{存在冲突?}"
    "D" -->|"是"| "E:标记冲突并留痕"
    "E" --> "F:实验员判断与标注"
    "D" -->|"否"| "G:波形回放与峰值提取"
    "F" --> "G"
    "G" --> "H:损伤照片关联"
    "H" --> "I:结果溯源链路生成"
    "I" --> "J:导出报告（一致性校验）"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深钢蓝 `#1B2838`，辅色：警告橙 `#E8722A`，强调色：信号绿 `#3DDC84`
- 按钮风格：工业风微圆角（4px），扁平化配深色底，活跃态带发光边框
- 字体：数字/数据使用 JetBrains Mono，UI文案使用 Noto Sans SC
- 布局风格：深色工业风仪表盘，顶部工具栏+左侧轨道面板+右侧详情面板
- 图标风格：线性描边图标，统一2px线宽

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 回放工作台 | 数据导入区 | 拖拽虚线框，图标+提示文字，深色半透明背景 |
| 回放工作台 | 时序对齐面板 | 三条水平轨道，时间轴刻度，漂移标记（橙色竖线），微调滑块 |
| 回放工作台 | 波形可视化区 | 深色画布，绿色加速度曲线，蓝色位移曲线，峰值三角标注，饱和区域红色半透明遮罩 |
| 回放工作台 | 损伤照片条 | 水平滚动缩略图条，缺失阶段红色虚线占位，当前播放位置黄色竖线指示 |
| 回放工作台 | 冲突留痕区 | 底部折叠面板，冲突条目卡片列表，优先级色标（红/橙/黄），判断理由文本框 |
| 回放工作台 | 回放控制栏 | 播放/暂停/步进按钮组，速度选择下拉，当前时间数字显示（JetBrains Mono） |
| 明细溯源页 | 溯源链路图 | 从左到右的流程节点图，节点间连线，高亮当前溯源路径 |
| 明细溯源页 | 冲突详情卡 | 展开式卡片，标签页切换冲突类型，留痕时间线 |
| 明细溯源页 | 导出面板 | 格式选择按钮组，一致性校验结果指示灯（绿/红），下载按钮 |

### 4.3 响应式策略

- 桌面优先设计，适配1920×1080及以上分辨率
- 波形区域支持窗口缩放自适应
- 照片条在窄屏下切换为垂直滚动
