## 1. 产品概述

海浪浮标参数回放系统——替代维修备注手工核对，让每条人工改判与最终结论之间的因果链清晰可追溯，极端值疑似噪声时给出可操作的下一步指引。

- 目标用户：维修师傅（如阿岑）、值班工程师
- 核心价值：月底不再被"报警与人工备注对不上"拖住，一条改判为什么影响结论一目了然

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 维修师傅 | 直接访问 | 查看回放、录入改判、执行复算 |
| 值班工程师 | 直接访问 | 以上 + 确认/驳回改判、导出报告 |

### 2.2 功能模块

1. **参数回放页**：时序图表 + 参数明细表 + 人工改判标注 + 极端值噪声标记
2. **改判因果链页**：从单条改判到最终结论的完整影响路径
3. **复算验证页**：加入改判后重算，图表与明细同口径对比

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 参数回放页 | 时序图表 | 按时间轴展示浮标参数曲线，标注报警点和改判点 |
| 参数回放页 | 参数明细表 | 逐行展示原始值、改判值、是否被标记为噪声 |
| 参数回放页 | 坏数据溯源卡片 | 指出坏数据对应的维修备注原始行号和具体对象 |
| 参数回放页 | 极端值噪声提示 | 检测疑似噪声，给出可照做的人话指引（非技术术语） |
| 改判因果链页 | 改判列表 | 左侧列出所有人工改判，点击展开影响链 |
| 改判因果链页 | 影响路径图 | 右侧展示：改判 → 受影响的参数/报警 → 最终结论变化 |
| 改判因果链页 | 结论对比 | 改判前结论 vs 改判后结论，差异高亮 |
| 复算验证页 | 复算触发 | 一键"把改判放进回放重跑"，自动复算 |
| 复算验证页 | 口径一致性校验 | 图表数值与明细表数值必须完全一致，不一致标红提示 |
| 复算验证页 | 改判前后对比图 | 同一坐标系叠放改判前/后曲线，差异区域阴影标注 |

## 3. 核心流程

用户进入参数回放页 → 查看时序图表发现异常 → 查看极端值噪声提示 → 了解是否需要处理 → 录入人工改判 → 系统自动展示改判因果链（改判影响了哪些报警和结论）→ 确认后点击复算 → 图表与明细同时更新 → 核验口径一致性 → 结束

## 4. 用户界面设计

### 4.1 设计风格

- 整体风格：工业实用主义（Industrial Utilitarian）——朴素、信息密度高、零装饰
- 主色：深蓝灰 (#1e293b) 背景 + 青蓝 (#0ea5e9) 强调色 + 琥珀 (#f59e0b) 用于报警/改判标注
- 次色：灰白 (#f8fafc) 用于卡片背景，红色 (#ef4444) 用于异常/坏数据标记
- 按钮风格：小型、方正、微圆角 (rounded-sm)，无3D效果
- 字体：系统等宽字体用于数据表格，Source Sans 3 用于界面文字
- 布局：顶部窄导航条 + 左侧边栏（改判列表）+ 右主内容区

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 参数回放页 | 时序图表 | 深色背景折线图，报警点用琥珀色圆点，改判点用绿色三角，可疑噪声用虚线框 |
| 参数回放页 | 参数明细表 | 紧凑型表格，改判行浅绿底，噪声行浅黄底，坏数据行浅红底并附行号链接 |
| 参数回放页 | 坏数据溯源卡片 | 卡片式，显示"来源：维修备注第X行，对象：XX传感器"，可点击跳转 |
| 参数回放页 | 极端值噪声提示 | 黄色横幅，文字如"第12分钟波高值 15.2m 疑似噪声，建议：检查该时段传感器供电电压，若<10V则标记噪声" |
| 改判因果链页 | 改判列表 | 左侧垂直列表，每条显示：时间+参数+改前→改后，点击展开 |
| 改判因果链页 | 影响路径图 | 箭头流程图：改判节点 → 影响节点 → 结论节点，绿色=改判，琥珀=影响，蓝=结论 |
| 复算验证页 | 口径一致性校验 | 绿色勾号"一致" 或 红色叉号"不一致"加具体差异行 |
| 复算验证页 | 改判前后对比图 | 双折线叠加图，差异区域用半透明阴影填充 |

### 4.3 响应式设计

- 桌面端优先（维修室大屏为主场景）
- 表格在窄屏下可横向滚动
- 图表自适应宽度

## 5. 文档要求

启动、重跑、查看截图说明三件事讲清即可，不写虚的：

1. **启动**：`pnpm install && pnpm dev`，浏览器打开提示的地址
2. **重跑**：在复算验证页点击"复算"按钮，系统自动重算并更新图表和明细
3. **查看截图说明**：每个关键操作步骤附截图标注，截图命名如 `step-1-startup.png`
