# 海浪浮标参数回放 - 使用说明

只讲三件事：**启动**、**重跑**、**查看截图说明**。

---

## 1. 启动

```bash
pnpm install
pnpm dev
```

- 安装完成后，终端会输出本地访问地址（通常是 `http://localhost:5173`）
- 在浏览器打开该地址即可使用

> 注：如果没有 pnpm，用 `npm install && npm run dev` 也可以。

---

## 2. 重跑（复算）

打开系统后，按以下步骤操作：

### 步骤 1：查看参数回放（首页）

- 打开后默认在 **参数回放** 页
- 顶部显示时序图，下半部分是参数明细表
- 黄色横幅提示疑似噪声数据，可点击"标记为噪声"或"确认为有效"

### 步骤 2：录入人工改判

- 点击右上角 **"录入改判"** 按钮
- 填写表单：选择参数、时间点、原值→改判值、原因、操作员、来源备注行、来源对象
- 点击 **"确认添加"**

### 步骤 3：复算

- 点击右上角 **"复算"** 按钮
- 系统自动将人工改判加入回放重新计算
- 图表与明细表同步更新，顶部显示"已复算完成"

### 步骤 4：查看改判因果链

- 点击顶部导航 **"改判因果链"**
- 左侧选择一条改判
- 右侧显示完整影响路径：改判 → 影响的参数/报警 → 结论变化

### 步骤 5：验证口径一致性

- 点击顶部导航 **"复算验证"**
- 点击 **"复算"** 按钮
- 查看"口径一致性校验"结果（绿√表示图表与明细完全一致）
- 查看改判前后对比图，差值区域用橙色阴影标注
- 底部明细表逐行核对图表与表中的数值

## 3. 查看截图说明

系统内关键操作均有可视化标注，截图可保存以下关键页面：

| 截图位置 | 文件名 | 说明 |
|---------|--------|------|
| 参数回放页 | `step-1-replay-overview.png` | 整体界面：顶部时序图、底部明细表、噪声横幅 |
| 录入改判弹窗 | `step-2-add-override.png` | 录入改判表单，显示各字段填写位置 |
| 噪声提示横幅 | `step-3-noise-banner.png` | 疑似噪声提示，含"建议操作"人话指引 |
| 改判因果链页 | `step-4-causal-chain.png` | 改判→影响→结论的完整因果链路 |
| 复算验证页 | `step-5-recalc-check.png` | 口径一致性校验结果 + 改判前后对比图 |
| 坏数据溯源卡片 | `step-6-bad-data-trace.png` | 显示"来源：维修备注第X行，对象：XX传感器" |

### 截图操作指引：

1. **参数回放页概览**：打开首页 → 截取整个页面 → 标注：① 时序图 ② 改判点绿三角 ③ 噪声点黄点 ④ 噪声横幅 ⑤ 明细表 ⑥ 坏数据溯源卡片
2. **录入改判**：点击"录入改判" → 截图弹窗 → 标注：① 参数选择 ② 时间点 ③ 原值 ④ 改判值 ⑤ 来源备注行 ⑥ 来源对象
3. **噪声提示**：展开噪声横幅 → 截图 → 标注：① 判定依据 ② 建议操作（人话指引）③ 两个操作按钮
4. **因果链**：进入"改判因果链"页 → 截图 → 标注：① 改判列表 ② 改判节点 ③ 影响节点 ④ 结论节点 ⑤ 改判前后结论对比
5. **复算验证**：进入"复算验证"页 → 点击复算 → 截图 → 标注：① 口径一致性校验结果 ② 改判前后对比图 ③ 差值区域 ④ 逐行核对表
6. **坏数据溯源**：在参数回放页右侧 → 截图卡片 → 标注：① 来源行号 ② 来源对象 ③ 备注内容 ④ 是否已改判/标记噪声

## 附：人话操作指引（维修师傅阿岑版）

> 遇到疑似噪声怎么办？
>
> 1. 看黄色横幅里的"建议操作"，比如写着"检查供电电压，若<10V则标记噪声"
> 2. 去现场查传感器电压
> 3. 低于10V → 点"标记为噪声"按钮
> 4. 正常 → 点"确认为有效"按钮
> 5. 再点"复算"，自动重跑
>
> 改判完想知道为什么报警消了？
>
> → 去"改判因果链"页，三步连起来看：改了啥 → 影响了哪个报警 → 结论从啥变成了啥
