## 1. 产品概述

"配电抢修回合战"是一款面向电力公司抢修班组的培训小游戏，模拟风暴后电力抢修的回合制决策过程。玩家需要在有限资源下合理调度抢修队伍，在医院（最高优先级）与居民区（大量用户）之间做出权衡，体验真实调度中的优先级冲突、资源约束与时间压力。

- 核心目的：让抢修班组通过游戏理解调度优先级、资源管理、冷却时间等抢修规则
- 目标用户：电力公司抢修班组培训人员
- 价值：将反复出错的调度流程（重复派遣、超时、备件不足）可视化、游戏化

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学员 | 本地直接开始 | 进入游戏、操作调度、查看结果、导出报告 |

### 2.2 功能模块
1. **主界面**：游戏标题、开始关卡、关卡选择、操作说明
2. **游戏主界面**：回合信息面板、抢修队列表、配电线路/用户区列表、操作区、事件日志
3. **关卡结果页**：得分统计、失败原因明细、回放记录、导出报告
4. **回放页**：逐回合操作回放、错误标注、评分详情

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主界面 | 关卡选择 | 显示3个预设关卡（基础、进阶、挑战），点击进入 |
| 主界面 | 操作说明 | 弹出说明面板，展示游戏规则和优先级表 |
| 游戏主界面 | 回合信息面板 | 显示当前回合数、剩余时间、天气事件、备件数量 |
| 游戏主界面 | 抢修队列表 | 显示所有队伍状态（待命/执行中/冷却）、所属技能、冷却回合数 |
| 游戏主界面 | 用户区列表 | 显示医院、居民区、商业区的供电状态、超时倒计时、优先级 |
| 游戏主界面 | 操作区 | 点击队伍→点击目标区域完成派遣，支持撤回（冷却内不可撤） |
| 游戏主界面 | 事件日志 | 实时显示派遣结果、错误提示（含行号/来源）、天气事件通知 |
| 游戏主界面 | 结束回合按钮 | 结束当前回合，推进时间，执行冷却，触发事件 |
| 关卡结果页 | 得分统计 | 显示总得分、分项得分、扣分明细 |
| 关卡结果页 | 失败原因 | 列出所有失败事件（超时、重复派遣、备件不足），附回合号和详情 |
| 关卡结果页 | 回放记录 | 列出每回合操作历史，可点击查看详情 |
| 关卡结果页 | 导出报告 | 导出JSON格式的操作记录和评分报告 |
| 回放页 | 逐回合回放 | 自动或手动逐回合展示操作，错误处高亮标注 |

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝 (#1a2744) 作为底色，代表电力行业稳重感
- 辅助色：橙色 (#ff8c42) 作为强调色，警示/高亮；绿色 (#4caf50) 表示正常/成功；红色 (#f44336) 表示错误/超时
- 按钮风格：圆角方形，带阴影，悬浮时高亮
- 字体：标题使用 Noto Sans SC，数字/数据使用等宽字体 JetBrains Mono
- 布局：卡片式布局，左侧队伍面板，右侧区域面板，底部操作/日志区
- 图标风格：使用简洁的线条图标（电力杆、扳手、医院、房屋、工厂）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主界面 | 关卡卡片 | 深色卡片、标题+描述+难度标签、悬浮放大效果 |
| 游戏主界面 | 队伍卡片 | 状态色边框（绿=待命/橙=执行中/灰=冷却）、技能标签、冷却进度条 |
| 游戏主界面 | 区域卡片 | 优先级图标（医院🏥/居民区🏠/商业区🏢）、供电状态指示灯、超时倒计时条 |
| 游戏主界面 | 操作日志 | 时间戳、事件类型标签、错误信息高亮、来源位置引用 |
| 游戏主界面 | 顶部状态栏 | 回合进度条、天气图标、备件数量徽章 |
| 关卡结果页 | 得分面板 | 大号分数、分项得分进度条、扣分明细列表 |
| 关卡结果页 | 回放列表 | 回合操作卡片、错误处红色边框标注 |

### 4.3 响应式设计
- 桌面优先设计，最小支持宽度 1200px
- 游戏主界面采用三栏布局：左（队伍）、中（区域）、右（日志+操作）
- 移动端自适应为垂直堆叠布局
