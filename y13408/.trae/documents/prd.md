## 1. 产品概述

概率抽样边界复核看板——面向建模社成员的抽样结果边界审查工具，核心解决空集合、零值等边界情况被当作普通输入忽略的问题，确保复核过程中参数变化可追溯、异常可定位、报告可闭环。

- 目标用户：建模社成员（如阿乔），需在评审会前完成抽样边界复核并导出报告
- 核心价值：将"边界异常"从笼统的"异常"标签升级为可追溯到原始材料、可关联到结论影响的精确记录，避免状态流转沦为摆设

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 复核员 | 直接访问 | 录入样本、筛选复核、人工改判、导出报告 |
| 查阅者 | 直接访问 | 查看统计卡片、浏览明细、导出文件 |

### 2.2 功能模块

1. **复核看板页**：筛选条件区、统计卡片、明细表、操作栏——全部基于同一批计算结果
2. **人工改判页**：逐条改判记录，附带改判原因，历史不被覆盖
3. **异常溯源页**：外推越界等异常的原始材料触发点与结论影响说明
4. **导出与报告页**：一键导出复核报告，报告包含异常溯源链路

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 复核看板页 | 筛选条件区 | 按批次、参数类型、边界类型（空集合/零值/外推越界/正常）、复核状态筛选，参数变化可追溯到样本 |
| 复核看板页 | 统计卡片 | 总样本数、边界异常数、待复核数、已改判数——均来自同一计算批次 |
| 复核看板页 | 明细表 | 逐条样本记录，含原始值、换算后值（单位可见）、复核状态、改判历史入口 |
| 复核看板页 | 操作栏 | 批量复核确认、导出按钮、异常快速跳转 |
| 人工改判页 | 改判表单 | 选择目标记录、填写改判值、填写改判原因、提交后生成历史快照（不覆盖原记录） |
| 人工改判页 | 改判历史 | 某条样本的完整改判时间线，每条保留原始值与改判后值 |
| 异常溯源页 | 异常列表 | 按严重度排列的异常条目，含触发原始材料ID、影响结论编号 |
| 异常溯源页 | 溯源详情 | 点击某条异常展开：哪条原始材料触发→影响了哪个结论→建议处理方式 |
| 导出与报告页 | 报告预览 | 生成包含统计概要、异常溯源链、改判记录的完整报告 |
| 导出与报告页 | 文件导出 | 导出CSV明细表、PDF复核报告 |

## 3. 核心流程

复核员打开看板→通过筛选条件定位边界异常→点击异常条目查看原始材料触发点与结论影响→如需改判进入人工改判页提交改判→改判历史保留不覆盖→确认后导出报告，报告中异常条目附带溯源说明。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1a1f36) + 琥珀警告色(#f59e0b) + 翠绿正常态(#10b981)
- 辅助色：冷灰背景(#0f1219)、白色文字、红色错误态(#ef4444)
- 按钮风格：圆角矩形，主操作实心填充，次操作描边
- 字体：标题用 Source Serif 4（学术严谨感），正文用 DM Sans（清晰可读）
- 布局：左侧固定导航 + 右侧内容区，卡片式统计区 + 表格式明细区
- 图标风格：线性图标，2px 描边，与数据面板风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 复核看板页 | 筛选条件区 | 顶部横排下拉选择器，参数变化标签高亮，重置按钮 |
| 复核看板页 | 统计卡片 | 4列卡片网格，每张含大数字+趋势箭头+颜色指示 |
| 复核看板页 | 明细表 | 条纹表格，行悬停高亮，状态标签彩色胶囊，单位列显式展示 |
| 复核看板页 | 操作栏 | 表格上方工具条，批量操作按钮组+导出下拉菜单 |
| 人工改判页 | 改判表单 | 右侧抽屉式面板，字段分组，必填项标记，提交前确认弹窗 |
| 人工改判页 | 改判历史 | 时间线组件，竖向排列，每条含时间戳、操作人、改判前后对比 |
| 异常溯源页 | 异常列表 | 卡片列表，严重度左侧色条，展开/折叠交互 |
| 异常溯源页 | 溯源详情 | 展开区域：触发材料→影响结论→建议处理的步骤条 |
| 导出与报告页 | 报告预览 | A4纸样式预览区，分章节，异常条目可点击跳转 |
| 导出与报告页 | 文件导出 | 格式选择按钮组，导出进度条 |

### 4.3 响应式策略

桌面优先设计，最小支持1280px宽度。统计卡片在窄屏下从4列降为2列，明细表横向可滚动，抽屉面板在移动端全屏展开。
