
## 1. 产品概述
篮球投篮抛物面演示系统，用于处理真实设备坐标数据的异常检测与可视化分析，支持3D渲染对比、问题处理流程管理，主要服务于规划设计师进行数据质量评估和问题定位。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 规划设计师 | 无需注册 | 所有功能完整访问 |

### 2.2 功能模块
1. **数据导入页面**: 文件上传、数据预览、原始数据查看
2. **异常检测页面**: 离群点识别、异常列表、详情查看
3. **3D可视化页面**: 3D抛物面渲染、数据点展示、视角控制
4. **时间回放页面**: 前后对比、时间轴控制、参数调整
5. **问题处理页面**: 相机视角丢失问题处理、解决方案选择、结论对比
6. **报告页面**: 汇总报告、问题追溯、结果导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 数据导入 | 文件上传 | 支持CSV/JSON格式数据导入，包含设备坐标数据 |
| 数据导入 | 数据预览 | 表格展示原始数据，快速浏览 |
| 异常检测 | 离群点识别 | 自动检测漂浮的离群点数据 |
| 异常检测 | 异常列表 | 展示所有异常数据，支持筛选和排序 |
| 异常检测 | 详情查看 | 查看异常数据来源、处理意见、相关信息 |
| 3D可视化 | 3D渲染 | Three.js渲染篮球轨迹抛物面 |
| 3D可视化 | 数据点展示 | 正常点蓝色，异常点红色高亮 |
| 时间回放 | 前后对比 | 并排展示3D渲染修改前后的轨迹 |
| 时间回放 | 时间轴控制 | 可拖动时间轴查看不同时间点数据 |
| 问题处理 | 相机视角丢失处理 | 提供三种解决方案：重复运行、补录、人工确认 |
| 问题处理 | 新旧结论对比 | 并排展示坐标修改前后的结论 |
| 报告 | 问题追溯 | 可追溯离群点所在的材料来源 |
| 报告 | 结果导出 | 支持导出分析报告 |

## 3. 核心流程
用户首先导入真实设备坐标数据 → 系统自动检测异常 → 查看异常详情 → 通过3D可视化查看轨迹 → 使用时间回放对比修改前后效果 → 处理相机视角丢失问题 → 生成并查看最终报告。

```mermaid
flowchart TD
    A["数据导入"] --> B["异常检测"]
    B --> C["异常详情查看
    C --> D["3D可视化"]
    D --> E["时间回放"]
    E --> F["问题处理"]
    F --> G["报告生成"]
```

## 4. 用户界面设计
### 4.1 设计风格
- **主色调**: 深蓝色 (#1e3a8a) 配合 橙色 (#f97316)
- **辅助色**: 灰色系 (#f3f4f6, #6b7280, #1f2937)
- **按钮风格**: 扁平化圆角矩形，带有轻微阴影
- **字体**: Roboto + Noto Sans SC
- **布局风格**: 卡片式布局，顶部导航栏
- **图标**: 使用Material Icons

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 数据导入 | 上传区域 | 拖放区、文件选择器、进度条 |
| 异常检测 | 列表区域 | 数据表格、筛选栏、分页 |
| 3D可视化 | 3D画布 | 3D场景、控制面板、图例 |
| 时间回放 | 对比区域 | 左右分栏、时间滑块、播放控制 |
| 问题处理 | 处理面板 | 三种解决方案按钮、结果对比 |
| 报告 | 报告区域 | 报告内容、导出按钮 |

### 4.3 响应式
桌面端优先，支持平板和移动设备自适应。

### 4.4 3D场景指导
- **环境**: 简洁的篮球场场景，蓝色天空盒背景
- **灯光**: 柔和的环境光 + 两个方向光
- **相机**: 可自由旋转、缩放、平移的透视相机
- **交互**: 鼠标拖拽旋转，滚轮缩放
- **动画**: 篮球轨迹平滑动画
- **后处理**: 抗锯齿，轻微辉光效果
