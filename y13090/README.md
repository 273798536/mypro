# 桥隧检修平台空间复核

## 快速开始

```bash
npm install
npm run dev
```

## 三步操作

### 01 放样例
点击页面顶部「**放样例**」按钮，加载标准教学用例数据。
页面自动生成：筛选条件、统计卡片、明细表、截图说明——全部来自**同一结果集**。

### 02 重跑
调整筛选条件后，点击「**重跑**」基于当前筛选重新执行复核算法。

### 03 查看截图说明
点击截图说明区的「**查看截图说明**」，展开当前截图对应的视角参数与异常标注。

## 坏材料来了该看哪里

| 问题 | 去哪里看 |
|------|----------|
| **材料名称不一致**（"Q345旧版" vs 标准"Q345B 钢板"） | 右下角「异常检测面板」→ 切换到 **「名称不一致」** 标签 → 点「关联最终结论」把这条旧说法和结论连起来 |
| **楼层单位混写**（同区域既有"3层"又有"3F"又有"Floor3"） | 右下角「异常检测面板」→ 切换到 **「楼层单位混写」** 标签 → 这些记录已被**单独拎出**，不会混入正常结果 |
| **前一天保存的视角复原不了** | 页面中部「视图快照」栏 → 点击任意快照缩略图 → 一键复原当时的**视角 + 筛选条件** |
| **想从明细表定位异常对象** | 明细表每行右侧的「定位」按钮 → 3D 视图自动高亮对应传感器标记 |

> 林姐注意：所有统计、明细、截图都从**同一结果集**生成，不会出现"翻出一条旧说法和截图对不上"的情况。
