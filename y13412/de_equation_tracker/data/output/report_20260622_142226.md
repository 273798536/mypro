- **来源**：高数组-2024春
- **方程类型**：一阶线性
- **标准形式**：y' + P(x)y = Q(x)
- **输入参数**：P(x)=2/x，Q(x)=x*sin(x)
- **给出解**：y = (1/x^2) * (sin(x) - x*cos(x) + C)
- **解题方法**：积分因子法：先算积分因子 μ(x) = e^(∫P(x)dx)，再乘两边积分
- **通解公式**：y = e^(-∫Pdx) · (∫Q·e^(∫Pdx) dx + C)
- **备注**：课堂例题1

> 解题用的是积分因子法：先算积分因子 μ(x) = e^(∫P(x)dx)，再乘两边积分，套通解公式 y = e^(-∫Pdx) · (∫Q·e^(∫Pdx) dx + C)，
