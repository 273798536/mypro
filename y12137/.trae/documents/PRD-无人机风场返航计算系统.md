## 1. 产品概述

无人机风场返航计算系统，解决航测任务中无人机风场返航决策的核心计算、留痕与溯源问题。针对航测队长在补充载荷重量时担心旧结论被覆盖的痛点，提供从样例导入到报告输出的完整计算链路，确保每一步人工修正都有迹可循，每条判断结论都能追溯到原始数据来源。

目标用户为航测团队队长、飞控工程师和数据分析人员。核心价值在于计算过程透明化、历史数据持久化、风险提示精准化，避免因风场突变、电池老化、禁飞区绕行等复杂场景下的错误决策。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 航测队长 | 系统登录 | 导入样例、发起计算、人工修正、查看报告、管理历史记录 |
| 飞控工程师 | 系统登录 | 查看计算细节、溯源验证、风险分析 |

### 2.2 功能模块

1. **计算任务管理页：任务列表、新建计算、导入样例
2. **计算详情页：能耗模型展示、返航阈值计算、风险提示、人工修正、来源溯源
3. **报告输出页：完整报告、导出功能
4. **历史记录页：历史计算列表、去重展示、对比分析

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 计算任务管理 | 任务列表 | 展示所有计算任务，状态筛选，快速新建计算 |
| 计算任务管理 | 样例导入 | 支持JSON格式导入航点计划、载荷重量、返航报告混合数据包，自动解析分类 |
| 计算详情 | 能耗模型 | 实时计算无人机在不同风场、载荷、电池状态下的能耗曲线 |
| 计算详情 | 返航阈值 | 基于能耗模型计算安全返航的电池阈值、距离阈值、时间阈值 |
| 计算详情 | 风险提示 | 识别逆风突变、电池老化、禁飞区绕行等高风险场景并给出提示 |
| 计算详情 | 人工修正 | 支持人工调整参数，自动记录修正人、修正时间、修正前后值 |
| 计算详情 | 来源溯源 | 每条计算结论展示原始数据包、计算链路、修正记录完整溯源链 |
| 报告输出 | 报告生成 | 生成包含所有计算过程、风险提示、修正记录的完整报告 |
| 历史记录 | 历史列表 | 展示所有历史计算，支持按时间、任务筛选 |

| 历史记录 | 持久化存储 | 服务重启后历史记录不丢失 |

## 3. 核心流程

用户从导入样例数据包开始，系统自动解析航点计划、载荷重量、返航报告等不同类型数据。然后进入计算流程，依次执行能耗模型计算、返航阈值计算、风险识别。计算过程中支持人工修正参数，所有修正自动留痕。计算完成后生成完整报告，同时系统自动对计算结果哈希去重，避免重复结论。所有数据持久化存储到SQLite，服务重启后历史记录完整保留。

```mermaid
flowchart TD
    A["导入混合数据包"] --> B["自动解析分类<br/>
    B --> C["航点计划数据"]
    B --> D["载荷重量数据"]
    B --> E["返航报告数据"]
    C & D & E --> F["能耗模型计算"]
    F --> G["返航阈值计算"]
    G --> H["风险识别与提示"]
    H --> I{需要人工修正?}
    I -->|是| J["人工修正参数<br/>记录修正留痕"]
    J --> F
    I -->|否| K["生成计算报告"]
    K --> L["内容哈希去重"]
    L --> M["持久化存储到SQLite"]
    M --> N["输出报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝科技感配色，主色 #1e3a5f，辅助色 #00d4ff，强调警示色 #ff6b6b
- **按钮风格**：微立体圆角设计，悬停时有微妙阴影和过渡动画
- **字体**：标题使用 JetBrains Mono 等宽字体展示数据，正文使用 Inter 提升科技感
- **布局风格**：卡片式布局，左侧导航 + 右侧内容区，数据可视化区域突出展示
- **图标风格**：线性图标，数据溯源使用链条/链路可视化展示
- **背景**：深色科技感背景，配合渐变叠加网格纹理

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|----------|---------|
| 计算任务管理 | 任务列表 | 深色卡片式列表，状态标签，悬停高亮，渐入动画 |
| 计算详情 | 能耗曲线 | Chart.js 折线图，多维度数据可视化 |
| 计算详情 | 来源溯源 | 时间轴式溯源链路展示，节点可展开查看详情 |
| 计算详情 | 风险提示 | 警示卡片，红色边框闪烁动画，高对比度突出 |
| 计算详情 | 人工修正 | 修正记录表格，高亮显示前后对比 |
| 报告输出 | 报告预览 | 结构化报告，支持PDF/JSON导出 |
| 历史记录 | 去重标识 | 重复计算灰色叠加展示，对比视图 |
