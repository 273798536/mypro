# SaaS座席超额计费本地服务

## 启动方式

### 1. 安装依赖
```bash
npm install
```

### 2. 初始化样例数据
```bash
npm run init-data
```

### 3. 启动服务
```bash
npm start
```

服务默认端口：3000
API前缀：http://localhost:3000/api

### 4. 健康检查
```bash
curl http://localhost:3000/api/health
```

## 座席重复的触发办法

### 方式一：通过测试接口触发

**接口：** `POST /api/seat-usages/trigger-duplicate-test`

**请求体：**
```json
{
  "contract_id": 1,
  "billing_cycle": "2026-05",
  "employee_id": "EMP-TEST-DUP"
}
```

**效果：** 自动创建2条同一合同、同一计费周期、同一员工、同一日期的用量记录，系统会自动检测出重复。

**示例响应：**
```json
{
  "success": true,
  "message": "测试重复数据已创建",
  "data": {
    "testRecords": [
      { "id": 7, "usage_batch_no": "TEST-DUP-xxx-1", "current_active_seats": 2 },
      { "id": 8, "usage_batch_no": "TEST-DUP-xxx-2", "current_active_seats": 3 }
    ],
    "detectionResult": {
      "isDuplicate": true,
      "reason": "同一合同[1]同一计费周期[2026-05]同一员工[EMP-TEST-DUP]在[2026-05-31]已有用量记录"
    }
  }
}
```

### 方式二：批量检测现有数据

**接口：** `GET /api/seat-usages/detect-duplicates?contract_id=1&billing_cycle=2026-05`

**效果：** 扫描指定合同和计费周期下的所有用量，识别出同一员工同一日期的重复记录。

### 方式三：新增时自动检测

新增座席用量时，如果同一合同、同一计费周期、同一员工、同一日期已有记录，系统会：
1. 将新记录标记为 `is_duplicate: true`
2. 记录 `duplicate_of_id` 指向已有记录
3. 在响应中返回 `warnings` 提示重复

## 核心设计要点

### 1. 原始值与当前结论双轨存储
所有关键字段均保留 `original_*` 和 `current_*` 两份数据：
- `original_active_seats` / `current_active_seats`
- `original_contracted_seats` / `current_contracted_seats`
- `original_excess_seats` / `current_excess_seats`
- `original_billing_amount` / `current_billing_amount`

### 2. 计费规则缺失可操作提示
当计费规则缺失时，接口返回 `actionableHints`，包含：
- 问题类型（无规则、已过期、未生效等）
- 严重级别（error/warning/info）
- 具体操作建议
- 临时处理方案（人工修正）

### 3. 降配口径变更影响追踪
执行降配申请前，可通过 `/affected-usages` 接口预览：
- 受影响的计费周期
- 口径变更内容
- 每条受影响用量的旧值、新值、差异
- 总影响条数和金额

### 4. 跨月降配处理
支持三种跨月降配规则：
- `current_month`：当月生效
- `next_month`：次月生效
- `by_effective_date`：按降配生效日按天折算

### 5. 人工修正全程留痕
- 保留 `before_value` 和 `after_value` 完整快照
- `change_summary` 记录每个字段的变更差异
- 可通过 `/history` 接口查询完整修正历史
- 账单导出时包含原始值、当前值、差异三列

### 6. 发票红冲
- 创建红冲账单时自动关联原账单
- 同步更新相关用量记录的红冲标识
- 红冲金额计入账单 `red_flush_amount`
- 用量和账单均保留原始值便于复盘

### 7. 账单导出一致性
账单导出与账单生成使用**同一份数据**：
- 从 `bill_usage_links` 关联表读取用量
- 用量的 `current_*` 字段作为最终值
- `original_*` 字段用于差异列展示
- 导出次数、导出时间、导出人均有记录

## 状态流转说明

### 座席用量状态
```
draft → pending_review → reviewed → billing → billed
                      ↓          ↓
                  rejected   corrected ←┘
```

### 降配申请状态
```
pending → approved → executed
           ↓
        rejected
```

### 人工修正状态
```
pending → approved → executed
           ↓
        rejected
```

### 账单状态
```
draft → confirmed → invoiced → paid
          ↓            ↓        ↓
       cancelled   cancelled  cancelled
```

```bash
curl -X POST http://localhost:3000/api/seat-usages \
  -H "x-operator: zhangsan" \
  -H "Content-Type: application/json" \
  -d '{...}'
```

## 常见操作示例

### 1. 新增座席用量
```bash
curl -X POST http://localhost:3000/api/seat-usages \
  -H "x-operator: zhangsan" \
  -H "Content-Type: application/json" \
  -d '{
    "contract_id": 1,
    "billing_cycle": "2026-05",
    "usage_date": "2026-05-25",
    "employee_id": "EMP007",
    "employee_name": "周九",
    "department": "市场部",
    "active_seats": 3
  }'
```

### 2. 查看降配影响
```bash
curl http://localhost:3000/api/downgrade-requests/1/affected-usages
```

### 3. 执行人工修正
```bash
# 创建修正申请
curl -X POST http://localhost:3000/api/manual-corrections \
  -H "x-operator: lisi" \
  -H "Content-Type: application/json" \
  -d '{
    "target_type": "seat_usage",
    "target_id": 6,
    "correction_type": "usage",
    "fields": {
      "current_excess_seats": 10,
      "current_billing_amount": 3588
    },
    "reason": "5个测试账号不计入计费",
    "exception_type": "data_error"
  }'

# 审批
curl -X POST http://localhost:3000/api/manual-corrections/1/approve \
  -H "x-operator: wangwu"

# 执行
curl -X POST http://localhost:3000/api/manual-corrections/1/execute \
  -H "x-operator: zhaoliu"
```

### 4. 生成并导出账单
```bash
# 生成账单
curl -X POST http://localhost:3000/api/bills \
  -H "x-operator: caiwu" \
  -H "Content-Type: application/json" \
  -d '{
    "contract_id": 1,
    "billing_cycle": "2026-05"
  }'

# 导出（含差异列）
curl "http://localhost:3000/api/bills/1/export?include_diff=true" \
  -H "x-operator: caiwu"

# 下载文件
curl -O http://localhost:3000/api/bills/exports/BILL-xxx.csv
```
