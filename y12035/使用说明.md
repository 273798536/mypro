# 债券久期弹球 - 投教游戏原型

## 一、项目简介

"债券久期弹球"是一款面向金融培训场景的投教游戏原型，通过弹球游戏形式教授债券久期、利率风险、现金流管理等核心金融概念。游戏强调真实金融结算逻辑，适合课堂或培训现场试玩。

## 四、游戏机制说明

### 1. 核心概念

**债券久期（Duration）**：衡量债券价格对利率变动的敏感度，单位为"年"。

**核心公式**：
```
价格变动百分比 ≈ -修正久期 × 利率变动
```

**关键理解**：
- 利率上升 → 债券价格下降
- 利率下降 → 债券价格上升
- 久期越大，利率变动对价格的影响越大

### 2. 游戏元素

| 元素 | 颜色 | 作用 |
|------|------|------|
| 债券球 | 金色 | 代表一只债券，碰撞挡板触发利率事件 |
| 利率挡板（升息） | 红色 | 碰撞后利率上升，债券价格下降 |
| 利率挡板（降息） | 绿色 | 碰撞后利率下降，债券价格上升 |
| 利率挡板（缺字段） | 黄色 | 数据不完整，使用默认利率变动值（0.25%） |
| 现金流道具（票息） | 蓝色 | 碰撞后5秒内点击确认收集 |
| 现金流道具（本金） | 紫色 | 碰撞后5秒内点击确认收集 |

### 3. 利率连跳触发条件

**触发方式**：连续碰撞3次同方向（升息或降息）的挡板

**效果**：第3次及之后的碰撞会触发"利率连跳"，利率变动按累计值计算：
- 单次变动0.5% → 连跳3次总变动1.5%
- 久期结算也会按总变动值计算

## 五、复盘功能

游戏过程中的所有事件都会被记录，点击状态面板的图表图标可查看复盘：

### 1. 利率事件
- 每次利率变动的时间、数值、计算公式
- 利率连跳事件会单独标记⚡符号

### 2. 久期结算
- 每次利率变动后的久期计算明细
- 完整显示公式：`价格变动% = -修正久期 × 利率变动`
- 方向错误时显示修正建议

### 3. 现金流漏计
- 记录所有超时未收集的现金流
- 提供可操作的修正步骤：补记金额、影响分析等

### 4. 成绩导出
支持两种格式导出：
- **JSON格式**：完整数据结构，包含所有事件详情
- **CSV格式**：表格形式，适合导入Excel分析

## 六、特殊机制说明

### 1. 久期条延迟（关卡2+）
- 30%概率触发
- 久期数值会延迟1.5-2秒才更新显示
- 模拟真实市场中的信息延迟

### 2. 字段缺失
- 部分利率挡板缺少`rateChange`字段
- 系统自动使用默认值0.25%进行计算
- 挡板显示为黄色并标记"字段缺失"

### 3. 现金流漏计检测
- 道具被碰撞后5秒内必须点击确认
- 超时自动标记为"漏计"
- 显示修正建议和补记步骤

## 九、金融计算说明

### 修正久期计算

```typescript
修正久期 = 麦考利久期 / (1 + 收益率)
```

### 价格变动计算

```typescript
价格变动百分比 = -修正久期 × 利率变动
```

**示例**：
- 麦考利久期：4.5年
- 当前收益率：3.0%
- 利率变动：+0.5%
- 修正久期 = 4.5 / (1 + 0.03) ≈ 4.37
- 价格变动 = -4.37 × 0.5% ≈ -2.185%

## 十、常见问题

**Q: 如何触发利率连跳？**
A: 连续碰撞3次同方向的利率挡板。建议选择关卡2，该关卡有3个连续的升息挡板便于测试。

**Q: 现金流道具为什么会变灰？**
A: 碰撞后5秒内未点击确认收集，会被标记为"漏计"，此时道具变灰无法再收集。

**Q: 久期条显示"计算中..."是什么意思？**
A: 触发了久期延迟机制，模拟真实市场的信息延迟，数值会在1.5-2秒后更新。

**Q: 如何添加自定义关卡？**
A: 编辑 `/src/data/levels.ts` 文件，在levels数组中添加新的关卡配置即可。
