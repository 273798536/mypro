## 1. 产品概述

蒙特卡洛误差图表解释是一款面向数据分析人员的专业工具，解决蒙特卡洛模拟中单位换算偏差、数据来源混杂、结果跳变原因不明等核心痛点。

- **核心问题**：公式正确但单位切换导致结果偏差、计算草稿与正式记录混杂影响结论、结果跳变无法定位原因
- **目标用户**：数据分析员（小孟）、项目负责人
- **产品价值**：统一单位口径、清晰标记数据来源、智能诊断结果异常、可追溯的筛选历史

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 数据分析员 | 录入数据、运行模拟、查看图表、导出报告、管理记录 |
| 项目负责人 | 查看处理进度、审阅报告、确认已处理/待补证据项 |

### 2.2 功能模块

1. **误差图表主页**：蒙特卡洛模拟结果可视化、单位切换、实时数值展示
2. **数据记录管理**：正常记录、计算草稿、口头备注的分类管理与来源标记
3. **筛选历史时间线**：记录所有筛选口径变更，可回溯复现
4. **异常诊断面板**：重复样本检测、结果跳变原因分析、处理建议
5. **导出报告**：与屏幕数字一致的报告导出、处理进度汇总

## 3. 核心流程

用户录入数据 → 选择单位口径 → 运行蒙特卡洛模拟 → 查看误差图表 → 标记数据来源 → 保存筛选口径 → 检测异常/跳变 → 导出报告 → 负责人审阅

```mermaid
    B --> C["运行蒙特卡洛模拟"]
    C --> D["查看误差图表"]
    D --> E["标记数据来源"]
    E --> F["保存筛选口径"]
    F --> G["异常诊断检测"]
    G --> H{"是否有异常?"}
    H -->|是| I["查看跳变原因与处理建议"]
    H -->|否| J["导出报告"]
    I --> J
    J --> K["负责人审阅进度"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#1e3a5f) 作为主色，搭配青绿色 (#10b981) 作为数据正常态强调色，琥珀橙 (#f59e0b) 作为警告态
- **辅助色**：浅灰蓝背景 (#f0f4f8)，白色卡片，深灰文字 (#1f2937)
- **按钮风格**：圆角 8px，主按钮有轻微悬浮阴影，次要按钮为描边样式
- **字体**：标题使用 Cormorant Garamond（衬线字体，专业感），正文使用 Inter（清晰易读）
- **布局风格**：左侧导航 + 主内容区卡片式布局，图表区域占主要视觉重心
- **图标风格**：线性细图标，统一 24px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 误差图表主页 | 图表展示区 | 大型直方图 + 曲线叠加，数值标注悬浮提示，渐变色填充 |
| 误差图表主页 | 控制面板 | 单位下拉选择器、滑块控件、数字输入框、操作按钮组 |
| 误差图表主页 | 实时数值卡 | 4-6 个指标卡片，网格排列，数字大号突出 |
| 数据记录管理 | 记录列表 | 斑马纹表格，来源标签彩色标记，悬停高亮 |
| 筛选历史时间线 | 时间线列表 | 垂直时间轴，节点图标，时间戳，操作摘要 |
| 异常诊断面板 | 诊断卡片 | 警告图标 + 原因描述 + 分步处理建议，琥珀色边框 |
| 导出报告 | 进度汇总 | 双栏布局：已处理（绿色勾选）/ 待补证据（橙色提醒） |

### 4.3 响应式

桌面端优先设计，左侧固定导航栏，主内容区自适应。
- ≥1200px：三栏布局（导航 + 图表 + 侧栏指标）
- 768px-1200px：两栏布局（导航收起为图标 + 主内容）
- <768px：单栏堆叠，底部导航

### 4.4 动效设计

- 图表加载：柱状图从下往上渐次升起，曲线从左到右描边绘制
- 数值变化：数字翻转动效，平滑过渡
- 卡片悬浮：轻微上浮 + 阴影加深
- 时间线回溯：高亮脉冲动画，指示当前回放状态
- 异常提示：呼吸灯效果，吸引注意力但不刺眼
