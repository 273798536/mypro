# 整数规划边界校验 · 操作说明

## 一、放样例

把以下3个文件放在同一目录下即可：

| 文件 | 作用 |
|------|------|
| `题目清单_整数规划边界校验.csv` | 主线题目，阿宁据此拼出校验流程 |
| `正常记录_REC-2026-0613-0042.txt` | 单条样本数据，内含单位敏感问题 |
| `后补说明_重复样本挂起流程.md` | 重复样本时的处理规则 |

## 二、重跑

用任意Markdown预览工具打开 `整数规划边界校验_分析报告.md` 即可完成复核。报告内参数版本、异常点、解释在同一页，不需要跳转。

如需重新计算：
1. 核对"一、参数版本"表中所有系数和单位
2. 按"二、异常点1"中两条路径手算一遍灵敏度扰动
3. 对比结论是否一致
