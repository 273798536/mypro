# 整数规划边界校验 · 操作说明

## 一、放样例

把以下文件放在同一目录下即可（已就绪）：

| 文件 | 作用 |
|------|------|
| `题目清单_整数规划边界校验.csv` | 主线题目，阿宁据此拼出校验流程 |
| `批量样本数据_整数规划校验.csv` | 批量样本，含吨/kg混用和重复样本 |
| `正常记录_REC-2026-0613-0042.txt` | 单条样本解释，说明正常记录为何影响结论 |
| `后补说明_重复样本挂起流程.md` | IP-007重复样本处理规则 |
| `integer_program_checker.py` | **真实可执行的校验脚本**（核心新增） |

## 二、重跑（真实可执行流程）

打开终端，进入当前目录，执行：

```bash
python3 integer_program_checker.py
```

脚本会自动完成：
1. 读取 `批量样本数据_整数规划校验.csv` 全部样本
2. 逐条校验整数约束、边界约束、目标函数匹配
3. 自动检测单位不一致（IP-005）
4. 自动检测重复样本（IP-007），触发则挂起
5. 执行IP-006灵敏度分析（±5%扰动约束右端项）
6. 对比正确路径 vs 错误路径，输出警告
7. 生成 `整数规划边界校验_分析报告.md`

## 三、查看Markdown报告

报告文件：`整数规划边界校验_分析报告.md`

报告特点：**参数版本 + 异常点 + 解释全部在同一页**，复核时不用翻其他文档。

交接时请确认：
- 从题目清单能定位到原始说法（题号→页码）
- 从报告能讲清处理结果（当前批次因单位不一致+重复样本，状态：挂起）

## 四、异常提示速查

| 终端输出 | 含义 | 处理 |
|-----------|------|------|
| `[WARNING] 检测到【单位不一致】` | 吨/kg混用 | 按IP-005挂起，待确认 |
| `[WARNING] 检测到【重复样本】` | 输入参数完全一致 | 按IP-007挂起，待项目经理确认 |
| `⚠ 灵敏度结论不一致！` | 正确路径触发边界，错误路径假稳定 | 检查单位换算 |
| `批次状态: 挂起` | 存在异常 | 不要给假稳定结论 |
