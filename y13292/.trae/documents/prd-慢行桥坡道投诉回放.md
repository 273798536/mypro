# 慢行桥坡道投诉回放 - 产品需求文档

## 1. 产品概述

**慢行桥坡道投诉回放**是一套面向城市规划与运维团队的 GIS 点位投诉回溯工具。它将散落在聊天记录中的坡道投诉与 GIS 点位数据对齐，通过地图可视化、异常高亮、历史时间线和现场照片补录，帮助规划师和接手同事快速复盘投诉原因、确认处理进展，避免领导追问时只能翻聊天记录的尴尬。

- 目标用户：规划师、运维接手同事、部门领导
- 核心场景：周一早会复盘、投诉溯源、交接交底
- 产品定位：轻量、精准、可解释的 GIS 投诉回放工具

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心诉求 |
|------|----------|----------|
| 规划师（小赵） | 日常操作、数据补录 | 把投诉与GIS点位对齐，捋顺聊天记录里的线索 |
| 接手同事 | 复盘、交接 | 快速看懂每条投诉的来龙去脉，不踩容量超限的坑 |
| 部门领导 | 早会查看 | 一眼看到异常点位和处理进展 |

### 2.2 功能模块

1. **主地图面板**：GIS点位分布、正常/异常分层展示、点位来源标注
2. **异常筛选栏**：容量超限记录单独拎出，不混入正常结果
3. **历史时间线**：按时间回放投诉全流程，标注补录和人工确认节点
4. **现场照片补录**：上传照片后地图点位和时间线同步更新，可对比变化
5. **人工确认记录**：记录确认前后状态变化，支持复盘说明
6. **演示数据包**：内置"不太干净"的演示数据，含正常记录和容量超限

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面（单页应用） | 顶部标题栏 | 系统名称、当前数据包选择、演示数据切换 |
| 主页面 | 左侧点位列表面板 | 投诉列表，正常/超限分开展示，点击定位地图 |
| 主页面 | 中央GIS地图 | 点位标记，异常高亮闪烁，悬停显示来源 |
| 主页面 | 右侧详情面板 | 选中点位的详情、现场照片、状态变更历史 |
| 主页面 | 底部时间线 | 横向时间轴，可拖动回放，标注关键事件节点 |

## 3. 核心流程

### 3.1 投诉回放主流程

规划师打开系统 → 选择数据包 → 地图加载所有GIS点位 → 左侧列表区分正常/超限 → 点击某条超限记录 → 地图定位并高亮 → 右侧查看详情和照片 → 底部时间线拖动回放 → 看到人工确认前后变化 → 完成复盘

```mermaid
flowchart LR
    A["打开系统"] --> B["选择GIS数据包"]
    B --> C["地图加载点位"]
    C --> D["左侧列表分层展示"]
    D --> E["点击超限记录"]
    E --> F["地图定位高亮"]
    F --> G["右侧查看详情与照片"]
    G --> H["底部时间线回放"]
    H --> I["查看人工确认变化"]
    I --> J["完成复盘"]
```

### 3.2 现场照片补录流程

选中投诉点位 → 点击补录照片 → 上传现场照片 → 系统记录补录时间 → 地图点位更新状态 → 时间线新增补录节点 → 可对比补录前后差异

### 3.3 人工确认流程

选中待确认点位 → 查看历史记录 → 人工确认/驳回 → 记录确认人和时间 → 状态变更进入历史 → 周一早会可追溯解释

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#0F172A) 背景 + 青蓝 (#0EA5E9) 高亮，体现GIS专业感
- **异常色**：警示橙 (#F97316) 用于容量超限，脉冲动画强调
- **正常色**：墨绿 (#10B981) 用于正常记录
- **字体**：主标题使用空间感强的等宽字体，正文使用现代无衬线字体
- **布局**：三栏式 + 底部时间线，深色主题，地图为视觉中心
- **风格关键词**：科技感、数据驱动、专业冷峻、微光点缀

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 顶部标题栏 | 深色毛玻璃背景、系统名称、数据包下拉、演示模式开关 |
| 主页面 | 左侧列表 | 卡片式列表，超限卡片橙色边框，正常卡片绿色标记，可折叠分组 |
| 主页面 | 中央地图 | 暗色底图，点位发光标记，异常点脉冲动画，点击弹出信息窗 |
| 主页面 | 右侧详情 | 照片轮播、状态标签、来源信息、变更历史时间轴 |
| 主页面 | 底部时间线 | 横向可拖动时间轴，节点用不同图标区分事件类型 |

### 4.3 响应式

- 桌面端优先（1280px+），三栏布局完整展示
- 平板端左右面板可折叠，地图占主要空间
- 移动端单列堆叠，列表在上、地图在中、详情在下

### 4.4 动效设计

- 异常点位脉冲呼吸动画，每秒一次
- 列表项悬停微上浮 + 发光边框
- 时间线拖动时地图点位实时联动
- 照片补录后点位颜色渐变过渡
- 页面加载时元素错落淡入
