# 跨境收款汇损管理系统

专为外贸财务人员设计的跨境收款汇损管理工具，解决多币种收款、银行水单匹配、汇损计算与异常追溯。

## 功能特性

- **多币种换算**：支持 USD、EUR、CNY、GBP、GBP、JPY 等多币种自动换算
- **智能到账匹配**：订单号、日期、金额三重匹配，置信度可视化
- **汇损自动计算**：自动识别汇率日期错用、部分到账、手续费内扣等异常
- **数据追溯**：完整保留来源记录与修正痕迹
- **可视化看板**：汇损趋势图、币种分布图、异常分布图
- **CSV 导入导出**：支持批量导入与报表导出
- **本地存储**：基于 IndexedDB，数据安全不联网

## 快速开始

### 1. 启动项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

访问 http://localhost:5173

### 2. 造数（测试数据）

点击右上角「造数」按钮，系统将自动生成 30 天测试数据，包括：

- 客户订单（多币种）
- 银行水单
- 平台账单
- 汇率数据

### 3. 主要操作流程

**第一步：数据导入

- 左侧菜单「数据导入」
- 选择要导入的数据类型（订单/水单/账单/汇率）
- 下载模板，按格式填写数据
- 拖拽或选择 CSV 文件上传
- 预览数据后确认导入

**第二步：到账匹配**

- 左侧菜单「到账匹配」
- 点击「自动匹配」按钮
- 系统自动按订单号、日期、金额进行匹配
- 可手动取消错误匹配
- 查看匹配置信度

**第三步：计算汇损**

- 左侧菜单「汇损明细」
- 点击「计算汇损」按钮
- 系统自动计算每笔订单的汇损
- 自动标记异常情况

**第四步：处理异常**

- 查看异常标记的记录
- 可确认或忽略异常
- 导出汇损报表

### 4. 异常场景说明

系统会自动识别以下异常场景，并以橙色徽章标记：

| 异常类型 | 说明 | 处理方式 |
|---------|------|---------|
| 汇率日期不匹配 | 交易日期无对应汇率 | 补充汇率数据后重新计算 |
| 部分到账 | 到账金额与订单金额不符 | 手动核实实际到账金额 |
| 手续费内扣 | 到账金额已扣除手续费 | 需手动调整汇损金额 |
| 无匹配水单 | 订单未匹配到银行水单 | 检查订单号或手动匹配 |

### 5. 汇率管理

- 左侧菜单「汇率管理」
- 支持手动添加汇率
- 支持批量导入汇率
- 按币种对分组展示
- 可编辑删除手动录入的汇率

## 数据安全

- 所有数据均存储在浏览器本地 IndexedDB 中
- 不联网、不上传、不存储在服务器
- 清除浏览器数据将清除所有数据
- 建议定期导出重要数据

## 常见问题

**Q: 数据会丢失吗？
A: 数据存储在浏览器本地，只要不清除浏览器缓存或使用无痕模式，数据会一直保留。

**Q: 支持哪些浏览器？
A: 推荐使用 Chrome、Edge、Firefox 最新版本。

**Q: 如何备份数据？
A: 在汇损明细页面点击「导出报表」可导出 CSV 格式备份。

**Q: 汇损是怎么算的？
A: 汇损 = 订单金额 × 订单日汇率折算人民币 - 实际到账人民币金额。
