## 1. 产品概述

订单库幂等冲突报告工作台是面向业务审计、数据运维团队的本地 Web 工具，聚焦"迁移重复执行"类幂等冲突的发现、追溯、修正与交接。解决了审计前临时抱佛脚、重复执行无提前暴露、月底转交时记录可用性不清等痛点。

- 核心价值：把"没人想碰的脏活"变成日常可追踪、可解释、可导出的标准化流程；导出报告即自带原因解释，业务同事不进系统也能看懂。
- 目标用户：业务审计同事、数据迁移运维、DBA、月底交接人。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|---------|---------|
| 审计只读 | 本地账号 / SSO 映射 | 列表浏览、详情查看、导出下载、历史查阅 |
| 数据运维 | 本地账号 + 二次确认 | 全部只读权限 + 冲突修正、备份补录、回滚记录联动 |
| 管理员 | 本地账号 + 权限审计链 | 全部权限 + 角色管理、权限审计日志查看 |

### 2.2 功能模块

1. **冲突总览页（Dashboard）**：冲突趋势图（附带明细表解释）、按严重度分布、近 7 天拦截 Top 原因、快速筛选入口
2. **冲突列表页**：迁移重复执行记录表格、多维筛选、批量标记、批量导出、状态标签
3. **冲突详情页**：主记录信息、表结构快照（字段对比）、迁移执行轨迹、幂等键分析、旁边附明细解释面板
4. **修正操作页**：冲突修正表单、备份补录、回滚记录联动预览、二次确认弹窗
5. **操作历史页**：按记录 / 按人 / 按时间的操作审计链、权限变更记录、备份补录与回滚对应关系
6. **下载中心**：多种导出格式（PDF/Excel/CSV）、导出模板预览、导出历史追溯

| 操作历史页 | 筛选与追溯 | 可按记录 ID、操作人、操作类型、时间范围筛选，支持"跳转回原记录详情" |

## 3. 核心流程

### 3.1 日常冲突发现与处理流程

业务同事日常登录 → 打开 Dashboard 查看趋势与明细解释 → 发现异常趋势 → 点击趋势点跳转到对应筛选后的列表 → 查看单条详情 → 浏览表结构快照与字段差异说明 → 查看迁移执行轨迹与拦截原因 → 判断处理策略 → 进入修正操作 → 勾选备份补录 → 预览回滚记录更新 → 二次确认提交 → 自动更新操作历史与权限审计链 → 可随时导出包含完整解释的报告

### 3.2 月底转交流程

月底交接人登录 → 进入下载中心 → 选择"本月未处理/不可用记录"导出范围 → 勾选"包含不可用原因明细解释""包含表结构快照差异说明""包含权限审计链摘要" → 生成 PDF/Excel 报告 → 转交业务同事，对方无需登录系统即可通过报告理解哪些记录不能用、为什么不能用、拦截逻辑是什么

### 3.3 权限审计流程

```mermaid
flowchart LR
    A["操作发起"] --> B["读取操作人当前权限"]
    B --> C["记录权限快照（非一次性）"]
    C --> D["执行操作（修正/补录等）"]
    D --> E["生成备份补录记录"]
    E --> F["联动更新回滚记录"]
    F --> G["写入操作历史"]
    G --> H["关联权限快照 + 补录回滚对应关系"]
    H --> I["后续若权限变更，历史审计仍可追溯当时权限状态"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：深蓝 `#1E3A5F`（审计/专业感）+ 警示琥珀 `#D97706`（冲突标记）+ 成功绿 `#059669`（已处理）+ 危险红 `#DC2626`（严重冲突）
- **辅助色**：石板灰 `#64748B`（次要文本）+ 冷白 `#F8FAFC`（页面底色）+ 网格线灰 `#E2E8F0`
- **按钮风格**：轻微圆角（6px）、2px 边框强调色、hover 有内阴影 + 轻微上移动画、danger 按钮带斜纹纹理背景
- **字体**：
  - 标题："Noto Serif SC"（宋体衬线，审计文档感）
  - 正文/表格："JetBrains Mono" + "PingFang SC"（等宽保证数据对齐，中文清晰可读）
  - 数据强调：数字等宽 "Tabular Nums"
- **布局风格**：左右双栏为主（左侧数据区 + 右侧常驻明细解释面板）、顶部面包屑导航 + 全局筛选条、卡片式模块分区、表格密集信息但行高舒适（44px）
- **图标风格**：Lucide 线性图标为主，状态节点用带边框的小圆点，避免纯靠颜色区分（每个状态同时有形状 + 文字标签）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素要点 |
|---------|---------|------------|
| 冲突总览页 | 趋势图区域 | 左 70% 折线图 + 右 30% 明细解释面板；图表 X 轴为日期，Y 轴为冲突数；hover 时在解释面板同步显示该日具体拦截记录列表与原因摘要；线条用实虚线区分严重度，同时图例带文字说明 |
| 冲突总览页 | 严重度环图 | 环图每个扇区旁边有数字标签 + 状态圆点 + 文字描述卡片；颜色之外用不同图案（斜纹/点阵/空白）填充扇区 |
| 冲突列表页 | 数据表格 | 冻结 ID 和操作列；严重度用"彩色圆点 + 文字标签"双标记；重复次数用徽标数字 + 背景深浅；状态切换用下拉菜单带图标；整行 hover 出现左侧操作竖条 |
| 冲突详情页 | 表结构快照对比 | 左右两栏，中间"差异箭头"连接；字段差异行整行高亮 + 差异类型标签（新增/删除/修改）；每字段 hover 弹出"影响说明"tips |
| 冲突详情页 | 迁移执行轨迹时间线 | 左侧垂直时间轴，节点为带数字的菱形（表示第几次尝试）；节点颜色对应结果状态，同时旁边有文字标签；点击节点展开日志抽屉 |
| 修正操作页 | 二次确认弹窗 | 三栏式：操作摘要 / 影响预览 / 权限校验链；底部双按钮："确认提交（已读影响）"为强调色，"取消"为次要色；确认前需勾选"我已知晓备份补录与回滚记录将联动更新" |
| 操作历史页 | 权限审计链 | 每条操作卡片包含：操作人头衔 + 权限标签徽章 + 权限来源（角色/临时授权）时间戳；补录与回滚之间用虚线箭头连接，hover 显示对应关系详情 |
| 下载中心 | 导出报告预览 | 模拟文档翻页效果；每页右上角有"明细解释索引"徽标；目录页列出所有图表 + 对应页码 + 简要说明 |

### 4.3 响应式

- 桌面端（默认）：≥1280px，左右双栏布局完整展示
- 平板（768–1279px）：明细解释面板改为底部抽屉，点击展开；表格可横向滚动
- 移动端（<768px）：卡片式列表，详情改为全屏纵向滚动；图表与明细解释上下堆叠；核心操作按钮悬浮底部

### 4.4 交互细节

- 页面加载：左侧数据先渐入（0–300ms），右侧明细解释面板后滑入（150–400ms），带轻微透明度过渡
- 表格行：hover 时左侧出现 4px 强调色竖条，同时右侧解释面板显示该行的快速摘要
- 修正提交：按钮点击后出现"正在校验权限 → 正在备份 → 正在更新回滚 → 完成"四步进度条，每步完成打勾
- 导出文件：生成中出现文件折叠动画，完成后图标变绿色并出现"下载"涟漪效果
