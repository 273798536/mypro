## 1. 产品概述

供应商保函到期预警系统，解决项目经理在保函到期时才仓促处理、合同延期与额度占用分散在不同表格中无法联动的问题。面向项目管理团队，实现保函到期主动预警、确认留痕、筛选导出一体化，确保保函过期状态不可被合同延期或额度重复覆盖，历史操作全程可追溯。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限说明 |
|------|----------|
| 项目经理 | 查看预警、确认预警、修改备注、导出报告 |
| 采购管理员 | 管理供应商档案、维护采购合同和保函信息 |
| 系统管理员 | 管理额度占用、查看操作历史、数据维护 |

### 2.2 功能模块

1. **预警清单页**：保函到期预警列表，支持筛选、确认、导出，过期和延期问题醒目标红
2. **供应商档案页**：供应商基础信息管理，含缺字段标红提示
3. **采购合同页**：采购合同与保函关联管理，合同延期记录留痕

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 预警清单 | 预警列表 | 展示所有保函到期预警记录，按紧急程度着色（过期=红、即将到期=橙、正常=绿），支持按供应商/合同/状态筛选 |
| 预警清单 | 确认操作 | 项目经理逐条或批量确认预警，确认后状态变更写入操作历史，已确认不可撤回 |
| 预警清单 | 导出报告 | 导出当前筛选结果的CSV报告，包含额度改动标记列，人工改动过的额度行高亮标注 |
| 预警清单 | 备注修改 | 支持对预警记录添加/修改备注，备注变更写入历史，标注修改人和时间 |
| 供应商档案 | 供应商列表 | 展示供应商名称、资质状态、联系方式等，缺字段项标红提示 |
| 供应商档案 | 供应商详情 | 展示关联的合同和保函信息，缺失字段以红色占位符提示 |
| 采购合同 | 合同列表 | 展示合同编号、供应商、保函信息、额度占用、延期状态 |
| 采购合同 | 合同详情 | 合同延期操作记录，保函过期后延期操作被拦截并提示，操作留痕 |
| 采购合同 | 额度占用 | 额度占用信息展示，人工改动记录标记，节点联动显示改动影响范围 |

## 3. 核心流程

1. 系统根据保函到期日期自动生成预警记录（到期前30天/15天/7天分级预警）
2. 项目经理打开预警清单，通过筛选定位待处理项
3. 确认预警后状态变为"已确认"，操作写入历史
4. 若保函已过期，合同延期操作被拦截，必须先处理保函续期
5. 额度占用被人工修改时，系统记录修改前后值，联动更新相关合同节点
6. 导出报告反映当前筛选条件下的完整数据，包含额度改动标记

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰(zinc)为底，红色(过期预警)、橙色(即将到期)、绿色(正常)为功能色
- 按钮风格：圆角方形，功能按钮实色填充，操作按钮描边风格
- 字体：正文使用系统字体栈，标题使用 Source Han Sans / Noto Sans SC
- 布局：左侧导航 + 右侧内容区，表格为主体展示形式
- 图标：使用 lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 预警清单 | 预警列表 | 顶部筛选栏(供应商下拉+状态筛选+日期范围)，表格(行按状态着色)，底部分页 |
| 预警清单 | 确认操作 | 行内确认按钮(橙色)，批量确认按钮(顶部工具栏)，确认弹窗 |
| 预警清单 | 导出报告 | 顶部工具栏导出按钮，导出进度提示，CSV下载 |
| 预警清单 | 备注修改 | 行内备注图标，点击弹出编辑弹窗，修改历史可展开查看 |
| 供应商档案 | 供应商列表 | 搜索栏+表格，缺字段单元格红色虚线框+提示文字 |
| 采购合同 | 合同列表 | 筛选栏+表格，延期状态标签，过期状态红色醒目标签 |
| 采购合同 | 额度占用 | 额度列显示占用/总额，人工改动行显示改动手动标记图标 |

### 4.3 响应式

桌面端优先设计，表格在窄屏下支持横向滚动，筛选栏在移动端折叠为抽屉式。

### 4.4 保函过期和合同延期的醒目设计

- **保函过期**：整行背景浅红色 + 左侧4px红色竖条 + 状态列红色"已过期"徽章
- **合同延期**：状态列橙色"已延期"徽章 + 延期天数提示
- **两者同时出现**：整行背景深红色 + 红色粗体文字，状态列同时显示"已过期"+"已延期"双徽章
