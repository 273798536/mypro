## 六、快速操作

### 启动 Web 界面（推荐非开发同事使用）

在项目根目录执行，以下两条等价，任选其一：

```bash
streamlit run webapp.py
# 或
python3 -m streamlit run hk_tax_recon/webapp.py
```

然后浏览器打开 `http://localhost:8501`。

### 6.1 放样例数据并跑一轮（CLI）

```bash
python3 -m hk_tax_recon.cli sample --out-dir ./data
python3 -m hk_tax_recon.cli run \\
  --batch-id FROM-WEB \\
  --emails ./data/sample_emails.xlsx \\
  --tax    ./data/sample_tax.xlsx \\
  --out    ./reports
```

### 6.2 重跑同一批次（保留历史对比，CLI）

```bash
python3 -m hk_tax_recon.cli rerun \\
  --batch-json ./reports/FROM-WEB.json \\
  --remark   "补录凭证号后复核" \\
  --out      ./reports
```

### 6.3 查看产物

```bash
# Markdown 报告（可用浏览器 / VS Code / Typora 打开）
open ./reports/FROM-WEB.md

# 批次 JSON（用于 CLI rerun 或 Web「🔄 重跑批次」上传）
ls -la ./reports/FROM-WEB.json
```

### 材料入口 & 异常出口（给没参与开发的同事）

- **入口**：把审批邮件（`.xlsx/.csv/.eml`）和税费明细（`.xlsx/.csv`）放在同一个目录，跑 `run` 命令或在 Web 上传即可。
- **出口**：报告第四部分「异常与待处理」就是异常出口——每条都有 `原因` 和 `下一步` 两列，照着做即可。
- 凭证晚到（⏰）：交易日+3个工作日还没凭证号会标出来，找托管要凭证号后重跑。
- 需人工确认（👤）：缺邮件或缺税费，核对材料是否齐全。
- 不匹配（❌）：汇率或金额差了，以托管对账单为准，确认后改数据再跑。
- 历史不一致（⚠️）：同一批两轮结果不一样，确认是数据修正还是口径变更。
