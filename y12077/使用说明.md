# 立体仓储货位热图分析系统 - 使用说明

## 快速开始

### 1. 准备货架模型数据

**数据格式要求：**

- **货架结构**：行数 × 列数 × 层数，例如 4排 × 8列 × 5层 = 160个货位
- **货位编号规则**：L{层}-C{列}-R{排}，例如 L0-C0-R0
- **货位尺寸**：每个货位的宽、高、深度（米）

**示例JSON格式：**
```json
{
  "id": "rack-001",
  "name": "A区立体货架",
  "rows": 4,
  "columns": 8,
  "layers": 5,
  "cellWidth": 1.2,
  "cellHeight": 0.8,
  "cellDepth": 1.0
}
```

### 2. 货位编号导入

- 确保每个货位有唯一编号
- 编号格式建议：层号-列号-排号
- 系统会自动检测高度遮挡的货位

### 3. 出入库记录

**必填字段：**
- SKU编号
- 货位编号
- 操作类型（入库/出库）
- 时间戳
- 操作人
- 来源文件名

## 功能说明

### 🎯 3D热图页面
- **货位热图**：按出入库频次/周转率/重量显示热度颜色
- **冲突标记**：红色=货位重复，橙色=高度遮挡，紫色=数据不匹配
- **货位标签**：鼠标悬停显示货位详情
- **导出截图**：点击右上角按钮导出高清截图

### 📋 版本管理
- **创建新版本**：保存当前热图配置，不覆盖旧版本
- **锁定版本**：重要版本可锁定，防止被误删或覆盖
- **版本切换**：点击"查看"按钮切换不同版本

### ⚠️ 冲突检测
- **货位重复**：同一货位被分配给多个SKU
- **高度遮挡**：前排货位遮挡后排，影响拣货效率
- **数据不匹配**：货架、货位、记录三方数据不一致
- **材料追溯**：点击冲突项可查看是哪份导入文件导致的问题

### 🎬 路径回放
- **动画播放**：按时间顺序播放出入库路径
- **节点标注**：每个节点显示商品、操作人、时间信息
- **播放控制**：暂停/播放、倍速（0.5x/1x/2x/4x）、跳转
- **时间轴**：拖动滑块快速跳转到任意节点

## 复现货位重复问题

**操作步骤：**

1. 进入【冲突检测】页面
2. 在"货位重复"区域找到冲突项
3. 点击冲突卡片展开详情
4. 查看"问题来源材料"，会显示具体是哪两份导入文件冲突
5. 根据来源文件名，回去检查原始Excel/CSV文件
6. 修正数据后重新导入

**示例：**
- 冲突：货位 L0-C0-R0
- 来源材料：1月入库单.xlsx、1月出库单.xlsx
- 说明：两份文件对同一货位分配了不同SKU

## 导出截图用于演示

1. 调整3D视角到合适角度
2. 打开【冲突标记】显示问题货位
3. 点击【导出截图】按钮
4. 在会议/上课时标注说明：
   - 红色区域 = 货位重复冲突
   - 橙色区域 = 高度遮挡问题
   - 黄色虚线框 = 被遮挡货位

## 常见问题

**Q: 热图颜色怎么看？**
A: 黄色→橙色→红色，热度从低到高

**Q: 被遮挡的货位怎么识别？**
A: 虚线边框 + 半透明显示，悬停会显示"高度遮挡"提醒

**Q: 如何防止版本被覆盖？**
A: 在版本管理中点击锁定按钮，锁定后无法删除或覆盖

**Q: 导出的截图清晰吗？**
A: 默认2倍分辨率导出，适合PPT演示或打印
