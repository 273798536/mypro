# 评测分数置信区间系统

## 从空目录启动的完整步骤

### 1. 环境要求

- Node.js >= 18
- npm >= 9 或 pnpm >= 8

### 2. 依赖安装

```bash
cd /path/to/y12915
npm install
```

### 3. 启动命令

```bash
# 开发模式（推荐，带热更新）
npm run dev
# 访问地址：http://localhost:5173

# 生产构建
npm run build
npm run preview
```

### 4. 第一份样例位置

样例数据均为内置（固定随机种子=42，可复现），位于：

- 模型版本样例：`src/data/mockVersions.ts`（4个版本，v2.3.1为当前最新）
- 评测样本样例：`src/data/mockSamples.ts`（500条确定性样本，含原始行号1-500）
- 安全规则样例：`src/data/mockSafetyRules.ts`（8条规则，其中 rule_002 和 rule_005 演示不一致）
- 修正日志样例：`src/data/mockCorrectionLogs.ts`（50条历史记录）

打开系统后首页即为总览仪表盘，直接加载 v2.3.1 的全部样例数据。

### 5. 功能使用流程（数据标注负责人视角）

1. 打开首页 → 从顶部版本条选择模型版本
2. 检查右上角安全规则灯组 → 如有不一致（红点闪烁），点击进入「安全规则校验」
3. 进入「置信区间分析」 → 切到「人工修正前后对比」Tab 看收窄效果
4. 进入「人工修正工作台」 → 按行号/图片名搜索，逐项修正
5. 进入「分布统计」 → 点击结论旁的「📎来源」确认原始材料
6. 进入「导出中心」 → 运行预检 → 全部通过后导出

### 6. 训练组如何一眼区分可用等级

打开系统 → 首页 2x2 卡片矩阵：

- ✅ **翡翠绿卡片（左上）**：高分高置信 → 直接可用数据
- ⚠️ **琥珀橙卡片（右上）**：高分低置信 → 需找标注负责人复核（点卡片直接跳转修正页）
- ❌ **玫红卡片（左下）**：低分高置信 → 不合格数据
- 🔄 **石板灰卡片（右下）**：低分低置信 → 需补测数据

### 7. 追溯信息说明

每条样本均保留：原始行号（连续编号1-500）、源CSV文件名、图片名+图片预览链接、来源备注、历次修正记录。点击任意行的「🔍」按钮或「📎来源」按钮可查看完整追溯信息。

### 8. 常见问题

- **Q**: 如何重新生成不同种子的样例？
  **A**: 编辑 `src/data/mockSamples.ts` 中 `generateMockSamples(42)` 的种子数。

- **Q**: 人工修正后数据保存在哪里？
  **A**: 浏览器 LocalStorage，key 为 `confidence_app_samples` 和 `confidence_app_logs`。

- **Q**: 导出PDF/Excel在哪里下载？
  **A**: 浏览器默认下载目录，文件名格式：`评测报告_{版本号}_{时间戳}.pdf/.xlsx`
