# 天文双星轨道模拟器

一个用于模拟双星系统轨道运动的Python工具，支持实时参数调节、能量监控、轨道稳定性分析。

## 功能特性

- **数值积分**：支持多种积分方法（欧拉法、RK4、Verlet）
- **能量监控**：实时监测系统总能量，检测能量漂移
- **碰撞检测**：自动检测星体碰撞事件
- **轨道动画**：生成动态轨道可视化
- **参数预设**：内置多种天文场景预设
- **异常报告**：清晰标注时间步过大、能量漂移、碰撞等异常
- **结果导出**：支持导出动画和分析报告

## 快速开始

```bash
pip install -r requirements.txt
python -m binary_sim.cli --preset sun_earth
```

## 使用说明

### 命令行参数

```
python -m binary_sim.cli [options]
```

主要参数：
- `--m1`：星体1质量（太阳质量单位）
- `--m2`：星体2质量（太阳质量单位）
- `--distance`：初始距离（天文单位AU）
- `--v1`：星体1初始速度（AU/年）
- `--v2`：星体2初始速度（AU/年）
- `--dt`：时间步长（年）
- `--steps`：模拟步数
- `--method`：积分方法（euler/rk4/verlet）
- `--preset`：使用预设场景
- `--animate`：显示动画
- `--export`：导出动画到文件
- `--report`：生成分析报告
