## 1. 产品概述

海岛港口补给棋是一款浏览器内运行的策略棋盘游戏，面向物流培训场景，模拟海岛港口的船舶调度与资源补给。玩家需在潮汐变化、码头冲突、燃油限制等约束下完成多回合的航线规划与货物调度，每一步选择都真实影响局面走向。核心解决的问题是：让培训对象在可回溯、可复盘的沙盘中体验真实调度压力，而非"点击得分"的空壳游戏。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 调度员（玩家） | 直接开始游戏 | 执行回合调度、资源锁定、航线规划 |
| 观察员 | 通过分享链接进入 | 查看复盘、导出调度报告 |

### 2.2 功能模块

1. **棋盘主页**：海域地图、岛屿港口、船舶位置、潮汐指示器
2. **调度操作页**：回合调度面板、船舶卡选择、码头格分配、资源锁定确认
3. **冲突裁决页**：船舶卡与码头格合并冲突展示、潮汐缺失告警、燃油不足追溯
4. **结算复盘页**：航线回放动画、扣分明细、回合决策回溯
5. **调度报告页**：报告生成、资源锁定口径说明、一键分享

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 调度报告页 | 一键分享 | 生成可复制的报告文本或导出JSON，发送给相关同事 |

## 3. 核心流程

玩家进入游戏→查看海域地图与潮汐表→每回合开始：选择船舶与目标港口→系统检查潮汐窗口与码头冲突→展示船舶卡与码头格合并冲突（如有）→玩家裁决冲突或调整方案→确认资源锁定（燃油、泊位、货物）→执行调度→系统结算本回合→潮汐周期推进→下一回合→游戏结束→结算复盘→生成调度报告→分享给同事。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0A1628) + 潮汐青 (#00D4AA) + 告警琥珀 (#FF8C00)
- **辅助色**：码头灰 (#4A5568)、燃油红 (#E53E3E)、锁定金 (#D69E2E)
- **按钮风格**：圆角微3D，主按钮带潮汐流动光泽动画，危险操作按钮带脉冲告警
- **字体**：标题用 Noto Serif SC（庄重航海感），正文用 Noto Sans SC，数据用 JetBrains Mono
- **布局风格**：左侧地图为主舞台，右侧为操作面板（船舶卡/调度面板），底部为回合信息栏
- **图标风格**：线性航海图标（锚、罗盘、波浪），来自 lucide-react

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 棋盘主页 | 海域地图 | 深色海图风格背景，岛屿节点带微光晕，航道虚线带流动动画，潮汐水位用波浪填充高度表示 |
| 棋盘主页 | 船舶卡面板 | 可拖拽卡片，正面显示船名/载货/燃油/航速，翻转显示详细能力与锁定状态 |
| 棋盘主页 | 回合信息栏 | 底部固定栏，回合数+潮汐周期可视化时间轴，暂停/继续/重开按钮 |
| 棋盘主页 | 潮汐表组件 | 侧边抽屉，每港口一行，时间轴标注涨潮/退潮/危险时段，缺失数据用红色虚线+闪烁标记 |
| 调度操作页 | 回合调度面板 | 右侧面板，三步式引导（选船→选港→确认），每步带前置条件校验 |
| 调度操作页 | 资源锁定区 | 锁定项用金色边框+锁链图标，已锁定变暗不可操作，显示锁定原因与解锁条件 |
| 冲突裁决页 | 冲突列表 | 左右对照卡片布局，左侧船舶卡数据、右侧码头格数据，冲突字段高亮差异 |
| 冲突裁决页 | 潮汐缺失告警 | 顶部告警横幅，缺失港口名+影响回合范围，点击跳转到潮汐表补充入口 |
| 冲突裁决页 | 燃油不足追溯 | 链条式追溯卡片，从当前不足→逐回合消耗→超标航线，每步可点击查看详情 |
| 结算复盘页 | 航线回放 | 地图模式回放，船舶轨迹用虚线动画，关键决策点可暂停查看当时状态 |
| 结算复盘页 | 扣分明细 | 表格+图表混合，每项扣分可展开查看关联的调度记录与潮汐窗口 |
| 调度报告页 | 报告预览 | 分栏布局，左侧报告内容，右侧资源锁定口径说明，底部分享按钮 |

### 4.3 响应式

- 桌面优先设计（1920×1080 最佳体验）
- 1366×768 兼容：操作面板可折叠为侧边抽屉
- 平板横屏（1024×768）：地图缩小，面板改为底部标签页
- 触控优化：船舶卡拖拽、码头格点击、按钮尺寸≥44px

### 4.4 3D场景指引

不适用，本游戏采用2D海图风格渲染。
