## 1. 产品概述

联邦客户端成本看板是面向推荐算法团队的成本核算与追溯平台，解决当前依赖训练日志手工核对效率低、参数变化追溯难、历史判断易丢失的问题。

- 目标用户：推荐算法工程师（小许）、排班审核同事
- 核心价值：将成本计算公式透明化、历史变更可追溯、异常情况可操作、审核放行有指引

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 算法工程师 | 内部账号 | 查看成本详情、追溯历史、补充备注、导出数据 |
| 排班审核员 | 内部账号 | 对比两次看板结果、查看人工判断历史、审核放行 |

### 2.2 功能模块

1. **成本看板主页**：公式可视化、单位标注、边界值提示、实时成本计算
2. **历史时间线**：版本追溯、备注留存、截图归档、变更对比
3. **异常处理中心**：灰度比例异常检测、可操作处理指引、状态跟踪
4. **双版本对比**：两次快照对比、差异高亮、人工判断留存
5. **导出中心**：历史时间线导出、页内状态与文件一致性保障
6. **审核放行指引**：材料补全提示、放行条件判定、操作清单

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

### 3.1 算法工程师日常查看流程

```mermaid
flowchart LR
    A["打开成本看板"] --> B["查看公式与参数"]
    B --> C["检查边界值是否正常"]
    C --> D{"发现异常？"}
    D -->|是| E["进入异常处理中心"]
    D -->|否| F["查看历史时间线"]
    E --> G["按指引处理异常"]
    G --> H["补充备注与截图"]
    H --> F
    F --> I["追溯参数变更历史"]
    I --> J["导出时间线报告"]
```

### 3.2 排班审核对比流程

```mermaid
flowchart LR
    A["进入双版本对比"] --> B["选择两次看板快照"]
    B --> C["查看差异高亮"]
    C --> D["查看历史人工判断"]
    D --> E["判断新版本是否需要补充"]
    E --> F["进入审核放行页"]
    F --> G["查看材料清单"]
    G --> H{"材料齐全？"}
    H -->|否| I["标记需补充材料"]
    H -->|是| J["标记可放行"]
    I --> K["生成待办清单给小许"]
    J --> L["完成审核"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：工业蓝 `#1E3A5F` 作为主色，配合琥珀警告色 `#F59E0B`、危险红 `#EF4444`、成功绿 `#10B981`
- **背景**：深色主题 `#0F172A`，搭配渐变网格纹理，营造数据看板的专业感
- **字体**：标题使用 `Space Mono` 等宽字体突出数据感，正文使用 `Inter` 保障可读性
- **卡片风格**：细边框 + 半透明背景 + 微妙内发光，营造科技感
- **图标风格**：线性图标，统一 2px 描边，状态变化时带颜色过渡动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 成本看板主页 | 公式透明区 | 可折叠公式树，hover 显示参数详情，单位用角标标注 |
| 成本看板主页 | 边界值监控 | 进度条式展示，超出阈值部分用红色渐变填充 |
| 成本看板主页 | 成本概览卡 | 大字号数字 + 单位标注 + 环比趋势箭头 |
| 历史时间线页 | 时间轴组件 | 垂直时间轴，节点用不同颜色标识状态，带滑入动画 |
| 历史时间线页 | 版本详情卡 | 标签页切换：参数、备注、截图、人工判断 |
| 异常处理页 | 操作指引卡 | 步骤编号 + 操作按钮 + 完成勾选框 |
| 双版本对比页 | 差异高亮面板 | 左右分栏，差异行背景闪烁提示 |
| 审核放行页 | 材料清单 | 待办项用红色标记，完成项带绿色勾选 |

### 4.3 响应式

- 桌面端优先设计，主内容区最小宽度 1280px
- 平板端支持双栏布局，侧边栏可折叠
- 移动端简化为单页滚动，关键指标卡片置顶

### 4.4 动效设计

- 页面加载：卡片从下往上错落淡入，间隔 80ms
- 数据更新：数字滚动动画，持续 600ms，缓动函数 easeOutCubic
- 异常出现：边框呼吸动画（透明度 0.5-1 循环）
- 时间轴滚动：节点进入视口时从左滑入
- 按钮交互：hover 时背景色过渡 + 轻微上浮 2px
