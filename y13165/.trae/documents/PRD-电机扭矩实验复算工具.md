## 1. 产品概述

电机扭矩实验复算工具，面向设备检测工程师与项目助理，解决设备铭牌数据分批录入、单位混写导致数量级混乱、复算结果无法溯源到原始铭牌等痛点。工具提供单位智能换算、数据分批合并不覆盖、异常高亮与溯源、图表明细同口径、一键导出等核心能力，让项目助理小宋只需三步：看样例、找异常、导结果。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心需求 |
|------|----------|----------|
| 项目助理（小宋） | 浏览器打开即用 | 快速上手、看样例、找异常、导出结果 |
| 检测工程师 | 上传铭牌数据复算 | 单位准确、数据可追溯、异常不被覆盖 |

### 2.2 功能模块

1. **数据导入页**：Excel/CSV 上传、分批录入、历史版本列表、样例数据一键加载
2. **单位换算引擎**：自动识别扭矩单位（N·m / Nm / 牛米 / kgf·m / lbf·ft 等）、统一基准、数量级校验
3. **复算明细页**：逐条记录复算结果、原始铭牌行关联、异常高亮、安全阈值追溯
4. **图表可视化**：扭矩曲线柱状图、与明细数据同口径联动、点击定位原始行
5. **结果导出**：Excel 导出（含原始数据 + 复算结果 + 异常标注）、溯源信息保留

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 上传区 | 拖拽上传 Excel/CSV，支持分批追加，显示当前批次与累计数据量 |
| 数据导入页 | 历史版本 | 展示每次录入的时间、来源文件、新增条数，支持切换查看 |
| 数据导入页 | 样例加载 | 一键加载样例数据，供新手快速体验 |
| 复算明细页 | 数据表格 | 展示设备编号、铭牌原始值、原始单位、换算后值、复算结果、状态 |
| 复算明细页 | 单位换算 | 自动识别单位并换算到基准单位 N·m，标注换算系数 |
| 复算明细页 | 异常高亮 | 数量级异常、超阈值、缺失字段等用不同颜色标记，hover 显示原因 |
| 复算明细页 | 溯源面板 | 点击任一行展开原始铭牌行信息（文件名、行号、原始内容） |
| 图表页 | 扭矩柱状图 | 按设备排列的扭矩值柱状图，异常柱体用红色高亮，点击联动明细 |
| 图表页 | 阈值线 | 安全阈值用虚线标注，hover 显示阈值来源（铭牌哪条描述） |
| 导出功能 | 导出按钮 | 导出 Excel，含原始数据 sheet + 复算结果 sheet + 异常清单 sheet |

## 3. 核心流程

```mermaid
flowchart LR
    A["上传设备铭牌数据<br/>（Excel/CSV）"] --> B["单位智能识别与换算"]
    B --> C["电机扭矩复算计算"]
    C --> D["异常检测与高亮"]
    D --> E["明细 + 图表联动展示"]
    E --> F["点击溯源查看原始铭牌行"]
    E --> G["一键导出复算报告"]
```

用户典型路径：
1. 项目小宋打开工具 → 点击「加载样例」快速了解效果
2. 上传第一批评审数据 → 查看复算结果和异常 → 导出初版报告
3. 后补铭牌数据到了 → 追加上传 → 系统合并不覆盖 → 查看新增异常
4. 遇到异常 → 点击行 → 展开溯源面板 → 看到原始铭牌文件名、行号、原始内容
5. 确认无误 → 导出最终报告

## 4. 用户界面设计

### 4.1 设计风格
- **主色**：工业蓝 #1e3a8a（专业、可靠），辅以警示橙 #f97316（异常高亮）、安全绿 #10b981（正常）
- **字体**：标题用 "JetBrains Mono"（等宽、工程师感），正文用 "Noto Sans SC"（清晰易读）
- **布局**：左侧导航 + 右侧内容区，卡片式布局，数据表格占主体
- **图标**：线性图标，简洁工业风
- **整体调性**：工程师工具感，精准、克制、信息密度高但不杂乱

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 上传卡片 | 大虚线框上传区、拖拽高亮、文件列表、批次标签 |
| 数据导入页 | 样例入口 | 右上角「加载样例」按钮，配小型数据图标 |
| 复算明细页 | 顶部概览 | 统计卡片：总记录数、正常数、异常数、待确认数 |
| 复算明细页 | 数据表格 | 斑马纹、异常行橙红底、状态标签、可展开行 |
| 复算明细页 | 溯源抽屉 | 右侧滑出面板，展示原始数据快照 |
| 图表页 | 柱状图 | 蓝色柱体、异常橙色、阈值红色虚线、hover 详情 |
| 全局 | 顶部导航 | 左侧 logo + 页面标题，右侧导出按钮 + 用户信息 |

### 4.3 响应式
- 桌面端优先，保证数据表格信息密度
- 平板端适配：图表自适应宽度，表格可横向滚动
- 不做移动端深度优化（工具场景为桌面办公）

### 4.4 新手引导
- 首次访问自动弹出三步引导卡：「① 加载样例 → ② 查看异常 → ③ 导出结果」
- 关键按钮配 tooltip 简要说明
- 异常行 hover 显示「点击查看原始铭牌」提示
