## 1. 产品概述

实验课安全闯关是一款面向材料工程师的实验安全管理看板工具，核心解决实验数据中谱峰重叠等坏记录的快速识别、从结果到来源的全链路溯源、以及导出内容与界面摘要的一致性问题。目标用户为高校/科研课题组材料工程师，日常从浓度换算入口进入，月底或课前通过配平计算复核，谱图复核环节将谱图数据、安全备注与谱峰重叠纳入同一轮审查。

- 主旨：让材料工程师一眼拎出坏记录，一条链倒查到源头，一次导出前后一致
- 价值：减少实验安全事故隐患，提升课题组数据复核效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 材料工程师 | 直接使用 | 数据录入、复核、导出、溯源 |
| 课题组长 | 审核确认 | 复核确认、导出审批 |

### 2.2 功能模块

1. **看板首页**：温度曲线概览、安全状态统计、谱峰重叠告警列表、称量精度不足提示
2. **浓度换算**：日常入口，摩尔浓度/质量浓度/百分比浓度互转，附带安全上下文提示
3. **配平计算**：化学方程式配平与逐步解释，月底/课前复核用
4. **谱图复核**：谱峰重叠检测、谱图数据展示、安全备注，三者同轮复核
5. **记录溯源**：从任意结果记录倒查来源数据与处理记录链

## 3. 核心流程

材料工程师日常使用流程：从浓度换算入口进入系统 → 查看看板温度曲线和安全状态 → 发现谱峰重叠告警 → 进入谱图复核（谱图+安全备注+重叠检测同轮确认）→ 标记坏记录 → 通过记录溯源倒查来源 → 导出结果（界面摘要与文件内容一致）。

月底/课前流程：打开配平计算 → 验证方程配平解释是否清晰 → 回到看板确认所有记录状态 → 导出整月复核报告。

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深青色 `#0F766E`（teal-700），辅色：琥珀色 `#D97706`（amber-600）用于告警
- 按钮风格：圆角微凸（rounded-lg + shadow-sm），危险操作用红色实心
- 字体：标题用 `Outfit`（几何感、工业风），正文用 `Source Sans 3`
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块
- 图标风格：线条型（lucide-react），统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 看板首页 | 温度曲线卡片 | 折线图、异常区间红色底色、hover 显示数值 |
| 看板首页 | 安全状态统计 | 三个计数卡片（通过/待确认/不通过），颜色区分 |
| 看板首页 | 谱峰重叠告警列表 | 表格行，琥珀色左边框，点击跳转按钮 |
| 浓度换算 | 换算计算器 | 输入框+下拉选择单位，实时计算结果 |
| 浓度换算 | 安全上下文 | 卡片式，显示物质名称和安全等级标签 |
| 配平计算 | 方程配平器 | 输入框+配平按钮，结果用彩色系数标注 |
| 配平计算 | 配平解释 | 步骤列表，每步带守恒验证勾选 |
| 谱图复核 | 谱图数据展示 | SVG 折线图，峰值圆点标注，可缩放 |
| 谱图复核 | 谱峰重叠检测 | 高亮重叠区域，旁边标记"坏记录"按钮 |
| 谱图复核 | 安全备注栏 | 文本框+历史备注列表 |
| 记录溯源 | 溯源链路 | 纵向时间线，每节点显示数据快照 |
| 记录溯源 | 处理记录 | 卡片列表，显示操作人、时间、变更内容 |

### 4.3 响应式设计

桌面优先设计，导航栏在窄屏收起为底部标签栏，图表区域自适应宽度。

不适用。
