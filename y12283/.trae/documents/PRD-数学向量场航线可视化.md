## 1. 产品概述

数学向量场航线可视化工具，专为大学助教设计，用于检测和展示采样爆炸问题，避免临时表格硬凑的低效工作方式。

- 核心用途：可视化3D向量场流线，高亮标记采样爆炸区域，保留历史修改痕迹
- 目标用户：大学助教、数学课程评审人员
- 核心价值：通过可视化直观呈现采样爆炸问题，提供可追溯的数据审计能力

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 助教/评审 | 无需注册，本地使用 | 导入向量场公式、添加种子点、导出截图、查看历史记录 |

### 2.2 功能模块
1. **主可视化面板**：3D向量场流线渲染、采样爆炸标记、数据缺口提示
2. **种子点管理**：种子点列表、新增/编辑/删除、历史版本对比
3. **历史记录**：修改时间线、字段缺失标记、晚补记录、备注修改痕迹
4. **导出详情**：向量场公式、种子点参数、截图对应关系导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主可视化页面 | 3D渲染区 | Three.js渲染向量场流线，红色高亮采样爆炸区域 |
| 主可视化页面 | 数据缺口提示 | 3D画面旁明确标注数据缺口，不做虚假渲染 |
| 种子点管理面板 | 种子点列表 | 展示种子点坐标、参数、状态标记（缺字段/晚补/已修改） |
| 历史记录面板 | 时间线视图 | 按时间展示所有修改，保留前后差别痕迹 |
| 导出详情面板 | 对应关系表 | 向量场公式、种子点、截图的一一对应关系 |

## 3. 核心流程

用户导入向量场公式 → 添加种子点生成流线 → 系统检测采样爆炸并标记 → 用户可修改种子点重跑 → 系统自动记录历史差异 → 导出带对应关系的详情报告

```mermaid
flowchart LR
    A["导入向量场公式"] --> B["添加种子点"]
    B --> C["生成3D流线"]
    C --> D["检测采样爆炸"]
    D --> E["标记异常区域"]
    E --> F["用户修改种子点"]
    F --> G["记录历史差异"]
    G --> H["导出详情报告"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深空蓝(#0a1628)配科技青(#00d4ff)，营造科研专业感
- 异常标记：采样爆炸用警示红(#ff3366)高亮，数据缺口用橙黄(#ffaa00)
- 字体：JetBrains Mono（代码感）+ Noto Sans SC（中文可读性）
- 布局：左侧控制面板 + 右侧3D主视图 + 底部历史时间线
- 风格：科技感、数据驱动、专业严谨，适合学术评审场景

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主可视化页面 | 3D渲染区 | WebGL画布、悬浮数据标签、颜色图例、旋转控制 |
| 主可视化页面 | 数据缺口提示 | 橙色边框提示框、半透明遮罩、文字说明 |
| 种子点管理面板 | 种子点卡片 | 坐标显示、状态徽章（缺字段/晚补/已修改）、操作按钮 |
| 历史记录面板 | 时间线节点 | 时间戳、修改类型图标、前后对比预览 |
| 导出详情面板 | 对应关系表 | 公式预览、种子点参数、截图缩略图、导出按钮 |

### 4.3 响应式
- 桌面端优先，1440px及以上为最佳体验
- 平板端折叠侧边栏为抽屉模式
- 移动端简化为单视图滚动布局

### 4.4 3D场景指引
- 环境：深空背景，细微网格地面，营造数学空间感
- 光照：主光源+环境光，确保流线清晰可见，采样爆炸区域有发光效果
- 相机：默认透视视角，支持轨道控制、缩放、平移
- 动画：流线渐进式加载，采样爆炸检测到时脉冲闪烁效果
- 后处理：轻微辉光效果增强科技感，不影响数据可读性
