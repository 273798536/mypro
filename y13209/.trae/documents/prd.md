## 1. 产品概述

"录音棚时码分账对齐"是一个面向录音棚前台和复核人的轻量级小工具，用于将时码分账、授权到期、排练群截图备注、人工批注等信息统一对齐到一张面板上，确保筛选条件、备注和页面摘要刷新后不丢失、历史版本可追溯、导出与页面一致、复核人能独立跑完全流程。

- 解决授权到期藏在备注或截图后面、刷新后筛选/备注/摘要各走各的、历史只保留最终值、导出与页面不一致、复核人找不到材料等问题
- 目标用户：琴房前台（如小温）、评审复核人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 前台操作员 | 直接打开工具使用 | 录入时码、添加备注、触发扫描、导出摘要 |
| 复核人 | 直接打开工具使用 | 查看历史、跑复核流程、导出交付清单 |

### 2.2 功能模块

1. **时码分账对齐面板**：主操作界面，展示时码条目、授权到期状态、分账比例、备注与截图附件
2. **授权到期卡**：独立醒目卡片，不藏在备注里，到期/临期自动高亮，需要人工确认时显示原因与下一步
3. **筛选与摘要栏**：筛选条件 + 页面摘要，刷新后持久化，三者始终同步
4. **历史版本面板**：每次备注变更、截图补充都留历史快照，旧版本和人工批注可追溯
5. **导出功能**：导出页面摘要为文件，导出内容与页面当前状态完全一致
6. **交付清单与复核流程**：一键生成交付清单，复核人可独立跑完全流程，不需要追问材料位置

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 对齐面板页 | 时码条目列表 | 展示所有时码条目，含项目名、时段、分账比例、授权状态 |
| 对齐面板页 | 授权到期卡 | 独立醒目区域，显示授权起止日期、到期倒计时、需要人工确认时展示原因和下一步操作 |
| 对齐面板页 | 筛选与摘要栏 | 筛选条件（日期、项目、状态）+ 当前筛选下的摘要统计，刷新后状态保持 |
| 对齐面板页 | 备注与截图区 | 排练群截图上传、人工备注输入，每次变更自动存历史快照 |
| 对齐面板页 | 历史版本抽屉 | 点击打开历史记录，查看旧版本截图、旧备注、人工批注，时间线展示 |
| 对齐面板页 | 导出与交付栏 | 导出页面摘要按钮、生成交付清单按钮、复核状态指示 |

## 3. 核心流程

**主流程**：前台打开工具 → 查看/录入时码条目 → 授权到期卡检查到期状态 → 如需人工确认则显示原因与下一步 → 添加排练群截图或授权备注 → 触发"重扫描" → 历史版本自动记录 → 确认对齐后导出摘要 → 复核人自行打开工具跑复核流程

**复核流程**：复核人打开工具 → 查看交付清单 → 逐一核对时码/授权/备注/截图历史 → 如有问题标记待确认 → 全部通过则标记复核完成

```mermaid
    K --> L["复核人自行跑复核流程"]
    L --> M{"复核是否通过"}
    M -->|"否"| N["标记待确认"]
    M -->|"是"| O["标记复核完成"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰底(#1a1a2e) + 琥珀色强调(#f59e0b)，传达专业录音棚氛围
- 辅助色：冷灰(#374151)用于卡片、暗红(#ef4444)用于到期警告、翠绿(#10b981)用于对齐通过
- 按钮风格：圆角(8px)、微妙阴影、hover 时颜色加深
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，等宽数字用 JetBrains Mono
- 布局：桌面端左右分栏，左侧为时码条目列表 + 筛选，右侧为授权到期卡 + 备注 + 历史
- 图标：使用 lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 对齐面板页 | 时码条目列表 | 表格样式，行hover高亮，授权状态用彩色标签 |
| 对齐面板页 | 授权到期卡 | 独立卡片，红色边框临期/到期警告，内含倒计时数字 |
| 对齐面板页 | 筛选与摘要栏 | 顶部固定栏，下拉筛选 + 摘要统计数字 |
| 对齐面板页 | 备注与截图区 | 卡片内textarea + 图片缩略图列表 |
| 对齐面板页 | 历史版本抽屉 | 右侧滑出抽屉，时间线样式展示版本历史 |
| 对齐面板页 | 导出与交付栏 | 底部固定栏，操作按钮 + 复核状态徽章 |

### 4.3 响应式

- 桌面端优先（前台电脑和笔记本主要使用场景）
- 平板端：左右分栏变为上下排列
- 移动端：单列布局，抽屉变为全屏覆盖
