## 1. 产品概述

老街消防投诉回放——街道消防投诉的追溯复核工具，解决"领导问原因只能翻聊天"的痛点。面向街道办工作人员，将投诉记录、审批台账、材料口径变更、补录操作全部串成可回溯链路，让异常点一键溯源、口径变更有迹可查。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 街道办工作人员 | 内部系统登录 | 查看、复核、重跑、补录 |
| 领导 | 内部系统登录 | 查看回放、追问口径 |

### 2.2 功能模块

1. **回放主页**：投诉趋势图表 + 异常点标注 + 地图点位
2. **溯源详情页**：审批台账链路 + 材料口径变更记录 + 接口返回查看
3. **补录操作页**：照片补录 + 地图点位更新 + 变更说明

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 回放主页 | 投诉趋势图 | 按时间/区域展示投诉量折线图，异常点高亮标注，点击可跳转溯源 |
| 回放主页 | 地图点位 | 显示投诉地理分布，补录后点位变色并标注变更说明 |
| 回放主页 | 小样例列表 | 抽样展示投诉记录，重复投诉用醒目标签区分，处理结果不写成"正常通过" |
| 溯源详情页 | 审批台账 | 展示本次投诉关联的审批台账，含材料名称、来源、口径 |
| 溯源详情页 | 材料口径追踪 | 列出所有关联材料，标记哪份后来改过口径，显示变更前后对比 |
| 溯源详情页 | 接口返回 | 查看本次计算的接口返回原始数据，支持重跑 |
| 补录操作页 | 照片上传 | 上传现场照片，自动关联时间与地点 |
| 补录操作页 | 变更说明 | 补录后自动生成"本次补录改了什么"的说明，含地图点位差异与接口返回差异 |

## 3. 核心流程

工作人员打开回放主页，查看投诉趋势图表。发现异常点后点击，进入溯源详情页，查看审批台账和材料口径记录。若发现材料口径有变更，可对比前后差异。需要重新计算时点击重跑，查看接口返回。若需补充现场照片，进入补录操作页上传照片，系统自动更新地图点位并生成变更说明。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深炭灰 `#1a1a2e` + 消防警示橙 `#e94560` + 冷白 `#f5f5f0`
- 辅助色：口径变更蓝 `#0f3460`、补录成功绿 `#16c79a`、重复投诉黄 `#f5a623`
- 按钮：圆角矩形，主操作用消防橙填充，次操作用轮廓线
- 字体：标题用 Noto Serif SC（衬线庄重感），正文用 Noto Sans SC
- 布局：左侧导航 + 右侧内容区，卡片式模块
- 图标：线性图标，与数据治理场景适配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 回放主页 | 投诉趋势图 | 深色背景折线图，异常点用消防橙脉冲动画标注，hover显示摘要 |
| 回放主页 | 地图点位 | 深色底图，常规点冷白，补录变更点绿色脉冲，重复投诉点黄色 |
| 回放主页 | 小样例列表 | 卡片列表，重复投诉左边缘黄色竖条 + "重复"标签，处理结果用"已驳回/待复核"而非"正常通过" |
| 溯源详情页 | 审批台账 | 时间线布局，每份材料一张卡片，含来源、口径、时间戳 |
| 溯源详情页 | 材料口径追踪 | 卡片上方显示"口径已变更"蓝标签，展开可看变更前后diff |
| 溯源详情页 | 接口返回 | 代码块风格展示JSON，重跑按钮右上角，重跑后新旧对比 |
| 补录操作页 | 照片上传 | 拖拽区域 + 缩略图预览，上传后地图点位实时更新 |
| 补录操作页 | 变更说明 | 自动生成的文字说明，标注地图点位变化和接口返回差异 |

### 4.3 响应式

桌面优先设计，适配1280px以上大屏。平板端768px以上保持可用。移动端仅保留查看功能。

### 4.4 操作说明

应用内嵌简洁操作指引，仅覆盖三件事：
1. **放样例**：点击异常点查看关联样例
2. **重跑**：在溯源详情页点击重跑，对比新旧接口返回
3. **查看接口返回**：在溯源详情页展开接口返回面板查看原始数据
