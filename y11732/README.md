# 医保个人账户划拨 CLI

理清门诊报销和自费扣款流程的命令行工具。

## 功能特性

- **账户账本**：按患者、按月份生成详细账户收支明细
- **跨月归集**：自动识别跨月报销情况并标记
- **补划幂等**：检测重复补划申请，避免重复发放
- **差异解释**：自动计算账户余额差异并提示
- **导出单据**：多格式导出处理结果（Excel、TXT、JSON）
- **审计追踪**：保留所有修改记录和来源信息
- **版本隔离**：每次运行生成独立目录，不污染旧结果

## 安装

```bash
pip install -e .
```

或使用 poetry：

```bash
poetry install
```

## 快速开始

### 1. 准备数据

将以下文件放入输入目录（支持 CSV、Excel 格式）：

- `医保流水.csv` - 医保账户交易流水
- `门诊票据.csv` - 门诊收费票据
- `自费项目.csv` - 自费项目明细
- `账户余额.csv` - 账户余额表
- `补划申请.csv` - 补划申请表
- `解释单.csv` - 特殊情况说明

### 2. 运行处理

```bash
yibao process -i ./sample_data -o ./output
```

### 3. 查看历史运行

```bash
yibao list-runs -o ./output
```

### 4. 查看某次运行详情

```bash
yibao show -o ./output <run_id>
```

## 命令说明

### process 命令

处理医保数据，生成账户账本和分析报告。

```bash
yibao process --input <输入目录> --output <输出目录> [--quiet]
```

**选项：**
- `-i, --input`：输入数据目录（必需）
- `-o, --output`：输出结果目录（必需）
- `-q, --quiet`：安静模式，减少输出

### list-runs 命令

列出所有历史运行记录。

```bash
yibao list-runs --output <输出目录>
```

### show 命令

查看指定运行的详细报告。

```bash
yibao show --output <输出目录> <run_id>
```

## 输出目录结构

每次运行会在输出目录下创建独立的运行目录：

```
output/
└── run_abc123_20240315_143022/
    ├── summary.json              # 处理摘要（JSON格式）
    ├── summary.txt               # 处理摘要（文本格式）
    ├── ledgers/                  # 账户账本
    │   ├── 账户账本汇总.xlsx
    │   └── [身份证]_[期间].txt
    ├── warnings/                 # 警告信息
    │   ├── 全部警告.xlsx
    │   └── [类型].txt
    ├── records_by_status/        # 按状态分类的记录
    │   ├── needs_review.txt
    │   ├── cross_month.txt
    │   ├── duplicate.txt
    │   └── ...
    ├── transactions/             # 交易明细
    │   └── 交易明细.xlsx
    └── audit_trail/              # 审计追踪
        ├── 审计追踪.xlsx
        └── 审计追踪.txt
```

## 异常检测

工具会自动检测以下异常情况：

1. **跨月报销**：流水日期与票据日期不在同一月
2. **重复补划**：相同申请号或相同金额+原因的补划申请
3. **自费误扣**：已在医保报销的项目被标记为自费
4. **余额差异**：计算余额与实际余额不符
