## 1. 产品概述

沙丘风蚀体素演示系统是一个面向规划设计师和运维组的专业三维可视化与模拟分析平台。系统通过体素化技术展示沙丘风蚀过程，提供精确的参数测量、异常检测和结果导出功能，帮助用户理解风蚀机理并做出科学决策。

- **核心目标**：为规划设计师提供直观的风蚀模拟演示，为运维组提供可追溯的运行记录和异常报告
- **目标用户**：规划设计师（主要使用者）、运维组（报告审核者）、教师/工程师（演示讲解者）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 规划设计师 | 参数配置、模拟运行、结果分析 | 完整操作权限，可修改参数、导出结果 |
| 运维组 | 查看导出报告、异常审核 | 只读权限，查看运行记录和异常报告 |
| 教师/工程师 | 演示讲解、参数说明 | 可查看所有内容，添加解释备注 |

### 2.2 功能模块

1. **三维体素演示页面**：沙丘三维可视化、风蚀动态模拟、相机视角控制
2. **参数配置面板**：风蚀参数设置、测量记录管理、参数联动更新
3. **异常监控中心**：错误记录展示、异常分类处理、操作指导提示
4. **结果导出模块**：运行报告生成、多格式导出、历史版本管理

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：沙漠色系（琥珀色 #D97706、沙褐色 #C2956E、深棕 #78350F）
- **辅助色**：信息蓝 #3B82F6（正常状态）、警告橙 #F59E0B（需关注）、错误红 #EF4444（异常）
- **按钮风格**：圆角矩形（8px），带微妙阴影，悬停时有轻微上浮效果
- **字体**：标题使用 Source Serif 4（衬线体，体现专业感），正文使用 Noto Sans SC（清晰易读）
- **布局风格**：左侧导航 + 中央工作区 + 右侧信息面板的三栏布局
- **图标风格**：线性图标，2px 描边，与文字搭配使用

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 三维演示页 | 体素渲染区 | 深色背景（#1F2937），体素使用渐变色表示高度，支持鼠标旋转/缩放，右下角显示坐标轴辅助 |
| 三维演示页 | 相机控制面板 | 浮动面板，包含预设视角按钮（俯视、侧视、正视），当前位置坐标，视角丢失时显示黄色警告条 |
| 三维演示页 | 参数仪表盘 | 卡片式布局，每个参数一组，数值变化时有动画过渡，异常参数高亮显示 |
| 参数配置页 | 基础参数设置 | 表单布局，输入框带单位标签，参数间依赖关系用连线表示 |
| 参数配置页 | 测量记录管理 | 表格布局，支持行内编辑，补录按钮突出显示，删除需二次确认 |
| 参数配置页 | 参数联动面板 | 树形结构展示参数依赖，更新时节点闪烁提示 |
| 异常监控页 | 错误记录列表 | 时间线布局，每条记录包含：时间戳、异常类型、详细说明、处理建议、当前状态 |
| 异常监控页 | 异常详情面板 | 右侧抽屉式面板，展示异常的完整上下文、相关参数、历史同类异常 |
| 异常监控页 | 操作指导区 | 底部固定区域，根据当前选中异常动态显示操作步骤，使用编号列表 |
| 结果导出页 | 报告生成器 | 预览+配置双栏布局，左侧实时预览，右侧选择导出内容和格式 |
| 结果导出页 | 历史版本管理 | 卡片列表，每张卡片显示运行时间、参数摘要、异常数量，支持点击查看详情 |

### 4.3 响应式设计

- **桌面优先**：主要针对 1920x1080 及以上分辨率优化
- **移动端适配**：平板设备（768px-1024px）采用折叠式侧边栏，手机端（<768px）采用单栏布局
- **触摸优化**：三维视图支持手势操作（捏合缩放、双指旋转），按钮和输入框增大点击区域

### 4.4 三维场景指导

- **环境氛围**：沙漠黄昏场景，使用暖色调 HDRI 环境贴图，营造真实沙漠氛围
- **光照设置**：主光源模拟夕阳（方向光，橙黄色），辅助光填充阴影区域（环境光，淡蓝色）
- **相机设置**：默认透视相机，FOV 60°，支持正交相机切换；提供 6 个预设视角（前后左右上下）
- **构图焦点**：沙丘主体居中，周围留白展示风蚀效果扩散
- **交互动画**：体素高度变化使用缓动动画（ease-out），风蚀粒子效果随风向流动
- **后处理效果**：轻微泛光（Bloom）增强体素边缘，景深效果聚焦主体
- **性能预算**：体素数量上限 100,000，帧率目标 30fps（复杂场景）/ 60fps（简单场景）

## 5. 异常处理与用户引导设计

### 5.1 异常分类与处理建议

| 异常类型 | 显示样式 | 处理建议 |
|----------|----------|----------|
| 参数缺失 | 黄色提示条 | "请补录 [参数名] 数据，可在参数配置页 > 测量记录管理中添加" |
| 参数超限 | 橙色警告框 | "当前 [参数名] 值超出建议范围，建议调整至 [建议值]" |
| 相机视角丢失 | 红色警告条 + 恢复按钮 | "相机视角已丢失，点击'恢复默认视角'或从预设视角中选择" |
| 计算错误 | 红色错误面板 + 详情展开 | "计算过程中发生错误：[错误详情]。建议检查参数配置后重试" |
| 导出失败 | 红色提示 + 重试按钮 | "报告导出失败，请检查网络连接后重试" |

### 5.2 错误记录展示规范

每条错误记录必须包含以下信息：
1. **时间戳**：精确到秒的记录时间
2. **异常类型**：分类标签（参数/视角/计算/系统）
3. **详细说明**：用自然语言描述发生了什么
4. **影响范围**：说明此异常会影响哪些功能或结果
5. **处理建议**：明确的下一步操作指引
6. **当前状态**：待处理/处理中/已解决

### 5.3 图表与三维视图解释规范

- **图表旁边**：必须有 1-2 句话解释图表含义和数据来源
- **三维视图旁边**：显示当前视角参数、渲染统计（体素数、帧率）、操作提示
- **异常高亮**：不仅使用颜色区分，还需配合图标和文字说明

### 5.4 导出报告内容规范

导出报告必须能让运维组独立理解：
1. **运行摘要**：本次运行的基本信息（时间、参数、结果）
2. **异常汇总**：列出所有异常及其处理结果
3. **拦截原因**：如有拦截，明确说明原因和依据
4. **参数详情**：完整的参数配置记录
5. **三维截图**：关键帧截图，附带视角参数
6. **操作日志**：用户操作的时间线记录
