# 处理过程版本归档说明

> 每份报告的每个历史版本（R-v0.1, R-v0.2, ... R-v1.0）的完整 Markdown 文件都存放在本目录下。
>
> **命名规则**: `{报告编号}_R-v{版本号}_{日期缩写}.md`
>
> 例如: `ERR-20260614-003_R-v0.2_0614a.md`

---

## 必须保留的版本（不许删）

| 版本节点 | 说明 | 是否必须 |
|:---|:---|:---:|
| R-v0.1 | 初稿（第一次算出任何数字的版本，哪怕错很多） | ✅ 必须 |
| R-v0._ | 每次修改极端值判定后 | ✅ 如有修改必须 |
| R-v0._ | 每次补采样缺口后 | ✅ 如有修改必须 |
| R-v0._ | 参数/公式版本切换前后各一版 | ✅ 必须 |
| R-v1.0 | 定稿（复核通过版） | ✅ 必须 |

## 版本对比快速操作（给复核人）

想看某个报告从初稿到定稿改了什么，在终端执行：

```bash
cd 风洞烟线误差归因/02历史版本/处理过程/
diff ERR-XXXXXXX_R-v0.1_*.md ERR-XXXXXXX_R-v1.0_*.md
```

或者用 VS Code 打开两个文件，右键 → Select for Compare → Compare with Selected。
