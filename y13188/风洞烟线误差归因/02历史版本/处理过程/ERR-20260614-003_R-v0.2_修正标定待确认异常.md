## 第3页 · 计算过程（v0.2 已修正标定）

### 3.1 标定误差（已修正 ✅）

**正确公式**：
$$\varepsilon_\text{标定} = \frac{\sigma_{\text{标尺}}}{L_{\text{标尺}}} \times 100\%$$

$$\varepsilon_\text{标定} = \frac{3.8\text{mm}}{1000\text{mm}} \times 100\% = \textbf{0.38\%}$$

> 参考：A0手册§2.1，边界值1.0%。正常。

### 3.2 扩散误差

$$d_0 = 0.08\text{mm}, \quad D = 5.0\times10^{-6}\text{m}^2\text{/s}, \quad t = 0.15\text{s}$$
$$d_{理论} = d_0 + 2\sqrt{Dt} = 0.08 + 1.73 = 1.81\text{mm}$$
$$\varepsilon_{扩散} = \frac{|1.76 - 1.81|}{1.81} \times 100\% ≈ 2.9\% \quad (\text{单点})$$

> 取各测点包络最大值约7.2%作为保守估计。

### 3.3 风速脉动

$$\sigma_U = 0.1796\text{ m/s}, \quad \overline{U} = 12.47\text{ m/s}$$
$$\varepsilon_{风速} = \frac{0.1796}{12.47} \times 100\% = \textbf{1.44\%}$$

### 3.4 误差传播（简化版）

$$\varepsilon_总 ≈ \sqrt{0.38^2 + 7.2^2 + 1.44^2 + \text{边界层项}} ≈ \sqrt{53.7} ≈ 7.3\%$$

> 加上EV-001拉上去的部分约3个百分点 → 总共约10.3%（含EV-001）。
