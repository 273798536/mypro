# 现场照片归档规则

> **核心原则**: 照片是第一手证据。原始照片不许改、不许覆盖、不许删；补备注和旧版本截图分开存，所有人都能看到「当时是怎么说的」和「现在是怎么算的」。

---

## 一、三种类别、三个目录，绝对不许混

| 类别 | 存放目录 | 允许的操作 | 禁止的操作 |
|:---|:---|:---|:---|
| **① 原始照片** | `01现场照片归档/原始照片/` | 从相机/手机复制进来，只改文件名（编号），**文件内容一个像素都不许动** | ❌ 用画图工具画线/标框/写字<br>❌ 裁剪<br>❌ 调整亮度对比度<br>❌ 覆盖删除 |
| **② 补备注照片** | `01现场照片归档/补备注照片/` | 对原始照片做标注：手写拍照 / PS画框加字 / 红圈标异常点<br>**文件名与原始照片编号严格一致** | ❌ 删除对应原始照片<br>❌ 编号和原始照片对不上<br>❌ 只留备注版不留原版 |
| **③ 旧版本截图** | `01现场照片归档/旧版本截图/` | 截取之前分析过程的屏幕：Excel半成品 / Matlab图 / 旧版报告 / 邮件讨论截图 | ❌ 只留最终版不留过程版<br>❌ 截图无时间戳无版本号 |

---

## 二、编号规则（保证一一对应，不会乱）

```
命名格式: IMG_{实验日期}_{序号}_{类别缩写}.jpg

示例:
  原始照片第15张:    IMG_20260614_015_ORG.jpg      放 原始照片/
  补备注版第15张:    IMG_20260614_015_NOTE.jpg     放 补备注照片/
  旧分析截图第3张:   IMG_20260614_003_OLD.png      放 旧版本截图/

缩写说明:
  ORG  = Original  原始
  NOTE = Noted     补备注
  OLD  = Old version screenshot 旧版本截图
```

> **为什么要一一对应？** 交接时小林要能拿着补备注照片里的疑问，反查到原始照片里有没有这回事；反过来也一样。

---

## 三、补备注照片的标注要求（别让后人猜你画的红圈是什么意思）

每张补备注照片至少包含以下信息中的**至少2项**：

1. **明确的圈/箭头**: 把你想说的东西圈出来，别让别人猜「你指的是左边那条烟还是右边那条」
2. **文字说明**: 直接写在照片上（手写/后期都行），例如：
   - "此处烟线断了，原因：发烟丝卡住 06/14 14:23"
   - "此帧重拍！逆光严重"
   - "初算位移偏大，疑似边界层猝发 → EV-001"
3. **签名+日期**: 谁标的、什么时候标的
4. **关联编号**: 关联到报告中的极端值编号/缺口编号，例如 "EV-002"、"GAP-001"

### 反面教材（别这么干）

> ❌ 只画了一个红圈，没写任何字 → 3天后你自己都忘了圈的是什么
>
> ❌ 在原始照片上直接画 → 原版没了，无法证明你画的位置对不对

---

## 四、旧版本截图怎么留（防止「只剩最终结论」）

每次发生以下事件时，**必须截图存档**：

| 事件 | 要截什么图 | 最少张数 |
|:---|:---|:---:|
| 第一次算出任何数字（初稿） | Excel/Matlab全屏幕，包括公式栏和状态栏 | 1张 |
| 发现极端值，第一次标出来 | 散点图/箱线图，极端值高亮的那张 | 1张 |
| 改了参数/公式，前后对比 | 左右放两版结果对比 | 1张 |
| 补采样缺口之前/之后 | 补之前的缺口数据表 + 补之后的完整数据 | 2张 |
| 复核人提了修改意见 | 邮件/聊天记录截图 + 修改前报告对应部分 | 1~2张 |
| 任何时候你想「先删了这个重算」 | 删之前屏幕截一张，哪怕算错了也要留 | 1张 |

## 五、归档检查清单（每次实验后对照打勾）

> 归档人签字前必须全勾上，否则不许宣布实验结束。

| 检查项 | 是/否 |
|:---|:---:|
| 1. 原始照片全部导入 `原始照片/`，内容未做任何修改 | ⬜ |
| 2. 原始照片编号连续，无跳号（#001, #002, ... #N） | ⬜ |
| 3. 实验期间手写的现场记录纸，已拍照存入 `补备注照片/`（文件名开头加NOTE_SHEET_） | ⬜ |
| 4. 所有有疑问/有异常的帧，已在 `补备注照片/` 中有对应标注版，且编号与原始一致 | ⬜ |
| 5. 本次实验过程中至少存了 ≥3 张过程截图到 `旧版本截图/` | ⬜ |
| 6. 截图都有明确文件名（能看出是哪个版本/哪个步骤的） | ⬜ |
| 7. 三个目录分别统计了张数：原始___张，补备注___张，旧截图___张 | ⬜ |
| 8. （如有）重拍的照片，编号在原始序列之后顺延，并在备注中写「此帧为重拍」 | ⬜ |

## 六、如果发现归档不合规怎么办？

**别改旧文件！别改旧文件！别改旧文件！**

正确做法：
1. 在 `补备注照片/` 里新建一张：`IMG_日期_序号_CORRECTION.jpg`
2. 把错误标注（比如「之前EV-001圈错位置了，实际应该是这里」）写清楚
3. 在处理状态追踪看板补一条备注
4. 在对应报告的 §五历史版本对比中加一条说明

> 原理和考古一样：你不能把遗址挖错了就把土填回去假装没挖过；应该在旁边立个牌子写「此处之前判断有误，正确位置→」。
