# 交接验证清单 — 小林老师的普通交接流程

> **目的**: 收尾时让实验师小林按「普通同事交接」的方式走一遍，验证两件事：
> 1. **从现场照片能找到原始说法**（历史没丢）
> 2. **从Markdown报告能讲清处理结果**（结果没含糊）
>
> **使用方式**: 小林假装不知道中间过程，从头开始按清单走一遍，遇到任何过不去的地方，就是流程要改的地方。

## 第一关：从现场照片 → 找到原始说法（验证历史没丢）

> 小林此时**只看照片文件夹**，不看报告，假装是刚拿到现场照片的新同事。

### Step 1: 打开「01现场照片归档/原始照片/」

| 验证项 | 是否通过 | 遇到的问题（不通过时写） |
|:---|:---:|:---|
| 照片编号是否连续？（#001, #002... 无跳号） | ⬜是 ⬜否 | |
| 能否看出实验流程顺序？（风洞启动→标定→发烟→变工况→收尾） | ⬜清晰 ⬜部分 ⬜不行 | |
| 有没有某个关键步骤一张照片都没有？（如标定物全景） | ⬜没有 ⬜有：___ | |
| 照片是否为**未标注原始状态**？（允许有相机本身时间戳，不允许有后期画的线） | ⬜是 ⬜否 | |

### Step 2: 打开「01现场照片归档/补备注照片/」

| 验证项 | 是否通过 | 遇到的问题 |
|:---|:---:|:---|
| 是否与原始照片**编号一一对应**？（同编号有原始就有补备注版，不允许覆盖原始） | ⬜是 ⬜部分 ⬜否 | |
| 补的备注是手写还是后期标上去的？ | ⬜手写（好） ⬜后期标（可） ⬜都没（差） | |
| 能不能从补备注照片里看到**当时标注的疑问点**？（如「此处烟线断了」「重拍」） | ⬜能看到多处 ⬜能看到1-2处 ⬜完全看不到 | |
| 有没有哪张补备注照片上的说明，**在原始照片上完全找不到对应位置**？ | ⬜没有 ⬜有（编号#___） | |

### Step 3: 打开「01现场照片归档/旧版本截图/」

| 验证项 | 是否通过 | 遇到的问题 |
|:---|:---:|:---|
| 有没有至少1张**初稿分析过程**的截图？（哪怕是Excel/Matlab半成品也行） | ⬜有 ≥3张 ⬜有1-2张 ⬜完全没有 | |
| 能否从截图中看到**之前算错或遗漏的地方**？（验证不是只留最终版） | ⬜能明确看到 ⬜隐约能看到 ⬜看不出来 | |
| 截图有没有**时间戳或版本号**？（能和报告§五历史版本对上） | ⬜清晰对应 ⬜大致对应 ⬜对不上 | |

### Step 4: 闭眼抽一张照片 → 看能否找到对应信息

> 随机抽3张照片（比如#018、#052、#099），问自己：

| 随机抽的照片编号 | 在报告中能找到它被引用吗？（§2.1或§三或§四） | 引用的说法和照片上能看到的内容一致吗？ |
|:---:|:---:|:---:|
| #___ | ⬜能 ⬜找不到 ⬜找到了但对应错 | ⬜一致 ⬜部分对 ⬜对不上 |
| #___ | ⬜能 ⬜找不到 ⬜找到了但对应错 | ⬜一致 ⬜部分对 ⬜对不上 |
| #___ | ⬜能 ⬜找不到 ⬜找到了但对应错 | ⬜一致 ⬜部分对 ⬜对不上 |

> **第一关通过标准**: 以上所有 ⬜ 中，「否/不行/对不上/找不到」的项 ≤ 2 个。
> 否则 → 流程中「照片归档」环节要加强。

## 第二关：从Markdown报告 → 讲清处理结果（验证结果没含糊）

> 小林此时**只看报告文件**，不看照片，假装是接手的下一个研究员，需要给别人讲清楚这份实验的误差结论。

### Step 5: 看报告第1页（速览卡）→ 30秒内回答以下问题

| 问题 | 能答出来吗？ | 答案（写下来验证） |
|:---|:---:|:---|
| 1. 这份报告的总误差是多少（不含极端值）？ | ⬜能 ⬜不能 | |
| 2. 最大的误差来源是哪一项？ | ⬜能 ⬜不能 | |
| 3. 有没有极端值？几个？有没有确认完？ | ⬜能 ⬜不能 | |
| 4. 这份报告用的参数/公式版本号是多少？ | ⬜能 ⬜不能 | |
| 5. 数据完整吗？有没有缺口？ | ⬜能 ⬜不能 | |

> 要求：**5题全对**才算过。缺1题 → 第1页信息要补充。

### Step 6: 随机挑一个误差分量 → 看计算过程

> 随机挑2项（如扩散误差、风速脉动）

| 挑的误差项 | 公式、代入数值、中间过程、最终值，四要素齐全吗？ | 单位从头到尾一致吗？ | 能对照A0手册找到公式出处吗？ |
|:---|:---:|:---:|:---:|
| ___误差 | ⬜齐全 ⬜缺1项 ⬜缺≥2项 | ⬜是 ⬜否 | ⬜能 ⬜不能 |
| ___误差 | ⬜齐全 ⬜缺1项 ⬜缺≥2项 | ⬜是 ⬜否 | ⬜能 ⬜不能 |

> 要求：**不允许出现「最终值=0.83%」但没有过程**的情况。

### Step 7: 极端值解释 → 能讲给外行听

> 看报告§四，选1个已确认的极端值EV-00X，假装给不懂风洞的同事讲：

| 验证点 | 能不能做到？ |
|:---|:---:|
| 1. 它为什么是极端值（偏离多少）？ | ⬜能讲清楚 ⬜含糊 |
| 2. 最后判定是什么原因（真实物理/拍摄/操作）？ | ⬜能讲清楚 ⬜含糊 |
| 3. 为什么这个判定站得住脚（哪张照片/什么证据）？ | ⬜能讲清楚 ⬜含糊 |
| 4. 它对总误差的影响有多大（含vs不含差多少）？ | ⬜能讲清楚 ⬜含糊 |

> 要求：4点都能讲清楚。有任何一点含糊 → 极端值分析要重写。

### Step 8: 有没有被平均掉的风险？

| 检查项 | 结果 |
|:---|:---:|
| 总误差是否同时给出「含极端值」和「不含极端值」两个数字？ | ⬜是 ⬜否（大问题！） |
| 如果两者差 > 2%，报告中是否单独讨论了差异原因？ | ⬜是 ⬜否 ⬜差值≤2%无需 |
| 有没有任何一个数据点，在§2.3原始数据表中存在，但在统计时悄无声息地消失了？ | ⬜没有 ⬜疑似有（需查） |

## 第三关：交叉验证 — 照片说法 vs 报告说法一致

> 现在把照片和报告**放在一起对照**，模拟有人质疑「报告上这么写，照片上真的有吗？」

| 交叉验证点 | 报告中的说法（引用页码/段落） | 照片中的证据（编号+位置） | 是否一致 |
|:---|:---|:---|:---:|
| 标定物长度 | §2.1 第X页：L=___m | 标定照片#___ | ⬜一致 ⬜不一致 |
| 某个工况的风速 | §2.1：U=___m/s | 皮托管读数照片#___ | ⬜一致 ⬜不一致 |
| EV-001怀疑原因 | §四EV-001：___ | 照片#___中___位置 | ⬜一致 ⬜不一致 |
| 缺口GAP-001位置 | §六：#15~#17缺失 | 原始照片文件夹#045~#047 | ⬜确实缺 ⬜其实有 |
| （再加1-2个你关心的点） | | | |

> 要求：全部一致。任何一条不一致 → 改报告或补照片说明。
