## 1. 产品概述

渔获冷链靠港结算系统——面向港口调度员与船队的冷链结算复核计算工具。解决传统"经验传帮带"模式下轨迹漂移复核逻辑不透明、人工修正无留痕、巡检照片难以溯源、结果可用性不清晰等痛点，让新同事也能理解"为什么要复核"以及"怎么复核"。

- 目标用户：港口调度员（主操作人）、船队成员（结果消费方）、新入职调度员（学习方）
- 核心价值：将隐性的经验判断显性化、公式化、可追溯化，实现结算复核的标准化与透明化

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限 |
|------|------|
| 港口调度员 | 执行复核、人工修正（留痕）、标记数据状态、查看所有模块 |
| 船队成员 | 查看分级结果、仅看"可用/暂缓/重新采集"标签，无修改权限 |
| 新入职调度员 | 同港口调度员权限，但系统内嵌公式说明与适用范围指引 |

### 2.2 功能模块

1. **轨迹漂移复核计算工具**：公式、单位、适用范围、失败原因一目了然
2. **复核备注与轨迹清洗**：稳定运行的复核流程核心
3. **水质预警溯源**：结论拉回来源材料
4. **人工修正留痕**：待确认→通过的前后变化可追溯
5. **巡检照片追溯**：保留原始行号、图片名、来源备注
6. **结果分级展示**：可用/暂缓/重新采集，船队一眼分清
7. **同一轮复合材料**：气象预报、潮汐表、禁航区越界纳入同一复核轮次

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 结算总览 | 状态看板 | 展示当前批次结算整体状态：待复核/复核中/已通过/已退回数量，船队可直接看到分级标签 |
| 轨迹漂移复核 | 计算工具 | 输入轨迹参数后自动计算漂移量，公式、单位、适用范围、失败原因在计算结果旁展示 |
| 轨迹漂移复核 | 复核备注 | 调度员可添加复核备注，系统自动关联轨迹清洗结果 |
| 轨迹漂移复核 | 轨迹清洗 | 展示清洗前后的轨迹数据对比，异常点高亮 |
| 水质预警 | 预警结论与溯源 | 预警结论附带来源材料链接，点击可跳转至原始水质检测记录 |
| 人工修正留痕 | 修正记录 | 展示所有人工修正：待确认→通过的状态变更时间线，前后值对比 |
| 巡检照片 | 照片溯源 | 保留原始行号、图片名、来源备注，支持按行号/图片名检索 |
| 结果说明 | 分级结果 | 每条结果标注"可用/暂缓/重新采集"，附带简短说明 |
| 复合材料复核 | 气象/潮汐/禁航区 | 同一页面展示气象预报、潮汐表、禁航区越界信息，与当前结算批次关联 |

## 3. 核心流程

用户打开系统后，首先看到结算总览页面，了解当前批次整体状态。港口调度员进入轨迹漂移复核模块，输入参数后系统自动计算并展示公式、单位、适用范围和可能的失败原因。调度员可添加复核备注，系统同步展示轨迹清洗结果。水质预警模块将结论关联到来源材料。当调度员进行人工修正时，系统自动记录修改前后的变化，形成留痕时间线。巡检照片模块保留原始行号和来源信息。最终结果以"可用/暂缓/重新采集"三级标签展示，船队可一眼分清。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 `#0A2540`，体现渔港冷链的行业属性
- 辅助色：冰蓝 `#00D4FF`（可操作元素）、琥珀 `#F59E0B`（预警/暂缓）、翠绿 `#10B981`（可用/通过）、珊瑚红 `#EF4444`（退回/重新采集）
- 按钮风格：圆角微凸，带轻微阴影，传达"可点击"的触感
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据用 JetBrains Mono
- 布局：左侧导航 + 右侧内容区，卡片式模块布局
- 图标：lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 结算总览 | 状态看板 | 深色背景卡片、状态数字大字体、分级标签色块、批次列表表格 |
| 轨迹漂移复核 | 计算工具 | 左侧输入区（参数表单）、右侧结果区（公式展示+计算值+适用范围+失败原因提示框） |
| 轨迹漂移复核 | 复核备注 | 备注输入框、备注时间线列表、关联轨迹清洗高亮 |
| 轨迹漂移复核 | 轨迹清洗 | 清洗前后对比表格、异常点红色标记、展开/折叠详情 |
| 水质预警 | 预警结论与溯源 | 预警卡片（结论+等级）、来源材料链接按钮、跳转原始记录 |
| 人工修正留痕 | 修正记录 | 时间线组件、修改前后值对比（删除线+新值高亮）、操作人+时间戳 |
| 巡检照片 | 照片溯源 | 照片缩略图网格、行号标签、来源备注浮层、搜索筛选栏 |
| 结果说明 | 分级结果 | 三色标签（绿/黄/红）、简短说明文字、筛选器 |
| 复合材料复核 | 气象/潮汐/禁航区 | 三栏并排卡片、与当前批次关联的日期/区域信息、异常高亮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 大屏（≥1440px）充分利用空间展示复合材料并排
- 中屏（1280-1439px）复合材料改为 Tab 切换
- 移动端暂不做适配，主要使用场景为港口调度室桌面端
