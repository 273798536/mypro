# 热力学咖啡工坊 ☕

一款基于真实热力学原理的科普模拟游戏，玩家通过操作咖啡制作过程中的加热、加冰、搅拌等动作，学习热交换、热量守恒等物理概念。

## 核心特性

### 🎮 游戏功能
- **热交换物理模拟**：基于真实热力学公式 Q=cmΔT 计算
- **热量守恒校验**：每一步操作都会验证热量守恒定律
- **数据清洗模块**：自动处理原始数据中的空行、备注、缺列
- **异常检测**：温度越界、守恒错误、订单超时自动记录

### 📊 数据链路（重点）
```
水温表显示 → physicsStore.temperature
          ← heatEngine计算结果
          ← 玩家操作触发
          → temperatureHistory追加
          → 温度曲线渲染
          → 成绩计算引用
          → 导出报告（含完整操作ID和时间戳）
```

### 🔬 物理科普馆审核
- 异常记录筛选（温度越界、守恒错误、超时）
- 操作回放系统
- 曲线回放分析
- 坏行记录独立展示

## 物理公式

### 热交换公式
```
Q = c × m × ΔT

其中：
- Q: 热量 (J)
- c: 比热容 (J/g·℃)
- m: 质量 (g)
- ΔT: 温度变化 (℃)
```

### 水的物理常数
- 比热容：4.186 J/g·℃
- 冰的比热容：2.09 J/g·℃
- 熔化潜热：334 J/g

### 成绩计算公式
```
总分 = 温度准确度×40% + 时间效率×30% + 热量守恒×30%

温度准确度 = 100 - |实际温度 - 目标温度| × 5
时间效率 = 100 - 超时秒数 × 1
热量守恒 = 100 - 守恒错误×30 - 温度越界×20 - 超时×15
```

## 数据清洗规则

1. **空行**：完全空白的行 → 单独列入坏行报告
2. **备注行**：以 `#` 开头的行 → 单独列入坏行报告
3. **缺列**：关键字段缺失 → 单独列入坏行报告
4. **来源标记**：标记数据来源（顾客订单/搅拌记录/操作日志）

## 异常类型

| 异常类型 | 触发条件 | 扣分 |
|---------|---------|------|
| 温度越界 | 温度 < 0℃ 或 > 100℃ | -20分 |
| 热量守恒错误 | ΣQ入 ≠ ΣQ出 + ΔU（误差>1%） | -30分 |
| 订单超时 | 完成时间 > 时限 | -15分 |

## 导出格式

- 成绩明细

2. 物理准确性：基于真实热力学原理
