# 音乐课堂听辨题库管理系统

一套专为音乐课堂设计的听辨题库管理系统，支持智能抽题、难度监控、质量分析和答题追踪。

## ✨ 核心功能

### 📚 题库分层管理
- **32道预置样题**，涵盖节奏、和声、旋律、音程、和弦五大类
- **知识点标签体系**，18个细分标签支持多维度筛选
- **三级难度分级**（简单/中等/困难），均衡分布

### 🎯 智能抽题策略
- 按知识点、难度、题型进行**分层抽样**
- 实时显示抽题**平衡度评分**
- 支持导出试卷为 **Excel / PDF**

### 🔍 质量监控体系
- **重复题目识别**（基于编辑距离算法，相似度>0.7自动标记）
- **难度漂移检测**（答题正确率与预期难度对比）
- **标签缺失管理**，待确认分支流程

### 📝 答题补录与追踪
- 学生答题成绩录入
- **变更历史时间轴**，可追溯每次修改
- **双向查询**：从题目→结果→知识点标签，反向追溯

### 💾 数据持久化
- 基于 Zustand + LocalStorage，**刷新不丢数据**
- 支持一键导出/导入完整数据
- 可随时重置为示例数据

## 📖 使用指南

### 1. 基础查询流程（题目 → 结果 → 标签）

**步骤1：查找音频题目**
- 进入「题库列表」页面
- 使用搜索框输入关键词，或通过分类/难度筛选
- 点击题目行进入详情页

**步骤2：查看答题结果**
- 在题目详情页底部查看「学生答题历史」
- 点击学生姓名可展开该学生的答题统计
- 查看正确率曲线和答题详情

**步骤3：追溯知识点标签**
- 在答题统计的「知识点关联分析」区域
- 点击标签可查看该标签下的所有题目
- 点击题目可跳转回题目详情

### 2. 反向查询流程（结果 → 题目 → 标签）

**步骤1：从答题记录开始**
- 进入「答题补录」页面
- 选择左侧题目，查看右侧答题历史
- 点击学生姓名展开统计

**步骤2：关联分析**
- 查看「知识点标签关联」卡片
- 点击标签跳转筛选同类题目
- 点击题目编号跳转题目详情

### 3. 智能抽题操作

1. 进入「智能抽题」页面
2. 配置抽题策略：
   - 题目总数（默认10道）
   - 难度分布（简单30% / 中等50% / 困难20%）
   - 知识点覆盖（可多选）
3. 点击「生成试卷」查看平衡度评分
4. 调整题目或重新生成
5. 导出为 Excel 或 PDF

### 4. 质量监控流程

**难度漂移处理：**
1. 进入「质量监控」→「难度漂移检测」
2. 查看漂移详情（预期难度 vs 实际正确率）
3. 点击「分配处理人」指定教研员复核
4. 或直接点击「调整难度」自动修正

**重复题目处理：**
1. 进入「质量监控」→「重复题目识别」
2. 查看相似题目组，对比内容
3. 选择保留的题目，标记其他为已废弃

**标签缺失处理：**
1. 进入「质量监控」→「标签待确认」
2. 点击「编辑标签」补充知识点
3. 保存后状态变为「待复核」
4. 教研员切换角色后可确认标签

## 💡 核心算法说明

### 重复题目识别
采用**莱文斯坦编辑距离**算法，加权计算：
- 标题相似度（40%）+ 选项相似度（30%）+ 标签相似度（30%）
- 相似度 > 0.7 自动标记为重复

### 分层抽样抽题
```
目标：按难度和知识点均衡分布
1. 计算每类题目所需数量
2. 按权重随机抽取，确保不重复
3. 计算平衡度评分（分布均匀度）
4. 平衡度 < 70% 自动提示优化建议
```

### 难度漂移检测
```
阈值规则：
- 简单题：正确率 < 70% → 漂移（偏难）
- 中等题：正确率 < 50% 或 > 80% → 漂移
- 困难题：正确率 > 50% → 漂移（偏易）
```

## 🔄 角色切换说明

系统支持两种角色，点击右上角用户头像可切换：

**👨‍🏫 音乐教师（张老师）**
- 抽题组卷、导出试卷
- 录入学生答题成绩
- 查看题目详情和答题统计
- 编辑题目标签（状态变为待复核）

**👩‍💼 音乐教研员（李教研员）**
- 质量监控、难度漂移分析
- 复核确认标签状态
- 处理重复题目、调整难度
- 分配问题处理人

## 📊 月底复盘流程

1. 进入「智能抽题」页面
2. 点击「历史试卷」查看本月抽题记录
3. 进入「答题补录」导出本月全部答题数据（Excel）
4. 进入「质量监控」查看难度漂移趋势图
5. 根据分析结果调整题库难度和标签

## ⚠️ 常见问题

**Q: 刷新页面数据会丢失吗？**
A: 不会，所有数据自动保存到浏览器 LocalStorage。

**Q: 如何重置为示例数据？**
A: 点击左侧导航栏底部「重置示例数据」按钮。

**Q: 可以在不同设备间同步数据吗？**
A: 可以使用「导出数据」生成JSON文件，在另一设备「导入数据」。

**Q: 导出的PDF/Excel在哪里？**
A: 会自动下载到浏览器默认下载目录。
