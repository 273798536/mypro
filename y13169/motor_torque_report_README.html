🔴 关键小宋临时改过的判断留在历史里 AuditTrail 每次操作写一条 JudgmentEntry（timestamp / operator / action / reason / previous_value / new_value / formula）；报告 "判断历史记录" 章节以表格全量展示 下一班能看到每一次方向修正、覆盖放行、补料要求、参数调档，而不只是最终数字

🚀 使用示例

from motor_torque_report.exporter import MotorTorqueReportExporter
from motor_torque_report.models import FilterCriteria

# 1. 初始化 + 加载实验记录
exporter = MotorTorqueReportExporter(operator="小宋", output_unit="N·m")
exporter.load_records(SAMPLE_RECORDS)

# 2. 先跑异常检测（方向写反、单位混写、晚到附件）
anomalies = exporter.check_anomalies()
# → 产出待确认原因 + 影响范围 + 建议操作

# 3. 小宋临时判断
exporter.fix_direction("REC-003", reason="经复核确认方向写反")
exporter.release_record("REC-004", reason="晚到附件经确认可放行")
exporter.request_supplement("REC-003", reason="缺原始附件")

# 4. 调一档参数复算
exporter.recalculate("boundary_sigma", old_value=1.5, new_value=2.0)

# 5. 一次筛选 + 统计 + 明细 + 报告（同源）
md = exporter.export_markdown(
    filter_criteria=FilterCriteria(motor_ids=["M-100","M-101","M-102"])
)

with open("report.md", "w", encoding="utf-8") as f:
    f.write(md)

📊 Markdown 报告章节

  1. 筛选条件（FilterCriteria 完整序列化）
  2. 统计数字（CW/CCW 分开：均值、标准差、min/max、边界样本 ID）
  3. 明细表（原始值 + 单位 + 换算后 + 晚到标记 + 操作人）
  4. ⚠️ 待确认异常（逐条：类型、严重性、描述、影响范围、建议操作；未确认前不加统计）
  5. 参数调档影响分析（变更前→后、公式/换算因子、边界样本变化、结果变化百分比）
  6. 判断历史记录（完整审计表：时间、操作人、动作、原因、旧值、新值、公式）
  7. 📋 可操作清单
    • 🔴 需要补料/确认（逐条带记录号 + 建议操作）
    • ✅ 可以放行（清单条数）
