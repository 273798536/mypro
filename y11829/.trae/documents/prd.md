## 1. 产品概述

银行柜台排队Rush——面向银行柜员培训的交互式排队管理模拟小游戏。通过真实排队场景（VIP挤占、预约过号、柜台临时故障），让新人在实操中掌握队列重排与资源冷却规则，而非死记硬背。
- 目标用户：银行培训师、新入职柜员
- 核心价值：用游戏化操作替代枯燥规则讲解，失败原因精准归因到客户卡或柜台具体位置，暂停/重开/复盘全链路可视化队列重排与资源冷却影响

## 2. 核心功能

### 2.1 用户角色
| 角色 | 权限 |
|------|------|
| 培训师 | 配置场景参数（VIP等级、柜台数量、故障率）、启动/暂停/重开、查看复盘报告 |
| 柜员（学员） | 拖拽客户到柜台、处理VIP挤占、应对预约过号和柜台故障 |

### 2.2 功能模块
1. **游戏主界面**：客户队列区、柜台操作区、实时状态面板、操作反馈条
2. **复盘界面**：回合时间线、队列重排快照、资源冷却标记、失败归因详情

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 客户队列区 | 显示等待客户卡片（含VIP等级、预约时间、业务类型），支持拖拽到柜台 |
| 游戏主界面 | 柜台操作区 | 多个柜台槽位，每个柜台显示状态（空闲/占用/冷却/故障）、当前服务客户、剩余时间 |
| 游戏主界面 | 实时状态面板 | 等待人数、已服务人数、VIP积压数、预约过号数、柜台故障数 |
| 游戏主界面 | 操作反馈条 | 即时toast提示：VIP挤占发生、预约过号、柜台故障、服务完成等 |
| 游戏主界面 | 控制栏 | 暂停/继续、重新开始、复盘按钮 |
| 复盘界面 | 回合时间线 | 按时间轴展示每个事件（客户到达、分配、VIP挤占、过号、故障） |
| 复盘界面 | 队列重排快照 | 展示VIP挤占导致的队列重排前后对比，标注被挤占客户卡位置 |
| 复盘界面 | 资源冷却标记 | 展示柜台冷却/故障时段，标注影响的客户卡 |
| 复盘界面 | 失败归因详情 | 每个失败项指向具体客户卡ID或柜台编号，非模糊总分 |

## 3. 核心流程

游戏启动后，客户按配置节奏到达队列。柜员需将客户拖拽至空闲柜台处理。VIP客户到达时触发挤占规则：优先插队到队列前方，若柜台正在服务普通客户，可选择中断（普通客户回队列，柜台冷却）或拒绝VIP（扣分）。预约客户有固定时间窗口，过号则标记失败。柜台随机故障，故障柜台进入冷却期，冷却期间不可用。游戏结束后进入复盘，逐步回放事件并标注归因。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深银行蓝 (#1B3A5C) + 金色强调 (#D4A843)
- 辅助色：浅灰背景 (#F0F2F5)、警告红 (#E74C3C)、成功绿 (#27AE60)、冷却蓝 (#5DADE2)
- 按钮风格：圆角8px，立体阴影，金色主按钮
- 字体：Noto Sans SC（中文），Orbitron（数字/倒计时）
- 布局：顶部状态栏 + 左侧客户队列 + 右侧柜台矩阵 + 底部反馈条
- 图标风格：扁平线性图标 + 状态色标

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 游戏主界面 | 客户队列区 | 卡片式客户信息，VIP金色边框，预约倒计时徽章，可拖拽 |
| 游戏主界面 | 柜台操作区 | 网格柜台卡片，状态色标（绿空闲/橙占用/蓝冷却/红故障），进度条 |
| 游戏主界面 | 实时状态面板 | 数字仪表盘，Orbitron字体，动态变化动画 |
| 游戏主界面 | 操作反馈条 | 底部滑入toast，带图标和颜色区分 |
| 复盘界面 | 时间线 | 垂直时间线，事件节点可点击展开详情 |
| 复盘界面 | 队列快照 | 前后对比卡片，箭头标注重排移动路径 |
| 复盘界面 | 归因卡片 | 客户卡ID + 柜台编号 + 失败原因，可点击跳转 |

### 4.3 响应式
- 桌面优先设计，最小宽度1024px
- 柜台区域网格自适应列数
- 客户队列区支持滚动

### 4.4 样例场景设计（重点：触发队列重排与资源冷却）
1. **场景A：VIP挤占触发队列重排**
   - 初始：柜台1服务普通客户A(剩余3秒)，柜台2空闲，队列[B, C]
   - 事件：VIP客户D到达
   - 预期：D插入队列首位，柜员拖拽D到柜台2（无需中断），或拖拽D到柜台1（中断A，A回队列，柜台1冷却2秒）
   - 复盘标注：被挤占的客户A卡片高亮，柜台1冷却时段标记

2. **场景B：预约过号 + 柜台故障触发资源冷却**
   - 初始：柜台1空闲，柜台2服务中，队列[预约客户E(窗口30秒), 普通客户F]
   - 事件：柜台2突发故障，E的预约窗口耗尽
   - 预期：柜台2进入冷却5秒，E过号标记失败，F需等待柜台1
   - 复盘标注：E的客户卡标注"预约过号"，柜台2冷却时段标记，F的等待延时归因到柜台2故障
