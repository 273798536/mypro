## 1. 产品概述

保险分保赔款摊回系统是面向再保险业务核心工具，解决月底/上课前高发的免赔错用、口径不一致、临时表格硬凑等业务痛点。系统通过赔案单、分保合同、摊回表三位一体的数据联动，实现历史留痕机制确保免赔错用不被覆盖，支持筛选条件实时同步图表与明细，版本差异可视化对比，彻底告别手工操作风险。

## 2. 核心价值：
- 解决免赔错用的识别与留痕
- 统一口径的摊回计算
- 合同版本变更追溯
- 差异说明自动生成

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 再保会计 | 内部账号登录 | 数据录入、摊回计算、版本对比、报表导出 |
| 业务审核 | 内部账号登录 | 数据复核、差异确认、历史追溯 |

### 2.2 功能模块
1. **首页仪表盘：数据概览、关键指标、快速操作区
2. **赔案单管理：赔案列表、详情、编辑、导入导出
3. **分保合同管理：合同列表、版本管理、历史对比
4. **摊回计算引擎：自动计算、差异检测、免赔识别
5. **摊回表生成：明细报表、图表展示、筛选联动
6. **历史追溯：变更记录、版本差异、免赔错用留痕

| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 首页仪表盘 | 数据概览卡 | 展示赔款总额、摊回总额、免赔异常数、合同数等关键指标 |
| 首页仪表盘 | 快速操作 | 一键计算、新增赔案、新增合同入口 |
| 赔案单管理 | 赔案列表 | 赔案单列表展示，支持多条件筛选、排序、搜索 |
| 赔案单管理 | 赔案详情 | 赔案完整信息展示与编辑 |
| 分保合同管理 | 合同列表 | 合同列表展示，版本号、生效日期、状态 |
| 分保合同管理 | 版本对比 | 合同版本前后差异对比可视化 |
| 摊回计算 | 计算引擎 | 自动计算摊回金额、检测免赔错用 |
| 摊回表 | 明细报表 | 摊回明细表格，支持筛选同步 |
| 摊回表 | 图表展示 | 柱状图、饼图多维分析 |
| 历史追溯 | 变更记录 | 所有操作历史记录时间线 |
| 历史追溯 | 差异说明 | 自动生成差异说明文档 |

## 3. 核心流程

### 3.1 业务主流程

```mermaid
flowchart TD
    A["录入赔案单" --> B["维护分保合同"
    B --> C["触发摊回计算"]
    C --> D{"免赔错用检测"}
    D -->|是| E["标记异常并留痕"]
    D -->|否| F["正常计算"]
    E --> G["生成差异说明"]
    F --> G
    G --> H["生成摊回表"]
    H --> I["修改合同重跑"]
    I --> J["保留前后版本对比"]
```

### 3.2 版本变更流程

```mermaid
flowchart LR
    A["原始合同V1"] --> B["计算摊回V1"]
    B --> C["修改合同"]
    C --> D["新合同V2"]
    D --> E["重新计算V2"]
    E --> F["版本差异对比"]
    F --> G["生成差异报告"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色(#1e3a5f) - 专业、稳重、金融感
- **辅助色**：金色(#d4af37) - 强调、重要信息
- **警告色**：红色(#dc2626) - 免赔错用、异常
- **成功色**：绿色(#16a34a) - 正常状态
- **按钮风格**：圆角矩形，轻微阴影，hover效果
- **字体**：Noto Serif SC（标题）+ Noto Sans SC（正文）
- **布局风格**：卡片式布局，顶部导航+左侧菜单
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|-----------|----------|--------|
| 首页仪表盘 | 数据概览卡 | 渐变背景、数据大屏数字、趋势箭头 |
| 赔案单列表 | 数据表格 | 斑马纹、悬停高亮、状态标签 |
| 合同版本对比 | 差异对比 | 左右分栏、差异高亮、新增/删除标记 |
| 摊回表 | 图表区 | 可筛选联动图表 |
| 历史追溯 | 时间线 | 垂直时间线、彩色标记、差异气泡 |

### 4.3 响应式
- Desktop-first 设计，适配 1920×1080 及以上
- 平板端侧边栏折叠
- 移动端简化布局，保证核心功能可用

### 4.4 交互细节
- 表格筛选条件变更时图表实时刷新（300ms过渡动画
- 版本对比时差异内容平滑高亮
- 免赔错用标记红色闪烁提示
- 时间线滚动加载动画
