## 1. 产品概述

信用卡积分成本CLI Web工具 - 专为市场分析师设计的积分成本核算工具，解决联名卡活动后积分兑换、商户补贴和退款回滚的真实成本计算难题。

- 核心目标：准确核算信用卡积分活动的真实成本，识别异常情况（退款未回滚、补贴跨活动、积分倍率叠加）
- 目标用户：市场分析师、财务人员、活动运营人员
- 核心价值：提供可追溯的成本核算流程，保留数据来源和修正历史，避免"悄悄算进正常结果"的风险

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 分析师 | 本地访问 | 数据导入、筛选、修正、导出报告 |

### 2.2 功能模块
1. **仪表盘**: 成本概览、异常预警、关键指标
2. **积分账本**: 交易明细、积分变动、来源追溯
3. **活动版本**: 活动配置、规则对比、版本历史
4. **退款补偿**: 退款记录、回滚检查、补偿计算
5. **成本分摊**: 补贴分配、活动归属、成本明细
6. **报告导出**: 图表展示、多格式导出、状态分类

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 成本概览卡片 | 总成本、已处理、待处理、异常数量统计 |
| 仪表盘 | 异常预警区 | 高亮显示退款未回滚、补贴跨活动、积分倍率叠加 |
| 积分账本 | 交易筛选器 | 按时间、商户、活动、状态筛选交易 |
| 积分账本 | 明细表格 | 交易流水、积分变动、数据来源、修正痕迹 |
| 积分账本 | 修正弹窗 | 手动修正积分、备注原因、保留操作历史 |
| 活动版本 | 活动列表 | 活动配置、积分规则、补贴标准 |
| 活动版本 | 版本对比 | 规则变更历史、差异高亮 |

| 报告导出 | 分类报告 | 未处理、已修正、需人工确认三类分开 |

## 3. 核心流程

### 3.1 数据导入与处理流程
```mermaid
flowchart LR
    A["导入数据源<br/>(刷卡/积分/补贴/退款/兑换)"] --> B["数据校验与合并"]
    B --> C["自动检测异常"]
    C --> D["异常高亮标记"]
    D --> E["分析师筛选查看"]
    E --> F["手动修正确认"]
    F --> G["成本分摊计算"]
    G --> H["生成分类报告"]
    H --> I["导出图表与数据"]
```

### 3.2 积分修正流程
1. 用户筛选定位到目标交易
2. 查看交易完整来源信息
3. 发起修正申请，输入修正值和原因
4. 系统记录修正前后值、操作人、时间戳
5. 交易状态变更为"已修正"
6. 成本自动重新计算

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深邃海军蓝 (#1e3a5f) - 专业金融工具感
- **辅助色**: 橙色警告 (#f59e0b)、红色错误 (#ef4444)、绿色成功 (#10b981)
- **按钮风格**: 方形带轻微圆角，实心主色按钮配白色文字
- **字体方案**: JetBrains Mono (数据表格) + Noto Sans SC (正文)
- **布局风格**: CLI-inspired 控制台风格，左侧导航 + 主工作区 + 右侧详情面板
- **图标风格**: 极简线性图标，搭配状态指示灯（绿/黄/红圆点）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 仪表盘 | 概览卡片 | 深色卡片、大号数字、状态指示灯、趋势小箭头 |
| 仪表盘 | 异常列表 | 红色/橙色背景条、异常类型标签、快速处理按钮 |
| 积分账本 | 筛选器 | 下拉选择器、日期范围、搜索框、状态过滤按钮组 |
| 积分账本 | 数据表格 | 固定表头、斑马纹、悬停高亮、状态列彩色标签 |
| 积分账本 | 修正弹窗 | 暗色模态框、前后对比、原因输入框、确认按钮 |
| 报告导出 | 图表区 | 深色背景图表、网格线、交互式提示框 |

### 4.3 响应式
- 桌面优先设计，最小支持1280px宽度
- 平板端折叠侧边栏为图标模式
- 移动端简化表格显示，支持横向滚动

### 4.4 交互细节
- 异常行自动高亮，鼠标悬浮显示异常原因
- 修正操作需二次确认
- 数据加载时显示骨架屏
- 表格支持列宽拖拽调整
- 支持键盘快捷键快速操作
