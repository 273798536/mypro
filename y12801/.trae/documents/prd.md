## 1. 产品概述

单细胞聚类批次复核系统——面向育种专员的批次审查工具，解决测序结果与采样信息合并、时间点缺失决策、异常复核前后对比等核心痛点。系统确保图、表、文字说明三者一致，提供完整审计追溯链路。

- 目标用户：育种专员、实验室数据审核人员
- 核心价值：将"拍不了板"的模糊判断变为有据可查的标准化复核流程，污染样本混入时可追溯至操作人、时间与原因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 育种专员 | 系统分配 | 提交复核、查看结果、发起异常复核 |
| 审核主管 | 系统分配 | 审批异常复核、查看审计日志、修改结论 |

### 2.2 功能模块

1. **批次复核主页**：批次列表、数据合并入口、聚类可视化、复核状态总览
2. **复核详情页**：测序数据表格、聚类图、采样地点信息、结论文字说明、异常标记
3. **异常复核页**：前后结论并排对比、图像标注差异、修改原因记录、审批流程
4. **审计日志页**：操作历史时间线、筛选过滤、详情展开

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 批次复核主页 | 批次列表 | 展示所有批次卡片，含状态标签（待复核/已通过/异常）、样本数、测序平台 |
| 批次复核主页 | 数据合并面板 | 导入测序结果（旧表）+采样地点（群补充），自动匹配样本ID，高亮冲突项 |
| 批次复核主页 | 聚类可视化 | UMAP/t-SNE散点图，按批次着色，点击聚类簇查看样本详情 |
| 复核详情页 | 测序数据表 | 展示合并后的完整数据，标注数据来源（旧表/群补充），时间点缺失标红 |
| 复核详情页 | 结论面板 | 图+表+文字三位一体：聚类图标注→对应表格行→文字结论，互相联动 |
| 复核详情页 | 异常标记 | 标记污染样本，弹出修改表单（含原因字段），触发异常复核流程 |
| 异常复核页 | 前后对比 | 左侧旧结论（含旧聚类图+旧表格+旧文字），右侧新结论，差异高亮 |
| 异常复核页 | 图像标注 | 聚类图上标注前后差异：新增/移除的样本点用不同颜色/形状标记 |
| 异常复核页 | 修改记录 | 展示修改人、修改时间、修改原因，审批状态（待审批/已通过/已驳回） |
| 审计日志页 | 操作时间线 | 按时间倒序展示所有复核操作，支持按操作人/批次/时间范围筛选 |
| 审计日志页 | 详情展开 | 点击时间线条目展开查看完整变更详情，包含前后数据对比 |

## 3. 核心流程

育种专员打开系统后，从批次列表选择待复核批次→系统合并测序结果与采样地点→展示聚类图与数据表→专员检查三方一致性→发现异常则发起异常复核→填写修改原因→主管审批→系统记录完整审计日志→结论更新后旧结论与新结论可并排查看。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色(#0F766E)搭配琥珀色(#D97706)作为异常警示色
- 辅助色：石板灰体系(Slate)用于背景与文字层次
- 按钮风格：圆角矩形，主要操作用实心填充，次要操作用描边
- 字体：Noto Sans SC 用于中文正文，JetBrains Mono 用于数据/编号
- 布局风格：左侧导航栏 + 右侧主内容区，卡片式模块布局
- 图标风格：Lucide 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 批次复核主页 | 批次列表 | 卡片网格，每张卡片含状态徽章、样本数统计、最近操作时间 |
| 批次复核主页 | 数据合并面板 | 左右分栏拖拽区，中间匹配连线动画，冲突项橙色边框 |
| 批次复核主页 | 聚类可视化 | 深色背景散点图，悬浮提示样本信息，批次图例侧栏 |
| 复核详情页 | 测序数据表 | 条纹表格，数据来源用小标签标注，缺失单元格红底白字 |
| 复核详情页 | 结论面板 | 三列布局：左图-中表-右文字，联动高亮用同色框标注 |
| 异常复核页 | 前后对比 | 双栏对称布局，差异部分用渐变背景标注，箭头指示变更方向 |
| 异常复核页 | 图像标注 | SVG叠加标注层，新增点绿色三角、移除点红色叉号、移动点虚线箭头 |
| 审计日志页 | 时间线 | 垂直时间线，操作类型用不同颜色圆点，展开面板含数据对比表 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 侧边栏可折叠以适配中等屏幕
- 聚类图支持全屏查看模式

## 5. 边界样例设计

围绕测序结果线，设计以下时间点缺失场景，每个场景真实影响复核结论：

### 样例1：关键时间窗口缺失导致批次效应误判
- 场景：批次B-037的3个样本缺失采样时间点，实际属于T2时间窗但被归入T3
- 影响：聚类分析中这3个样本与T3批次聚类，产生虚假批次效应，错误结论为"批次B-037存在批次效应需剔除"
- 复核修正：补全时间点后3个样本回归T2聚类，结论变为"无批次效应，样本可保留"

### 样例2：采样地点缺失导致污染源误判
- 场景：样本SC-112缺失采样地点信息，默认归入"温室A"，实际来自"温室B（近期交叉污染区）"
- 影响：聚类图中SC-112与温室A群体聚类，结论为"无污染"，但实际已混入温室B污染样本
- 复核修正：群补充采样地点后，SC-112重新定位到温室B污染簇，结论变为"检出污染样本，建议剔除"

### 样例3：测序平台信息缺失导致质控误判
- 场景：2个样本缺失测序平台标注，默认归入NovaSeq，实际来自NextSeq（低深度）
- 影响：质控阈值按NovaSeq标准判定通过，但NextSeq低深度样本实际应被标记为低质量
- 复核修正：补全平台信息后，按NextSeq标准重新质控，结论变为"2个样本低质量，建议重新测序"
