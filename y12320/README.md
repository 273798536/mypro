# 📊 非线性定价拟合器

SaaS商业定价分析工具，用于分析套餐价格变动对转化率的非线性影响，识别价格敏感区间，支持按客户规模分组对比。

## ✨ 功能特性

### 1. 数据管理
- **版本追踪**: 自动记录数据来源、时间、版本号
- **数据校验**: 检查数据格式完整性和类型正确性
- **历史回溯**: 支持加载历史数据版本进行对比分析

### 2. 异常检测
- **异常大客户识别**: 基于95分位阈值识别异常大规模客户
- **折扣记录检测**: 识别疑似享受折扣的转化记录
- **稀疏价格点标记**: 标记样本量不足的价格档位
- **异常值影响分析**: 详细说明各类异常对结果的影响

### 3. 非线性曲线拟合
支持5种曲线类型自动拟合：
- **Logistic (S曲线)**: 适合典型的价格-需求关系
- **Exponential (指数曲线)**: 适合快速衰减场景
- **Power (幂函数)**: 适合弹性稳定场景
- **Polynomial (3次多项式)**: 适合复杂非线性关系
- **Sigmoid (带偏移S曲线)**: 适合有基线转化率场景

### 4. 价格敏感度分析
- **弹性系数计算**: 各价格点的价格弹性
- **敏感度分级**: 高/中/低敏感区间自动识别
- **置信区间**: Bootstrap法计算弹性系数置信区间
- **关键洞察**: 最敏感/最不敏感价格点识别

### 5. 分组对比分析
- **客户规模分组**: 按分位数自动分组（2-5组）
- **组间差异检验**: T检验、卡方检验
- **分组曲线拟合**: 各组独立拟合曲线对比
- **最优价格差异**: 识别各组最优定价区间

### 6. 报告导出
- **Excel报告**: 多工作表详细报告
- **JSON报告**: 结构化数据便于后续处理
- **可视化图表**: 交互式Plotly图表

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动应用
```bash
streamlit run app.py
```

### 3. 使用流程

#### 方式一：加载示例数据
1. 进入应用后，在"数据概览"标签页
2. 点击"加载示例数据"按钮
3. 点击"开始完整分析"

#### 方式二：上传自有数据
1. 准备CSV或Excel文件，包含以下列：
   - `price`: 套餐价格（数值）
   - `converted`: 是否转化（0/1）
   - `customer_size`: 客户规模指标（数值）
   
2. 在左侧上传文件，填写数据来源和描述
3. 点击"加载数据"
4. 点击"开始完整分析"

- 价格弹性系数计算

### GroupAnalyzer - 分组分析

## 🔧 配置参数

### 数据清洗参数
- **IQR异常值阈值**: 1.0-3.0（默认1.5）
- **每价格点最小样本数**: 1-20（默认5）

### 曲线拟合参数
- **置信水平**: 90%-99%（默认95%）
- **显示所有曲线**: 勾选后展示5种曲线对比

### 分组分析参数
- **客户规模分组数**: 2-5组（默认3组）
- **启用分组分析**: 可开关分组功能

## 💡 最佳实践

1. **数据质量**: 确保每价格档位至少有5个样本
2. **价格覆盖**: 价格档位分布均匀，避免极端值
3. **样本量**: 建议总样本量≥500，以获得可靠拟合
4. **异常处理**: 仔细评估异常记录影响，不轻易剔除
5. **分组检验**: 分组后进行统计显著性检验验证差异
6. **定期更新**: 价格变动后及时更新数据重新分析

## 🔍 常见问题

**Q: 曲线拟合效果不好怎么办？**
A: 检查价格档位是否足够多，样本量是否充足，或尝试手动选择其他曲线类型。

**Q: 为什么分组分析结果不稳定？**
A: 各组样本量可能不足，建议减少分组数或增加总样本量。

**Q: 如何选择最优价格？**
A: 结合转化率目标、价格敏感度、客户规模分布综合判断。高敏感区间谨慎调价。

**Q: 数据版本如何管理？**
A: 每次上传都会创建新版本，可在左侧"历史版本"中切换。
