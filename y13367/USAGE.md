# 召回漏斗异常回放

推荐算法复核用的回放工具。把样本、版本、人工修正和异常队列串起来。

---

## 一、启动回放任务

从灰度配置发起一次新的回放。

1. 左侧菜单 → **回放任务** → 右上角「启动回放」
2. 选择要跑的灰度配置（可搜索配置名）
3. 可选填写重跑说明（如"修复 embedding 参数后验证"）
4. 点击「启动」，任务进入运行中状态，约 3 秒后完成

> 说明：新任务的证据目录独立保存，不会覆盖旧证据。若同日同配置重复运行，run_id 会自动标记为「ID重复」，证据路径加后缀区分。

---

## 二、重跑已有任务

对某次回放结果不满意时重跑，保留历史证据。

方式一（任务列表页）：
- 找到要重跑的行 → 操作列「重跑」→ 确认配置和说明 → 启动

方式二（任务详情页）：
- 进入任务详情 → 顶部「重跑此任务」按钮

> 说明：重跑会关联到原任务（`rerun_from` 字段），原任务的样本、证据、人工改判均保留不覆盖。

---

## 三、查看异常队列

排班组看哪些已处理、哪些还要补证据。

1. 左侧菜单 → **异常队列**
2. 顶部 6 个指标卡：
   - 异常总数 / 待处理 / 处理中 / 已处理 / 需补证据 / 处理完成率
3. Tab 按处理状态切换：全部、待处理、处理中、已改判、已确认正常
4. 可按处理人筛选
5. 每条点击「处理」进入样本详情，可提交人工改判

> 评审时要看哪几条样本把结论拉偏：切到「影响分析」页，通道维度和样本 Top 偏离排行都在那里。
