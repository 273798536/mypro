## 1. 产品概述

整数拆分讲解器是一款面向小学奥数教师的整数拆分可视化教学工具。核心解决三个痛点：手工列举拆分方案易遗漏、条件过滤后结果难以追溯、重复排列与方案爆炸缺乏预警。目标是让教师能快速生成、筛选、讲解所有拆分方案，并在课堂上直观展示递归过程与异常结论。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 奥数教师 | 直接访问，无需注册 | 生成拆分、设置条件、导入材料、导出截图 |

### 2.2 功能模块

1. **工作台页面**：输入面板（目标整数、限制条件、材料导入）、递归生成过程展示、方案结果表格（含去重排序）、异常提示区、截图导出
2. **历史记录页面**：所有计算会话列表、材料来源追溯、修正痕迹时间线、会话对比

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 目标输入区 | 输入目标整数（1~100），设置拆分模式（有序/无序）、最小/最大加数、加数个数限制 |
| 工作台 | 条件过滤区 | 支持多条件组合：加数范围、奇偶性、是否允许重复加数、自定义谓词表达式 |
| 工作台 | 递归过程展示 | 实时展示递归树生成过程，高亮当前分支、剪枝节点、最终路径，可逐步播放 |
| 工作台 | 方案结果区 | 展示去重排序后的全部方案，标注被过滤掉的方案及原因，支持展开查看单条方案详情 |
| 工作台 | 异常提示区 | 方案数超过阈值时弹出爆炸警告、重复排列标记、条件漏用检测提示 |
| 工作台 | 材料导入区 | 支持导入目标整数、限制条件、拆分方案、学生答案、课堂备注、讲解截图，选择忽略/覆盖/追加策略 |
| 工作台 | 截图导出区 | 一键导出当前方案展示为 PNG 图片，包含标题、条件、方案列表 |
| 历史记录 | 会话列表 | 按时间倒序展示所有计算会话，可搜索、删除、恢复 |
| 历史记录 | 来源追溯 | 展示每次计算的数据来源（手动输入/文件导入），保留导入元信息 |
| 历史记录 | 修正时间线 | 展示每次参数修改或条件变更的记录，可回溯到任意历史状态 |
| 历史记录 | 会话对比 | 选取两个会话并排对比方案差异 |

## 3. 核心流程

用户打开工作台 → 输入目标整数和限制条件（或导入材料）→ 点击生成 → 递归过程逐步展示 → 查看去重排序后的方案结果 → 根据异常提示调整条件 → 过滤后查看最终方案 → 导出截图或保存会话 → 可随时查看历史记录追溯修正痕迹

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深板岩色 (#1e293b) 背景 + 暖黄粉笔色 (#fbbf24) 强调色，模拟黑板粉笔课堂氛围
- **辅助色**：薄荷绿 (#34d399) 表示正确/有效方案，珊瑚红 (#f87171) 表示异常/警告
- **字体**：标题使用 LXGW WenKai（霞鹜文楷）营造手写板书感，正文使用 Noto Sans SC 保证可读性
- **按钮风格**：圆角微凸，粉笔质感边框，hover 时有粉笔灰散落微动效
- **布局**：左右分栏，左侧输入+控制，右侧结果+展示，底部可展开修正痕迹时间线
- **图标风格**：lucide-react 线性图标，统一暖色调描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 工作台 | 目标输入区 | 数字输入框、拆分模式切换、范围滑块、深色卡片容器 |
| 工作台 | 条件过滤区 | 条件标签（可增删）、下拉选择器、开关切换 |
| 工作台 | 递归过程展示 | 树状可视化（SVG/Canvas）、播放控制条、步骤计数器 |
| 工作台 | 方案结果区 | 表格布局、行展开详情、过滤掉方案灰色显示+删除线、分页器 |
| 工作台 | 异常提示区 | 顶部横幅通知、图标+文字+操作按钮 |
| 工作台 | 材料导入区 | 文件上传区（拖拽）、策略选择单选组、导入预览表格 |
| 工作台 | 截图导出区 | 导出按钮、预览模态框、下载链接 |
| 工作台 | 修正时间线 | 底部抽屉式面板、时间线节点、条件变更对比 |
| 历史记录 | 会话列表 | 卡片列表、搜索框、日期筛选、删除确认弹窗 |
| 历史记录 | 来源追溯 | 标签式来源标记、元信息浮层 |
| 历史记录 | 会话对比 | 双栏并排、差异高亮 |

### 4.3 响应式设计

- 桌面端优先，最小宽度 1024px
- 平板端（768px~1024px）左右分栏改为上下布局
- 移动端暂不优先适配，保证桌面端教学投屏体验
