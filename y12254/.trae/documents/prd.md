## 1. 产品概述

排队论奶茶店是一款基于排队论数学建模的教育小游戏。玩家扮演奶茶店店长，通过配置服务窗口、管理顾客队列来理解排队论核心参数（到达率 λ、服务率 μ、窗口数 c）对系统性能的影响。
- 核心目标：让数学建模学习者在模拟中直观理解排队论，关卡虽少但规则反馈、失败提示和回放复盘完整
- 目标用户：数学建模课程学生、排队论学习者

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 玩家 | 无需注册 | 选择关卡、配置窗口、运行模拟、查看复盘、导出报告 |

### 2.2 功能模块
1. **首页**：关卡选择、规则说明入口
2. **游戏页面**：顾客队列可视化、窗口状态面板、时间轴控制器、事件日志
3. **复盘页面**：回放播放器、窗口配置对比、等待分布图表、报告导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 关卡列表 | 展示3个递进关卡（M/M/1 → M/M/c → M/M/c含异常），每关显示难度标签和排队论模型标注 |
| 首页 | 规则说明 | 弹窗展示游戏规则：顾客卡含义、窗口操作、失败条件、预约机制 |
| 游戏页面 | 顾客队列 | 动态展示等待队列，每张顾客卡显示：预约号、到达时间、制作时长、等待计时、状态标签 |
| 游戏页面 | 窗口面板 | 展示各服务窗口当前状态（空闲/服务中/停用），正在服务的顾客卡缩略信息，进度条 |
| 游戏页面 | 时间控制 | 播放/暂停、加速(1x/2x/4x)、手动步进，当前模拟时间显示 |
| 游戏页面 | 事件日志 | 实时滚动日志，标注异常事件（爽约/停用/时长异常）并关联触发源 |
| 游戏页面 | 失败提示 | 弹出式提示，显示触发原因→卡点位置→建议下一步 |
| 游戏页面 | 窗口配置 | 侧边栏或弹窗，调整窗口数量、启用/停用窗口，显示参数影响预测 |
| 复盘页面 | 回放播放器 | 时间轴拖拽回放，标注关键事件节点 |
| 复盘页面 | 窗口配置面板 | 显示本局实际窗口配置随时间变化 |
| 复盘页面 | 等待分布图 | 柱状图展示顾客等待时间分布，标注均值/中位数/P95 |
| 复盘页面 | 报告导出 | 下载JSON/CSV报告，包含窗口结论、事件链、顾客卡详情；页面摘要与文件内容一致 |
| 复盘页面 | 详情关联链 | 每条记录展示：顾客卡ID ↔ 窗口编号 ↔ 报告条目索引，方便复核 |

## 3. 核心流程

玩家选择关卡 → 查看初始参数(λ,μ,c) → 配置窗口 → 启动模拟 → 观察队列与窗口实时状态 → 遭遇异常时收到失败提示(触发源+卡点+下一步) → 调整窗口配置继续 → 模拟结束进入复盘 → 回放关键事件 → 查看等待分布与窗口配置 → 导出报告 → 核对详情关联链

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：奶茶暖棕(#C8956C) + 奶白(#FFF8F0) + 焦糖深棕(#5D3A1A)
- 辅助色：窗口空闲绿(#6BCB77)、服务中橙(#FF9F45)、停用红(#FF6B6B)、异常紫(#9B59B6)
- 按钮风格：圆角胶囊按钮，微投影，hover时轻微上浮
- 字体：标题用ZCOOL XiaoWei(站酷小薇)，正文用Noto Sans SC
- 布局风格：卡片式布局，顶部导航，游戏区域左右分栏（队列 | 窗口）
- 图标风格：lucide-react线性图标，搭配少量emoji装饰（🧋🥤📋）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 关卡列表 | 3张横向排列卡片，每卡含模型名、难度星标、参数预览、开始按钮 |
| 游戏页面 | 顾客队列 | 左侧纵向队列，每张顾客卡为小卡片：预约号、制作时长、等待计时动画 |
| 游戏页面 | 窗口面板 | 右侧网格展示窗口，每格含状态色条、进度条、顾客缩略 |
| 游戏页面 | 时间控制 | 底部工具栏：播放/暂停、速度切换、时间显示 |
| 游戏页面 | 事件日志 | 右下角可折叠面板，异常行高亮，点击跳转对应顾客卡 |
| 复盘页面 | 回放播放器 | 顶部时间轴，可拖拽，事件节点可点击 |
| 复盘页面 | 等待分布图 | Canvas柱状图，底部标注统计指标 |
| 复盘页面 | 详情关联链 | 表格：顾客卡ID | 窗口号 | 报告条目 | 跳转链接 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度1024px
- 游戏区域在窄屏下队列和窗口改为上下布局
- 复盘页面图表自适应宽度

### 4.4 3D场景指导
- 不适用，本项目为2D界面
