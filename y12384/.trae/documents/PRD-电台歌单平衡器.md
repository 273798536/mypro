## 1. 产品概述

电台歌单平衡器是一个AI辅助的歌单编排复盘工具，解决电台节目编排中同艺人连播、广告撞歌、新歌过密等问题。通过可视化的冲突检测、版本追溯和编排报告，帮助编排人员快速定位问题、追溯原因并进行人工修正。

- **核心价值**：将手工排查的多线索（歌曲库、新歌权重、广告时段）自动归并，实现从一条结果到歌单约束、权重排序、冲突提示的全链路追踪
- **目标用户**：电台节目编排人员、音乐总监、内容审核团队

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 编排人员 | 系统账号 | 查看歌单、检测冲突、查看报告、人工修正 |
| 音乐总监 | 系统账号 | 调整权重参数、查看历史版本、导出报告 |

### 2.2 功能模块

1. **歌单总览页**：歌单时间轴、冲突热力图、关键指标概览
2. **冲突详情页**：同艺人连播/广告撞歌/新歌过密的详细分析、溯源跳转
3. **版本对比页**：历史版本对比、人工修正记录、样本数据追溯
4. **编排报告页**：完整的编排分析报告、冲突来源说明、改进建议

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 歌单总览页 | 时间轴视图 | 按时间轴展示歌曲播放序列，用颜色标记冲突类型，点击可跳转详情 |
| 歌单总览页 | 冲突热力图 | 按时间段展示冲突密度，快速定位问题区域 |
| 歌单总览页 | 指标卡片 | 同艺人连播次数、新歌密度、广告冲突数、约束满足率 |
| 冲突详情页 | 冲突溯源链 | 展示"触发材料 → 约束规则 → 检测算法 → 冲突提示"的完整链路 |
| 冲突详情页 | 关联跳转 | 从冲突点跳转到歌曲库详情、权重配置、版本历史 |
| 冲突详情页 | 人工修正 | 标注已处理、添加备注、调整排序列 |

| 编排报告页 | 报告概览 | 统计摘要、关键发现、改进建议 |

| 编排报告页 | 冲突分析 | 每个冲突的详细成因分析和触发材料来源 |

## 3. 核心流程

用户上传或选择歌单 → 系统自动检测三类冲突（同艺人连播/广告撞歌/新歌过密） → 可视化展示冲突位置和严重程度 → 点击冲突点查看完整溯源链 → 进行人工修正 → 生成编排报告 → 保存版本历史

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝 (#1a237e) - 专业、稳重，适合数据分析工具
- **辅助色**：琥珀橙 (#ff8f00) - 警告提示；薄荷绿 (#2e7d32) - 正常状态；砖红 (#c62828) - 严重冲突
- **按钮风格**：微圆角 (6px)，轻微阴影，悬停时有微妙的上浮动效
- **字体**：标题使用 Playfair Display（优雅专业），正文使用 Source Sans Pro（清晰易读）
- **布局风格**：卡片式布局，多层级信息架构，时间轴贯穿核心页面
- **图标风格**：线性图标，简洁现代，配合微妙的颜色编码

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 歌单总览页 | 时间轴视图 | 横向时间轴、彩色标记点、悬停详情卡片、缩放控制 |
| 歌单总览页 | 冲突热力图 | 网格热力图、颜色渐变图例、点击跳转 |
| 冲突详情页 | 溯源链 | 竖向连接的卡片、箭头指示流向、可展开的详情节点 |
| 编排报告页 | 报告概览 | 大号数字指标、趋势小图表、分区内容块 |

### 4.3 响应性

- **桌面优先**：1440px 作为基准设计宽度
- **平板适配**：1024px 时侧边栏收起为图标模式，卡片宽度自适应
- **触屏优化**：可点击区域最小 44x44px，滚动行为自然流畅

### 4.4 动效设计

- 页面加载：内容从下往上渐入，时间差 50ms 的错峰动画
- 悬停效果：卡片轻微上浮 (translateY(-2px))，阴影加深
- 冲突标记：脉冲动画吸引注意力，强度根据严重程度调整
- 溯源链：节点展开时的平滑高度过渡
