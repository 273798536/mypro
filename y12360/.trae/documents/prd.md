## 1. 产品概述

水泵相似律计算本地服务，帮助水务工程师快速估算水泵换转速后流量、扬程和功率的变化，替代现场经验判断，确保选型准确。
- 解决现场凭经验选泵容易出错的问题，将相似律三公式（流量比=转速比、扬程比=转速比²、功率比=转速比³）落地为可追溯的计算服务
- 目标用户：水务工程师、泵站运维人员，价值在于减少选型失误、保留完整计算与校验记录

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 工程师 | 新建计算、提交复核、查看结果、导出报告 |
| 审核人 | 复核计算、推进状态、标记问题 |

### 2.2 功能模块
1. **计算工作台**：输入水泵参数与目标转速，实时计算流量/扬程/功率变化，校验输入合法性
2. **方案对比**：同一水泵多转速方案并列对比，含效率校验
3. **计算记录**：所有计算记录列表，支持按状态/日期/来源筛选，可追溯完整链路
4. **报告导出**：单条或批量导出计算报告（JSON/CSV），含来源与版本信息

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 计算工作台 | 参数输入区 | 输入额定流量/扬程/功率/转速、目标转速、单位制选择，实时显示校验警告 |
| 计算工作台 | 结果展示区 | 显示相似律计算结果（新流量/扬程/功率）、效率校验、校验警告详情 |
| 计算工作台 | 方案对比区 | 多方案并排对比，高亮差异项 |
| 计算记录 | 记录列表 | 分页展示，状态标签（草稿/已复核/已批准/已归档），来源与版本号 |
| 计算记录 | 筛选与搜索 | 按状态/日期范围/来源筛选，关键字搜索 |
| 计算详情 | 追溯链路 | 从结果追溯到相似律计算→效率校验→方案对比，展示每步参数与版本 |
| 计算详情 | 状态推进 | 草稿→已复核→已批准→已归档，操作留痕 |
| 报告导出 | 导出面板 | 选择记录/格式，生成并下载报告文件 |

## 3. 核心流程

用户打开计算工作台 → 输入水泵参数（额定流量Q₁、扬程H₁、功率P₁、转速n₁）和目标转速n₂ → 系统实时校验（单位混用/转速越界/工况缺失）→ 计算相似律结果（Q₂=Q₁×n₂/n₁、H₂=H₁×(n₂/n₁)²、P₂=P₁×(n₂/n₁)³）→ 效率校验 → 保存为草稿 → 提交复核 → 审核人复核通过 → 批准 → 可导出报告。

```mermaid
    "显示警告并标注受影响结果" --> "相似律计算（标注受影响项）"

    "退回修改" --> "输入水泵参数"

```

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深蓝灰（#1e293b）+ 水蓝强调色（#0ea5e9），体现水务行业专业感
- 辅色：琥珀色（#f59e0b）用于警告，翡翠绿（#10b981）用于通过状态
- 按钮风格：圆角（8px），填充色按钮为主，边框按钮为辅
- 字体：JetBrains Mono 用于数值展示，Noto Sans SC 用于中文正文
- 布局：顶部导航 + 侧边状态栏，卡片式内容区
- 图标：lucide-react 图标库，线性风格

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 计算工作台 | 参数输入区 | 表单卡片，输入框带单位选择器，实时校验红框+警告图标 |
| 计算工作台 | 结果展示区 | 三列数值卡片（流量/扬程/功率），变化百分比标签，警告行高亮 |
| 计算工作台 | 方案对比区 | 多列对比表格，差异单元格高亮 |
| 计算记录 | 记录列表 | 表格+状态徽章，行操作按钮（查看/复核/导出） |
| 计算详情 | 追溯链路 | 垂直时间线组件，每步节点可展开查看参数快照 |
| 报告导出 | 导出面板 | 全选/多选复选框，格式选择下拉框，下载按钮 |

### 4.3 响应式
- 桌面优先设计，最小宽度 1024px
- 表格在窄屏下横向滚动
- 方案对比在窄屏下切换为上下堆叠

### 4.4 3D 场景
- 不适用
