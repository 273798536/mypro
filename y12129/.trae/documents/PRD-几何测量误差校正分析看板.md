## 1. 产品概述

几何测量误差校正分析看板，面向质检工程师的专业分析工具。解决夹具偏移判定争议、测量数据混批、误差溯源困难等问题，通过最小二乘算法实现精准误差校正，确保图表、明细、下载数据完全同源。

- 核心价值：让每条质量判断都可追溯到原始测量数据，避免批次混入导致的错误结论
- 目标用户：质检工程师、计量校准人员、生产质量管理人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 质检工程师 | 本地应用，无需注册 | 导入数据包、执行误差校正、查看分析结果、导出报告 |

### 2.2 功能模块

1. **分析看板主页面**：数据包导入、批次选择、核心算法执行、结果可视化
2. **测量点明细面板**：单条记录溯源、设计尺寸对比、复测记录展示
3. **误差校正详情**：最小二乘拟合曲线、夹具偏移量计算、校正前后对比
4. **数据导出**：同源CSV/JSON导出，确保图表与下载数据一致性

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 分析看板 | 数据导入区 | 支持拖拽导入测量数据包，自动识别测量点、批次信息、校正报告 |
| 分析看板 | 批次筛选器 | 按批次号、测量时间、夹具编号筛选，自动标记疑似混批记录 |
| 分析看板 | 误差校正图表 | 最小二乘拟合曲线、公差带显示、校正前后误差对比折线图 |
| 分析看板 | 测量点明细表 | 展示所有测量点，每行带溯源链接，异常记录高亮显示 |
| 分析看板 | 溯源抽屉 | 点击记录后展示原始数据快照、设计尺寸、复测记录全链路 |
| 分析看板 | 统计摘要卡 | 夹具偏移量、平均误差、合格率、异常记录数等关键指标 |
| 分析看板 | 数据导出区 | 一键导出当前分析批次的完整数据包（CSV+JSON） |

## 3. 核心流程

用户导入测量数据包 → 系统自动解析并识别数据类型 → 执行最小二乘拟合计算 → 标记异常记录（点位缺失、批次混入） → 用户选择批次查看校正结果 → 点击单条记录溯源 → 导出同源分析报告

```mermaid
flowchart LR
    A["导入数据包"] --> B["解析测量点/批次/报告"]
    B --> C["最小二乘拟合计算"]
    C --> D["异常检测<br/>（点位缺失/混批）"]
    D --> E["批次筛选与分组"]
    E --> F["误差校正分析"]
    F --> G["图表展示与明细"]
    G --> H["单条记录溯源"]
    H --> I["同源数据导出"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：工业蓝 `#1e3a8a` 作为主色，配合精密灰 `#374151`，异常警示红 `#dc2626`，合格绿 `#059669`
- **辅助色**：公差带橙色半透明 `rgba(249, 115, 22, 0.1)`，拟合曲线科技蓝 `#3b82f6`
- **按钮风格**：直角矩形，2px边框，hover时轻微上浮+阴影加深，体现精密仪器感
- **字体**：等宽字体 `JetBrains Mono` 用于数值展示，`Noto Sans SC` 用于中文说明
- **布局风格**：工业控制面板风格，分区明确，卡片带细边框和轻微阴影，数据网格对齐
- **图标风格**：线性图标，简洁精准，避免圆润可爱风格

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI Elements |
|-----------|-------------|-------------|
| 分析看板 | 顶部工具栏 | 深色背景，导入按钮、批次选择下拉、导出按钮、当前批次信息 |
| 分析看板 | 统计卡片区 | 4张数据卡片，大字号数值+趋势箭头，网格布局 |
| 分析看板 | 主图表区 | 左上方折线图，显示拟合曲线与公差带，右侧误差分布图 |
| 分析看板 | 数据表格区 | 下方全宽表格，斑马纹，异常行红底高亮，操作列带溯源按钮 |
| 分析看板 | 溯源抽屉 | 右侧滑出，三栏布局：原始数据、设计尺寸、复测记录 |
| 分析看板 | 状态栏 | 底部显示数据来源文件名、记录数、计算时间戳 |

### 4.3 响应性

- Desktop-first设计，最小支持1280px宽度
- 表格支持横向滚动，图表自适应容器宽度
- 抽屉在小屏幕变为底部滑出面板
- 关键数值在所有尺寸下保持清晰可读

### 4.4 交互动效

- 数据加载：骨架屏+进度条，计算完成时数字滚动动画
- 异常标记：呼吸灯效果提醒质检工程师注意
- 抽屉滑出：300ms ease-out 过渡
- 悬停行：背景色加深，左侧显示2px宽主色指示条
- 图表数据点：hover时显示十字准线+详细数据tooltip
