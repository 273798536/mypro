## 1. 产品概述

收益预测区间校准工具，解决销量预测汇报中业务不信任预测区间的问题。针对热门品类常被低估、冷门品类区间过宽的痛点，以覆盖率为主线，批量校准预测区间，智能标注异常情况。

- 核心目标：让数据分析师能快速验证预测质量，输出业务可解释的校准结果
- 目标用户：数据分析师、业务分析人员
- 市场价值：提升预测可信度，减少"热门估低、冷门估宽"的系统性偏差

## 2. 核心特征

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 数据分析师 | 无需注册，本地工具 | 上传数据、运行校准、查看结果、导出报告 |

### 2.2 功能模块

1. **数据上传页**：文件上传、数据预览、脏数据检测
2. **校准分析页**：覆盖率主线展示、分组校准面板、异常标注侧边栏
3. **结果导出页**：错误行单独列表、校准结果下载、分析报告生成

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据上传页 | 文件上传区 | 支持CSV/Excel上传，拖拽或点击选择，实时解析进度 |
| 数据上传页 | 数据预览表 | 显示前10行数据，高亮空值和异常格式，统计脏数据比例 |
| 数据上传页 | 字段映射配置 | 自动识别预测值、真实值、上下限、品类、时间等字段，支持手动调整 |
| 校准分析页 | 覆盖率主线看板 | 大字号展示整体覆盖率，分品类覆盖率趋势图，目标覆盖率对比线 |
| 校准分析页 | 分组校准面板 | 按热门/冷门/普通分组展示，校准前后区间对比，校准系数建议 |
| 校准分析页 | 异常标注侧边栏 | 可筛选的异常列表：促销异常、样本过少、覆盖不足、明显坏值 |
| 校准分析页 | 坏值样例专区 | 突出展示最严重的坏预测样例，用红色卡片标注，一键查看详情 |
| 结果导出页 | 错误行列表 | 单独列出所有脏行，标注重复、空值、格式错误类型，支持单独导出 |
| 结果导出页 | 校准结果下载 | 完整校准结果CSV，包含原始值、校准后区间、覆盖率标签 |
| 结果导出页 | 分析报告 | 自动生成HTML报告，包含核心指标、问题分类、改进建议 |

## 3. 核心流程

用户上传包含预测值、真实销量、置信区间的CSV/Excel文件 → 系统自动解析并标记脏数据（不中断）→ 配置字段映射 → 运行校准算法：计算覆盖率→分组识别→区间校准→异常检测 → 查看覆盖率为主线的分析结果 → 筛选异常类别 → 导出校准结果和错误行清单

```mermaid

    A["上传数据文件"] --> B["解析并检测脏数据"]
    B --> C["配置字段映射"]
    C --> D["计算覆盖率（主线）"]
    D --> E["分组校准（热门/冷门）"]
    E --> F["异常检测与标注"]
    F --> G["可视化展示"]
    G --> H["筛选查看异常"]
    H --> I["导出结果+错误清单"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 #0F3460（专业、可信），辅助色：珊瑚橙 #E94560（异常警示）、薄荷绿 #16C79A（正常通过）
- **按钮风格**：圆角8px，悬停有微阴影，危险操作按钮加红边
- **字体**：标题用 Playfair Display（衬线，权威感），正文用 Inter（清晰易读）
- **布局风格**：三栏布局，中间主栏展示覆盖率主线，左侧分组校准，右侧异常标注
- **图标风格**：线性图标，异常用实心红色图标突出，正常状态用空心图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据上传页 | 文件上传区 | 大虚线框，拖拽动画，文件图标浮动效果 |
| 数据上传页 | 数据预览表 | 斑马纹行，空值单元格浅红背景，鼠标悬停显示备注 |
| 校准分析页 | 覆盖率主线看板 | 大数字带趋势箭头，环形进度图，分品类柱状图 |
| 校准分析页 | 分组校准面板 | 卡片式分组，校准前后区间对比条，滑动条调整校准系数 |
| 校准分析页 | 异常标注侧边栏 | 标签式筛选，列表项带状态圆点，展开显示详情 |
| 校准分析页 | 坏值样例专区 | 红边卡片，警告图标，预测值与真实值对比条形图 |
| 结果导出页 | 错误行列表 | 可排序表格，错误类型标签，批量选择导出 |

### 4.3 响应性

- 桌面端为主（1280px+），三栏布局
- 平板端（768-1280px）：两栏布局，异常栏折叠为抽屉
- 移动端（<768px）：单栏堆叠，覆盖率置顶

### 4.4 数据可视化指导

- **覆盖率环形图**：蓝色填充，未覆盖部分用灰色，目标线用虚线标注
- **分组校准对比**：每组用不同透明度的蓝色，校准后区间用实心，校准前用虚线
- **异常散点图**：横轴预测值，纵轴真实值，正常点蓝色，异常点红色，坏值用大尺寸橙色圆点
- **热门/冷门分类**：用箱线图展示销量分布，阈值线用红色虚线
