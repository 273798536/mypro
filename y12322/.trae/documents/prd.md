## 1. 产品概述

积分近似误差教具——面向大学助教的数值积分可视化与复盘工具。支持输入函数表达式与积分区间，自动检测奇点附近、区间反向、步长过大等边界情形，计算结果与原始材料严格分离存储，同批函数反复运算不累积偏差，截图导出与报告导出均携带边界提示，确保课堂演示与事后复盘口径一致。

- 目标用户：大学数学/数值分析课程助教
- 核心价值：让助教在课堂演示和课后复盘中，对积分近似误差的来源一目了然，尤其不再因奇点与步长问题而遗漏关键结论

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 助教 | 直接使用，无需注册 | 导入材料、运行积分、查看结果、导出报告与截图 |

### 2.2 功能模块

1. **工作台页面**：函数表达式输入/导入、步长设置、积分区间设置、课堂备注、一键计算、边界提示面板、结果可视化、截图导出、报告导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 函数表达式输入区 | 支持手动输入或从文本文件/JSON导入函数表达式，每次导入标记为"原始材料"，计算结果标记为"处理结果" |
| 工作台 | 积分参数区 | 步长设置（含过大提示）、积分区间端点（含反向检测与奇点附近检测） |
| 工作台 | 课堂备注区 | 独立文本区，与函数表达式来源分离，可单独导入 |
| 工作台 | 计算引擎 | 梯形法/辛普森法数值积分，同一批函数重跑结果幂等不漂移 |
| 工作台 | 边界提示面板 | 实时显示奇点附近警告、区间反向警告、步长过大警告，提示内容与导出报告口径一致 |
| 工作台 | 结果可视化 | 函数曲线图+积分区域填充+误差标注，支持辛普森法与梯形法对比 |
| 工作台 | 截图导出 | 将当前可视化图表+边界提示+函数表达式一起导出为PNG图片 |
| 工作台 | 报告导出 | 导出完整文本报告，包含函数表达式、参数、计算结果、边界提示（奇点/反向/步长过大）、课堂备注 |

## 3. 核心流程

用户打开教具 → 输入或导入函数表达式与参数 → 系统自动检测边界情形（奇点/反向/步长过大）→ 显示边界提示 → 执行数值积分计算 → 可视化展示结果与误差 → 用户可截图导出或报告导出（均携带边界提示内容）

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰蓝（#1e293b）搭配琥珀色（#f59e0b）作为警告/强调色，青绿（#10b981）作为正确/结果色
- 辅助色：浅灰背景（#f8fafc），白卡片，红色（#ef4444）用于严重警告
- 按钮风格：圆角6px，带微妙阴影，hover时加深
- 字体：JetBrains Mono 用于数学表达式，Noto Sans SC 用于中文界面
- 布局风格：左侧参数输入面板 + 右侧可视化面板，卡片式分区
- 图标风格：线条型 lucide-react 图标

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 函数表达式输入区 | 卡片容器，等宽字体输入框，"导入"按钮，来源标签（原始材料/处理结果），删除按钮 |
| 工作台 | 积分参数区 | 卡片容器，步长滑块+数字输入，区间端点输入，方法选择（梯形法/辛普森法） |
| 工作台 | 课堂备注区 | 卡片容器，文本域，独立导入按钮 |
| 工作台 | 边界提示面板 | 固定在右侧可视区顶部，三色标签（琥珀=奇点，红=反向，橙=步长过大），可展开详情 |
| 工作台 | 结果可视化 | Canvas/SVG图表区域，函数曲线+填充+误差标注，方法切换标签页 |
| 工作台 | 导出操作栏 | 底部固定栏，"截图导出"按钮（相机图标），"报告导出"按钮（文件图标） |

### 4.3 响应式

- 桌面优先设计，左右双栏布局
- 平板端堆叠为上下布局
- 手机端全宽堆叠，参数面板可折叠
