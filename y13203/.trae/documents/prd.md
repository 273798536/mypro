## 1. 产品概述

巡演耳返异常提醒系统——面向巡演音频团队的专业工具，用于追踪、批注和复盘耳返通道异常事件。核心价值：每一次判断变更都留有影响范围和来源行，换班交接时不再靠人口头解释。

- 解决问题：巡演临时改动容易漏通知，边界样本影响结论时缺乏可追溯解释，人工批注覆盖旧判断后无法复盘
- 目标用户：录音师、音频工程师、项目经理（换班交接时自行跑通）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 音频工程师 | 默认进入 | 查看异常、添加批注、授权备注 |
| 项目经理 | 默认进入 | 查看全部、跑通提醒、复盘历史 |

### 2.2 功能模块

1. **异常提醒与分析页**：异常列表、边界样本分析、批注覆盖、授权备注入口
2. **变更溯源与对齐页**：变更历史时间线、文件-曲目表-清单对齐校验、授权备注影响追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 异常提醒与分析 | 异常列表 | 按通道/场次列出所有异常条目，标注状态（待处理/已确认/已覆盖） |
| 异常提醒与分析 | 边界样本分析 | 对处于判定边界的样本，展示其特征值、阈值线和"为什么它影响结论"的三段式解释（数据→阈值→影响） |
| 异常提醒与分析 | 批注覆盖 | 手动批注覆盖旧判断时，自动记录：被覆盖判断原文、影响范围（哪些文件/曲目受影响）、来源行（批注引用的原始数据行号） |
| 异常提醒与分析 | 授权备注 | 输入授权备注（如音频文件夹备注），提交后触发对齐校验，展示判断变更清单 |
| 变更溯源与对齐 | 变更历史 | 时间线展示所有变更：谁、何时、改了什么、影响范围、来源行；支持按场次/通道筛选 |
| 变更溯源与对齐 | 对齐校验 | 文件夹↔曲目表↔最后清单三方对齐，标注对齐/偏移状态，点击偏移项可查看具体差异 |
| 变更溯源与对齐 | 授权备注影响 | 输入授权备注后，自动列出：该备注改变了哪些判断、哪些文件被重新对齐、哪些仍偏移 |

## 3. 核心流程

### 3.1 日常异常处理流程

录音师打开系统 → 查看异常列表 → 点击边界样本查看影响解释 → 添加人工批注（系统自动记录影响范围和来源行）→ 批注覆盖旧判断 → 变更写入历史

### 3.2 授权备注对齐流程

录音师补入授权备注（如音频文件夹备注）→ 系统重新计算文件-曲目表-清单对齐 → 展示对齐结果和判断变更清单 → 确认后变更写入历史

### 3.3 换班复盘流程

项目经理打开系统 → 查看变更历史时间线 → 筛选本场次变更 → 逐条查看影响范围和来源行 → 对齐校验确认无偏移 → 完成交接

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰 #1A1A2E + 琥珀色 #F59E0B 警告高亮 + 翠绿 #10B981 确认状态
- 按钮风格：小圆角（4px）、扁平按钮，授权操作用琥珀色实底突出
- 字体：标题用 JetBrains Mono（工程感），正文用 Noto Sans SC
- 布局：左侧固定导航 + 右侧内容区，内容区上下分区
- 图标：线性图标，与音频工程仪表盘风格一致
- 整体美学：工业仪表盘 / 控制台风格，深色主题，信息密度高但不拥挤

### 4.2 页面设计总览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 异常提醒与分析 | 异常列表 | 紧凑表格，行高36px，状态用色点标记，行可展开查看详情 |
| 异常提醒与分析 | 边界样本分析 | 横向阈值图：当前值线 + 阈值区段 + 三段式文字解释卡片 |
| 异常提醒与分析 | 批注覆盖 | 内联编辑：点击判断值即可覆盖，覆盖后原值灰显保留，右侧弹出影响范围面板 |
| 异常提醒与分析 | 授权备注 | 顶部输入区 + 提交后下方展开判断变更清单 |
| 变更溯源与对齐 | 变更历史 | 垂直时间线，每条变更卡片含：时间、操作人、变更摘要、影响范围标签、来源行号 |
| 变更溯源与对齐 | 对齐校验 | 三列对齐视图：文件夹 | 曲目表 | 清单，对齐行用连线，偏移行用红点+差异文字 |
| 变更溯源与对齐 | 授权备注影响 | 变更清单：每条含原判断→新判断，标注是否已对齐 |

### 4.3 响应式

- 桌面优先（1920px/1440px）
- 最小支持 1024px 宽度
- 平板横屏可正常使用

不适用
