# 供应链预付款口径对账 · 风控复核工作台

## 两三步就能上手

1. **启动**：`npm install` → `npm run dev`，浏览器打开 http://localhost:5173
2. **看异常**：仪表盘上点击任意一条异常流水，直接跳到该笔的银行流水 + 双口径计算规则
3. **补备注 / 导出**：在详情页填补充备注（勾选受影响的判断项）→ 保存自动记录历史 → 右上角"导出复核说明"拿截图+文字说明

---

## 坏材料来了，先看哪里

| 坏材料场景 | 去哪里看 | 怎么处理 |
|------------|----------|----------|
| 同一笔钱被供应链预付款和运营费用两个口径都认走 | 详情页 → **"双口径计算规则对比"**，两个色块并排，冲突项有琥珀色竖条高亮 | 先补一条备注说明哪条规则该改，勾选受影响的判断，保存后系统自动写入历史 |
| 审批人改了名（张建均 → 张建军） | 详情页 → **"审批人改名提示"** 蓝色卡，四步 Checklist | 每做完一步打勾，系统记录处理进度；四步全完再复核判断是否还成立 |
| 补录备注后结论变了 | 详情页 → **"历史变更记录"** 时间线 | 点开任一条可看到：旧结论（删除线）/ 新备注 / 改判原因 / 引用的旧材料 |
| 导出时要保证截图和文字一致 | 详情页右上角 **"导出复核说明"** | 先点"生成页面截图预览"，系统同时生成文字说明，两者一一对应再下载 |
| 周一早会临时补一条流水备注 | 详情页 → **"临时补录备注"** 模块 | 填内容 + 改判原因 + 勾选受影响规则，保存后该流水卡片会显示"有补充备注"标记 |
