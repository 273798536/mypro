## 1. 产品概述

冷却塔水滴参数回放系统——面向设备工程师和算法值班人，解决传感器日志中后补备注丢失、安全阈值变更无痕迹、中间计算过程不透明三大痛点。系统保留每一次参数变更的完整历史（包括后补备注和旧版本截图），让"为什么这条备注影响了结论"可追溯、可复盘。

- 目标用户：冷却塔设备工程师（老何等）、算法值班人
- 核心价值：从传感器日志中还原参数演变全貌，后补备注的影响链路可解释，安全阈值变更永不被误读为"正常通过"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 设备工程师 | 直接访问 | 查看回放、添加后补备注、查看异常队列 |
| 算法值班人 | 直接访问 | 参数对照、查看中间计算过程、单位换算、重跑回放 |

### 2.2 功能模块

1. **参数回放页**：时间轴驱动的参数回放、历史备注面板、后补备注影响链路展示、中间计算过程与单位换算
2. **异常队列页**：异常记录列表、安全阈值变更标记、处理结果区分（正常通过 vs 阈值变更 vs 后补备注修正）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 参数回放页 | 时间轴 | 可拖拽时间轴，定位到任意时刻的参数快照，时间轴上标注备注节点、阈值变更节点 |
| 参数回放页 | 参数图表 | 显示水滴直径、流速、温度等关键参数随时间变化的折线图，阈值线用虚线标注 |
| 参数回放页 | 历史备注面板 | 展示当前时刻所有备注（含后补），后补备注标注"后补"标签和补入时间，点击后补备注展示影响链路 |
| 参数回放页 | 影响链路弹窗 | 后补备注→影响了哪些参数→最终如何改变结论，逐步展示推理过程 |
| 参数回放页 | 中间计算面板 | 展示两组参数对照时的中间计算步骤和单位换算过程，不隐藏任何推导 |
| 参数回放页 | 旧版本截图区 | 嵌入传感器日志中的旧版本参数截图，保留原始视觉记录 |
| 异常队列页 | 异常列表 | 列出所有异常记录，每条标注来源类型（安全阈值变更 / 参数超限 / 后补备注修正） |
| 异常队列页 | 处理结果标签 | 安全阈值变更记录标记为"阈值变更"（非"正常通过"），后补备注修正标记为"备注修正" |
| 异常队列页 | 状态一致性指示器 | 重启/重跑后，校验历史备注数量、当前状态、异常队列条目是否一致，不一致则红色警告 |

## 3. 核心流程

### 3.1 参数回放流程

用户打开参数回放页 → 时间轴加载全部历史节点 → 用户拖拽时间轴到目标时刻 → 参数图表刷新显示该时刻数据 → 历史备注面板展示该时刻所有备注（含后补）→ 用户点击后补备注 → 弹出影响链路窗口 → 逐步展示备注如何影响结论

### 3.2 异常队列流程

用户打开异常队列页 → 查看异常列表 → 每条异常带来源类型标签（阈值变更/超限/备注修正）→ 点击异常条目 → 展开详情含中间计算和单位换算 → 重跑后校验一致性

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青灰色（#1a2332）背景 + 琥珀色（#f59e0b）强调色 + 冰蓝色（#38bdf8）辅助色
- 按钮：圆角矩形，主操作琥珀色填充，次要操作线框
- 字体：JetBrains Mono（数据/代码区域）+ Noto Sans SC（中文正文）
- 布局：左侧时间轴 + 中间图表区 + 右侧备注/计算面板
- 图标风格：线性描边（Lucide），工业监控仪表盘风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 参数回放页 | 时间轴 | 垂直时间轴、节点带类型图标（备注/阈值变更/快照）、拖拽手柄、缩放控制 |
| 参数回放页 | 参数图表 | 折线图、阈值虚线、悬浮数据点、后补备注标记点 |
| 参数回放页 | 历史备注面板 | 卡片列表、"后补"橙色标签、补入时间戳、点击展开影响链路 |
| 参数回放页 | 影响链路弹窗 | 步骤式流程图：备注内容→影响参数→结论变化，每步用箭头连接 |
| 参数回放页 | 中间计算面板 | 计算公式展示、单位换算标注、两组参数左右对照表 |
| 异常队列页 | 异常列表 | 表格行、来源类型彩色标签（阈值变更=红、超限=橙、备注修正=蓝） |
| 异常队列页 | 一致性指示器 | 顶部状态条，绿色=一致、红色=不一致+差异详情 |

### 4.3 响应式

桌面优先设计，最小支持1280px宽度。时间轴在窄屏下折叠为顶部水平滚动条。

### 4.4 3D场景

不适用
