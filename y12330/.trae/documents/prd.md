## 1. 产品概述

谱聚类社群拆分工具面向社区运营分析师，解决用户标签与时间窗口互相冲突导致社群划分不稳定的问题。通过谱聚类算法将用户互动网络拆分为稳定社群，并提供完整的数据溯源、质量检测和结果导出能力。

- 目标用户：社区运营分析师及其同事
- 核心价值：将谱聚类这条线稳定下来，让分析师能自行导入数据、看图、点明细、带走结果，且全链路可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 社区运营分析师 | 无需注册，直接使用 | 导入数据、执行聚类、查看可视化、导出结果 |
| 协作同事 | 无需注册，直接使用 | 导入样例数据、查看可视化与明细 |

### 2.2 功能模块

1. **数据导入页**：导入互动边、用户标签、活动记录，追踪来源与版本
2. **聚类分析页**：执行谱聚类、调节参数、查看社群评分与异常节点
3. **可视化图页面**：力导向图展示社群结构、孤立节点高亮、点击节点查看明细
4. **结果溯源页**：从单条结果追踪到谱聚类参数、社群评分和异常节点，导出结果

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 数据源面板 | 支持上传互动边CSV（源用户、目标用户、权重、时间戳）、用户标签CSV（用户ID、标签列表）、活动记录CSV（用户ID、活动类型、时间戳） |
| 数据导入页 | 来源与版本追踪 | 记录每个数据源的文件名、导入时间、数据版本号、行数统计，合并后生成数据集版本快照 |
| 数据导入页 | 数据质量预检 | 导入后自动检测孤立节点、活动噪声、标签缺失，显示受影响的节点数和边数，标注影响范围 |
| 聚类分析页 | 参数面板 | 设置聚类数K、相似度阈值、权重衰减系数，显示当前参数组合的版本号 |
| 聚类分析页 | 执行与进度 | 一键执行谱聚类，显示计算进度，完成后弹出社群概览 |
| 聚类分析页 | 社群评分表 | 每个社群的模块度、紧密度、节点数、边数、评分等级，点击可跳转到可视化图 |
| 聚类分析页 | 异常节点列表 | 标注孤立节点、噪声节点、标签缺失节点，说明影响哪些社群和结果 |
| 可视化图页面 | 力导向图 | D3力导向图展示社群结构，不同社群不同颜色，孤立节点用虚线圈标注 |
| 可视化图页面 | 节点明细面板 | 点击节点显示用户ID、所属社群、标签、活动记录、异常标记 |
| 可视化图页面 | 质量标注叠层 | 在图上叠加数据质量标注（孤立节点红色闪烁、噪声节点橙色标记、缺失标签灰色虚线） |
| 结果溯源页 | 溯源链条 | 从任意结果节点展开完整溯源链：结果 → 社群评分 → 聚类参数 → 数据源版本 → 质量检测记录 |
| 结果溯源页 | 导出面板 | 导出CSV/JSON，包含社群划分、评分、异常标记、溯源信息 |

## 3. 核心流程

用户导入互动边数据 → 系统自动检测数据质量（孤立节点、噪声、缺失） → 用户确认质量报告 → 设置聚类参数 → 执行谱聚类 → 查看社群评分和异常节点 → 在可视化图中浏览社群结构 → 点击节点查看明细 → 追溯到聚类参数和数据源 → 导出结果

```mermaid
flowchart TD
    "A[导入数据]" --> "B[数据质量预检]"
    "B" --> "C{有质量问题?}"
    "C" -->|"是"| "D[展示质量报告，标注影响范围]"
    "C" -->|"否"| "E[设置聚类参数]"
    "D" --> "E"
    "E" --> "F[执行谱聚类]"
    "F" --> "G[社群评分与异常节点列表]"
    "G" --> "H[可视化图浏览]"
    "H" --> "I[点击节点查看明细]"
    "I" --> "J[溯源到参数和数据源]"
    "J" --> "K[导出结果]"
```

孤立节点失败路径（关键测试场景）：

```mermaid
flowchart TD
    "A[导入仅含互动边的数据]" --> "B[检测到孤立节点]"
    "B" --> "C[质量报告：标注孤立节点及其影响]"
    "C" --> "D[执行聚类时孤立节点单独成组]"
    "D" --> "E[社群评分：孤立节点组标记为异常]"
    "E" --> "F[可视化图：孤立节点红色闪烁+虚线圈]"
    "F" --> "G[溯源：孤立节点 → 影响的社群 → 聚类参数 → 数据源]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1a1f36）背景 + 青绿（#00d4aa）强调色，营造数据分析专业感
- 辅助色：琥珀色（#f59e0b）用于异常/警告，红色（#ef4444）用于错误/孤立节点
- 按钮风格：圆角微凸（rounded-lg + shadow-sm），主按钮青绿填充，次按钮描边
- 字体：DM Sans（正文）+ JetBrains Mono（数据/代码），层次分明
- 布局风格：左侧导航栏 + 右侧内容区，卡片式模块排列
- 图标风格：Lucide 线性图标，16-20px

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 数据源面板 | 三列卡片（互动边/标签/活动），每卡片含上传区域、文件名、版本号、行数统计，拖拽上传 |
| 数据导入页 | 来源与版本追踪 | 时间线组件，每条记录显示文件名、导入时间、版本号、数据快照ID |
| 数据导入页 | 数据质量预检 | 三色预警卡片（红/橙/灰），展开后显示受影响的节点列表和影响范围说明 |
| 聚类分析页 | 参数面板 | 滑块+数字输入框，实时预览参数影响 |
| 聚类分析页 | 社群评分表 | 表格，每行可展开详情，评分等级用色条标注 |
| 聚类分析页 | 异常节点列表 | 带图标标注的列表，点击跳转可视化图对应节点 |
| 可视化图页面 | 力导向图 | 全屏D3画布，缩放/平移/框选，右侧浮动面板显示选中节点信息 |
| 可视化图页面 | 质量标注叠层 | 图上叠加半透明标注层，开关控制 |
| 结果溯源页 | 溯源链条 | 树形展开组件，从结果到数据源的完整链路 |
| 结果溯源页 | 导出面板 | 下拉选择格式，预览前10行，一键下载 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 可视化图页面支持全屏模式
- 表格和列表在小屏幕下支持横向滚动
