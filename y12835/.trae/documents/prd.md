## 1. 产品概述

细胞冻存复苏台账是一套本地化实验室信息管理系统，解决细胞冻存、复苏全流程中培养记录断裂、显微照片漏页、标注边界不清导致导出失真等问题。目标用户为实验室技师（日常操作）和科研学生（查阅结果）。

- 核心价值：让每条培养记录从试剂批号到最终结论形成完整可点击链路，异常复核自动追溯到来源材料，学生一眼分清可用与待复核数据
- 场景：从空目录起步，通过 curl 或脚本即可跑完完整流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 实验室技师 | 本地登录 | 增删改查所有记录、导入导出、异常复核确认 |
| 科研学生 | 本地登录（只读视图） | 查阅台账、查看分组统计与谱系追踪、下载导出 |

### 2.2 功能模块

1. **台账总览页**：统计卡片、最近操作、异常提醒
2. **培养记录页**：冻存/复苏记录 CRUD、显微照片附件、试剂批号关联
3. **分组统计页**：按细胞系/批号/时间分组汇总，可视化图表
4. **谱系追踪页**：细胞传代链路可视化、从子代回溯到原始冻存管
5. **异常复核页**：标注异常记录、追溯到来源材料、复核确认流程
6. **数据导入页**：批量导入、重复检测、导入预览与确认

## 3. 核心流程

### 3.1 冻存记录创建流程

1. 技师进入培养记录页，点击"新增冻存记录"
2. 填写细胞系、代次、冻存日期、冻存液配方、试剂批号
3. 上传显微照片（至少 1 张），系统校验照片是否关联到记录
4. 如缺少照片或关键字段，系统给出可操作提示（如"缺少冻存前显微照片，请上传 P0 代照片"）
5. 保存后记录进入台账，状态标记为"直接可用"或"待复核"

### 3.2 复苏记录与谱系追踪

1. 技师新增复苏记录，关联源冻存管编号
2. 系统自动建立传代链路，谱系追踪页更新
3. 如复苏后存活率异常，自动标记"待复核"并推送至异常复核页

### 3.3 异常复核流程

1. 系统自动检测异常（缺照片、标注冲突、存活率异常）
2. 异常复核页列出异常记录，附带可操作提示
3. 技师查看异常，点击追溯到来源培养记录与试剂批号
4. 填写复核意见，更新状态为"复核通过"或"复核未通过"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色 (#0F766E) + 琥珀色 (#D97706) 强调色，传达实验室严谨与生命力
- 辅助色：石板灰 (#475569) 用于正文，翠绿 (#10B981) 表示"直接可用"，琥珀 (#F59E0B) 表示"待复核"，红色 (#EF4444) 表示"异常"
- 按钮：圆角 6px，主按钮填充色，次按钮描边
- 字体：正文 Source Sans 3 / 标题 Playfair Display
- 布局：左侧固定导航栏 + 右侧内容区，卡片式内容组织
- 图标：lucide-react 图标集

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 台账总览页 | 统计卡片 | 4 张统计卡片（深青渐变背景 + 白色数字），hover 上浮效果 |
| 台账总览页 | 最近操作 | 紧凑表格，状态标签（圆角药丸形），行 hover 高亮 |
| 台账总览页 | 异常提醒 | 黄色边框卡片，异常类型图标 + 可操作文字链接 |
| 培养记录页 | 记录列表 | 筛选栏 + 分页表格，状态标签颜色编码 |
| 培养记录页 | 记录详情 | 左右分栏：左侧字段 + 右侧照片缩略图网格 |
| 培养记录页 | 试剂追溯 | 面包屑路径 + 关联记录时间线 |
| 分组统计页 | 分组汇总 | 选项卡切换分组维度，下方图表区 |
| 分组统计页 | 图表展示 | Recharts 柱状图/折线图/饼图，图表主题匹配主色调 |

| 数据导入页 | 导入确认 | 逐行确认表格，操作列含下拉菜单 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1024px
- 导航栏在窄屏折叠为汉堡菜单
- 表格在窄屏切换为卡片列表
- 图表在窄屏切换为简化视图

### 4.4 学生视图特殊设计

- 状态标签突出显示："✓ 直接可用"（绿色）vs "⚠ 待复核"（琥珀色）
- 待复核记录附带提示文字："此记录需实验室技师复核后使用"
- 学生视图隐藏删除按钮和复核操作，仅显示查阅与导出
