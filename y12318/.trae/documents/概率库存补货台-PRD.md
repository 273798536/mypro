## 1. 产品概述

概率库存补货台是一款面向零售数据分析师的专业补货决策工具，解决销售历史备注变更、促销日历版本迭代导致的口径混乱问题。核心目标：让分析师自行导入样例数据、可视化查看、钻取明细、导出结果，并在销售历史与库存快照结论不一致时保留缺货记录作为补充证据，确保从任一结果可追溯至概率预测、安全库存和补货建议全链路。

- 目标用户：零售企业数据分析师、库存规划师、供应链运营人员
- 核心价值：消除多版本数据口径混乱，保留关键决策证据链，实现补货分析全程可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 零售数据分析师 | 无需注册，直接使用 | 导入数据、查看分析、导出结果 |
| 库存规划师 | 无需注册，直接使用 | 查看补货建议、追溯证据链、核验异常 |

### 2.2 功能模块

1. **数据导入台**：销售历史导入、促销日历导入（支持多版本）、库存快照导入、缺货记录导入、版本差异检测、冲突预警
2. **概览分析台**：概率库存分布图、安全库存水位图、补货建议汇总表、口径一致性状态、异常标记与筛选
3. **详情溯源台**：单品补货决策详情、概率预测曲线、安全库存计算过程、证据链时间线（含缺货记录、负库存快照、需求突增标记、到货延迟标记）、结果导出（一致性校验）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入台 | 数据源卡片组 | 四个独立卡片（销售历史、促销日历、库存快照、缺货记录），每个支持 CSV/Excel 拖拽上传，显示导入状态和行数 |
| 数据导入台 | 版本差异面板 | 促销日历新版本导入后自动对比差异，标注新增/修改/删除的促销档期 |
| 数据导入台 | 口径冲突预警 | 销售历史备注变更与库存快照结论不一致时，弹出冲突列表并标记严重程度 |
| 数据导入台 | 样例数据加载 | 一键加载内置样例数据集，方便快速体验全流程 |
| 概览分析台 | 概率库存分布图 | 按品类/门店展示库存概率分布热力图，颜色映射缺货概率 |
| 概览分析台 | 安全库存水位图 | 柱状图对比当前库存与安全库存水位，低于安全线的标红 |
| 概览分析台 | 补货建议汇总表 | 表格列出所有 SKU 的补货建议（补货量、优先级、置信度），支持排序筛选 |
| 概览分析台 | 口径一致性状态栏 | 顶部状态条显示销售历史与库存快照的结论一致率，点击跳转冲突详情 |
| 概览分析台 | 异常标记筛选器 | 按异常类型筛选：需求突增、到货延迟、负库存被覆盖、备注变更 |
| 详情溯源台 | 补货决策卡片 | SKU 名称、当前库存、安全库存、补货量、置信度、概率预测区间 |
| 详情溯源台 | 概率预测曲线 | 折线图展示未来 14 天需求概率分布，含 P50/P75/P90 三条曲线 |
| 详情溯源台 | 安全库存计算过程 | 展示安全库存的计算公式和各参数来源（服务水准、需求标准差、补货周期） |
| 详情溯源台 | 证据链时间线 | 垂直时间线展示所有影响该 SKU 决策的证据节点：缺货记录、负库存快照、需求突增标记、到货延迟、备注变更，每个节点可展开查看详情 |
| 详情溯源台 | 结果导出面板 | 导出 CSV/Excel，导出前自动校验库存快照结论与页面摘要一致性，不一致则拦截并提示 |

## 3. 核心流程

用户打开应用后，可先加载样例数据体验，也可直接导入自己的数据。导入后系统自动检测版本差异和口径冲突，在概览分析台展示分析结果。用户点击任意 SKU 进入详情溯源台，查看完整的概率预测、安全库存计算和证据链。导出结果时系统自动校验一致性。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深炭灰 (#1A1D23) 为背景底色，搭配钢蓝 (#4A90D9) 为功能色，琥珀 (#E8A838) 为警告色，翡翠绿 (#34C759) 为正常状态色
- **辅助色**：柔和的卡片背景 (#22262E)，边框线 (#2D3139)，文字分层（白 #F5F5F7 / 灰 #8E8E93 / 淡灰 #636366）
- **按钮风格**：圆角 6px，功能色填充按钮为主操作，描边按钮为次操作，悬浮有微妙光影
- **字体**：数据展示用 JetBrains Mono（等宽数字），标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式模块布局，表格带斑马纹
- **图标风格**：线性图标，2px 描边，统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 数据导入台 | 数据源卡片组 | 四张等宽卡片，每张含拖拽区域（虚线边框 + 上传图标）、文件名、行数、状态标签；卡片底部含"加载样例"按钮 |
| 数据导入台 | 版本差异面板 | 左右对比布局，旧版左侧（灰色背景）、新版右侧（蓝色背景），差异行高亮黄色 |
| 数据导入台 | 口径冲突预警 | 顶部横幅式预警条，红色/橙色/黄色三级，可展开查看冲突明细列表 |
| 概览分析台 | 概率库存分布图 | 热力图，行=品类，列=门店，颜色从绿到红映射缺货概率，悬浮显示具体数值 |
| 概览分析台 | 安全库存水位图 | 分组柱状图，每组两根柱（当前库存 vs 安全库存），低于安全线区域填充红色半透明 |
| 概览分析台 | 补货建议汇总表 | 宽表格，列含 SKU、品类、当前库存、安全库存、补货量、置信度、优先级标签、异常标记图标；行悬浮高亮，点击跳转详情 |
| 概览分析台 | 口径一致性状态栏 | 顶部窄条，进度条样式，绿色=一致，红色=冲突，显示百分比和点击入口 |
| 概览分析台 | 异常标记筛选器 | 标签组（Pill 按钮），可多选：需求突增、到货延迟、负库存被覆盖、备注变更 |
| 详情溯源台 | 补货决策卡片 | 大卡片，左侧关键数字（补货量、置信度大字号），右侧参数明细列表 |
| 详情溯源台 | 概率预测曲线 | 面积折线图，三条曲线（P50 实线蓝、P75 虚线灰、P90 点线琥珀），当前库存水平线红色 |
| 详情溯源台 | 安全库存计算过程 | 公式展示区 + 参数卡片，每个参数可点击查看数据来源 |
| 详情溯源台 | 证据链时间线 | 垂直时间线，左侧时间戳，右侧事件卡片（图标 + 标题 + 展开详情），不同类型不同图标和颜色 |
| 详情溯源台 | 结果导出面板 | 底部固定栏，导出按钮 + 格式选择（CSV/Excel），一致性校验状态指示灯 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 导航栏在 1024px 以下折叠为图标模式
- 卡片网格在 1440px 以上为四列，1280-1440 为两列
- 表格在小屏支持横向滚动

### 4.4 动效设计

- 页面切换：淡入淡出 200ms
- 数据导入完成：卡片状态标签从"解析中"脉冲动画变为"已完成"打勾
- 冲突预警：预警条从顶部滑入，轻微抖动吸引注意
- 时间线节点：交错淡入，每个节点延迟 80ms
- 图表加载：柱状图从底部生长，折线从左到右绘制
