# 数学向量投影工坊 - 快速启动

## 从零开始运行

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开 http://localhost:5173/
```

## 功能说明

### 📊 三种投影方案
1. **正交投影** - 基于标准正交基的投影计算
2. **斜投影** - 支持非正交基的广义投影
3. **坐标轴投影** - 投影到 XY 平面（固定基）

### 📌 保留原始值
- 侧边栏始终显示输入的原始向量坐标
- 诊断系统基于原始输入进行分析
- 导出截图包含当前标注状态

### 🔍 分开诊断（不笼统）
系统会分别检测并说明：
- ✅ **基底正交性** - e₁ 与 e₂ 夹角是否为 90°
- ⚠️ **坐标越界** - 坐标绝对值是否超过建议范围
- ❌ **分量反号** - 基底点积为负时提示风险
- ℹ️ **基底长度** - 提示单位化建议

### 👁️ 读数标注联动
- 坐标值、长度、夹角可独立开关
- 切换投影方案时标注自动更新
- 标注位置随 3D 视角实时同步

### 📸 截图导出
- 点击「导出截图」直接下载 PNG
- 文件名包含方案名和时间戳
- 截图保留当前所有标注显示状态
