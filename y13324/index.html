筛选条件、统计数字、明细表与 CSV 明细由同一套结果生成；泄漏样本单独隔离；模型换版本后旧的人工判断不被覆盖；坏数据可溯源到原始行。

使用说明

  1. 本看板为自包含单文件，双击 index.html 即可在浏览器打开，无需安装任何环境。
  2. 用下方筛选栏选择「模型版本 / 年级 / 题型 / 数据状态 / 仅看缺引用」，统计、明细表、CSV 会同步同源刷新。
  3. 缺引用样本会以黄底标注，统计区显示「结论待补」，不展示无保留的肯定结论。
  4. 点击「人工修正区」里的原始行号，可定位到明细表对应行并高亮。
  5. 点「导出 CSV」下载当前筛选结果（与明细表同源）。
