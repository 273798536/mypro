# 化学装置流程卡片

一个用于化学装置流程图评分复盘的 Web 应用。

## 功能特性

- **评分表导入**: 支持 Excel/CSV 格式的评分表导入，自动解析字段
- **异常筛选**: 快速筛选出有异常的记录，支持按严重程度和状态过滤
- **详情追溯**: 点击记录查看详情，保留原始行号、图片名和来源备注
- **网格标注**: 支持网格吸附的异常标注功能，可精确绘制标注框
- **图层管理**: 控制不同类型数据的显示，支持锁定和隐藏
- **数据导出**: 导出结果与界面显示一致，包含汇总、评分记录和异常记录
- **颜色规则**: 内置颜色标注规则速查，版本信息清晰可见

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

应用将在 http://localhost:3000 打开

### 3. 第一份样例

应用启动后，默认加载了 `src/data/sampleData.ts` 中的样例数据。

样例数据位置: `src/data/sampleData.ts`

包含:
- 5 条评分记录（包含不同状态和异常类型）
- 4 条异常记录（包含素材缺失、连接错误等）
- v2.0 版本的颜色标注规则

## 使用说明

### 状态说明

| 颜色 | 状态 | 说明 |
|------|------|------|
| 🟢 绿色 | 通过 | 可直接使用 |
| 🟡 黄色 | 待确认 | 需要进一步确认 |
| 🟠 橙色 | 需复核 | 请找航拍剪辑复核 |
| 🔴 红色 | 驳回 | 有问题，需重新提交 |

### 评分表页面

1. **搜索筛选**: 输入装置名称或图片名搜索
2. **状态筛选**: 按审核状态过滤记录
3. **异常筛选**: 只看有异常或无异常的记录
4. **快速改状态**: 在操作列直接修改记录状态
5. **查看详情**: 点击整行打开详情弹窗

### 标注画布页面

1. **选择工具**: 点击工具栏中的异常类型按钮
2. **绘制标注**: 在画布上拖拽绘制矩形标注
3. **网格吸附**: 开启后自动对齐到网格
4. **移动标注**: 选中标注后可拖拽移动
5. **删除标注**: 选中后点击"删除选中"按钮

### 异常面板

1. **筛选异常**: 按严重程度或处理状态筛选
2. **查看详情**: 点击异常卡片查看完整信息和处理建议
3. **来源追溯**: 每条异常都关联原始行号和图片信息

### 图层管理

1. **显隐控制**: 点击眼睛图标切换图层可见性
2. **锁定状态**: 🔒 图标表示图层已锁定
3. **数据统计**: 显示每个图层包含的数据项数

### 导入/导出

**导入**:
- 支持格式: .xlsx, .xls, .csv
- 自动识别字段: 装置名称、状态、分数、图片名、备注等
- 保留原始行号

**导出**:
- 导出为 Excel 文件
- 包含三个 Sheet: 汇总、评分记录、异常记录
- 导出内容与页面显示状态一致

## 导入文件格式要求

Excel/CSV 文件应包含以下列（列名近似匹配即可）:

| 推荐列名 | 说明 |
|----------|------|
| 装置名称 / 设备 | 装置名称（必填） |
| 类别 / 分类 | 装置类别 |
| 颜色 / 色标 | 颜色代码或名称 |
| 状态 / 审核结果 | 审核状态 |
| 分数 / 得分 | 评分分数 |
| 满分 / 总分 | 满分值 |
| 异常 / 问题 | 异常描述 |
| 图片名 / 文件名 | 关联图片文件名 |
| 备注 / 说明 | 其他备注信息 |
| 处理人 / 负责人 | 处理人员 |
| 原始行号 | 自动生成 |

```
│   ├── Header.tsx       # 顶部导航（导入/导出）
│   ├── Sidebar.tsx      # 侧边栏（概览、规则）
│   ├── ScoreTable.tsx   # 评分表格
│   ├── AnomalyPanel.tsx # 异常列表面板
│   ├── LayerPanel.tsx   # 图层管理面板
│   ├── GridCanvas.tsx   # 网格标注画布
│   └── DetailModal.tsx  # 详情弹窗
├── context/
│   └── AppContext.tsx   # 全局状态管理
├── data/
│   └── sampleData.ts    # 样例数据
├── types/
│   └── index.ts         # TypeScript 类型定义
├── utils/
│   └── index.ts         # 工具函数
├── App.tsx              # 主应用组件
├── main.tsx             # 入口文件
└── index.css            # 全局样式
```
