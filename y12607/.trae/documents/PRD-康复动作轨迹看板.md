## 1. 产品概述

康复动作轨迹看板是面向康复医疗场景的数据审核工具，解决离线素材缺失导致评分判断失效的问题。通过统一的处理记录池，实现图层管理与命中检测数据同源，导入后自动筛出异常，详情可追溯评分表来源与处理意见，导出结果面向非技术人员可读。

- 核心问题：截图素材晚到导致图层遮挡判断失效，界面与报告数据不一致，导出结果难以理解
- 目标用户：康复治疗师、数据审核员、质量管理人员
- 价值：异常可追溯、数据同源、导出友好，验收时可沿异常反向查到评分表与处理意见

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 审核员 | 本地登录（演示用） | 导入评分表、查看异常、追溯详情、导出结果 |

### 2.2 功能模块

1. **看板首页**：导入入口、异常概览统计、异常记录列表、筛选条件
2. **异常详情页**：评分表原始数据、素材缺失说明、来源追溯、处理意见
3. **说明文档页**：启动、导入、查看异常、导出结果四步操作指南

## 3. 核心流程

用户导入康复评分表后，系统自动检测离线素材缺失等异常并在列表中标注。用户点击异常记录查看详情，可追溯评分表来源、图层检测记录和处理意见。确认后可导出面向非技术人员的可读报告。

```mermaid
flowchart LR
    A["启动系统"] --> B["导入评分表"]
    B --> C["系统自动检测异常"]
    C --> D["异常列表展示"]
    D --> E["点击异常查看详情"]
    E --> F["追溯评分表+图层记录+处理意见"]
    F --> G["导出可读报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：沉稳的医疗蓝 `#1e40af`，辅以警示红 `#dc2626` 标记异常
- 中性色：以 slate 灰为基底，表格清晰易读
- 按钮风格：直角矩形，边框明显，hover 有轻微阴影
- 字体：系统无衬线字体，标题加粗，正文清晰
- 布局：顶部导航 + 左侧筛选 + 右侧主内容区，数据密度适中
- 图标风格：lucide 线性图标，简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 看板首页 | 统计卡片 | 四张卡片横向排列，数字突出，图标在左 |
| 看板首页 | 记录表格 | 斑马纹行，异常行红底浅红文字，状态标签彩色 |
| 看板首页 | 筛选面板 | 左侧固定，下拉选择 + 日期范围 |
| 异常详情页 | 信息区块 | 卡片式分组，每块有标题，字段左对齐 |
| 异常详情页 | 追溯链路 | 时间线样式展示从评分表到异常的完整路径 |
| 说明文档页 | 步骤说明 | 编号步骤，代码块展示命令，简洁清晰 |

### 4.3 响应式

桌面端优先，1200px 以上最佳显示；平板端折叠筛选面板；移动端横向滚动表格。

## 5. 数据要求

### 5.1 样例数据特点

贴近日常真实场景：
- 包含旧格式评分表（字段不全）
- 有补录备注记录
- 存在漏填单位的记录
- 混合正常、待处理、已处理三种状态
- 素材缺失原因包含："截图未上传"、"视频帧损坏"、"图层标记不全"等口语化描述

### 5.2 导出格式

- Excel 格式，面向非技术人员
- 列名使用中文全称，避免缩写和字段名
- 异常原因用自然语言描述，不显示内部编码
- 包含处理建议列，便于转交后续处理
