# 采样包授权台账系统

专为音乐制作人设计的采样包授权管理与风险预警系统。

## 核心特性

### 📊 数据统一管理
- 图表、明细、下载文件来自同一批数据，确保一致性
- 支持脏数据智能清洗和备注解析
- 自动字段补全和格式修复

### ⚠️ 智能风险预警
- **授权过期检测**：精确计算剩余天数，提供明确结论
- **同名采样检测**：自动发现重名采样包，给出可操作的修正建议
- **商用限制检查**：检测非商用授权在商业项目中的使用风险
- **署名要求提醒**：追踪需要署名的采样包使用情况

### 🔄 版本追踪与对比
- 每次修改自动创建数据快照
- 支持任意两个版本的完整对比
- 清晰展示新增风险、已解决风险和变更内容
- 验收时可直观看到修改前后的差别

### 📥 多格式导出
- Excel 导出（多工作表）
- JSON 导出
- 风险报告导出

## 快速开始

### 安装依赖
```bash
npm install
```

### 启动开发服务

同时启动后端和前端：
```bash
npm run dev:full
```

或者分别启动：

后端服务 (端口 3001):
```bash
npm run server
```

前端开发服务 (端口 3000):
```bash
npm run dev
```

### 访问应用
打开浏览器访问: http://localhost:3000

## 验收测试指南

### 测试修改授权协议后的版本对比

1. **初始状态**：
   - 进入「版本历史」标签页，查看初始快照
   - 记录当前的风险状态

2. **修改授权协议**：
   - 在「风险概览」中找到「即将到期的授权」
   - 点击任意授权的「续期」按钮
   - 输入新的到期日期（如：2025-12-31）

3. **查看变化**：
   - 系统自动创建新的快照
   - 进入「版本历史」标签页
   - 选择初始版本，点击「与最新版本对比」
   - 查看：
     - **变更的项目**：显示授权日期的修改
     - **已解决风险**：过期风险消失
     - 所有数据来源一致，图表和明细同步更新

### 主要功能模块

| 模块 | 功能说明 |
|------|---------|
| 风险概览 | 风险分布图表、时间线、风险预警明细、到期提醒、同名检测 |
| 授权管理 | 所有授权协议列表、状态标识、类型分类 |
| 采样包 | 采样包清单、供应商、价格、标签 |
| 曲目项目 | 音乐项目、状态追踪、采样使用统计 |
| 版本历史 | 快照列表、版本对比、变更审计 |

## 数据模型

- **SamplePack**：采样包基本信息
- **LicenseAgreement**：授权协议条款
- **TrackProject**：音乐曲目项目
- **SampleUsage**：采样使用记录
- **RiskAlert**：风险预警
- **VersionSnapshot**：版本快照

## API 接口

```
GET    /api/dashboard          # 看板数据
GET    /api/sample-packs       # 采样包列表
GET    /api/licenses           # 授权列表
GET    /api/tracks             # 曲目列表
GET    /api/versions           # 版本列表
GET    /api/versions/compare   # 版本对比
GET    /api/export/excel       # 导出 Excel
GET    /api/export/json        # 导出 JSON
POST   /api/snapshot           # 创建快照
PUT    /api/licenses/:id       # 更新授权
```
