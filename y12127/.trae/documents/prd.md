## 1. 产品概述

多项式插值实验台是一个面向数学教学的交互式工具，旨在让学生直观理解高阶多项式插值在边界处的发散现象（Runge 现象）、重复采样点为何被拒绝、以及噪声对插值结果的放大效应。目标用户为高校数学教师和数值分析课程学生。

- 解决"以为点越多越准"的认知误区，让边界震荡与噪声放大一目了然
- 提供可重复、可对比的实验环境，支撑课堂演示与课后探究

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 教师 | 直接访问 | 导入数据、切换函数类型、手动修正、并排对比 |
| 学生 | 直接访问 | 导入数据、查看实验结果、理解异常提示 |

### 2.2 功能模块

1. **实验台主页**：插值画布（Canvas 绑定函数曲线与插值曲线）、采样点表格、参数面板
2. **两阶段导入面板**：第一阶段导入采样点与函数类型，第二阶段补充噪声参数，系统展示前后变化
3. **边界样例区**：预置重复 x 值、边界震荡（Runge）、噪声放大三类样例
4. **误差分析区**：误差曲线实时渲染、参数对比表、异常提示条
5. **手动修正入口**：修改函数类型后，新旧结果并排展示

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 实验台主页 | 插值画布 | 绘制原始函数曲线、插值多项式曲线、采样点标记，支持缩放平移 |
| 实验台主页 | 采样点表格 | 显示/编辑采样点坐标，重复 x 值标红并阻止，显示被拦原因 |
| 实验台主页 | 参数面板 | 选择函数类型（Runge/Sin/Exp/自定义）、设置插值阶数、噪声参数 |
| 两阶段导入面板 | 第一阶段 | 输入采样点与函数类型，生成无噪声插值结果 |
| 两阶段导入面板 | 第二阶段 | 补充噪声参数（类型、强度），重新计算并对比前后变化 |
| 边界样例区 | 重复 x 值样例 | 预置含重复 x 值的数据集，展示拦截过程与原因说明 |
| 边界样例区 | 边界震荡样例 | Runge 函数高阶等距插值，展示边界处剧烈震荡 |
| 边界样例区 | 噪声放大样例 | 带噪声低阶 vs 高阶对比，展示高阶对噪声的放大 |
| 误差分析区 | 误差曲线 | 实时绘制 |f(x) - P(x)| 曲线，参数变化后自动刷新 |
| 误差分析区 | 参数对比表 | 展示不同参数组合下的最大误差、均方误差等指标 |
| 误差分析区 | 异常提示 | 检测到边界震荡、噪声放大时弹出提示条 |
| 手动修正入口 | 修正面板 | 修改函数类型/参数后，左侧旧结果、右侧新结果并排渲染 |

## 3. 核心流程

用户进入实验台后，可选择"从零开始"或"加载样例"两条路径：

1. **从零开始**：第一阶段输入采样点与函数类型 → 系统校验重复 x 值 → 生成无噪声插值与误差曲线 → 第二阶段补充噪声参数 → 系统重新计算并对比前后变化
2. **加载样例**：选择预置样例（重复 x 值 / 边界震荡 / 噪声放大）→ 自动填充数据并执行插值 → 展示异常现象与提示

手动修正流程：用户在修正面板修改函数类型 → 系统保留旧结果 → 重新计算新结果 → 并排渲染新旧插值曲线与误差曲线

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1a1f36）为底，搭配琥珀色（#f59e0b）作为强调色，营造科学仪器的严谨感
- **次色调**：翠绿（#10b981）用于正确/安全状态，玫红（#f43f5e）用于错误/警告状态
- **按钮风格**：圆角矩形，hover 时微亮，点击时下沉
- **字体**：显示字体用 JetBrains Mono（代码/数据感），正文用 Noto Sans SC（中文友好）
- **布局风格**：左右分栏，左侧画布区占 60%，右侧控制面板占 40%
- **图标风格**：线性图标（lucide-react），与整体简约科技感一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 实验台主页 | 插值画布 | 深色背景 Canvas，网格线半透明，函数曲线用翠绿，插值曲线用琥珀，采样点为圆点 |
| 实验台主页 | 采样点表格 | 深色卡片内嵌表格，重复 x 行标红背景，hover 显示拦截原因 tooltip |
| 两阶段导入面板 | 步骤指示器 | 水平步骤条（1→2），当前步骤高亮琥珀色，已完成步骤翠绿勾 |
| 边界样例区 | 样例卡片 | 三张并排卡片，每张含缩略图与标题，选中时琥珀边框 |
| 误差分析区 | 误差曲线 | 独立 Canvas，玫红填充误差区域，最大误差点标注 |
| 误差分析区 | 异常提示 | 顶部滑入提示条，分 warning（琥珀）和 error（玫红）两级 |
| 手动修正入口 | 并排对比 | 双 Canvas 左右排列，中间竖线分隔，底部参数对比表 |

### 4.3 响应式

- 桌面优先设计，1920×1080 为基准
- 1280px 以下右侧面板折叠为底部抽屉
- 触屏设备采样点支持点击添加
