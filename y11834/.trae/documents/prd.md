## 1. 产品概述

"港口拖轮潮汐战"是一款面向港口拖轮调度培训的交互式模拟游戏。学员扮演调度员，在有限潮汐窗口内为进出港船舶指派拖轮、安排泊位，需同时应对潮汐错过、拖轮冲突、燃油不足、泊位占用等多重约束。核心教学目标：让新人理解潮汐窗口不是抽象概念，而是真实影响调度成败的关键因素。

- 目标用户：港口拖轮调度课新员工、培训讲师
- 核心价值：将抽象的潮汐窗口/泊位/燃油知识转化为可操作、可感知的模拟体验，每次失败都有明确归因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 调度员（学员） | 执行拖轮指派、泊位分配、时间推进等操作 |
| 讲师 | 可查看调度报告、复盘失败归因 |

### 2.2 功能模块

1. **调度主界面**：港口地图、时间轴、船舶列表、拖轮状态、泊位状态
2. **调度报告页**：每轮结束后展示分类失败原因与调度评分

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 调度主界面 | 港口地图 | 轻量级2D港口俯瞰图，展示泊位位置与船舶动态 |
| 调度主界面 | 时间轴 | 以30分钟为步进的时间轴，标注潮汐高低点、船舶到达时间 |
| 调度主界面 | 船舶列表面板 | 显示待调度/已调度船舶，含潮汐窗口、所需拖轮数、吨位 |
| 调度主界面 | 拖轮状态面板 | 显示各拖轮位置、燃油、当前任务、可用状态 |
| 调度主界面 | 泊位状态面板 | 显示各泊位占用情况、预计释放时间 |
| 调度主界面 | 调度操作区 | 拖轮指派、泊位分配、时间推进按钮 |
| 调度主界面 | 实时反馈栏 | 每次操作后即时弹出分类反馈（潮汐错过/拖轮冲突/燃油不足/泊位占用） |
| 调度报告页 | 失败归因汇总 | 按类型分列所有失败事件，不合并为总分 |
| 调度报告页 | 调度评分 | 各维度分别评分：潮汐管理、拖轮利用率、燃油管理、泊位周转 |

## 3. 核心流程

学员进入调度界面，时间轴从06:00开始自动推进。船舶按预定时间到达港外锚地，学员需在船舶潮汐窗口关闭前完成拖轮指派和泊位分配。每次指派操作即时反馈是否成功及失败原因。当所有船舶完成调度或时间轴到达24:00时，进入调度报告页，展示分类失败归因和各维度评分。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝(#0A1628) + 港口橙(#F59E0B)警报色 + 浅灰蓝(#94A3B8)辅助色
- **按钮风格**：圆角微3D，操作按钮用港口橙，状态按钮用绿/红
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据用 JetBrains Mono
- **布局**：左侧港口地图+时间轴，右侧船舶/拖轮/泊位三栏面板，底部实时反馈栏
- **图标**：Lucide图标 + 自定义船舶/拖轮/泊位SVG简笔图标
- **氛围**：模拟港口调度室暗色环境，关键数据高亮闪烁

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 调度主界面 | 港口地图 | 深色底图，泊位用矩形色块，船舶用三角形箭头，拖轮用小圆点，潮汐水位用渐变填充 |
| 调度主界面 | 时间轴 | 横向条形，潮汐高低点用波浪线标注，当前时间用竖线指示，可拖动跳转 |
| 调度主界面 | 船舶列表 | 卡片式列表，潮汐窗口用倒计时条显示，紧急度用颜色渐变 |
| 调度主界面 | 拖轮状态 | 紧凑卡片，燃油用进度条，任务状态用图标+文字 |
| 调度主界面 | 泊位状态 | 网格布局，占用状态用色块+倒计时 |
| 调度主界面 | 实时反馈栏 | 底部固定栏，按类型分色显示：潮汐错过-紫色，拖轮冲突-红色，燃油不足-橙色，泊位占用-黄色 |
| 调度报告页 | 失败归因 | 四列布局，每类失败独立列表，点击可回溯到具体时间点 |
| 调度报告页 | 维度评分 | 雷达图+数字评分，四轴：潮汐管理/拖轮利用率/燃油管理/泊位周转 |

### 4.3 响应式

桌面优先设计，最低支持1280px宽度。移动端暂不优先适配。

### 4.4 关键交互

- 点击船舶卡片 → 弹出调度面板 → 选择拖轮和泊位 → 确认指派
- 时间轴可手动步进（每次+30分钟），也可自动播放
- 实时反馈栏每条消息5秒后淡出，但可点击展开历史
- 调度报告页的失败项可点击跳转到时间轴对应位置复盘
