## 🎮 操作说明

### 基础交互
| 操作 | 说明 |
|------|------|
| 🖱️ 左键拖动磁体 | 移动磁体位置，场线自动更新 |
| 🔄 右键拖动 | 旋转3D视角 |
| 🔍 滚轮 | 缩放场景 |
| 空格 Space | 暂停/继续场线动画 |
| R 键 | 重置并继续动画 |

### 磁体控制
1. **位置调整**：
   - 使用左侧面板的 X/Y/Z 坐标微调
   - 或直接在3D场景中拖动磁体

2. **磁极方向**：
   - 点击"N极向上"/"S极向上"按钮切换
   - 点击 🔄 按钮快速反向磁极
   - **重要**：磁极变更后场线会自动重新计算

3. **磁场强度**：
   - 拖动滑块调整 (0.1 - 3.0)
   - 强度越高，场线越密集

### 场线参数
| 参数 | 范围 | 建议值 | 说明 |
|------|------|--------|------|
| 采样密度 | 1-10 | 5-7 | 越高场线越平滑，但计算越慢 |
| 场线数量 | 5-50 | 20 | 从磁体发出的场线数量 |
| 场强上限 | 10-500 | 100 | 防止数值溢出的安全阈值 |

> ⚠️ **注意**：采样密度 > 8 时会触发性能警告

## ⚠️ 冲突检测系统

### 什么是配置冲突？
当磁体位置和磁极方向由不同人员维护时，系统会自动检测并展示冲突。

### 冲突类型
1. **📍 位置 vs 磁极方向**
   - 触发条件：位置维护者和磁极维护者先后修改同一磁体
   - 处理方式：选择"保留A方"、"保留B方"或"合并两者"

2. **📊 采样密度 vs 性能**
   - 触发条件：采样密度 > 8
   - 影响：场线计算时间增加 30%-150%

3. **⚡ 场强 vs 稳定性**
   - 触发条件：磁体距离 < 0.3 且强度 > 1.5
   - 风险：可能出现场强"爆炸"

### 如何解决冲突
1. 点击冲突卡片展开详情
2. 查看 A/B 两方的修改内容和时间
3. 选择解决策略：
   - **保留A方**：使用位置维护者的版本
   - **保留B方**：使用磁极维护者的版本
   - **合并两者**：同时应用两方修改（推荐）

## 📋 问题报告系统

系统会自动检测并生成非技术友好的问题报告，可直接转发给同事。

### 常见问题及"人话"解释

#### 1. 🔄 磁极反向未生效
> **人话解释**：就像你把磁铁翻了个面，但系统"忘了"更新场线的走向。
> 
> **为啥会这样**：
> 1. 只点了"反向"按钮，但场线没重新计算
> 2. 或者3D模型翻了，但磁场计算还用的老数据
> 3. 就像你把遥控器反过来按，但电视没反应——遥控器变了，电视没收到信号
>
> **怎么解决**：按一下旁边的"🔄 重新生成场线"按钮就好。

#### 2. 📊 采样过密
> **人话解释**：就像你用显微镜看地图，看得太细了，电脑算不过来。
>
> **为啥会这样**：你把"采样密度"拉太高了。本来只需要画100条线，现在要画1000条。
> 就像老师让你画10个点，你硬要画100个——不是不行，就是手会酸，时间会久。
>
> **怎么解决**：把采样密度滑块往左拉一点，降到5-7之间就好。

#### 3. 💥 场强"爆炸"
> **人话解释**：就像你把两块磁铁N极对N极硬挤在一起，中间的磁场太强了，超出了系统能显示的范围。
>
> **为啥会这样**：
> 1. 两个磁体贴太近了
> 2. 或者磁场强度设得太高
> 3. 就像往气球里吹气太多——不是真的爆炸，是数值太大超出显示范围了
>
> **怎么解决**：把磁体拉开一点距离，或者把"磁场强度"调低一些。

### 使用问题报告
1. 点击问题卡片展开详情
2. 查看"人话版"解释和解决方案
3. 点击"复制报告"按钮，可直接粘贴转发给非技术同事
4. 问题解决后，点击 × 关闭卡片

## 🔄 同步更新机制

**关键原则**：任一参数变更，所有关联模块同步更新。

```
用户操作 → 状态更新 → 同步触发
   │            │
   │            ├─→ 更新3D磁体模型
   │            ├─→ 重新生成磁场线
   │            ├─→ 更新交互说明文字
   │            ├─→ 更新暂停/重置按钮状态
   │            └─→ 检测配置冲突
   │
   └─→ 记录操作历史（用于问题追溯）
```

### 触发同步更新的操作
- ✅ 拖动磁体位置
- ✅ 切换磁极方向
- ✅ 调整磁场强度
- ✅ 修改采样密度
- ✅ 调整场线数量
- ✅ 点击暂停/继续
- ✅ 添加新磁体
- ✅ 重置所有配置

## 🏗️ 技术架构（供技术同事参考）

```
前端应用层
  ├─ React UI 组件
  ├─ 3D 场景渲染 (Three.js + R3F)
  ├─ 状态管理 (Zustand)
  └─ 交互控制模块

业务逻辑层
  ├─ 磁场物理计算引擎 (磁偶极子模型)
  ├─ 参数同步控制器
  ├─ 冲突检测与合并
  └─ 问题报告生成器

数据层
  ├─ 配置状态 Store
  ├─ 历史记录 Store
  └─ 问题知识库
```

### 核心算法
- **磁场计算**：毕奥-萨伐尔定律（磁偶极子近似）
- **场线追踪**：四阶龙格-库塔法
- **性能优化**：空间分区、LOD、按需重计算

## ❓ FAQ

**Q: 为什么磁极反向后场线没变？**
A: 检查是否触发了"磁极反向未生效"问题报告。点击"重新生成场线"按钮即可解决。

**Q: 为什么拖动磁体时画面很卡？**
A: 采样密度设置过高会导致实时计算变慢。尝试将采样密度降到5以下。

**Q: 场强爆炸记录有什么用？**
A: 这些记录可以帮助你定位是哪两个磁体在什么位置导致了异常，方便教学演示时重现特定场景。

**Q: 冲突检测会自动合并吗？**
A: 不会。系统会明确展示冲突，由用户决定如何合并，避免悄悄选一边导致数据丢失。

**Q: 如何导出配置？**
A: 当前版本可通过截图或复制问题报告分享。后续版本将支持JSON配置导入导出。
