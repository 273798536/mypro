# 热泵 COP 估算面板 - 使用说明

## 快速开始

### 1. 启动项目

```bash
# 安装依赖（首次使用）
npm install

# 启动开发服务器
npm run dev
```

启动后在浏览器访问显示的地址（通常是 http://localhost:5173）

### 2. 默认演示数据

系统内置了完整的演示数据，打开页面即可看到：
- 默认机组：美的 AQUA HEAT 10
- 室外温度：7℃
- 供水温度：45℃
- 热负荷：8kW
- 电价：北京居民峰谷电价

## 主要功能操作

### 🎮 3D模型交互

- **旋转视角**：鼠标拖拽3D模型区域
- **缩放**：滚轮滚动
- **查看部件信息**：鼠标悬停在热泵部件上
- **效率颜色指示**：
  - 🟢 绿色：COP ≥ 4.5（优秀）
  - 🔵 蓝色：COP 3.5~4.5（良好）
  - 🟡 黄色：COP 2.5~3.5（一般）
  - 🔴 红色：COP < 2.5（较低）

### ⚙️ 参数配置（左侧面板）

1. **机组型号**：选择不同品牌和型号的热泵
2. **室外温度**：滑动调整 -30℃ ~ 45℃
3. **供水温度**：滑动调整 20℃ ~ 65℃
4. **建筑热负荷**：输入建筑物所需制热量（kW）
5. **电价方案**：
   - 选择地区电价模板
   - 或手动输入峰/平/谷电价
6. **运行时间**：设置每日各时段运行小时数

### 📊 结果查看（右侧面板）

实时显示计算结果：
- COP能效比（大号数字 + 等级标签）
- 制热量、耗电量
- 峰/平/谷时段电费
- 日/月/年电费估算
- COP-温度曲线图表
- 年度月度电费曲线

### 💾 情景管理

1. **保存情景**：调整参数后，点击"保存"按钮，输入名称
2. **选择对比**：点击情景卡片可多选进行对比
3. **加载情景**：点击情景卡片上的上传图标
4. **删除情景**：点击情景卡片上的删除图标

### ⚠️ 风险提示

当参数异常时自动显示：
- 🔴 红色错误：参数超出范围，无法计算
- 🟡 黄色警告：参数可能不合理，建议检查
- 🔵 蓝色提示：合理范围内的提示信息

点击风险提示区域可展开/收起详情，每个提示都包含修正建议。

### 📤 导出功能

1. **导出截图**：导出整个面板的高清截图（PNG格式）
2. **生成报告**：生成PDF格式的估算报告，包含：
   - 机组参数
   - 计算条件
   - 估算结果
   - 风险提示
3. **修订记录**：查看所有参数修改历史

## 异常路径说明

### 1. 温度越界 ❌

**现象**：室外温度设置低于机组最低工作温度或高于最高工作温度

**处理**：
- 显示红色错误提示
- 停止计算，结果区域显示"参数存在错误"
- 提示中给出建议温度范围

**修正方法**：
- 调整室外温度到有效范围
- 或更换适应该温度的机组型号

### 2. 热负荷缺失/异常 ❌

**现象**：热负荷为0或负数，或远大于机组容量

**处理**：
- 0/负数：红色错误，停止计算
- 过大：黄色警告，可继续计算

**修正方法**：
- 输入正确的建筑热负荷值
- 大负荷考虑多机并联方案

### 3. 峰谷电价错误 ⚠️

**现象**：峰电价 ≤ 谷电价

**处理**：
- 黄色警告，可继续计算
- 提示检查电价设置

**修正方法**：
- 通常峰 > 平 > 谷
- 如确有特殊电价，可忽略警告

### 4. 运行时间异常 ❌

**现象**：每日运行时间合计 > 24小时 或 = 0

**处理**：
- 红色错误，停止计算

**修正方法**：
- 调整各时段小时数，合计不超过24小时

## 计算公式

### COP计算
```
COP实际 = COP额定 × 温度修正系数

温度修正系数 = 
  1 - 0.015 × |室外温度 - 额定室外温度|
  - 0.012 × |供水温度 - 额定供水温度|
  - 低温额外修正

系数范围限制：0.4 ~ 1.2
```

### 电费计算
```
小时耗电量 = 热负荷 / COP实际
小时电费 = 小时耗电量 × 对应时段电价
日电费 = Σ(各时段小时电费 × 各时段运行小时数)
月电费 = 日电费 × 30
年电费 = 日电费 × 365
```
