## 1. 产品概述

保险风险地理柱图（Insurance Risk Geographic Bar Chart）是一款面向保险精算团队的 Web3D 可视化工具，用于将不同地区的出险率、保费和赔付额以立体柱图形式呈现在三维地图上，帮助精算分析师快速识别风险集中区域、异常赔付和比例失衡问题。

- 核心价值：将多维保险精算数据以空间可视化方式呈现，解决传统二维表格难以直观发现地区风险差异和极端值遮挡的问题
- 目标用户：保险精算分析师、风险管理团队、精算管理层

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限说明 |
|------|----------|
| 精算分析师 | 导入数据、切换指标、筛选区域、导出截图、查看明细 |
| 精算管理层 | 查看可视化结果、导出报告截图 |

### 2.2 功能模块

1. **3D 地图柱图主页**：三维中国地图 + 立体柱图、指标切换、筛选面板、悬浮信息卡、异常高亮、明细联动面板、数据导入面板、截图导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D 地图柱图主页 | 3D 地图柱图场景 | 基于三维地图的立体柱图展示，柱高映射指标值，支持旋转、缩放、平移交互 |
| 3D 地图柱图主页 | 指标切换面板 | 在出险率、保费、赔付额、保单数之间切换柱图映射维度，支持单指标和多指标对比模式 |
| 3D 地图柱图主页 | 地区筛选面板 | 按省份/区域筛选显示范围，支持多选和全选 |
| 3D 地图柱图主页 | 悬浮信息卡 | 鼠标悬停柱体时弹出地区详细数据卡片（地区名、保单数、出险率、保费、赔付额、精算备注、数据来源、修正记录） |
| 3D 地图柱图主页 | 异常高亮系统 | 自动检测地区合并、极端赔付遮挡、比例误读三种异常，以醒目颜色和图标高亮标记，并提供文字提示 |
| 3D 地图柱图主页 | 明细联动面板 | 点击柱体后右侧展开该地区完整明细，包含修正历史时间线 |

| 3D 地图柱图主页 | 截图导出 | 将当前 3D 视图导出为 PNG 图片，包含当前指标、筛选状态水印 |

## 3. 核心流程

### 3.1 数据导入与可视化流程

1. 用户通过导入面板上传 CSV/JSON 文件
2. 系统解析数据，检测地区名称匹配
3. 若存在重复地区，弹出模式选择（忽略/覆盖/追加）
4. 数据加载后，3D 地图上生成对应柱体
5. 异常检测引擎自动运行，标记异常柱体
6. 用户通过指标切换、筛选、悬浮、点击进行交互分析

### 3.2 异常检测流程

1. **地区合并检测**：若导入数据中同一地区出现多条记录且选择"追加"模式，标记为"地区合并"异常
2. **极端赔付遮挡**：若某地区赔付额超过整体均值的 3 倍标准差，标记为"极端赔付"异常，该柱体用红色描边高亮
3. **比例误读**：若出险率与赔付额/保费比值偏离过大（赔付率 > 200% 或 < 10%），标记为"比例误读"异常

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0A1628) 为底色，搭配冰蓝 (#4FC3F7) 作为数据柱主色、琥珀橙 (#FF8F00) 作为异常高亮色
- **辅色**：翡翠绿 (#00E676) 表示低风险/正常、珊瑚红 (#FF5252) 表示高风险/异常
- **柱体风格**：半透明玻璃质感柱体，带底部光晕，顶部有数值标签
- **字体**：标题使用 Orbitron（科技感），数据使用 JetBrains Mono（等宽清晰），正文使用 Noto Sans SC
- **布局**：左侧为 3D 地图主区域（占 70%），右侧为可收起的控制面板和明细面板（占 30%）
- **图标**：线性图标风格，2px 描边，圆角

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 3D 地图柱图主页 | 3D 地图柱图场景 | 深色背景、半透明蓝色柱体、地区标签、网格地面、环境光+点光源、轨道控制器 |
| 3D 地图柱图主页 | 指标切换面板 | 顶部横向 Tab 切换条，选中态带底部高亮线，支持多指标对比模式开关 |
| 3D 地图柱图主页 | 地区筛选面板 | 右侧面板下拉多选框，带搜索，全选/清空快捷按钮 |
| 3D 地图柱图主页 | 悬浮信息卡 | 跟随鼠标的卡片，毛玻璃背景，显示6项数据+来源+修正记录条数，入场动画 |
| 3D 地图柱图主页 | 异常高亮 | 柱体红色描边脉冲动画 + 顶部警告图标，底部提示栏滚动显示异常汇总 |
| 3D 地图柱图主页 | 明细联动面板 | 右侧滑出面板，顶部地区名+指标摘要，中部数据表，底部修正历史时间线 |
| 3D 地图柱图主页 | 数据导入面板 | 右上角上传按钮，拖拽上传区域，模式选择 Radio 组（忽略/覆盖/追加），导入预览表格 |
| 3D 地图柱图主页 | 截图导出 | 工具栏相机图标按钮，点击后保存 PNG，带当前时间+指标+筛选水印 |

### 4.3 响应式

- 桌面优先设计（1920×1080 最佳体验）
- 1440px 以下右侧面板默认收起，点击展开
- 1024px 以下控制面板移至底部抽屉

### 4.4 3D 场景指引

- **环境**：深色太空感背景，底部带微弱网格地面，远处的星空粒子
- **光照**：环境光 (AmbientLight) + 从上方的定向光 (DirectionalLight) + 柱体底部点光源 (PointLight)
- **相机**：透视相机，45° 俯视角度，支持轨道控制器旋转/缩放/平移，默认缩放至中国地图全景
- **柱体**：CylinderGeometry，半透明材质 (MeshPhysicalMaterial)，底部发光圈 (RingGeometry)，顶部浮动数值标签 (CSS2DRenderer)
- **交互**：鼠标悬浮柱体高亮 + 信息卡，点击柱体展开右侧明细，双击聚焦单个地区
- **动画**：柱体加载时从底部生长动画，异常柱体脉冲发光，指标切换时柱高平滑过渡
- **后处理**：Bloom 效果增强发光体，环境遮蔽 (SSAO) 增强空间感

## 5. 数据模型

### 5.1 数据字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| region | string | 地区名称（省份/直辖市） |
| policyCount | number | 保单数 |
| claimRate | number | 出险率（0-1之间的小数） |
| premium | number | 保费（万元） |
| claimAmount | number | 赔付额（万元） |
| actuarialNote | string | 精算备注 |
| source | string | 数据来源标识 |
| revisionHistory | array | 修正记录数组 |

### 5.2 修正记录结构

| 字段名 | 类型 | 说明 |
|--------|------|------|
| timestamp | string | 修正时间 ISO 格式 |
| field | string | 修正字段名 |
| oldValue | any | 修正前值 |
| newValue | any | 修正后值 |
| reason | string | 修正原因 |

### 5.3 异常类型

| 异常类型 | 触发条件 | 提示文案 |
|----------|----------|----------|
| 地区合并 | 追加模式下同一地区存在多条记录 | "该地区存在合并数据，请注意数值可能为累计值" |
| 极端赔付遮挡 | 赔付额 > 均值 + 3×标准差 | "该地区赔付额极端偏高，可能遮挡其他地区差异，建议使用对数刻度" |
| 比例误读 | 赔付率 > 200% 或 < 10% | "该地区赔付率异常偏离，出险率与赔付额/保费比例不一致，请核实数据" |
