## 1. 产品概述

社区基金财务管理系统——面向社区居委会和物业管理，解决支出申请、发票查重、审批缺页、项目延期等问题，实现从支出归集到凭证校验再到公示状态的全链路追溯，确保导出报告结论与页面摘要一致。

- 核心痛点：发票重复难以发现、项目延期打乱原结论、原始材料与处理结果混淆、问题仅停留在页面提醒而无后续追踪
- 目标用户：社区财务人员、居委会审批人员、居民监督代表

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 财务人员 | 管理员分配 | 创建/编辑支出申请、发票录入、导出报告 |
| 审批人员 | 管理员分配 | 审批支出申请、标记缺页、签署意见 |
| 居民代表 | 管理员分配 | 查看公示、提交居民意见 |
| 管理员 | 系统预设 | 全部权限、用户管理、系统配置 |

### 2.2 功能模块

1. **仪表盘**：财务总览、异常预警（发票重复/审批缺页/项目延期）、最近变更时间线
2. **支出申请**：创建/编辑支出申请、关联发票与审批单、追踪状态流转
3. **发票管理**：发票录入、自动查重检测、重复标记与关联、凭证校验状态
4. **审批追踪**：审批流程可视化、缺页检测与提醒、居民意见采集与归档
5. **公示管理**：支出公示发布、公示状态流转、居民反馈关联
6. **导出报告**：生成含异常说明的完整报告、确保结论与页面一致、支持下载

## 3. 核心流程

**支出申请全流程**：财务人员提交支出申请 → 录入关联发票 → 系统自动查重检测 → 发现重复则标记异常 → 审批人员逐级审批（检测缺页） → 居民意见采集 → 审批通过后进入公示 → 公示期结束确认 → 可导出完整报告

**发票查重流程**：发票录入时 → 系统按发票号码+金额+开票方自动比对 → 发现疑似重复 → 标记为待确认 → 财务人员确认或排除 → 确认重复则关联原始发票 → 影响关联的支出申请状态

**项目延期处理流程**：标记项目延期 → 记录原截止日期与新截止日期 → 填写延期原因与影响描述 → 系统自动更新关联审批和公示状态 → 变更记录写入审计日志

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0F766E) 搭配暖橙强调色 (#EA580C)，传达专业严谨与警觉提醒
- **辅助色**：石板灰 (#475569) 用于正文，浅灰 (#F1F5F9) 用于背景
- **按钮风格**：圆角微凸（rounded-lg + shadow-sm），主要操作实色填充，次要操作描边
- **字体**：标题使用 Noto Serif SC（衬线体，庄重感），正文使用 Noto Sans SC（无衬线，易读）
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局，表格为主的数据展示
- **图标**：Lucide Icons 线性风格，异常标记使用实心圆点

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 财务总览卡片 | 四宫格统计卡片，数字加粗加大，趋势箭头图标，浅色背景区分 |
| 仪表盘 | 异常预警面板 | 三列横向排列，每列一种异常类型，红色/橙色/黄色标记级别，点击展开列表 |
| 仪表盘 | 变更时间线 | 垂直时间线，左侧时间戳，右侧操作描述，不同操作类型用不同颜色标记 |
| 支出申请 | 申请列表 | 表格布局，状态标签彩色编码，延期标记橙色图标，行悬停阴影 |
| 支出申请 | 申请详情 | 上下分区：上部信息卡片，中部原始材料/处理结果双栏，底部追溯导航条 |
| 发票管理 | 发票列表 | 表格布局，重复行红色背景高亮，筛选栏顶部固定，批量操作工具栏 |
| 审批追踪 | 审批流程图 | 横向流程节点，完成节点绿色勾、待审节点灰色、缺页节点红色叹号 |
| 公示管理 | 公示列表 | 卡片列表，状态标签（草稿灰/公示中绿/已结束蓝），倒计时提示 |
| 导出报告 | 报告生成 | 左侧配置面板，右侧实时预览区，底部下载按钮 |

### 4.3 响应式设计

- 桌面优先设计，导航栏在大屏固定左侧、小屏收起为汉堡菜单
- 表格在小屏转为卡片列表
- 审批流程图在小屏转为垂直布局
