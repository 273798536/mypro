# 采样包素材异常提醒

给白班/夜班交接用的采样包素材校验工具。核心解决：**相同请求不要重复算、临时改的判断要留痕、半拍时码不要乱下结论、坏材料来了一眼知道看哪儿**。

---

## 三步操作

### 1. 跑演示（最常用，先看输出长什么样）

```bash
python cli.py demo
```

会依次走：初扫 → 相同请求再扫一次（幂等验证）→ 补舞台通道备注 → 林姐临改判断 → 补排练备注 + 重扫 → 打印交接班摘要。
每一步都会印出检测条目、受哪些备注影响、交叉对齐结果。

### 2. 扫自己的包

把素材信息写成 `pkg.json`（字段见 `cli.py` 里的 `build_demo_package()`），然后：

```bash
python cli.py scan --input pkg.json --output result.json --operator "小王" --handoff
```

- `--output`：把结构化结果落盘，方便归档/发下一班
- `--handoff`：同时打印交接班摘要，**坏材料来了必加这个参数**

### 3. 跑单元测试（改完代码以后）

```bash
python -m pytest tests/ -v
```

## 坏材料来了该看哪里（重点）

拿到一份扫描结果，按下面顺序看就不会漏：

### ① 先看挂起项（HANG）

结果里带 `⏸️ [HANG]` 的就是**不能下稳定结论的项**，典型是「时码偏半拍」。
不要自行判断，直接转给 `requires_confirm_role` 标注的角色（一般是**运营主管**）。
**规则：宁可挂起等确认，也不给 PASS/WARNING 的假稳定结论。**

### ② 看「舞台通道表备注：判断影响说明」汇总条目

这是整个报告里最重要的一条，会把 **每条舞台通道备注覆盖了哪些原始判定、之前是什么状态、现在是什么状态** 一一列出来。
林姐不想每次临时解释为什么临时改动容易漏通知——这条就是写给下一班看的「变更说明」。

### ③ 看交叉对齐块（旧版本 ↔ 人工批注 ↔ 交付清单）

底部「交叉对齐」区域：
- 标 ❌ 的就是三者对不上，比如清单里缺素材但批注没提 → 要补批注或补素材
- HANG 项如果在**上次报告有、这次没了**，但没看到「主管确认」类批注 → **就是漏了**，别放过

### ④ 交接班摘要（handoff_summary）

如果用了 `--handoff` 或跑 demo，最后会印一份 `=== 采样包素材异常提醒 · 交接班摘要 ===`。
**下一班直接看这份就够**，里面按顺序有：
1. 挂起项（必须先处理）
2. 林姐或其他老师的临时改动
3. 完整变更轨迹（每一次谁改了什么）
4. 交叉对齐检查结论

## 备注类型对照（加备注时要选对）

| 类型 | 用在什么场景 |
|---|---|
| `stage_channel` | 舞台通道表临时加的，会覆盖 WARNING/FAIL 的检测结论 |
| `rehearsal` | 彩排确认 OK 的，跟时码半拍主管确认一起用 |
| `authorization` | 版权/授权类补充 |
| `teacher_edit` | **林姐临时改判断就选这个**，交接班摘要会单独拎出来高亮 |
| `other` | 其他 |

加备注时记得填 `affects_fields`，匹配不到相关判定的备注会被视为无效（不覆盖也不报错）。
