## 1. 产品概述

汇率避险经营赛是一款面向商学院学生的外贸公司经营模拟游戏。玩家在回合制经营中面对汇率波动，通过选择远期锁汇或裸奔（不避险）来管理汇率风险，同时处理订单、库存、现金流等经营要素。游戏旨在帮助学生理解汇率风险管理、远期合约机制和现金流管理的核心概念。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生玩家 | 无需注册，直接进入游戏 | 完整游戏体验、成绩保存与导出、历史记录查看 |

### 2.2 功能模块
1. **游戏主界面**：回合面板、资源状态栏、操作区
2. **订单系统**：订单生成、选择、取消处理
3. **汇率系统**：实时汇率波动、汇率卡展示
4. **远期合约系统**：锁汇操作、合约管理、到期结算
5. **库存与现金流**：库存管理、现金收支、赤字预警
6. **经营报告**：回合结算、盈亏分析、错因回放
7. **历史记录**：游戏存档、成绩回看、失败原因分析
8. **成绩导出**：CSV格式导出完整经营数据

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色（#1e3a5f）代表金融专业感，搭配琥珀色（#f59e0b）作为风险提示色
- **辅助色**：绿色（#10b981）表示盈利/正常，红色（#ef4444）表示亏损/警告
- **按钮风格**：圆角矩形，轻微阴影，hover时有上浮效果
- **字体**：标题使用 Noto Serif SC 营造专业感，正文使用 Inter 保证可读性
- **布局风格**：卡片式布局，清晰的信息层级，数据可视化图表
- **图标**：使用 lucide-react 线性图标，保持简洁专业

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 开始页面 | 欢迎模块 | 大标题、游戏简介卡片、规则展开面板、开始按钮 |
| 游戏主页面 | 顶部状态栏 | 回合计数器、现金显示、库存数量、预警指示灯 |
| 游戏主页面 | 左侧面板 | 订单卡片列表、滚动区域、接单/拒单按钮 |
| 游戏主页面 | 中央面板 | 汇率走势图、当前汇率卡、远期汇率报价表 |
| 游戏主页面 | 右侧面板 | 锁汇操作区、比例滑块、合约列表、确认按钮 |
| 游戏主页面 | 底部控制栏 | 暂停/继续、重开、结束回合按钮 |
| 结算弹窗 | 结算展示 | 收入明细、支出明细、净盈亏、异常事件高亮 |
| 经营报告页 | 报告主体 | 周期总览、资产曲线图、决策回顾表 |
| 经营报告页 | 错因回放 | 时间轴、关键事件标记、点击展开详情 |
| 历史记录页 | 列表视图 | 游戏卡片、得分、日期、查看详情按钮 |

### 4.3 响应式
- 采用桌面端优先设计，主界面为三栏布局
- 平板端自动调整为两栏，移动端转为单栏垂直滚动
- 触摸设备优化按钮尺寸和点击区域

### 4.4 数据可视化
- 使用 Recharts 绘制汇率走势图、资产变化曲线
- 关键数据使用卡片+数字动画展示
- 风险状态使用颜色编码和进度条直观呈现
