## 1. 产品概述

马尔可夫链边界校验工具，面向投研场景，帮助投研助理阿乔对参数表与权重进行边界校验，保留完整的数据处理痕迹和变更历史，支持两组参数对照分析，并提供可交付的校验结果包。

- 解决问题：人工记录参数变更繁琐易遗漏、校验过程不透明、脏数据清洗后无法追溯、除零边界难以识别
- 目标用户：投研助理（日常使用）、运营主管（对照审核）
- 产品价值：校验全过程可追溯、数据源统一、边界标记清晰、交付物完整

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 投研助理 | 本地使用，无需登录 | 上传参数、执行校验、查看历史、导出结果 |
| 运营主管 | 本地使用，无需登录 | 对照两组参数、查看中间计算过程、审核结果 |

### 2.2 功能模块

1. **校验工作台**：参数上传、原始数据保留、筛选条件、统计面板、明细表、CSV导出
2. **历史记录**：参数版本、权重变更记录、临时判断留痕、操作人时间戳
3. **参数对照**：两组参数并排对比、中间计算过程展开、单位换算透明化
4. **交付视图**：参数表、处理记录、CSV明细一站式展示与导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 校验工作台 | 上传区域 | 拖拽或点击上传CSV参数表，支持多文件，保留原始数据副本 |
| 校验工作台 | 筛选面板 | 按状态（正常/边界/异常）、区间、除零标记等多条件筛选 |
| 校验工作台 | 统计概览 | 总条数、正常数、边界数、异常数、除零标记数，均来自同一结果集 |
| 校验工作台 | 明细表格 | 展示每条数据的原始值、计算值、边界状态、除零标记、计算过程展开 |
| 校验工作台 | 导出功能 | 导出CSV明细，包含原始数据和标记列 |
| 历史记录 | 版本列表 | 每次参数修改生成新版本，记录修改时间、操作人、变更说明 |
| 历史记录 | 变更详情 | 展示前后差异（参数值、权重），保留临时判断备注 |
| 参数对照 | 双栏对比 | 左右两栏分别加载不同版本参数，并排展示 |
| 参数对照 | 计算过程 | 展开中间步骤和单位换算，高亮差异项 |
| 交付视图 | 交付总览 | 参数表 + 处理记录 + CSV明细三合一展示，可整体导出 |

## 3. 核心流程

投研助理阿乔上传参数表 → 系统保留原始数据副本 → 执行马尔可夫链边界校验计算 → 生成统一结果集 → 阿乔设置筛选条件 → 查看统计与明细 → 标记除零边界和临时判断 → 生成历史版本 → 运营主管对照两组参数 → 导出交付包（参数表+处理记录+CSV明细）

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色背景（slate-900），配琥珀色（amber）作为边界警告色，青绿色（emerald）作为正常状态色
- **设计风格**：工业/终端风格，专业严谨，数据密集但层次清晰
- **按钮样式**：方角微圆（rounded-sm），实心填充 + 细边框，hover 时有轻微发光效果
- **字体**：数据列使用等宽字体（JetBrains Mono），标题和正文使用现代无衬线字体
- **布局**：左侧导航 + 右侧内容区，表格固定表头可滚动
- **图标风格**：Lucide 线性图标，保持细线风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 校验工作台 | 上传区域 | 虚线边框上传框，拖拽时边框高亮，文件列表显示原始文件名 |
| 校验工作台 | 筛选面板 | 横向排列的筛选芯片，点击切换激活状态，计数标签 |
| 校验工作台 | 统计卡片 | 四个数字卡片并排，底部有进度条占比可视化 |
| 校验工作台 | 明细表格 | 斑马纹行，除零行用琥珀色背景标记，可展开计算详情 |
| 历史记录 | 时间线 | 左侧时间轴，右侧版本卡片，hover 显示变更摘要 |
| 参数对照 | 双栏布局 | 中间可拖拽分隔线，差异行高亮闪烁 |
| 交付视图 | 三栏折叠 | 参数表/处理记录/CSV明细三段式，可各自展开 |

### 4.3 响应式

- 桌面端优先设计，主内容区最小宽度 1024px
- 表格区支持横向滚动，保证数据列完整展示
- 移动端简化为单列布局，导航收为底部标签栏

### 4.4 动效细节

- 数字变化时使用计数滚动动画
- 除零边界行有轻微呼吸发光效果
- 版本切换时内容淡入淡出
- 展开/收起计算详情时有平滑高度过渡
