# 机器人路径格子沙盘

一个用于绘制和标注机器人路径的Web应用，支持图层管理、离线素材检查和报告导出功能。

## 功能特性

- **网格沙盘绘制**：在网格上绘制机器人路径和障碍物
- **网格吸附**：支持网格对齐，可开关
- **图层管理**：多个图层独立管理，支持显示/隐藏、删除
- **样例数据**：内置3条样例数据，包含正常、错误和警告状态
- **离线素材检查**：检测并显示素材状态
- **评分系统**：路径完整性、障碍规避、素材齐全性、标注完整性检查
- **导出报告**：生成并下载包含不可用记录、素材检查和人工备注的报告
- **撤销/重做**：支持操作历史记录
- **人工备注保留**：原样保留所有人工备注内容

## 使用方法

直接用浏览器打开 `index.html` 即可使用，无需服务器。

## 操作说明

1. **绘制路径**：选择"绘制路径"工具，在网格上点击并拖动
2. **绘制障碍**：选择"绘制障碍"工具，在网格上点击添加障碍物
3. **图层操作**：在左侧面板管理图层，可新建、显示/隐藏、删除
4. **加载样例**：点击左侧样例加载数据，查看不同状态的记录
5. **导出报告**：点击顶部"导出报告"按钮生成并下载报告
6. **网格吸附**：可通过复选框开启/关闭网格吸附功能

## 样例说明

- **样例1（正常）**：完整的路径和障碍，素材齐全
- **样例2（错误）**：存在离线素材缺失，记录不可用
- **样例3（警告）**：需要补录标注

## 浏览器兼容性

支持现代浏览器（Chrome、Firefox、Safari、Edge）
