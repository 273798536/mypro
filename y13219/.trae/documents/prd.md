## 1. 产品概述

版权授权分账对齐工具，面向琴房前台工作人员（如小温），解决排练群截图中的授权期限、分账比例、曲名别名等信息难以系统化对齐的问题。核心目标是：让每一次人工改判有据可查，让曲名别名警告可追溯到排练群截图原始说法，让旧版本、人工批注和交付清单彼此对应。

- 目标用户：琴房前台值班人员（需要核对版权授权、分账比例并向上级或合作方汇报）
- 核心价值：将散落在排练群截图和备注中的授权信息结构化，保留改判历史，输出可交付的摘要

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 琴房前台值班人员 | 直接使用网页工具 | 导入截图、录入/改判记录、导出交付摘要 |
| 下一班接班人员 | 查看历史与交付摘要 | 只读历史记录、查看改判原因 |

### 2.2 功能模块

1. **分账对齐总览页**：展示当前所有版权授权条目的对齐状态，高亮异常项（人工改判、别名冲突、授权期限缺失）
2. **排练群截图录入与溯源页**：录入排练群截图及其关联信息，支持从截图追溯到具体条目

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分账对齐总览页 | 条目卡片列表 | 每条授权记录以卡片呈现，显示曲名、别名、授权期限、分账比例、对齐状态；人工改判条目带醒目标记和改判原因折叠区 |
| 分账对齐总览页 | 别名冲突溯源 | 曲名别名重复时，不是含糊警告，而是展示冲突来源（哪条排练群截图、谁说的、原始措辞），点击可跳转到截图详情 |
| 分账对齐总览页 | 人工改判说明 | 展示改判前值→改判后值、改判人（小温）、改判时间、改判原因；改判记录不可删除，仅可追加 |
| 分账对齐总览页 | 交付摘要面板 | 一键生成交付摘要：排练群截图清单、处理记录摘要、当前对齐状态汇总；格式简洁，方便前台转发给他人 |
| 分账对齐总览页 | 版本时间线 | 每次重扫生成一个版本快照，人工批注附在快照上；可对比任意两个版本的差异 |
| 排练群截图录入页 | 截图录入表单 | 上传截图图片、填写关联曲名/别名、授权期限（从备注提取）、分账比例、来源群名、发言者 |
| 排练群截图录入页 | 截图溯源链 | 从任意条目反向查找到原始截图及录入时的备注字段 |

## 3. 核心流程

用户（琴房前台小温）打开工具后，首先看到分账对齐总览页，所有授权条目以卡片列表呈现。当发现曲名别名冲突时，点击警告标记可查看冲突溯源（追溯到排练群截图原始说法）。当需要对某条记录进行人工改判时，点击改判按钮，填写改判原因，改判记录永久保留在历史中。新截图录入后点击"重扫"，系统重新对齐并生成新版本快照，旧版本和人工批注保留可查。值班结束时，点击"生成交付摘要"，得到可转发的摘要文本。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖灰底色 (#F5F3EF) + 深墨绿强调色 (#2D4739)，传达沉稳的档案管理感
- 次色调：琥珀色 (#C4913B) 用于人工改判标记，赭红色 (#B85450) 用于异常/冲突警告
- 按钮风格：圆角矩形，轻微阴影，低饱和度配色
- 字体：标题用衬线体（Noto Serif SC），正文用无衬线（Noto Sans SC），区分层次
- 布局风格：左侧固定侧边导航栏 + 右侧内容区，内容区采用卡片网格布局
- 图标风格：线性图标，1.5px 描边，与文字大小协调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 分账对齐总览页 | 条目卡片列表 | 卡片网格，每卡片含曲名标题、别名标签、授权期限条、分账比例饼图微型、对齐状态徽章；人工改判卡片左上角琥珀色竖条 |
| 分账对齐总览页 | 别名冲突溯源 | 点击别名标签弹出溯源弹窗，展示冲突两条记录的原始截图缩略图+发言者+原始措辞高亮 |
| 分账对齐总览页 | 人工改判说明 | 改判卡片内折叠区，展示改判时间线：原值→新值，改判人标签，原因文本 |
| 分账对齐总览页 | 交付摘要面板 | 右侧抽屉式面板，点击"生成交付摘要"展开；含截图清单、处理记录、状态汇总三段式布局 |
| 分账对齐总览页 | 版本时间线 | 页面底部横向时间线，每个版本节点可点击查看快照；选中两个节点后显示差异对比 |
| 排练群截图录入页 | 截图录入表单 | 左侧截图预览区（支持拖拽上传），右侧表单字段垂直排列；底部"关联已有条目"搜索框 |
| 排练群截图录入页 | 截图溯源链 | 条目详情页中，"溯源"区块展示从条目→截图→录入备注的链接链 |

### 4.3 响应式设计

- 桌面优先设计，内容区最小宽度 1024px
- 卡片网格在 1440px 以上为 3 列，1024-1440px 为 2 列
- 侧边导航可折叠为图标模式
