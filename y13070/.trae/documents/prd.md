## 1. 产品概述

山地索道站空间复核系统是一套面向工程评审与教学交接的专业工具，解决坐标系混用导致空间复核结果不可信的核心问题。系统确保筛选条件、统计数字、明细表与截图说明从同一套计算结果生成，完整保留评审批注中的历史备注与旧版截图，并在相邻点位合错时给出可执行的下一步提示。

- 目标用户：评审工程师、教学老师（如林姐）、项目交接人员
- 核心价值：让坐标系混用问题可追溯、可定位、可交接，而非只留最终数值

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 评审工程师 | 工号登录 | 执行空间复核、标注问题、编写处理链 |
| 教学老师 | 工号登录 | 查看批注历史、执行交接验证、添加教学备注 |
| 交接人员 | 工号登录 | 生成交接报告、导出截图说明、确认处理结果 |

### 2.2 功能模块

1. **复核工作台**：3D 站点视图 + 时间轴 + 侧边明细 + 统计面板 + 筛选条件联动
2. **批注与历史**：评审批注全版本存档、备注时间线、旧版截图保留、坐标系变更记录
3. **交接报告**：从批注追溯原始说法、截图说明讲清处理结果、一键导出交接文档

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|

| 复核工作台 | 筛选条件栏 | 按坐标系/站点/偏差范围/处理状态筛选，所有面板联动同一数据源 |
| 复核工作台 | 相邻点位合错提示 | 检测相邻点位合错，显示可执行的下一步操作（如"重新测量 A3-A4 段"） |

## 3. 核心流程

**复核与交接主流程**：评审工程师在复核工作台执行空间复核 → 系统自动检测坐标系混用和相邻点位合错 → 异常点位高亮并给出可执行提示 → 工程师编写处理链和批注 → 教学老师在批注与历史页面查看全版本记录并追加教学备注 → 交接人员生成交接报告 → 教学老师逐条验证确认 → 导出交接文档

```mermaid
    "加载站点数据" --> "3D渲染与坐标检测"
    "3D渲染与坐标检测" --> "是否存在坐标系混用?"
    "是否存在坐标系混用?" -->|"是"| "高亮异常点位 + 生成可执行提示"
    "是否存在坐标系混用?" -->|"否"| "标记正常"
    "高亮异常点位 + 生成可执行提示" --> "工程师编写处理链"
    "标记正常" --> "工程师编写处理链"
    "工程师编写处理链" --> "保存批注(含旧版截图)"
    "保存批注(含旧版截图)" --> "教学老师查看历史 + 追加备注"
    "教学老师查看历史 + 追加备注" --> "生成交接报告"
    "生成交接报告" --> "教学老师逐条验证"
    "教学老师逐条验证" --> "导出交接文档"
```

**时间轴切换流程**：用户点击时间轴某段 → 系统加载该段数据 → 侧边明细更新 → 3D 视图高亮同步 → 统计面板刷新 → 筛选条件重置为该段范围

**重启恢复流程**：系统启动 → 从 localStorage 加载历史备注、当前状态、截图索引 → 校验一致性 → 恢复至上次状态

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青灰 (#1a2332) 为底，警示橙 (#e8743b) 标异常，通过绿 (#34d399) 标正常，冰蓝 (#60a5fa) 标交互
- **按钮风格**：圆角矩形（8px），扁平+微投影，主按钮填充色，次按钮描边
- **字体**：JetBrains Mono 用于数据/坐标显示，Noto Sans SC 用于中文正文
- **布局风格**：左侧 3D 视图 + 右侧面板，顶部时间轴，工业控制台风格
- **图标风格**：线性图标（Phosphor Icons 风格），2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|

| 复核工作台 | 时间轴 | 水平条状，分段色块，当前段高亮，hover 显示日期范围 |

### 4.3 响应式策略

桌面优先设计（1920x1080 为基准），1280px 以下侧边面板可折叠，768px 以下切换为标签页布局。3D 视图支持触摸旋转缩放。

### 4.4 3D 场景指引

- **环境**：深色 HDRI，微弱环境光，专业测量感
- **灯光**：主方向光模拟日照（偏暖），辅助点光源在异常点位处发橙光
- **相机**：透视相机，默认 45° 俯角，OrbitControls 限制最大仰角
- **构图**：站点主体居中，连线延伸至边缘，异常点位用脉冲光环吸引注意力
- **交互**：点击点位弹出信息卡，双击聚焦，滚轮缩放，拖拽旋转
- **后处理**：Bloom 效果作用于异常点位光环，环境遮蔽增强站点立体感
- **性能**：点位数 < 500，目标 60fps，使用 InstancedMesh 优化渲染
