## 1. 产品概述

滩涂贝类采样日程管理系统——为海洋监测人员提供采样计划编排、风险分层研判、异常追踪与报告导出的完整工具链。系统使用本地 SQLite 数据库，从空目录一键启动，确保海事处等外单位查看导出报告时能清晰理解每条结论的数据来源与风险依据。

- 解决问题：风浪预报晚到、禁航区越界、水质记录延迟等场景下采样日程频繁卡住，现有手工流程无法追踪风险结论受哪些数据影响
- 目标用户：海洋老师（日常复核）、海事处（只看导出报告）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 海洋老师 | 本地启动浏览器 | 编排日程、导入数据、查看异常、复核确认、导出报告 |
| 海事处 | 接收导出报告文件 | 只读查看结论与风险说明 |

### 2.2 功能模块

1. **日程总览页**：采样任务日历视图、任务状态标签（顺利/待确认/异常）、风浪与潮汐信息摘要
2. **采样记录管理页**：录入/导入采样记录、风浪预报补录、潮汐表补录、水质记录补录
3. **异常追踪页**：风险分层列表、受影响结论提示、数据晚到影响链
4. **报告导出页**：生成可交付海事处的报告、结论溯源说明

### 2.3 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 日程总览 | 任务卡片列表 | 按日期展示采样任务，每条显示状态标签、风浪/潮汐/水质三项数据完备情况 |
| 日程总览 | 风险快照条 | 顶部横幅显示当前待确认数量和异常数量，点击跳转异常追踪 |
| 采样记录管理 | 记录表单 | 录入采样日期、区域、贝类品种、风浪预报、潮汐数据、水质数据 |
| 采样记录管理 | 补录入口 | 对已有记录补录缺失字段，补录后自动触发风险重新评估 |
| 采样记录管理 | 导入功能 | 支持通过 curl/API 批量导入 JSON 数据 |
| 异常追踪 | 风险分层列表 | 按"顺利→待确认→异常"三级排列，每条标注风险因素 |
| 异常追踪 | 影响链提示 | 展示某条数据缺失影响了哪些结论，而非静默覆盖 |
| 报告导出 | 报告预览 | 预览将导出内容，包括结论溯源说明 |
| 报告导出 | 导出按钮 | 生成 JSON/CSV 报告文件，包含风浪预报晚到被拦原因说明 |

## 3. 核心流程

采样日程从录入到交付海事处的完整流程：

1. 海洋老师启动系统，录入或导入采样计划
2. 系统根据风浪预报、潮汐数据、水质记录自动进行风险分层
3. 若数据缺失（如风浪预报晚到），标记为"待确认"并提示影响范围
4. 数据补录后，风险分层自动重新评估，相关结论同步更新
5. 海洋老师复核确认后，导出报告交付海事处
6. 导出报告中明确标注每条结论的数据来源和风险依据

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 #0A2540，辅助色：潮汐青 #00B4D8，警示色：珊瑚红 #E63946
- 按钮风格：圆角 8px，轻微阴影，悬停加深
- 字体：Noto Sans SC 作为正文，数字用 JetBrains Mono 等宽字体
- 布局：左侧导航栏 + 右侧内容区，卡片式布局
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 日程总览 | 任务卡片列表 | 卡片含日期、区域、品种、三级状态标签（绿/黄/红）、数据完备度图标 |
| 日程总览 | 风险快照条 | 固定顶部横幅，黄/红计数徽章，点击可跳转 |
| 采样记录管理 | 记录表单 | 分组表单（基础信息/风浪/潮汐/水质），缺失字段高亮黄色边框 |
| 采样记录管理 | 补录交互 | 点击缺失字段进入补录模式，保存后即时刷新风险状态 |
| 异常追踪 | 风险分层列表 | 三列布局（顺利/待确认/异常），卡片可拖拽或点击查看详情 |
| 异常追踪 | 影响链 | 展开式面板，箭头连接"缺失数据→受影响结论" |
| 报告导出 | 报告预览 | 结构化预览面板，结论标注数据来源脚注 |
| 报告导出 | 导出按钮 | JSON/CSV 双格式按钮，导出含风险说明段落 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px。平板和移动端提供简化视图，异常追踪页在小屏下切换为单列列表。
