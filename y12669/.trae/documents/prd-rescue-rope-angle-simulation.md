# 救援绳索角度模拟工作台 - 产品需求文档

## 1. 产品概述

救援绳索角度模拟工作台是一个本地 Web 应用，旨在解决周会前时间参数与风险备注不匹配的问题，为展馆讲解员提供完整的记录复核、修正和追溯能力。通过可视化的角度模拟、剖面图分析和时间回放功能，确保每条记录都有清晰的异常说明和处理建议，避免手工补锅。

**核心价值**：
- 消除时间参数与风险备注不匹配的记录问题
- 提供完整的记录生命周期管理（列表→详情→修正→历史→下载）
- 通过可视化图表和明细解释，让异常原因和处理方式一目了然
- 确保导出报告能清晰说明透明遮挡误读等问题的拦截原因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限说明 |
|------|----------|
| 展馆讲解员 | 复核记录、修正参数、查看历史、导出报告 |
| 运维组 | 查看导出报告、理解拦截原因 |

### 2.2 功能模块

1. **记录列表页**：展示所有救援绳索角度模拟记录，支持筛选、搜索和状态过滤
2. **记录详情页**：查看单条记录的完整信息，包括时间参数、风险备注、剖面图和异常说明
3. **记录修正页**：修正时间参数和风险备注，实时预览修正后的剖面图
4. **历史追溯页**：查看记录的修改历史，支持时间回放
5. **报告导出功能**：生成包含明细解释的导出报告

## 4. 用户界面设计

### 4.1 设计风格

**主色调**：
- 主色：深蓝色 (#1E3A5F) - 专业、可靠
- 辅助色：橙色 (#FF6B35) - 警示、重要操作
- 成功色：绿色 (#2ECC71) - 正常状态
- 异常色：红色 (#E74C3C) - 错误状态
- 背景色：浅灰 (#F8F9FA) - 清爽、专业

**按钮风格**：
- 主要按钮：圆角矩形，深蓝色背景，白色文字
- 次要按钮：圆角矩形，白色背景，深蓝色边框和文字
- 危险按钮：圆角矩形，红色背景，白色文字

**字体**：
- 标题字体：思源黑体 (Source Han Sans) - 专业、清晰
- 正文字体：苹方 (PingFang SC) - 易读、现代
- 代码字体：JetBrains Mono - 技术感

**布局风格**：
- 顶部导航栏 + 左侧菜单 + 右侧内容区
- 卡片式布局，每个功能模块独立成卡
- 响应式设计，支持桌面端和移动端

**图标风格**：
- 线性图标，简洁明了
- 使用 Lucide Icons 图标库

### 4.3 响应式设计

- **桌面优先**：主要面向桌面端使用，确保大屏幕下的最佳体验
- **移动端适配**：支持平板和手机访问，简化布局，优化触摸操作
- **触摸优化**：按钮和交互元素最小尺寸 44px，支持手势操作

### 4.4 三维视图指导

**环境设置**：
- 使用浅灰色渐变背景，营造专业氛围
- 环境光 + 定向光，确保模型清晰可见

**光照设置**：
- 主光源：定向光，模拟日光
- 辅助光：环境光，补充阴影区域

**相机设置**：
- 透视相机，FOV 60度
- 支持鼠标旋转、缩放、平移
- 默认视角：俯视角度

**交互和动画**：
- 鼠标悬停高亮
- 点击选中显示详细信息
- 平滑过渡动画

**性能预算**：
- 模型面数 < 10,000
- 60 FPS 流畅运行
- 快速加载（< 3秒）

## 5. 异常类型与处理建议

### 5.1 异常类型分类

| 异常类型 | 异常代码 | 说明 | 处理建议 |
|---------|---------|------|---------|
| 时间参数不匹配 | TIME_MISMATCH | 时间参数与风险备注中的时间不一致 | 检查时间参数，修正为一致的时间 |
| 风险备注缺失 | RISK_NOTE_MISSING | 缺少风险备注或备注不完整 | 补充风险备注，确保完整性 |
| 透明遮挡误读 | TRANSPARENT_OCCLUSION | 透明遮挡导致角度读取错误 | 调整遮挡参数，重新计算角度 |
| 参数超出范围 | PARAM_OUT_OF_RANGE | 参数值超出允许范围 | 调整参数值到允许范围内 |
| 数据格式错误 | DATA_FORMAT_ERROR | 数据格式不符合要求 | 修正数据格式 |

### 5.2 异常说明面板设计

每个异常都应包含以下信息：
1. **异常类型**：清晰的异常类型名称和图标
2. **异常原因**：详细说明异常产生的原因
3. **影响范围**：说明异常对记录的影响
4. **下一步操作**：明确的操作建议（补材料/改口径）
5. **参考文档**：链接到相关操作指南

## 6. 导出报告要求

### 6.1 报告内容

导出报告应包含：
1. **报告摘要**：记录总数、异常数量、处理状态
2. **异常记录详情**：每条异常记录的详细信息
3. **拦截原因说明**：清晰说明每条记录被拦截的原因
4. **处理建议**：针对每条异常记录的处理建议
5. **操作日志**：记录的操作历史

### 6.2 报告格式

支持以下格式：
- PDF 格式（默认）
- Excel 格式
- Word 格式

### 6.3 报告可读性要求

- 运维组无需查看系统即可理解报告内容
- 每个异常都有清晰的说明和处理建议
- 使用图表和可视化元素增强可读性
- 包含操作指南链接
