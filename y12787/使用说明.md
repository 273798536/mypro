# 化妆品稳定性台账系统 使用说明

## 环境要求
- Python 3.8+
- 无第三方依赖，纯标准库实现

---

## 一、启动（初始化工作目录）

首次使用前需要初始化工作目录：

```bash
cd /path/to/your/workspace
python stability.py init
```

执行后会自动创建以下目录结构：
```
data/
├── input/    # 存放待导入的CSV数据文件
├── output/   # 存放导出的报告
└── work/     # 系统内部数据（请勿手动修改）
```

也可以指定工作目录：
```bash
python stability.py -w /your/work/dir init
```

---

## 二、导入数据

### 1. 准备数据文件
将CSV格式的数据文件放入 `data/input/` 目录。系统支持：
- 旧格式表格（有标题行、合并单元格文字说明等）
- 列名不统一（"时间点"/"考察时间"/"月份"都会自动识别）
- 补录数据（有补录说明列）
- 单位填写混乱（有的写在数值里，有的漏填）

### 2. 执行导入

导入批次信息：
```bash
python stability.py import 批次信息表_2024旧格式.csv -o 张三
```

导入检验结果：
```bash
python stability.py import 检验结果_批次20240101_补录.csv -o 李四
```

参数说明：
- `-o` 或 `--operator`：操作员姓名，默认"系统管理员"

导入完成后会显示统计信息：
```
✓ 导入完成
  批次新增: 1
  批次更新: 0
  考察点新增: 10
  考察点更新: 0
  检验项新增: 40
  检验项更新: 0
```

**说明**：同一批材料重复导入不会导致数据混乱，系统会自动识别并更新已有记录，每次导入都会生成独立的处理记录。

---

## 三、查看异常

### 1. 检测异常
每次导入新数据后，建议运行异常检测：

```bash
# 检测所有批次
python stability.py check -o 张三

# 检测指定批次
python stability.py check -b 20240101 -o 张三
```

检测结果示例：
```
✓ 检测完成，新增 8 条异常

批次 20240101: 5 条
  🔴 [ANOM-20240610-0001] 记录缺失: 3月考察点反应时间漏记，系统无法判定为正常样例
  🔴 [ANOM-20240610-0002] 空白对照缺失: 1月时间点有供试品检测，但缺少空白对照
  🟡 [ANOM-20240610-0003] 单位漏填: 1月含量测定值97.8缺少单位
  ...
```

### 2. 查看所有异常
```bash
# 查看所有异常
python stability.py anomalies

# 按批次筛选
python stability.py anomalies -b 20240101

# 按状态筛选
python stability.py anomalies -s 待复核
```

### 3. 查看异常详情及追溯链
这是验收关键：从异常往回查，能查到批次报告和处理意见。

```bash
python stability.py view -a ANOM-20240610-0001
```

输出内容包括：
- 异常基本信息（类型、严重程度、描述、检测时间）
- 通俗解释（什么是反应时间漏记，有什么影响）
- 关联处理记录（哪次导入/操作产生的）
- 所属批次信息
- 该批次所有处理记录（完整追溯链）

### 4. 处理异常
```bash
python stability.py handle ANOM-20240610-0001
```

系统会提示输入：
1. 处理意见（如"已找到原始记录，反应时间为2024-04-16 09:48:00"）
2. 选择新状态：
   - 1. 正常 - 数据经复核无误
   - 2. 已作废 - 数据无效
   - 3. 待复核 - 需要进一步核实

也可以用参数直接指定：
```bash
python stability.py handle ANOM-20240610-0001 \
  -m "已补录反应时间，数据有效" \
  -s 正常 \
  -o 李四
```

## 四、导出结果

### 1. 先计算稳定性
导出前需要先进行稳定性计算：

```bash
# 计算所有批次
python stability.py calc -o 张三

# 计算指定批次
python stability.py calc -b 20240101 -o 张三
```

计算内容包括：
- 含量降解率（线性回归法）
- pH值稳定性（极差法）
- 微生物稳定性（限度检查法）
- 性状稳定性（合格项统计法）
- 有效期推算

### 2. 导出报告

导出HTML格式（推荐，可直接用浏览器打开）：
```bash
# 导出所有批次汇总报告
python stability.py export

# 导出指定批次报告
python stability.py export -b 20240101
```

导出CSV格式（适合用Excel打开）：
```bash
python stability.py export -f csv
```

### 3. 报告内容

**HTML报告**包含：
- 异常汇总（放在最前面，一眼能看到问题）
- 批次基本信息
- 考察时间点记录（反应时间漏记会标红）
- 检验结果表格（单位漏填标黄，不合格标红）
- 稳定性计算结果
- 异常记录 + 通俗解释 + 处理建议（不用查字典就能看懂）
- 处理记录追溯链（时间线形式，能看到每一步操作）
- 术语解释（什么是含量降解率、Z值、线性回归法等）

**CSV报告**会生成多个文件：
- 每个批次一个CSV文件（包含所有数据）
- `异常汇总.csv`（含通俗解释和处理建议列，可直接转给不懂代码的人看）

## 六、验收要点

顺着一条异常往回查，确认完整链路：

1. `stability anomalies` 找到一条异常，记录ID
2. `stability view -a <异常ID>` 查看：
   - ✓ 异常信息完整
   - ✓ 能看到关联的处理记录ID
   - ✓ 能看到所属批次
   - ✓ 能看到该批次所有处理记录
3. `stability view <批次号>` 查看：
   - ✓ 批次基本信息
   - ✓ 检验数据完整
   - ✓ 异常记录在列
   - ✓ 处理记录追溯链完整
4. `stability export` 导出报告：
   - ✓ 异常有通俗解释，不是字段名和缩写
   - ✓ 空白对照缺失有说明为什么重要
   - ✓ 能转给不懂代码的人看懂

## 七、数据文件格式说明

### 批次信息表（CSV）
必需列：批次号、产品名称  
可选列：产品代码、规格、生产日期、拟有效期、生产厂家、储存条件、检验员、备注

### 检验结果表（CSV）
必需列：批次号、时间点 + 检验项目列  
可选列：检验日期、温度、湿度、检验员、记录时间、空白对照、标准规定、备注、补录说明

系统会自动识别各种列名写法，无需严格统一。

---

## 八、注意事项

1. **反应时间漏记**：系统不会将其当成正常样例，会标记为严重异常，且该考察点数据不参与稳定性计算。
2. **同一批重复跑**：每次导入都会生成独立处理记录，数据更新有完整历史可查，不会越跑越乱。
3. **批次追踪和异常留痕**：共用同一套处理记录，界面、报告、追溯链数据来源一致，不会各算各的。
4. **空白对照缺失**：导出报告会用通俗语言说明影响，不会只显示"MISSING_BLANK_CONTROL"这类字段名。
