## 1. 产品概述

风洞升阻力曲线管理系统——为车辆工程助教提供本地化的小型服务，将零点漂移出现时需手工翻查的迎角记录、力传感器、曲线报告统一归口到同一事件下，实现新增、复核、状态推进和导出全流程走真实数据。

- 解决零点漂移、迎角越界、速度缺采等异常出现时，助教需同时翻阅多份材料、容易遗漏关键信息的问题
- 目标用户：车辆工程风洞实验室助教、实验负责人、交接同事

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 实验助教 | 直接访问 | 新增试验批次、录入材料、复核异常、导出报告 |
| 实验负责人 | 直接访问 | 审核推进状态、查看异常汇总、归档 |
| 交接同事 | 通过报告链接 | 查看曲线报告及零点修正口径 |

### 2.2 功能模块

1. **试验总览页**：所有试验批次的列表与状态概览，支持按模型编号/迎角/日期快速筛选
2. **试验详情页**：单个试验批次的完整材料归集、升阻力计算、异常追踪、状态推进
3. **异常追踪页**：跨批次的异常汇总视图，展示异常触发来源、卡点位置、待补材料
4. **报告导出页**：生成包含零点修正口径的曲线报告，支持直接转交同事

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 试验总览页 | 批次列表 | 展示所有试验批次卡片，显示模型编号、状态标签（待复核/异常/已完成）、关键异常计数 |
| 试验总览页 | 快速筛选 | 按模型编号、迎角范围、日期区间、状态筛选批次 |
| 试验总览页 | 新增批次 | 弹窗表单，录入模型编号、风洞编号、试验日期，自动生成批次号 |
| 试验详情页 | 材料归集 | 将迎角记录、力传感器数据、曲线报告关联到同一批次，展示关联状态 |
| 试验详情页 | 升阻力计算 | 根据关联的力传感器与迎角数据计算升力系数/阻力系数曲线，日常处理口径 |
| 试验详情页 | 异常检测 | 自动检测零点漂移、迎角越界、速度缺采，标记触发材料与卡点 |
| 试验详情页 | 状态推进 | 待录入 → 待复核 → 异常处理 → 已完成，每步记录操作人与时间 |
| 试验详情页 | 异常说明 | 记录异常原因、零点修正口径、补录材料说明，与计算口径保持一致 |
| 异常追踪页 | 异常汇总 | 跨批次异常列表，按异常类型分组（零点漂移/迎角越界/速度缺采） |
| 异常追踪页 | 触发溯源 | 每条异常展示：触发材料名称、所在批次、卡在哪个步骤、下一步需补什么 |
| 异常追踪页 | 待办清单 | 按紧急度排列的待处理异常，支持标记处理中/已解决 |
| 报告导出页 | 报告预览 | 在线预览曲线报告，含升阻力曲线图、零点修正说明、异常处理记录 |
| 报告导出页 | 导出与分享 | 导出为PDF，包含完整零点修正口径，交接同事无需再回来追问 |

## 3. 核心流程

### 3.1 试验批次全生命周期

用户录入新批次 → 关联迎角记录/力传感器/曲线报告 → 系统自动检测异常 → 如有异常：标记触发材料、卡点位置、待补项 → 助教复核并录入异常说明 → 状态推进至已完成 → 生成包含修正口径的报告 → 分享给交接同事

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1E293B) 为底，琥珀色 (#F59E0B) 标记异常/警告，翡翠绿 (#10B981) 标记正常/已完成
- **辅助色**：石板灰 (#64748B) 次要信息，红色 (#EF4444) 严重异常
- **按钮风格**：圆角矩形（8px），主操作实色填充，次操作描边
- **字体**：JetBrains Mono 数据展示，Noto Sans SC 中文正文，标题加粗
- **布局风格**：左侧导航栏 + 主内容区，卡片式布局，顶部操作栏
- **图标风格**：线性图标（Lucide），与数据表格搭配清晰

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 试验总览页 | 批次列表 | 卡片网格，每卡片含模型编号、状态标签、异常计数徽标，悬停展开摘要 |
| 试验总览页 | 快速筛选 | 顶部筛选条，下拉选择模型编号/状态，日期范围选择器 |
| 试验总览页 | 新增批次 | 模态弹窗，表单含模型编号输入、风洞编号选择、日期选择 |
| 试验详情页 | 材料归集 | 三栏并排（迎角记录/力传感器/曲线报告），每栏显示关联状态与操作 |
| 试验详情页 | 升阻力计算 | 曲线图表区域（SVG/Canvas），下方数据表格，参数调整滑块 |
| 试验详情页 | 异常检测 | 异常横幅通知，异常列表含类型图标、触发材料链接、卡点高亮 |
| 试验详情页 | 状态推进 | 顶部步骤条（横向），当前步骤高亮，可点击查看历史 |
| 异常追踪页 | 异常汇总 | 按类型分组的折叠面板，每组含计数徽标与展开列表 |
| 异常追踪页 | 触发溯源 | 异常详情侧面板，含材料名称、批次链接、步骤定位、待补项清单 |
| 报告导出页 | 报告预览 | A4比例预览区域，含曲线图、修正说明、异常记录表格 |
| 报告导出页 | 导出与分享 | 底部操作栏，导出PDF按钮，生成分享链接按钮 |

### 4.3 响应式设计

- 桌面优先设计，主内容区最小宽度 1024px
- 侧边栏可折叠，内容区自适应宽度
- 表格在窄屏时支持横向滚动

### 4.4 无3D场景

本项目不涉及3D场景
