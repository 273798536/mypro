# 慢行桥坡道点位归并

## 启动

```bash
npm install
npm run dev
```

前端 `http://localhost:5173`，后端 `http://localhost:3001`，Vite 自动代理 `/api`。

## 样例数据

打开「材料导入」页，点击「载入示例数据」，会写入 8 条会议纪要条目。其中混了两条"乱材料"用于试跑：

- 名称不一致：「慢行天桥北坡道」与「慢行桥北坡道」指同一处，前端标橙色「名称不一致」
- 坐标偏到隔壁街：一条「慢行桥西坡道」坐标偏移约 2.7km，前端标红色「坐标偏移」

归并后所有坡道按名称相似度 + 坐标距离聚为一组，合并坐标取中位数（不被偏移值带偏），原始说法全部保留可查。

## 重跑归并

打开「归并操作」页 → 点击「执行归并」或「重跑归并」。重跑会清空旧分组和备注、基于全部条目重新聚类。修改某组备注后失焦即自动同步后端，导出结果随之变化。

## 查看页面摘要

打开「摘要查看」页 → 点击行展开原始条目 → 点击「导出 CSV」下载。CSV 每行一条原始记录，附带所属组号、归并名称、归并坐标、备注，社区核点人员可直接核对原始说法。
