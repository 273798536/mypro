## 1. 产品概述

慢行桥坡道点位归并工具，面向市政设计人员和运营主管，解决旧版意见被新表覆盖、归并后原始说法丢失的问题。核心价值：前端改一条备注，后端数据和导出同步变化；合并结果可追溯每条原始说法。

- 目标用户：市政设计师（老曹等）、运营主管、社区核点人员
- 核心痛点：旧版意见被新表盖掉、归并后看不到原始说法、坐标/名称不一致时归并露怯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 运营主管 | 导入材料、执行归并、修改备注、导出结果、查看摘要 |
| 市政设计师 | 查看归并结果、补充备注、导出 |
| 社区核点人员 | 查看摘要、核对点位 |

### 2.2 功能模块

1. **材料导入页**：批量导入会议纪要条目，自动解析点位名称、坐标、意见内容
2. **归并操作页**：展示待归并点位列表，支持手动/自动归并，修改备注后实时同步后端，归并结果可展开查看原始说法
3. **摘要查看页**：归并后的点位摘要，支持一键导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 材料导入页 | 纪要录入区 | 粘贴或上传会议纪要文本，解析出点位条目 |
| 材料导入页 | 条目预览表 | 显示解析出的条目列表（名称、坐标、意见、来源），标记名称/坐标异常 |
| 归并操作页 | 点位分组区 | 按名称相似度和坐标距离自动分组，支持手动调整 |
| 归并操作页 | 备注编辑区 | 修改归并后备注，实时同步后端，展示原始说法标签 |
| 归并操作页 | 重跑按钮 | 一键重新执行归并算法 |
| 摘要查看页 | 归并摘要表 | 每行一个归并点位，展示合并后名称、坐标、备注、原始说法列表 |
| 摘要查看页 | 导出按钮 | 导出为 Excel/CSV |

## 3. 核心流程

运营主管导入会议纪要 → 系统解析出点位条目 → 自动按名称相似度+坐标距离分组 → 主管检查分组，手动调整 → 修改备注（后端实时同步）→ 查看摘要 → 导出结果

    "检查/调整分组" --> "重跑归并"

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深灰蓝 (#1e293b)，辅色：暖橙 (#f59e0b) 用于操作高亮
- 按钮风格：圆角微凸，hover 微上浮
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- 布局：左侧导航 + 右侧内容区，表格为主
- 异常标记：名称不一致用橙色标签，坐标偏移用红色标签

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 材料导入页 | 纪要录入区 | 文本框 + 解析按钮，解析后切换到表格视图 |
| 材料导入页 | 条目预览表 | 表格：序号、名称、坐标、意见、来源、异常标记 |
| 归并操作页 | 点位分组区 | 卡片式分组，每组内列出原始条目，拖拽调整 |
| 归并操作页 | 备注编辑区 | 行内编辑，保存后即时同步，下方展示原始说法标签 |
| 归并操作页 | 重跑按钮 | 顶部工具栏，橙色按钮，确认弹窗 |
| 摘要查看页 | 归并摘要表 | 紧凑表格，行展开显示原始说法，最后一列"原始说法"可点击展开 |
| 摘要查看页 | 导出按钮 | 顶部工具栏，支持 CSV 下载 |

### 4.3 响应式

桌面优先，表格宽度 ≥ 1024px 时完整展示列；移动端横向滚动

### 4.4 样例数据要求

- 混入一条名称不一致材料：如"慢行天桥北坡道"与"慢行桥北坡道"
- 混入一条坐标偏到隔壁街的条目
- 合并后的反馈需展示所有原始说法原文
