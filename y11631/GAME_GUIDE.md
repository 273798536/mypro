# 做市商价差挑战 - 游戏说明

## 🎮 快速开始

### 1. 启动游戏
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 浏览器打开 http://localhost:5173
```

### 2. 开始游戏
1. 在主页选择难度（新手/进阶/专家/地狱）
2. 点击"开始游戏"按钮
3. 游戏自动开始，倒计时开始

---

## 🎯 游戏目标

作为做市商，通过**双边报价**（同时挂出买单和卖单）赚取买卖价差。在游戏时间结束时获得最高分数。

### 得分公式
```
总得分 = 已实现盈亏 + 未实现盈亏 - 手续费 - 库存惩罚 + 事件奖励
```

---

## 🕹️ 主要操作

### 挂单操作
1. **设置报价**：在中间面板输入买单价格和卖单价格
   - 买单价格应低于当前价格
   - 卖单价格应高于当前价格
   - 价差越大，成交概率越低，但利润越高

2. **调整数量**：设置每笔订单的交易数量（默认5）

3. **点击挂单**：
   - 绿色按钮挂买单
   - 红色按钮挂卖单
   - 每边最多同时挂3单

4. **快速报价**：点击左侧订单簿上的价格可快速填充报价

### 订单管理
- 查看活跃订单在报价面板下方
- 点击 × 按钮可撤销未成交订单

### 游戏控制
- ⏸️ 暂停：顶部暂停按钮
- 🔄 重开：顶部刷新按钮
- 💰 结算：提前结束游戏查看报告

## ⚠️ 风险提示（重要！）

### 1. 库存偏斜 🔴
- 库存超过 **±10** 会触发惩罚系数
- 惩罚会持续扣除得分
- 仪表盘会显示红色警告动画
- **解决方法**：通过反向交易平仓，降低库存

### 2. 价格跳空 🚨
- 随机事件导致价格瞬间涨跌3-5%
- 持仓方向与跳空方向相反会造成大幅亏损
- 屏幕会闪烁红色边框提示
- **应对策略**：保持库存中性，避免单边重仓

### 3. 手续费吞噬 💸
- 每笔成交收取手续费（0.05%-0.20%，根据难度）
- 手续费占利润比例 >50% 会在结算页高亮标红
- **避免方法**：不要频繁交易，保证每笔交易有足够价差

### 4. 强制平仓 💥
- 总得分低于 -5000 会被强制平仓
- 游戏提前结束，记入失败记录

## 🏆 结算报告

游戏结束后会生成详细的结算报告，包含：

### 盈亏分解
- 已实现盈亏：平仓赚取的价差
- 未实现盈亏：当前持仓的浮动盈亏
- 手续费：总交易成本
- 库存惩罚：风险管理不善的代价

### 交易统计
- 总成交笔数
- 买卖比
- 平均价差
- 库存超标次数

### 评级系统
- **S**：超过目标150%
- **A**：达到目标100%-150%
- **B**：达到目标70%-100%
- **C**：达到目标40%-70%
- **D**：0%-40%
- **F**：负分

### 失败原因分析
报告会明确指出需要改进的地方，如：
- 手续费占比过高
- 库存超标次数过多
- 价格跳空导致亏损

   - 播放/暂停
   - 倍速播放（0.5x / 1x / 2x / 4x）
   - 进度条拖拽
   - 导出回放JSON文件

## 💡 做市策略建议

### 新手入门
1. 保持小价差，确保成交频率
2. 及时平仓，避免库存累积
3. 不要贪多，稳扎稳打

### 进阶技巧
1. 根据市场波动率调整价差
2. 预判事件影响，提前调整仓位
3. 利用价格跳空机会，反向操作

### 风险管理
1. 永远不要让库存超过 ±10
2. 手续费是沉默的杀手，避免过度交易
3. 保持耐心，等待好的报价机会

## ❓ 常见问题

**Q: 为什么挂单没有成交？**
A: 做市商报价需要被市场"吃掉"。如果你的买单远低于当前价格，或卖单远高于当前价格，成交概率会很低。

**Q: 库存惩罚是怎么计算的？**
A: 超过阈值部分 × 惩罚系数 × 当前价格 × 0.01。例如库存15，价格100，惩罚系数0.3，则惩罚为 (15-10) × 0.3 × 100 × 0.01 = 1.5。

**Q: 可以保存游戏进度吗？**
A: 目前不支持中途保存。但每局结束后会自动保存到排行榜。

**Q: 如何提高得分？**
A: 核心是赚取稳定价差，控制库存风险。建议：
   - 保持双边报价，捕捉双向成交
   - 库存超标时及时调整
   - 避免在波动率高时重仓
