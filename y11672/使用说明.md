# 港口集装箱堆场Web3D可视化系统 - 使用说明

## 一、系统启动

### 1.1 环境要求
- Node.js >= 18
- 现代浏览器 (Chrome/Edge/Firefox/Safari 最新版)
- 支持 WebGL 的显卡

### 1.2 安装依赖
```bash
npm install
```

### 1.3 启动开发服务器
```bash
npm run dev
```
访问 `http://localhost:5173` (或提示的其他端口)

### 1.4 构建生产版本
```bash
npm run build
npm run preview
```

---

## 二、数据生成

### 2.1 模拟数据
系统启动后自动生成约180-200个模拟集装箱数据，包含：
- **普通箱**: 干货箱、冷藏箱、罐式箱、开顶箱
- **危险品箱**: 9个等级，约15%比例
- **预约箱**: 约70%有预约信息，包含5个车次
- **异常案例**: 自动植入压箱(8个)、危险品相邻(3对)、预约过期(若干)

### 2.2 数据来源标识
每个集装箱都带有数据来源标识：
- `EDI系统` / `人工录入` / `船公司同步` / `码头作业系统` / `预约平台`

### 2.3 修改历史
每个箱子保留最近的修改记录，包括：
- 修改时间、操作人
- 修改字段、原值、新值

### 2.4 重新生成数据
点击工具栏**「刷新数据」**按钮，系统会重新生成一批新的随机数据。

## 三、主要操作

### 3.1 3D视角控制
| 操作 | 说明 |
|------|------|
| 鼠标左键拖拽 | 旋转视角 |
| 鼠标滚轮 | 缩放 |
| 鼠标右键拖拽 | 平移 |
| 点击集装箱 | 选中/取消选中，显示详情 |
| 悬停集装箱 | 显示悬浮信息面板 |

### 3.2 视图模式切换
工具栏提供三种视图模式：
- **普通视图**: 显示所有集装箱，按类型着色
- **危险品视图**: 高亮危险品集装箱（红色标记）
- **提箱视图**: 高亮有待提箱任务的集装箱（绿色标记）

### 3.3 筛选功能（左侧面板）
| 筛选项 | 说明 |
|--------|------|
| 箱号搜索 | 模糊匹配箱号 |
| 贝位(Bay) | 选择堆场横向位置 |
| 排(Row) | 选择堆场纵向位置 |
| 危险品等级 | 多选0-9级危险品 |
| 预约车次 | 模糊匹配车次号 |
| 预约状态 | 多选：待处理/就绪/已完成/已过期 |

点击**「重置筛选」**清空所有筛选条件。

### 3.4 异常告警（右侧面板）
右侧面板实时显示所有异常告警，分为三类：
- **压箱**: 箱子被上层箱子压住，无法直接提取
- **危险品相邻**: 危险品之间距离过近，违反隔离规则
- **预约过期**: 预约时间已过或即将到期

**筛选**: 可按「全部/严重/警告」过滤
**定位**: 点击告警条目，自动定位到对应的集装箱

### 3.5 提箱模拟（底部操作栏）
| 操作 | 说明 |
|------|------|
| 播放/暂停 | 开始/暂停提箱动画 |
| 上一步/下一步 | 手动逐步模拟 |
| 重置 | 回到初始状态 |
| 速度控制 | 0.5x/1x/2x/4x 倍速 |
| 进度条拖拽 | 跳转到任意步骤 |

模拟过程中，被提取的集装箱会逐渐升起并淡出，表示已完成提箱。

### 3.6 悬浮信息面板
悬停或点击集装箱时，中间底部显示详情面板，包含：
- 箱号、位置(贝/排/层)
- 尺寸类型、危险品信息
- 预约信息(车次、提箱顺序、时间、状态)
- **异常信息**(如有)
- **数据来源**和**修改历史**

### 3.7 导出功能
| 功能 | 说明 |
|------|------|
| 截图 | 导出当前3D场景为PNG图片 |
| 数据 | 导出集装箱数据为JSON文件 |
| 作业报告 | 生成PDF报告，包含概览、告警列表、场景截图 |

## 四、异常路径说明

### 4.1 压箱检测
**触发条件**: 有预约的箱子上方存在其他箱子
**提示方式**:
- 集装箱顶部显示橙色警告球
- 右侧告警面板列出所有压箱
- 悬浮面板显示「箱位被 N 个箱子压住，需先移走上层箱子」

**处理建议**: 调整提箱顺序，先提取上层箱子

### 4.2 危险品相邻检测
**触发条件**: 危险品之间距离违反隔离规则：
- 1/2级危险品: 周围3x3x3范围内不能有其他危险品
- 3/4级危险品: 周围1x3x1范围内不能有同类危险品

**提示方式**:
- 集装箱轻微缩放动画 + 红色警告球
- 右侧告警面板列出违规对
- 悬浮面板显示「XX 与其他危险品距离过近，违反隔离规则」

**处理建议**: 调整危险品位置，保持安全距离

### 4.3 预约过期检测
**触发条件**:
- 预约时间已过 → 严重告警(红色)
- 预约时间2小时内到期 → 警告(黄色)

**提示方式**:
- 预约状态显示为红色「已过期」
- 右侧告警面板列出过期预约
- 悬浮面板显示「预约已过期，请尽快处理或重新预约」

**处理建议**: 尽快处理或联系相关方重新预约

### 4.4 数据加载异常
如果数据加载失败，会显示加载动画，可点击**「刷新数据」**重试。

### 4.5 导出失败处理
- **截图失败**: 检查浏览器是否允许弹窗，重试
- **报告失败**: 如果截图失败，报告仍会生成（不含截图）

## 五、技术架构

### 5.1 核心技术栈
- **前端**: React 18 + TypeScript
- **3D渲染**: Three.js + @react-three/fiber + @react-three/drei
- **状态管理**: Zustand
- **样式**: TailwindCSS 3
- **构建**: Vite 5

### 5.2 项目结构
```
src/
├── components/
│   ├── panels/          # UI面板
│   │   ├── FilterPanel.tsx      # 筛选面板
│   │   ├── AlertPanel.tsx       # 告警面板
│   │   ├── InfoTooltip.tsx      # 悬浮信息
│   │   └── SimulationBar.tsx    # 提箱模拟栏
│   ├── three/           # 3D组件
│   │   ├── YardScene.tsx        # 堆场场景
│   │   ├── Container3D.tsx      # 集装箱3D
│   │   └── Ground.tsx           # 地面
│   └── Toolbar.tsx      # 顶部工具栏
├── store/
│   └── useYardStore.ts  # 状态管理
├── types/
│   └── index.ts         # TypeScript类型
├── utils/
│   ├── dataGenerator.ts # 模拟数据
│   ├── detection.ts     # 异常检测
│   └── export.ts        # 导出功能
└── App.tsx              # 主应用
```
