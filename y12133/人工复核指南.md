# 声学节拍相似度分析 - 人工复核指南

## 📋 概览

本指南帮助音乐版权分析员解读系统输出的分析结果，进行高效、准确的人工复核。

**核心设计原则**：
- ✅ 不依赖临时表格判断节拍对齐
- ✅ 音频片段、节拍点、旋律轮廓三者对齐展示
- ✅ 变速版本和移调片段醒目标记，明确指出问题材料
- ✅ 数据、图表、导出结果三者一致，无矛盾

## 🚨 重点关注：异常检测标记

### 1. 变速版本识别

**醒目位置**：
- 控制台输出：`🚨 变速检测` 红色标记
- 图表4（`04_anomaly_detection.png`）：左上红色边框卡片
- `issues.csv`：类型为 `speed_change` 的记录

**关键指标**：
```
速度因子 ≠ 1.0 （正常范围：0.92 ~ 1.08）
  > 1.08 → 加速处理
  < 0.92 → 减速处理
```

**证据三重验证**（三者应指向同一结论）：
1. **BPM比**：文件2 BPM / 文件1 BPM
2. **节拍间隔比**：文件1平均间隔 / 文件2平均间隔
3. **时长比**：文件1时长 / 文件2时长

**复核要点**：
- 检查 `material_ref` 字段，确认哪份材料被标记为变速版本
- 如三项证据差异 > 0.1，可能存在剪辑或拼接，需仔细核对
- 严重程度：`轻微`（<15%）、`中度`（15-30%）、`显著`（>30%）

---

### 2. 移调片段识别

**醒目位置**：
- 控制台输出：`🚨 移调检测` 红色标记
- 图表4（`04_anomaly_detection.png`）：右上红色边框卡片
- 图表2（`02_melody_chroma_comparison.png`）：已自动修正移调显示
- `issues.csv`：类型为 `transposition` 的记录

**关键指标**：
```
移调半音数 ≠ 0
  正值 → 升调处理
  负值 → 降调处理
```

**验证方法**：
1. **色度相关系数**：> 0.7 为高度相关，> 0.85 为极强相关
2. **移调方向验证**：色度检测与音高检测是否一致（`shift_confirmed` 字段）
3. **12档位扫描**：图表4右下角显示各移调档位的相关性，确认最佳匹配

**复核要点**：
- 系统已自动应用移调修正进行相似度计算（见 `ℹ️ 已自动修正移调: +X 半音`）
- 如 `shift_confirmed = false`，需人工听辨确认是否真的存在移调
- 检查修正后的旋律轮廓（图表2）是否对齐

## 📊 五维相似度解读

系统计算5个维度的相似度，权重如下：

| 维度 | 权重 | 说明 | 关注点 |
|------|------|------|--------|
| 色度相似度 | 35% | 音高分布（12个音级） | 是否使用了相同的和弦进行 |
| 旋律相似度 | 25% | 主旋律轮廓走向 | 旋律线是否高度重合 |
| 节拍相似度 | 20% | 节拍间隔模式 | 节奏型是否一致 |
| 音色相似度 | 10% | 频谱特征（MFCC） | 使用的乐器/音色是否相似 |
| 节奏相似度 | 10% | 能量起伏模式 | 强弱拍分布是否一致 |

**整体相似度分级**：
```
≥ 0.85 → 🔴 极高相似度（几乎一致）
0.70 ~ 0.85 → 🟠 高相似度（明显相似）
0.55 ~ 0.70 → 🟡 中等相似度（部分相似）
0.40 ~ 0.55 → 🟢 低相似度（巧合可能）
< 0.40 → ✅ 无相似
```

## 🎯 匹配片段精确定位

**定位方法**：
1. 查看 `matched_segments.csv` 获取精确时间段
2. 对照图表1（`01_waveform_beat_comparison.png`）底部的匹配片段时间轴
3. 对照图表3（`03_dtw_alignment_analysis.png`）右下角的逐帧相似度曲线

**字段说明**：
```
文件1: 0.231s → 2.154s (时长: 1.923s)
文件2: 0.198s → 2.121s (时长: 1.923s)
平均相似度: 0.912
```

**复核操作步骤**：
1. 打开音频编辑软件（如Audacity）
2. 分别加载两个音频文件
3. 跳转到指定时间段
4. 循环播放对比，听辨是否实质性相似
5. 如相似度 ≥ 0.85 且时长 ≥ 2秒，标记为重点嫌疑

## 🥁 节拍对齐核查

**核查方法**：
1. 查看 `beat_alignment.csv`，对比两文件的节拍时间点
2. 观察图表1中上半部分的节拍点标记（蓝色/橙色三角）
3. 检查节拍间隔对比柱状图是否存在规律

**质量指标**：
- `beat_alignment_quality` > 0.7 → 对齐质量良好
- 0.5 ~ 0.7 → 对齐质量一般，需注意
- < 0.5 → 对齐质量差，结果仅供参考

**常见问题**：
- 某文件节拍数明显偏少 → 可能节拍不明显或非打击乐
- 节拍间隔差 > 0.1秒且有规律 → 可能存在变速
- 局部节拍缺失 → 可能存在剪辑或静音段

## ⚖️ 风险等级判定

| 风险等级 | 阈值条件 | 建议动作 |
|----------|----------|----------|
| 🔴 HIGH_RISK | 整体相似度 ≥ 0.8 且置信度 ≥ 0.7 | 立即启动版权复核流程 |
| 🟠 MEDIUM_RISK | 相似度 ≥ 0.65 且检测到异常 | 人工复核全部匹配片段 |
| 🟡 LOW_MEDIUM_RISK | 相似度 ≥ 0.65 无异常 | 快速人工抽查 |
| 🟢 LOW_RISK | 相似度 0.5 ~ 0.65 | 可酌情抽样复核 |
| ✅ NO_RISK | 相似度 < 0.5 | 排除抄袭嫌疑 |

**风险分值计算**：
```
总分 = 相似度×50 + 变速证据×15 + 移调证据×15 + 匹配时长×5 + 置信度×10
（满分100）
```

## 🔍 异常处理流程

### 场景1：检测到变速 + 高相似度
```
1. 核对三份变速证据是否一致
2. 检查匹配片段时长是否 ≥ 2秒
3. 听辨时注意调整播放速度对齐
4. 标记：涉嫌抄袭（变速伪装）
5. 归档：在issues.csv中记录处理结果
```

### 场景2：检测到移调 + 高相似度
```
1. 查看修正后的旋律轮廓图是否对齐
2. 确认12档位扫描的相关性峰值
3. 听辨时可使用移调插件对齐调式
4. 标记：涉嫌抄袭（移调伪装）
5. 特别注意：移调3/4/5个半音是常见伪装手法
```

### 场景3：同时检测到变速 + 移调
```
1. 这是最刻意的伪装，需高度警惕
2. 先修正速度，再修正移调
3. 使用系统自动修正后的结果作为参考
4. 检查是否存在片段拼接痕迹
5. 标记：高度涉嫌抄袭（多重伪装）
```

### 场景4：高相似度但无异常
```
1. 检查是否为同一录音的不同编码
2. 确认是否获得授权使用
3. 比对音色细节判断是否同源
4. 标记：需核查授权状态
```

## 💾 结果一致性校验

**三要素必须一致**：
1. 📊 图表中的相似度数值 = 📋 CSV中的数值 = 📄 JSON中的数值
2. 📊 图表中的匹配时间段 = 📋 CSV中的时间段 = 📄 JSON中的时间段
3. 🚨 控制台异常标记 = 📋 issues.csv记录 = 📄 issues字段

**如发现不一致**：
- 检查是否使用了相同版本的分析结果
- 确认分析参数（移调不变性、速度归一化）是否一致
- 重新运行分析确保可复现

## 💡 实用技巧

1. **快速筛查**：先看控制台输出的风险等级和异常标记，再决定是否深入
2. **重点锁定**：优先复核 `avg_similarity ≥ 0.85` 且 `duration ≥ 2s` 的片段
3. **对比聆听**：使用音频编辑软件的循环功能，反复对比匹配片段
4. **变速对比**：对检测到变速的文件，调整播放速度后再对比
5. **移调对比**：对检测到移调的文件，使用移调插件对齐后再对比
6. **批量处理**：使用 `--generate-test-data` 验证系统对已知案例的判断

## ⚠️ 局限性说明

本系统为辅助分析工具，存在以下局限性：
- 对纯打击乐或无明显旋律的音乐效果有限
- 对经过复杂效果处理（混响、失真、降噪）的片段准确率下降
- 对极短片段（< 1秒）的检测可靠性较低
- 无法判断是否属于「合理使用」或「思想/表达二分」范畴

**最终判定必须结合人工复核！**

## 📞 问题排查

| 现象 | 可能原因 | 处理方法 |
|------|----------|----------|
| 置信度 < 0.6 | 音频质量差、节拍不明显 | 检查原始音频质量 |
| 对齐质量 < 0.5 | 两首音频结构差异大 | 谨慎参考结果 |
| 三项变速证据不一致 | 可能存在剪辑拼接 | 仔细听辨完整音频 |
| 移调验证不通过 | 可能是巧合或复杂和声 | 延长听辨时间，对比更多维度 |
