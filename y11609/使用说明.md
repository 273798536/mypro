# 保险理赔免赔额复核工具 - 使用说明

## 快速开始

### 1. 启动项目
```bash
npm run dev
```
访问 http://localhost:5173/

### 2. 造数说明
- 首次进入系统会自动加载 5 条模拟理赔数据
- 点击列表页右上角「重置数据」按钮可恢复初始数据
- 数据自动保存在浏览器 localStorage 中，刷新页面不丢失

### 3. 预置测试场景
| 理赔单号 | 申请人 | 异常类型 | 说明 |
|----------|--------|----------|------|
| claim-001 | 张三 | 无异常 | 正常理赔单，可正常复核 |
| claim-002 | 李四 | 票据重复 | 票据 INV-2025-0001 与 claim-001 重复 |
| claim-003 | 王五 | 跨年度 + 缺材料 | 票据日期 2025-06-02 超出保单有效期，且缺少出院小结 |
| claim-004 | 赵六 | 需重算 | 补料后更新了总金额，未重新计算 |
| claim-005 | 孙七 | 无异常 | 已通过审核的历史单据 |

## 主要操作

### 一、查看理赔单列表
1. 进入系统默认显示理赔单列表
2. 异常单据优先排序并标红背景
3. 支持搜索：理赔单号、申请人、保单号
4. 支持按状态筛选

### 二、查看详情
1. 点击列表行右侧「眼睛」图标进入详情页
2. 可查看：保单信息、票据明细、补充材料、计算过程、赔付结论
3. 每项数据标注来源（系统导入/人工录入）
4. 异常信息在页面顶部醒目展示

### 三、编辑复核
1. 点击列表行右侧「编辑」图标或详情页「编辑复核」按钮
2. **票据管理**：
   - 填写票据号、金额、日期、来源后点击「添加」
   - 系统实时检测票据号是否重复，重复则拦截并提示
   - 可删除已有票据
3. **补充材料**：
   - 添加补料项目，设置状态（待提供/已提供/已豁免）
   - 全部材料提供后状态自动变为「复核中」
4. **规则引擎计算**：
   - 点击「执行规则引擎计算」按钮
   - 系统自动匹配免赔规则，计算赔付金额
   - 显示完整计算过程
5. **赔付结论**：填写审核意见
6. **保存/通过/驳回**：
   - 保存：仅保存修改
   - 通过：填写通过原因，状态变为已通过
   - 驳回：填写驳回原因，状态变为已驳回

### 四、查看历史记录
1. 点击列表行右侧「时钟」图标进入历史页
2. 时间线展示每次操作：创建、更新、计算、通过、驳回
3. 显示操作人、时间、变更前后对比

### 五、导出
1. 在详情页点击「导出」按钮
2. 支持三种格式：
   - **JSON**：完整结构化数据
   - **CSV**：表格格式，可用 Excel 打开
   - **赔付说明**：纯文本格式，包含完整计算过程和异常说明

## 异常路径处理

### 🔴 票据重复报销
- **表现**：
  - 列表页行背景标红，显示「票据重复」标签
  - 详情页顶部红色警示条提示
  - 编辑页添加重复票据时直接拦截
- **处理**：
  - 核实票据原件，确认是否重复报销
  - 如确属重复，删除该票据
  - 如票据无误但系统误判，可人工确认后继续

### 🟡 免赔额跨年度
- **表现**：
  - 列表页显示「跨年度免赔」标签
  - 详情页警示：票据日期不在保单年度内
- **处理**：
  - 核查保单条款，确认跨年是否适用免赔规则
  - 人工确认后可继续流程

### 🟠 补料后结论未刷新
- **表现**：
  - 列表页显示「需重新计算」标签
  - 详情页警示条提供「立即计算」快捷按钮
  - 保存前如未重算会弹出确认提示
- **处理**：
  - 点击「执行规则引擎计算」重新计算
  - 确认计算结果无误后保存

### 🔵 缺少补充材料
- **表现**：
  - 列表页显示「缺少补充材料」标签
  - 理赔单状态为「待补料」
- **处理**：
  - 催促申请人提交材料
  - 收到材料后更新状态为「已提供」
  - 所有材料齐全后自动转为「复核中」

## 核心功能

### 规则引擎
- 自动根据保单产品匹配免赔规则
- 计算公式：`赔付金额 = (总金额 - 免赔额) × 共保比例`
- 支持三种预置规则：小额医疗、门诊、住院

### 票据去重
- 维护全局票据号库
- 新增票据时实时校验
- 已存在的票据号直接拦截，不允许入库

### 状态持久化
- 使用 Zustand + localStorage
- 刷新页面状态完全恢复
- 支持「重置数据」恢复初始状态
