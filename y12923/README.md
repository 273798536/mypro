# 敏感词规则回归测试工具

## 从空目录开始的完整步骤

### 1. 安装依赖
```bash
npm run install:all
```
这会同时安装后端依赖和前端依赖。

### 2. 初始化示例数据（第一份样例）
```bash
npm run seed
```
这会创建数据库并导入第一批样例数据，位置在：
- 数据库文件：`data/sensitive_word.db`
- 示例 CSV 数据：`data/samples/` 目录下

### 3. 启动服务
```bash
# 开发模式（前后端同时启动）
npm run dev

# 或仅启动后端
npm run start
```

启动后访问：
- 前端界面：http://localhost:5173
- 后端 API：http://localhost:3001

## 核心功能

### 1. 数据导入（幂等）
- 同一批标注记录用 `batch_id` 标识
- 第二次导入相同 `batch_id` 的数据不会产生重复结论
- 已存在的记录会更新标注信息，保留修正历史

### 2. 三种样本类型
- **正常样本**：不应被拦截的安全内容
- **边界样本**：模棱两可、需要人工判断的内容
- **明显坏样本**：明确应被拦截的违规内容

### 3. 人工修正
- 对自动判定结果进行人工修正
- 每次修正都记录原因和时间戳
- 可追溯完整的修正历史

### 4. 导出功能
- 导出内容与界面摘要完全一致
- 支持 CSV 格式导出
- 包含完整的判定结果和修正历史
