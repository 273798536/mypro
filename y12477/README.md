# 🌊 水波干涉乐园

课堂/培训用的水波干涉物理模拟游戏，重点解决边界反射的判定问题。

## 核心功能

### 1. 波源数据模型 (`wave_source.py`)
- 支持备注字段（物理社团老师的标注）
- 自动处理缺字段（如相位缺失时用默认值 0）
- 波源重叠检测
- 状态标记：正常/不完整/重叠

### 2. 波动模拟核心 (`wave_simulator.py`)
- 多波源叠加计算
- 干涉模式分类（平静/弱/中/强干涉）
- 各波源贡献度追踪

### 3. 边界反射检测 (`boundary_reflection.py`)
**三种反射类型，流程分明：**
- ✅ `NORMAL` - 正常反射，无需处理
- ⚠️ `EXCEPTION_NEEDS_CONFIRM` - 例外情况，需人工确认
- ❌ `ERROR` - 明确错误

**检测成因：**
- 边界边缘反射
- 振幅尖峰异常
- 波源距离过近

### 4. 水面网格延迟处理 (`water_grid.py`)
- 异步创建网格（模拟"晚到"的情况）
- Promise 风格回调
- 超时和错误处理

### 5. 结算系统 (`settlement.py`)
**关键特性：**
- 失败时详细说明与波动模拟的关系
- 不只是给总分，要说清楚物理原理
- 失败原因分类：
  - 波源重叠
  - 边界反射过多
  - 波源数据不完整
  - 模拟错误
  - 振幅不达标

### 6. 游戏主流程 (`game.py`)
- 三条预设样例场景
- 完整的游戏记录追踪

## 快速开始

物理社团老师无需读代码，直接运行：

```bash
pip install -r requirements.txt
python main.py
```

然后按 Enter 逐步查看三个样例：

| 样例 | 场景 | 预期结果 | 验证分支 |
|------|------|----------|----------|
| 1 | 正常双波源干涉 | 胜利 | 正常分支 |
| 2 | 靠近边界的高振幅波源 | 待人工复审 | 边界反射例外分支 |
| 3 | 波源重叠且缺字段 | 失败，附带波动模拟关系说明 | 失败分支 |

## 设计要点

1. **边界反射不等于错误** - 流程中明确区分正常、需确认、错误三种状态
2. **玩家选择影响局势** - 波源位置、振幅、相位的选择直接影响后续结算
3. **输赢后知道原因** - 结算报告关联物理原理，解释为什么失败
4. **包容不完美数据** - 波源备注、缺字段、网格延迟都能正常处理
5. **样例驱动验证** - 三条样例覆盖主要分支，老师无需读代码
