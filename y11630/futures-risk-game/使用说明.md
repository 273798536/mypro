# 期货交易风控桌游 - 使用说明

## 一、启动方式

### 1. 开发环境启动
```bash
# 进入项目目录
cd futures-risk-game

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```
启动后访问：http://localhost:5173/

### 2. 生产构建
```bash
# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 二、游戏流程

### 1. 开始界面
- 点击「开始游戏」按钮进入游戏
- 系统自动生成4个客户账户和初始持仓
- 每局游戏共10个回合，每回合30秒

### 2. 游戏主界面
- **顶部状态栏**：显示当前回合、剩余时间、总分数
- **控制按钮**：暂停/继续、重开
- **客户账户区**：4个客户账户卡片，显示风险度和持仓
- **交易操作区**：追加保证金、部分平仓、全部平仓、跳过
- **行情事件区**：显示当前回合的行情事件
- **强平队列**：风险度超标的账户按优先级排序
- **爆仓记录**：记录已爆仓的账户

### 3. 操作步骤
1. **选择账户**：点击客户账户卡片选中要操作的账户
2. **选择操作**：
   - **追加保证金**：向账户注入资金，将风险度降到安全线以下
   - **部分平仓**：平掉一半持仓，释放保证金
   - **全部平仓**：平掉所有持仓，立即止损
   - **跳过本回合**：不进行操作，进入下一回合
3. **确认操作**：高危操作需要二次确认

## 三、核心机制

### 1. 风险度计算
```
风险度 = 保证金占用 / 账户权益 × 100%
```
- **安全**：风险度 < 80%（绿色）
- **预警**：80% ≤ 风险度 < 100%（黄色）
- **危险**：100% ≤ 风险度 < 120%（橙色）
- **强平**：风险度 ≥ 120%（红色）

### 2. 行情事件
- 每回合随机触发行情事件
- 事件类型：大涨、小涨、大跌、小跌、震荡
- 极端行情可能连续触发（行情连跳）

### 3. 强平规则
- 风险度 ≥ 120% 自动进入强平队列
- 按风险度从高到低排序
- 如玩家未及时处理，系统将自动强平
- 强平顺序争议：始终以风险度优先级为准

## 四、异常场景处理

### 1. 行情连跳
- 连续2-3个回合出现极端行情
- 界面显示「行情连跳」警告标识
- 多个账户同时进入强平队列

### 2. 客户资金不足
- 追加保证金时检查账户可用资金
- 资金不足时显示明确提示
- 建议改用平仓操作

### 3. 强平顺序争议
- 强平队列按风险度严格排序
- 相同风险度按账户权益排序
- 所有操作都有日志记录，可复盘查证

### 4. 操作超时
- 每回合30秒倒计时
- 超时后系统自动处理：
  - 有强平队列时自动强平最高风险账户
  - 无强平队列时跳过本回合

## 五、结算与复盘

### 1. 结算条件
- 完成全部10个回合
- 或所有账户爆仓
- 或玩家主动结束游戏

### 2. 成绩评级
- **S级**：90分以上，零爆仓
- **A级**：75-89分，1个以内爆仓
- **B级**：60-74分，2个以内爆仓
- **C级**：60分以下，3个以上爆仓

### 3. 复盘功能
- 查看每回合的操作记录
- 失败原因分析
- 得分明细拆解
- 操作日志回放

### 4. 成绩导出
- 支持导出JSON格式
- 支持导出CSV格式
- 包含：基本信息、得分明细、操作日志、爆仓记录

## 六、数据生成机制

### 1. 客户账户
- 4个虚拟客户，资金规模10万-50万
- 初始持仓1-3个期货合约
- 风险度随机分布在50%-90%

### 2. 期货合约
- 豆粕、螺纹钢、原油、黄金、沪深300
- 每个合约有独立的保证金比例

### 3. 行情事件
- 价格波动范围：±3% ~ ±15%
- 极端行情概率：20%
- 连跳概率：连续极端行情时增加

## 七、快捷键

- 空格：暂停/继续
- R：重开游戏
- 1-4：快速选择客户账户
- A：追加保证金
- P：部分平仓
- F：全部平仓
- S：跳过本回合

## 八、常见问题

### Q: 为什么不能追加保证金？
A: 请检查账户是否有足够的可用资金，或尝试减少追加金额。

### Q: 强平后为什么分数扣了很多？
A: 系统强平会额外扣分，建议在进入强平队列前主动处理。

### Q: 如何查看历史操作？
A: 游戏结算后可在复盘面板查看完整操作日志。

### Q: 可以自定义游戏参数吗？
A: 修改 `src/constants/gameConfig.ts` 中的配置项。
