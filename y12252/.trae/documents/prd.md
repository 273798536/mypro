## 1. 产品概述
数学证明法庭是一款浏览器内单局制辩论模拟游戏，玩家扮演法官角色，审查学生提交的数学证明题。通过拖拽条件卡、连线逻辑推理链、判定反例证据的有效性，发现证明中的引理错用、条件缺失和反例未排除等错误，最终给出判决并生成可分享的判决报告。
- 目标用户：奥数教练、数学教师、数学教育工作者
- 核心价值：将枯燥的证明审查过程游戏化，提升教师发现学生证明跳步问题的效率，并产出结构化判决报告便于同事协作

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 法官（玩家） | 直接进入游戏 | 审查证明、连线判定、导出报告 |
| 观察者 | 通过分享链接查看 | 查看判决报告和复盘 |

### 2.2 功能模块
1. **游戏主页面**：案件概览、条件卡面板、反例证据面板、逻辑连线画布、计时器、操作按钮（开始/暂停/重开）
2. **结算页面**：步骤评分明细、扣分原因说明、最终得分与评级
3. **复盘页面**：逐步回放游戏过程、查看每步判定结果、对比正确推理链
4. **判决报告页面**：结构化报告展示、一键导出/分享

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主页面 | 案件概览 | 展示当前证明题目、学生原始证明文本、已发现的问题计数 |

| 游戏主页面 | 计时器 | 倒计时/正计时，暂停时冻结，显示剩余/已用时间 |
| 游戏主页面 | 操作栏 | 开始、暂停、重开按钮，当前回合状态指示 |

## 3. 核心流程

玩家进入游戏后，先查看证明题目和学生证明文本，然后通过拖拽条件卡到画布、连线构建逻辑链、判定反例证据等操作完成审查。每一步操作都会影响最终评分。游戏结束后进入结算页面查看评分，可进入复盘回放过程，最终导出判决报告。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色法庭风格，深棕木纹质感底色 + 金色高光点缀，营造严肃庄重的法庭氛围
- 辅助色：证据绿（已排除）、警告红（未排除/错误）、推理蓝（逻辑连线）
- 按钮风格：立体浮雕效果，金色边框，深色填充，hover时金色光晕
- 字体：标题使用衬线体（如 Playfair Display），正文使用等宽风格字体（如 JetBrains Mono）突出数学公式感
- 布局：左侧条件卡/证据面板，中央逻辑连线画布，右侧计时器和操作面板
- 图标/装饰：天平、法槌、卷轴等法律元素装饰，数学符号作为点缀

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主页面 | 案件概览 | 卷轴风格卡片，金色标题栏，衬线体标题，等宽体证明文本 |
| 游戏主页面 | 条件卡面板 | 卡片式列表，原始条件用实线金色边框，推导条件用虚线蓝色边框，拖拽手柄 |
| 游戏主页面 | 反例证据面板 | 证据卡带状态标签（已排除/未排除），红/绿色标识 |
| 游戏主页面 | 逻辑连线画布 | SVG画布，节点可拖拽，连线带箭头和标签，有效连线绿色、无效连线红色、待判定黄色 |
| 游戏主页面 | 计时器 | 怀表造型，金色边框圆形，数字等宽字体，暂停时指针冻结动画 |
| 游戏主页面 | 操作栏 | 浮雕按钮组，法槌图标开始，沙漏图标暂停，刷新图标重开 |
| 游戏主页面 | 证据导入区 | 拖拽上传区域，文件类型图标，导入后分栏显示原始材料和处理结果 |
| 结算页面 | 得分总览 | 大号金色评分，星级/等级徽章，木纹背景 |
| 结算页面 | 步骤评分明细 | 表格式，每行一个步骤，扣分项红色高亮，展开可查看原因 |
| 结算页面 | 扣分解释 | 弹出式详情卡，引用具体证据卡编号和判定记录 |
| 复盘页面 | 回放控制器 | 播放/暂停/上下步按钮，时间线进度条带步骤标记 |
| 复盘页面 | 逐步对比 | 左右分栏，左侧玩家操作，右侧正确推理，差异高亮 |
| 判决报告页面 | 报告正文 | 官方文书风格，印章装饰，结构化排版 |
| 判决报告页面 | 导出与分享 | 导出按钮组，分享链接输入框，证据判定口径附录 |

### 4.3 响应式设计
- 桌面优先设计，最小支持1024px宽度
- 画布区域自适应，条件卡面板可折叠
- 触屏支持：拖拽操作兼容触摸事件

### 4.4 3D场景指引
- 不适用，本项目为2D界面
