# 地铁换乘楼层人流分析系统 — 使用说明

## 1. 启动

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后打开浏览器访问控制台显示的地址（默认 http://localhost:5173）。

系统首次启动会自动加载示例数据（120 条模拟人流记录，包含约 12% 的异常离群点）。

---

## 2. 导入数据

支持导入 JSON 格式的人流记录数组。单条记录格式如下：

```json
{
  "id": "abc123",
  "timestamp": 1718000000000,
  "x": 45.2,
  "y": 32.7,
  "floor": 2,
  "peopleCount": 78
}
```

导入操作：点击主界面顶部 **「导入」** 按钮 → 选择 `.json` 文件 → 系统自动进行异常检测。

支持的异常类型：
- **剖切面越界**：坐标 (x,y) 或楼层超出画布边界
- **人流突增**：单点位人流超过 160 人
- **零人流异常**：非空时段检测到零人流

---

## 3. 查看异常与复核

### 主界面交互
- **鼠标滚轮**：缩放剖面图
- **拖拽空白**：平移视角
- **双击**：复位视角
- **点击数据点**：查看详情 + 异常复核

### 检测流程（游戏化控制）
| 按钮 | 功能 |
|------|------|
| 开始检测 | 进入运行状态，自动登记已检测到的异常点，碰撞检测开始记录 |
| 暂停 / 继续 | 控制检测进程 |
| 结算 | 生成得分与碰撞记录 |
| 复盘 | 进入回溯模式 |
| 重开 | 清空当前会话，重新开始 |

### 异常复核
1. 在剖面图或异常列表中点击一条异常记录
2. 填写 **复核人** 与 **处理意见**（必填）
3. 点击 **「确认异常」** 或 **「排除异常」**
4. 所有复核动作永久写入 **处理历史**，包含：操作人、时间、原因

### 碰撞检测与视角保存
- 鼠标悬停或点击数据点时自动产生碰撞事件
- 每次视角缩放 / 平移后自动保存快照
- 碰撞检测与视角快照共用同一批 `GameSession` 处理记录，界面、报告数据完全一致

---

## 4. 剖面图对比（新旧结论并排看）

点击顶部 **「剖面图对比」** 进入：

- 左右两侧各选择一个剖面版本（支持历史快照 + 当前实时剖面）
- 下方 **变更差异分析** 自动统计：
  - 未变更的异常
  - 已排除的异常（旧有新无）
  - 新增异常（旧无新有）

修改剖面图后，可直接并排对比影响范围，无需靠猜。

---

## 5. 异常处理中心

点击顶部 **「异常处理」** 进入：

- 四色统计卡：全部 / 待复核 / 已确认 / 已排除
- **异常列表**：支持按 ID、类型搜索，支持一键「定位 →」跳回剖面图
- **复核详情**：完整处理历史时间线，可回溯每条操作的：
  - 谁改的（user）
  - 什么时候改的（timestamp）
  - 为什么改（reason）
- **全局操作时间线**：所有异常的处理动作汇总展示

顺着一条异常往回查 → 能看到剖面图定位 + 处理意见 + 完整历史，链路通顺。

---

## 6. 导出结果

点击主界面 **「导出」** 按钮，下载完整 JSON 报告，包含：

```jsonc
{
  "generatedAt": "...",
  "sessionId": "...",
  "totalRecords": 120,
  "anomaliesFound": 14,
  "anomaliesConfirmed": 8,
  "anomaliesDismissed": 3,
  "records": [ /* 原始数据 */ ],
  "anomalies": [ /* 异常记录 */ ],
  "snapshots": [ /* 所有剖面快照，用于回溯对比 */ ]
}
```

## 数据边界参考

| 维度 | 合法范围 |
|------|----------|
| X 坐标 | 0 – 100 |
| Y 坐标 | 0 – 80 |
| 楼层 | 1 – 3 |
| 单点位人流 | 0 – 200 |
