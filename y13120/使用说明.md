# 最短路径错题复盘 · 使用说明

只讲三件事: **启动 / 重跑 / 查看截图说明**。不讲虚的。

---

## 一、启动（一条命令跑完整包样例）

在项目根目录下执行:

```bash
python3 sp_review.py run-all
```

第一次运行会自动:

1. 在 `samples/` 下生成 5 份样例 CSV (共 30 行数据, 覆盖正确/距离错/排序不稳/空集合/脏数据 5 种场景)
2. 逐行对比 `student_answer` 与 `expected_answer`
3. 在控制台打印汇总, **退出提示会直接说清排序不稳定卡在哪** (样例3里 B/E 同距离 5, 学生先写 B 但应该先写 E)
4. 在 `output/` 生成两份报告:
   - `latest_report.md` — 技术报告 (含影响范围、来源行、原始草稿字段、文件指纹)
   - `human_readable_report.md` — 白话报告 (给不看代码的人, 数字从哪来有线索)
5. 在 `store/state.json` 保存本次运行的所有状态 (供后续重跑/备注/截图关联)

**退出码**:

| 码 | 含义 |
|---|---|
| 0 | 全部通过 |
| 3 | 排序不稳定 (最常见, 看退出提示里的 "卡住 @ … 第X位") |
| 4 | 有空集合输入 (阿宁月底的痛点) |
| 5 | 脏数据解析失败 (已保留原稿, 不清洗) |

> 如果想同时加一句备注 (比如"张老师发过来的这一批"):
> ```bash
> python3 sp_review.py run-all --note "张老师5月批次"
> ```

## 二、重跑

和启动是同一条命令:

```bash
python3 sp_review.py run-all
```

每次重跑:

- 会生成**新的 `run_id`** (时间戳格式), 追加到 `store/state.json` 的 `runs` 数组
- 上一次运行的**历史备注、截图说明、状态**全部保留, 不会被覆盖
- `current_run_id` 自动指向最新一次
- `output/latest_report.md` 与 `output/human_readable_report.md` 更新为最新一次的内容

想查看所有历史运行:

```bash
python3 sp_review.py list-runs
```

想看当前运行的状态 (退出码、提示、备注数、截图数):

```bash
python3 sp_review.py status
```

想给某次运行追加历史备注 (不指定 `--run-id` 就加给当前):

```bash
python3 sp_review.py add-note "排序不稳那题已和教研确认, 是学生用了heapq无稳定性"
python3 sp_review.py add-note "只改了样例3" --run-id "2026-06-12_14-30-00"
```

## 三、查看截图说明

### 3.1 先登记截图

把截图放到 `screenshots/` 目录 (或任意位置), 然后登记:

```bash
python3 sp_review.py add-screenshot "screenshots/sort_unstable_board.png" "白板书: 样例3距离=5时 B先于E的排序过程"
```

登记后:

- 截图说明会写入 `store/state.json` 对应 run 的 `screenshots` 里
- `output/latest_report.md` 末尾的"备注与截图"章节会自动刷新, 让截图说明和报告保持对得上
- 重启/重跑后, 只要 run_id 还在, 截图说明就一直在

### 3.2 查看某运行的所有截图说明

```bash
python3 sp_review.py show-screenshots           # 当前运行
python3 sp_review.py show-screenshots --run-id "2026-06-12_14-30-00"   # 指定历史运行
```

输出格式:

```
运行 2026-06-12_14-30-00 截图说明 (共2张):
  1. screenshots/sort_unstable_board.png
     说明: 白板书: 样例3距离=5时 B先于E的排序过程
     记录: 2026-06-12 14:35:22
```

## 附: 目录结构（一次看懂, 别再问文件放哪）

```
y13120/
├── sp_review.py              # 工具本体, 一切入口
├── samples/                  # 样例数据 (run-all 时自动生成)
│   ├── sample01_basic_ok.csv
│   ├── sample02_wrong_distance.csv
│   ├── sample03_sort_unstable.csv    # ← 排序不稳在这里
│   ├── sample04_empty_set.csv        # ← 空集合在这里
│   └── sample05_dirty_draft.csv      # ← 脏数据在这里
├── store/
│   └── state.json            # 持久化: 历史runs + 备注 + 截图说明 (跨重启不丢)
├── output/
│   ├── latest_report.md      # 技术报告: 有影响范围/来源行/原始字段/指纹
│   └── human_readable_report.md  # 白话报告: 讲给不看代码的人听
└── screenshots/              # 截图文件放这里 (自己放)
```
