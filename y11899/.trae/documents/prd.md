## 1. 产品概述

多目标评分排序器——面向设备采购评审委员会的评分排名工具，解决委员临时改权重导致排名混乱、异常报价难以识别、淘汰/并列项无法溯源的核心痛点。目标用户为采购评审委员及采购管理人员，核心价值在于：评分流程可回看、权重校验可审计、异常路径可验证。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 评审委员 | 参与设备采购评分 | 调整权重、添加备注、查看排名与异常 |
| 采购管理员 | 组织评审流程 | 导入供应商报价、锁定权重、导出结果 |

### 2.2 功能模块

1. **评分面板**：供应商报价录入/导入、四维权重调节（价格/能耗/售后/交付期）、评委备注
2. **排名看板**：加权排名表、雷达图、淘汰/并列标注、异常说明
3. **溯源与审计**：权重变更历史、异常数据追踪、前后一致性校验
4. **导出中心**：CSV 导出、一致性校验报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 评分面板 | 供应商报价区 | 录入/粘贴供应商原始报价，保留原始名称与单位，支持逐条标注数据来源 |
| 评分面板 | 权重调节区 | 四维滑块调节权重，实时显示权重总和，总和≠100%时高亮警告并锁定计算 |
| 评分面板 | 评委备注区 | 每条备注绑定供应商+评分项，备注文本保留原始输入 |
| 排名看板 | 加权排名表 | 按加权总分排序，并列排名相同序号，淘汰项红色标注并指回具体评分项 |
| 排名看板 | 雷达图 | 各供应商四维得分的雷达对比图，异常维度用虚线标注 |
| 排名看板 | 异常说明面板 | 列出所有异常（报价为0/负数/极端偏离、权重不一致），每条可点跳至原始数据 |
| 溯源与审计 | 权重变更历史 | 记录每次权重调整的前后值，标注调整人与时间 |
| 溯源与审计 | 一致性校验 | 对比当前权重、评分、排名与导出内容是否一致，不一致时列出差异原因 |
| 导出中心 | 导出面板 | 一键导出CSV，导出前自动触发一致性校验，不一致时阻止导出并提示 |

## 3. 核心流程

委员进入评分面板 → 确认供应商报价数据完整 → 调节四维权重 → 系统校验权重总和=100% → 计算加权得分 → 生成排名 → 异常检测自动标注 → 查看排名看板（雷达图+排名表+异常说明） → 如有异常，点击溯源至原始数据 → 确认无误后导出结果

```mermaid
    "A[录入/导入供应商报价]" --> "B[调节四维权重]"
    "B" --> "C{权重总和=100%?}"
    "C" -->|"否"| "D[高亮警告，锁定计算]"
    "D" --> "B"
    "C" -->|"是"| "E[计算加权得分]"
    "E" --> "F[生成排名]"
    "F" --> "G[异常检测]"
    "G" --> "H[排名看板展示]"
    "H" --> "I{一致性校验通过?}"
    "I" -->|"否"| "J[列出差异原因]"
    "J" --> "K[修正后重新校验]"
    "K" --> "I"
    "I" -->|"是"| "L[导出CSV]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1E293B) + 琥珀色 (#F59E0B) 作为强调色，传达专业与警示并存
- **次色调**：石板灰 (#64748B) 用于边框与辅助文字，翠绿 (#10B981) 用于正常状态
- **按钮风格**：圆角 (rounded-lg)，主操作用实色填充，次要操作用描边
- **字体**：Noto Sans SC 作为正文，JetBrains Mono 用于数字/评分显示
- **布局**：左侧固定导航 + 右侧内容区，卡片式模块布局
- **图标风格**：Lucide 线性图标，统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 评分面板 | 供应商报价区 | 可编辑表格，行悬停高亮，异常行红底标注，列头固定 |
| 评分面板 | 权重调节区 | 四组滑块+数字输入，实时总和进度条，警告横幅 |
| 评分面板 | 评委备注区 | 浮动标签输入框，按供应商分组，可折叠 |
| 排名看板 | 加权排名表 | 排名列+供应商名+四维分+总分，淘汰行红色背景，并列同序号 |
| 排名看板 | 雷达图 | SVG 雷达图，4轴，多供应商叠加，异常维度虚线 |
| 排名看板 | 异常说明面板 | 右侧抽屉式面板，异常列表带图标与跳转链接 |
| 溯源与审计 | 权重变更历史 | 时间线列表，每条显示变更前后值 |
| 溯源与审计 | 一致性校验 | 校验状态卡片，通过/不通过+差异详情 |
| 导出中心 | 导出面板 | 导出按钮+校验状态，阻止导出时显示原因 |

### 4.3 响应式

- 桌面优先（1280px+），平板适配（768px+），移动端基本可用
- 表格在窄屏横向滚动，雷达图自适应缩放
