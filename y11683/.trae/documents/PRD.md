## 1. 产品概述

期货期限结构隧道可视化工具，面向大宗研究员，将不同交割月的期货价格以3D隧道形式呈现，快速发现近远月倒挂现象。
- 核心解决：传统2D图表难以直观展示多合约月份价格时序关系，研究员难以快速识别倒挂、月份缺口等异常
- 目标用户：大宗商品研究员、期货分析师、交易员
- 产品价值：让期限结构的三维关系一目了然，显著降低分析成本，提高倒挂发现效率

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 大宗研究员 | 本地工具无需注册 | 上传数据、3D交互分析、导出图表、查看修正痕迹 |

### 2.2 功能模块
1. **主页面**：3D隧道视图 + 侧边明细面板 + 顶部工具栏 + 底部时间轴播放器
2. **数据上传模块**：CSV/Excel导入，字段映射，错误保留原始行号
3. **3D隧道可视化模块**：三维曲线渲染、月份轴、价格轴、时间轴、成交量热力
4. **倒挂检测模块**：自动识别近远月价格倒挂，高亮标注，可筛选
5. **异常检测模块**：月份缺口提示、成交量遮挡检测、倒挂标注验证
6. **明细联动模块**：3D视图交互与侧边面板实时同步
7. **时间播放模块**：按时间窗口自动推进，动态展示期限结构变化
8. **导出模块**：PNG截图、CSV导出修正后数据

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 3D隧道画布 | Three.js渲染三维期限结构，X轴=合约月份，Y轴=价格，Z轴=时间窗口；支持鼠标拖拽旋转、滚轮缩放、悬停提示 |
| 主页面 | 侧边明细面板 | 显示当前选中合约的详细信息：合约月份、价格、成交量、基差、时间窗口、研究备注、数据来源、修正记录 |
| 主页面 | 顶部工具栏 | 数据上传按钮、倒挂筛选开关、成交量热力开关、视角重置、导出按钮 |
| 主页面 | 底部时间轴 | 可拖动的时间滑块，支持播放/暂停，显示当前时间窗口范围 |
| 主页面 | 异常提示区 | 浮动提示卡片，展示月份缺口、倒挂标注异常、成交量遮挡等警告，附带原始行号 |
| 数据上传 | 字段映射界面 | 上传CSV/Excel后，列名与系统字段匹配，确认后入库；解析错误保留原始行号定位 |
| 数据上传 | 错误报告 | 列出解析失败、格式异常、数据缺口的行，保留原始行号和来源，标记为待修正 |

## 3. 核心流程

研究员上传期货数据 → 系统校验并标注异常（保留原始行号） → 3D隧道自动渲染期限结构 → 研究员通过拖动/旋转/筛选交互探索 → 发现倒挂或异常时点击高亮 → 侧边面板显示该合约明细及来源 → 可播放时间轴观察演变 → 导出截图或数据

## 4. 用户界面设计

### 4.1 设计风格
- **主色**：深空蓝 `#0A1628`，营造专业金融数据终端感
- **强调色**：倒挂红 `#FF4757`（警示）、正常绿 `#2ED573`、信息蓝 `#3B82F6`
- **背景**：深色渐变 + 微妙网格纹理，3D场景内用暗色雾化增强纵深感
- **按钮风格**：扁平圆角，3px圆角，悬停发光效果
- **字体**：系统等宽字体展示数据（价格/月份），无衬线字体展示标签和注释
- **布局**：左侧3D画布占65%，右侧明细面板占35%，底部时间轴贯穿全宽
- **图标**：简洁线性图标，使用SVG

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 3D隧道画布 | Three.js Canvas，相机透视投影，OrbitControls拖拽；曲线用TubeGeometry，颜色按基差渐变；X/Y/Z轴带刻度标签；悬停显示十字准星和浮动tooltip |
| 主页面 | 侧边明细面板 | 卡片式布局，分区展示：合约信息、研究备注、修正历史、数据来源；标题栏可折叠；滚动条自定义样式 |
| 主页面 | 顶部工具栏 | 透明磨砂背景，图标+文字按钮，悬停上浮；右侧为操作按钮组 |
| 主页面 | 底部时间轴 | 渐变进度条，当前帧指示线，播放/暂停按钮，速度控制，帧步进 |
| 主页面 | 异常提示区 | 右下角浮动卡片，警告图标+文字，点击跳转对应数据位置；多条可折叠展开 |
| 数据上传 | 字段映射界面 | 表格形式展示列名映射，下拉选择目标字段类型，必填字段标记红色 |
| 数据上传 | 错误报告 | 按严重程度分组（错误/警告/信息），每行显示原始行号、列名、错误原因，可标记为已修正 |

### 4.3 响应式设计
- 桌面端优先设计，最小支持宽度1200px
- 侧边面板可折叠至25%宽度
- 3D画布自适应容器尺寸
- 触控设备支持双指缩放和单指拖动

### 4.4 3D场景指引
- **环境**：深空蓝背景 `#0A1628`，Fog雾化 `#0A1628`，近0远200
- **光照**：AmbientLight强度0.4，DirectionalLight从右上方，强度0.8，色温5000K
- **相机**：PerspectiveCamera，初始位置(80, 60, 100)，FOV 45
- **构图**：X轴从左到右为合约月份（近月→远月），Y轴价格从下到上，Z轴从后到前为时间窗口
- **交互**：OrbitControls，阻尼0.05，禁用平移；悬停曲线高亮；点击选中联动侧边面板
- **后期处理**：Bloom泛光效果增强曲线发光感；SMAA抗锯齿
- **性能**：单条曲线最多200个采样点，总曲线数≤50；使用InstancedMesh优化；目标帧率60fps
