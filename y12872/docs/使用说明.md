# 海洋科考样品箱追踪系统 - 使用说明

## 一、启动

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化数据库

```bash
python cli.py init
```

### 3. 生成演示数据（可选，用于验收测试）

```bash
python generate_demo.py
```

演示数据包含一条"风浪预报晚到"的验收场景：样品箱 BOX007（舟山站，2024-06-17）关联的风浪预报晚到6小时。

### 4. 导入演示数据

```bash
python cli.py import boxes data/demo/样品箱数据.xlsx
python cli.py import logs data/demo/养殖日志数据.xlsx
python cli.py import waves data/demo/风浪预报数据.xlsx
```

### 5. 启动 Web 界面

```bash
python app.py
```

启动后访问：http://localhost:5000

---

## 二、导入数据

支持三种数据类型导入，格式支持 Excel (.xlsx) 和 CSV。

### 命令行导入

```bash
# 导入样品箱数据
python cli.py import boxes <文件路径>

# 导入养殖日志
python cli.py import logs <文件路径>

# 导入风浪预报
python cli.py import waves <文件路径>
```

### 数据字段说明

**样品箱数据字段：**
- 样品箱编号（必填）
- 航次名称
- 站点名称
- 样品类型
- 采样时间
- 存储温度（℃）
- 运输状态

**养殖日志字段：**
- 日期（必填）
- 站点名称
- 水温
- 盐度
- 溶解氧
- PH值
- 投饵量
- 死亡数
- 备注

**风浪预报字段：**
- 预报日期（必填）
- 预报时间
- 站点名称
- 浪高
- 浪周期
- 风速
- 风向
- 预报发布时间
- 实际到达时间
- 是否延迟（是/否）
- 延迟原因

## 三、查看异常

### 命令行查看

```bash
# 查看汇总统计
python cli.py summary

# 列出所有样品箱
python cli.py list

# 只看异常的
python cli.py list --status abnormal

# 搜索某个样品箱
python cli.py list --keyword BOX007
```

### Web 界面查看

1. 打开 http://localhost:5000
2. 首页展示所有样品箱列表，每行有颜色状态标记
3. 可通过下拉框按状态筛选，或输入关键词搜索
4. 点击"查看/追溯"进入详情页

### 颜色含义

| 颜色 | 状态 | 说明 |
|------|------|------|
| 🟢 绿色 | 正常 | 无异常 |
| 🟡 黄色 | 预警 | 需关注 |
| 🔴 红色 | 异常 | 检测到异常 |
| 🔵 蓝色 | 已复核 | 完成复核 |
| ⚪ 灰色 | 待处理 | 刚导入未检测 |

### 异常类型

- **风浪预报晚到**：采样当日的风浪预报延迟到达
- **样品温度越界**：存储温度超出 2-8℃ 范围
- **运输超时**：运输状态标记为延迟
- **养殖日志缺失**：采样当日无对应养殖日志

## 四、追溯与复核

### 追溯链路

每个异常都可以从结果一路追溯回来源：

```
结果（样品箱状态）
  ↓
处理记录（谁、什么时候、做了什么操作）
  ↓
关联原始数据（养殖日志、风浪预报）
  ↓
来源文件（哪个文件、第几行）
```

**命令行追溯：**
```bash
python cli.py trace BOX007
```

**Web 界面追溯：**
进入样品箱详情页，向下滚动查看"追溯链路"板块。

### 复核操作

**命令行复核：**
```bash
python cli.py review BOX007
```

交互式输入复核人、结果、意见、处理建议。

**Web 界面复核：**
进入样品箱详情页，滚动到"复核入口"，填写表单提交。

复核后样品箱状态自动更新，处理记录自动新增，报告导出时包含最新复核结果。

## 五、导出结果

### 命令行导出

```bash
# 导出完整 Excel 报告
python cli.py export

# 只导出异常的
python cli.py export --status abnormal

# 导出 CSV 格式
python cli.py export --format csv

# 导出 JSON 格式
python cli.py export --format json
```

### Web 界面导出

1. 点击顶部导航"报告导出"
2. 选择格式和筛选条件
3. 点击"生成报告"
4. 下载生成的文件

### 导出内容

Excel 报告包含 4 个工作表：
1. **汇总** - 各状态数量统计
2. **样品箱列表** - 所有样品箱详情
3. **复核记录** - 所有复核意见和处理建议
4. **处理记录** - 所有操作记录（含来源文件和行号）

### 数据一致性

界面展示和报告导出共用同一批处理记录：
- 导入、检测、复核等所有操作都写入 `processing_records` 表
- 报告导出时直接从该表读取，不会单独计算
- 复核操作同时更新状态表和记录表

## 六、验收测试流程（风浪预报晚到场景）

1. 生成演示数据：`python generate_demo.py`
2. 依次导入三类数据
3. 查看汇总：`python cli.py summary`，确认有异常数据
4. 查看异常列表：`python cli.py list --status abnormal`
5. 找到 BOX007，追溯链路：`python cli.py trace BOX007`
6. 验证能看到：风浪预报延迟记录、养殖日志、处理记录
7. 进行复核：`python cli.py review BOX007`
8. 导出报告：`python cli.py export`
9. 打开报告，确认复核记录已包含在内
