## 1. 产品概述

精算助理的蒙特卡洛保费模拟工具——把保单样本、赔付分布、费用率对齐到一次模拟里跑完。核心解决两个痛点：样本不足时参数对比说不清、极端赔付出现后不知道卡在哪份材料。

- 目标用户：产险/再保精算助理、定价分析师
- 核心价值：用随机模拟暴露极端赔付风险，用材料追溯定位问题来源，而不是只给一个"处理失败"

## 2. 核心功能

### 2.1 功能模块

1. **模拟工作台**：保单样本导入、参数配置、蒙特卡洛模拟运行、结果展示
2. **风险诊断面板**：极端赔付拦截诊断、材料卡点追溯、VaR/TVaR 风险指标

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 模拟工作台 | 保单样本区 | 粘贴/上传 CSV 导入保单样本，展示样本摘要（条数、保额范围、赔付记录数） |
| 模拟工作台 | 参数配置区 | 免赔额、限额、费用率、安全加载、模拟次数，每项可调且标注对保费的影响方向 |
| 模拟工作台 | 模拟运行区 | 一键运行蒙特卡洛，进度条，完成后展示纯保费、毛保费、综合成本率 |
| 模拟工作台 | 亏损分布图 | 直方图展示模拟亏损分布，叠加 VaR(95%/99%)、TVaR 标线 |
| 模拟工作台 | 极端赔付诊断 | 列出被免赔/限额拦截的极端赔付，标注来源保单ID和具体材料字段 |
| 风险诊断面板 | 材料追溯 | 按风险因子分组，展示哪个参数/材料导致极端结果，标注"样本不足"或"免赔边界" |
| 风险诊断面板 | 参数敏感度 | 调整单一参数后重新跑模拟，对比前后差异 |

## 3. 核心流程

用户导入保单样本 → 配置模拟参数（免赔额、限额、费用率、安全加载）→ 运行蒙特卡洛模拟 → 查看亏损分布与风险指标 → 诊断极端赔付来源 → 调整参数重新模拟

## 5. 蒙特卡洛模拟算法要点

1. **赔付频率**：从保单样本中估计 Poisson 参数 λ，模拟 N~Poisson(λ) 次赔付
2. **赔付 severity**：对样本赔付金额拟合经验分布（或 Pareto 尾部），模拟每次赔付金额
3. **免赔与限额拦截**：每次模拟赔付应用免赔额 d 和限额 u：赔付 = min(max(X, d), u) - d
4. **极端赔付标记**：超过 99 分位数的赔付记录来源保单ID和对应材料字段
5. **保费计算**：纯保费 = E(总赔付)，毛保费 = 纯保费 / (1 - 费用率)，综合成本率 = 毛保费中赔付占比
6. **样本不足检测**：当样本数 < 30 或经验分布尾部数据点 < 5 时，标注"样本不足"警告并建议补充材料
