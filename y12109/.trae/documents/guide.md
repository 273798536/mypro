# MC-Sim 蒙特卡洛保费模拟

## 快速开始

```bash
npm install
npm run dev
# 浏览器打开 http://localhost:5173
```

## 怎样准备保单样本

CSV 格式，首行为列名，支持中英文：

```
id,premium,sumInsured,claimCount,claimAmounts,lineOfBusiness
P001,12000,500000,2,8500;3200,机动车
P002,35000,1500000,1,75000,财产
```

必填列：`id`（保单号）、`premium`（保费）、`sumInsured`（保额）、`claimCount`（赔付次数）

选填列：`claimAmounts`（赔付金额，分号分隔）、`lineOfBusiness`（险种）

中文列名同样识别：保单号、保费、保额、赔付次数、赔付金额、险种

也可直接点击「加载 20 条示例保单」快速体验。

## 怎样复现极端赔付

1. 加载保单样本（示例数据中 P004、P010、P016 已预设大额赔付）
2. 调整免赔额和限额参数——免赔额越高拦截越多，限额越低封顶越多
3. 点击「运行蒙特卡洛模拟」
4. 右侧「极端赔付诊断」表格会列出被拦截的赔付，标注来源保单 ID 和险种
5. 进入「风险诊断」页面查看材料追溯，定位哪份保单反复触发极端赔付

## 极端赔付为什么会被拦住

模拟引擎对每笔赔付执行三层拦截：

- **免赔拦截**：赔付额 ≤ 免赔额 → 赔付归零，标注为「免赔拦截」
- **限额封顶**：赔付额 - 免赔额 ≥ 限额 → 按限额赔付，超出部分被截断
- **未被拦截**：赔付额在免赔和限额之间 → 正常赔付，但金额超过 99 分位数仍标记为极端

拦截记录追溯到具体保单 ID 和险种字段，不是只报「处理失败」。

## 模拟参数说明

| 参数 | 默认值 | 对保费影响 |
|------|--------|-----------|
| 免赔额 | 5,000 元 | ↑ → ↓纯保费 |
| 限额 | 500,000 元 | ↑ → ↑纯保费 |
| 费用率 | 25% | ↑ → ↑毛保费 |
| 安全加载 | 10% | ↑ → ↑毛保费 |
| 模拟次数 | 5,000 | ↑ → ↑精度 |
