## 1. 产品概述

基金赎回排队看板是面向基金运营团队的工作台，将分散的赎回申请、份额确认、额度阈值等材料串联成可追踪的排队队列。核心解决"数据串不起来、清算卡点看不清、结论无处溯源"的问题，让运营人员一眼看清谁在排队、卡在哪步、依据是什么。

- 目标用户：基金运营专员、运营主管
- 核心价值：赎回流程可视化 + 数据可溯源 + 异常可追踪

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限 |
|------|------|
| 基金运营专员 | 查看队列、修正数据、导出报表、标记复核 |
| 基金运营主管 | 审批复核事项、查看历史、修改阈值 |

### 2.2 功能模块

1. **排队看板主页**：赎回队列列表、排队规则主线、额度扣减/状态推进辅助解释、筛选与排序
2. **赎回详情面板**：溯源链（每条结论的来处）、清算日顺延卡点、修正操作
3. **复核工作台**：部分确认复核、同客户多笔申请复核
4. **历史记录**：操作日志、状态变更时间线
5. **数据导出**：CSV/Excel 导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 排队看板 | 队列列表 | 展示所有赎回申请，支持按状态/基金/客户筛选，显示排队位置、状态标签 |
| 排队看板 | 排队规则主线 | 右侧面板展示当前排队规则流程图，高亮当前节点 |

| 赎回详情 | 清算日顺延卡点 | 当出现清算日顺延时，以步骤条显示卡在哪一步（如：份额确认→额度检查→清算日计算→顺延触发） |

| 数据导出 | 导出面板 | 支持按筛选条件导出 CSV，包含溯源信息 |

## 3. 核心流程

### 3.1 赎回排队主流程

1. 客户提交赎回申请 → 系统录入赎回信息（来源：赎回申请表）
2. 份额确认 → 系统校验持有份额（来源：份额确认表）
3. 额度检查 → 判断赎回额度是否超过阈值（来源：额度阈值配置）
4. 排队排序 → 按申请时间优先级排队，额度不足时部分确认
5. 清算日计算 → 根据基金类型计算预计到账日
6. 清算日顺延检测 → 若遇节假日/异常则顺延，标记卡点
7. 状态推进 → 确认/部分确认/顺延/完成

```mermaid

    "赎回申请" --> "份额确认"
    "份额确认" --> "额度检查"
    "额度检查" -->|"额度充足"| "全额确认"
    "额度检查" -->|"额度不足"| "部分确认→复核"
    "全额确认" --> "清算日计算"
    "部分确认→复核" --> "运营复核审批"
    "运营复核审批" --> "清算日计算"
    "清算日计算" -->|"无顺延"| "预计到账"
    "清算日计算" -->|"遇节假日/异常"| "清算日顺延"
    "清算日顺延" --> "标记卡点步骤"
    "标记卡点步骤" --> "预计到账"
    "同客户多笔申请" --> "合并审查"
    "合并审查" --> "运营复核审批"
```

### 3.2 数据溯源链

每条数据结论都标注来源：
- 排队位置 → 来源：申请时间排序规则
- 确认份额 → 来源：份额确认表 / 额度扣减结果
- 预计到账日 → 来源：清算日计算规则 / 顺延标记
- 顺延原因 → 来源：节假日配置 / 清算规则

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深靛蓝（#1e293b）为主背景，营造专业金融感
- **辅助色**：琥珀色（#f59e0b）作为警示/顺延高亮，翡翠绿（#10b981）作为成功/确认状态
- **按钮风格**：圆角 6px，主按钮实心填充，次按钮描边
- **字体**：标题使用 DM Sans，数据使用 JetBrains Mono（等宽字体便于数据对齐）
- **布局风格**：左侧列表+右侧详情面板的经典双栏工作台布局，顶部工具栏
- **图标**：Lucide 图标库

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 排队看板 | 队列列表 | 表格布局，状态标签彩色药丸，排队序号醒目，hover 行高亮 |
| 排队看板 | 排队规则主线 | 右侧纵向流程图，当前步骤高亮，已过步骤勾选，未到步骤灰色 |
| 排队看板 | 辅助解释 | 点击行旁信息图标弹出浮层，展示额度扣减明细 |
| 赎回详情 | 溯源链 | 纵向时间线，每个节点标注来源标签（赎回申请/份额确认/额度阈值） |
| 赎回详情 | 清算日顺延 | 步骤条，卡点步骤红色高亮+原因文字 |
| 赎回详情 | 修正操作 | 侧滑面板，表单+必填原因文本框 |
| 复核工作台 | 复核列表 | 卡片式列表，每张卡片含摘要+操作按钮 |
| 历史记录 | 日志时间线 | 纵向时间线，操作类型标签 |
| 数据导出 | 导出面板 | 顶部工具栏按钮，下拉选择导出范围 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 双栏布局在窄屏下可切换为单栏+抽屉

### 4.4 数据持久化

- 所有数据存储在 localStorage，刷新不丢失
- 每次状态变更自动保存
- 支持手动重置为样例数据
