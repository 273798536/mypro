## 1. 产品概述
书店退货整理赛是一款面向书店兼职员工的培训小游戏，通过模拟真实书店退货、破损书和预订书的处理流程，帮助员工快速掌握正确的整理规则。游戏强调操作反馈、错误提示和结果回放，确保员工能理解每一步的对错原因。

- 目标用户：书店店长、兼职员工
- 核心问题：预订书误退、破损未登记、货架错位等常见错误的培训
- 产品价值：通过游戏化方式降低培训成本，提高员工处理退货事务的准确率

## 2. 核心功能

### 2.1 功能模块
1. **主界面**：游戏标题、开始游戏、关卡选择、历史记录
2. **游戏界面**：待处理物品区、处理操作区、货架区、计时器、实时反馈
3. **结果界面**：得分详情、错误明细、正确/错误操作回放
4. **报告界面**：导出整理报告、错误统计图表、操作时间线

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：温暖的米白色 `#F5F0E8` 作为背景，深棕色 `#5D4037` 作为主色，橙红色 `#E67E22` 作为强调色
- **辅助色**：成功绿 `#27AE60`、错误红 `#E74C3C`、警告黄 `#F39C12`
- **按钮风格**：圆角矩形，带阴影，悬停时有上浮动画
- **字体**：标题使用思源宋体，正文使用思源黑体
- **布局风格**：卡片式布局，货架使用立体书架样式
- **图标**：使用 lucide-react 图标库

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主界面 | 游戏标题 | 大字体标题，书架背景装饰，渐变动画 |
| 主界面 | 关卡选择 | 卡片列表，关卡编号，通关标记，最高分显示 |
| 游戏界面 | 待处理物品区 | 可拖拽卡片，显示书名、状态标记、预订人信息 |
| 游戏界面 | 处理操作区 | 四个目标区域：退货/破损/预订/货架，带图标和标签 |
| 游戏界面 | 实时反馈 | 浮动提示，成功绿色闪光，错误红色抖动 |
| 游戏界面 | 计时器 | 大号数字显示，最后10秒红色脉冲动画 |
| 结果界面 | 得分详情 | 分类得分列表，每项显示正确/错误数量 |
| 结果界面 | 错误回放 | 时间轴样式，可展开查看每条错误详情 |
| 报告界面 | 统计图表 | 雷达图，柱状图，操作时间线 |

### 4.3 响应式设计
- 桌面端优先设计，支持平板横屏
- 拖拽操作同时支持鼠标和触摸
- 关键信息区域固定，滚动区域自适应

## 5. 游戏规则

### 5.1 物品类型
| 物品类型 | 描述 | 正确处理方式 |
|---------|------|-------------|
| 正常退货书 | 无破损、无预订 | 拖入退货区 |
| 破损书 | 有破损标记 | 拖入破损登记区，需记录破损情况 |
| 预订书 | 有预订人信息 | 拖入预订保留区，不可退货 |
| 正常销售书 | 无退货标记 | 拖入对应货架区 |

### 5.2 错误类型及扣分
| 错误类型 | 扣分 | 说明 |
|---------|------|------|
| 预订书误退 | -15 | 将预订书拖入退货区 |
| 破损未登记 | -10 | 破损书未拖入破损区 |
| 货架错位 | -8 | 书拖入错误的货架 |
| 退货区错位 | -5 | 非退货书拖入退货区 |

### 5.3 关卡难度
| 关卡 | 物品数量 | 时间限制 | 特殊机制 |
|------|---------|---------|---------|
| 第1关 | 8件 | 60秒 | 基础操作，无时间压力 |
| 第2关 | 12件 | 50秒 | 引入预订书判断 |
| 第3关 | 15件 | 45秒 | 引入破损书判断 |
| 第4关 | 18件 | 40秒 | 混合所有类型 |
| 第5关 | 20件 | 35秒 | 限时挑战，快速决策 |
