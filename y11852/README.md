# 音乐厅声场可视化

一个用于音乐厅声学设计和分析的 3D 可视化工具，帮助声学顾问在剧场改造会议中直观地向甲方展示声场效果。

## ✨ 核心功能

### 🎯 3D 声场可视化
- **实时声线追踪**：动态展示声波从声源传播到座位的完整路径
- **频段区分**：低频（红色）、中频（青色）、高频（蓝色）三种颜色区分声线
- **时间轴控制**：支持播放、暂停、逐帧、倍速，直观观察声波传播过程
- **多视角切换**：透视图、俯视图、正视图、侧视图、正交视图自由切换

### 📊 数据分析
- **热力图映射**：RT60（混响时间）、SPL（声压级）、C80（清晰度）三种指标
- **座位明细**：每个座位的详细声学参数，支持排序和筛选
- **问题筛选器**：材料缺失、座位遮挡、频段错误单独筛选
- **数据校验**：导入数据自动校验，问题高亮显示

### 📁 数据管理
- **分批导入**：厅堂模型、声源位置、座位区可分别导入，自动标记导入批次
- **导入顺序追踪**：不同批次数据用不同颜色边框区分，清晰显示导入先后
- **内置样例**：一键加载扇形剧场样例，无需准备数据即可体验完整功能

## 🚀 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0 或 pnpm >= 8.0.0

### 依赖安装

```bash
npm install
```

或使用 pnpm：

```bash
pnpm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后访问：http://localhost:5173

### 构建生产版本

```bash
npm run build
```

### 类型检查

```bash
npm run check
```

## 📂 第一份样例数据位置

系统内置了一份完整的扇形剧场样例数据，无需额外下载：

| 数据类型 | 文件路径 |
|---------|---------|
| 厅堂模型 | `src/data/samples/hall-model.json` |
| 声源配置 | `src/data/samples/sound-sources.json` |
| 座位数据模板 | `src/data/samples/seats-data.json` |
| 材料参数库 | `src/data/materials.json` |

### 一键加载样例

1. 启动应用后，点击欢迎界面的 **「加载样例数据」** 按钮
2. 或点击顶部工具栏的 **「加载样例」** 按钮
3. 点击 **「开始计算」** 按钮运行声线追踪
4. 使用底部时间轴播放，观察声波传播过程

## 🖱️ 操作指南

### 3D 视图操作
- **旋转视角**：鼠标左键拖拽
- **平移视图**：鼠标右键拖拽
- **缩放视图**：鼠标滚轮
- **选中座位**：鼠标左键点击座位

### 顶部工具栏
- **导入模型**：导入厅堂模型（支持 .json, .glb, .obj）
- **导入声源**：导入声源位置配置（.json）
- **导入座位**：导入座位区数据（.json）
- **加载样例**：一键加载内置样例数据
- **开始计算**：运行声线追踪算法
- **重置视角**：恢复默认相机位置
- **视图**：切换视角预设（透视/俯视/正视/侧视/正交）
- **显示**：控制各图层显示和透明度

### 侧边面板
- **问题筛选**：按问题类型筛选座位（材料缺失/遮挡/频段错误）
- **热力映射**：切换显示指标和频段，查看统计数据
- **座位明细**：查看所有座位的详细参数，点击可在 3D 视图中定位

### 底部时间轴
- **播放/暂停**：控制声线动画播放
- **逐帧控制**：左右箭头按钮逐帧前进/后退
- **倍速控制**：0.5x / 1x / 2x / 4x 四档速度
- **进度条**：直接点击跳转至任意时间点

## 📐 核心算法

### 声线追踪 (Ray Tracing)
- 镜像反射法模拟声波传播
- 支持最大 5 次反射
- 实时遮挡检测
- 距离衰减计算

### 声学参数计算
- **RT60**：Sabine 混响时间公式
- **SPL**：声压级（考虑距离衰减和吸声）
- **C80**：清晰度指数（早期与后期声能比）

### 数据校验
- Zod 运行时类型校验
- 材料参数完整性检查
- 频段范围验证
- 座位遮挡检测

## 📁 数据格式

### 厅堂模型格式
```json
{
  "name": "扇形剧场",
  "width": 25,
  "depth": 20,
  "height": 8,
  "meshes": [
    {
      "name": "舞台",
      "material": "wood",
      "vertices": [...],
      "faces": [...]
    }
  ]
}
```

### 声源格式
```json
[
  {
    "id": "source-1",
    "name": "主扬声器",
    "position": [0, 2, -8],
    "frequency": "mid",
    "power": 90
  }
]
```

### 座位格式
```json
[
  {
    "id": "seat-A01",
    "row": "A",
    "number": 1,
    "position": [-5, 0, 5],
    "importBatch": 1
  }
]
```

## 🎯 使用场景

1. **剧场改造会议**：向甲方直观展示声场分布，替代抽象的形容词描述
2. **声学设计验证**：验证不同材料配置下的声场效果
3. **座位质量评估**：识别遮挡座位和声学参数异常区域
4. **方案对比**：快速对比不同设计方案的声学表现

## ⚠️ 注意事项

- 材料参数缺失时系统会高亮提示，不会自动通过计算
- 座位区后补导入时，批次 #1 #2 #3 徽章会清晰显示导入顺序
- 筛选面板可单独筛出座位遮挡和频段错误，便于针对性整改
- 声线动画支持 4 倍速播放，快速预览完整传播过程
