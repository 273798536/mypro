## 1. 产品概述

音乐厅混响座位图——面向声学顾问的专业可视化工具，用于讲解与评审。核心解决三大痛点：**材料缺参无法识别、座位遮挡被忽略、频段切错混入正常结果**。工具需在空间颜色、位置、标签上直观暴露数据缺陷，将异常归入独立清单，3D声场渲染时明确标注数据缺口，并提供手动修正入口与新旧结果并排对比。

- 目标用户：声学顾问、厅堂声学评审人员
- 核心价值：避免脏数据在评审中被遗漏，让缺参、遮挡、频段问题无处藏身

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 声学顾问 | 直接使用 | 查看/标注/修正所有数据，导出异常清单 |
| 评审人员 | 只读查看 | 查看座位图、3D声场、异常清单 |

### 2.2 功能模块

1. **主工作台页面**：2D座位图、3D声场、异常清单、修正面板四区联动
2. **数据管理面板**：导入厅堂模型、补充声源位置和吸声材料，增量更新不覆盖已有判断

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主工作台 | 2D座位图 | 俯视座位布局，每个座位按混响值着色；缺参座位用斜线纹理+警告图标标注；被遮挡座位用虚线边框+遮挡标签标注 |
| 主工作台 | 3D声场视图 | 厅堂3D渲染，声场云图叠加；数据缺口区域覆盖半透明警告遮罩+文字提示"该区域数据不完整"；无数据时禁止渲染伪彩色 |
| 主工作台 | 异常/待确认清单 | 左侧抽屉面板，分类列出：材料缺参项、座位遮挡项、频段切错项；每项可点击跳转到对应座位/区域；状态分为"待确认"和"已确认" |
| 主工作台 | 手动修正面板 | 右侧抽屉面板，可拖拽修改声源位置；修正后触发重新计算；新旧结果并排对比（左旧右新），差异区域用高亮框标注 |
| 主工作台 | 数据增量管理 | 顶部工具栏，导入新材料时与已有判断做合并校验；新增声源/吸声材料不覆盖已有异常标记；补充完整参数后自动将异常项移至"已修复" |

## 3. 核心流程

**主流程**：导入厅堂模型 → 系统检测缺参/遮挡/频段问题 → 问题自动进入异常清单 → 顾问在座位图/3D视图中查看问题分布 → 手动修正声源位置 → 新旧结果并排对比 → 确认或回退修正 → 导出评审报告

```mermaid
    "系统自动检测" --> "缺参/遮挡/频段异常"
    "缺参/遮挡/频段异常" --> "归入异常清单"
    "归入异常清单" --> "座位图+3D标注"
    "座位图+3D标注" --> "手动修正声源"
    "手动修正声源" --> "并排对比新旧结果"
    "并排对比新旧结果" --> "确认修正"
    "确认修正" --> "更新异常清单状态"
    "补充材料参数" --> "增量合并校验"

    "保留已有异常标记" --> "参数完整则标记已修复"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海军蓝(#0A1628)为底，声场用琥珀渐变(从#F59E0B暖色到#3B82F6冷色表示混响时长)，异常用珊瑚红(#EF4444)警示
- **辅助色**：灰绿(#6B7280)用于正常状态，翡翠绿(#10B981)用于已修复状态
- **按钮风格**：微圆角(6px)、扁平化，主要操作用琥珀色填充，危险操作用珊瑚红描边
- **字体**：数据/标签用 JetBrains Mono 等宽字体，UI文本用 Noto Sans SC
- **布局**：三栏式（左侧异常清单抽屉 + 中间主视图区 + 右侧修正抽屉），主视图区可切换2D/3D
- **纹理/图标**：缺参用斜线纹理叠加，遮挡用虚线+锁图标，频段错误用锯齿波图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主工作台 | 2D座位图 | 深色底，座位格子热力图着色，缺参座位斜线纹理+⚠图标，遮挡座位虚线框+🔒图标，hover弹出详情tooltip |
| 主工作台 | 3D声场视图 | Three.js渲染厅堂模型，声场云图半透明叠加，数据缺口区域红色半透明遮罩+文字"数据不完整"，右下角图例 |
| 主工作台 | 异常清单抽屉 | 左侧280px宽抽屉，三个tab（材料缺参/座位遮挡/频段错误），列表项可点击高亮定位，状态徽标 |
| 主工作台 | 修正面板抽屉 | 右侧320px宽抽屉，声源位置拖拽控制，修正按钮，并排对比区域（左旧右新各50%），差异高亮框 |
| 主工作台 | 顶部工具栏 | 导入按钮、视图切换(2D/3D)、频段选择器、数据完整性指示灯(绿/黄/红) |

### 4.3 响应式

- 桌面优先设计，最小宽度1280px
- 侧边抽屉可折叠，主视图区自适应
- 2D/3D视图全屏模式

### 4.4 3D场景指引

- 环境：深色HDRI，模拟音乐厅暗场环境
- 灯光：环境光+定向光模拟舞台照明
- 相机：透视相机，默认俯瞰角度(45°)，可OrbitControls旋转
- 交互：鼠标悬停显示声压级数值，点击跳转异常详情
- 后处理：无额外后处理，保持数据可视化清晰度
