# 梁体挠度报告导出

桥梁检测数据导出与历史追溯系统。

## 快速开始

```bash
npm install
npm run dev
```

访问 http://localhost:5173

## 三步操作

1. **首页看总览** — 统计卡片 + 异常队列，一眼知道哪些梁有问题
2. **异常中心查分类** — 疑似噪声 / 极端值 / 待确认 / 已驳回，按类型处理
3. **点记录看历史** — 备注时间线、截图快照、人工确认记录，完整追溯

## 坏材料来了该看哪里

| 场景 | 去哪看 | 看什么 |
|------|--------|--------|
| 报警和备注对不上 | 历史页 → 备注时间线 | 补录备注有橙色「补录」标记，版本号连续不丢失 |
| 极端值混进正常数据里 | 明细页 / 异常中心 | 极端值红底红字，疑似噪声黄底黄字，和正常通过泾渭分明 |
| 怀疑图表和明细口径不一 | 边界校验页 → 执行复算 | 同一套 UnifiedDataSource 生成图表和明细，复算结果一致性校验 |
| 人工确认前后变了啥 | 历史页 → 人工确认记录 | 状态前后对比 + 数值变化 + 操作人 + 原因，公示复盘可解释 |
| 旧版本截图找不到 | 历史页 → 截图快照 | 多版本并排对比，数据哈希防篡改 |

## 核心设计

- **单数据源**：筛选 → 噪声识别 → 统计 → 异常队列，同一条管道出结果
- **全历史**：备注、截图、确认记录全部留存，不止保留最终值
- **可追溯**：人工确认全过程留痕，公式版本号一并记录
