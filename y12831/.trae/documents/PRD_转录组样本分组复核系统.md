## 1. 产品概述

转录组样本分组复核系统是一款面向生物信息学实验室的质量控制工具，专注于解决临近复测前样本分组信息反复调整的追踪难题。系统帮助生态调查员、老师和工程师完整记录每次导入、修正和确认操作，确保复核过程可追溯、可解释、可对比。

### 核心价值
- 解决转录组分析前样本分组信息频繁变动的历史追溯问题
- 为边界不清的标注提供可复用的解释模板，便于团队沟通
- 直观展示人工修正对差异分析结果的影响范围
- 完整记录低质量读段复核通过的责任人、时间和原因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 生态调查员 | 工号登录 | 导入样本、提交复核意见、修正分组信息 |
| 实验室老师 | 工号登录 | 审核复核结果、确认最终分组、查看历史对比 |
| 生物信息工程师 | 工号登录 | 查看差异分析影响、导出复核报告 |

### 2.2 功能模块

1. **样本列表页**：样本批次管理、筛选搜索、复核状态概览、快速导入

3. **历史对比视图**：操作时间线、新旧结论并排对比、差异分析前后可视化
4. **复核记录追溯页**：完整操作日志、修改原因追踪、责任人查询

## 3. 核心流程

### 3.1 主流程描述

生态调查员导入样本批次数据 → 系统自动标记低质量读段和边界情况 → 调查员逐样本复核，填写修正意见和原因 → 系统自动保存历史版本 → 实验室老师审核确认 → 生成可追溯的复核报告 → 工程师查看差异分析影响 → 导出最终分组信息

```mermaid

    E --> F["保存历史版本"]

    G --> H["生成复核报告"]
    H --> I["查看差异影响"]
    I --> J["导出最终分组"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0F3B5F) - 代表科学严谨
- **辅助色**：苔绿 (#4A7C59) - 代表生命科学、通过确认；暖橙 (#E07B39) - 代表待复核、边界情况；锈红 (#C44536) - 代表低质量、异常
- **中性色**：近白 (#F5F3EE)、浅灰 (#E0DED8)、中灰 (#8B8A84)、深灰 (#2C2C2C)
- **按钮风格**：微圆角 (6px)、轻微悬浮阴影、状态色填充
- **字体**：标题使用 "Noto Serif SC" 衬线体体现学术感；正文使用 "Noto Sans SC" 无衬线体保证可读性
- **布局风格**：卡片式布局、清晰的信息层级、充足留白、细分割线
- **图标风格**：线性简约图标、与文字同色、16px/20px 标准尺寸

### 4.2 设计基调

学术严谨 + 数据驱动。整体采用冷静克制的色调，通过微妙的纸张纹理和细腻的阴影层次营造专业实验室的氛围。数据对比区域使用大胆的分栏布局，确保新旧差异一目了然。

### 4.3 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 样本列表页 | 批次概览卡片 | 左对齐标题、状态徽章、数据指标网格、悬浮阴影 |
| 样本列表页 | 数据表格 | 斑马纹悬停、状态色标记行、操作列固定、分页器 |
| 样本复核详情页 | 分组信息面板 | 双栏布局、可编辑下拉框、边界标签徽章、解释气泡 |
| 样本复核详情页 | 边界标注卡片 | 淡橙色背景、虚线边框、类型下拉、解释文本域 |
| 历史对比视图 | 并排对比面板 | 50/50 分栏、中间垂直分割线、删除线标记旧值、绿色高亮新值 |
| 历史对比视图 | 时间线 | 左侧垂直线、圆点标记事件、悬浮显示详情、按时间倒序 |
| 历史对比视图 | 差异分析对比图 | 左右并排MA图/火山图、差异基因高亮、统计指标对比表 |

### 4.4 响应式设计

- **桌面端优先**：针对实验室大屏显示器优化 (1280px+)
- **平板适配**：1024px 时侧边栏收起为图标、表格支持横向滚动
- **移动端**：768px 时卡片堆叠、表格转为列表视图、操作按钮底部悬浮

## 5. 真实样例数据说明

系统内置3组典型边界情况样例，每组都会实际改变分析结果：

1. **低质量读段复核通过样例**：样本ID S002-LV，原始Q20为18.3%（阈值20%），但因该位点为稀有生态位样本，经研究员确认后通过。改变：保留样本 vs 剔除样本 → 差异基因数量变化 +127 个。

2. **分组边界不清样例**：样本ID S015-MO，原始标注为"对照组"，但采样记录显示处理时间点存在交叉。修正为"处理组8h"。改变：分组归属变化 → 该组富集通路从"代谢过程"变为"应激响应"。

3. **阴性对照异常样例**：样本ID NTC-03，阴性对照检出低丰度表达，判定为交叉污染而非操作失误。改变：判定标准变化 → 同批次另外2个样本免于重测。
