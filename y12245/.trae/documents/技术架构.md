## 2. 技术描述

- **前端框架**: React@18 + TypeScript
- **构建工具**: Vite
- **样式方案**: TailwindCSS@3
- **状态管理**: Zustand（轻量级）
- **可视化**: Canvas 原生 API
- **数据存储**: LocalStorage
- **无后端，纯前端应用

## 3. 路由定义

| 路由 | 页面 | 用途 |

interface Level {

### 4.2 游戏会话数据

```typescript
interface GameSession {
  id: string;
  levelId: string;
  startTime: number;
  endTime: number;
  steps: GameStep[];
  result: 'success' | 'failed';
  score: number;
}

interface GameStep {
  stepIndex: number;
  parameters: Record<string, number>;
  timestamp: number;
  trajectory: { x: number; y: number }[];
  errors: GameError[];
  triggered: boolean; // 是否触发曲线生成
}

interface GameError {
  type: 'out_of_bounds' | 'curve_break' | 'speed_mismatch';
  position: { x: number; y: number };
  message: string;
  severity: 'warning' | 'critical';
}
```

### 4.3 预设关卡样例

| 关卡名称 | 包含问题类型 | 说明 |
|---------|-------------|------|
| 参数越界关卡 | out_of_bounds | 演示参数超过范围的后果 |
| 曲线断裂关卡 | curve_break | 演示函数不连续导致轨迹断裂 |
| 速度误判关卡 | speed_mismatch | 演示导数变化过快问题 |
| 综合挑战关卡 | 全部类型 | 综合所有问题类型 |
