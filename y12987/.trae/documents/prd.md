## 1. 产品概述

ETL 任务依赖拓扑管理系统，面向研发团队与财务系统维护人员，提供 ETL 任务的依赖关系可视化、业务工单追踪、变更审计与版本对比能力。核心解决三个问题：一是依赖拓扑的可视化与异常溯源，二是工单变更前后的结论并排对比，三是分页顺序不稳定等异常的审计留痕，确保"谁改的、什么时候改的、为什么改"有据可查。

- 目标用户：研发团队（查看拓扑、排查异常）、财务系统维护人员（复核工单、审计变更）
- 核心价值：单一数据源驱动图表/明细/导出，权限审计与备份校验共用同一批处理记录，异常可沿工单线溯源

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 研发人员 | 管理员分配 | 查看拓扑、排查异常、导出结果 |
| 财务维护人员 | 管理员分配 | 复核工单、查看审计记录、版本对比 |
| 系统管理员 | 系统内置 | 全部权限，含工单审批与用户管理 |

### 2.2 功能模块

1. **拓扑看板页**：ETL 任务依赖关系图（DAG）、节点状态着色、异常节点高亮、点击节点查看工单详情
2. **业务工单页**：工单列表（稳定分页）、工单详情、变更历史、版本对比（并排查看新旧结论）
3. **审计日志页**：操作记录列表（谁/何时/为何）、筛选与搜索、导出审计报告
4. **操作指南页**：启动步骤、导入数据、查看异常、导出结果的说明文档（非宣传页风格）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 拓扑看板页 | 依赖关系图 | DAG 可视化，节点按状态着色（成功/失败/运行中），支持缩放与拖拽 |
| 拓扑看板页 | 异常节点面板 | 点击异常节点弹出工单摘要与处理意见，可跳转工单详情 |
| 拓扑看板页 | 筛选与搜索 | 按任务名、状态、时间范围筛选拓扑节点 |
| 业务工单页 | 工单列表 | 稳定分页（按创建时间排序，不可变），显示工单号/状态/创建人/变更次数 |
| 业务工单页 | 工单详情 | 工单基本信息、关联任务、处理意见、变更时间线 |
| 业务工单页 | 版本对比 | 并排展示工单变更前后的结论字段，差异高亮 |
| 业务工单页 | 变更历史 | 记录每次修改的操作人、时间、原因，支持回溯 |
| 审计日志页 | 操作记录 | 全部操作记录列表，含操作类型/操作人/时间/原因/影响范围 |
| 审计日志页 | 筛选导出 | 按操作类型/时间/操作人筛选，导出为 CSV |
| 操作指南页 | 启动与导入 | 启动系统、导入任务依赖数据的步骤说明 |
| 操作指南页 | 异常与导出 | 查看异常、导出拓扑结果的操作步骤 |

## 3. 核心流程

### 3.1 异常溯源流程

用户在拓扑看板发现异常节点 → 点击节点查看关联工单摘要 → 跳转至工单详情页 → 查看处理意见与变更历史 → 如有变更，使用版本对比并排查看新旧结论 → 确认影响范围。

```mermaid
flowchart TD
    "发现异常节点" --> "点击节点查看工单摘要"
    "点击节点查看工单摘要" --> "跳转工单详情"
    "跳转工单详情" --> "查看处理意见"
    "查看处理意见" --> "有变更记录?"
    "有变更记录?" --> "是" --> "版本对比：并排查看新旧结论"
    "有变更记录?" --> "否" --> "确认影响范围"
    "版本对比：并排查看新旧结论" --> "确认影响范围"
    "确认影响范围" --> "查看审计日志"
```

### 3.2 工单变更审计流程

工单被修改 → 系统自动记录操作人/时间/原因 → 审计日志页同步更新 → 权限审计与备份校验共用同一批处理记录 → 财务维护人员复核时可追溯完整变更链。

```mermaid
flowchart TD
    "工单被修改" --> "系统记录操作人/时间/原因"
    "系统记录操作人/时间/原因" --> "审计日志页同步更新"
    "审计日志页同步更新" --> "权限审计与备份校验共用记录"
    "权限审计与备份校验共用记录" --> "财务维护人员复核追溯"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰 (#1e293b) 为底，翠绿 (#10b981) 表示正常，琥珀 (#f59e0b) 表示警告，玫红 (#ef4444) 表示异常
- 按钮：圆角矩形，扁平风格，hover 微阴影
- 字体：代码/数据区使用 JetBrains Mono，界面文字使用 Noto Sans SC
- 布局：左侧固定侧栏导航 + 右侧内容区，卡片式模块
- 图标：线性图标风格 (Lucide)

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 拓扑看板页 | 依赖关系图 | 深色背景画布，DAG 节点为圆角矩形，连线带箭头，颜色按状态区分，支持缩放拖拽 |
| 拓扑看板页 | 异常节点面板 | 右侧抽屉式面板，显示工单摘要卡片，包含状态标签和跳转链接 |
| 拓扑看板页 | 筛选与搜索 | 顶部工具栏，下拉筛选 + 搜索输入框 |
| 业务工单页 | 工单列表 | 表格布局，固定表头，分页器固定底部，行 hover 高亮 |
| 业务工单页 | 版本对比 | 左右分栏并排展示，差异字段红色删除线 / 绿色新增标记 |
| 审计日志页 | 操作记录 | 时间线 + 表格双视图切换，操作类型彩色标签 |
| 操作指南页 | 步骤说明 | 分步骤卡片，代码块展示命令，简洁非宣传风格 |

### 4.3 响应式设计

桌面优先设计，内容区最小宽度 1024px。拓扑图区域需占据主要空间，侧栏可折叠。

### 4.4 数据一致性原则

- 图表、明细列表、导出结果使用同一数据查询接口，前端不做二次加工
- 权限审计与备份校验共用 `audit_logs` 表，界面和报告从同一数据源读取
- 分页排序字段固定为 `created_at DESC`，确保分页顺序稳定
