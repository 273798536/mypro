## 1. 产品概述

量子态布洛赫球课件是一款面向物理科普教师的交互式教学工具，用于直观展示和讲解量子态在布洛赫球上的表示。核心解决三大教学痛点：概率未归一化导致的误判、相位越界引发的渲染偏差、测量基混淆造成的解读错误。工具支持增量式数据输入（量子态参数先到、测量基和概率条后补），确保补材料时不覆盖已有判断，并通过独立的异常清单和3D画面旁的缺口提示，让教师和评审者一眼识别数据问题。

- 目标用户：物理科普教师、量子计算课程评审者
- 核心价值：将"脏数据"从正常明细中剥离，确保教学与评审过程中量子态参数→测量基→最终结果的双向追溯链路完整透明

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 科普教师 | 直接使用 | 输入量子态参数、查看布洛赫球、管理异常清单、追溯数据链路 |
| 评审者 | 直接使用 | 审查数据完整性、查看异常标记、验证双向追溯 |

### 2.2 功能模块

1. **主课件页**：3D布洛赫球可视化、量子态参数面板、测量基与概率条面板、异常/待确认清单、双向追溯面板
2. **数据输入页**：增量式量子态参数输入、测量基补充、概率条补充

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主课件页 | 3D布洛赫球 | 交互式3D布洛赫球渲染，量子态点位置、颜色反映归一化状态，数据缺口时旁边显示明确提示文字 |
| 主课件页 | 量子态参数面板 | 显示θ、φ参数，颜色标注未归一/越界状态，标签说明异常类型 |
| 主课件页 | 测量基与概率条面板 | 显示测量基选择和对应概率条，概率条颜色区分已确认/待确认 |
| 主课件页 | 异常/待确认清单 | 独立列表展示概率未归一、相位越界、测量基混淆条目，不含正常项 |
| 主课件页 | 双向追溯面板 | 支持从量子态参数查到最终结果，从结果反查回测量基的完整链路 |
| 数据输入页 | 增量输入表单 | 先到的量子态参数单独提交，后续补入测量基和概率条时不覆盖已有判断 |
| 数据输入页 | 输入校验反馈 | 实时校验概率归一性、相位范围、测量基一致性，问题即时进异常清单 |

## 3. 核心流程

**教学/评审流程**：教师输入量子态参数 → 系统校验并渲染布洛赫球 → 异常项自动进入异常清单 → 教师补充测量基和概率条 → 系统更新概率条但不覆盖已有异常判断 → 教师通过追溯面板双向查看数据链路 → 评审者审查异常清单和追溯链路

```mermaid

    "A: 输入量子态参数" --> "B: 校验概率归一性"
    "B" --> "C: 校验相位范围"
    "C" --> "D: 校验测量基一致性"
    "D" --> "E: 渲染布洛赫球"
    "E" --> "F: 生成异常清单"
    "F" --> "G: 补充测量基/概率条"
    "G" --> "H: 更新概率条(不覆盖已有判断)"
    "H" --> "I: 双向追溯验证"
    "B -->|未归一| F"
    "C -->|越界| F"
    "D -->|混淆| F"
    "E -->|数据缺口| J: 显示缺口提示"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝黑底(#0a0e1a) + 量子青(#00e5ff)高亮 + 警示琥珀(#ffb300)标记异常
- 辅助色：归一化正常绿(#00e676)、未归一化红(#ff1744)、待确认灰蓝(#546e7a)
- 字体：标题用 JetBrains Mono（科学感），正文用 Noto Sans SC（中文友好）
- 布局：左侧3D布洛赫球大区 + 右侧参数/清单/追溯面板，桌面端优先
- 动效：布洛赫球慢速自转，异常项闪烁脉冲，追溯链路高亮动画

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主课件页 | 3D布洛赫球 | 深蓝球体+经纬线网格、量子态点(颜色随状态变化)、数据缺口时旁边半透明警示条 |
| 主课件页 | 量子态参数面板 | θ/φ数值卡片、归一化状态徽章(绿/红/灰)、越界标记 |
| 主课件页 | 测量基与概率条 | 测量基标签、水平概率条(已确认绿/待确认灰蓝)、概率数值 |
| 主课件页 | 异常清单 | 卡片列表、分类标签(概率未归一/相位越界/测量基混淆)、脉冲动画 |
| 主课件页 | 双向追溯面板 | 链路图(量子态→测量基→结果)、可点击节点、正反向高亮 |
| 数据输入页 | 增量输入表单 | 分步表单(先量子态→后测量基/概率)、实时校验红框提示 |

### 4.3 响应式设计

- 桌面端优先，3D球区占主视觉区域
- 平板端3D球区缩小，面板改为标签页切换
- 移动端3D球区全宽，面板堆叠

### 4.4 3D场景指引

- 环境：深空黑背景，微弱星尘粒子
- 灯光：柔和环境光+方向光，突出球体轮廓
- 相机：默认45度俯角，可鼠标拖拽旋转/缩放
- 焦点元素：布洛赫球本体+量子态点+坐标轴标签
- 交互：鼠标悬停量子态点显示参数tooltip，拖拽旋转视角
- 后处理：球体表面菲涅尔边缘光，异常态点发光bloom效果
