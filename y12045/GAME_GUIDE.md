# 算法快递分拣场 - 游戏说明

## 快速开始

1. 选择场景预设（标准模式 / 急件饥饿演示 / 路线堵塞演示等）
2. 点击「开始」按钮启动游戏
3. 点击待分拣包裹进行选择
4. 点击目标分拣线完成分配
5. 观察异常并实时调整策略

## 包裹卡准备

### 包裹类型
- **普通件**（灰色）：标准优先级，正常处理时间
- **急件**（红色）：高优先级，超时会触发「急件饥饿」异常
- **破损件**（黄色）：需要额外 50% 处理时间，容易超时

### 包裹卡属性
每张包裹卡显示以下信息：
- 类型标签（普通/急件/破损）
- 优先级星级（1-5 星，5 星最高）
- 目的地（A/B/C）
- 预计处理时间
- 剩余倒计时

### 自定义包裹配置
修改 `src/config/presets.ts` 文件中的场景配置：

```typescript
const customPreset: GameConfig = {
  duration: 120,           // 游戏时长（秒）
  packageInterval: [2, 5], // 包裹生成间隔范围
  urgentRatio: 0.2,        // 急件占比 20%
  damagedRatio: 0.1,       // 破损件占比 10%
  priorityWeights: [0.4, 0.3, 0.15, 0.1, 0.05], // P1-P5 权重
  processingTimeRange: [3, 8],   // 处理时间范围
  deadlineRange: [15, 45],       // 截止时间范围
  starvationThreshold: 20,       // 急件饥饿阈值（秒）
  congestionThreshold: 0.8,      // 拥堵阈值（80% 容量）
};
```

## 复现急件饥饿问题

### 步骤 1：选择场景
在控制面板中选择「急件饥饿演示」场景。

**关键配置：**
- 急件占比：10%
- 普通件占比：90%
- 低优先级（P1）权重：60%
- 饥饿阈值：15 秒

### 步骤 2：设置策略
- 队列策略：**先进先出 (FIFO)**
- 路径策略：**目的地匹配**

### 步骤 3：开始游戏
点击「开始」，观察急件在队列中等待。当急件等待超过 15 秒时，会触发「急件饥饿」异常并扣 50 分。

### 步骤 4：对比优化
暂停游戏，将队列策略切换为「优先级排序」。观察高优先级急件如何被优先处理，饥饿问题得到解决。

## 队列策略对比

| 策略 | 算法原理 | 优点 | 缺点 |
|------|----------|------|------|
| **FIFO** | 先进先出，按到达顺序处理 | 公平，无饥饿 | 急件可能被阻塞 |
| **优先级** | 高优先级先处理 | 急件优先 | 低优先级可能饥饿 |
| **SJF** | 处理时间短的优先 | 吞吐量最大 | 长作业等待时间长 |

## 异常类型与扣分

| 异常类型 | 触发条件 | 扣分 |
|----------|----------|------|
| 急件饥饿 | 急件等待超过阈值 | -50 |
| 路线堵塞 | 分拣线负载超过 80% | -30 |
| 破损件失败 | 破损件处理超时 | -40 |
| 超时未送达 | 包裹超过截止时间 | -25 |

## 游戏控制

- ⏸ **暂停**：随时暂停调整策略
- ⏩ **倍速**：1x/2x/3x 加速模拟
- 🔄 **重开**：重置当前场景
- 📊 **复盘**：游戏结束后查看时间轴回放

## 教学要点

1. **优先队列**：包裹队列对应优先队列数据结构
2. **堆排序**：优先级策略底层使用堆排序
3. **饥饿问题**：高优先级任务持续占用资源导致低优先级任务饿死
4. **死锁**：路线堵塞类似资源竞争导致的死锁
5. **贪心算法**：SJF 策略是贪心算法的典型应用

## 键盘快捷键

- `Space`：开始/暂停
- `R`：重开游戏
- `1/2/3`：切换游戏速度
