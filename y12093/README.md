# 化学晶体结构漫游

基于 Three.js 的交互式 3D 晶体结构可视化工具，专为化学教学设计。

## 快速开始

1. 在项目根目录启动本地服务器：
```bash
python3 -m http.server 8080
# 或
npx serve .
```

2. 浏览器打开 `http://localhost:8080`

## 核心功能

### 🎯 3D 主视图
- **旋转**：鼠标左键拖拽
- **缩放**：鼠标滚轮 / 右键拖拽
- **平移**：中键拖拽
- **选中原子**：点击原子查看详细信息

### 📊 左侧控制面板
- **晶胞参数**：a/b/c 轴长，α/β/γ 夹角
- **晶胞复制**：X/Y/Z 方向扩展晶胞（1-5倍）
- **键长阈值**：调整化学键判定距离
- **原子筛选**：按元素类型显示/隐藏
- **显示选项**：晶胞线框、坐标轴、原子标签

### 📋 右侧明细面板
- **原子列表**：所有原子的坐标和元素信息
- **选中原子**：详细坐标、配位数、成键列表
- **化学键列表**：所有键长数据

### 💾 数据操作
- **保存/恢复视角**：记录当前观察角度
- **导出数据**：导出完整结构为 JSON
- **自定义数据**：粘贴原子坐标手动构建

## 如何准备原子坐标数据

### 格式要求
每行一个原子，使用**分数坐标**（0-1 范围）：
```
元素符号  x  y  z
```

### 示例（金刚石结构）：
```
C  0.0   0.0   0.0
C  0.0   0.5   0.5
C  0.5   0.0   0.5
C  0.5   0.5   0.0
C  0.25  0.25  0.25
C  0.25  0.75  0.75
C  0.75  0.25  0.75
C  0.75  0.75  0.25
```

### 注意事项：
- 元素符号区分大小写（如：Na, Cl, Si）
- 坐标可以是小数，用空格或制表符分隔
- 建议使用分数坐标（相对晶胞的比例）
- 加载前先设置正确的晶胞参数（a/b/c）

## 键长误连问题复现与解决

### 常见原因
1. **阈值过小**：没有化学键显示
2. **阈值过大**：非键合原子被误判为成键
3. **周期边界**：相邻晶胞原子距离计算问题

### 复现方法
1. 选择**氯化钠 (NaCl)** 结构
2. 将键长阈值设为 **2.0 Å** → 没有键（阈值过小）
3. 将键长阈值设为 **4.0 Å** → 出现大量误连（阈值过大）
4. 正确阈值应为 **2.8-3.2 Å**

### 调试技巧
- 先看**配位数**是否符合预期
  - 金刚石：配位数 4
  - NaCl：配位数 6
  - CsCl：配位数 8
- 勾选「显示键长标注」检查实际距离
- 点击化学键列表，定位具体键对
- 扩展晶胞后重新计算键（查看周期边界影响）

## 错误提示说明

系统会明确指出问题所在的材料：
- `材料: diamond` → 金刚石数据问题
- `材料: nacl` → 氯化钠数据问题  
- `材料: custom_data` → 自定义输入数据问题
