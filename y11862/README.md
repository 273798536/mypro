# 音乐频谱雕塑台

## 启动命令

```bash
npm install
npm run dev
```

启动后访问 http://localhost:5173

## 样例在哪

首页中央有两个演示按钮：
- **正常样例** - 44.1kHz标准采样率的模拟音频数据
- **采样率错误样例** - 22.05kHz非标准采样率，带峰值遮挡问题

也可以拖拽 WAV/MP3/AIFF 音频文件到页面中央上传区导入自己的音频。

## 怎样看到采样率错误

1. 点击右侧「采样率错误样例」按钮
2. 等待分析完成（约0.8秒）
3. 观察以下位置：
   - 顶部状态栏：采样率显示为红色 `22050 Hz`
   - 左侧边栏：采样率字段显示红色
   - 右侧边栏「峰值标注/问题清单」标签页：
     - 看到 `采样率 22050Hz 不符合专业标准` 的错误条目
     - 点击展开可看到操作建议、责任人、相关文件说明
     - 同时会看到 `峰值遮挡（削波风险）` 的错误条目
4. 对比「正常样例」：采样率显示为绿色 `44100 Hz`，无错误提示
