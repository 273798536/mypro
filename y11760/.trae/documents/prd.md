## 1. 产品概述

融资担保关系沙盘是一款面向担保公司风控团队的3D交互式关系可视化工具，用于梳理企业、实控人与担保链路之间的复杂关联，精准识别循环担保、同人多企、风险标签遮挡等隐蔽风险，确保每一条风险线索可追溯、每一个评分可解释。

- 目标用户：担保公司风控审查员、合规审计人员、风控主管
- 核心价值：从真实材料出发，理清担保关系网络，避免风险在担保圈内隐匿传导

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 风控审查员 | 查看3D关系图、筛选联动、路径展开、导出报告 |
| 风控主管 | 审核修正记录、查看风险评分明细、审批报告 |

### 2.2 功能模块

1. **沙盘主页面**：3D关系网络、侧边明细面板、筛选工具栏、风险预警区
2. **路径展开页面**：选定节点后展开担保链路、风险传导路径
3. **数据溯源页面**：查看数据来源、修正痕迹、评分解释

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 沙盘主页面 | 3D关系网络 | 以三维力导向图展示企业（蓝色球体）、实控人（橙色球体）、担保合同（绿色连线）节点与关系，支持拖拽、缩放、旋转、点击选中 |
| 沙盘主页面 | 侧边明细面板 | 选中节点后展示详情：企业工商信息、实控人关联企业、担保合同条款、贷款余额、风险标签、调查报告摘要，支持来源标注 |
| 沙盘主页面 | 筛选工具栏 | 按风险等级、担保类型、企业行业、贷款余额区间筛选，筛选后3D视图与侧边面板同步更新 |
| 沙盘主页面 | 风险预警区 | 实时高亮循环担保路径（红色闪烁）、同人多企（黄色标记）、风险标签遮挡（紫色警示），不可关闭只能确认 |
| 路径展开页面 | 担保链路展开 | 点击节点后以该节点为起点，沿担保方向逐层展开，展示风险传导路径与金额 |
| 路径展开页面 | 风险传导模拟 | 沿担保链路模拟风险传导，标注每个环节的影响金额与传导概率 |
| 数据溯源页面 | 来源追溯 | 每条数据标注来源：企业信息来自工商登记、实控人来自股权穿透、担保合同来自合同库、贷款余额来自核心系统、风险标签来自风控模型、调查报告来自尽调团队 |
| 数据溯源页面 | 修正痕迹 | 记录每次数据修正的操作人、时间、原值、新值、修正原因，形成审计轨迹 |
| 数据溯源页面 | 评分解释 | 展示风险评分的拆分明细：每个因子的权重、原始值、贡献分值、异常来源说明 |

## 3. 核心流程

**主流程**：用户进入沙盘 → 3D关系图加载 → 通过筛选器聚焦目标群体 → 点击节点查看侧边明细 → 发现风险预警 → 展开担保链路 → 溯源数据来源 → 导出报告

**风险识别流程**：系统自动检测循环担保/同人多企/标签遮挡 → 在3D图中高亮标记 → 侧边面板弹出预警卡片 → 用户确认风险 → 记录确认操作 → 风险状态更新

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#0F1117）+ 科技蓝（#3B82F6）节点 + 琥珀橙（#F59E0B）实控人 + 翡翠绿（#10B981）担保连线 + 危险红（#EF4444）风险高亮
- **按钮风格**：圆角8px，微透明背景+发光边框，悬停时发光增强
- **字体**：标题使用 Source Han Sans（思源黑体）Bold，正文使用 Source Han Sans Regular，数据标注使用 JetBrains Mono
- **布局风格**：左侧筛选面板 + 中间3D画布 + 右侧明细面板，三栏联动
- **图标风格**：线性图标（Lucide），配合发光效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 沙盘主页面 | 3D关系网络 | 深色背景3D画布，节点为发光球体+文字标签，连线为半透明管道，悬停时节点放大+信息浮窗 |
| 沙盘主页面 | 侧边明细面板 | 右侧可折叠面板，卡片式布局，顶部节点名称+类型标签，中部信息列表，底部操作按钮 |
| 沙盘主页面 | 筛选工具栏 | 左侧竖向工具栏，下拉选择器+范围滑块，筛选时3D视图实时过滤，非匹配节点半透明 |
| 沙盘主页面 | 风险预警区 | 底部横幅+右侧面板预警卡片，循环担保红色脉冲动画，同人多企黄色呼吸灯，标签遮挡紫色闪烁 |
| 路径展开页面 | 担保链路展开 | 从选中节点向外辐射的3D路径，每层节点间距递增，连线标注金额，风险节点红色光晕 |
| 数据溯源页面 | 来源追溯 | 时间线式布局，每条记录显示来源系统+数据快照，修正记录红色标记变更部分 |
| 数据溯源页面 | 评分解释 | 环形图展示评分构成，每段可点击展开因子详情，异常因子红色标注+来源链接 |

### 4.3 响应式设计

- 桌面端优先（1920×1080为基准），3D画布占满可用空间
- 平板端（1024×768）侧边面板改为底部抽屉
- 不支持移动端（3D交互需要精确操作）

### 4.4 3D场景指引

- **环境**：深色星空背景+微弱网格地面，营造数据空间感
- **灯光**：环境光（低强度冷白）+ 点光源（跟随选中节点），营造聚焦感
- **相机**：透视相机，默认45度俯瞰，支持自由旋转/缩放/平移
- **构图**：力导向布局，节点自然分布，风险节点自动外扩避免遮挡
- **交互**：鼠标拖拽旋转场景，滚轮缩放，单击选中节点，双击展开路径，右键菜单
- **后处理**：选中节点Bloom发光效果，风险节点脉冲后处理，连线半透明效果
- **性能预算**：支持500+节点/1000+连线流畅交互，FPS不低于30
