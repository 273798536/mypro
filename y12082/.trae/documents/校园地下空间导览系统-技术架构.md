## 1. 架构设计

```mermaid
graph TD
    A["前端应用"] --> B["3D渲染层"]
    A --> C["状态管理层"]
    A --> D["数据处理层"]
    B --> B1["Three.js渲染"]
    B --> B2["React Three Fiber"]
    C --> C1["React状态管理"]
    C --> C2["联动更新机制"]
    D --> D1["数据清洗模块"]
    D --> D2["异常检测模块"]
```

## 2. 技术描述

- 前端: React@18 + TypeScript + Vite
- 3D渲染: Three.js + @react-three/fiber + @react-three/drei
- 样式: TailwindCSS@3
- 状态管理: React Context + useReducer
- 数据处理: 本地Mock数据 + PapaParse (CSV解析
- 路径规划: A*寻路算法

### 4.2 数据结构定义

```typescript
interface SpaceNode {
  id: string;
  name: string;
  type: 'corridor' | 'room' | 'equipment' | 'pipe_well';
  x: number;
  y: number;
  z: number;
  floor: number;
  description?: string;
}

interface Path {
  id: string;
  from: string;
  to: string;
  distance: number;
  status: 'open' | 'closed' | 'access_issue';
  access_control?: boolean;
}

interface WorkOrder {
  id: string;
  title: string;
  locationId: string;
  status: 'pending' | 'in_progress' | 'completed';
  createTime: Date;
}

interface Anomaly {
  id: string;
  type: 'access_failed' | 'path_closed' | 'floor_mismatch' | 'bad_row';
  description: string;
  pathId?: string;
  resolved: boolean;
}
```
