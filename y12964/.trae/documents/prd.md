## 1. 产品概述

冷热数据归档助手是面向数据库管理员的专业数据治理工具，解决备份缺口检测、分页顺序不稳定等复杂归档场景下的异常识别与追溯问题。通过数据导入、异常筛选、详情溯源、动态状态追踪和审计友好的报告导出，帮助DBA高效处理冷热数据归档中的各类异常记录。

### 核心价值：
- 精准识别备份缺口、分页顺序异常等归档问题
- 提供可追溯的异常来源和处理意见
- 支持慢查询日志补录后的动态报告更新
- 导出报告满足审计组独立审查需求

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------------------|------------------|
| 数据库管理员(DBA) | 内置账号 | 数据导入、异常筛选、详情查看、日志补录、报告导出 |
| 审计人员 | 只读账号 | 报告查看与导出 |

### 2.2 功能模块
1. **归档记录列表页**：数据导入、异常筛选、状态展示、批量操作
2. **归档详情页**：异常来源追溯、处理意见展示、图表+明细解释、状态流转
3. **报告导出**：按运行批次区分文件名和内容、审计友好格式

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 记录列表页 | 数据导入 | 支持CSV/JSON格式导入归档记录 |
| 记录列表页 | 异常筛选 | 按状态、异常类型、时间范围筛选 |
| 记录列表页 | 状态标签 | 顺利/待确认/异常 三类状态 |
| 记录详情页 | 来源追溯 | 展示数据来源、分页信息、校验日志 |
| 记录详情页 | 处理意见 | 系统建议+人工备注 |
| 记录详情页 | 图表明细 | 备份缺口可视化+详细数据解释 |
| 记录详情页 | 慢查询补录 | 补录日志后自动更新状态和报告 |
| 报告导出 | 批次区分 | 文件名含运行批次号，内容标注运行时间戳 |

## 3. 核心流程

```mermaid
flowchart LR
    A["导入归档记录"] --> B["异常检测与分类"]
    B --> C{"状态判断"}
    C -->|顺利| D["标记为正常"]
    C -->|待确认| E["进入人工审核"]
    C -->|异常(备份缺口)| F["拦截并生成处理意见"]
    E --> G["补录慢查询日志"]
    F --> G
    G --> H["重新计算状态"]
    H --> I["生成审计报告"]
    I --> J["按批次导出报告"]
```

**用户操作流程**：
1. DBA导入归档记录数据
2. 系统自动检测异常，标记状态
3. DBA筛选异常记录，进入详情查看
4. 查看来源追溯和处理意见
5. 如需补录慢查询日志，补录后状态自动更新
6. 导出包含完整追溯链的审计报告

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深空灰(#1e293b) + 警示红(#dc2626) + 确认绿(#059669) + 待确认橙(#d97706)
- **按钮风格**：直角矩形、细边框、hover时轻微背景加深
- **字体**：JetBrains Mono (等宽字体，适合数据展示) + Noto Sans SC
- **布局风格**：高密度数据表格、左侧筛选栏、顶部操作栏
- **图标风格**：Lucide 线性图标，保持专业工具感

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 记录列表页 | 顶部操作栏 | 导入按钮、筛选条件、状态统计卡片 |
| 记录列表页 | 数据表格 | 状态标签色标、分页控件、行hover高亮 |
| 记录详情页 | 头部 | 大字号状态标签、运行批次号、时间戳 |
| 记录详情页 | 来源追溯区 | 时间线布局展示数据来源链 |
| 记录详情页 | 图表区 | 备份缺口柱状图 + 右侧明细表格 |
| 记录详情页 | 处理意见区 | 卡片式布局，系统建议与人工备注分开展示 |
| 记录详情页 | 操作区 | 补录日志按钮、导出按钮 |

### 4.3 响应式
- Desktop-first，1280px 起适配
- 表格支持横向滚动
- 移动端简化为卡片列表

### 4.4 可视化设计
- 备份缺口图表：横向柱状图对比预期备份 vs 实际备份
- 图表旁配明细表，逐项标注缺口数值、时间范围、影响记录数
- 颜色仅作辅助，数值和文字说明为主

**样例数据**：
1. 顺利记录：order_backup_2026_001 - 全量备份完整，分页连续
2. 待确认记录：user_log_2026_002 - 分页顺序异常，需补录慢查询日志
3. 异常记录(备份缺口)：payments_2026_003 - 2026-06-15 02:00-04:00 存在 147 条记录缺口
