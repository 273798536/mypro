## 1. 产品概述

宏基因组污染筛查系统是一套面向微生物实验室的污染检测与审计平台。核心目标是让实验室技师和导师能从"低质量读段为什么没通过"开始，沿着培养记录这条线，一路追踪到异常复核、处理意见和报告导出，做到"一条异常查到底"。

- **解决的核心问题**：现有流程中，筛查结论不可解释、复核无审计、界面与报告数据不一致、历史变更无对比，导致实验室技师与导师之间反复沟通
- **目标用户**：实验室技师（日常操作）、实验室导师（审查验收）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验室技师 | 管理员分配账号 | 执行筛查、提交复核、导出报告 |
| 实验室导师 | 管理员分配账号 | 审查复核、批准/驳回异常、查看审计日志 |

### 2.2 功能模块

1. **筛查总览页**：运行批次列表、低质量读段统计、快速筛选
2. **筛查详情页**：读段质量明细、低质量原因人话解释、一键标记异常
3. **异常复核页**：待复核列表、复核操作（批准/驳回）、审计字段（谁/何时/为何）
4. **培养记录页**：培养记录CRUD、历史变更对比（新旧结论并排）
5. **报告导出页**：批次报告生成、文件名含运行标识、可追溯的处理记录

## 3. 核心流程

### 3.1 筛查与复核主流程

实验室技师上传或导入测序数据后，系统自动运行质量筛查，标记低质量读段并给出人话解释。技师对可疑读段发起异常复核，导师审查后批准或驳回，全程审计留痕。修改培养记录时，旧结论与新结论并排展示。导出报告时，界面和报告共用同一批处理记录。

```mermaid
flowchart TD
    "A[导入测序数据]" --> "B[自动质量筛查]"
    "B" --> "C{读段质量达标?}"
    "C" -->|"是"| "D[标记为通过]"
    "C" -->|"否"| "E[标记为低质量 + 人话解释原因]"
    "E" --> "F{技师是否认可?}"
    "F" -->|"认可，无需复核"| "G[记录结论，关闭]"
    "F" -->|"不认可，发起异常复核"| "H[提交复核申请]"
    "H" --> "I[导师审查]"
    "I" --> "J{导师决定}"
    "J" -->|"批准通过"| "K[更新培养记录结论]"
    "J" -->|"驳回"| "L[维持原结论]"
    "K" --> "M[新旧结论并排对比 + 审计日志]"
    "M" --> "N[导出报告（含完整处理记录）]"
```

### 3.2 追溯流程

验收时，导师从任意异常出发，可沿以下路径回溯：异常 → 低质量读段 → 原因解释 → 培养记录 → 处理意见 → 复核历史。

```mermaid
flowchart LR
    "A[异常条目]" --> "B[低质量读段详情]"
    "B" --> "C[人话原因解释]"
    "B" --> "D[关联培养记录]"
    "D" --> "E[处理意见]"
    "D" --> "F[变更对比（新旧并排）]"
    "D" --> "G[变更审计日志]"
    "A" --> "H[复核历史时间线]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 (#0F766E) 作为品牌色，搭配暖灰 (#F5F5F4) 背景，强调专业实验室氛围
- **辅助色**：琥珀色 (#D97706) 用于警示/异常标记，翡翠绿 (#059669) 用于通过状态
- **按钮风格**：圆角矩形（rounded-lg），主按钮实心填充，次按钮描边
- **字体**：标题用 "Source Serif 4"（衬线体，学术感），正文用 "DM Sans"（无衬线，清晰易读）
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式内容分组
- **图标风格**：使用 Lucide 图标库，线条风格，统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 筛查总览页 | 运行批次卡片 | 白底圆角卡片，左侧状态色条，右上角批次ID，标题字体 Source Serif 4，微妙阴影 |

| 筛查详情页 | 标记异常按钮 | 琥珀色描边按钮，hover 实心填充 |

### 4.3 响应式设计

- 桌面优先设计（1280px+），左侧导航始终可见
- 平板端（768-1279px）导航栏收缩为图标模式
- 手机端（<768px）导航栏变为底部标签栏，表格改为卡片列表
