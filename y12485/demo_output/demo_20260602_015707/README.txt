电磁场线粒子厅 - 导出结果
==================================================

文件说明:
  - tracking_chain.json: 完整链路追踪数据
  - annotations.json: 版本化读数标注
  - classification.json: 结果分类报告
  - scheme_comparison_report.*: 方案比较报告

复核节点清单:
  1. 检查方向反转事件的来源（E场/B场）
  2. 确认反转与越界事件是否被错误合并
  3. 核对标注的版本历史和置信度
  4. 通过链路追踪追溯配置变更
