# 太阳能阵列阴影台 - 使用说明

## 怎么启动

```bash
# 安装依赖
npm install --legacy-peer-deps

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后浏览器打开终端显示的地址（默认 http://localhost:5173）。

## 怎样触发组件遮挡分析

### 步骤1：启动应用，等待障碍物加载
- 打开页面后，左上角会显示"障碍物数据加载中..."约2.5秒
- 期间3D场景中障碍物显示为橙色虚线框

### 步骤2：点击"开始阴影分析"按钮
- 按钮在工具栏最右侧，蓝色
- 点击后显示加载动画，约1秒完成
- 完成后自动生成：
  - 阴影记录（每个组件×四季×15小时）
  - 方位角错误记录
  - 季节切换漏算记录
  - 发电估算数据

### 步骤3：查看遮挡结果
1. **3D视图实时反馈**：
   - 组件颜色变化：蓝(正常)→绿(低)→黄(中)→橙(高)→红(严重)
   - 问题组件角落显示标记：
     - 🟡 黄球 = 有备注
     - 🟠 菱形虚线 = 缺字段
     - 🟣 圆环 = 方位角错误
     - 🔵 三角锥 = 季节漏算

2. **底部明细表**：
   - 分标签页查看：全部/阴影/方位角/季节
   - 点击任意行展开，左侧是问题详情，右侧是**可操作修正建议**
   - 点击"定位"按钮，3D视图自动聚焦该组件并筛选

3. **筛选同步**：
   - 工具栏筛选器（严重度/原因/季节）与明细表、3D视图双向同步
   - 左侧阴影面板切换季节也会同步筛选
   - 3D视图中未匹配筛选的组件会变暗

## 核心功能使用

### 视角操作
- **旋转**：鼠标左键拖拽
- **缩放**：鼠标滚轮
- **平移**：鼠标右键拖拽
- **保存视角**：工具栏"视角"按钮 → 输入名称 → 保存
- **恢复视角**："视角"下拉 → 点击保存的视角名 → 平滑动画过渡

### 阴影播放
- 左侧面板季节按钮：春分/夏至/秋分/冬至
- 播放按钮：循环播放5:00-19:00阴影变化
- 滑块：手动拖动到指定时刻
- 速度：0.5x / 1x / 2x / 4x
- 实时显示太阳高度角、方位角

### 发电估算
- 右侧面板显示当前季节：
  - 总发电量 / 有效发电 / 阴影损失 / 方位角损失
  - 逐时发电面积图
  - 四季修正前后对比柱状图
- 点击3D组件，面板底部显示组件详情

### 方位角错误处理
- 分析后自动检测与屋顶基准方位角偏差>5°的组件
- 明细表中每条记录给出：
  - 期望角度 / 实际角度 / 偏差度数
  - 具体修正方向（顺时针/逆时针）和度数
  - 预计发电量提升百分比和kWh数

### 季节切换漏算
- 自动识别冬季低太阳高度角导致的后排遮挡
- 给出季节-specific的修正建议（调整间距/倾角/温度系数等）

## 常见问题

**Q: 为什么组件显示橙色虚线框？**
A: 数据缺字段（width/height/model/efficiency），系统用默认值渲染但标记出来提醒补全。

**Q: 方位角偏差多少度会被标记？**
A: >5°。阈值在 `src/engine/azimuthChecker.ts` 中 `AZIMUTH_TOLERANCE` 可改。

**Q: 阴影分析的计算原理？**
A: 基于太阳位置公式计算每小时高度角/方位角，然后用投影法计算障碍物和前排组件在目标组件上的阴影面积占比。

**Q: 如何换成真实数据？**
A: 修改 `src/data/mockData.ts` 中的三个导出对象，或在 `App.tsx` 的 `useEffect` 中改为从API加载。
