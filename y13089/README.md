# 博物馆展柜灯光方案比选系统

## 📋 系统概述

本系统用于博物馆展柜灯光方案的点位坐标审核与异常管理。系统内置了一包现场点位坐标数据（包含一条名称不一致的记录），支持筛选条件持久化、人工备注、异常队列管理和导出功能。

> **重要特性**：刷新页面后，筛选条件、人工备注、异常处理状态将自动保持同步。

## 🚀 快速开始（阿乔操作指南）

### 第一步：启动开发服务器

```bash
npm run dev
```

启动后访问 `http://localhost:5173`

### 第二步：查看异常队列

启动后，请首先点击顶部导航栏的 **"异常队列"** 标签页，这里列出了所有需要处理的异常：

- **EX-001**（中危）：点位名称不一致 - PT-006 原始名称与系统名称不匹配
- **EX-002**（高危）：显色指数低于标准要求 - 多个点位CRI<90
- **EX-003**（中危）：照度超出书画类文物标准 - PT-004 照度85lux
- **EX-004**（低危）：相邻点位合并存在歧义 - PT-001与PT-002坐标相邻
- **EX-005**（高危/已解决）：玉器展区照度过高 - 已与设计方沟通

### 第三步：处理异常流程

1. 点击任意异常查看详情
2. 查看**空间位置**确认关联点位坐标
3. 查看**原始证据链**追溯来源文件和原始数据
4. 查看**人工备注**了解历史沟通记录
5. 更新**状态管理**（待处理→处理中→需补证据→已解决）
6. 添加备注记录处理过程
7. 点击"导出JSON"导出完整的异常报告（包含空间位置、备注、原始证据）

### 第四步：项目经理总览

点击 **"项目总览"** 标签页，项目经理可以看到：

- 点位处理进度统计
- 异常解决进度统计
- 需补充证据的异常清单
- 按灯光方案和展柜的处理进度
- 未解决异常清单

## ✨ 核心功能

### 1. 点位坐标管理

- 内置10个点位坐标数据，来自真实现场测量
- **PT-006**特意设置为名称不一致：
  - 系统显示名称：`展柜C-展品聚焦灯`
  - 原始文件名称：`展柜C-文物聚光灯`
- 每个点位包含完整溯源信息：来源文件、行号、导入时间

### 2. 筛选条件持久化

- 支持按灯光方案、展柜筛选
- 支持按照度、CRI、色温范围筛选
- 支持关键词搜索
- 支持"仅显示名称不一致"和"仅显示异常相关"快捷筛选
- **所有筛选条件自动保存，刷新页面不丢失**

### 3. 相邻点位合并

- 自动识别同一展柜内坐标相近的点位
- 合并时保留所有原始点位的证据链
- 可追溯到每个点位的原始坐标和来源
- 名称不一致时会高亮提示

### 4. 异常队列管理

- 按严重程度（高/中/低）排序显示
- 支持4种状态流转：待处理→处理中→需补证据→已解决
- 每条异常关联原始证据链
- 支持添加人工备注

### 5. 导出功能

点击异常详情页的"导出JSON"，导出内容包含：

```
异常编号、类型、严重程度、状态、标题、描述
├── 空间位置：关联点位的ID、名称、原始名称、坐标、展柜、灯光方案
├── 原始证据：点位名称、原始坐标、来源文件、行号、原始值
└── 人工备注：作者、内容、时间
```

## 🔍 测试要点

1. **刷新测试**：设置筛选条件后刷新页面，确认筛选条件保留
2. **名称不一致**：找到PT-006，确认原始名称与系统名称的差异提示
3. **相邻点位合并**：查看PT-001或PT-002的合并信息，点击"查看原始点位证据链"
4. **异常导出**：点击任意异常→"预览导出"→"导出JSON"，确认导出内容包含空间位置、备注、原始证据
5. **状态流转**：将EX-001从"待处理"改为"处理中"，刷新页面确认状态保留
6. **添加备注**：在异常或点位详情中添加备注，刷新页面确认备注保留
