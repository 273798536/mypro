## 1. 产品概述

农机作业补贴核验系统是面向农业合作社财务人员的本地数据核验工具，解决农机作业面积、北斗轨迹和农户签字表三方数据不一致导致的补贴发放延迟问题。系统通过数据导入、智能核验、状态流转和问题导出四个核心环节，拦截脏数据，确保补贴发放前数据口径一致。

- **目标用户**：农业合作社财务人员、补贴申报专员
- **核心价值**：将日常核验和事后复核对齐到同一数据口径，问题可追踪、可导出、可复盘
- **部署方式**：本地单节点小服务，数据全部存储在本地，无需联网

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 操作员 | 本地登录 | 数据导入、面积核验、状态推进、问题导出 |
| 复核员 | 本地登录 | 人工复核、导出清单、查看历史记录 |

### 2.2 功能模块

1. **数据导入页**：农户档案导入、面积申报导入、北斗轨迹导入、补贴规则导入，保留原始材料版本
2. **面积核验页**：日常数据处理主界面，展示核验进度、问题列表、快捷处理入口
3. **人工复核页**：事后复盘界面，逐条复核可疑数据，标记复核结论
4. **导出管理页**：导出核验报告、问题清单、补贴发放清单，所有问题均体现在导出文件中
5. **使用说明页**：农户档案准备指南、轨迹断点复现方法、导出清单解读

## 3. 核心流程

补贴核验从数据导入开始，经过自动核验标记问题，然后进入人工复核，最后导出结果。所有操作均保留原始数据和处理痕迹。

```mermaid
flowchart LR
    A["导入数据<br/>(农户/面积/轨迹/规则)"] --> B["自动核验<br/>(轨迹断点/面积重复/签字缺失)"]
    B --> C["日常处理<br/>(面积核验页)"]
    C --> D["状态推进<br/>(待核验→核验中→待复核)"]
    D --> E["人工复核<br/>(事后复盘)"]
    E --> F["已通过/已驳回"]
    F --> G["导出报告<br/>(含全部问题标记)"]
    G --> H["补贴发放清单"]
```

**关键规则**：
1. 原始数据导入后不可修改，处理结果与原始数据分离存储
2. 三类问题（轨迹断点、面积重复、签字缺失）自动检测，支持人工调整
3. 日常核验和事后复核共用同一数据模型，导出口径完全一致
4. 所有导出文件必须包含问题标记，不得以页面提示代替书面记录

## 4. 用户界面设计

### 4.1 设计风格

面向财务人员的专业工具，采用**严谨稳重的工业风**设计，强调数据清晰度和操作效率。

- **主色调**：深蓝 `#1e3a5f`（专业可靠），辅助色：橙红 `#d9534f`（问题警示）、绿色 `#5cb85c`（通过）、橙色 `#f0ad4e`（待处理）
- **字体**：标题使用 `Noto Serif SC`（稳重有质感），数据表格使用 `JetBrains Mono`（数字对齐清晰），正文使用 `Noto Sans SC`（可读性好）
- **布局**：左侧导航 + 右侧主内容区，数据密集型表格布局，信息密度适中
- **交互**：问题标记使用醒目的徽章（Badge），状态流转使用清晰的时间线展示
- **背景**：浅灰渐变背景 +  subtle noise 纹理，避免纯白纸感

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据导入页 | 上传区域 | 拖拽上传区、文件类型图标、上传进度条 |
| 数据导入页 | 批次列表 | 卡片式展示导入批次，包含导入时间、数据条数、状态标记 |
| 面积核验页 | 仪表盘 | 四个统计卡片（总数/通过/待处理/问题），问题类型饼图 |
| 面积核验页 | 数据表格 | 固定表头、斑马纹、问题列高亮、行内快捷操作 |
| 人工复核页 | 复核详情 | 左右分栏：左侧数据列表，右侧原始材料与处理记录对比 |
| 导出管理页 | 导出选项 | 复选框组选择导出内容，预览按钮，格式选择 |
| 使用说明页 | 说明卡片 | 三段式卡片布局，每段包含标题、步骤、示意图 |

### 4.3 响应式

桌面端优先设计，适配 1280px 及以上屏幕。数据表格支持横向滚动，确保在较小屏幕下数据完整性。

### 4.4 动效设计

- 页面加载：内容区域淡入，统计数字滚动增长
- 状态变更：状态徽章颜色渐变过渡
- 问题标记：标记操作时轻微缩放反馈
- 表格行：悬停时背景色柔和过渡
