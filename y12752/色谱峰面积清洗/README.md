# 色谱峰面积清洗工具

## 这是做什么的

把 **称量单、色谱峰面积原始数据、谱图判读记录** 三份 CSV 自动对齐合并，
同一批号多次复检时自动选最新记录，不打架；导出的 Excel 报告里有普通话说明，
安全员可以直接复制转发给同事。想追根溯源时，一条命令就能回溯到谱图数据文件和处理意见。

---

## 快速开始（3 步跑通样例）

### 1. 安装依赖

```bash
cd 色谱峰面积清洗
pip install -r requirements.txt
```

### 2. 跑样例数据（第一次推荐先跑这个）

```bash
python main.py run
```

样例数据放在 `sample_data/` 目录下，不用你手工整理：

| 文件 | 说明 |
|------|------|
| `sample_data/称量单.csv` | 含 8 条称量记录，其中 2 条是复检批号 |
| `sample_data/色谱峰面积.csv` | 含 16 条峰面积记录（8 次进样，每次 2 个峰） |
| `sample_data/谱图判读记录.csv` | 含 8 条判读记录，含异常和复检说明 |

### 3. 查看输出

报告在 `output/色谱峰面积清洗报告_时间戳.xlsx`，含 5 个工作表：

| 工作表 | 给谁看 | 内容 |
|--------|--------|------|
| 最终结果汇总 | 质检主管 | 每批号最终采用的数据，复检批号有标注 |
| 重复批号说明 | 所有人 | 哪些批号测了多次、为什么重复、采用哪条 |
| 全部记录明细 | 存档/对账 | 所有历史记录，含被替代的旧记录 |
| 安全员说明（可直接转发） | 同事 | 纯普通话，复制粘贴就能发 |
| 异常追溯明细 | 安全员复核 | 从批号往下钻到谱图文件名、称量详情、判读意见 |

## 完整命令参考

### `run` — 跑清洗 + 导出报告

```bash
# 使用默认样例
python main.py run

# 指定自己的文件
python main.py run \
  --weight /path/称量单.csv \
  --peak /path/色谱峰面积.csv \
  --interpretation /path/谱图判读记录.csv \
  --output ./output
```

**参数说明：**

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--weight` | 称量单 CSV 路径 | `sample_data/称量单.csv` |
| `--peak` | 色谱峰面积 CSV 路径 | `sample_data/色谱峰面积.csv` |
| `--interpretation` | 谱图判读记录 CSV 路径 | `sample_data/谱图判读记录.csv` |
| `--output` | 报告输出目录 | `output/` |

### `list` — 列出所有可追溯批号

```bash
python main.py list
```

会显示每个批号是否异常、是否为复检批次。

### `trace` — 追溯某批号全过程（顺着异常往回查）

```bash
# 文本格式
python main.py trace --batch B20260601-01

# 同时输出 JSON，方便对接其他系统
python main.py trace --batch B20260601-03 --json
```

输出会展示：
- 该批号共检测几次、每次的记录编号和时间
- 每次检测的主峰面积、处理意见、结论
- 原始谱图数据文件名（能定位到仪器上的原始文件）
- 称量详情（称量人、重量、稀释倍数等）
- 判读详情（判读人、峰形评价、异常类型、复核人等）

## 输入 CSV 格式要求

不用手工整理列顺序，只要包含以下必要列即可，顺序随意：

### 称量单 `--weight`

必要列：`批号`、`样品名称`、`称量日期`
推荐列：`称量单号`、`称量人`、`样品重量(g)`、`稀释倍数`、`进样体积(uL)`、`备注`

### 色谱峰面积 `--peak`

必要列：`批号`、`样品名称`、`记录编号`、`进样时间`
推荐列：`峰序号`、`保留时间(min)`、`峰面积`、`峰高`、`数据文件名`、`仪器编号`

### 谱图判读记录 `--interpretation`

必要列：`批号`、`判读日期`
推荐列：`判读编号`、`判读人`、`主峰面积`、`峰形评价`、`异常类型`、`处理意见`、`复核人`、`复核结论`

---

## 重复批号 / 复检处理逻辑

1. **同一批号第二次及以后导入** → 自动标为「重复批次」，前次记录的「被替代记录」字段会指向最新记录编号
2. **最终采用哪条** → 按检测时间取最新一条（看 `进样时间` 或 `称量日期`）
3. **为什么重复** → 工具会读称量单的「备注」字段：
   - 备注含「复检」 → 说明里写清楚复检原因
   - 不含「复检」 → 写通用的多次检测说明
4. **界面、报告、追溯共用同一批 `BatchRecordManager` 记录** → 保证三处看到的结论一致，不会各算各的

## 安全员验收时怎么追异常

以样例中的 `B20260601-03` 为例：

```bash
python main.py trace --batch B20260601-03
```

你会看到：
1. **第 1 次检测**：主峰前有肩峰，处理意见「建议复检」，复核人同意复检
2. **第 2 次检测**：肩峰已消失，结论「复检合格，放行」
3. 两次的谱图原始文件名、称量单号、判读人、复核人都能查到

把这条链路给质检主管看，就算顺。
