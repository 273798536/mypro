## 1. 产品概述

磁场小车竞速是一款面向物理竞赛学员的交互式教育游戏，通过操控带电粒子在磁场中运动，让玩家在实时操作中感受洛伦兹力方向判定、圆弧轨迹模拟与能量约束之间的取舍与权衡。目标用户为高中物理竞赛教练与学员，解决方向反判、能量超限、质量缺失等常见错误缺乏系统化捕获与反馈的教学痛点。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学员 | 昵称注册 | 参与竞速关卡、查看个人错误清单与规则复盘 |
| 教练 | 邀请码注册 | 发布关卡、修改材料参数、审核异常清单、查看学员对比报告 |

### 2.2 功能模块

1. **赛道页面**：磁场板渲染、电流条注入、靶门定位、小车实时轨迹、力方向箭头
2. **材料面板**：分步录入磁场板/电流条/靶门，后补材料不覆盖前判
3. **异常清单页面**：方向反判/能量超限/质量缺失归类为待确认或异常，与正常明细隔离
4. **复盘页面**：错误定位到具体规则（力方向左/右手定则、轨迹半径公式、能量守恒），参数修改前后差异对比

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 赛道页面 | 磁场板画布 | Canvas 渲染磁场区域（⊗/⊙符号），支持拖拽放置 |
| 赛道页面 | 电流条注入 | 点击电流条设置 I 值与方向，实时更新洛伦兹力箭头 |
| 赛道页面 | 靶门定位 | 拖拽靶门到目标位置，计算理论轨迹是否穿过靶门 |
| 赛道页面 | 小车轨迹 | 基于当前参数实时模拟带电粒子圆弧运动，显示预测轨迹与实际轨迹 |
| 赛道页面 | 力方向指示 | 实时显示洛伦兹力 F 方向箭头，玩家需判断与拖拽方向是否一致 |
| 材料面板 | 分步录入 | 磁场板先到→电流条后补→靶门再补，后补不覆盖已有判定 |
| 材料面板 | 判定锁定 | 已确认的磁场板判定在电流条到达后锁定，仅扩展不覆盖 |
| 异常清单页面 | 异常归类 | 方向反判→待确认区，能量超限→异常区，质量缺失→异常区 |
| 异常清单页面 | 隔离展示 | 异常项不进入正常明细，需教练确认后才能归档或修正 |
| 复盘页面 | 规则定位 | 错误时高亮指出违反的具体规则条目（如"左手法则：拇指应指向 B 方向"） |
| 复盘页面 | 参数对比 | 修改电流条后重跑，保留前后参数快照与轨迹差异对比 |

## 3. 核心流程

玩家进入赛道→磁场板先到达→玩家设置磁场方向与强度→电流条到达→玩家设置电流大小与方向→系统实时计算洛伦兹力方向→玩家操控小车选择出发角度→靶门到达→玩家判断靶门位置是否在轨迹上→系统判定方向反判/能量超限/质量缺失→异常项进入异常清单→复盘时定位具体规则违反条目→教练修改参数重跑对比。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝黑底（#0a0e1a）+ 电光青蓝（#00e5ff）+ 磁力琥珀（#ffab00）
- 辅助色：正常态翠绿（#00e676）、异常态赤红（#ff1744）、待确认态琥珀黄（#ffd600）
- 按钮风格：圆角矩形带发光边框，hover 时发光扩散
- 字体：标题用 Orbitron（科技感），正文用 Noto Sans SC
- 布局：赛道画布居中占 70%，左侧材料面板，右侧异常清单
- 图标风格：线性发光图标，磁场用⊗/⊙符号，电流用箭头符号

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 赛道页面 | 磁场板画布 | 深色背景+网格线，⊗/⊙符号阵列，拖拽放置高亮区 |
| 赛道页面 | 电流条 | 竖向滑轨+发光圆点，方向切换按钮（↑/↓） |
| 赛道页面 | 靶门 | 双竖线发光门框，拖拽定位，理论轨迹穿过时门框变绿 |
| 赛道页面 | 小车 | 发光圆点+尾迹，出发角度弧线指示器 |
| 赛道页面 | 力方向箭头 | 从小车中心出发的发光箭头，颜色按 F/B/v 区分 |
| 材料面板 | 分步卡片 | 磁场板卡（锁定态）、电流条卡（可编辑）、靶门卡（待到达灰态） |
| 异常清单页面 | 分类标签页 | 待确认（琥珀）/ 异常（赤红）/ 已归档（灰）三栏 |
| 复盘页面 | 规则卡片 | 高亮违反条目，规则原文+玩家操作对比 |
| 复盘页面 | 对比面板 | 左侧修改前参数+轨迹，右侧修改后参数+轨迹，差异高亮 |

### 4.3 响应式

桌面优先设计，赛道画布在 1440px+ 下全功能展示；1024-1439px 隐藏侧面板为抽屉；<1024px 暂不支持。

### 4.4 3D 场景指引

不适用，本项目使用 2D Canvas 渲染。
