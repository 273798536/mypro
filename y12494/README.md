# 钢琴共振可视琴房

一个交互式的 3D 工作台，用于可视化钢琴琴弦共振效果。

## 功能特性

- 🎹 **交互式 3D 场景** - 可旋转、缩放的钢琴模型和琴弦
- 🎵 **琴弦分组管理** - 灵活的分组编辑，支持自定义音域和颜色
- 🎼 **时间轴回放** - 可视化音符事件，支持播放/暂停/重置
- 🔄 **共振可视化** - 实时显示琴弦振动和共振强度
- ⚠️ **边界值检测** - 共振过强时自动警告
- 💾 **数据导入导出** - JSON 格式保存和加载配置
- 📸 **截图导出** - 一键导出当前 3D 场景截图
- 🏷️ **清晰标注** - 振动琴弦显示音符名和共振百分比

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

浏览器会自动打开 `http://localhost:3000`

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 使用指南

### 1. 加载演示数据

点击左侧「加载演示模型」按钮，即可看到预设的琴弦分组和音符事件。

### 2. 管理琴弦分组

- **添加分组**：点击「添加分组」按钮
- **编辑分组**：直接在输入框中修改分组名称、起始音符和结束音符
- **删除分组**：点击分组下方的「删除」按钮
- **颜色标识**：每个分组有独立颜色，便于在 3D 场景中识别

音符编号范围：21 (A0) - 88 (C8)

### 3. 管理音符事件

- **添加事件**：点击「添加事件」按钮
- **编辑事件**：修改音符名（如 C4）、触发时间和持续时间
- **删除事件**：点击事件下方的「删除」按钮

### 4. 时间轴回放

时间轴按琴弦分组显示音符事件：
- ▶️ 播放 - 开始回放音符序列
- ⏸️ 暂停 - 暂停当前回放
- ⏮️ 重置 - 回到起始位置

### 5. 调整共振参数

拖动滑块调整共振强度（0 - 1）：
- 正常范围：0 - 0.8
- 警告范围：> 0.8（会显示红色警告）

共振过强可能导致琴弦振动异常。

### 6. 数据管理

- **导出数据**：将当前配置保存为 JSON 文件
- **导入数据**：加载之前保存的 JSON 配置
- **截图导出**：将 3D 场景保存为 PNG 图片

### 7. 3D 场景操作

- **旋转视角**：鼠标左键拖动
- **缩放**：鼠标滚轮
- **平移**：鼠标右键拖动

## 导出文件说明

导出的 JSON 文件包含以下内容：

```json
{
  "version": "1.0",
  "exportTime": "2024-01-01T12:00:00.000Z",
  "stringGroups": [
    {
      "id": 1,
      "name": "低音区",
      "startNote": 21,
      "endNote": 36,
      "color": "#ff6b6b"
    }
  ],
  "noteEvents": [
    {
      "id": 1,
      "note": "C4",
      "midiNote": 60,
      "time": 0.5,
      "duration": 1.0,
      "velocity": 0.8
    }
  ],
  "resonanceSettings": {
    "strength": 0.5
  },
  "summary": {
    "totalGroups": 1,
    "totalEvents": 1,

```

**注意**：导出文件的 `summary` 部分与界面右侧「当前状态」面板以及终端输出的摘要信息保持一致。

## 核心技术栈

- **Three.js** - 3D 渲染引擎
- **Vite** - 构建工具
- **OrbitControls** - 3D 场景交互控制

## 从空目录开始的完整流程

1. 确保已安装 Node.js
2. 克隆或创建项目目录
3. 运行 `npm install` 安装依赖
4. 运行 `npm run dev` 启动开发服务器
5. 浏览器打开后点击「加载演示模型」
6. 点击「播放」查看共振效果
7. 调整参数后点击「截图导出」保存结果

## 注意事项

- 共振强度超过 0.8 时会触发警告，建议在正常范围内使用
- 导出的 JSON 文件可以在不同环境间共享配置
- 截图功能会导出当前 3D 视口的画面，建议调整好角度后再导出
- 所有编辑操作实时生效，无需重建模型

## 排错指南

**问题**：页面空白，没有 3D 场景
- 检查浏览器控制台是否有错误
- 确认 `npm install` 已成功执行
- 尝试刷新页面

**问题**：琴弦不振动
- 确认已点击「播放」按钮
- 检查音符事件的时间设置
- 确认共振强度不为 0

**问题**：导入数据失败
- 确认 JSON 文件格式正确
- 检查文件是否损坏
- 查看终端错误信息
