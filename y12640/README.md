# 音乐节人流热区画板

一款教育类网页应用，旨在帮助教研老师检测和分析音乐节人流热区数据中的常见问题。

## 功能特性

- **画布展示**: 交互式Canvas画布，支持热点标记和热区绘制
- **状态控制**: 开始、暂停、重开、结算功能
- **智能检测**: 自动检测底图坐标不完整、比例尺错用、数据重复等问题
- **复盘导出**: 生成评分表和复盘报告，支持JSON和HTML格式导出
- **样例数据**: 提供三条样例数据（顺利记录、待确认记录、坏数据记录）

## 技术栈

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 3
- Zustand (状态管理)
- Lucide React (图标)

## 使用说明

1. **选择样例**: 从工具栏选择一个样例数据（顺利记录、待确认记录、坏数据记录）
2. **开始检测**: 点击「开始」按钮运行检测
3. **查看结果**: 在右侧检测面板查看检测结果和问题分类
4. **结算评分**: 点击「结算」生成评分表和综合评价
5. **导出报告**: 选择导出JSON或HTML格式的复盘报告

## 检测规则

| 严重程度 | 颜色 | 检测内容 |
|---------|------|---------|
| 错误 | 红色 | 重复坐标、坐标翻转、无效比例尺 |
| 待确认 | 黄色 | 空值、未标注比例尺、备注混写 |
| 正常 | 绿色 | 数据完整可用 |

## 样例数据说明

### 1. 顺利记录 (smooth)
- 坐标完整、比例尺正确、数据一致的标准样例
- 预期检测结果: 全部通过

### 2. 待确认记录 (pending)
- 存在空值和未标注比例尺
- 需要人工复核确认

### 3. 坏数据记录 (bad)
- 存在坐标翻转、重复和备注混写问题
- 用于测试检测引擎的健壮性

```
├── types/               # 类型定义
├── App.tsx              # 主应用组件
├── main.tsx             # 入口文件
└── index.css            # 全局样式
```

## 导出格式

### JSON 格式
包含检测结果、评分表和原始数据的结构化JSON文件

### HTML 格式
带有样式的独立HTML报告，包含检测概览、详细结果和评分可视化
