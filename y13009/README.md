# ABS 现金流风险预警

本地单机使用，数据存于浏览器 localStorage。

---

## 一、启动

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 http://localhost:5173）。

构建生产版本：

```bash
npm run build
npm run preview
```

## 二、重跑

主控面板顶部「重跑全部」按钮。

- 所有**未撤回**的记录重置为「待确认」，可重新核对。
- 已撤回的记录保持撤回状态不变。
- 操作会写入时间线，可追溯。

## 三、查看 Markdown 报告

两种方式：

1. **在线预览**：顶部导航切到「Markdown 报告」页，页面状态与报告正文实时一致。
2. **下载 .md 文件**：主控面板或报告页的「导出 Markdown / 下载 .md 文件」按钮，文件名自动带时间戳。
