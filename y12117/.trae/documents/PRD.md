## 1. 产品概述

"相关性误判提醒器是一款面向数据分析新人导师使用的专业分析工具，用于自动检测时间序列数据中的相关性误判风险，重点识别滞后关系和共同趋势问题。

- 解决数据分析教学场景下导师需手工判断滞后关系的痛点
- 帮助新人理解"相关性 ≠ 因果性
- 目标用户：数据分析导师、数据分析师、教学场景
- 核心价值：自动定位问题材料，提供可解释的分析结论

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 导师用户 | 无需注册，本地使用 | 上传数据、分析、导出 |

### 2.2 功能模块

1. **数据分析看板**：数据上传对齐、核心计算结果展示、问题警告
2. **结果明细页**：相关性矩阵、滞后检测结果、共同趋势识别、材料定位
3. **数据导出**：统一数据源导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 分析看板 | 数据上传区 | 支持多文件上传，自动识别时间字段、指标字段、分组字段 |
| 分析看板 | 参数配置区 | 时间范围选择、分组字段选择、指标字段选择、滞后范围设置 |
| 分析看板 | 相关性矩阵 | 热力图展示变量间相关性系数 |
| 分析看板 | 滞后检测区 | 展示最佳滞后阶数检测结果，醒目标注问题 |
| 分析看板 | 共同趋势区 | 识别并高亮共同趋势变量组 |
| 分析看板 | 材料定位区 | 精确定位问题所在的数据行/材料来源 |
| 分析看板 | 数据导出 | 导出当前分析的图表、明细数据 |

## 3. 核心流程

用户上传多份数据材料 → 系统自动对齐时间字段、分组字段、指标字段 → 自动计算相关性 → 检测滞后关系 → 识别共同趋势 → 生成警告并定位问题材料 → 展示分析结果 → 导出统一数据源

```mermaid
flowchart LR
    A["上传数据文件"] --> B["自动识别字段"]
    B --> C["对齐时间/分组/指标"]
    C --> D["相关性计算"]
    D --> E["滞后关系检测"]
    E --> F["共同趋势识别"]
    F --> G["生成问题警告"]
    G --> H["定位问题材料"]
    H --> I["展示分析结果"]
    I --> J["导出统一数据"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰背景（#0f172a）+ 琥珀色警告（#f59e0b）+ 红色错误（#ef4444）+ 青色强调（#06b6d4）
- 按钮风格：直角、扁平、高对比度
- 字体：等宽字体（JetBrains Mono）用于数据展示，无衬线字体（Noto Sans SC）用于正文
- 布局：信息密度高，层次分明，警告区域使用边框和背景色突出
- 图标风格：简洁线性图标，警告使用醒目色块

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|----------|----------|
| 分析看板 | 数据上传区 | 拖拽上传、文件列表、字段映射预览 |
| 分析看板 | 参数配置区 | 下拉选择器、日期范围选择器、数值输入框 |
| 分析看板 | 相关性矩阵 | 热力图、悬停显示数值、点击查看详情 |
| 分析看板 | 滞后检测区 | 卡片式布局、问题卡片使用红/橙色边框突出、材料来源标注 |
| 分析看板 | 共同趋势区 | 分组卡片、趋势线图表、变量列表 |
| 分析看板 | 警告区 | 顶部固定、醒目色块、问题描述、定位链接 |

### 4.3 响应式

- 桌面端优先设计，适配 1280px 及以上分辨率
- 移动端自动适配平板设备
- 表格和图表支持水平滚动
- 触控操作优化

### 4.4 动画

- 问题卡片入场动画：渐入 + 轻微上浮
- 警告提示：脉冲动画突出重要信息
- 悬停效果：微妙的背景色变化
