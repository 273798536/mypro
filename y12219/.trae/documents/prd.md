## 1. 产品概述

线上课程退款拆分系统，面向教育机构财务人员，解决退款口径不一致、优惠追回解释模糊、课程进度变更后退款计算无据可查的问题。核心目标：每一次退款拆分都能输出可审计、可呈报的说明，筛选条件变动后图表和明细自动同步，学员订单、优惠券、退款说明各自独立可追溯。

- 目标用户：教育机构财务、教务复核人员
- 核心价值：退款拆分口径统一、优惠追回有据可依、课程进度改动影响可见

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 财务人员 | 日常退款操作与导出 | 退款拆分计算、导出退款说明 |
| 教务复核人员 | 审核退款合理性 | 查看退款明细、比对课程进度变更、复核导出说明 |

### 2.2 功能模块

1. **退款拆分总览页**：筛选条件面板 + 拆分汇总图表 + 退款明细列表，筛选条件变化时图表和明细同步刷新
2. **学员退款详情页**：学员订单区、优惠券区、退款说明区三块独立展示，课程进度变更历史与优惠回滚影响可展开查看
3. **退款说明与导出页**：按"进度补录""优惠追回""资料已发"分节生成说明，支持导出含改动影响的完整退款说明

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 退款拆分总览 | 筛选条件面板 | 按学员、课程、日期、退款状态筛选，条件变化后图表和明细同步更新 |
| 退款拆分总览 | 拆分汇总图表 | 饼图/柱状图展示退款金额、优惠追回金额、实退金额分布，随筛选联动 |
| 退款拆分总览 | 退款明细列表 | 每条退款记录独立展示订单来源、优惠来源、退款说明来源，不被压成一行总记录 |
| 学员退款详情 | 学员订单区 | 展示该学员关联的原始订单信息（金额、时间、支付方式），独立区块 |
| 学员退款详情 | 优惠券区 | 展示该订单使用的优惠券（面额、使用条件、追回状态），独立区块 |
| 学员退款详情 | 退款说明区 | 展示退款拆分计算过程与结果，含优惠追回、课时消耗、资料扣费等明细 |
| 学员退款详情 | 课程进度变更历史 | 时间线展示课程进度的人工修改记录，标注修改前后差异及对退款的影响 |
| 学员退款详情 | 优惠回滚影响 | 当课时消耗被人工改过时，展示优惠回滚金额的前后对比 |
| 退款说明与导出 | 进度补录说明 | 单独一节说明因进度补录导致的退款调整，含补录原因和金额影响 |
| 退款说明与导出 | 优惠追回说明 | 单独一节说明优惠追回的计算依据和金额，不笼统合并 |
| 退款说明与导出 | 资料已发说明 | 单独一节说明因已发资料产生的扣费，含资料名称和扣费金额 |
| 退款说明与导出 | 导出说明 | 生成完整退款说明文档，含改动影响标注、学员订单与课程进度对应关系 |

## 3. 核心流程

用户进入退款拆分总览页，通过筛选条件定位目标退款记录。点击某条记录进入学员退款详情页，查看订单、优惠券、退款说明三个独立区域。若课程进度被人工修改过，可展开查看变更历史和优惠回滚影响。在退款说明与导出页，系统按"进度补录""优惠追回""资料已发"分节生成说明，用户确认后导出含完整审计信息的退款说明。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青灰（#1a2332）+ 琥珀金（#d4943a）强调色，体现财务严谨与可信赖感
- 辅助色：浅灰底（#f5f6f8）、白色卡片、绿色/红色状态标注
- 按钮风格：圆角 6px，主按钮实色填充，次按钮描边
- 字体：思源黑体 / Noto Sans SC，标题 18px 加粗，正文 14px 常规，标注 12px
- 布局：左侧导航 + 右侧内容区，卡片式分区，表格行间距充裕
- 图标：线性图标风格（Lucide），统一尺寸 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 退款拆分总览 | 筛选条件面板 | 顶部固定栏，下拉选择 + 日期范围选择器，筛选条件标签化展示 |
| 退款拆分总览 | 拆分汇总图表 | 左侧饼图（退款构成）+ 右侧柱状图（月度趋势），动画过渡 |
| 退款拆分总览 | 退款明细列表 | 表格，每行展开后显示订单来源、优惠来源、退款说明来源三个子行 |
| 学员退款详情 | 学员订单区 | 卡片，表格式展示订单字段，左上角标签"订单信息" |
| 学员退款详情 | 优惠券区 | 卡片，列表展示优惠券，追回状态用色块标注 |
| 学员退款详情 | 退款说明区 | 卡片，分条展示退款拆分明细，每条标注来源 |
| 学员退款详情 | 课程进度变更历史 | 时间线组件，每节点显示修改前/后值和影响金额 |
| 学员退款详情 | 优惠回滚影响 | 对比卡片，左右分列展示修改前后金额，差异高亮 |
| 退款说明与导出 | 进度补录说明 | 独立卡片，标题栏标注类型，内容含补录原因和金额 |
| 退款说明与导出 | 优惠追回说明 | 独立卡片，标题栏标注类型，内容含计算依据 |
| 退款说明与导出 | 资料已发说明 | 独立卡片，标题栏标注类型，内容含资料清单 |
| 退款说明与导出 | 导出按钮 | 页面底部固定，支持导出含审计信息的完整文档 |

### 4.3 响应式设计

- 桌面优先，最小宽度 1280px
- 1024px-1280px 区间表格列可折叠
- 移动端暂不支持（内部财务工具）
