# 地铁站厅导流贴图系统 - 产品需求文档

## 1. 产品概述

地铁站厅导流贴图系统是一个面向车间主管和训练员的Web应用，用于管理、测试和导出站厅导流贴图的边界记录。系统支持前端直接操作（拖拽、筛选、标注、撤销、导出），重点测试边界记录而非仅顺利路径，提供坐标翻转检测与普通话解释，确保导出报告清晰易懂。

**核心价值**：
- 提供完整的边界记录测试能力，而非静态演示
- 支持设备清单补录后的画布状态实时更新
- 导出报告包含人工备注原话和坐标翻转的普通话解释
- 训练员仅看导出报告即可理解为何记录被拦截

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 车间主管 | 测试边界记录、导出复盘报告、审核标注结果 |
| 训练员 | 操作画布、标注记录、查看导出报告 |

### 2.2 功能模块

1. **画布操作页面**：拖拽贴图、筛选记录、标注状态、撤销操作、实时预览
2. **记录管理页面**：查看记录列表、状态筛选、批量操作、设备清单补录
3. **导出报告页面**：生成报告、查看坐标翻转解释、下载复盘材料

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 画布操作页面 | 拖拽模块 | 支持贴图元素拖拽定位，实时显示坐标 |
| 画布操作页面 | 筛选模块 | 按状态、类型、时间筛选记录 |
| 画布操作页面 | 标注模块 | 标记记录状态（顺利/待确认/坏数据），添加人工备注 |
| 画布操作页面 | 撤销模块 | 支持多步撤销，状态同步更新 |
| 画布操作页面 | 颜色规则模块 | 不同状态显示不同颜色，实时更新 |
| 记录管理页面 | 记录列表 | 显示所有记录，支持排序和筛选 |
| 记录管理页面 | 设备清单补录 | 补录设备信息后自动更新画布状态 |
| 记录管理页面 | 评分表 | 显示记录评分，支持手动调整 |

## 3. 核心流程

### 3.1 主流程描述

用户进入系统后，首先在画布操作页面上传或加载站厅底图，然后拖拽贴图元素进行定位。系统自动检测坐标翻转等异常情况，并用颜色规则标识不同状态。用户可标注记录、添加人工备注，支持多步撤销。设备清单补录后，画布状态自动同步更新。最后生成导出报告，包含坐标翻转的普通话解释和人工备注原话。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色 (#1E3A5F) 表示专业可靠，橙色 (#FF6B35) 作为强调色标识异常
- **辅助色**：绿色 (#4CAF50) 表示顺利，黄色 (#FFC107) 表示待确认，红色 (#F44336) 表示坏数据
- **按钮风格**：圆角矩形，轻微阴影，hover时有微动画
- **字体**：标题使用思源黑体，正文使用苹方，代码和数据使用等宽字体
- **布局风格**：左侧画布区域，右侧工具面板，顶部导航栏
- **图标风格**：线性图标，2px粗细，与整体风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 画布操作页面 | 拖拽模块 | 可拖拽贴图元素、实时坐标显示、网格辅助线 |
| 画布操作页面 | 筛选模块 | 下拉选择器、日期选择器、状态标签 |
| 画布操作页面 | 标注模块 | 状态选择器、备注输入框、快捷标注按钮 |
| 画布操作页面 | 撤销模块 | 撤销/重做按钮、操作历史列表 |
| 画布操作页面 | 颜色规则模块 | 颜色图例、实时状态指示器 |
| 记录管理页面 | 记录列表 | 表格视图、状态标签、操作按钮 |
| 记录管理页面 | 设备清单补录 | 表单输入、自动完成、保存按钮 |
| 记录管理页面 | 评分表 | 评分矩阵、手动调整控件 |
| 导出报告页面 | 报告生成 | 预览区域、导出按钮、格式选择 |
| 导出报告页面 | 样例展示 | 三栏布局、状态标识、详细说明 |

### 4.3 响应式设计

- **桌面优先**：主要在桌面端使用，最小宽度1280px
- **移动适配**：平板端可查看报告，手机端仅支持基础查看
- **触控优化**：拖拽操作支持触控，按钮尺寸适配触控操作

### 4.4 交互细节

- **拖拽反馈**：拖拽时显示半透明预览，释放时有轻微弹跳动画
- **状态切换**：颜色变化有过渡动画，持续300ms
- **撤销提示**：撤销操作后显示toast提示，3秒后自动消失
- **坐标翻转警告**：检测到坐标翻转时弹出警告框，包含普通话解释
- **导出进度**：导出时显示进度条，完成后自动下载

## 5. 样例数据规范

### 5.1 三类样例

1. **顺利记录**：坐标正常、状态明确、无需人工干预
2. **待确认记录**：坐标翻转或异常、需要人工确认、包含人工备注
3. **坏数据**：明显错误、无法使用、标记为废弃

### 5.2 样例展示要求

- 每类样例至少一条，最多三条
- 样例需包含完整的字段信息
- 待确认记录需保留人工备注原话
- 坏数据需标注错误原因

## 6. 导出报告规范

### 6.1 报告内容

- **基本信息**：导出时间、操作人员、记录总数
- **状态统计**：顺利/待确认/坏数据数量及占比
- **坐标翻转记录**：包含普通话解释，可直接复制
- **人工备注**：保留原话，不做自动修改
- **评分汇总**：颜色规则、评分表、撤销后状态同步情况

### 6.2 报告格式

- 支持PDF和Excel两种格式
- PDF格式适合打印和存档
- Excel格式适合后续数据处理

## 7. 非功能性需求

### 7.1 性能要求

- 画布渲染帧率不低于30fps
- 拖拽响应延迟不超过100ms
- 导出报告生成时间不超过5秒

### 7.2 可用性要求

- 操作历史支持至少50步撤销
- 自动保存间隔不超过1分钟
- 异常情况下数据不丢失

### 7.3 兼容性要求

- 支持Chrome 90+、Edge 90+、Safari 14+
- 不支持IE浏览器
