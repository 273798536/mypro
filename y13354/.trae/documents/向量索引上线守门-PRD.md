## 1. 产品概述

向量索引上线守门工具是MLOps值班团队用于在向量索引模型上线前进行质量把关的透明化小工具。核心解决离线指标与线上口径不一致、验证集污染藏在特征快照后、人工改判无迹可寻等问题。

- 目标用户：MLOps值班人员（小林）、运营主管、模型评审人员
- 核心价值：把守门决策的公式、明细、历史、改判全部摆在明处，便于交接和追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| MLOps值班 | 查看守门报告、执行人工改判、添加备注、导出CSV明细 |
| 运营主管 | 查看总指标、下钻异常样本、追溯历史判断 |
| 评审人员 | 对比不同版本快照、查看验证集污染溯源 |

### 2.2 功能模块

1. **守门总览页**：指标总览、通过/不通过结论、公式说明、边界值配置
2. **样本明细页**：CSV明细表格、异常样本高亮、验证集污染标记溯源
3. **历史追踪页**：版本时间线、人工改判记录、备注历史、旧版本快照截图
4. **演示数据模式**：一键加载含人工改判和验证集污染的演示数据

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 守门总览 | 指标卡片区 | 展示Recall@10、Precision、QPS、Latency等核心指标及其单位、数值、是否达标 |
| 守门总览 | 公式透明区 | 展示每个指标的计算公式（含分子分母展开）、阈值边界、判断逻辑 |
| 守门总览 | 结论区 | 红绿状态展示最终结论，标注是否存在人工改判 |
| 守门总览 | 边界值配置 | 可配置各指标阈值（带默认值），实时预览判定结果 |
| 样本明细 | CSV表格 | 展示全量样本的query、ground_truth、topk预测、score、是否命中、是否污染标记 |
| 样本明细 | 异常样本下钻 | 筛选拉低指标的Top N样本，展示其详细特征快照原始说法 |
| 样本明细 | 验证集污染溯源 | 点击污染标记可跳转查看特征快照中的原始备注和截图 |
| 样本明细 | CSV导出 | 一键导出当前明细为CSV文件，含所有标记和备注字段 |
| 历史追踪 | 版本时间线 | 按时间倒序展示所有快照版本，含提交人、时间、备注 |
| 历史追踪 | 人工改判记录 | 展示所有值班人员的改判操作：改判人、时间、原值、新值、改判理由 |
| 历史追踪 | 备注与附件 | 展示特征快照中补充的备注、旧版本截图缩略图，可点击放大 |
| 演示模式 | 数据切换 | 一键切换真实/演示数据，演示数据包含1条人工改判样本和2条验证集污染样本 |

## 3. 核心流程

用户打开工具 → 加载特征快照数据 → 系统自动计算守门指标并应用公式判定 → 用户查看指标和公式 → 下钻异常样本和验证集污染 → 如需改判则填写理由提交 → 导出CSV明细 → 查看历史版本和改判记录

```mermaid
flowchart LR
    A["打开工具"] --> B["加载特征快照"]
    B --> C["自动计算守门指标"]
    C --> D["展示公式/单位/边界值"]
    D --> E["判定通过/不通过"]
    E --> F["下钻异常样本"]
    F --> G["溯源验证集污染"]
    G --> H["执行人工改判(可选)"]
    H --> I["填写改判理由"]
    I --> J["记录到历史"]
    J --> K["导出CSV明细"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝科技感（#0F172A背景 + #3B82F6主色），配合#10B981通过绿和#EF4444不通过红
- 按钮风格：圆角6px，实心主按钮 + 描边次按钮，hover有阴影和微位移
- 字体：标题用JetBrains Mono等宽字体体现技术感，正文用PingFang SC
- 布局：卡片式栅格布局，左侧主导航，右侧内容区，信息密度适中
- 图标风格：Lucide线性图标，与配色统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 守门总览 | 指标卡片区 | 4列网格卡片，每卡含指标名、数值、单位、达标状态灯、小趋势箭头 |
| 守门总览 | 公式透明区 | 折叠面板，展开后用等宽字体显示数学公式，分子分母分行 |
| 守门总览 | 边界值配置 | 滑块+数字输入框组合，阈值线与当前值在同一条进度条上对比 |
| 样本明细 | CSV表格 | 斑马纹行，固定表头，异常行红底，污染行黄底，支持列排序 |
| 样本明细 | 异常样本下钻 | 抽屉式侧滑面板，展示原始特征快照JSON格式化展示 |
| 历史追踪 | 版本时间线 | 左侧竖线时间轴，右侧卡片含版本信息，当前版本高亮 |
| 历史追踪 | 改判记录 | 表格展示，改判前后值用删除线+新值对比显示 |

### 4.3 响应式

桌面端优先设计（1280px+），平板端自适应两栏，移动端折叠导航为抽屉菜单。

### 4.4 交互细节

- 公式区hover时分子分母分别高亮
- 异常样本行hover显示下钻按钮
- 时间线版本点击时平滑滚动到对应详情
- 改判操作有确认弹窗，强制填写理由（≥10字）
