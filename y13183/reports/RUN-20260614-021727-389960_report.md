## 三、公式与单位

```
修正后流量 Q_corr = Q_raw × K_boundary × K_env × K_drift
误差率 ε = (Q_corr - Q_ref) / Q_ref × 100%
其中:
  K_boundary: 边界修正系数 (低端取 boundary_low_correction, 高端取 boundary_high_correction)
  K_env = 1 + env_temp_correction × (T - 25)/10 + env_humidity_correction × (RH - 60)/100
  K_drift: 漂移修正系数, 根据近7天均值动态估算
```

**符号与单位**:

| 符号 | 单位及含义 |
|------|-----------|
| Q_raw | m3/h (原始读数) |
| Q_ref | m3/h (参考值) |
| Q_corr | m3/h (修正后) |
| T | °C (水温) |
| RH | % (相对湿度) |
| ε | % (相对误差) |
