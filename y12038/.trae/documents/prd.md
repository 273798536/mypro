## 1. 产品概述

期货套保农场是一款面向农产品培训师的期货套期保值教学原型。通过回合制模拟，让学员在"作物地块 + 天气事件 + 现货订单 + 期货持仓"四维联动的场景中，亲历套保计算、对账对齐、合约到期、仓储爆仓、现货违约等真实困境，培养风险判断力和报表解读能力。

- 目标用户：农产品期货培训师、农场管理者、套保岗位学员
- 核心价值：让"合约到期混进正常记录"这类隐蔽风险在可控环境里暴露，复盘时可导出与界面一致的结算报表

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 学员 | 直接进入 | 选择关卡、操作模拟、查看复盘、导出报表 |

### 2.2 功能模块

1. **关卡选择页**：3 个关卡入口 + 关卡说明卡片
2. **模拟主界面**：作物地块面板、天气事件横幅、现货订单簿、期货持仓表、仓储指示器、回合操作区
3. **结算复盘页**：套保计算明细、风险提示汇总、综合损益表、报表导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 关卡选择页 | 关卡卡片 | 展示 3 个关卡（顺利套保 / 合约到期 / 仓储爆仓+现货违约），点击进入对应模拟 |

| 结算复盘页 | 报表导出 | 导出 CSV/JSON 文件，文件中期货合约结论与界面摘要一致 |

## 3. 核心流程

学员选择关卡 → 进入模拟 → 按回合操作（决策+事件响应） → 关卡结束触发结算 → 进入复盘页查看套保计算和风险提示 → 导出报表

    "J" --> "K[查看风险提示汇总]"

    "L" --> "M[导出报表]"

### 3.1 关卡设计

**关卡一：顺利套保**（4 回合）
- 场景：正常天气，价格小幅波动，期货空头对冲现货多头
- 教学点：套保基本原理、基差概念
- 预期：学员顺利完成套保，净损益接近零

**关卡二：合约到期**（5 回合）
- 场景：期货合约到期时现货价格大幅偏离，需决定实物交割或现金结算
- 教学点：合约到期处理、交割vs平仓选择、基差风险
- 关键事件：第 4 回合合约到期提醒，第 5 回合必须处理到期合约

**关卡三：仓储爆仓 + 现货违约**（6 回合）
- 场景：丰收导致仓储接近极限，同时现货买方违约
- 教学点：仓储成本、违约风险、多重压力下的决策
- 关键事件：第 3 回合仓储预警，第 4 回合现货违约通知，第 5 回合仓储爆仓

### 3.2 套保计算规则

- 期货盈亏 = (平仓价 - 开仓价) × 手数 × 合约乘数（空头取反）
- 现货盈亏 = (实际成交价 - 预期价格) × 数量
- 基差 = 现货价格 - 期货价格
- 净套保效果 = 期货盈亏 + 现货盈亏
- 仓储成本 = 库存量 × 单位仓储费 × 回合数
- 违约损失 = 违约订单金额 × 违约比例

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深橄榄绿（#2D3B2D）+ 暖金色（#C8A951）作为强调色，传达农业与金融双重气质
- 辅助色：浅米白（#F5F0E8）背景，暗红（#B84233）用于风险/亏损警示
- 按钮风格：圆角矩形（rounded-lg），主按钮深色填充，危险操作暗红描边
- 字体：Playfair Display 用于标题（体现金融质感），Noto Sans SC 用于正文（中文友好）
- 布局风格：仪表盘式卡片布局，顶部导航 + 主内容区网格
- 图标风格：lucide-react 线性图标，统一 stroke-width

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 关卡选择页 | 关卡卡片 | 3 列卡片，深绿背景金色边框，hover 放大效果，难度星标 |
| 模拟主界面 | 整体布局 | 顶部状态栏（回合/资金）+ 左侧地块+仓储 + 中间期货+现货 + 底部操作区+日志 |
| 模拟主界面 | 作物地块面板 | 卡片式，绿/黄/红色生长阶段指示，产量进度条 |
| 模拟主界面 | 天气事件横幅 | 全宽横幅，图标+文字，暴雨蓝色/干旱橙色/正常绿色 |
| 模拟主界面 | 期货持仓表 | 表格，盈亏列绿涨红跌，到期日高亮闪烁 |
| 模拟主界面 | 现货订单簿 | 表格，违约风险列红色标记，交割日期倒计时 |
| 模拟主界面 | 仓储指示器 | 圆弧进度条，>80% 橙色预警，>95% 红色爆仓 |
| 模拟主界面 | 事件日志 | 深色背景终端风格，新事件淡入动画 |
| 结算复盘页 | 套保计算明细 | 分组卡片，每笔交易一行，期货/现货颜色区分 |
| 结算复盘页 | 风险提示汇总 | 时间线布局，红色/橙色/黄色图标分级 |
| 结算复盘页 | 综合损益表 | 表格式，期末资金大字高亮，正负值颜色区分 |
| 结算复盘页 | 报表导出 | 导出按钮 + 格式选择（CSV/JSON），导出后 toast 提示 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1024px
- 模拟主界面在窄屏下改为上下堆叠布局
- 复盘页表格在窄屏下支持横向滚动
