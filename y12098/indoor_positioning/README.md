# 📍 室内定位信号地图分析工具

物联网工程专用 - 楼层串跳检测、信标重号、轨迹漂移分析

---

## 🎯 核心功能

| 功能 | 描述 | 关键特性 |
|------|------|----------|
| **数据清洗** | 处理空行、备注、缺列、无效值 | 坏行单独导出，不混入正常数据 |
| **楼层串跳检测** | 识别定位点突然跳至其他楼层 | 支持单点/多点串跳，红色虚线标注跳跃路径 |
| **信标重号检测** | 同一时间戳同一信标出现多次 | 计算重号点间距，便于工程师复核 |
| **轨迹漂移检测** | 移动速度过快或突然转向 | 速度阈值5m/s，转角阈值>143° |
| **3D可视化** | 楼层+轨迹立体展示 | 文字标注+特殊符号，不依赖颜色区分 |
| **轨迹回放** | 逐帧动画回放定位过程 | 时间轴控制，当前位置高亮 |
| **分析报告** | 截图友好的HTML报告 | 统计卡片+异常详情表+分层平面图 |

## 🚀 快速开始

```bash

```

## 📋 输入数据格式

CSV文件需要包含以下列（列名不区分大小写）：

| 列名 | 类型 | 说明 |
|------|------|------|
| `timestamp` | 数值 | 时间戳（秒） |
| `x` | 数值 | X坐标（米） |
| `y` | 数值 | Y坐标（米） |
| `floor` | 整数 | 楼层号（1, 2, 3...） |
| `beacon_id` | 字符串 | 信标ID |

**支持的原始数据问题：**
- ✅ 空行（自动过滤）
- ✅ 备注行（`#`开头，自动过滤）
- ✅ 缺列行（列数不足，单独导出）
- ✅ 无效值（数值解析失败，单独导出）

## 🔧 检测算法参数

可以根据实际场景调整以下参数：

### 楼层串跳检测
- 单点串跳：中间层与前后都不同，且时间跨度 < 30秒
- 多点串跳：连续2-3个点偏离主楼层，且总时长 < 60秒

### 轨迹漂移检测
- 高速漂移：同楼层内移动速度 > 5.0 m/s
- 急转漂移：转角 > 143° 且跳距 > 3.0 米

### 信标重号检测
- 同一 `timestamp` + `beacon_id` 出现次数 > 1

## ❓ 常见问题

**Q: 楼层串跳没有检测出来？**
- 检查串跳的时间跨度是否超过了阈值（单点<30s，多点<60s）
- 确认前后点是否在同一楼层

**Q: 正常上下楼被误判为串跳？**
- 正常上下楼是连续的楼层变化（1→2→3），不会被判定为串跳
- 串跳的定义是：A→B→A 的突变模式

**Q: 如何调整检测灵敏度？**
- 修改 `src/anomaly_detector.py` 中的阈值参数
- 楼层串跳：调整 `time_span < 30` 和 `duration < 60`
- 轨迹漂移：调整 `speed > 5.0` 和 `angle > 2.5`（弧度）
