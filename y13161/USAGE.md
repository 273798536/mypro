# 海浪浮标阈值预警系统 - 使用说明

## 1. 启动

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 访问地址
启动后访问终端显示的地址，例如 `http://localhost:5173/` 或 `http://localhost:5174/`（如端口被占用会自动切换）。

### 启动后
- 首次启动会弹出欢迎引导
- 点击「加载样例数据」即可查看完整功能演示
- 或点击「导入传感器日志」上传自己的日志文件
- 支持 CSV、JSON、TXT 三种格式

---

## 2. 重跑

### 什么时候需要重跑
- 修改参数配置后
- 确认或忽略异常后
- 想对比不同参数的分析结果

### 如何重跑
1. 点击左侧边栏的「重跑分析」按钮
2. 系统会使用当前参数重新分析已加载的数据
3. 每次重跑自动保存为一条新的历史记录
4. 可在历史时间线中对比不同重跑结果

### 参数版本
每次重跑都会记录当时的参数配置：
- 波高阈值（默认 0-15m）
- 波速阈值（默认 0-30m/s）
- 水温阈值（默认 -2-35°C）
- 方向检测窗口大小（默认 20 条）

---

## 3. 查看历史时间线

### 历史记录在哪
左侧边栏「历史分析记录」区域，按时间倒序展示

### 操作说明
- **点击不同记录**：切换查看该次分析结果
- **再次点击当前记录**：查看该次分析详情
- **最多保存 50 条**：超过自动清理最旧记录

### 数据存储
- 所有数据保存在浏览器本地存储（LocalStorage）
- 清除浏览器数据会丢失历史记录
- 如需长期保存，请导出原始日志文件

---

## 快速体验路径
1. `npm install` → `npm run dev`
2. 浏览器访问显示的地址（如 http://localhost:5173/）
3. 点击「加载样例数据」
4. 在时间线图表上点击异常点
5. 右侧复核面板查看完整追溯信息
6. 点击「重跑分析」生成新记录
7. 在左侧历史时间线切换对比
