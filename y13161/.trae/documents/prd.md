## 1. 产品概述

海浪浮标阈值预警系统，用于处理海洋传感器日志数据，解决单位混写导致数量级错误的问题，提供可追溯的异常预警和复核功能。

- **核心问题**：传感器日志中单位混写（如 m 与 km、m/s 与 km/h）导致数量级偏差，方向符号写反（如 N/S 写反），需保留原始数据痕迹并提供可复核的预警。
- **目标用户**：海洋数据分析师、运维人员、复核人员。
- **产品价值**：确保数据质量，提供可追溯的异常检测，支持高效复核流程。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 分析师 | 无需注册，本地应用 | 数据导入、异常检测、查看结果、重跑分析 |
| 复核人员 | 无需注册，本地应用 | 查看异常详情、追溯原始日志、查看计算口径、确认/标记异常 |

### 2.2 功能模块

1. **数据导入与解析**：传感器日志上传、原始数据展示、日志格式识别
2. **单位混写检测与标准化**：自动检测单位不一致、单位换算标准化、保留原始数据痕迹
3. **异常预警**：阈值检测、方向符号反转检测、待确认异常标记
4. **复核面板**：参数版本展示、异常点详情、计算口径说明、原始数据追溯
5. **历史管理**：历史分析记录、时间线查看、重跑功能、样例数据

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 主页面 | 数据导入区 | 支持拖放或选择传感器日志文件，显示导入进度 |
| 主页面 | 时间线图表 | 可视化展示传感器数据序列，标记异常点，支持缩放和点击交互 |
| 主页面 | 异常列表 | 列出所有检测到的异常，包含类型、严重程度、时间戳 |
| 复核面板 | 参数版本 | 显示当前分析使用的参数版本、单位换算规则、阈值配置 |
| 复核面板 | 异常详情 | 点击异常点展示：原始日志记录、标准化后的值、计算口径、影响范围 |
| 复核面板 | 待确认区域 | 方向符号反转等可疑异常先标记为"待确认"，展示可能原因和影响范围 |
| 侧边栏 | 历史时间线 | 按时间展示历史分析记录，支持点击查看详情 |
| 侧边栏 | 操作区 | 重跑当前分析、加载样例数据、查看说明文档 |

## 3. 核心流程

```mermaid
flowchart LR
    A["导入传感器日志"] --> B["解析原始数据"]
    B --> C["单位混写检测"]
    C --> D["单位标准化换算"]
    D --> E["方向符号检测"]
    E --> F{符号写反?}
    F -->|是| G["标记为待确认<br>计算影响范围"]
    F -->|否| H["阈值预警检测"]
    G --> H
    H --> I["生成异常列表"]
    I --> J["时间线可视化"]
    J --> K["点击异常点"]
    K --> L["复核面板展示<br>参数版本+异常+解释+原始数据"]
    L --> M["确认异常/重跑分析"]
```

用户操作流程：
1. 导入传感器日志文件或加载样例数据
2. 系统自动进行单位检测、标准化换算、方向检测、阈值检测
3. 用户在时间线图表上查看数据和异常标记
4. 点击异常点，复核面板显示完整上下文（参数版本、原始日志、计算口径、影响范围）
5. 方向符号写反的异常先标记为"待确认"，提示可能原因和影响范围
6. 用户可重跑分析（使用相同或调整后的参数）
7. 历史分析记录保存在时间线中，可随时回溯查看

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0F2B4A) 作为主色，配合浅蓝 (#1E4A7E)、警告橙 (#FF7A45)、确认绿 (#22C55E)
- **辅助色**：数据曲线用青色 (#06B6D4)，异常标记用红色 (#EF4444)，待确认用黄色 (#EAB308)
- **字体**：标题使用 "JetBrains Mono" 等宽字体，正文使用 "PingFang SC" 中文无衬线
- **布局**：三栏布局 - 左侧历史/操作栏、中间时间线图表、右侧复核面板
- **按钮风格**：扁平方正、细边框、悬停时轻微上浮和阴影变化
- **图标**：使用 lucide-react 线性图标，保持一致的线条粗细

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主页面 | 数据导入区 | 拖放区域边框动画、文件图标、导入进度条 |
| 主页面 | 时间线图表 | SVG绘制的曲线图、可点击的异常点标记、X轴时间刻度、Y轴数值刻度 |
| 主页面 | 异常列表 | 卡片式列表、异常类型标签、严重程度色条 |
| 复核面板 | 参数版本 | 版本号标签、配置项列表、修改时间戳 |
| 复核面板 | 异常详情 | 原始日志代码块、标准化结果高亮、计算口径公式展示 |
| 复核面板 | 待确认区域 | 黄色警告边框、可能原因列表、影响范围估算 |
| 侧边栏 | 历史时间线 | 垂直时间轴、分析记录节点、状态指示点 |
| 侧边栏 | 操作区 | 三个主要按钮：加载样例、重跑分析、查看说明 |

### 4.3 响应性

- 采用桌面优先设计，主视图最小宽度 1280px
- 在小屏幕下自动调整为上下布局：顶部操作区、中部图表、底部详情面板
- 触摸设备优化：增大点击区域，支持手势缩放时间线

### 4.4 数据可视化

- **时间线图表**：使用 SVG + D3.js 实现交互式曲线图
- **异常点**：使用圆形标记，不同异常类型使用不同颜色和大小
- **影响范围**：使用半透明区域高亮显示受影响的数据段
- **原始数据追溯**：点击异常点时，高亮显示对应原始日志记录
