# 组合计数边界校验

组合计数边界校验工具包——把历史答案、边界样本、晚到附件、重复检测、复核摘要打包成一套材料。

## 快速开始

**第一步：运行校验脚本**

```bash
python3 boundary_check.py
```

脚本会读取 `data/` 下的批次数据，执行校验、检测重复、关联晚到附件，然后生成复核页面。

**第二步：查看复核摘要页面**

打开生成的页面文件：

```
output/review_summary.html
```

用浏览器直接打开即可，页面上按已处理、待补材料、人工改判分类汇总。

## 页面上有什么

复核摘要页 `output/review_summary.html` 包含以下内容，同一页内可顺序查看：

| 区块 | 内容 | 说明 |
|------|------|------|
| 顶部汇总卡片 | 已处理 / 待补材料 / 人工改判 / 边界样本数量 | 一眼看整体状态 |
| 一、异常点速览 | 结果不符、参数缺失等异常记录 | 需重点关注的问题 |
| 二、重复样本检测 | 按(n,k,类型,结果)分组，标注影响范围和来源行 | 以前靠人眼扫，现在自动留痕 |
| 三、晚到附件 | 公式不明确 / 单位不统一 / 阈值超界三类问题 | 算不出的不消失，卡在哪一步写清楚 |
| 四、完整校验明细 | 全量记录，含期望值、边界标签、问题、备注、状态 | 逐条核对 |
| 五、历史答案参考 | 历史校验记录 | 边界样本太少时对照参考 |
| 六、边界样本库 | 已知边界情况及来源 | 积累下来，不用全靠记 |

## 状态分类说明

- **已处理**：正常计算并校验通过的记录（含已处理·异常——算出来但结果不对）
- **待补材料**：晚到附件带来的问题，公式/单位/阈值没确认，算不了
- **人工改判**：带约束条件的组合/排列，公式不通用，需要人来判

## 参数版本

当前参数版本：`v2.3.1`

- 大值阈值：`1e15`（超过则标记需确认大数处理）
- 重复判定：n、k、计算类型、提交结果四者均相同视为重复
- 边界识别：零值、空选、全选、越界、负数等自动打标签

如需调整参数，修改 `boundary_check.py` 顶部的 `PARAM_VERSION` 和 `THRESHOLD_LARGE`。

## 数据格式说明

所有数据用 CSV 格式，方便用 Excel 打开和编辑。

**current_batch.csv（当前批次）** 字段：
- 记录ID、场景描述、n、k、计算类型、提交结果、来源行号、数据来源

**late_attachments.csv（晚到附件）** 问题类型取值：
- `公式不明确` — 公式/条件描述不清
- `单位不统一` — 单位口径不一致
- `阈值超界` — 结果超出系统处理范围
