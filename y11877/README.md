# 几何光路批改器

面向物理助教的批量光学作业批改工具。自动计算入射光线与镜面线段的交点、反射角，判定交点是否在线段边界内，将错误、冲突、待确认条目分类标记并生成可追溯的批改报告。

## 快速开始

### 依赖安装

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后浏览器访问 `http://localhost:5173/`

### 构建生产版本

```bash
npm run build
```

## 使用流程

1. **数据导入**（`/import`）：在文本框中粘贴镜面线段和入射光线数据，或点击"一键加载样例"
2. **批改执行**（`/grading`）：点击"开始批改"，查看分类结果（通过/错误/待确认），右侧面板显示光路可视化
3. **报告明细**（`/report`）：查看报告总览与冲突类型分布，展开每条记录查看计算过程，导出 JSON/CSV 报告

## 输入格式

### 镜面线段

每行一条，支持 `#` 或 `//` 注释：

```
startX, startY, endX, endY[, normalAngle]
```

示例：

```
2, 0, 2, 4, 180
0, 5, 5, 5, 90
6, 1, 9, 4
```

也支持 JSON 数组格式：

```json
[
  {"startX": 2, "startY": 0, "endX": 2, "endY": 4, "normalAngle": 180}
]
```

### 入射光线

每行一条：

```
originX, originY, directionAngle[, deg|rad]
```

示例：

```
0, 2, 0, deg
1, 1, 45, deg
1, 7, 200, rad
```

## 内置样例数据位置

样例数据定义在 `src/utils/sampleData.ts`，包含：

- 5 条镜面线段（M1–M5）
- 10 条入射光线（R1–R10），含正常、平行、角度单位错误等场景

在数据导入页面点击"一键加载样例"按钮即可填充。

## 批改判定规则

| 判定 | 条件 |
|------|------|
| ✅ 通过 | 交点在线段上，反射角等于入射角，无角度单位冲突 |
| ❌ 错误 | 角度单位冲突（如 200rad 疑似应为 deg） |
| ⏳ 待确认 | 平行无交、交点在延长线上、角度单位疑似错误 |

### 冲突来源标签

- **交点计算冲突**：计算结果与预期不符
- **反射角偏差**：反射角偏差超过 1° 阈值
- **边界越出**：交点不在镜面线段上
- **角度单位冲突**：角度值与单位标记不匹配
- **平行无交**：射线与镜面线段平行
- **延长线交点**：交点在镜面延长线上

### 待确认后续动作

- 平行无交 → 请确认平行是否为预期
- 延长线交点 → 请确认延长线交点是否有效
- 角度单位冲突 → 请确认角度单位是否正确
