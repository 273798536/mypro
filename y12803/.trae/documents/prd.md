## 1. 产品概述

植物表型生长曲线管理工具，面向实验室技师和导师，解决培养记录与样本清单对不上、标注边界不清混入正常结果、重复导入导致同一事件多份结论等痛点。提供本地数据库驱动的完整流程，支持从空目录一键跑通，首次打开即含示例数据。

- 核心目标：让培养记录、试剂批号、生长曲线、最终结论之间可双向追溯，杜绝重复数据污染结论
- 目标用户：实验室技师（日常录入与质控）、导师（查看分组统计与最终结论）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 实验室技师 | 日常录入培养记录、导入数据、质控检查 | 全部读写权限 |
| 导师 | 查看分组统计、生长曲线最终结论 | 只读权限，重点关注最后一页摘要 |

### 2.2 功能模块

1. **分组统计**：日常入口，按实验组汇总生长曲线，导师可直接跳到最后一页看结论
2. **生长曲线详情**：单组/单株曲线可视化，含异常标注与边界标记，末页汇总结论
3. **培养记录**：录入与查询培养记录，试剂批号→结论可点击追溯，补录自动关联
4. **质控与导入**：样本质控面板（月底/课前复查）、数据导入（含重复导入检测与冲突处理）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分组统计 | 组列表卡片 | 按实验分组展示，每组显示株数、最新测量日期、结论状态 |
| 分组统计 | 快速筛选 | 按日期范围、实验批次、异常标记筛选 |
| 生长曲线详情 | 曲线图表 | 多株叠加或单株展示生长曲线，支持翻页，末页为结论汇总 |
| 生长曲线详情 | 异常标注 | 标注边界清晰区分正常/异常/待定，颜色编码不可混淆 |
| 生长曲线详情 | 追溯链接 | 点击数据点可跳转至对应培养记录与试剂批号 |
| 培养记录 | 记录列表 | 表格展示所有培养记录，支持按批号/日期/样本筛选 |
| 培养记录 | 试剂批号追溯 | 点击批号可查看该批次所有关联样本与最终结论 |

| 质控与导入 | 示例数据 | 首次打开自动加载示例数据，技师无需手动造表 |

## 3. 核心流程

### 3.1 日常使用流程

技师打开工具 → 进入分组统计（日常入口） → 选择实验组查看生长曲线 → 需要时点击追溯至培养记录 → 导师直接翻到末页看结论

### 3.2 数据导入流程

技师准备数据文件 → 进入质控与导入页 → 上传文件 → 系统检测重复 → 冲突时展示详情供技师决策 → 导入完成 → 更新分组统计

### 3.3 月底质控流程

月底/课前 → 打开质控面板 → 查看异常率和标注完整性 → 发现问题追溯至培养记录 → 补录或修正

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深绿（#2D6A4F）搭配浅灰底色（#F8F9FA），契合植物科研主题
- 辅助色：琥珀色（#E09F3E）用于异常标注，石板蓝（#577590）用于信息提示
- 按钮：圆角矩形，轻微阴影，hover 时加深
- 字体：标题用 Source Serif 4（学术感），正文用 DM Sans（清晰易读）
- 布局：左侧固定导航栏 + 右侧内容区，卡片式信息组织
- 图标风格：线条图标（Lucide），统一 18px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 分组统计 | 组列表卡片 | 卡片网格布局，每卡含组名、株数、日期、状态标签（正常/异常/待定），悬停展开摘要 |
| 分组统计 | 快速筛选 | 顶部筛选栏，下拉选择 + 日期范围选择器，实时过滤 |
| 生长曲线详情 | 曲线图表 | 大面积折线图区域，底部翻页控件，末页切换为结论面板 |
| 生长曲线详情 | 异常标注 | 数据点旁标签，绿色（正常）/ 琥珀色（异常）/ 蓝色（待定），点击可追溯 |
| 培养记录 | 记录列表 | 表格布局，斑马纹行，批号列可点击（蓝色链接样式），补录行有左侧色条 |
| 培养记录 | 追溯面板 | 右侧滑出面板，展示批号关联的所有样本与结论链 |
| 质控与导入 | 质控面板 | 顶部指标卡片（异常率/缺失率/完整性），下方月度趋势图 |
| 质控与导入 | 导入区域 | 拖拽上传区，冲突弹窗显示重复数据对比，三个操作按钮 |

### 4.3 响应式设计

桌面优先设计，导航栏在窄屏下折叠为汉堡菜单，表格在窄屏下切换为卡片列表。

### 4.4 首次打开体验

首次启动时自动填充示例数据（3个实验组、每组5-8株、含2条异常记录、1条补录记录、1组重复导入冲突），技师打开即可看到完整的分组统计与曲线，快速理解工具功能。
