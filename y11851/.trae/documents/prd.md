## 1. 产品概述

地下管线冲突沙盘是一款面向市政工程师的 Web3D 冲突分析工具，解决道路开挖前燃气、电力、排水图纸版本不一、标高交错、旧图未作废等导致的"挖到未知管线"风险。通过三维可视化管线空间关系、自动冲突检测与可追溯的协调记录，让工程师快速定位冲突、切换参数对比、保存视角并导出一致结论报告。

- 目标用户：市政道路建设/维护工程师、管线权属单位协调人员
- 核心价值：将多版本图纸的空间冲突从"表格+脑补"升级为"3D可查、可切、可定位"，减少现场开挖事故

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 工程师 | 默认角色 | 查看3D场景、切换图层参数、保存视角、导出报告 |
| 协调员 | 管线权属方 | 新增/编辑协调记录 |

### 2.2 功能模块

1. **沙盘主页**：3D管线场景、剖切面板、冲突列表、图层切换、视角保存
2. **协调记录页**：冲突关联的协调记录列表与详情

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 沙盘主页 | 3D管线场景 | 展示燃气/电力/排水管线三维模型，井盖点标记，开挖范围半透明体，支持旋转/缩放/平移 |
| 沙盘主页 | 图层控制面板 | 按管线类型、图纸版本切换显隐，调整透明度 |
| 沙盘主页 | 冲突检测与高亮 | 自动检测标高冲突和管线交叉，高亮冲突区域，点击跳转至管线模型/井盖点具体位置 |
| 沙盘主页 | 剖切查看 | 水平/垂直剖面裁切，查看管线空间叠放关系 |
| 沙盘主页 | 视角保存与切换 | 保存当前相机参数为命名视角，快速切换对比 |
| 沙盘主页 | 协调记录面板 | 侧边栏展示冲突关联的协调记录，支持展开详情 |
| 沙盘主页 | 报告导出 | 导出JSON/CSV报告，井盖点相关结论与界面摘要一致 |
| 协调记录页 | 记录列表 | 全部协调记录，按管线/井盖/冲突筛选 |
| 协调记录页 | 记录详情 | 协调内容、关联管线、关联井盖、状态（待协调/已确认/旧图作废） |

## 3. 核心流程

用户打开沙盘 → 加载3D场景与样例数据 → 浏览管线/井盖/开挖范围 → 点击"冲突检测" → 查看冲突列表（标高错、管线交叉、旧图未作废）→ 点击冲突项定位到3D场景具体位置 → 使用剖切深入查看 → 保存视角用于汇报 → 切换图层参数对比不同版本 → 查看协调记录 → 导出报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1a2332）为背景，工业感暗色主题
- 辅助色：管线类型色彩编码（燃气-橙 #e67e22、电力-黄 #f1c40f、排水-蓝 #3498db）
- 冲突色：红色高亮 #e74c3c，旧图未作废-紫色 #9b59b6
- 按钮风格：圆角8px，半透明毛玻璃质感
- 字体：标题用 JetBrains Mono（工程图纸感），正文用 Noto Sans SC
- 布局：左侧图层面板 + 中央3D视口 + 右侧冲突/协调面板

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 沙盘主页 | 3D视口 | Three.js Canvas全屏，OrbitControls旋转，网格地面，坐标轴 |
| 沙盘主页 | 图层控制 | 左侧浮动面板，管线类型复选框，版本下拉选择，透明度滑块 |
| 沙盘主页 | 冲突列表 | 右侧浮动面板，冲突项卡片（类型标签+位置描述+跳转按钮） |
| 沙盘主页 | 剖切面板 | 底部工具栏，水平/垂直剖切切换，剖面高度/位置滑块 |
| 沙盘主页 | 视角保存 | 顶部工具栏，保存/加载视角下拉，缩略图预览 |
| 沙盘主页 | 协调记录 | 右侧面板tab切换，记录卡片列表 |
| 协调记录页 | 记录列表 | 表格布局，筛选栏，状态标签 |

### 4.3 响应式

桌面优先设计，最低支持1366px宽度。3D视口占据主要空间，面板可折叠收起以适配较小屏幕。

### 4.4 3D场景指引

- 环境：深色工业风HDRI，低调环境光
- 灯光：平行光模拟日光，补充点光源在井盖位置
- 相机：透视相机，默认45°俯视，OrbitControls自由旋转
- 管线渲染：TubeGeometry沿路径，按类型着色，冲突段发光
- 井盖点：圆柱体标记+文字标签，悬停显示详情
- 开挖范围：半透明BoxGeometry，可调高度
- 剖切：ClippingPlane实现实时裁切
- 冲突高亮：emissive发光+脉冲动画
- 后处理：可选bloom效果增强冲突发光
