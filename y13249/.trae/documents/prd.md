## 1. 产品概述

播客片头分账对齐——一个轻量级的交接工具，帮助录音师、老师和复核人从排练群截图中提取、批注、对齐片头分账信息，确保屏幕所见与导出文件一致，让任何接手人无需口头询问即可知道材料入口、异常位置和重新导出路径。

- 解决排练群截图里进步信息被淹没、人工批注无法覆盖旧判断、导出与页面数字脱节的问题
- 目标用户：录音师（老许等）、授课老师、分账复核人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 录音师 | 直接访问 | 上传截图、添加批注、触发重扫、导出 |
| 老师 | 直接访问 | 查看进度标注、查看异常、导出 |
| 复核人 | 直接访问 | 查看全部记录、查看人工批注覆盖、重新导出 |

### 2.2 功能模块

1. **工作台页面**：材料投放区、截图列表与状态、筛选器与页面摘要、导出入口
2. **截图详情面板**：单张截图的识别结果、人工批注覆盖、排练/授权备注

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 材料投放区 | 拖拽或点击上传排练群截图，支持批量上传，投放区有明确视觉提示 |
| 工作台 | 截图列表 | 按上传时间排列截图缩略图，显示每条的识别状态（待处理/已识别/异常/已批注），支持点击展开详情 |
| 工作台 | 筛选器 | 按状态、日期、是否有异常、是否有人工批注筛选，筛选口径实时反映在页面摘要中 |
| 工作台 | 页面摘要 | 显示当前筛选口径下统计数字（总数、异常数、已批注数、待处理数），筛选条件文字保留在摘要中 |
| 工作台 | 导出入口 | 一键导出页面摘要（含筛选口径），导出文件中的状态文字与页面显示完全一致 |
| 截图详情 | 识别结果 | 展示系统从截图中提取的分账关键信息（参与人、份额、片头类型） |
| 截图详情 | 人工批注 | 允许用户手动覆盖系统判断，标记为"人工批注覆盖"，覆盖后原判断保留但置灰 |
| 截图详情 | 排练/授权备注 | 可追加备注文字，备注与截图绑定，触发重扫后备注不丢失 |
| 截图详情 | 版本追踪 | 每次批注或重扫生成版本快照，可查看旧版本、人工批注和交付清单的对齐关系 |

## 3. 核心流程

用户上传排练群截图 → 系统初步识别分账信息 → 用户查看识别结果 → 用户添加人工批注覆盖旧判断 → 用户追加排练/授权备注 → 触发重扫 → 系统结合备注重新识别 → 版本快照生成 → 用户筛选并查看页面摘要 → 导出页面摘要（含筛选口径）→ 复核人接手，直接定位材料入口、异常区域和导出路径

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色 (#1a1a2e) + 琥珀色强调 (#f0a500)，营造录音棚工作台氛围
- **辅助色**：薄荷绿 (#4ecca3) 用于"正常/已对齐"状态，珊瑚红 (#e84545) 用于"异常"
- **按钮风格**：微圆角 (4px)，扁平但带细微内阴影，hover 时亮起琥珀光晕
- **字体**：标题用 Noto Serif SC（衬线中文字体，带文化质感），正文用 Noto Sans SC
- **布局**：左侧窄栏放截图列表和筛选器，右侧宽区放详情和操作，顶部固定摘要条
- **图标风格**：线性图标，2px 描边，与录音棚调音台旋钮风格呼应

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 顶部摘要条 | 固定顶栏，左侧显示筛选口径文字标签，右侧显示统计数字卡片（总数/异常/已批注/待处理），数字与筛选联动 |
| 工作台 | 材料投放区 | 虚线边框拖拽区，琥珀色虚线，拖入时边框变为实线并发光，支持点击选择文件 |
| 工作台 | 左侧截图列表 | 缩略图网格，每张带状态角标（色点+文字），异常项边框闪红，支持多选 |
| 工作台 | 左侧筛选器 | 下拉和标签式筛选，已选条件以标签形式显示，与摘要条口径一致 |
| 工作台 | 右侧详情区 | 选中截图后展开，上方识别结果卡片，中部人工批注编辑区，下方备注区和版本时间线 |
| 工作台 | 导出按钮 | 右上角固定按钮，点击后确认导出范围（当前筛选/全部），导出含筛选口径的摘要文件 |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。移动端暂不适配，因排练截图审阅场景以桌面为主。

### 4.4 3D 场景指引

不适用。
