## 1. 产品概述

"利率曲线拼图战"是一款面向投教课堂的交互式风险管理教学工具。玩家通过拖拽收益率曲线段、组合债券卡，在事件叠加的压力下完成组合结算，感受曲线形态变化与持仓风险之间的取舍。
- 解决投教老师"曲线反向、事件叠加时难以讲清风险提示"的痛点
- 目标用户：券商/基金投教讲师、金融专业学员、合规培训参与者

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学员 | 课堂码加入 | 操作拼图、查看反馈、回溯记录 |
| 讲师 | 管理后台创建 | 编辑关卡/样例、发布课堂码、查看全班记录 |

### 2.2 功能模块

1. **拼图战场页**：收益率曲线可视化 + 拖拽交互 + 债券卡组合 + 事件面板
2. **结算复盘页**：组合结算明细 + 规则校验反馈 + 前后差异对比
3. **课堂记录页**：操作溯源链 + 修改重跑对比 + 学员/讲师双视角

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 拼图战场 | 曲线画布 | SVG绘制收益率曲线，支持拖拽控制点改变曲线形态，实时显示久期/凸性指标 |
| 拼图战场 | 债券卡槽 | 可拖入债券卡的组合区域，显示每张卡的久期、到期收益率、信用评级 |
| 拼图战场 | 事件面板 | 叠加宏观事件（加息、衰退、流动性危机），实时影响曲线形态 |
| 拼图战场 | 风险仪表 | 实时显示组合久期缺口、VaR、曲线反向警告 |
| 拼图战场 | 提交结算 | 提交当前组合进入结算引擎校验 |
| 结算复盘 | 规则校验 | 逐条显示曲线拖拽规则和组合结算规则的通过/违规情况，违规项标注具体规则编号 |
| 结算复盘 | 差异对比 | 修改债券卡后重跑，左右对照前后两次结算结果 |
| 课堂记录 | 溯源链 | 从任意结算结果点击回溯至原始曲线形态、债券卡参数、事件配置 |
| 课堂记录 | 时间轴 | 按时间线展示操作序列，每步操作可展开查看详情 |

## 3. 核心流程

玩家进入战场 → 观察初始曲线形态 → 拖拽曲线段调整预期 → 拖入债券卡构建组合 → 事件叠加触发曲线变形 → 实时风险仪表反馈 → 提交结算 → 规则校验引擎评分 → 查看违规规则明细 → 修改债券卡参数 → 重跑结算 → 前后差异对比 → 课堂记录溯源

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨蓝 (#0A1628) 为底，配以琥珀金 (#D4A017) 强调色，传达金融专业感
- **辅助色**：风险红 (#E53935)、安全绿 (#43A047)、中性灰 (#78909C)
- **按钮风格**：圆角 6px，微弱内阴影，hover 时琥珀金描边
- **字体**：标题用 Noto Serif SC，正文用 Noto Sans SC，数据用 JetBrains Mono
- **布局风格**：三栏布局（左：债券卡池 / 中：曲线画布 / 右：事件与风险面板）
- **图标**：使用 Lucide 图标库的金融风格图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 拼图战场 | 曲线画布 | SVG 画布 800×500，网格底纹，控制点为可拖拽圆点，曲线段用渐变描边，hover 显示坐标值 |
| 拼图战场 | 债券卡槽 | 卡片式布局，每张卡显示发行主体/久期/YTM/评级，拖入时琥珀金描边高亮 |
| 拼图战场 | 事件面板 | 时间轴式排列，事件卡用红/黄/绿三色标签区分风险等级，激活时脉冲动画 |
| 拼图战场 | 风险仪表 | 圆环进度条，久期缺口用数字+色带，曲线反向时红色闪烁警告 |
| 结算复盘 | 规则校验 | 列表式，✓/✗ 图标+规则编号+规则描述+具体违规数值，可折叠展开 |
| 结算复盘 | 差异对比 | 左右分栏，差异项高亮，变更数值用红/绿箭头标注方向 |
| 课堂记录 | 溯源链 | 面包屑导航式，每层可点击跳转至对应数据源页面 |
| 课堂记录 | 时间轴 | 竖向时间线，节点可展开查看操作快照 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1280px
- 中屏 (1024-1279px)：事件面板折叠为底部抽屉
- 小屏 (<1024px)：暂不支持，提示使用桌面端

## 5. 样例数据场景

### 5.1 曲线反向场景
- 初始正常曲线 → 加息事件叠加 → 短端急升 → 曲线倒挂
- 玩家需识别反向风险，调整组合久期方向

### 5.2 久期漏算场景
- 债券卡含可赎回条款 → 简单久期计算低估风险 → 有效久期差异显著
- 玩家需检查每张卡的久期类型标签

### 5.3 事件叠加场景
- 加息 + 衰退双重事件 → 曲线熊平 + 信用利差走阔 → 同时冲击利率风险和信用风险
- 玩家需同时管理两个维度的风险敞口

## 6. 规则校验体系

| 规则编号 | 规则类别 | 规则描述 | 违规反馈模板 |
|----------|----------|----------|-------------|
| CR-01 | 曲线拖拽 | 久期缺口不得超过组合净值的 5% | "久期缺口 {actual}% 超出 5% 限制，建议调整 {direction} 端持仓" |
| CR-02 | 曲线拖拽 | 曲线反向时必须降低组合久期 | "曲线已反向，组合久期 {duration} 仍为正，应转为负久期或对冲" |
| CR-03 | 组合结算 | 组合 VaR 不得超过基准的 120% | "组合 VaR {var}% 超出基准 120%，需减少 {asset} 暴露" |
| CR-04 | 组合结算 | 信用评级低于 BBB 不得超组合 20% | "低评级债券占比 {ratio}%，超 20% 上限" |
| CR-05 | 事件叠加 | 双重事件下必须同时检查利率+信用风险 | "仅处理了利率风险，遗漏信用利差走阔影响" |
| CR-06 | 久期计算 | 含权债必须使用有效久期 | "债券 {name} 含赎回条款，使用简单久期 {simple} 低估了 {diff}" |
