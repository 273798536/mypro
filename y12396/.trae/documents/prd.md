## 1. 产品概述

"鼓手练习速度阶梯"是一款面向架子鼓教师的本地 Web 工作台，用于管理学生练习的节奏检测、速度分层和错因分析。解决的核心问题是：当学生记录晚到时，教师难以判断节奏检测和速度分层是否被篡改，以及抢拍、漏拍、BPM 跳级等异常的先后顺序无法追溯。

- 目标用户：架子鼓教师、教学助理
- 核心价值：让三证据源（练习音频、BPM 阶梯、节拍标记）的冲突可留痕、可追溯、可导出，确保练习报告口径一致，减少同事间反复确认

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 架子鼓教师 | 本地登录 | 查看练习列表、进入详情、修正数据、导出报告、查看历史 |
| 教学助理 | 本地登录 | 查看练习列表、进入详情、查看报告、导出报告 |

### 2.2 功能模块

1. **练习列表页**：按学生/日期筛选练习记录，显示练习状态（正常/有冲突/已修正），支持快速搜索
2. **练习详情页**：三证据源并排展示（音频播放器、BPM 阶梯图、节拍标记时间线），冲突留痕区，证据对应关系面板
3. **数据修正页**：对有冲突的记录进行修正，修正操作自动留痕（操作人、时间、原值、新值），修正后触发重新检测
4. **历史追溯页**：按时间线展示单条练习的所有变更记录，含节奏检测、速度分层、错因提示的完整链路
5. **报告导出页**：生成练习报告，含三证据源对应关系、修正记录、口径说明，支持下载和转交

## 3. 核心流程

**主流程**：教师打开工作台 → 浏览练习列表 → 发现冲突记录 → 进入详情查看三证据源 → 在冲突留痕区判断 → 如需修正则进入修正页 → 修正后系统自动留痕 → 导出报告转交同事

**冲突处理流程**：系统检测到三证据源冲突 → 自动标注冲突类型（音频与BPM不一致 / 节拍标记与BPM跳级矛盾等）→ 教师查看冲突详情 → 选择"先留痕"（保留原始数据+标注疑问）或"直接修正" → 修正后自动关联原始数据和修正记录

**抢拍+漏拍+BPM跳级场景**：节拍标记检测到抢拍事件 → 同时发现漏拍事件 → BPM阶梯显示跳级 → 系统按时间戳排序三个事件 → 结果中标注"抢拍(t=12.3s) → 漏拍(t=12.3s) → BPM跳级(t=12.5s, 晚到0.2s)"的先后顺序

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色主题，以深灰/近黑为底，辅以琥珀色（amber）作为强调色——呼应架子鼓的金属质感
- **辅助色**：冲突用红色标注，修正用绿色标注，待确认用黄色标注
- **字体**：标题使用 DM Sans（几何感、现代感），正文使用 Source Sans 3
- **布局**：左侧导航栏 + 右侧内容区，内容区顶部有面包屑导航
- **按钮风格**：圆角矩形，微妙的3D凸起效果，hover时有光泽变化
- **图标风格**：线性图标（lucide-react），与深色主题搭配

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 练习列表页 | 筛选栏 | 下拉选择器、日期范围选择器、状态标签组，深色背景配琥珀色高亮 |
| 练习列表页 | 记录卡片 | 卡片式布局，左侧状态色条，右侧BPM数值，底部时间戳，hover阴影效果 |
| 练习详情页 | 音频播放器 | 深色波形图，琥珀色播放进度条，可点击跳转的节拍标记点 |
| 练习详情页 | BPM阶梯图 | 阶梯折线图，跳级点用红色圆点标注，hover显示具体数值和时间 |
| 练习详情页 | 节拍标记时间线 | 水平时间轴，抢拍标红色三角、漏拍标黄色方块，时间戳在下方 |
| 练习详情页 | 冲突留痕区 | 红色边框卡片，列出冲突项，"留痕"和"修正"两个操作按钮 |
| 练习详情页 | 证据对应关系面板 | 三列布局（音频 | BPM | 报告），行间用连线表示映射关系 |
| 数据修正页 | 修正表单 | 表单布局，原值灰色显示，新值琥珀色输入框，变更原因文本域 |
| 数据修正页 | 修正留痕 | 时间线布局，每条修正记录显示操作人头像、时间、变更对比 |
| 历史追溯页 | 变更时间线 | 垂直时间线，节点用不同颜色区分事件类型，hover展开详情 |

| 报告导出页 | 报告预览 | A4纸样式预览，深色底配浅色内容区，口径说明用引用块突出 |
| 报告导出页 | 导出下载 | 按钮：导出PDF（琥珀色主按钮）、导出JSON（灰色次按钮） |

### 4.3 响应式设计

- 桌面优先设计，最小支持1280px宽度
- 平板适配：详情页三证据源从并排改为上下堆叠
- 移动端暂不支持（教师工作台场景以桌面为主）
