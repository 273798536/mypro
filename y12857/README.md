# 船舶 AIS 漂移清洗系统 使用说明

## 一、启动服务

### 方式一：Web 界面
```bash
npm start
```
启动后浏览器访问 `http://localhost:3000`

### 方式二：命令行交互
```bash
npm run cli
```

### 方式三：命令行直连（脚本调用）
```bash
# 查看批次列表
node src/cli/index.js list

# 新建导入批次
node src/cli/index.js import "批次名称" --ais ./ais.csv --water ./water.csv

# 执行清洗
node src/cli/index.js clean <批次ID>

# 导出报告
node src/cli/index.js export <批次ID> csv
node src/cli/index.js export <批次ID> json
```

## 二、导入数据

### 准备文件

**1. AIS 轨迹 CSV**
必填列：`mmsi`, `timestamp`, `lon`, `lat`
可选列：`ship_name`, `speed`, `course`

示例：
```csv
mmsi,ship_name,timestamp,lon,lat,speed,course
413123456,东海渔政001,2026-06-12 08:00:00,121.5000,30.0000,8.5,120.0
```

**2. 水质记录 CSV**
必填列：`station_id`, `timestamp`
可选列：`lon`, `lat`, `ph`, `dissolved_oxygen`, `turbidity`

> 水质数据缺失不会导致整批失败，系统会先算能算的，再把缺口列出来让你补。

示例：
```csv
station_id,timestamp,lon,lat,ph,dissolved_oxygen,turbidity
ST001,2026-06-12 08:00:00,121.5500,30.0300,7.8,6.5,15.2
ST003,2026-06-12 09:00:00,121.2000,31.0000,,,
```

### Web 端导入
1. 点右上角 "新建导入"
2. 填批次名称
3. 选 AIS 文件、水质文件（至少选一个）
4. 点 "导入"

### CLI 端导入
进入 CLI 后选 "1) 新建导入批次"，按提示输入路径。

## 三、查看异常与复核

### 状态流转
```
已导入 → 清洗中 → 已清洗 → 复核中 → 已复核 → 已导出
```

### 执行清洗
导入数据后，点 "开始清洗" 或 CLI 选 "4) 执行漂移清洗"。

清洗会做三件事：
1. **轨迹漂移检测**：船速与位移不符、瞬时航速异常、位置跳变
2. **风险分层**：高/中/低三级，结合水质数据（如果有）
3. **生成风险通报**：每条异常对应一份风险通报单

### 查看异常
**Web 端**：选批次 → "异常列表" 标签页
- 可按风险等级筛选
- 点异常条目看详情，详情里能看到风险通报和复核意见

**CLI 端**：进入批次详情 → 选 "1) 查看异常列表" → 选 "7) 异常详情追溯"

> 顺着一条异常往回查：异常详情 → 风险通报 → 复核意见，整条线是通的。

### 添加复核意见
有两种入口：
1. 异常详情页点 "添加复核意见"（针对单条异常）
2. 批次详情页 "批量复核" 按钮（全批次通用意见）

处理动作可选：确认异常、误报排除、待补材料、通报船方

> 不用重新导入就能修正判断，复核意见直接挂在异常记录上。

## 四、查看水质缺口

清洗后如果水质数据有缺失，在 "水质缺口" 标签页能看到所有缺数据的站点和时间，照着补就行。

水质缺失不影响清洗出结果，风险分层时会标注"水质数据缺失，仅基于轨迹分析"。

## 五、导出结果

支持两种格式：

### CSV 报告
包含：批次统计、异常明细、风险通报、水质缺口清单

### JSON 报告
结构化数据，包含全部详情（批次、异常、风险通报、复核意见、水质缺口）

Web 端点 "导出CSV" 或 "导出JSON" 按钮即可下载。

CLI 端进入批次详情后选 "6) 导出报告"。

## 六、数据持久化

所有数据存在 `data/ais_drift.db`（SQLite），重启服务后历史批次、异常、复核记录都还在。

如果要重置数据，删掉 `data/` 目录重新启动即可。

## 七、示例数据

`sample_data/` 目录下有示例文件：
- `ais_sample.csv` — AIS 轨迹示例（含正常船、锚泊漂移船、高速异常船、跳点船）
- `water_quality_sample.csv` — 水质示例（含完整数据和缺失数据）

可以用来快速试跑。
