## 1. 产品概述

剧院吊杆阵列碰撞预审系统是一套面向剧院灯光/舞美技术团队的 Web3D 审查工具，用于在吊杆排布方案落地前自动发现空间碰撞风险、管理评审批注、生成可追溯的预审报告。
- 核心问题：教学老师林姐等审查者在批注中反复翻出旧说法变成异常对象、补材料时无声覆盖早先判断、重叠对象提示无法落地操作
- 目标用户：剧院舞美/灯光技术审查人员（如教学老师林姐）、预审负责人（月底封账自跑一遍）、审批专家（分批提交批注）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 审查员 | 工号登录 | 点选对象、切时间轴、筛选异常、截图标注、提交批注 |
| 审批专家 | 工号登录 | 分批提交评审批注、补充材料、查看批注版本链 |
| 负责人 | 工号登录 | 查看预审报告、导出截图说明、月底自主跑预审流程 |

### 2.2 功能模块

1. **3D 场景预审页**：Web3D 吊杆阵列可视化、碰撞检测高亮、对象点选联动
2. **时间轴与筛选面板**：吊杆运动时间轴切换、按碰撞状态/对象类型筛选
3. **批注与材料管理页**：评审批注版本链、补充材料不可覆盖机制、重叠对象行动提示
4. **导出与报告页**：单对象导出（空间位置+备注+截图对齐）、负责人截图说明（已处理/待补材料/人工改判三色区分）

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D 场景预审页 | 吊杆阵列 3D 视图 | Three.js 渲染吊杆阵列模型，碰撞对象红色高亮，点击选中联动右侧面板 |
| 3D 场景预审页 | 碰撞检测结果面板 | 自动碰撞检测，列出所有碰撞对，点击定位到 3D 对象 |
| 3D 场景预审页 | 对象属性面板 | 显示选中对象的空间坐标、杆号、挂载灯具清单、碰撞状态 |
| 时间轴与筛选面板 | 运动时间轴 | 可拖拽时间轴，显示吊杆在不同帧位的空间位置，碰撞帧标红 |
| 时间轴与筛选面板 | 筛选器 | 按碰撞状态（碰撞/安全/待确认）、对象类型（吊杆/灯具/景片）筛选 |
| 批注与材料管理页 | 批注版本链 | 每条批注带时间戳和批次标记，补材料追加而非覆盖，历史版本可回溯 |
| 批注与材料管理页 | 重叠对象提示 | 当对象重叠影响碰撞结果时，生成行动提示："请将 X 号杆降低 0.5m 或将 Y 号灯移至 Z 号杆" |
| 批注与材料管理页 | 材料提交区 | 审批专家分批提交补充材料，每次提交自动标注批次号和时间 |
| 导出与报告页 | 单对象导出 | 点击异常对象导出 PDF/图片，空间位置、备注、截图说明三者对齐 |
| 导出与报告页 | 负责人截图说明 | 截图标注三色标签：绿色=已处理、橙色=待补材料、红色=人工改判 |
| 导出与报告页 | 封账自检清单 | 负责人月底自主运行的检查清单，材料位置一目了然无需追问 |

## 3. 核心流程

**审查员碰撞预审主流程**：审查员进入 3D 场景 → 系统自动碰撞检测并高亮 → 审查员点选异常对象查看详情 → 切换时间轴查看碰撞帧 → 筛选特定类型碰撞 → 截图标注提交批注 → 导出异常对象报告

**审批专家批注流程**：审批专家查看碰撞结果 → 分批提交评审批注 → 系统记录批次号和时间 → 后续补充材料追加到批注链 → 历史批注不可被覆盖

**负责人月底封账流程**：负责人进入报告页 → 查看三色标签截图说明 → 按自检清单逐项确认 → 确认所有材料位置清晰 → 封账完成

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空灰 (#0D1117) + 舞台暖金 (#E8A838) + 碰撞警示红 (#FF4757)
- **辅助色**：已处理绿 (#2ED573)、待补材料橙 (#FFA502)、人工改判红 (#FF6B81)
- **字体**：标题使用 Noto Serif SC（衬线体呼应剧院庄重感），正文使用 Noto Sans SC
- **布局**：左侧 3D 场景主区域（70%），右侧属性/批注联动面板（30%），底部时间轴
- **按钮风格**：圆角微凸（border-radius: 6px, subtle box-shadow），hover 时微浮起
- **图标风格**：线性图标（Lucide Icons），与文字等高对齐

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 3D 场景预审页 | 吊杆阵列 3D 视图 | 深色背景，吊杆金属质感，碰撞对象红色光晕脉冲动画，选中对象金色描边 |
| 3D 场景预审页 | 碰撞检测结果面板 | 右侧面板，碰撞对列表，每条含杆号、碰撞距离、状态徽章 |
| 3D 场景预审页 | 对象属性面板 | 选中时滑入，含坐标 XYZ、杆号、挂载清单、碰撞标记 |
| 时间轴与筛选面板 | 运动时间轴 | 底部横条，帧刻度，碰撞帧红色三角标记，拖拽滑块 |
| 时间轴与筛选面板 | 筛选器 | 顶部工具栏，下拉菜单+复选框组合 |
| 批注与材料管理页 | 批注版本链 | 时间线布局，每条批注卡片含批次号、时间、内容，补充材料用虚线连接 |
| 批注与材料管理页 | 重叠对象提示 | 黄色警示卡片，带行动箭头图标，文字可操作 |
| 导出与报告页 | 单对象导出 | 预览卡片：左图（3D截图）右文（坐标+备注），导出按钮 |
| 导出与报告页 | 负责人截图说明 | 三色标签系统，绿色/橙色/红色标签在截图上叠加 |
| 导出与报告页 | 封账自检清单 | 清单卡片式，每项含状态图标和材料链接 |

### 4.3 响应式

- 桌面优先设计，最小支持 1280px 宽度
- 3D 场景区域可全屏切换
- 侧面板可折叠/展开

### 4.4 3D 场景指引

- **环境/HDRI**：暗色剧院环境，顶部微弱工作灯照明，营造剧场排练氛围
- **灯光**：主光来自舞台顶部工作灯（偏暖白），碰撞对象自带红色点光源强调
- **摄像机**：默认斜 45° 俯视（OrbitControls），可切换正视/侧视/俯视
- **构图与焦点**：吊杆阵列占据画面中央 2/3，碰撞区域放大提示
- **交互与动画**：鼠标悬停对象微亮，点击选中金色描边+信息面板弹出，碰撞对象红色脉冲光晕
- **后处理**：Bloom 效果用于碰撞高亮发光，微弱环境光遮蔽增加深度感
- **资产来源**：吊杆模型程序化生成（CylinderGeometry），灯具用简化 Box 组合
- **性能预算**：30+ 吊杆 + 60+ 灯具流畅运行，目标 60fps
