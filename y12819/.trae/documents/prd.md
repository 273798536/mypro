## 1. 产品概述

动物行为轨迹分析系统——面向实验室技师与质控组，解决培养记录与试剂批号对不上、异常标注模糊、分组统计不联动等痛点。系统提供本地数据库驱动的全流程质控闭环：从培养记录录入、试剂批号校验、分组统计动态更新、异常复核可操作指引，到导出报告自解释，确保验收前不再手工补锅。

- 目标用户：实验室技师（日常录入与复核）、质控组（审核与导出报告）
- 核心价值：培养记录与试剂批号自动校验、异常状态可操作（补材料/改口径）、图表旁附明细解释、导出报告自含拦阻原因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验室技师 | 本地账号 | 录入培养记录、补录采样地点、查看异常复核建议、操作轨迹可视化 |
| 质控组 | 本地账号 | 审核分组统计、导出报告、查看异常明细与边界不清原因 |

### 2.2 功能模块

1. **仪表盘**：全局概览——异常计数（分类非单一红色数字）、近期培养记录状态、分组统计摘要
2. **培养记录管理**：录入/编辑培养记录、试剂批号自动校验、采样地点补录、校验结果即时反馈
3. **分组统计**：按实验组/采样地点/时间段分组、采样地点补录后统计自动更新、异常复核联动
4. **异常复核**：异常分类（批号不匹配、标注边界不清、数据缺失）、每类异常给出明确操作建议（补材料/改口径/重新采样）、复核状态流转
5. **轨迹可视化**：动物行为轨迹2D/3D视图、图表旁附明细解释面板、不依赖颜色传递关键信息
6. **导出报告**：一键导出质控报告、报告内含拦阻原因与操作建议、质控组无需回系统即可理解

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1E293B）+ 琥珀色强调（#F59E0B），营造专业实验室氛围
- 辅助色：翡翠绿（正常状态 #10B981）、珊瑚红（异常状态 #EF4444）、天蓝（信息态 #3B82F6）
- 按钮风格：圆角（8px）、微阴影，主要操作琥珀色填充，次要操作描边
- 字体：标题用 Source Serif 4（衬线，学术感），正文用 DM Sans（清晰易读）
- 布局：左侧固定导航 + 右侧内容区，卡片式模块布局
- 图标：Lucide Icons 线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 仪表盘 | 异常分类卡片 | 卡片网格，每卡顶部图标+数字，底部建议文字，hover微抬升 |
| 仪表盘 | 培养记录状态概览 | 环形图+右侧文字说明列表，非纯颜色区分 |
| 仪表盘 | 分组统计摘要 | 紧凑表格+迷你趋势折线 |
| 培养记录管理 | 记录列表 | 条纹表格，状态列图标+文字，行hover高亮 |
| 培养记录管理 | 录入表单 | 分区表单，校验结果行内提示 |
| 分组统计 | 统计图表区 | 左侧图表+右侧明细解释面板，面板可折叠 |
| 异常复核 | 异常列表 | Tab切换类型，每行展开显示操作建议 |
| 异常复核 | 操作建议卡片 | 琥珀/红/蓝边框卡片，内含步骤列表 |
| 轨迹可视化 | 3D轨迹视图 | 中央3D画布+右侧明细面板+底部时间轴 |
| 导出报告 | 报告预览 | 模拟A4纸面排版，含图例与说明 |

### 4.3 响应式

- 桌面优先设计，1280px+ 最佳体验
- 平板（768-1280px）侧边栏折叠为图标模式
- 手机端暂不作为主要目标，保证内容可滚动查看即可

### 4.4 3D场景指引

- 环境：浅灰实验室环境，柔和环境光
- 灯光：主方向光（模拟实验室顶灯）+ 弱环境光
- 相机：45度俯视，可拖拽旋转缩放
- 交互：鼠标悬停轨迹节点弹出标注，滚轮缩放，拖拽旋转
- 后处理：轻微抗锯齿，无过度特效
