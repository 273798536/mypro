# 黑洞光线弯曲演示 Web3D - 使用说明

## 项目简介

本项目是一个基于WebGL的交互式黑洞光线弯曲3D演示系统，使用广义相对论的施瓦西度规模拟光线在黑洞引力场中的偏折现象。

**技术栈**: React 18 + TypeScript + Three.js + TailwindCSS + Vite

## 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问: http://localhost:5173/

### 4. 构建生产版本
```bash
npm run build
```

## 主要操作流程

### 启动模拟
1. 在左侧控制面板调整参数（详见下方参数说明）
2. 点击"开始模拟"按钮
3. 观察右侧3D视图中的光线轨迹
4. 等待模拟完成（进度条显示）

### 运行控制
- **开始**: 启动光线追踪模拟
- **暂停**: 暂停当前模拟
- **继续**: 恢复暂停的模拟
- **重置**: 清除所有结果，回到初始状态

### 视角控制
- **鼠标拖拽**: 旋转3D视角
- **滚轮**: 缩放视图
- **双击**: 重置视角到默认位置

## 参数说明

### 物理参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 黑洞质量 | 1-100 M☉ | 10 | 黑洞质量，影响引力场强度和事件视界大小 |
| 光线数量 | 10-200 | 50 | 同时追踪的光线路数 |
| 碰撞参数 | 3-30 | 10 | 光线入射的最小距离参数 |
| 光线角度范围 | 10-180° | 60 | 光线入射的角度分布范围 |

### 计算设置

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 积分步数 | 500-5000 | 2000 | 数值积分的精度，越大越精确但越慢 |
| 积分步长 | 0.01-0.5 | 0.05 | 每步积分的距离，小步长更精确 |

### 显示选项

| 选项 | 说明 |
|------|------|
| 显示网格 | 显示参考网格平面 |
| 显示事件视界 | 显示黑洞的事件视界边界（橙色线框） |
| 显示光子球 | 显示光子球边界（青色线框） |

## 异常处理

系统会检测并提示以下异常情况：

### 参数超限警告
- **黄色警告**: 参数接近临界值（如黑洞质量>50M☉）
- **红色警告**: 参数超出安全范围，可能导致不稳定
- 临界参数会阻止模拟启动

### 计算异常
- **光线被吞噬**: 光线进入事件视界，标记为"已吸收"（红色轨迹）
- **光线逃逸**: 光线成功脱离引力场，标记为"已逃逸"（绿色轨迹）
- **轨迹不连续**: 检测到积分步长跳跃，显示警告
- **数值发散**: 计算出现非数值，立即终止并显示错误

### 性能警告
- 帧率低于30FPS时显示黄色警告
- 帧率低于15FPS时显示红色警告
- 建议减少光线数量或积分步数

## 导出功能

- 格式: PNG

- 文件名: `blackhole_YYYYMMDD_HHMMSS.png`
- 水印包含: 黑洞质量、光线数量、积分步数、帧率

- 格式: JSON
- 内容: 完整参数配置、统计数据、光线状态摘要
- 文件名: `params_YYYYMMDD_HHMMSS.json`

## 物理模型说明

本项目使用**施瓦西度规**（Schwarzschild Metric）描述黑洞周围的时空：

```
ds² = -(1-2M/r)dt² + (1-2M/r)⁻¹dr² + r²(dθ² + sin²θ dφ²)
```

其中:
- M = 黑洞质量
- r = 径向距离
- 事件视界位于 r = 2M
- 光子球位于 r = 3M

光线轨迹通过**4阶龙格-库塔法**（RK4）数值积分测地线方程得到。

## 性能建议

- 光线数量建议: 10-100条（超过150条性能下降明显）
- 积分步数建议: 1000-3000步
- 黑洞质量建议: 1-50 M☉（过大质量会导致事件视界过大）
- 帧率目标: 60FPS

## 常见问题

### Q: 模拟开始后界面卡住？
A: 参数设置过高（如光线数量200+积分步数5000）会导致计算量大，请降低参数后重试。

### Q: 看不到光线轨迹？
A: 检查是否开启了"显示事件视界"或"显示光子球"，这些会遮挡部分视线。尝试旋转视角。

### Q: 导出的截图是黑的？
A: 请确保3D场景已渲染完成后再截图，且不要在模拟运行中截图。

### Q: 如何保存参数配置？
A: 在信息面板中点击"保存"图标按钮，参数会自动保存到浏览器本地存储。
