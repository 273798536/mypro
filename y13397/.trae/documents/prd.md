## 1. 产品概述

影子流量异常回放是一套面向 MLOps 团队与项目经理的异常回放追踪工具，解决训练日志参数变化未进报告、材料口径不一致、特征迟到被揉进正常结果等痛点。目标用户为 MLOps 值班人员和项目经理，核心价值是让每一次回放的记录、补录和异常都能溯源、分类、导出，保证接口查询与 Markdown 报告状态一致。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| MLOps 值班 | 默认进入 | 录入回放记录、补录材料、标记异常、导出报告 |
| 项目经理 | 默认进入 | 查询明细、版本对比、预览和导出 Markdown 报告 |

### 2.2 功能模块

1. **回放工作台**：回放记录列表、状态标签、材料溯源标记、快速筛选
2. **版本对比**：前一版与当前版的样本/阈值/人工修正/指标变化分层展示
3. **报告预览与导出**：Markdown 报告实时生成，按已处理/待补材料/人工改判分类

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 回放工作台 | 记录列表 | 展示 3-4 条回放记录，每条含状态标签（顺利记录/补录记录/异常记录）、材料溯源标记（训练日志/后补备注/口头说明，标注是否改过口径） |
| 回放工作台 | 特征迟到标记 | 特征迟到记录单独高亮，与正常结果分离展示 |
| 回放工作台 | 快速筛选 | 按状态（已处理/待补材料/人工改判）筛选记录 |
| 版本对比 | 样本变化 | 前一版与当前版的样本数、分布差异对比 |
| 版本对比 | 阈值变化 | 阈值调整前后对照，标注变更原因 |
| 版本对比 | 人工修正 | 人工改判记录独立展示，含修正前后值与修正人 |
| 版本对比 | 指标变化 | 精确率/召回率/F1 等指标前后对比 |
| 报告预览与导出 | 报告分类 | 按已处理/待补材料/人工改判三大类组织内容 |
| 报告预览与导出 | Markdown 导出 | 一键导出与接口查询状态一致的 Markdown 报告 |

## 3. 核心流程

项目经理查询影子流量异常回放明细的典型流程：

1. 进入回放工作台，查看所有回放记录及状态
2. 筛选特定状态（如待补材料），定位需要关注的记录
3. 点击记录进入版本对比，查看样本/阈值/人工修正/指标各维度变化
4. 确认材料溯源，识别哪些材料后来改过口径
5. 进入报告预览，确认已处理/待补材料/人工改判分类正确
6. 导出 Markdown 报告，状态与接口查询一致

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色 + 琥珀色（amber）强调色，传达运维监控的专业感
- **辅色**：翡翠绿（已处理）、珊瑚橙（待补材料）、玫红（人工改判）
- **按钮风格**：圆角矩形、微阴影、hover 时琥珀色描边
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据使用 JetBrains Mono
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式信息块
- **图标风格**：线性图标，与状态色呼应

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 回放工作台 | 记录列表 | 卡片列表，左上角状态色条，右上角材料溯源标签（含口径变更脉冲动画），特征迟到卡片带橙色边框 |
| 回放工作台 | 快速筛选 | 顶部三个胶囊按钮（已处理/待补材料/人工改判），选中态琥珀色填充 |
| 版本对比 | 样本变化 | 双列对比表格，变化值用箭头和颜色标注（升绿降红） |
| 版本对比 | 阈值变化 | 滑块式对照，旧值左新值右，变更原因 tooltip |
| 版本对比 | 人工修正 | 独立卡片，修正前后值用删除线和新值标注，修正人头像标签 |
| 版本对比 | 指标变化 | 迷你折线图或进度条，前后指标对比 |
| 报告预览与导出 | 报告分类 | 三段式折叠面板，标题带状态色圆点 |
| 报告预览与导出 | Markdown 导出 | 预览区 + 右上角导出按钮，预览区仿 Markdown 渲染样式 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1024px
- 平板适配：导航栏折叠为顶部汉堡菜单
- 移动端暂不作为主要适配目标
