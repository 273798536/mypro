# 信贷评分灰度对比系统

串联样本、版本、人工修正与接口返回，支撑信贷评分模型的灰度评审。

## 核心能力

- **材料串联**：将样本、模型版本、阈值版本、人工修正、接口返回串成完整对比链路
- **重复评测检测**：发现重复评测时先输出待确认原因与影响范围，不急于计算最终结论
- **灰度结果拆解**：报告中拆分为样本变化、阈值变化、人工改判三部分
- **历史追踪**：人工确认前后的变化进入历史，评审复盘可追溯
- **工单备注生成**：评审会前自动生成线上工单备注摘要，说明本次灰度改变了哪些判断

## 快速开始

```bash
pip install -e .
credit-gray-compare --help
```

## 目录结构

```
src/credit_gray_compare/
├── models/          # 数据模型（样本、版本、工单、评测历史等）
├── engine/          # 核心业务引擎（对比、拆解、重复检测、历史追踪）
├── report/          # 报告生成
├── cli.py           # 命令行入口
└── config.py        # 配置
```

## 典型使用流程

1. 算法值班人在评审会前执行 `credit-gray-compare run`
2. 系统自动检测重复评测、输出待确认项
3. 生成拆解报告，明确样本/阈值/人工三部分贡献
4. 输出工单备注摘要，可直接贴入线上工单
