## 1. 产品概述

录音棚时码排期冲突管理系统——帮助音乐老师林姐把合同扫描件中散落在备注里的授权期限、排期冲突等关键信息捋顺，确保导出 CSV 与页面展示完全一致，支持后补备注和曲名别名重复检测，方便向演出/发行同事交接。

- 解决合同授权期限藏在备注、排期信息零散、导出与页面不一致的问题
- 目标用户：音乐版权管理员、演出/发行交接人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 版权管理员 | 本地登录 | 导入合同、管理记录、导出CSV、添加后补备注 |
| 交接同事 | 只读访问 | 查看清单、导出CSV |

### 2.2 功能模块

1. **排期冲突总览页**：冲突列表、状态筛选、曲名搜索、异常统计
2. **合同导入与管理页**：上传合同扫描件、录入/编辑记录、添加后补备注
3. **CSV导出与校验页**：筛选口径导出、页面与文件一致性校验、别名重复检测

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 排期冲突总览 | 冲突卡片列表 | 按状态/时码范围/曲名筛选，每张卡片显示曲名、时码区间、授权期限、状态标签、异常原因（人话） |
| 排期冲突总览 | 异常统计面板 | 显示冲突总数、待处理数、已解决数、异常类型分布 |
| 排期冲突总览 | 筛选栏 | 状态筛选、时码范围筛选、曲名/别名搜索，筛选条件同步到CSV导出 |
| 合同导入与管理 | 合同上传区 | 拖拽上传合同扫描件（PDF/图片），自动关联记录 |
| 合同导入与管理 | 记录编辑表单 | 编辑曲名、别名、时码起止、授权期限起止、备注、后补备注字段 |
| 合同导入与管理 | 后补备注面板 | 对已有记录追加后补备注，记录追加时间和变化说明 |
| CSV导出与校验 | 导出配置面板 | 选择筛选口径、字段列、是否包含筛选条件说明行 |
| CSV导出与校验 | 一致性校验面板 | 对比当前页面显示状态与CSV内容，标记不一致项 |
| CSV导出与校验 | 别名重复检测结果 | 列出别名重复的记录，给出原因说明和人工确认建议 |

## 3. 核心流程

**主流程**：导入合同扫描件 → 录入/解析记录 → 检测排期冲突 → 标记异常原因 → 补充后补备注 → 筛选查看 → 导出CSV交接

**后补备注流程**：选择已有记录 → 点击"追加后补备注" → 填写变化说明 → 系统记录追加时间和内容 → 状态自动更新 → CSV导出包含变化说明

**别名重复检测流程**：导入/编辑时触发检测 → 发现别名重复 → 列出冲突记录 → 给出原因和下一步建议 → 人工确认处理

```mermaid
flowchart TD
    "A[导入合同扫描件]" --> "B[录入/解析记录]"
    "B" --> "C[检测排期冲突]"

    "D" --> "是" --> "E[标记异常原因(人话)]"
    "D" --> "否" --> "F[正常记录]"
    "E" --> "G[补充后补备注]"
    "F" --> "G"
    "G" --> "H[别名重复检测]"
    "H" --> "I{有重复?}"
    "I" --> "是" --> "J[列出原因+下一步建议]"
    "I" --> "否" --> "K[记录正常]"
    "J" --> "L[人工确认]"
    "K" --> "M[筛选查看]"
    "L" --> "M"
    "M" --> "N[导出CSV(含筛选口径)]"
    "N" --> "O[一致性校验]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝(#1a1a2e) + 琥珀黄(#f0a500)点缀，营造录音棚专业感
- 辅助色：暖灰(#2d2d44)用于卡片背景，#e8e8e8用于文字
- 按钮风格：圆角微凸(3D shadow)，主操作用琥珀黄，次操作用透明边框
- 字体：标题用 Noto Serif SC(衬线，体现音乐人文感)，正文用 Noto Sans SC
- 布局：左侧固定导航栏 + 右侧内容区，卡片式布局，表格与卡片切换视图
- 图标：线性图标(Feather Icons风格)，关键状态用琥珀黄圆点标记

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 排期冲突总览 | 冲突卡片列表 | 卡片网格，每卡含状态色带、曲名大字、时码区间、异常原因标签、授权期限进度条 |
| 排期冲突总览 | 异常统计面板 | 顶部横幅，数字大字+描述，琥珀黄标记待处理 |
| 排期冲突总览 | 筛选栏 | 下拉+输入混合，时码范围用双滑块，筛选条件chip展示 |
| 合同导入与管理 | 合同上传区 | 虚线拖拽区，上传后缩略图展示，点击预览 |
| 合同导入与管理 | 记录编辑表单 | 侧滑抽屉式，字段分组，后补备注区用琥珀黄边框高亮 |
| 合同导入与管理 | 后补备注面板 | 时间线样式，每条备注含时间戳+操作人+内容，最新在最上 |
| CSV导出与校验 | 导出配置面板 | 勾选列+筛选口径预览，一键导出按钮 |
| CSV导出与校验 | 一致性校验面板 | 对比表格，绿色对勾/红色叉号标记一致/不一致 |
| CSV导出与校验 | 别名重复检测结果 | 分组卡片，重复记录归组，原因+建议用琥珀黄文字 |

### 4.3 响应式

- 桌面优先设计，1920px为基准宽度
- 平板(768px-1024px)：卡片从3列变2列，导航栏折叠为图标
- 手机(<768px)：单列卡片，底部标签导航，表格改为列表视图

不适用
