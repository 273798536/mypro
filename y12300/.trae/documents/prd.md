## 1. 产品概述

博物馆客流热区模型是一个 Web3D 可视化平台，面向展陈运营团队，解决二维客流图无法呈现楼层、楼梯和临时展影响的痛点。通过三维展厅建模叠加实时热力映射与路线播放，帮助运营人员快速定位拥堵区域、追溯数据来源、生成可分享的热区报告。

- 目标用户：博物馆展陈运营、安全管理、展览策划团队
- 核心价值：将平面客流数据升级为空间维度的热区洞察，消除楼层错配与路线断点带来的误判风险

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 运营分析员 | 直接访问 | 浏览3D热区、筛选楼层/展厅、查看明细、导出报告 |
| 展览策划员 | 直接访问 | 浏览路线播放、查看临时展影响、导出报告 |

### 2.2 功能模块

1. **热区主视图页**：3D展厅模型、热力映射叠加、楼层筛选、对象点击明细、截图
2. **热区报告页**（侧边栏内）：数据来源追踪、校验结果、热力映射口径、导出/分享

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 热区主视图页 | 3D展厅场景 | 可旋转/缩放/平移的3D博物馆模型，含楼层、展厅、楼梯、临时展区 |
| 热区主视图页 | 热力映射图层 | 在3D模型上叠加客流密度热力图，支持按楼层/展厅/时间段筛选 |
| 热区主视图页 | 对象点击明细 | 点击展厅/楼梯/临时展区弹出信息面板，展示客流计数、容量比、数据来源 |
| 热区主视图页 | 截图工具 | 一键截取当前3D视图（含热力图层与筛选状态），下载为PNG |
| 热区主视图页 | 侧边栏-热力映射 | 二维热力映射面板，支持楼层切换、色阶调节、时间轴拖拽 |
| 热区主视图页 | 侧边栏-路线播放 | 客流路线动画播放，支持速度调节、路线高亮、断点标记 |

| 热区报告页 | 报告生成 | 基于当前筛选状态生成热区摘要报告，含热力映射口径说明 |
| 热区报告页 | 报告分享 | 一键复制报告链接或下载PDF，报告内嵌数据来源与校验结果 |

## 3. 核心流程

**主流程**：用户进入页面 → 加载3D模型与客流数据 → 数据校验并标注异常 → 热力映射叠加 → 用户旋转/筛选/点击查看 → 侧边栏同步联动 → 截图或生成报告分享

**校验流程**：数据加载时自动执行三层校验 → 楼层错配检测（展厅楼层与客流楼层是否一致）→ 客流重复检测（同一展厅同一时段是否有多条计数）→ 路线断点检测（相邻展厅间是否有路径连接）→ 异常项标注影响范围（影响哪些展厅/路线/统计结果）

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰蓝 (#0F1923) 为底，热力色阶从冷蓝 (#2196F3) 到暖红 (#FF5722) 渐变
- **辅助色**：琥珀色 (#FFB300) 用于警告标注，翠绿 (#00E676) 用于正常状态
- **按钮风格**：圆角矩形，半透明玻璃质感（backdrop-blur），hover 时发光边框
- **字体**：标题使用 Noto Sans SC Bold，数据标签使用 JetBrains Mono
- **布局风格**：左侧3D主视图占 70%，右侧侧边栏占 30%，顶栏放全局筛选
- **图标风格**：线性图标（Phosphor Icons 风格），2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 热区主视图页 | 3D展厅场景 | Three.js 渲染，OrbitControls 旋转，楼层半透明切换，展厅hover高亮 |
| 热区主视图页 | 热力映射图层 | 3D空间热力贴图，色阶从蓝到红，支持透明度调节 |
| 热区主视图页 | 对象点击明细 | 右侧浮动卡片，含数据来源标签、校验状态徽标、客流趋势迷你图 |
| 热区主视图页 | 截图工具 | 顶栏截图按钮，点击后闪光动画+自动下载 |
| 热区主视图页 | 侧边栏-热力映射 | 二维楼层平面热力图，色阶图例，时间轴滑块 |
| 热区主视图页 | 侧边栏-路线播放 | 路线列表+播放控制条，路线在3D视图中以流动粒子高亮 |
| 热区主视图页 | 筛选同步 | 顶栏楼层/展厅/时间筛选器，变更时3D视图与侧边栏同步更新 |
| 热区报告页 | 报告生成 | 模态弹窗，含热区摘要表格、热力映射口径说明、数据来源清单、校验结果列表 |
| 热区报告页 | 报告分享 | 复制链接按钮+下载PDF按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 侧边栏可折叠为抽屉式面板
- 3D视图自适应容器尺寸

### 4.4 3D 场景指导

- **环境/HDRI**：暗色室内环境贴图，模拟博物馆展厅照明
- **灯光设置**：顶部区域光模拟展厅射灯，环境光偏冷蓝色调，热力点自发光
- **相机设置**：透视相机，默认俯视45度角，OrbitControls 允许旋转/缩放/平移
- **构图与焦点**：当前选中楼层清晰，其余楼层半透明
- **交互与动画**：楼层切换时平滑过渡动画，热力值变化时渐变动画，路线播放时粒子流动
- **后处理效果**：Bloom 用于热力高亮区域发光，环境遮蔽增强空间感
- **资源来源**：展厅几何体程序化生成，热力纹理动态渲染
- **性能预算**：目标 60fps，展厅模型 < 50K 三角面，热力贴图 512x512
