## 1. 产品概述

博物馆展柜灯光时序回放系统——面向博物馆巡检与教学场景的灯光时序记录、判读与回放工具。核心解决巡检照片中灯光异常的快速定位、判读追溯与交接报告生成问题，确保异常对象不被淹没在大量模型数据中，原始脏数据痕迹可追溯，改判历史完整保留。

- 目标用户：博物馆巡检人员、教学老师（如林姐）、交接班人员
- 核心价值：将"异常藏在一堆模型里"的痛点转化为可筛选、可追溯、可交接的结构化工作流

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 巡检人员 | 默认进入 | 浏览列表、查看详情、导出截图与报告 |
| 教学老师 | 角色切换 | 巡检人员权限 + 改判、标注、审核 |
| 交接班人员 | 默认进入 | 浏览列表与历史、查看 Markdown 报告 |

### 2.2 功能模块

1. **时序列表页**：灯光时序记录总览，支持多维度筛选、视角切换、快速定位异常
2. **时序详情页**：单条记录的完整信息，含原始巡检照片、标注区、侧边明细面板
3. **改判功能**：教学老师对判断结果进行修改，自动写入历史记录
4. **历史追踪**：查看每条记录的完整改判链路，含操作人、时间、原始判断与新判断
5. **Markdown 报告**：一键生成处理结果报告，确保与页面标注、侧边明细一致

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 时序列表页 | 筛选栏 | 按楼层、展柜编号、异常类型、处理状态、日期范围筛选；支持视角切换（异常优先/时间顺序/按展柜分组） |
| 时序列表页 | 列表主体 | 卡片式展示时序记录，标注异常等级色块、原始来源标识、处理状态标签；楼层单位混写等脏数据以特殊样式标记，处理结果不伪装为正常通过 |
| 时序列表页 | 批量操作 | 选中多条记录后可批量导出截图或生成报告 |
| 时序详情页 | 巡检照片区 | 展示原始巡检照片，保留原始来源信息（拍摄时间、设备、原始文件名），不可被编辑覆盖 |
| 时序详情页 | 标注区 | 在照片上添加/查看标注，标注内容同步写入侧边明细 |
| 时序详情页 | 侧边明细面板 | 展示结构化数据：展柜信息、灯光参数、异常描述、处理状态、判断结果；数据与标注、报告保持一致 |
| 时序详情页 | 改判按钮 | 教学老师可用，弹出改判表单（原判断→新判断、改判理由），提交后自动写入历史 |
| 历史追踪页 | 时间线视图 | 展示单条记录的完整改判时间线：操作人、时间戳、原值→新值、改判理由 |
| 历史追踪页 | 对比视图 | 并排展示不同版本的判断结果，突出差异 |
| 历史追踪页 | 原始溯源 | 从历史记录可跳转至原始巡检照片和原始说法 |
| Markdown 报告页 | 报告生成 | 选择时间范围和筛选条件，一键生成 Markdown 格式报告 |
| Markdown 报告页 | 报告预览 | 在线预览报告内容，确保标注、侧边明细、报告三者一致 |
| Markdown 报告页 | 报告导出 | 导出 .md 文件，含原始数据溯源链接 |

## 3. 核心流程

### 3.1 巡检录入与判读流程

巡检人员上传照片 → 系统自动提取灯光时序数据 → 系统初步判读（标注异常/正常）→ 教学老师审核 → 发现问题则改判（记录历史）→ 生成处理结果

### 3.2 交接班流程

接班人员打开列表 → 切换"上一班改判"筛选 → 逐条查看改判历史与原始照片 → 阅读Markdown报告 → 确认交接

```mermaid
    "巡检照片上传" --> "系统提取灯光时序"
    "系统提取灯光时序" --> "初步判读"
    "初步判读" --> "教学老师审核"
    "教学老师审核" --> "是否改判？"
    "是否改判？" -->|"是"| "录入改判理由"
    "录入改判理由" --> "写入历史记录"
    "写入历史记录" --> "更新侧边明细与标注"
    "是否改判？" -->|"否"| "确认判断"
    "确认判断" --> "处理结果标记"
    "处理结果标记" --> "生成Markdown报告"
    "生成Markdown报告" --> "交接班查阅"
```

### 3.3 异常对象定位流程

打开列表 → 切换"异常优先"视角 → 按异常类型筛选 → 快速定位目标 → 进入详情查看原始照片与标注

```mermaid
    "查看原始巡检照片" --> "查看标注与侧边明细"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨色（#1A1A2E）+ 琥珀色点缀（#D4A574），呼应博物馆沉稳氛围
- **辅助色**：异常红（#E74C3C）、待处理橙（#F39C12）、正常绿（#27AE60）、脏数据紫（#8E44AD）
- **按钮风格**：圆角矩形，主操作使用琥珀色填充，次操作使用描边
- **字体**：标题使用 Noto Serif SC（衬线体，博物馆质感），正文使用 Noto Sans SC
- **布局风格**：左侧固定导航栏 + 右侧内容区，详情页采用左右分栏（照片+标注 / 侧边明细）
- **图标风格**：线性图标，2px 描边，配合微弱光晕效果
- **脏数据标记**：楼层单位混写等异常数据使用紫底色块 + 删除线原值 + 修正值旁注，处理结果以"已处理（含异常）"标签呈现，不伪装为正常通过

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 时序列表页 | 筛选栏 | 下拉筛选器组、视角切换按钮组（异常优先/时间顺序/按展柜分组）、日期范围选择器 |
| 时序列表页 | 列表主体 | 卡片网格，每张卡片含缩略图、展柜编号、楼层、异常等级色块、原始来源小标签、处理状态标签 |
| 时序列表页 | 批量操作栏 | 浮动底栏，含导出截图、生成报告按钮 |
| 时序详情页 | 照片区 | 大图展示，保留原始EXIF信息标签，支持缩放与标注覆盖层 |
| 时序详情页 | 标注工具栏 | 画笔、箭头、文字标注工具，标注列表与照片联动 |
| 时序详情页 | 侧边明细 | 折叠面板：展柜信息、灯光参数、异常描述、判断结果、处理状态；脏数据紫底标记 |
| 时序详情页 | 改判弹窗 | 表单：原判断（只读）、新判断（下拉+文本）、改判理由（必填）、提交按钮 |
| 历史追踪页 | 时间线 | 垂直时间线，每个节点含操作人头像、时间戳、变更内容（原值→新值高亮） |
| 历史追踪页 | 对比视图 | 双栏并排，差异文字高亮 |
| Markdown 报告页 | 报告编辑器 | 左侧编辑/配置区，右侧实时预览，底部导出按钮 |

### 4.3 响应式设计

- 桌面优先（1920×1080 为基准）
- 1280px 以下侧边明细转为抽屉式
- 移动端列表转为单列卡片，详情页全屏照片+底部抽屉明细

### 4.4 动效设计

- 列表加载：卡片交错淡入（stagger 100ms）
- 视角切换：卡片重新排列动画
- 异常色块：微弱脉冲动画提示
- 改判提交：历史时间线新增节点滑入
- 页面切换：淡入淡出 + 微弱位移
