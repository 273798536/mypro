# 舞台灯光预演器

一款面向演出灯光师的专业3D灯光预演工具，支持灯位冲突检测、路线遮挡分析、版本追踪和带标注的截图导出。

## 快速启动

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 类型检查
npm run check
```

启动后访问: http://localhost:5173/

## 核心功能

### 🎭 3D舞台场景
- 可旋转缩放的3D舞台视窗，支持透视、正面、侧面、俯视四种视角
- 真实的聚光灯/面光灯渲染，带阴影效果
- 光锥可视化，清楚显示每盏灯的照射范围
- 烟雾效果补录，后期调整浓度和高度

### 💡 灯位管理
- 8盏预置灯位（面光、顶光、侧光、追光、背景光）
- 完整参数配置：光束角、亮度、色温、位置、目标点
- 灯位状态标记：正常（绿）/ 待确认（黄）/ 冲突（红）

### ⚠️ 冲突检测
**灯位冲突检测**（`detectLightConflicts`）:
- 光束重叠检测：两束光交叠区域过大标记冲突
- 物理碰撞检测：灯具与舞台结构/其他灯具距离过近
- 结果自动走"待确认"分支，标注责任灯光师

**路线遮挡检测**（`detectRouteOcclusions`）:
- 沿演员路线等距采样，射线检测障碍物遮挡
- 遮挡比例 > 30% 的线段高亮显示
- 自动标注"下一步找舞台监督核"

**段落错位检测**（`detectParagraphMismatch`）:
- 多演员同段落时间同步性检查
- 时间差超过阈值标记错位

### 🎬 演员路线
- 预置2条演员路线（主角A、配角B）
- 胶囊体演员模型沿路线动画移动
- 路线带颜色区分，点击可选中查看详情
- 段落标记支持"开场/对话1/退场"等

### 🏷️ 标注系统
- 灯位编号标签（悬停显示，不依赖颜色猜）
- 冲突区域：红色虚线立方体框 + 详细说明卡片
- 遮挡线段：黄色高亮 + 遮挡率显示
- 联动关系：每盏灯与照射目标的光锥连线

### 📸 截图导出
- 一键导出高清PNG截图（2x分辨率）
- 截图包含所有标注，用于会议沟通
- 文件名带时间戳，便于版本管理

### 📚 版本追踪
- 保存版本快照，记录每次改动
- 自动对比前后状态，标记被推翻的结论
- 支持双向查询：
  - 正向：舞台模型节点 → 关联灯位 → 检测结论
  - 反向：检测结论 → 关联灯位参数 → 关联舞台模型

## 预置样例

### 样例1：经典镜框舞台（默认加载）
- **舞台**: 16m × 12m 标准舞台，含背景墙、左右立柱、中央台阶
- **灯位**: 8盏灯（面光×3、顶光×1、侧光×2、追光×1、背景光×1）
- **路线**: 主角A + 配角B，含开场→对话1→退场段落
- **预置问题**:
  1. ❌ 面光3号与侧光右光束重叠严重
  2. ⚠️ 面光2号与左侧立柱距离过近
  3. ⚠️ 主角A经过台阶时被侧光左遮挡45%
  4. ⚠️ "对话1"段落两人灯光衔接有2秒空白

### 样例2：小剧场黑箱
- 简化版10m × 8m舞台，无障碍物
- 4盏基础灯位配置
- 单演员路线

## 使用演示流程

### 演示1：灯位冲突沟通
1. 打开页面，右侧检测结果面板显示4个待确认问题
2. 点击"面光3号与侧光右光束重叠"条目
3. 3D场景自动聚焦到冲突区域，红色虚线框标记冲突范围
4. 左侧灯位面板选中"面光3号"，调整角度滑块
5. 点击工具栏"重新检测"（⚡图标）
6. 点击"导出截图"（📷图标）保存用于会议

### 演示2：路线遮挡分析
1. 点击"主角A路线第3段遮挡"结果
2. 查看关联信息：遮挡源为中央台阶，关联灯位侧光左
3. 点击播放按钮（▶️）观看演员移动动画
4. 可以看到演员经过台阶时光线被遮挡的实际效果
5. 结论标注"下一步找舞台监督核实台阶是否可移动"

### 演示3：版本对比
1. 调整某盏灯的参数
2. 点击"保存版本"（💾图标），输入说明"调整面光3号角度"
3. 修改另一个参数，再次保存
4. 版本列表中可看到每次改动的字段，以及哪些结论被推翻

### 光束重叠检测
```typescript

// 重叠体积 > 阈值则标记冲突
function checkBeamOverlap(light1, light2): Vec3 | null
```

### 遮挡射线检测
```typescript
// 沿路线等距采样20个点
// 对每个采样点，射线检测从灯具到采样点是否被障碍物遮挡
// 遮挡比例 > 30% 的线段高亮
function detectRouteOcclusions(route, lights, obstacles)
```

### 双向查询
```typescript
// 正向：障碍物 → 关联灯位 → 检测结论
queryByObstacle(obstacleId)

// 反向：结论 → 关联灯位/路线/障碍物
queryByResult(resultId)
```

## 快捷键 & 交互

- **鼠标左键拖动**: 旋转视角
- **鼠标右键拖动**: 平移视角
- **滚轮**: 缩放

## 技术栈

- React 18 + TypeScript
- Vite 构建工具
- Three.js + @react-three/fiber (3D渲染)
- @react-three/drei (3D组件库)
- @react-three/postprocessing (后处理Bloom效果)
- Zustand (状态管理)
- Tailwind CSS (样式)
- Lucide React (图标)
- html2canvas (截图导出)

## 设计特色

- 🌑 **舞台暗房风格**: 深空灰底色，灯光效果突出
- 🏷️ **清晰标注**: 不依赖颜色，每个元素带文字标签
- 🔴 **冲突可视化**: 虚线框 + 说明卡片，截图即可说明问题
- ⏳ **待确认分支**: 检测结果不直接判定，走人工确认流程
- 🔗 **双向追溯**: 从模型到结论，从结论回查参数
- 💨 **后期烟雾**: 先确定方案，再补录烟雾效果看最终呈现
