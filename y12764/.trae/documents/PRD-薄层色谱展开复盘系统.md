## 1. 产品概述

薄层色谱展开复盘系统是面向化学实验室的实验记录审核与报告工具。核心解决批号重复、反应时间漏记等常见实验记录异常问题，通过图谱、数据表、文字说明三者联动呈现，帮助化学老师快速复盘实验数据并导出可直接交付的报告。

- 目标用户：化学实验教师、质检主管、实验室记录人员
- 产品价值：降低实验记录复盘的沟通成本，让质检主管仅通过导出报告即可理解异常拦截原因

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 化学老师 | 日常实验复盘、异常处理、补录数据 | 查看全部记录、编辑补录、导出报告 |
| 质检主管 | 审核导出报告、了解拦截原因 | 查看报告、阅读异常解释 |

### 2.2 功能模块

1. **实验记录列表页**：三类样例记录展示（顺利/待确认/坏数据），状态标签，快速筛选
2. **记录详情页**：谱图展示、数据表、文字说明三者联动，补录编辑，异常高亮
3. **报告预览与导出页**：整合图表文字，异常解释段落（可直接复制的普通话说明），一键导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 实验记录列表页 | 记录卡片列表 | 展示批号、日期、状态标签、异常标记，点击进入详情 |
| 实验记录列表页 | 筛选工具栏 | 按状态（顺利/待确认/坏数据）、批号关键词筛选 |
| 记录详情页 | 谱图展示区 | 薄层色谱条带模拟图，标注各组分Rf值，支持补录后重绘 |
| 记录详情页 | 数据表区 | 展示实验参数（批号、反应时间、展开剂比例等），异常字段红框高亮 |
| 记录详情页 | 文字说明区 | 实验结论、人工备注（保留原话）、系统判读说明 |
| 记录详情页 | 补录操作区 | 漏记字段补录输入框，确认后触发图谱与报告联动更新 |
| 报告预览与导出页 | 报告正文 | 按顺序整合：实验信息表 → 谱图 → 数据表 → 判读说明 → 异常解释 |
| 报告预览与导出页 | 异常解释模块 | 批号重复等异常的普通话解释段落，带一键复制按钮 |
| 报告预览与导出页 | 导出操作区 | PDF/打印格式导出，确保质检主管离线可读 |

## 3. 核心流程

化学老师从列表页选择一条记录进入详情，系统自动高亮异常字段（如批号重复、反应时间为空）。老师补录漏记信息后，谱图、数据表、文字说明同步更新。确认无误后进入报告预览，异常解释段落自动生成且可复制，最终一键导出供质检主管审阅。

```mermaid
flowchart LR
    A["选择实验记录"] --> B["查看谱图+数据表+说明"]
    B --> C{"是否存在异常"}

    D --> E["补录漏记信息"]
    E --> F["图谱/数据/说明同步更新"]
    C -->|否| G["进入报告预览"]
    F --> G
    G --> H["查看异常解释段落"]
    H --> I["一键复制解释或导出报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色：实验室蓝 `#1E40AF`（专业可靠），辅色：警示橙 `#D97706`（待确认）、错误红 `#DC2626`（坏数据）、成功绿 `#059669`（顺利）
- 按钮风格：直角微圆角（2px），扁平化，状态色边框填充
- 字体：思源宋体（标题，学术感）+ 思源黑体（正文数据，可读性强）
- 布局风格：左右分栏，左侧谱图区（大），右侧数据表与说明区，卡片式分组
- 图标风格：线性简约图标，异常时对应颜色实心图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 实验记录列表页 | 记录卡片列表 | 卡片悬浮微上浮，状态色标签，批号重复时卡片左侧红色竖条标记 |
| 记录详情页 | 谱图展示区 | 米色实验室滤纸背景，条带手绘感线条，Rf值悬浮标注 |
| 记录详情页 | 数据表区 | 表格斑马纹，异常单元格红底白字感叹号图标 |
| 记录详情页 | 文字说明区 | 人工备注使用引用样式（左边框灰色），保留原始换行与口语化表达 |
| 报告预览与导出页 | 异常解释模块 | 浅橙底圆角卡片，一键复制按钮，文字为可直接转发的口语化说明 |

### 4.3 响应式

桌面端优先（≥1280px），平板端左右分栏改为上下堆叠，移动端单列滚动布局，表格支持横向滑动。
