# 声呐网格追踪 - 游戏操作指南

## 🚀 快速开始

### 启动游戏

```bash
# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

启动后，在浏览器中打开显示的本地地址（通常是 `http://localhost:5173`）。

## 🎮 游戏玩法

### 游戏目标
在有限的回合和能量内，通过声呐扫描确定潜艇的最终位置。定位越准确，得分越高。

### 基本操作

| 操作 | 说明 |
|------|------|
| **左键点击网格** | 发射声呐扫描该区域，显示回波强度 |
| **右键点击网格** | 标记/取消标记可疑区域（黄色三角警告） |
| **定位目标按钮** | 进入定位模式，选择你认为潜艇所在的位置 |
| **结束回合** | 结束当前回合，潜艇会移动 |
| **重新开始** | 重置当前关卡 |

### 游戏流程

1. **选择关卡** → 从开始界面选择难度合适的关卡
2. **扫描探测** → 左键点击网格进行声呐扫描
3. **分析信号** → 根据回波强度判断潜艇位置
4. **标记区域** → 右键标记可疑区域帮助推理
5. **结束回合** → 点击"结束回合"，潜艇会移动
6. **定位目标** → 当你有足够信息时，点击"定位目标"选择位置
7. **提交答案** → 选择位置后点击"提交位置猜测"查看结果

## 📡 声呐原理

### 回波强度
- **绿色 (60-100%)**：强回波，潜艇距离非常近（0-2格）
- **黄色 (30-59%)**：弱回波，潜艇距离中等（3-4格）
- **灰色 (0-29%)**：无回波，潜艇距离较远（5格以上）

### 噪声干扰
- 红色闪烁的区域表示存在噪声干扰
- 噪声会降低回波强度，导致信号不可靠
- 尽量避开噪声区域进行关键扫描

### 潜艇行为
- 潜艇每回合会移动1-2格（取决于关卡难度）
- 潜艇有概率改变方向，注意转向提示
- 潜艇不会移动到网格外

## ⚡ 能量管理

- 每次扫描消耗固定能量（关卡不同，消耗不同）
- 能量耗尽则游戏结束
- 剩余能量会转化为额外得分
- **策略建议**：不要盲目扫描，有计划地探索区域

## 🎯 评分系统

### 得分构成
| 项目 | 说明 | 最高分 |
|------|------|--------|
| 距离分 | 定位越准确分数越高 | 1000 |
| 效率分 | 使用回合越少分数越高 | 500 |
| 能量奖励 | 剩余能量×2 | 300 |

### 评级标准
| 评级 | 分数 | 说明 |
|------|------|------|
| S | ≥1200 | 完美 |
| A | ≥1000 | 优秀 |
| B | ≥800 | 良好 |
| C | ≥600 | 及格 |
| D | ≥400 | 欠佳 |
| F | <400 | 失败 |

## 🔍 高级技巧

### 推理方法
1. **三角定位法**：在不同位置扫描，根据回波强度交汇判断位置
2. **轨迹预测**：根据潜艇移动规律预测下一步位置
3. **排除法**：先扫描大范围，逐步缩小搜索区域

### 注意事项
- 注意噪声干扰提示，不要被假信号误导
- 能量不足时及时提交答案，不要浪费最后的能量
- 潜艇转向时会有明确提示，注意调整推理

## 📊 数据功能

### 回放系统
- 每局游戏自动保存回放（最多20条）
- 在开始界面点击"历史记录"查看
- 支持播放/暂停、逐帧控制
- 可以导出JSON格式的完整数据

### 数据导出
- 回放数据包含所有扫描记录和操作
- 可用于教学演示或数据分析
- JSON格式易于程序处理

## 🐛 异常处理

### 常见问题
1. **扫描没反应**：检查能量是否充足，冷却是否结束
2. **页面显示异常**：刷新页面或清除浏览器缓存
3. **数据丢失**：回放数据保存在LocalStorage，清除浏览器数据会丢失

### 控制台调试
按 `F12` 打开开发者工具，可以查看：
- 游戏状态变化
- 潜艇实际位置（调试用）
- 错误信息和警告

## 📖 关卡说明

### 关卡1：新手海域
- 8×8网格，15回合，能量100
- 潜艇速度慢，转向少
- 适合熟悉基本操作

### 关卡2：大陆架边缘
- 8×8网格，12回合，能量100
- 噪声源增加
- 开始有挑战性

### 关卡3：深海峡谷
- 10×10网格，12回合，能量120
- 冷却时间增加到2回合
- 需要更精准的推理

### 关卡4：繁忙航道
- 10×10网格，10回合，能量120
- 潜艇速度提升到2格/回合
- 噪声干扰严重

### 关卡5：极地冰下
- 12×12网格，10回合，能量150
- 最高难度，考验所有技巧
- 适合高手挑战

- 资源管理策略
