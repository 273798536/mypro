## 1. 产品概述

园区行政班车排程系统，基于整数规划算法解决班车调度问题。解决月底/开学前容量超限混进正常结果的痛点，实现口径统一、筛选联动、历史留痕的专业班车排程方案。

- 核心目标：通过整数规划算法优化站点选择和路线规划
- 解决问题：容量超限覆盖问题、临时表格硬凑问题、口径不一致问题
- 目标用户：园区行政人员、调度管理人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|-----------|----------|
| 园区行政 | 系统内置 | 完整管理权限、数据导入、算法运行、报告导出 |

### 2.2 功能模块

1. **员工住址管理**：员工信息导入、查询、编辑、数据管理
2. **站点候选管理**：候选站点维护、容量设置、坐标维护
3. **整数规划排程**：算法配置、站点选择、路线优化、容量检测
4. **调度报告中心**：方案对比、容量超限告警、历史留痕、导出报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 员工住址管理 | 数据表格 | 导入Excel、批量编辑、字段校验、缺字段标记 |
| 员工住址管理 | 筛选查询 | 按部门/区域/状态筛选、双向关联站点 |
| 站点候选管理 | 站点列表 | 新增/编辑/删除候选站点、容量设置 |
| 站点候选管理 | 坐标地图 | 站点地理位置可视化 |
| 整数规划排程 | 算法配置 | 参数设置、算法运行状态 |
| 整数规划排程 | 方案对比 | 多方案对比、最优方案推荐 |
| 调度报告 | 容量超限告警 | 实时检测、历史留痕、不可覆盖 |
| 调度报告 | 导出报告 | 路线明细、对应关系留存 |
| 双向查询 | 住址→结果 | 从员工查分配站点 |
| 双向查询 | 结果→站点 | 从结果反查候选站点 |

## 3. 核心流程

员工住址导入 → 站点候选维护 → 整数规划运算 → 容量超限检测 → 方案对比选择 → 调度报告导出

```mermaid
flowchart LR
    A["员工住址导入"] --> B["数据校验(缺字段标记)"]
    B --> C["站点候选维护"]
    C --> D["整数规划运算"]
    D --> E["容量超限检测"]
    E --> F{"是否超限?"}
    F -->|是| G["历史留痕记录"]
    F -->|否| H["生成排程方案"]
    G --> H
    H --> I["方案对比选择"]
    I --> J["调度报告导出"]
    J --> K["双向查询复核"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝色系（#1e3a5f 深蓝、#2563eb 蓝色、#1d4ed8 深蓝高亮
- 辅助色：橙红色告警（#dc2626 红色）、绿色正常（#059669）
- 按钮风格：直角微圆、悬浮阴影、悬浮效果
- 字体：思源黑体 + Roboto Mono（数据展示）
- 布局风格：卡片式布局，左侧导航+主内容区
- 图标风格：线性图标，简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|---------|--------|
| 员工住址管理 | 数据表格 | 斑马纹表格、行高亮、缺字段红框标记 |
| 站点候选管理 | 站点卡片 | 容量进度条、状态徽章 |
| 整数规划排程 | 算法面板 | 进度动画、参数滑块、运行状态指示器 |
| 调度报告 | 告警面板 | 红色横幅、历史时间线 |
| 双向查询 | 关联展示 | 链路图、高亮连接线 |

### 4.3 响应式
- 桌面端优先设计，支持1920×1080标准分辨率
- 平板自适应布局调整
- 移动端核心功能可用
