## 1. 产品概述

海洋课堂洋流沙盘是一套面向水产养殖场长的潮汐与水质数据复核工具，核心解决"巡检照片更新后旧结果、新结果和船队报告各说各话"的问题。产品确保图表、表格、文字说明三者始终一致，让数据从录入到报告形成可追溯、可复现的闭环。

- 目标用户：水产养殖场长、船队数据审核员
- 核心价值：将风险通报、水质记录、重复上报统一纳入同一轮复核，消除数据结论不一致

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 场长 | 日常从潮汐计算入口进入 | 浏览数据、执行复核、修正留痕、导出报告 |
| 船队审核员 | 查看场长发布的报告 | 只读报告、查看复核备注 |

### 2.2 功能模块

1. **潮汐计算首页**：日常入口，展示当日潮汐曲线、水位表格和文字摘要，三者强制一致
2. **数据复核面板**：处理脏数据（空值、重复、时区错、备注混写），人工修正留痕，重导入去重
3. **复核报告**：统一呈现风险通报、水质记录、重复上报，让船队看出处理的是眼前这批具体材料

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 潮汐计算首页 | 潮汐曲线图 | 按时间轴展示潮位曲线，标注异常点（空值、时区偏移） |
| 潮汐计算首页 | 水位数据表 | 与曲线图同步的表格，空值/重复行高亮显示 |

## 3. 核心流程

1. 场长日常从"潮汐计算"入口进入，查看当日潮汐曲线、表格、文字摘要
2. 发现异常数据（空值/重复/时区错）后进入数据复核面板
3. 系统自动检测数据质量问题，场长逐条确认或修正
4. 每次修正自动留痕，标注改前值、改后值和原因
5. 重新导入数据时自动去重，防止同一事件出现两份结论
6. 复核完成后生成统一报告，风险通报、水质记录、重复上报在同一轮呈现
7. 报告中的图表文字三者强制一致，船队拿到的是一份"说同一件事"的报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝(#0A2342) + 浅海青(#2EC4B6) + 警示珊瑚橙(#FF6B35)
- 辅助色：雾白(#F0F4F8)用于背景、深墨(#1A1A2E)用于文字
- 按钮风格：圆角胶囊型，主按钮深海蓝底白字，危险操作用珊瑚橙
- 字体：标题用 Noto Serif SC（衬线体，海洋文献感），正文用 Noto Sans SC
- 布局：左侧窄导航栏 + 右侧主内容区，卡片式模块布局
- 图标：线性图标搭配海浪纹理装饰

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 潮汐计算首页 | 潮汐曲线图 | 深色背景折线图，异常点用珊瑚橙脉冲动画标注，鼠标悬停显示详情 |
| 潮汐计算首页 | 水位数据表 | 斑马纹表格，空值行淡黄底色，重复行淡红底色，备注列混写时显示拆分图标 |
| 潮汐计算首页 | 文字摘要 | 卡片式文字块，关键数值用青色高亮，与图表数值联动 |
| 潮汐计算首页 | 示例数据引导 | 首次访问弹出半透明引导卡片，一键加载示例数据集 |
| 数据复核面板 | 数据质量检测 | 左侧问题清单（红/黄/灰三级），右侧对应数据预览 |
| 数据复核面板 | 人工修正区 | 行内编辑模式，修正后显示删除线+新值，底部自动记录修正原因 |
| 数据复核面板 | 修正留痕时间线 | 垂直时间轴，每节点显示改前→改后，悬停展开原因 |
| 数据复核面板 | 重导入去重 | 导入后弹出去重对比面板，并排显示旧记录与新记录，标记冲突 |
| 数据复核面板 | 复核备注 | 备注列表，每条带状态标签（待确认/已通过），支持筛选 |
| 复核报告 | 统一报告视图 | 三栏并排：风险通报(红) + 水质记录(蓝) + 重复上报(橙)，下方汇总表 |
| 复核报告 | 一致性校验 | 顶部状态条：绿色通过/橙色警告/红色不一致，点击跳转问题位置 |
| 复核报告 | 船队视图 | 精简卡片布局，突出关键结论和具体材料编号 |

### 4.3 响应式

- 桌面优先设计，最小宽度1280px
- 平板端(768-1279px)侧边栏折叠为顶部导航，三栏报告改为标签切换
- 移动端(<768px)单列布局，表格改为可横向滚动
