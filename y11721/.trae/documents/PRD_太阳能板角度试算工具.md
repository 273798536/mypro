## 1. 产品概述

校园节能小组太阳能板角度试算Web3D工具，用于估算不同季节太阳能板倾角带来的发电差异。支持地理位置、日期、倾角、天气系数、面板面积等参数调节，实时3D可视化展示，支持方案保存、对比和截图导出。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 节能小组成员 | 无需注册 | 使用全部功能，保存/导入方案 |

### 2.2 功能模块
1. **主界面：3D场景、参数控制面板、实时数据展示
2. **方案管理：保存、导入、对比、导出
3. **报告生成：试算报告、图表导出、截图导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 主页面 | 3D场景模块 | 太阳能板3D模型，太阳位置模拟，实时角度变化 |
| 主页面 | 参数控制面板 | 地理位置、日期、倾角、天气系数、面板面积调节 |
| 主页面 | 数据展示区 | 太阳高度角、辐照量、发电量实时显示 |
| 主页面 | 悬浮信息 | 鼠标悬停显示详细参数信息 |
| 主页面 | 错误提示 | 时区错误、阴天系数、倾角越界的醒目提示 |
| 方案管理 | 保存方案 | 保存当前参数配置 |
| 方案管理 | 导入方案 | 支持忽略/覆盖/追加三种导入模式 |
| 方案管理 | 情景对比 | 多方案并排对比展示 |
| 导出功能 | 截图导出 | 导出3D场景截图 |
| 导出功能 | 报告导出 | 生成试算报告（含数据和来源记录 |

## 3. 核心流程

用户调整参数 → 系统验证参数合法性 → 计算太阳高度角和辐照量 → 实时更新3D场景和数据 → 可保存方案 → 可对比方案 → 可导出截图和报告

```mermaid
flowchart TD
    A["用户输入参数" --> B{"参数校验"}
    B -->|合法| C["计算太阳高度角"]
    B -->|不合法| D["显示错误提示"]
    C --> E["计算辐照量"]
    E --> F["更新3D场景"]
    F --> G["显示实时数据"]
    G --> H["保存方案"]
    G --> I["对比方案"]
    G --> J["导出截图/报告"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：科技蓝 #165DFF 科技感，配合生态绿 #00B42A
- 按钮风格：圆角矩形，微立体阴影
- 字体：现代无衬线字体，清晰易读
- 布局风格：左侧3D场景居中，右侧参数面板，底部数据展示
- 图标风格：线性图标，简洁现代

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|-----------|----------|----------|
| 主页面 | 3D场景 | 居中大面积展示，支持鼠标交互 |
| 主页面 | 参数面板 | 右侧滑出式面板，可折叠 |
| 主页面 | 数据卡片 | 底部悬浮卡片，半透明玻璃态 |
| 主页面 | 错误提示 | 顶部醒目红色警告条 |
| 方案管理 | 弹窗 | 居中模态框，清晰操作按钮 |

### 4.3 响应式
- 桌面端：3D场景自适应，参数面板可折叠
- 移动端：参数面板移至底部，滚动查看

### 4.4 3D场景指引
- 环境：明亮日光环境，HDRI环境贴图
- 光照：模拟真实太阳光，随时间变化
- 相机：轨道控制器，可旋转缩放
- 交互：点击太阳能板显示详细信息
- 动画：太阳轨迹动画，参数变化平滑过渡
- 后处理：轻微泛光效果，增强科技感
