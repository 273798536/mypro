### 1. 安装依赖
```bash
cd /Users/mac/pro/solo/workspaces/y12144
```

## 核心功能模块

### 📊 样例数据 (`/api/samples`)
| 接口 | 用途 |
|------|------|
| `POST /generate` | 生成含异常的样例（到时缺失/台站重复/波速错） |
| `POST /generate/clean` | 生成纯净样例（可直接反演） |
| `GET /stats` | 查看数据统计 |
| `POST /clear` | 清空所有数据 |
| `POST /import/stations` | CSV导入台站 |
| `POST /import/arrivals` | CSV导入到时 |
| `POST /import/json` | JSON批量导入 |

### 🏢 台站管理 (`/api/stations`)
| 接口 | 用途 |
|------|------|
| `GET /` | 台站列表 |
| `POST /` | 新增台站 |
| `GET /{id}` | 台站明细 |
| `GET /code/{code}` | 按代码查台站 |
| `GET /{id}/trace` | **追溯**: 台站→到时→反演结果 |
| `PUT /{id}` | 更新台站 |
| `PATCH /{id}/status` | 修改台站状态 |

### ⏱️ 到时记录 (`/api/arrivals`)
| 接口 | 用途 |
|------|------|
| `GET /` | 到时列表（支持按事件/状态/震相筛选） |
| `POST /` | 新增到时 |
| `GET /{id}` | 到时明细 |
| `GET /{id}/trace` | **追溯**: 到时→台站→反演结果 |
| `PATCH /{id}/status` | 修改状态（状态机校验） |
| `PATCH /{id}/magnitude` | 补录震级备注（自动记录变更） |
| `GET /{id}/transitions` | 查看可转换的状态 |
| `GET /{id}/audit` | 查看变更日志 |

### 📈 波速模型 (`/api/velocity`)
| 接口 | 用途 |
|------|------|
| `GET /` | 模型列表 |
| `POST /` | 新增模型（自动校验层结构） |
| `GET /{id}` | 模型明细 |
| `GET /active` | 当前激活模型 |
| `PATCH /{id}/activate` | 激活模型 |
| `PATCH /{id}/status` | 标记波速版本错 |

### 🌍 震源反演 (`/api/inversion`)
| 接口 | 用途 |
|------|------|
| `GET /` | 反演结果列表 |
| `POST /` | **执行反演**（Geiger法） |
| `GET /{id}` | 反演明细（含各台站残差） |
| `GET /event/{tag}` | 按事件标签查结果 |
| `GET /{id}/trace` | **追溯**: 结果→到时→台站 |
| `GET /{id}/recompute` | 重算（可调整残差阈值） |

### 📤 导出结果 (`/api/export`)
| 接口 | 用途 |
|------|------|
| `GET /stations/csv` | 台站CSV |
| `GET /arrivals/csv` | 到时CSV |
| `GET /inversion/{id}/csv` | 反演结果CSV |
| `GET /inversion/{id}/json` | 反演结果JSON |
| `GET /event/{tag}/all` | 事件完整数据包 |
| `GET /report/monthly` | 月度复盘报告 |
| `GET /report/event/{tag}` | 事件报告JSON |
| `GET /report/event/{tag}/txt` | **事件报告TXT**（月底复盘用） |

### 🔍 变更追踪 (`/api/audit`)
| 接口 | 用途 |
|------|------|
| `GET /logs` | 所有变更日志 |
| `GET /arrival/{id}` | 单条记录变更历史 |
| `GET /magnitude-updates` | 震级备注更新列表 |
| `GET /status-flow/{id}` | 状态流转时间线 |
| `GET /pending-actions` | **待办事项**（按审核人分类） |
| `GET /summary` | 审核统计汇总 |

## 状态流转说明

```
待确认(pending_confirm)
    │
    ├→ 数据采集员确认 → 正常(normal)
    ├→ 到时缺失 → missing_arrival (找数据采集员补录)
    ├→ 波速版本错 → wrong_velocity (找波速专家核对)
    └→ 台站重复 → duplicate_station (找台站管理员处理)

到时缺失(missing_arrival)
    ├→ 补录完成 → 正常(normal)
    └→ 无法补录 → 已剔除(rejected) [教师确认]

正常(normal)
    ├→ 教师审核 → 已确认(confirmed)
    └→ 残差过大 → 已剔除(rejected) [教师确认]
```

## 双向追溯演示流程

### 正向: 台站 → 到时 → 反演结果
```bash
# 1. 查台站BJI的明细
curl http://localhost:8000/api/stations/code/BJI

# 2. 追溯台站关联的到时和反演结果
curl http://localhost:8000/api/stations/1/trace
```

### 反向: 反演结果 → 到时 → 台站
```bash
# 1. 查反演结果明细（含各台站残差）
curl http://localhost:8000/api/inversion/1

# 2. 追溯结果关联的到时和台站
curl http://localhost:8000/api/inversion/1/trace
```

### 从结果反查回到时
```bash
# 查看某台站在反演中的残差
curl http://localhost:8000/api/inversion/1 | python3 -m json.tool | grep -A5 station_code

# 找到对应的arrival_id，查到时明细
curl http://localhost:8000/api/arrivals/{arrival_id}

# 查看该到时的完整变更历史
curl http://localhost:8000/api/audit/arrival/{arrival_id}
```

## 典型工作流

### 1. 造样例 → 查问题 → 改状态 → 反演 → 导出
```bash
# 1. 生成样例（含异常）
curl -X POST http://localhost:8000/api/samples/generate?event_tag=EVT_TEST01

# 2. 查看待办
curl http://localhost:8000/api/audit/pending-actions

# 3. 处理到时缺失（补录+改状态）
curl -X PUT http://localhost:8000/api/arrivals/5 \
  -H "Content-Type: application/json" \
  -d '{"arrival_time": 30015.678, "arrival_time_str": "08:20:15.678"}'

curl -X PATCH http://localhost:8000/api/arrivals/5/status \
  -H "Content-Type: application/json" \
  -d '{"status": "normal", "operator": "data_collector_01"}'

# 4. 执行反演
curl -X POST http://localhost:8000/api/inversion \
  -H "Content-Type: application/json" \
  -d '{"event_tag": "EVT_TEST01", "residual_threshold": 2.0}'

# 5. 导出结果和报告
curl http://localhost:8000/api/export/inversion/1/csv
curl http://localhost:8000/api/export/report/event/EVT_TEST01/txt
```

### 2. 月底复盘
```bash
# 月度报告
curl http://localhost:8000/api/export/report/monthly

# 待处理事项
curl http://localhost:8000/api/audit/pending-actions

# 数据质量汇总
curl http://localhost:8000/api/audit/summary

# 震级备注变更列表
curl http://localhost:8000/api/audit/magnitude-updates
```

## 数据模型关系

```
Station (台站)
    │ 1
    │
    │ N
Arrival (到时记录) ── AuditLog (变更日志)
    │ N
    │
    │ 1
InversionResult (反演结果)
    │ 1
    │
    │ N
InversionStation (反演台站明细)
    │
    ├→ 关联 Station
    ├→ 关联 Arrival
    └→ 记录 residual, is_rejected
```
