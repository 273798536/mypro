# 鼓组节拍异常提醒

琴房前台用：把合同扫描件里文件名和曲目表对不上的记录捋顺、留痕、交接。

## 三步上手

**1. 启动服务**
```bash
# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# 前端（另开一个终端）
cd frontend
npm install
npm run dev
```
浏览器打开 http://localhost:5173

**2. 录入异常**
点击「新增记录」→ 填文件名、曲目名称 → 勾选「标记为异常」→ 选异常类型 → 写备注 → 选备注来源（合同/后补备注/口头）→ 保存。
**修改备注会自动同步到后端和导出 Excel**。

**3. 人工复核 + 导出交接**
点「人工复核」写清判断原因和下一步 → 点「导出 Excel」把清单发给演出/发行同事。
想知道哪份材料改过口径 → 点每行的「历史」。

---

## 坏材料来了看哪里

当小温把合同扫描件 + 后补备注 + 口头说明一起丢过来、口径对不上时：

| 看哪里 | 怎么找 | 说明 |
| --- | --- | --- |
| **原始行** | 表格里「📄 扫描件X_第Y行」 | `contract_scan_ref` 字段，定位合同扫描件里的原始行号或对象 |
| **坏数据提示** | 表格里「🔍 …」 | 自动告诉你这条记录来自哪里、有没有书面材料 |
| **谁改的口径** | 行末「历史」按钮 | 每次修改都记了：改了啥、来源（合同/后补/口头/人工）、操作人、时间 |
| **备注来源标签** | 备注下方的蓝/黄/灰标签 | 蓝=合同扫描件、黄=后补备注、灰=口头说明或系统识别 |
| **人工判断** | 「已复核」标签下方 | 复核人写的判断原因和下一步会原样带进导出 Excel |

导出的 Excel 文件名是「鼓组节拍异常提醒.xlsx」，异常行底色标黄，所有列按琴房交接习惯排版。
