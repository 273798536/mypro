## 1. 产品概述

土壤重金属浸提报告系统面向环境监测员和课题组，解决实验记录不完整、谱峰重叠标注不清、结果导出对不上三大痛点。系统将配平计算、谱图判读、异常留痕三条核心线拉通，让课题组拿到报告时一眼分清哪些结论可直接使用、哪些需找监测员复核。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 环境监测员 | 录入实验记录、执行配平计算、判读谱图、标注异常 | 录入、编辑、复核、导出 |
| 课题组 | 查看报告、确认/退回待复核项 | 只读查看、确认/退回 |

### 2.2 功能模块

1. **实验记录录入页**：实验记录表单录入、空值检测、重复检测、备注混写识别、完整性评分
2. **配平计算与谱图判读页**：浸提配平计算、谱峰重叠标注、温度曲线/pH越界判定
3. **复核与分级页**：异常留痕、结论可信度分级（可直接用/需复核/数据坏）、反应条件-温度曲线-pH越界统一复核
4. **报告导出页**：一键导出、导出对账校验、差异高亮

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 实验记录录入 | 记录表单 | 录入样品编号、浸提方法、反应条件（温度/pH/时间）、实验员、备注；空值标红、重复行标黄、备注混写拆分提示 |
| 实验记录录入 | 完整性评分 | 实时计算记录完整度百分比，缺失字段清单 |
| 配平计算与谱图判读 | 配平计算器 | 输入浸提液体积、样品质量、稀释倍数，自动算出浓度，校验配平偏差 |
| 配平计算与谱图判读 | 谱图标注 | 标注谱峰位置，自动检测峰重叠，重叠区域标橙并提示需二次确认 |
| 配平计算与谱图判读 | 越界判定 | 温度曲线与pH越界自动标红，与反应条件在同一卡片展示 |
| 复核与分级 | 异常留痕 | 所有异常（空值/重叠/越界/配平偏差）汇总列表，点击跳转至来源材料 |
| 复核与分级 | 结论分级 | 每条记录标注可信度：✅可直接用 / ⚠️需复核 / ❌数据坏 |
| 报告导出 | 导出对账 | 导出前自动比对录入数据与计算结果，差异项高亮，确认后导出 |
| 报告导出 | 报告生成 | 生成结构化报告，含结论分级标识，课题组可按分级筛选 |

## 3. 核心流程

用户操作主流程：录入实验记录 → 系统自动完整性检查 → 执行配平计算 → 谱图判读与重叠标注 → 越界判定 → 异常留痕汇总 → 结论可信度分级 → 导出报告（含对账校验）。

```mermaid
    "录入实验记录" --> "完整性检查"
    "完整性检查" --> "空值/重复/备注混写检测"

    "配平计算" --> "谱图判读"

    "峰重叠标注" --> "异常留痕汇总"
    "温度/pH越界判定" --> "异常留痕汇总"
    "配平计算" --> "配平偏差检测"
    "配平偏差检测" --> "异常留痕汇总"
    "异常留痕汇总" --> "结论可信度分级"
    "结论可信度分级" --> "导出报告"

    "导出对账校验" --> "课题组查看"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深石板蓝 (#1e293b) 搭配琥珀警告色 (#f59e0b) 和翡翠确认色 (#10b981)
- **辅助色**：冷灰底色系，危险红 (#ef4444) 用于坏数据标识
- **按钮风格**：圆角微阴影，主操作用实色填充，次要操作用描边
- **字体**：标题用 Noto Serif SC（衬线学术感），正文用 Noto Sans SC
- **布局**：桌面优先，左侧导航 + 右侧内容区，卡片式模块布局
- **图标**：Lucide 图标，搭配状态色使用

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 实验记录录入 | 记录表单 | 卡片式表单，空值字段红色边框+提示，重复行黄色条纹背景，备注混写蓝色拆分标签 |
| 实验记录录入 | 完整性评分 | 环形进度条 + 缺失字段清单面板 |
| 配平计算与谱图判读 | 配平计算器 | 紧凑计算卡片，输入框联动输出，偏差超限红色闪烁 |
| 配平计算与谱图判读 | 谱图标注 | 模拟谱图区域，峰位置标记点，重叠区域橙色半透明遮罩 |
| 配平计算与谱图判读 | 越界判定 | 温度/pH折线图 + 红色越界区间标注，与反应条件信息并排 |
| 复核与分级 | 异常留痕 | 时间线式异常列表，每条异常带跳转链接和来源摘要 |
| 复核与分级 | 结论分级 | 三色标签卡片（绿/黄/红），支持筛选和批量操作 |
| 报告导出 | 导出对账 | 差异对照表，不一致项红底高亮 |
| 报告导出 | 报告生成 | 预览面板 + 导出按钮，分级标识嵌入报告头 |

### 4.3 响应式

- 桌面优先设计（1280px+最佳体验）
- 平板端（768px-1279px）侧边栏收为图标导航
- 移动端（<768px）单列堆叠，关键操作置底

## 5. 样例数据设计

三条样例记录覆盖典型场景：

| 样例 | 场景 | 特征 |
|------|------|------|
| S-2026-001 | 顺利记录 | 所有字段完整，配平偏差 <5%，无峰重叠，温度/pH在范围内，结论：✅可直接用 |
| S-2026-002 | 待确认记录 | pH值越界（6.8 > 6.5上限），一个峰重叠需二次确认，配平偏差8%，结论：⚠️需复核 |
| S-2026-003 | 明显坏数据 | 多处空值，温度曲线断裂，配平偏差23%，备注中混写了"仪器故障 可能不准"，结论：❌数据坏 |
