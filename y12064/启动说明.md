# 电磁炮靶场 - 启动说明

## 项目简介

电磁炮靶场是一款物理教学互动游戏，帮助学生通过可视化模拟理解洛伦兹力的方向判断。

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

默认访问地址: http://localhost:5173

### 3. 构建生产版本

```bash
npm run build
```

## 游戏操作说明

### 参数调节

1. **磁场板 (B)**
   - 方向：向上/向下/向左/向右
   - 强度：1-10 特斯拉 (T)

2. **电流条 (I)**
   - 方向：正向/反向
   - 大小：5-100 安培 (A)

3. **弹丸质量 (m)**
   - 范围：0.1-100 千克 (kg)
   - 提供快捷按钮：1, 5, 10, 25, 50

### 游戏流程

1. 调节磁场、电流和弹丸参数
2. 观察"理论洛伦兹力方向"提示
3. 点击"发射弹丸"按钮
4. 观看弹丸轨迹动画
5. 查看射击结果和错误分析
6. 可选：点击"查看回放"分析操作步骤

## 样例配置

### 样例1: 命中靶心（推荐）
- 磁场：5T 向上
- 电流：30A 正向
- 质量：10kg
- 预期：水平飞行，命中中间靶位

### 样例2: 向上偏转
- 磁场：8T 向上
- 电流：50A 正向
- 质量：5kg
- 预期：明显向上偏转，命中小靶

### 样例3: 方向反向测试
- 磁场：5T 向下
- 电流：30A 反向
- 质量：10kg
- 预期：触发方向待确认警告

### 样例4: 能量测试
- 磁场：3T 向上
- 电流：80A 正向
- 质量：2kg
- 预期：高速飞行，注意能量阈值

## 错误类型说明

| 错误类型 | 严重程度 | 说明 | 下一步 |
|---------|---------|------|-------|
| 方向反判 | 待确认 | 计算方向与预期相反 | 复核左手定则 |
| 能量超限 | 警告 | 动能超过安全阈值 | 联系竞赛社核实 |
| 质量缺失 | 错误 | 质量超出有效范围 | 重新设置参数 |

## 物理竞赛社复盘指南

### 反查路径
```
结果偏差 → 磁场板设置 → 电流条设置 → 弹丸质量
```

### 关键检查点
1. 查看回放中标记"触发模拟"的操作
2. 方向错误走待确认分支，需人工复核
3. 能量超限需联系器材管理员
4. 从结果反查参数，找出导致偏差的关键修改

## 技术栈

- React 18 + TypeScript
- Vite 构建工具
- TailwindCSS 样式框架
- Zustand 状态管理
- Canvas 2D 物理模拟
- Lucide React 图标库
