## 1. 产品概述

车间缺陷圈选工具是一款面向车间巡检与教学场景的缺陷管理应用，支持在车间平面图上圈选、标注缺陷，按颜色规则分类，筛选异常项并追踪处理状态。目标用户为车间巡检员（日常操作）和实训学生（只读查看）。

- 解决问题：车间缺陷分散在纸质记录与口头交接中，颜色规则与底图坐标对不上时容易遗漏或重复，离线素材缺失混入正常结果导致误判
- 核心价值：导入即筛异常、点进即看来源与处理意见、导出与界面摘要严格一致、重复导入不会产生冲突结论

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 巡检员 | 默认进入完整视图 | 圈选标注、导入导出、编辑处理意见、颜色规则管理 |
| 学生 | 切换至学生视图 | 只查看最终结论页，不可编辑 |

### 2.2 功能模块

1. **图层管理页**：车间列表、各图层状态总览、快速入口
2. **画布编辑页**：车间平面图底图、缺陷圈选工具、颜色规则侧栏、图层叠加控制
3. **缺陷列表页**：异常筛选、状态过滤、批量操作、导入导出入口
4. **缺陷详情页**：来源信息、处理意见、状态流转记录、坐标定位

## 3. 核心流程

### 3.1 日常巡检流程

巡检员打开图层管理，进入车间画布，在平面图上圈选缺陷区域，选择颜色规则分类，保存后缺陷进入列表。月底或课前查看画布状态，确认所有异常已处理。

```mermaid
flowchart TD
    "打开图层管理" --> "选择车间"
    "选择车间" --> "进入画布编辑"
    "进入画布编辑" --> "圈选缺陷区域"
    "圈选缺陷区域" --> "选择颜色规则分类"
    "选择颜色规则分类" --> "保存缺陷记录"
    "保存缺陷记录" --> "缺陷进入列表(待确认)"
    "缺陷进入列表(待确认)" --> "填写处理意见"
    "填写处理意见" --> "状态流转(已通过/已驳回/已处理)"
    "状态流转(已通过/已驳回/已处理)" --> "月底/课前查看画布状态"
```

### 3.2 导入与去重流程

上传 CSV/JSON 后系统自动筛选异常（离线素材缺失、颜色规则不匹配、坐标偏移），标记为"待确认"。对已存在的同一缺陷（相同位置+同类型），仅追加补录不新增结论。

```mermaid

    "上传 CSV/JSON" --> "解析数据"
    "解析数据" --> "自动筛选异常"
    "自动筛选异常" --> "离线素材缺失?"
    "离线素材缺失?" -->|"是"| "标记素材缺失警告"
    "离线素材缺失?" -->|"否"| "颜色规则匹配?"
    "标记素材缺失警告" --> "颜色规则匹配?"
    "颜色规则匹配?" -->|"否"| "标记规则不匹配"
    "颜色规则匹配?" -->|"是"| "坐标偏移检测"
    "标记规则不匹配" --> "坐标偏移检测"
    "坐标偏移检测" --> "重复检测"
    "重复检测" --> "存在同一缺陷?"
    "存在同一缺陷?" -->|"是"| "追加补录(不新增结论)"
    "存在同一缺陷?" -->|"否"| "新增缺陷记录"
```

### 3.3 导出一致性校验流程

导出前自动对比界面摘要与待导出数据，确保状态一致。不一致时阻断导出并提示差异项。

```mermaid
flowchart TD
    "点击导出" --> "读取界面当前摘要"
    "读取界面当前摘要" --> "读取待导出数据"
    "读取待导出数据" --> "对比状态字段"
    "对比状态字段" --> "一致?"
    "一致?" -->|"是"| "生成导出文件"
    "一致?" -->|"否"| "阻断导出并提示差异项"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深铁灰（#2D2D2D）作为背景，警示橙（#E87722）作为强调色，工业绿（#4CAF50）表示通过/正常
- **辅助色**：冷灰蓝（#607D8B）用于次要信息，红色（#D32F2F）用于异常/驳回
- **按钮风格**：轻微圆角（4px），扁平化为主，重要操作用实底色按钮
- **字体**：思源黑体 Noto Sans SC 为主字体，12px/14px/16px 三档正文，20px 标题
- **布局风格**：左侧固定侧栏 + 右侧主内容区，顶部简洁导航栏
- **图标**：Lucide 线性图标，线条感强，与工业风格匹配
- **整体风格**：工业实用主义（Industrial Utilitarian），不花哨，信息密度适中，功能优先

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|

### 4.3 响应式策略

- 桌面优先设计，最小支持 1280px 宽度
- 画布编辑页在窄屏下侧栏可折叠为抽屉
- 学生视图简化布局，单列展示结论卡片

### 4.4 学生视图

- 隐藏所有编辑入口，只展示最终结论页
- 不显示导入导出、颜色规则编辑、图层管理操作
- 缺陷列表只显示已处理的最终结论，按类型汇总统计
- 底部显示"数据仅供教学参考"水印
