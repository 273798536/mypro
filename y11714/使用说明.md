# 碰撞恢复系数实验工具 - 使用说明

## 🚀 快速开始

### 启动方式
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后访问：http://localhost:5173/

---

## 🎮 主要操作流程

### 1. 设置实验参数
在右侧控制面板中调整：
- **小球质量**：0.001kg - 10kg，滑块或数值输入
- **地面材质**：从下拉菜单选择（水泥、木质、橡胶、玻璃、泥土、海绵）
- **恢复系数**：0 - 1，可自定义或跟随材质预设

### 2. 调整下落高度
- 鼠标移动到蓝色小球上
- 按住左键拖动小球上下移动
- 左侧会显示实时高度 h = X.XXm
- 释放鼠标确定高度

### 3. 开始实验
- 点击 **▶ 开始实验** 按钮释放小球
- 观察小球下落和反弹过程
- 实验完成后自动显示结果

### 4. 慢放与回放
- **播放速度**：0.1x - 1x，拖动滑块调整
- **暂停/继续**：实验中可随时暂停
- **单步前进**：暂停后可逐帧观察
- **重置**：回到初始状态重新实验

### 5. 保存与导出
- **💾 保存实验记录**：将当前实验存入本地数据库
- **📸 导出截图**：保存带数据的实验画面
- **导出CSV**：导出所有实验数据表格
- **📄 下载报告**：每条记录可单独下载Markdown报告

## ⚠️ 异常情况说明

系统会自动检测以下异常情况，出现异常时数据会被标记：

### 1. 能量增加 (ENERGY_INCREASE)
- **现象**：反弹高度 > 下落高度
- **原因**：参数设置错误或物理引擎计算偏差
- **提示**：红色告警框显示，记录标记为异常

### 2. 碰撞穿透 (COLLISION_PENETRATION)
- **现象**：小球穿透地面
- **原因**：时间步长过大或速度过快
- **提示**：黄色告警框显示

### 3. 参数越界
- 质量超出 0.001kg - 10kg 范围
- 恢复系数超出 0 - 1 范围
- **提示**：输入框下方红色文字提示，无法开始实验

## 📊 数据解释

### 恢复系数计算公式
```
e = √(h₂ / h₁)

其中：
- h₁ = 下落高度（米）
- h₂ = 反弹高度（米）
- e  ∈ [0, 1]
```

### 结果解读
| 恢复系数 | 碰撞类型 | 说明 |
|---------|---------|------|
| e = 1 | 完全弹性碰撞 | 无能量损失，反弹高度 = 下落高度 |
| 0.7 < e < 1 | 高弹性碰撞 | 如：橡胶、玻璃 |
| 0.3 < e < 0.7 | 中等弹性 | 如：木质、水泥地面 |
| 0 < e < 0.3 | 低弹性碰撞 | 如：泥土、海绵 |
| e = 0 | 完全非弹性 | 碰撞后不反弹 |

### 能量损失计算
```
能量损失% = (1 - h₂/h₁) × 100%
```

## 🔬 测试数据建议

### 标准测试用例
| 测试场景 | 质量 | 材质 | 预期恢复系数 |
|---------|------|------|-------------|
| 水泥地面 | 1kg | 混凝土 | ~0.6 |
| 橡胶高弹 | 1kg | 橡胶垫 | ~0.85 |
| 玻璃弹性 | 1kg | 玻璃 | ~0.9 |
| 泥土低弹 | 1kg | 泥土 | ~0.3 |

### 边界测试
1. **极小质量**：0.001kg，观察是否正常计算
2. **极大质量**：10kg，验证惯性效果
3. **极高高度**：10m，测试最大量程
4. **极低高度**：0.01m，测试灵敏度
5. **极端系数**：e=0（不反弹）、e=0.99（高反弹）

## 🐛 常见问题

**Q: 小球不反弹？**
A: 检查恢复系数是否设置为0，或选择了"海绵"材质

**Q: 反弹高度异常高？**
A: 检查是否出现"能量增加"异常提示，可能是参数设置问题

**Q: 实验记录不见了？**
A: 清除浏览器缓存会导致数据丢失，建议及时导出CSV备份

**Q: 画面卡顿？**
A: 尝试降低播放速度，或减少同时进行的实验次数
