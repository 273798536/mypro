## 1. 产品概述

交响乐声部覆盖图工具，面向声学顾问，提供3D可视化声场分析能力，解决声部遮挡检测、吸声材料参数追踪、乐手位置与声压对应关系复核等痛点。系统自动保留参数变更与操作溯源记录，避免依赖聊天截图确认结果。

- 目标用户：声学顾问、音乐厅设计工程师
- 核心价值：参数变更后3D场景与侧边数据实时联动，声部遮挡时自动给出原因与处理建议，操作全程可追溯

## 2. 核心功能

### 2.1 功能模块

1. **主工作台**：3D声场可视化 + 侧边数据面板 + 时间轴控制 + 截图导出 + 遮挡告警

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主工作台 | 3D声场场景 | Three.js渲染交响乐舞台，展示乐手位置、声压辐射锥、吸声材料区域；支持旋转/缩放/拖动乐手 |
| 主工作台 | 侧边数据面板 | 实时显示当前选中乐手的声压、位置坐标、所属声部、吸声材料参数；参数变更自动同步3D场景 |
| 主工作台 | 声部筛选器 | 按声部（弦乐/木管/铜管/打击乐）筛选显示，筛选后3D场景和声压数据同步更新 |
| 主工作台 | 时间轴播放 | 模拟演奏进程，随时间轴移动高亮不同声部进入，3D声场动态更新 |
| 主工作台 | 遮挡检测面板 | 自动检测声部遮挡关系，显示遮挡原因（前方乐手/材料阻挡/位置偏移）及处理建议 |
| 主工作台 | 截图导出 | 导出当前3D视图+数据快照为PNG，附带参数水印和溯源链接 |
| 主工作台 | 操作溯源日志 | 记录所有参数变更、筛选操作、截图导出事件，支持点回来源查看当时状态 |
| 主工作台 | 详情面板 | 展示乐手位置↔乐器声压↔报告说明的对应关系，方便复核 |

## 3. 核心流程

用户打开主工作台 → 加载交响乐布局与样例数据 → 通过侧边面板调整乐手位置/声压/材料参数 → 3D场景实时更新 → 系统自动检测遮挡并弹出告警 → 点击告警查看原因与建议 → 拖动时间轴观察声部变化 → 筛选声部细化分析 → 导出截图并自动记录操作 → 通过溯源日志回溯任意操作

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝黑（#0a0e1a）背景 + 琥珀金（#d4a855）强调色，营造音乐厅暗场氛围
- 辅助色：冰蓝（#4fc3f7）声压辐射、珊瑚红（#ef5350）遮挡告警、翠绿（#66bb6a）正常状态
- 按钮：圆角6px，悬浮微光边框，暗色底+金/蓝文字
- 字体：JetBrains Mono（数据区）+ Noto Sans SC（中文界面）
- 布局：左侧3D场景占70%，右侧数据面板30%，底部时间轴条

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主工作台 | 3D声场场景 | 深色背景+网格地面，乐手为发光柱体，声压为半透明锥体，吸声材料为色块平面 |
| 主工作台 | 侧边数据面板 | 暗色卡片列表，数值用等宽字体，变更项金色高亮 |
| 主工作台 | 遮挡检测面板 | 右侧滑出面板，遮挡项红色标记，建议蓝色标记，可点击跳转3D位置 |
| 主工作台 | 时间轴 | 底部横向滑块，声部进入点标注，播放/暂停按钮 |
| 主工作台 | 截图导出按钮 | 右上角相机图标，点击弹出缩略预览+导出按钮 |
| 主工作台 | 溯源日志 | 右下角可折叠列表，每条带时间戳+参数快照摘要 |

### 4.3 响应式

桌面优先设计，最小支持1280px宽度；3D场景可自适应缩放，面板可折叠

### 4.4 3D场景指导

- 环境：深色空间，模拟音乐厅暗场环境，底部微光网格
- 灯光：环境光（低强度暖白）+ 聚光灯（从舞台上方照射）+ 乐手点光源（按声压强度变化）
- 相机：透视相机，默认俯视45度，支持轨道控制（旋转/缩放/平移）
- 声压可视化：半透明锥体从乐手位置向前辐射，颜色从中心到边缘渐变
- 遮挡可视化：遮挡区域红色高亮，虚线连接遮挡源与被遮挡目标
- 吸声材料：半透明平面，按吸声系数着色（低吸声偏蓝，高吸声偏绿）
- 交互：点击乐手高亮+弹出详情，拖动乐手改变位置，鼠标悬停显示声压值
