# 数值积分能耗估算系统 - 运行说明

## 新同事5分钟上手指南

### 第一步：准备环境（从空目录开始）

```bash
# 1. 确认项目目录结构
ls -la
# 应该看到: src/ data/ output/ requirements.txt main.py

# 2. 安装依赖（首次运行）
pip3 install -r requirements.txt
```

### 第二步：生成示例数据（或准备你自己的数据）

```bash
# 生成包含各种数据质量问题的示例数据（用于演示）
python3 data/raw/generate_sample_data.py
```

**如果你有自己的数据：**
- 支持格式: `.csv`, `.xlsx`, `.xls`
- 数据格式要求:
  - 必须有一列时间（列名含"时间"/"time"/"日期"等可自动识别，或手动指定）
  - 其余数值列会被识别为用电读数列
  - 示例格式:
    ```
    时间,主回路,照明回路,空调回路
    2026-06-01 00:00:00,85.2,120.5,62.3
    2026-06-01 00:15:00,88.7,118.9,65.1
    ...
    ```

### 第三步：一键运行（最简方式）

```bash
# 使用示例数据，默认参数
python3 main.py

# 或者指定你的数据文件
python3 main.py --input 你的数据文件.csv
```

运行完成后，你会在 `output/` 目录下看到所有输出文件。

## 常见使用场景

### 场景1：按日统计用电量

```bash
python3 main.py --input data/raw/sample_load_data.csv --group-by D
```

### 场景2：使用辛普森法提高积分精度

```bash
python3 main.py --method simpsons
```

### 场景3：指定单位（数据单位不是kW时）

```bash
# 主回路单位是W（瓦），照明回路是kW
python3 main.py --units 主回路=W 照明回路=kW
```

### 场景4：只统计指定时间范围

```bash
python3 main.py --start-time "2026-06-01 08:00:00" --end-time "2026-06-01 18:00:00"
```

### 场景5：排除负值和空值

```bash
python3 main.py --exclude-negative
```

## 完整参数说明

```
--input, -i      输入数据文件路径（默认: data/raw/sample_load_data.csv）
--time-column,-t 时间列名（自动检测，特殊格式时手动指定）
--columns, -c    指定要计算的读数列（默认全部数值列）
--units          各列单位，如: 主回路=kW 照明回路=W
--group-by, -g   分组口径: total(全部)/H(小时)/D(日)/W(周)/M(月)/Q(季)/Y(年)
--method, -m     积分方法: trapezoidal(梯形法)/simpsons(辛普森法)
                 left_riemann(左矩形)/right_riemann(右矩形)
--start-time     筛选起始时间，格式: YYYY-MM-DD HH:MM:SS
--end-time       筛选结束时间
--exclude-negative  排除负值读数
--no-charts      不生成图表（加快速度）
```

## 数据质量问题说明

系统会自动检测并分类说明以下问题：

| 问题类型 | 通俗说法 | 可能原因 | 影响 |
|----------|----------|----------|------|
| 缺采样 | 采样中断 | 网络断了、仪表断电 | 缺失时段是估算的 |
| 时间乱序 | 顺序错了 | 数据传输延迟 | 不修正会算错 |
| 负值读数 | 出现负数 | 仪表故障、反向送电 | 需要现场核实 |
| 空值读数 | 数据空缺 | 个别丢包 | 影响小，自动补 |

**注意：所有问题都会在报告中分别说明，不会笼统归为"数据异常"。**

## 数值积分方法选择

| 方法 | 精度 | 适用场景 | 备注 |
|------|------|----------|------|
| 梯形法 | 中等 | 大多数情况 | 默认，稳健 |
| 辛普森法 | 高 | 等间隔采样、数据点为奇数 | 精度高，要求严格 |
| 左/右矩形 | 低 | 快速估算、均匀负荷 | 可能高估或低估 |

**计算公式（以梯形法为例）：**
```
每个时段能耗 = (起始功率 + 结束功率) / 2 × 时间间隔(小时)
总能耗 = Σ 每个时段能耗
```

**单位转换（以W转kW为例）：**
```
kW = W × 0.001
能量(kWh) = 功率(kW) × 时间(h)
```

## 口径一致化机制

系统确保**筛选条件、图表、明细三者口径完全一致**：

1. 所有筛选条件（时间范围、通道选择、分组口径、积分方法）封装在 `FilterConfig` 中
2. 修改筛选条件时，调用 `modify_filter()` 自动重新计算
3. `sync_filter_to_all()` 同时输出图表数据、明细数据、汇总数据，使用完全相同的筛选条件

**示例：调整时间范围后重新计算**
```python
from src.filter_sync import modify_filter

# 修改时间范围，图表和明细会自动同步
new_result = modify_filter(
    existing_config=old_config,
    dataset=dataset,
    unit_report=unit_report,
    time_start=new_start,
    time_end=new_end
)
```

## 常见问题

### Q: 报告里的"数据质量评分"是怎么算的？
A: (有效数据点数 ÷ 总数据点数) × 100。每类问题按影响程度扣减。

### Q: 原始数据会被修改吗？
A: 不会。`dataset.raw_df` 永远保留原始读数，处理只在 `processed_df` 中进行。

### Q: 负值读数怎么处理？
A: 默认保留（因为可能是反向送电等正常情况），可以加 `--exclude-negative` 参数排除。

### Q: 辛普森法报错说需要奇数个点？
A: 辛普森法要求奇数个数据点，系统会自动把最后一个区间改用梯形法，并在报告中说明。

### Q: 导出给外行同事看时需要注意什么？
A: 直接发 `能耗估算报告_*.xlsx` 即可，内部字段名和技术术语已被替换为通俗说法。
