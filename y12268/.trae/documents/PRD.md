## 1. 产品概述

"债务偿还经营赛"是一款浏览器内单局制回合经营策略游戏，面向财经社学生，让玩家在基建投资、利息偿还与民生满意度之间寻找平衡。核心目标是让学生通过实操理解地方债运作机制——当项目卡结论与债务额度不一致时，满意度作为补充证据留在详情中；人工核利息漏算、项目延期凭印象、收入下滑被新版本覆盖等常见问题，均通过证据链保留与可导出经营报告加以解决。

- 目标用户：财经社教师及学生
- 核心价值：将抽象的地方债知识转化为可交互的经营博弈，所有计算口径留痕、可追溯、可分享

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 玩家（学生） | 直接打开浏览器 | 经营决策、查看证据链、导出报告 |
| 裁判（教师） | 同一浏览器复盘 | 查看结算、审计证据链、接收报告 |

### 2.2 功能模块

1. **开局页**：规则说明、难度选择、开始按钮
2. **经营主界面**：仪表盘、项目卡、操作区、证据日志
3. **结算页**：总分、扣分明细、项目收益扣分说明
4. **复盘页**：完整回合回放、证据链审计、报告导出

### 2.3 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 开局页 | 规则说明 | 图文展示游戏规则：收入来源、利息计算、满意度影响、胜负条件 |
| 开局页 | 难度选择 | 简单/普通/困难三档，影响初始债务、利率、满意度衰减速度 |
| 开局页 | 开始按钮 | 进入第1回合经营主界面 |
| 经营主界面 | 仪表盘 | 显示国库余额、总债务、综合利率、民生满意度、当前回合 |
| 经营主界面 | 项目卡区 | 每回合抽取2-3张项目卡（基建/民生/偿债），显示成本、预期收益、风险等级、延期概率 |
| 经营主界面 | 操作区 | 分配预算：基建投资、利息偿还、民生支出；确认结束回合 |
| 经营主界面 | 证据日志 | 实时记录每步操作的计算过程，标记利息漏算、项目延期、收入变动 |
| 经营主界面 | 暂停/重开 | 暂停冻结状态；重开回到开局页 |
| 结算页 | 总分展示 | 经营评分、债务健康度、满意度稳定性等维度评分 |
| 结算页 | 扣分明细 | 逐项列出项目收益造成的扣分，含计算口径与证据引用 |
| 结算页 | 一致性检查 | 项目卡结论与债务额度不一致时的标注，满意度作为补充证据 |
| 复盘页 | 回合回放 | 可逐回合查看所有决策与结果，支持时间线拖拽 |
| 复盘页 | 证据链审计 | 所有利息计算、项目延期、收入变动的完整记录，版本化不可覆盖 |
| 复盘页 | 报告导出 | 一键生成经营报告（JSON/HTML），含偿债计算口径说明，可直接转发同事 |

## 3. 核心流程

玩家从开局页选择难度后进入第1回合。每回合：系统抽取项目卡 → 玩家分配预算（基建/偿债/民生） → 结算回合收益与利息 → 检查满意度与债务阈值 → 证据日志记录全过程。当达到终局条件（回合用尽/满意度归零/债务失控）时进入结算页，展示评分与扣分明细。玩家可进入复盘页回放全过程并导出报告。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿（#0D1B1E）为底，琥珀金（#D4A843）为强调色——营造财政严肃感与经营紧张感
- **辅助色**：暗红（#8B2500）用于警告/扣分，青灰（#3A506B）用于信息面板
- **字体**：标题用 Noto Serif SC（宋体感、公文气质），正文用 Noto Sans SC
- **按钮风格**：圆角矩形（8px），金边填充按钮为主操作，灰色描边为次要操作
- **布局**：左侧仪表盘 + 中间项目卡与操作区 + 右侧证据日志，三栏布局
- **图标**：简约线性图标，金色线条

### 4.2 页面设计概览

| 页面 | 模块 | UI 要素 |
|------|------|---------|
| 开局页 | 规则说明 | 居中卡片式布局，深色背景金色边框，规则用图标+短文分块 |
| 开局页 | 难度选择 | 三张并排卡片，选中态金色高亮边框 |
| 经营主界面 | 仪表盘 | 左侧固定面板，数字用大号等宽字体，进度条显示满意度 |
| 经营主界面 | 项目卡区 | 中间区域，卡片横排，翻转动画展示详情，延期标记红色角标 |
| 经营主界面 | 操作区 | 中间底部，滑块分配预算，确认按钮金色 |
| 经营主界面 | 证据日志 | 右侧可滚动面板，条目带时间戳和类型图标，利息/延期/收入三类颜色区分 |
| 结算页 | 总分展示 | 顶部大号分数，雷达图展示各维度 |
| 结算页 | 扣分明细 | 可展开列表，每项引用证据日志条目，口径说明用小字灰色标注 |
| 复盘页 | 回合回放 | 底部时间线滑块，上方重现对应回合状态快照 |
| 复盘页 | 证据链审计 | 表格式，支持筛选（利息/延期/收入），版本号标注 |
| 复盘页 | 报告导出 | 底部操作栏，JSON和HTML两种格式按钮 |

### 4.3 响应式

- 桌面优先设计，最小支持 1024px 宽度
- 1024-1280px：三栏布局，证据日志可折叠
- 1280px+：三栏全展开，最佳体验

### 4.4 动效

- 回合开始：项目卡从上方滑入，轻微弹跳
- 利息计算：数字滚动动画
- 满意度变化：进度条平滑过渡，低于阈值时红色脉冲
- 项目延期：卡片抖动 + 红色角标渐显
- 结算页加载：分数从0滚动到最终值
- 证据日志新增：条目从右侧滑入，带淡入效果
