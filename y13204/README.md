# 巡演耳返分账对齐 - 材料处理系统

音乐老师林姐专用：把排练群里零散的材料串成一条完整的处理链，让老师一眼就能看到学生哪里进步了。

## 快速开始

### 第1步：扫描材料
```bash
python -m src.cli scan ./materials
```
读取 `materials/` 目录下所有材料，自动识别授权到期、关联晚到附件、生成处理状态。

### 第2步：查看报告
```bash
python -m src.cli review
```
打开上次处理的 Markdown 报告，查看：
- `reports/分账对齐报告.md` - 分账明细与对齐状态
- `reports/学生进步分析.md` - 每个学生的进步点追踪

### 第3步：添加备注
```bash
python -m src.cli note "排练时学生A的高音稳了"
python -m src.cli note --type auth "授权到期日调整为2026-07-15"
```

### 第4步：重扫（新增备注后）
```bash
python -m src.cli scan ./materials --rescan
```
保留历史备注、关联旧版本、重新生成报告。

### 第5步：导出交付
```bash
python -m src.cli export ./delivery
```
导出带标记的完整材料包，包含：
- 所有原始材料（授权到期带⚠️标记）
- 历史版本对比
- 人工批注
- 最终交付清单

## 目录结构

```
.
├── materials/          # 现场收到的材料（排练群截图、附件、授权文件）
├── data/               # 处理状态持久化（重启不丢失）
│   └── state.json      # 历史备注、当前状态、版本追踪
├── reports/            # 生成的 Markdown 报告
├── src/                # 源代码
└── tests/              # 测试用例
```

## 核心特性

✅ **重启不丢状态** - 服务重启再打开，复核人仍能看到前一次处理状态和报告  
✅ **晚到附件关联** - 自动把最后到的附件和最终结论连起来  
✅ **授权到期标记** - 筛选、详情、导出处处留标记  
✅ **版本对齐** - 旧版本、人工批注、交付清单彼此对应  
✅ **处理链透明** - 老师只想知道学生哪里进步，报告里讲得清清楚楚
