# 光学薄透镜成像器

面向初中物理教学的 Web3D 交互工具，通过可视化方式展示薄透镜成像原理。

## 🚀 快速开始

### 启动项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

访问 http://localhost:5173 即可使用。

## 📚 使用说明

### 主要操作

1. **调整参数**
   - 拖拽「焦距 f」滑块：改变透镜焦距（2-30cm）
   - 拖拽「物距 u」滑块：改变物体到透镜的距离（1-60cm）

2. **3D 视角控制**
   - 鼠标左键拖拽：旋转视角
   - 鼠标滚轮：缩放场景
   - 鼠标右键拖拽：平移场景

3. **保存步骤**
   - 点击控制面板的 💾 按钮：保存当前参数配置
   - 步骤自动记录时间戳和来源
   - 点击步骤记录可快速回退到历史状态

4. **导出截图**
   - 点击右上角「导出截图」按钮
   - 自动生成带参数标注的 PNG 图片

### 异常情况提示

| 状态 | 提示级别 | 说明 |
|------|---------|------|
| 🔴 焦点附近 | 严重 | 物距接近焦距，光线接近平行 |
| 🟠 成虚像 | 警告 | 像距为负，无法在光屏呈现 |
| 🔵 正立像 | 信息 | 放大率为正，通常为虚像 |
| 🟢 正常成像 | - | 参数正常，成像清晰 |

### 物理公式

- **透镜公式**: `1/f = 1/u + 1/v`
- **放大率**: `m = -v/u = hᵢ/hₒ`
- **符号规则**：
  - 物距 u：实物为正
  - 焦距 f：凸透镜为正
  - 像距 v：实像为正，虚像为负
  - 放大率 m：正表示正立，负表示倒立

## 🎯 典型实验场景

| 物距范围 | 像的性质 | 应用 |
|-----------|---------|------|
| u > 2f | 倒立、缩小、实像 | 照相机 |
| u = 2f | 倒立、等大、实像 | 测焦距 |
| f < u < 2f | 倒立、放大、实像 | 投影仪 |
| u = f | 不成像（平行光） | 探照灯 |
| u < f | 正立、放大、虚像 | 放大镜 |

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **3D 渲染**: Three.js + React Three Fiber
- **状态管理**: Zustand
- **样式**: TailwindCSS + Framer Motion
- **构建工具**: Vite

## ⚠️ 注意事项

1. 光线追迹显示三条典型光线：
   - 平行于主光轴的光线 → 经过像方焦点
   - 经过光心的光线 → 方向不变
   - 经过物方焦点的光线 → 平行于主光轴出射

2. 数据保存在浏览器 localStorage 中，刷新页面不会丢失步骤记录。

3. 截图导出功能需要浏览器支持 WebGL 和 Canvas 特性。
