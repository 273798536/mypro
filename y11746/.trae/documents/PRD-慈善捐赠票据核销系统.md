# 慈善捐赠票据核销系统 PRD

## 1. 产品概述

基金会财务票据核销管理系统，解决多来源数据整合、定向项目分类、实物捐赠估值、退款票据冲销等核心痛点，确保月底给捐赠人开票的准确性。

- 解决问题：实物估值缺失、项目错挂、退款后票据未冲等异常情况的自动检测与提示
- 目标用户：基金会财务人员、票据管理员
- 核心价值：理清流程、保留溯源、异常预警、报告导出

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 财务管理员 | 系统内置 | 数据导入、核销处理、异常查看、报告导出 |

### 2.2 功能模块

1. **数据导入**：多来源数据导入（捐赠流水、项目标签、实物估值、退款记录、票据号码、核销报告）、样例数据加载
2. **核销工作台**：票据状态管理、项目归集、退款冲销处理
3. **异常检测**：自动检测异常（实物估值缺失、项目错挂、退款未冲）、保留原始行号
4. **修正痕迹**：数据溯源、修改历史记录
5. **报告导出**：核销报告生成、Excel/CSV 下载

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 文件上传区 | 支持 CSV/Excel 多文件批量上传，显示来源标识 |
| 数据导入页 | 样例数据 | 一键加载演示数据，包含各种异常场景 |
| 数据导入页 | 数据预览 | 表格展示导入数据，高亮异常行，保留原始行号 |
| 核销工作台 | 票据概览 | 统计正常/异常/待核销/已冲销票据数量 |
| 核销工作台 | 项目归集 | 按定向项目分类展示捐赠明细 |
| 核销工作台 | 退款冲销 | 退款记录与票据关联，自动冲销标记 |
| 异常清单页 | 异常分类 | 按类型分组显示异常（估值缺失/项目错挂/退款未冲） |

| 报告导出页 | 报告预览 | 核销汇总报表、异常明细报表预览 |
| 报告导出页 | 下载功能 | 支持 Excel、CSV 格式导出 |
| 修正痕迹页 | 修改历史 | 展示所有修正记录、操作人、时间、前后值对比 |

## 3. 核心流程

```mermaid
flowchart LR
    A["导入多来源数据"] --> B["样例数据/上传文件"]
    B --> C["数据校验与预处理"]
    C --> D["自动检测异常"]
    D --> E["核销处理"]
    E --> F["项目归集"]
    E --> G["退款冲销"]
    F --> H["生成核销报告"]
    G --> H
    D --> I["异常清单展示"]
    I --> J["人工修正"]
    J --> E
    H --> K["导出报告"]
```

**流程说明**：
1. 财务人员导入捐赠流水、项目标签、实物估值、退款记录、票据号码等数据
2. 系统自动校验数据完整性，检测异常（估值缺失、项目错挂、退款未冲等）
3. 异常数据进入异常清单，保留原始行号和来源，供人工修正
4. 正常数据进入核销流程，进行项目归集和退款冲销
5. 生成核销报告，支持导出下载
6. 所有修正操作保留痕迹，支持溯源

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青色 #0F52BA（专业、稳重），搭配白色背景
- **辅助色**：
  - 正常状态：绿色 #10B981
  - 异常状态：红色 #EF4444
  - 警告状态：橙色 #F59E0B
  - 待处理：蓝色 #3B82F6
- **按钮风格**：圆角 6px，微阴影，悬停有轻微上浮效果
- **字体**：系统无衬线字体，标题 16-18px，正文 14px
- **布局风格**：卡片式布局，左侧导航 + 主内容区
- **图标风格**：简约线性图标，使用 emoji 增强辨识度

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 上传区域 | 拖拽上传框，文件列表，来源标签，进度条 |
| 核销工作台 | 统计卡片 | 四色统计卡片（正常/异常/待核销/已冲销），数字动效 |
| 核销工作台 | 数据表格 | 可筛选、可排序、行号列、异常高亮、操作列 |
| 异常清单页 | 分类标签 | 异常类型 Tab 切换，数量徽标 |
| 异常清单页 | 异常卡片 | 红色边框，错误图标，原始行号，修正按钮 |
| 报告导出页 | 报告预览 | 表格预览，分页，导出按钮组 |
| 修正痕迹页 | 时间线 | 垂直时间线，前后值对比，来源链接 |

### 4.3 响应式

- 桌面端优先设计（1280px+）
- 平板端（768px-1279px）：导航收缩，表格横向滚动
- 移动端（<768px）：简化视图，核心功能保留

### 4.4 动效设计

- 页面加载：顶部进度条，内容淡入
- 表格行：悬停背景色变化
- 异常提示：轻微抖动动画 + 红色脉冲
- 统计数字：计数动画
- 按钮：点击缩放反馈
