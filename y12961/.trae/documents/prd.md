# 分库分表路由检查看板 — 产品需求文档（PRD）

## 1. 产品概述

为安全审计员提供一套"分库分表路由检查"看板，把同事交来的备份记录、数据字典、慢查询日志三类口径不一的材料，归并到同一批数据里做检查；图表、明细与下载结果同源，审计变更前后差别、权限越权复核历史、外键断链卡点、备份记录新旧结论全部可追溯。

- 解决的问题：材料口径不一、人工猜影响范围、报告看不出问题卡在哪份材料上
- 目标用户：安全审计员、审计组（只看最后报告的角色）
- 价值：把"分库分表路由检查"从人工猜变成可追溯的看板，每条结论都能回溯到材料与变更人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 安全审计员 | 日常真跑检查、复核越权、对比备份记录 | 查看全部、下载结果、切换批次 |
| 审计组 | 只看最后报告，定位问题卡点 | 只读报告与断链卡点跳转 |

### 2.2 功能模块

1. **总览看板页**：批次指示器、KPI、图表、下载结果（同源数据）
2. **路由明细页**：路由规则明细表、按库/状态/材料筛选、行级关联材料
3. **Schema 对比页**：前后版本列级 diff，标注由权限审计变更触发的差别
4. **审计追踪页**：权限越权复核历史（who/when/why）+ 外键断链卡在哪份材料
5. **备份记录对比页**：备份记录被改后的新旧结论并排 + 影响范围 + 真实坏数据样例

### 2.3 页面明细

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 总览看板页 | 批次指示器 | 显示当前批次号、生成时间、三类材料覆盖状态，全局唯一数据源标识 |
| 总览看板页 | KPI 卡片 | 路由总数、通过/未通过数、阻断问题数、材料覆盖率 |
| 总览看板页 | 图表区 | 分片分布(按库)、各材料检查结果(堆叠)、问题严重度分布(环形)，均来自同一批数据 |
| 总览看板页 | 下载结果 | 导出 CSV/JSON，数据与图表明细同源 |
| 路由明细页 | 明细表 | 路由规则、分片键、目标库表、检查结果、关联材料、问题说明 |
| 路由明细页 | 筛选与展开 | 按库/状态/材料筛选，行展开显示检查依据来自哪份材料 |
| Schema 对比页 | 前后版本 diff | 列级新增/修改/删除，高亮"判断变更来源" |
| Schema 对比页 | 变更关联 | 标注哪些 diff 由权限审计变更触发，可跳转审计记录 |
| 审计追踪页 | 权限越权复核历史 | 记录谁改、何时改、为什么改、变更内容、复核状态 |
| 审计追踪页 | 外键断链追踪 | 断链链路 + 卡在哪份材料上 + 跳转到该材料 |
| 备份记录对比页 | 新旧结论并排 | 旧结论 vs 新结论并排，不再让审计员猜影响范围 |
| 备份记录对比页 | 影响范围 | 列出受影响的路由/库表 |
| 备份记录对比页 | 真实坏数据样例 | 高亮那条够真实的坏数据（分片标注错 + 时间口径不一致） |

## 3. 核心流程

安全审计员选择批次后，看板从同一批数据加载：图表展示概览 → 明细可下钻到具体路由 → 发现问题后，Schema 对比看前后差别并关联权限审计 → 审计追踪页确认谁改的/何时改/为什么改、外键断链卡在哪份材料 → 备份记录对比页并排看新旧结论与影响范围，最后下载同源结果。

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深色审计控制台底（#0a0b0e），主强调色天蓝 #38bdf8，辅以琥珀 #fbbf24（告警）、玫红 #fb7185（阻断/失败）、翡翠 #34d399（通过）
- 按钮风格：圆角矩形、细边框、hover 微抬升与描边发光
- 字体：标题 Sora（几何现代），数据/等宽 JetBrains Mono（终端审计感），正文 Sora
- 布局：左侧固定导航 + 顶栏批次指示器，卡片栅格 + 内部滚动
- 图标：lucide-react 线性图标

### 4.2 页面设计概览

| 页面 | 模块 | UI 要素 |
|------|------|---------|
| 总览看板页 | 批次指示器 | 顶栏胶囊，等宽字体批次号，材料覆盖圆点 |
| 总览看板页 | KPI 卡片 | 深色卡片、大号等宽数字、状态色描边 |
| 总览看板页 | 图表区 | recharts 柱/堆叠/环形，统一配色与图例 |
| 路由明细页 | 明细表 | 斑马行、状态徽章、行展开抽屉 |
| Schema 对比页 | diff | 双栏并排 + 行级 +/- 高亮 |
| 审计追踪页 | 时间线 | 垂直时间线 + 材料卡跳转 |
| 备份记录对比页 | 并排对比 | 左旧右新双卡 + 影响范围列表 + 坏数据高亮 |

### 4.3 响应式

桌面优先（审计控制台场景），平板自适应收起侧栏，移动端简化为单列卡片堆叠。

### 4.4 3D 场景

不适用。
