# 安全拒答样本归因系统 - 操作说明

> 本文档仅说明核心操作步骤：启动、导入、查看异常、导出结果。不是宣传页。

---

## 一、启动系统

### 1. 启动开发服务器
```bash
npm install
npm run dev
```

### 2. 系统首页
系统启动后自动进入启动页，包含：
- **四步操作指引**：启动 → 导入 → 查看异常 → 导出结果
- **快速体验入口**：一键加载贴近日常的样例数据（推荐首次使用）
- **真实数据导入入口**：前往导入页面上传Excel/CSV文件

### 3. 快速体验（推荐）
点击「加载样例数据并开始分析」按钮，系统将：
1. 自动生成50条贴近日常工作场景的样例数据
2. 包含：25%旧表导入、20%补录备注、10%漏填单位、45%正常录入
3. 自动绑定提示词版本并创建统一处理记录
4. 跳转到分析页面

---

## 二、导入数据

### 1. 选择/创建提示词版本
> 重要：必须先绑定提示词版本，避免"晚到半天"问题

**选择现有版本：**
- 右侧版本列表显示所有已有的提示词版本
- 点击选择对应版本（有风险的版本会标红⚠️）
- 查看版本发布时间（精确到小时）、内容、变更说明

**创建新版本：**
1. 点击版本列表右上角的「+」按钮
2. 填写版本号（如：v1.3）
3. 填写提示词内容
4. 填写版本说明（可选）
5. 填写变更内容（逗号分隔）
6. 点击「创建版本」

### 2. 上传数据文件
**支持格式：**
- Excel (.xlsx, .xls)
- CSV (.csv)

**上传方式：**
1. 拖拽文件到虚线框区域
2. 或点击「选择文件」按钮

**数据格式要求：**
| 列名 | 说明 | 示例 |
|------|------|------|
| content | 样本内容（必填） | 用户询问如何办理信用卡... |
| unit | 计量单位 | 个、条、次、元 |
| annotation_label | 人工标注标签 | 业务咨询、投诉建议 |
| security_label | 安全标签 | 正常、敏感、拒答 |
| remark | 备注 | 张三补录2024-01-15 |

### 3. 导入结果
导入成功后显示：
- 总数据条数
- 各类问题统计（漏填单位、旧表导入、补录备注）
- 点击「前往分析」进入归因分析页面

---

## 三、查看异常

### 1. 运行归因分析
首次进入分析页面时：
1. 确认数据已加载（页面显示样本总数）
2. 点击「运行归因分析」按钮
3. 系统自动执行：
   - 安全规则匹配（8条预设规则）
   - 异常检测（规则漏配、标签冲突、漏填单位、格式错误）
   - 标签冲突检测（与上一版本对比）
   - 生成分布统计

### 2. 三者对齐视图
分析完成后页面分为三个联动区域：

**① 上方图表区**
- **分布统计图**：内环显示数据来源分布，外环显示异常类型分布
- **规则匹配热力图**：显示各安全规则的命中/未命中情况
- 点击图表数据点可筛选表格数据

**② 下方数据表格**
- 显示所有样本的明细信息
- 异常样本用橙色⚠️标记，显示异常数量
- 有标签冲突的样本会高亮闪烁
- 点击行查看样本详情

**③ 右侧说明面板**
- **分析摘要**：文字说明分布统计结果
- **样本详情**：点击表格行后显示该样本的完整信息
  - 样本内容、来源类型、单位、标签
  - 异常列表（含自然语言描述）
  - 匹配的安全规则
  - 「追溯异常原因」链接

### 3. 三者对齐验证
点击「验证三者对齐」按钮：
- 系统自动验证图表、表格、文字说明的数据一致性
- 验证通过显示绿色✓，有问题显示红色✗并列出问题

### 4. 查看异常详情
点击样本详情中的「追溯异常原因」链接，进入异常详情页：

**追溯链路（从上到下）：**
1. **异常样本** - 点击展开查看样本完整信息
2. **关联安全规则** - 查看规则描述、匹配条件、状态
3. **漏配原因说明** - 自然语言描述，非技术人员可读
4. **处理意见** - 查看系统建议，填写人工处理意见

**处理异常：**
1. 点击「填写处理意见」
2. 输入处理人姓名
3. 输入具体处理措施
4. 点击「确认处理」

---

## 四、导出结果

### 1. 选择导出格式
- **Excel**：多工作表，包含完整数据
- **PDF**：适合打印和分享
- **Word**：可编辑的文档格式

### 2. 选择报告模板
- **评审会专用模板**：包含完整分析摘要、异常明细、规则匹配情况
- **日常分析模板**：简洁明了的关键指标和异常列表

### 3. 导出选项（默认都勾选）
- **使用自然语言描述**：安全规则漏配原因用自然语言说明，避免字段名和缩写
- **包含追溯链路说明**：标注每条异常的追溯链路（异常样本→安全规则→处理意见）

### 4. 预览和导出
- 右侧显示报告预览效果
- 查看可复现性信息（运行ID、随机种子等）
- 点击「导出」按钮下载文件

### 5. 导出报告特点
- 非技术人员可直接阅读
- 每条异常都有自然语言的原因说明
- 包含运行ID，可用于复现分析结果
- 分布统计和版本追踪基于同一批处理记录，数据一致

---

## 五、版本追踪（可选）

### 1. 版本时间轴
查看所有提示词版本的发布时间轴：
- 精确到小时的时间刻度
- 有"晚到半天"风险的版本用红色标记⚠️
- 点击版本点高亮显示

### 2. 版本对比
1. 选择旧版本和新版本
2. 点击「检测标签冲突」
3. 系统自动列出所有因版本变更导致标签不一致的样本
4. 查看冲突样本的标签变化和原因说明

---

## 六、可复现性说明

每次分析生成唯一的「运行ID」，格式如：`RUN-1717234567890-abc12345`

**复现分析结果：**
1. 记录下运行ID
2. 在分析页面点击「复现分析」按钮
3. 或调用API传入运行ID
4. 系统使用相同的随机种子和配置重新分析
5. 得到完全一致的结果

---

## 七、验收标准

真正验收时，顺着一条异常往回查：
```
异常样本（如：漏填单位）
    ↓
关联的安全规则（如：R003-单位校验规则）
    ↓
漏配原因说明（自然语言，不是字段名）
    ↓
处理意见（处理人 + 处理时间 + 措施）
```

以上链路完整可查，才算验收通过。
