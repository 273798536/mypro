# 高分子分子量分布处理系统 - 使用说明

本系统用于高分子 GPC（凝胶渗透色谱）数据的分子量分布计算、异常追溯、结果导出，面向化学课题组日常使用。

---

## 1. 启动

在项目目录执行：

```bash
pip install -r requirements.txt
python run.py
```

浏览器打开：`http://127.0.0.1:5000`

> 首次运行会自动创建 `data/` 目录（存放上传文件、导出报告、处理记录）。

---

## 2. 导入数据

1. 在页面顶部"1. 导入数据"处填写：
   - **批号**（必填）：如 `PS-20240512-A`
   - **备注**（可选）
   - **批号重复策略**：
     - 合并（默认）：保留历史记录并更新"最新结果"，界面、报告均能看到历次结果
     - 覆盖：同一批号以本次为准
     - 跳过：批号已存在则不导入
   - **选择文件**：支持 `.xlsx / .xls / .csv / .txt`，需包含"分子量"和"重量分数"两列（中英文列名均支持）
2. 点击"导入并计算"。

想快速体验，可直接点击右上角 **"加载示例数据"**，系统自动生成 3 批示例（含同一批号重复导入一次）。

---

## 3. 查看异常

- **批次详情页异常追溯**：点击批次列表的"查看详情"，在"异常追溯"区可逐条看到：
  - 异常标题与严重程度（警告/提示）
  - 具体描述（说明发生了什么）
  - 处理意见（下一步建议怎么做）
  - 安全备注（潜在风险）
  - 关联的异常号、运行号（可与 Excel 报告交叉核对）
- **全部异常记录**：页面下方"4. 全部异常记录"汇总所有批次的异常，点击批号可跳转到对应批次详情。

验收时的反向追溯路径：任意异常 → 批号 → 运行号 → 处理记录 → 安全备注与处理意见。

---

## 4. 导出结果

- **单批次导出**：批次详情页点击"导出本批次 Excel 报告"。Excel 内含：
  - 摘要（批号、导入次数、备注）
  - 统计结果（Mn、Mw、Mz、PDI 等，含每次导入的历史值对比）
  - 分布曲线数据（分子量、logM、重量分数、累积重量）
  - 处理记录（每次导入的运行号、时间、核心指标、是否为重复批号）
  - 异常记录（含中文描述、处理建议、安全备注）
  - "关于批号重复"工作表（专设说明，避免非技术人员看不懂）
- **全部批次汇总**：顶部右上角"导出全部批次"，导出一个含所有批号核心指标的总表。

> 界面显示、复测建议、Excel 报告三者均读取同一份处理记录（存储在 `data/records.json`），不会出现"界面一个数、报告一个数"的情况。

---

## 5. 批号重复的处理逻辑

同一批号第二次导入时：

1. 默认策略为 **合并** —— 不会产生两份互相矛盾的结论：
   - "最新结果"以最近一次导入为准
   - "统计结果"表里历次结果并列展示，便于对比
   - "处理记录"表登记每次来源
2. 若两次 PDI / Mn 等差异超过阈值，会在"复测建议"中额外提醒。
3. 导出的 Excel 有专门一页"关于批号重复"，用自然语言说明原因，不是堆字段名。

---

## 6. 数据存储位置

| 内容 | 路径 |
|---|---|
| 上传的原始文件 | `data/uploads/` |
| 导出的 Excel 报告 | `data/exports/` |
| 统一处理记录（界面/报告共用） | `data/records.json` |
