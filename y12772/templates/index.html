5. 使用说明

  1. 启动：在项目目录运行 pip install -r requirements.txt 后，执行 python run.py，浏览器打开 http://127.0.0.1:5000。
  2. 导入：在顶部填写批号、选择文件，点击"导入并计算"。同一批号可重复导入（默认合并，保留历史）。
  3. 查看异常：在批次详情或"全部异常记录"中可见每条异常的描述、处理建议、安全备注，可直接反向追溯到对应批号与运行号。
  4. 导出结果：批次详情页"导出本批次 Excel 报告"，或顶部"导出全部批次"。报告中含统计结果、分布曲线数据、历次处理记录、异常说明及批号重复说明。

界面显示、复测建议、Excel 报告三者均读取同一条处理记录（存储于 data/records.json），不会出现"界面一个数、报告一个数"的情况。
