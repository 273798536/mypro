# 仓库退供复核重试补偿队列 API

## 系统概述

本系统用于处理仓库退供复核流程中的异常情况，提供可信的记录追踪和补偿机制。

## 核心功能

- **外部回执提交**：支持供应商回执批量导入
- **排队重试**：自动排队、限次重试、指数退避
- **人工接管**：异常单人工介入、改判、补偿入账
- **审计追踪**：所有状态变更记录时间、操作者、原因
- **数据一致性**：重复提交策略、导出冻结、历史追溯

## 快速开始

```bash
pip install -r requirements.txt
cp .env.example .env
uvicorn app.main:app --reload
```
