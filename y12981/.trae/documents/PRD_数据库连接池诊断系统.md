## 1. 产品概述

数据库连接池诊断系统是面向SRE值班人员的专业诊断工具，解决月结前数据库连接池问题反复调整、缺乏审计追踪的痛点。系统提供完整的操作留痕、数据一致性保障、版本对比和边界测试能力，让SRE在快速排查问题的同时，确保每一次操作都可追溯、可复核、可回滚。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| SRE值班 | 企业账号登录 | 导入数据、执行诊断、查看结果、下载报告 |
| SRE复核 | 企业账号登录 | 复核操作、审批权限变更、查看审计历史 |
| 系统管理员 | 企业账号登录 | 用户管理、权限配置、数据字典维护 |

### 2.2 功能模块

1. **诊断看板**：连接池概览图表、问题明细列表、一键诊断、结果下载
2. **审计历史**：操作流水记录、版本快照对比、回滚操作、变更原因追溯
3. **数据字典管理**：字段配置、版本对比、新旧结论并排展示
4. **权限管理**：越权申请、复核审批、操作人留痕
5. **边界案例库**：常见问题样例、外键断链测试、真实坏数据模拟

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 诊断看板 | 连接池概览 | 实时展示连接池使用率、等待队列、超时次数等关键指标图表 |
| 诊断看板 | 问题明细 | 列出诊断发现的具体问题，支持筛选、排序、标记处理状态 |

## 3. 核心流程

### 3.1 诊断执行流程
```mermaid
flowchart LR
    A["导入连接池数据"] --> B["系统自动快照留存"]
    B --> C["执行诊断分析"]
    C --> D["生成图表/明细/报告（同一批数据）"]
    D --> E["SRE确认诊断结果"]
    E --> F["记录操作审计"]
    F --> G["如需回滚→选择历史版本"]
    G --> H["生成前后对比校验记录"]
```

### 3.2 权限越权审批流程
```mermaid
flowchart LR
    A["SRE申请越权操作"] --> B["系统记录申请人和原因"]
    B --> C["推送复核人审批"]
    C --> D{是否通过?}
    D -->|通过| E["执行操作并完整留痕"]
    D -->|驳回| F["记录驳回原因"]
    E --> G["审计历史永久保存"]
```

### 3.3 数据字典变更流程
```mermaid
flowchart LR
    A["修改数据字典"] --> B["保存新版本"]
    B --> C["自动重算受影响的历史诊断"]
    C --> D["新旧结论并排展示"]
    D --> E["SRE确认影响范围"]
    E --> F["记录变更审计"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海军蓝 `#0f172a` 作为背景，搭配警示橙 `#f97316` 表示告警，成功绿 `#10b981` 表示正常，信息蓝 `#3b82f6` 表示操作
- **按钮风格**：扁平化设计，2px圆角，hover时有轻微上浮和阴影效果，disabled状态半透明
- **字体**：标题使用 "JetBrains Mono" 等宽字体增强技术感，正文使用 "Inter" 保证可读性
- **布局风格**：三栏式布局，左侧导航、中间主内容区、右侧详情面板，采用卡片式分组，信息密度适中
- **图标风格**：使用 lucide-react 线性图标，保持简洁一致

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI Elements |
|-----------|-------------|-------------|
| 诊断看板 | 概览图表 | 深色背景配亮色折线图/柱状图，数据点hover显示详情，时间范围快速选择 |
| 诊断看板 | 问题列表 | 斑马纹表格，告警级别用颜色标签区分，每行可展开查看详情 |
| 审计历史 | 时间轴 | 垂直时间轴设计，不同操作类型用不同颜色节点，点击展开对比面板 |
| 审计历史 | 版本对比 | 左右分栏布局，差异行用背景色高亮，新增/删除/修改用不同标识 |
| 数据字典 | 并排对比 | 双列对比视图，中间用竖线分隔，差异字段用箭头连接 |
| 边界案例 | 案例卡片 | 悬停卡片设计，每个案例包含问题描述、影响范围、测试按钮 |

### 4.3 响应式
- **桌面端优先**：1280px以上完整三栏布局
- **平板适配**：1024px折叠为两栏，右侧面板改为抽屉式
- **移动端**：768px以下单栏布局，导航改为底部tabbar
- 所有表格支持水平滚动，关键操作按钮固定在可视区域

### 4.4 交互细节
- 页面加载时采用渐入动画，元素按顺序出现
- 诊断执行时有进度条和状态提示
- 版本对比时差异行有高亮脉冲动画
- 表格行hover时有背景色变化
- 模态框采用缩放出现动画
