
## 1. 产品概述
跨店储值卡余额清算系统，解决连锁门店跨店消费资金清算难题，替代手工台账，实现余额分层、门店分摊、异常复核的自动化处理。
- 核心目标：解决跨店消费资金不清、赠金不可退规则执行、门店撤店清算等财务痛点
- 目标用户：连锁财务人员、门店店长、总部审计

## 2. 核心功能

### 2.1 用户角色
| 角色 | 核心权限 |
|------|----------|
| 连锁财务 | 查看清算明细、执行清算、导出报表、异常复核 |
| 门店店长 | 查看本店清算记录、提交异常申诉 |
| 总部审计 | 审计追踪、操作日志查询 |

### 2.2 功能模块
1. **清算工作台**：跨店消费记录列表、余额分层展示、门店分摊明细
2. **异常复核**：异常记录识别、人工复核、申诉处理
3. **审计追踪**：操作日志、数据溯源、变更历史
4. **样例验证**：预设样例数据、场景模拟、结果验证

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 清算工作台 | 余额分层卡片 | 本金/赠金/冻结金额分层展示，赠金不可退标记 |
| 清算工作台 | 门店分摊表格 | 消费门店/充值门店的资金分摊明细，支持追溯 |
| 清算工作台 | 清算记录列表 | 跨店消费记录，状态筛选，一键清算 |
| 异常复核 | 异常识别面板 | 门店撤店、赠金退款、超额消费等异常场景 |
| 审计追踪 | 变更历史 | 每次改动的来源、前后变化对比 |
| 样例验证 | 场景模拟 | 正常记录/门店撤店样例对比展示 |

## 3. 核心流程
用户导入混合数据包 → 系统自动识别会员卡/退款/清算记录 → 余额分层计算 → 门店资金分摊 → 异常标记 → 财务复核确认 → 执行清算 → 生成审计记录

```mermaid
flowchart LR
    A["导入混合数据包"] --> B["自动识别记录类型"]
    B --> C["余额分层计算\n(本金/赠金/冻结)"]
    C --> D["门店资金分摊"]
    D --> E{"异常检测"}
    E -->|正常| F["财务复核"]
    E -->|异常| G["异常标记&申诉"]
    G --> F
    F --> H["执行清算"]
    H --> I["生成审计记录"]
```

## 4. 用户界面设计
### 4.1 设计风格
- **主色调**：深蓝 (#1e3a5f) 专业稳重，体现财务系统的严谨性
- **辅助色**：
  - 正常状态：深绿 (#059669)
  - 异常状态：橙红 (#dc2626)
  - 警告状态：琥珀 (#d97706)
  - 赠金标记：紫色 (#7c3aed)
- **按钮风格**：扁平化直角设计，清晰的状态区分
- **字体**：使用 JetBrains Mono 等宽字体展示金额，保证数字对齐；Inter 作为正文字体
- **布局风格**：卡片式布局，信息密度适中，重点数据突出显示
- **图标风格**：线性简约图标，避免花哨装饰

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|----------|
| 清算工作台 | 余额分层卡片 | 三栏并排卡片，本金/赠金/冻结各占一栏，金额放大显示，赠金卡加紫色边框 |
| 清算工作台 | 门店分摊表格 | 固定表头，斑马纹行，悬停高亮，可展开查看溯源信息 |
| 清算工作台 | 清算记录列表 | 左侧状态标签，右侧操作按钮，支持批量选择 |
| 异常复核 | 异常识别面板 | 红色边框卡片，异常原因高亮，提供复核按钮 |
| 审计追踪 | 变更历史 | 时间线布局，前后对比用 diff 样式展示 |
| 样例验证 | 场景模拟 | 左右分栏对比，左侧正常记录，右侧门店撤店样例 |

### 4.3 响应性
- 桌面端优先设计（1280px 以上）
- 平板端：表格横向滚动，卡片自适应宽度
- 移动端：卡片堆叠展示，简化表格列数

### 4.4 动效设计
- 金额变化时的数字滚动动画
- 异常标记的脉冲提醒效果
- 展开/收起溯源信息的平滑过渡
- 清算执行成功的确认反馈
