## 1. 产品概述

贝叶斯故障定位系统——面向设备工程师的工业故障推理工具，基于贝叶斯更新框架对报警记录、维修结果、定位报告三类证据进行增量推理，输出故障部件概率排序、证据解释与复检建议。

- 解决设备故障定位中样本过少、先验过强、标签滞后导致误判的问题
- 确保单位换算一致、边界值有提示、报告间不互相打架，支持从报警到结果、结果到传感器序列的双向追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 设备工程师 | 直接使用 | 录入证据、查看定位结果、追溯链路 |
| 质量审核员 | 审核模式 | 审核定位报告、标记冲突 |

### 2.2 功能模块

1. **证据录入页**: 报警记录录入、维修结果录入、定位报告导入
2. **定位看板页**: 贝叶斯概率排序、证据解释面板、复检建议、双向追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 证据录入页 | 报警记录录入 | 录入传感器报警数据，含传感器序列号、报警类型、量值（支持多单位）、时间戳；自动检测样本量不足 |
| 证据录入页 | 维修结果录入 | 录入维修工单结果，含故障部件、维修措施、确认/排除标记；自动检测标签滞后 |
| 证据录入页 | 定位报告导入 | 导入已有定位报告，系统检测与现有证据的单位换算冲突、口径不一致 |
| 证据录入页 | 单位换算引擎 | 自动将不同单位换算为系统基准单位，标记换算来源，不替业务偷改口径 |
| 证据录入页 | 冲突检测面板 | 实时展示三类证据间的冲突项（单位不一致、口径不同、量值越界），标记但不自动修改 |
| 定位看板页 | 概率排序面板 | 按后验概率排序的故障部件列表，贝叶斯更新后排序变化时高亮标注 |
| 定位看板页 | 证据解释面板 | 对当前概率排序的解释：哪些证据推动了排序变化，置信度评估 |
| 定位看板页 | 复检建议面板 | 基于当前概率与不确定性，给出具体到材料/对象的复检建议 |
| 定位看板页 | 双向追溯链路 | 正向：报警记录→中间推理→最终结果；反向：结果→证据来源→传感器序列号 |

## 3. 核心流程

用户从报警记录入手，逐步补充维修结果和定位报告。系统在每次新增证据时执行增量贝叶斯更新，概率排序实时变化。当样本过少或先验过强时，系统给出具体到材料/对象的警告。当报告间出现冲突时，系统标记但不替业务偷改口径。用户可随时沿报警→结果或结果→传感器序列两条路径追溯。

```mermaid
flowchart TD
    "报警记录录入" --> "单位换算与边界检测"
    "维修结果录入" --> "单位换算与边界检测"
    "定位报告导入" --> "冲突检测"
    "单位换算与边界检测" --> "增量贝叶斯更新"
    "冲突检测" --> "标记冲突（不自动修改）"
    "标记冲突（不自动修改）" --> "增量贝叶斯更新"
    "增量贝叶斯更新" --> "概率排序变化?"
    "概率排序变化?" --> "是: 更新证据解释与复检建议"
    "概率排序变化?" --> "否: 保持当前状态"
    "更新证据解释与复检建议" --> "双向追溯可用"
    "双向追溯可用" --> "正向: 报警→结果"
    "双向追溯可用" --> "反向: 结果→传感器序列"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深灰底色（#1a1a2e）+ 琥珀色强调（#f59e0b）+ 冰蓝辅助（#38bdf8）
- **按钮风格**: 扁平圆角，状态色区分（录入-琥珀、警告-红、通过-绿）
- **字体**: 数据区等宽（JetBrains Mono），说明区无衬线（Noto Sans SC）
- **布局**: 左侧证据录入区 + 右侧定位看板，顶部追溯导航条
- **图标**: Lucide图标，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 证据录入页 | 报警记录表单 | 表单卡片，含单位选择器、样本量指示条、时间戳 |
| 证据录入页 | 维修结果表单 | 表单卡片，含确认/排除切换、标签滞后警告条 |
| 证据录入页 | 定位报告导入 | 拖拽上传区 + 冲突检测结果列表 |
| 证据录入页 | 冲突检测面板 | 侧滑面板，红/黄/绿标记冲突等级 |
| 定位看板页 | 概率排序 | 横向概率条形图，排序变化时箭头动画 |
| 定位看板页 | 证据解释 | 时间线式证据链，标注每条证据对排序的贡献 |
| 定位看板页 | 复检建议 | 卡片列表，具体到材料/对象，含优先级标记 |
| 定位看板页 | 双向追溯 | 面包屑+树形结构，点击节点展开详情 |

### 4.3 响应式

桌面优先设计，关键操作区最小宽度1024px，概率排序和追溯链路在窄屏时切换为纵向堆叠。
