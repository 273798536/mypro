# 夜市外摆投诉回放 - 使用说明

## 一、启动

```bash
# 安装依赖
npm install

# 启动开发服务（前端 + 后端同时启动）
npm run dev

# 单独启动前端
npm run client:dev

# 单独启动后端
npm run server:dev
```

启动后访问：http://localhost:5173

## 二、放样例

1. 点击顶部工具栏 **「放样例」** 按钮
2. 在确认弹窗中点击 **「确认生成」**
3. 系统将自动生成 3 条投诉测试数据，包含：
   - 1 张名称不一致的照片（红旗路 vs 红星路）
   - 坐标偏移到隔壁街的场景（偏移约 200 米）
   - 完整的变更历史记录
4. 所有数据保存到 `api/data/` 目录下的 JSON 文件，服务重启不丢失

## 三、重跑

1. 在左侧列表点击选中一条投诉记录
2. 点击顶部工具栏 **「重跑」** 按钮
3. 系统将重新校验：
   - 所有照片的文件名一致性
   - 所有照片的坐标偏移距离
4. 校验结果会自动更新到：
   - 地图点位标注
   - 照片列表标记
   - 变更历史记录
   - Markdown 报告版本号

## 四、查看 Markdown 报告

1. 在左侧列表点击选中一条投诉记录
2. 点击顶部工具栏 **「查看Markdown报告」** 按钮
3. 系统跳转到报告页面，包含：
   - 投诉基本信息
   - 每张照片的详细信息和问题标注
   - 名称不一致检测结果
   - 坐标偏移检测结果
   - 完整变更历史对比表
   - 处理建议
4. 可点击 **「复制」** 或 **「下载」** 按钮导出报告

## 五、补录照片（可选）

1. 选中一条投诉记录后，点击 **「补录照片」** 按钮
2. 可点击 **「快速填充」** 自动生成测试数据
3. 或手动填写：
   - 原始文件名、系统重命名
   - 照片URL、坐标、地址
4. 提交后系统自动：
   - 记录变更历史
   - 更新地图点位
   - 递增报告版本号

---

**数据持久化说明**：所有操作均实时写入 `api/data/` 目录下的 JSON 文件，服务重启后仍可看到前一次处理状态和 Markdown 报告。
