# 马尔可夫链批量验算

面向错题教研场景的批量马尔可夫链转移验算工具。

## 两三步上手

1. **启动服务**
   ```bash
   pip install -r requirements.txt
   python app.py
   ```
   浏览器打开 http://localhost:5000

2. **录入数据**
   在「① 录入/导入」里单条录入，或贴 JSON 批量导入。
   每条记录至少要有：`raw_source`（来源）、`student_id`、`timestamp`、`sequence`（错题序列，值域 = 粗心/审题/计算/概念）。

3. **运行验算**
   可选：在「② 参数A/B」里改两组参数做对照。
   点「③ 执行运算」里的按钮，在「④ 结果总览」看每条记录的 A/B 结果与中间计算步骤。

## 坏材料来了，看哪里

| 看到的现象 | 去哪里查 | 说明 |
|---|---|---|
| 状态是 **排序不稳定** | 结果总览里「问题/排序不稳定原因」列 → 对应记录的 `raw_payload` | 缺学号、缺时间戳、序列里有 `?` 占位符，都会被单独拎出来，原始内容不会被修掉 |
| 状态是 **需补证据** | 同问题列，点开中间步骤里的「证据不足判定」 | 序列长度低于参数里 `min_observations`，或根本没解析出合法序列 |
| 图表好看但点不回明细？ | 结果总览表格行 → 点开「查看 N 步中间计算 / 单位换算」 | 每一步「转移计数 / 概率归一化（次→概率）/ 对照差异」都留痕，A/B 两组各算各的 |
| 服务重启后数据丢了？ | 不会丢。数据写在 `data/state.jsonl`，首页会自动加载最近批次；历史批次在页面底部可切换 | 每一条录入、参数修改、运算执行，都会追加到「⑤ 历史时间线」 |
| 原始数据被自动清洗了？ | 看 `raw_payload` 列，永远保留录入的第一手内容；`cleaned_payload` 只做解析辅助，不回写覆盖 | |

## 文件

- `app.py` — Flask Web 服务
- `markov_engine.py` — 马尔可夫链验算 + 数据清洗 + 排序稳定判定
- `models.py` — 数据模型（批次、记录、时间线、计算步骤）
- `storage.py` — JSONL 持久化，重启可恢复
- `data/state.jsonl` — 所有批次快照
- `data/meta.json` — 最近使用的批次 ID
