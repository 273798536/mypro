# 影视投资回款分账系统

## 核心功能

- **统一分账计算**：所有接口复用同一套分账瀑布逻辑，避免口径不一
- **持久化存储**：SQLite数据库，重启后数据不丢失
- **冲突检测**：合同与回款数据合并时高亮展示差异，不自动覆盖
- **版本留痕**：投资比例变更、回款分期调整均可追溯原始记录
- **成本追补**：专项管理，避免遗漏导致返工
- **分账单导出**：标准函件格式，可直接转发同事

## 快速开始

```bash
# 安装依赖
npm install

# 初始化数据库
npm run init-db

# 启动服务
npm start

# 运行测试
npm test
```

## API 文档

### 核心流程

1. 创建投资合同 → 2. 录入回款计划/实际回款 → 3. 冲突检测与合并 → 4. 成本追补 → 5. 执行分账计算 → 6. 导出版本分账单
