# 置信区间口径对比工具 — 使用说明

按建模社助教的日常使用流程编写，四步搞定：启动 → 导入 → 查异常 → 导出。

---

## ① 启动

```bash
cd /path/to/this/project
python3 -m pip install -r requirements.txt   # 首次运行安装依赖
streamlit run app.py
```

浏览器会自动打开看板（默认 http://localhost:8501）。

---

## ② 导入数据

### 数据格式
支持 Excel (`.xlsx`/`.xls`) 和 CSV。

**必要列：**
| 列名（任一别名均可） | 说明 | 示例 |
|---|---|---|
| `student_id` / 学生ID / 学号 | 学生唯一标识 | S001 |
| `question_id` / 题目ID / 题号 | 题目唯一标识 | Q001 |

**可选列：**
| 列名 | 说明 | 示例 |
|---|---|---|
| `is_correct` / 是否正确 | 是否答对（1/0、True/False、对/错均可） | 1 |
| `score` / 得分 | 具体分值（0~1 连续值或整数） | 0.5 |
| `answer_time` / 答题时间 | 提交时间（用于识别晚到） | 2025-06-01 10:30 |
| `tags` / 标签 | 多值用逗号分隔 | 知识点:函数,难度:中等 |

> 部分数据未评分也可以导入，系统会在异常面板提示。

### 导入操作
左侧边栏 **① 导入数据**：
- **上传文件** Tab：拖拽或选择本地文件 → 点"读取并保存为快照"
- **选择历史快照** Tab：从之前导入过的版本中选一个 → 点"加载此快照"

每次导入都会自动保存为快照，不会覆盖之前的数据。

### 评分补录
如果导入的数据里存在未评分记录，左侧 **② 评分补录** 区会列出。
- 选记录 → 选对错/填分 → 点"添加评分记录"
- 补录后所有分析结果**自动更新**，不需要重新上传文件。

## ③ 查看异常与分析结果

页面顶部的 KPI 卡片先给一个总览：答题记录数、分组数、异常总数。

### 异常面板（核心）
异常分**两栏**，直接告诉你下一步该做什么，不会混在一堆红色数字里：

| 分类 | 标识颜色 | 含义 | 下一步 |
|---|---|---|---|
| **需补材料** | 🟡 黄色 | 数据本身缺失（未评分、样本量不够） | 补答题记录或评分，重算 |
| **需改口径** | 🔴 红色 | 方法适用问题（近似条件不满足、误差过大） | 评估口径或调整阈值 |

点开每条异常可查看：严重程度、详细说明、受影响口径。

### 图表与明细
- **区间对比图**：横向展示每个分组三种口径的置信区间范围，决策阈值用虚线标出。
- **宽度散点图**：观察区间宽度与样本量的关系。
- **口径对比明细表**：每行一个分组，多列展示各口径上下限。
  - 🔴 红色行：正态近似误差过大，已拦截
  - ⚠️ 黄色行：本次导入/补录影响到的分组
- **单组钻取**：在表格下方选一个分组，查看该题各口径的数值细节。

### 晚到错题提示
如果本次导入的数据相对上一快照有新增或评分变更，页面顶部会出现一条黄色提示，
写明"新增 X 条，评分更新 X 条，影响 X 个分组的结论"，同时表格中受影响分组会标注。
旧结果不会被悄悄覆盖，所有历史快照均可回溯。

## ④ 导出结果给运营

页面底部 **📤 导出报告** 区域：
1. 点"生成 Excel 报告"按钮
2. 稍等几秒，出现"下载 Excel 报告"按钮
3. 点击下载，文件自动命名含快照 ID 和时间戳

### 导出的 Excel 包含 6 个 Sheet：

| Sheet | 给谁看 | 内容 |
|---|---|---|
| 总览 | 所有人 | 记录数、异常数、版本对比等关键指标 |
| 口径对比明细 | 所有人 | 每行一个分组，三种口径的上下限+宽度，被拦截的行标红 |
| 异常清单 | 助教/运营 | 每条异常按"需补材料/需改口径"分类，附处理建议 |
| 近似误差分析 | 助教 | 每组正态近似相对于精确口径的误差，超限的行标红 |
| 反例清单 | 助教 | 不同口径结论不一致的分组 |
| **说明** | **运营** | **用通俗语言解释了各种标记的含义（为什么被标红、为什么被拦截、异常类型是什么意思）** |

> 运营同事即使只看导出的 Excel，打开"说明"Sheet 也能明白「近似误差过大」是什么意思，为什么这些分组的结果被标红拦截。
