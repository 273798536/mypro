## 1. 产品概述

粒子电场沙盒是一个基于 Web3D 的交互式物理教学工具，帮助学生直观理解电场的方向与强弱关系。学生可以在3D空间中自由拖动电荷，实时观察电场线的方向箭头和场强着色变化，解决"方向与强弱混淆"的核心教学痛点。

- 目标用户：高中/大学物理教师与学生
- 核心价值：将抽象的电场概念转化为可交互的3D可视化体验，参数变化后3D场景与侧边数据同步更新

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 教师 | 直接访问 | 添加/删除/拖动电荷、查看样例记录、播放时间轴 |
| 学生 | 直接访问 | 添加/删除/拖动电荷、查看样例记录、播放时间轴 |

### 2.2 功能模块

1. **3D电场场景页**：3D空间、电荷拖拽、电场线渲染、方向箭头、场强着色
2. **侧边数据面板**：电荷参数表、场强数据、样例记录列表、时间轴控件

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D电场场景 | 电荷模型 | 3D球体表示正/负电荷，颜色区分极性，可拖拽移动 |
| 3D电场场景 | 电场线渲染 | 从正电荷出发、到负电荷终止的3D曲线，方向箭头标注电场方向 |
| 3D电场场景 | 场强着色 | 电场线颜色/粗细映射场强大小，红色强→蓝色弱 |
| 3D电场场景 | 重叠保护 | 同点电荷重叠时场强取上限而非爆炸，方向箭头保留原始方向不覆盖 |
| 侧边数据面板 | 电荷参数表 | 实时显示所有电荷的位置(x,y,z)、电量(q)、极性 |
| 侧边数据面板 | 场强数据 | 鼠标悬停/选中点处的场强矢量(E_x, E_y, E_z)与模值 |
| 侧边数据面板 | 样例记录 | 含正常记录、缺字段记录、晚补记录、备注改过记录、方向箭头反记录 |
| 侧边数据面板 | 时间轴 | 历史状态回放，支持播放/暂停/重置/筛选，拖动后3D与数据同步更新 |

## 3. 核心流程

用户打开页面 → 3D场景初始化（默认2个电荷）→ 拖动电荷改变位置 → 电场线实时重新计算并渲染 → 侧边数据面板同步更新 → 查看样例记录确认分支逻辑 → 播放时间轴回溯历史状态

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深空蓝 (#0a0e27)，辅色：电场青 (#00f5d4)、正电荷红 (#ff4757)、负电荷蓝 (#1e90ff)
- 按钮：圆角玻璃拟态，带发光边框
- 字体：标题用 Orbitron（科技感），正文用 Noto Sans SC
- 布局：左侧3D场景占70%，右侧数据面板占30%，深色主题
- 图标：lucide-react 图标集

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 3D电场场景 | 电荷模型 | 发光球体、正电荷红/负电荷蓝、拖拽光晕效果 |
| 3D电场场景 | 电场线 | 带箭头的3D曲线、颜色渐变映射场强、半透明管状 |
| 3D电场场景 | 场景背景 | 深空星场粒子、微弱网格平面 |
| 侧边数据面板 | 电荷参数表 | 暗色卡片、数字高亮、可编辑电量输入框 |
| 侧边数据面板 | 样例记录 | 列表卡片、标签标记状态（正常/缺字段/晚补/改过/箭头反） |
| 侧边数据面板 | 时间轴 | 底部滑块条、播放/暂停/重置按钮、状态标记点 |

### 4.3 响应式

- 桌面优先设计，最小宽度1024px
- 3D场景支持鼠标拖拽旋转/缩放
- 触屏设备支持手势操控

### 4.4 3D场景指引

- 环境：深色空间环境，微弱环境光 + 点光源跟随电荷
- 灯光：AmbientLight(0x1a1a2e, 0.6) + PointLight跟随电荷位置
- 相机：PerspectiveCamera，初始45度俯视，支持OrbitControls旋转
- 构图：3D场景居中，电荷默认分布在XZ平面
- 交互：电荷拖拽使用 @react-three/drei 的 DragControls 或自定义 raycaster
- 后处理：Bloom发光效果增强电荷和箭头的视觉冲击
- 资源：纯程序化生成，无外部模型文件
- 性能预算：电场线数量 ≤ 200条，实时计算帧率 ≥ 30fps
