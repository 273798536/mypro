## 1. 产品概述
项目现金燃尽曲面是一款面向创业团队的3D交互可视化工具，通过三维曲面实时展示项目预算、已花金额和预计收入的动态变化，帮助团队在周会上快速识别现金流风险。

- **核心问题**：创业团队缺乏直观的现金流可视化工具，难以及时发现收入延期、支出超支、里程碑错位等风险
- **目标用户**：创业团队创始人、财务负责人、项目经理
- **核心价值**：将抽象的财务数据转化为可交互的3D曲面，一眼识别风险，支持数据溯源和历史追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 团队成员 | 本地登录/无登录 | 查看3D曲面、筛选数据、导出图片、查看明细 |
| 管理员 | 本地登录/无登录 | 所有成员权限 + 导入/修正数据 |

### 2.2 功能模块
1. **3D燃尽曲面主视图**：三维曲面展示预算线、支出线、收入预测线
2. **时间切片控制器**：拖动时间轴查看不同时间点的现金流状态
3. **风险标记系统**：高亮显示收入延期、支出重复、里程碑错位等风险点
4. **负责人筛选器**：按负责人筛选相关支出和收入项
5. **侧边明细面板**：展示选中区域的详细数据，与3D视图实时同步
6. **数据溯源模块**：展示每条数据的来源和修正历史
7. **导出功能**：支持导出当前3D视图为图片
8. **历史版本管理**：支持查看历史数据和重启项目后的一致性校验

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 3D曲面视图 | 支持鼠标旋转、缩放、平移，悬停显示数据点详情 |
| 主页面 | 顶部工具栏 | 时间切片滑块、负责人筛选下拉框、导出按钮、视图切换 |
| 主页面 | 左侧风险面板 | 按类型列出当前识别的所有风险，点击定位到3D视图对应位置 |
| 主页面 | 右侧明细面板 | 展示选中数据点的详细信息、来源、修正历史 |
| 主页面 | 底部时间轴 | 项目全周期时间轴，可拖动选择时间范围，标记里程碑 |

## 3. 核心流程

用户打开应用 → 加载项目数据 → 3D曲面自动渲染 → 用户拖动时间切片查看不同阶段 → 点击风险标记查看详情 → 按负责人筛选数据 → 调整3D视角 → 导出图片用于周会汇报 → 关闭应用时保存当前视图状态

```mermaid

    C --> D["自动识别风险点"]
    D --> E["用户交互（旋转/缩放/筛选）"]
    E --> F["视图与明细实时同步"]
    F --> G["导出图片/查看历史"]
    G --> H["保存状态"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深空蓝 (#0A1628) 作为背景，营造科技感
- **辅助色**：
  - 预算线：科技蓝 (#3B82F6)
  - 支出线：警告橙 (#F59E0B) 
  - 收入线：成功绿 (#10B981)
  - 风险标记：危险红 (#EF4444)
- **字体**：JetBrains Mono 作为数字字体，Inter 作为界面字体
- **布局**：深色主题，半透明玻璃态面板，毛玻璃效果
- **图标**：线性图标，统一2px描边

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 3D曲面视图 | 三色曲面、网格地面、坐标轴、数据点标签、风险标记悬浮球 |
| 主页面 | 顶部工具栏 | 滑块、下拉框、按钮组、状态指示灯 |
| 主页面 | 左侧风险面板 | 风险卡片、风险类型图标、数量徽章、定位按钮 |
| 主页面 | 右侧明细面板 | 数据表格、来源标签、修正历史时间线、负责人头像 |
| 主页面 | 底部时间轴 | 里程碑标记、时间刻度、范围选择器、播放按钮 |

### 4.3 响应式
- 桌面端为主（1280px+），侧边面板固定宽度
- 平板端可折叠侧边面板
- 支持全屏模式展示3D视图

### 4.4 3D场景指导
- **环境**：深色空间背景，微弱星空粒子效果，营造数据空间感
- **光照**：环境光 + 三盏方向光（冷色主光 + 暖色补光 + 边缘光）
- **相机**：透视相机，初始45度俯视角，支持轨道控制
- **构图**：曲面居中，底部显示半透明网格地面，坐标轴显示在角落
- **交互**：鼠标悬停显示数据点信息面板，点击高亮并联动侧边明细
- **动画**：曲面加载动画、风险点脉冲动画、时间切片切换过渡动画
- **后处理**：Bloom效果增强发光区域，轻微景深突出主体
