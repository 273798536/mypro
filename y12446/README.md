# 声学剧场调音战

## 启动方式

### 方式一：直接打开
直接双击 `index.html` 文件，在浏览器中打开即可运行。

### 方式二：本地服务器（推荐）
使用 Python 启动本地服务器：
```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```
然后在浏览器中访问 `http://localhost:8000`

或者使用 Node.js：
```bash
npx http-server
```

## 样例位置

关卡样例数据位于 `data/levels.js`，包含 3 个预设关卡：

1. **关卡 1 - 初入剧场**（ID: 1）
   - 学习基础调音，处理简单啸叫
   - 2 个声源（主唱、吉他手）
   - 1 个初始麦克风
   - 目标覆盖率：70%
   - 时间限制：90秒

2. **关卡 2 - 混响迷宫**（ID: 2）
   - 处理混响问题，优化声场覆盖
   - 3 个声源（主唱、吉他手、鼓手）
   - 2 个初始麦克风
   - 目标覆盖率：80%
   - 时间限制：120秒

3. **关卡 3 - 完美声场**（ID: 3）
   - 综合挑战，达到完美声场
   - 6 个声源（主唱、和声×2、吉他、键盘、鼓手）
   - 1 个初始麦克风
   - 目标覆盖率：90%
   - 时间限制：150秒

## 啸叫触发办法

啸叫（Howling）是声音正反馈现象，由以下条件共同触发：

### 触发条件（需同时满足多项）

1. **麦克风增益过高**
   - 麦克风增益 > 70 时，每超出 1 点增加 2 点风险值

2. **声源音量过大**
   - 声源音量 > 80 时，每超出 1 点增加 1.5 点风险值

3. **距离过近**
   - 麦克风与声源距离 < 50px 时，每近 1px 增加 0.5 点风险值

4. **高频过多**
   - 高频均衡（EQ High）> 15 时，每超出 1 点增加 0.8 点风险值

5. **麦克风朝向正对声源**
   - 麦克风角度与声源方向夹角 < 30° 时，增加 10 点风险值

6. **反馈灯口径过小**
   - 反馈灯口径 < 5 时，每小 1 点增加 3 点风险值

### 快速触发啸叫的操作

1. 将麦克风增益拉到 80 以上
2. 将高频均衡（EQ High）拉到 25 以上
3. 把麦克风拖到距离声源 30px 以内
4. 将反馈灯口径调到 1-2

当风险值 ≥ 70 时，系统判定为啸叫触发。

### 解决啸叫的方法

1. 降低麦克风增益到 70 以下
2. 降低声源音量到 80 以下
3. 增加麦克风与声源的距离（> 50px）
4. 降低高频均衡到 15 以下
5. 增大反馈灯口径（> 5）
6. 调整麦克风角度，避免正对声源

## 游戏操作

### 麦克风操作
- **添加麦克风**：点击"添加麦克风"按钮
- **移动麦克风**：在画布上拖拽麦克风
- **调整增益**：在右侧面板拖动麦克风增益滑块
- **删除麦克风**：点击麦克风条目右侧的"删除"按钮

### 声场调节
- **主音量**：0-100，影响整体音量
- **混响**：0-100，>60 会触发混响过长问题
- **延迟**：0-100，与混响配合调节
- **高频均衡**：-50 到 50，过高易引发啸叫
- **低频均衡**：-50 到 50，影响声音厚度
- **反馈灯口径**：1-10，越小灵敏度越高但越易啸叫

### 问题类型
- **啸叫（红色）**：正反馈现象，需立即处理
- **混响过长（黄色）**：混响时间 > 3s，声音浑浊
- **座位遮挡（紫色）**：障碍物阻挡声音路径
- **麦克风缺失（黄色提示）**：无麦克风或位置不当

### 复盘功能
点击"复盘模式"查看详细报告，包含：
- 得分明细（覆盖、问题、效率、反馈）
- 问题汇总与解决情况
- 参数对比（原始值 → 当前值）
- 反馈灯口径影响分析
- 事件时间线

点击"导出成绩"可下载文本格式的复盘报告。

## 通关条件

1. 声场覆盖率 ≥ 关卡目标值
2. 所有非警告类问题已解决
3. 总分 ≥ 60 分

## 评分规则

- **声场覆盖**：40分，达到目标覆盖率得满分
- **问题处理**：30分，每个未解决问题扣10分，警告扣5分
- **效率**：15分，50%时间内完成得满分
- **反馈调节**：15分，反馈灯口径越稳定得分越高
