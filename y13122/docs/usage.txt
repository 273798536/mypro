最短路径参数试算 · 使用说明

一、样例
  样例文件在 samples/ 目录：
  ・question-list.csv — 题目清单（含正常/坏行/空行/重复行
  ・single-normal-record.csv — 一条正常记录
  ・supplement-note.txt — 后补说明

二、重跑
  终端执行：
    node bin/sptrial.js 你的文件.csv
  
  常用参数：
    -t 500000  设阈值（米）
    -u km      指定期望单位
    -b baseline.json  跟基线比对
    -d         显示坏行原文

三、查看截图说明
  报告输出分四块：
  1. 顶部汇总：总数 / 已处理 / 坏行 / 跳过行 / 重复行，各占一行
  2. 阈值/单位：设了才显示
  3. 跳变分析：带 -b 才显示，标出可能原因
  4. 明细：坏行、跳过行、重复行各一段，都带行号
