## 1. 产品概述

贷款审批漏斗体是一个面向银行运营人员的3D可视化分析工具，将贷款审批全流程以3D漏斗形式呈现，支持按渠道、产品、拒绝原因多维筛选联动，实时悬浮查看节点明细，追溯历史修正痕迹，并支持导出截图。

- 核心目标：让运营人员直观识别审批瓶颈、渠道错归和拒绝原因覆盖等数据异常
- 目标用户：银行运营团队、风控分析师、审批流程管理者

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限说明 |
|------|----------|
| 运营分析师 | 查看3D漏斗、筛选联动、节点明细、历史对比、导出截图 |
| 风控管理员 | 在分析师基础上可标记异常、确认修正 |

### 2.2 功能模块

1. **漏斗主页面**：3D漏斗体渲染、筛选面板、节点悬浮信息、异常提示、历史对比面板、导出截图

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 漏斗主页面 | 3D漏斗体 | 以三维漏斗形式展示申请→初审→复审→终审→放款各阶段的通过量和转化率，支持旋转、缩放、悬浮高亮 |
| 漏斗主页面 | 筛选联动面板 | 支持按渠道（线上/线下/代理）、产品（消费贷/经营贷/房贷）、拒绝原因（信用不足/资料不全/政策限制）三维交叉筛选，筛选结果实时联动3D漏斗 |
| 漏斗主页面 | 节点明细弹窗 | 悬浮/点击漏斗节点弹出详情：申请量、通过量、拒绝量、拒绝原因分布、来源追溯 |
| 漏斗主页面 | 异常检测提示 | 自动检测节点重复、渠道错归、拒绝原因覆盖三种异常，以醒目标记和浮动提示展示 |
| 漏斗主页面 | 历史对比面板 | 展示漏斗数据的历史版本列表，支持两期对比，高亮差异节点和修正痕迹 |
| 漏斗主页面 | 修正痕迹追踪 | 记录每次数据修正的时间、操作人、修正前后值、修正原因，支持来源回溯 |
| 漏斗主页面 | 导出截图 | 将当前3D漏斗视图（含筛选状态和异常标记）导出为PNG图片 |

## 3. 核心流程

用户打开页面后，3D漏斗体加载全量数据。通过左侧筛选面板选择渠道、产品、拒绝原因进行交叉筛选，漏斗体实时联动更新。悬浮/点击漏斗节点查看明细信息，异常节点自动标记并弹出警告。可打开历史对比面板查看往期数据和修正痕迹，最终导出当前视图截图用于报告。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深空蓝(#0A1628)背景 + 金色(#F0B429)强调色，营造金融专业感
- 辅助色：冰蓝(#4FC3F7)用于数据高亮，红色(#EF4444)用于异常警告
- 漏斗材质：半透明玻璃质感，节点悬浮时发光边缘
- 字体：标题使用 DM Serif Display，正文使用 Noto Sans SC
- 布局：左侧筛选面板 + 中央3D漏斗 + 右侧节点明细/历史面板
- 图标风格：线性描边，与3D场景协调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 漏斗主页面 | 3D漏斗体 | 半透明玻璃材质漏斗，每层渐变色，悬浮发光边缘，层间流动粒子效果 |
| 漏斗主页面 | 筛选联动面板 | 深色卡片背景，三组下拉/多选筛选器，活跃筛选标签 |
| 漏斗主页面 | 节点明细弹窗 | 毛玻璃弹窗，数据指标卡片，拒绝原因环形图，来源时间线 |
| 漏斗主页面 | 异常检测提示 | 红色脉冲动画标记，浮动警告条，可展开详情 |
| 漏斗主页面 | 历史对比面板 | 侧边滑出面板，期次选择器，对比差异热力图 |
| 漏斗主页面 | 导出截图按钮 | 顶部工具栏图标按钮，点击后保存PNG |

### 4.3 响应式

- 桌面优先设计，最低支持1280px宽度
- 3D场景自适应容器尺寸
- 筛选面板在窄屏可折叠

### 4.4 3D场景指引

- 环境：深空蓝渐变背景，微弱星点粒子
- 灯光：顶部冷白方向光 + 底部暖色补光，营造漏斗纵深感
- 相机：45度俯视，支持鼠标旋转/缩放/平移
- 构图：漏斗居中，筛选面板半透明叠加左上角
- 交互：鼠标悬浮高亮漏斗层，点击展开详情，拖拽旋转视角
- 后处理：辉光(Bloom)效果使漏斗边缘发光，环境遮蔽增强层次感
- 性能预算：保持60fps，粒子数控制在2000以内

## 5. 数据来源与样例

### 5.1 数据来源

| 数据来源 | 字段示例 |
|----------|----------|
| 申请单 | 申请编号、渠道、产品、申请日期、申请人 |
| 渠道 | 渠道编码、渠道名称（线上/线下/代理） |
| 产品 | 产品编码、产品名称（消费贷/经营贷/房贷） |
| 审批节点 | 节点ID、节点名称、进入量、通过量、拒绝量 |
| 拒绝原因 | 原因编码、原因描述、关联申请编号 |
| 漏斗报告 | 报告期次、生成时间、数据快照 |

### 5.2 样例数据

- **正常记录**：申请编号APP-2026-001，渠道=线上，产品=消费贷，完整通过初审→复审→终审→放款
- **边界记录**：申请编号APP-2026-002，渠道=代理，产品=经营贷，复审被拒后资料补充重新进入，同一申请出现重复节点
- **明显坏数据**：申请编号APP-2026-003，渠道=线上（但归属码指向线下代理），拒绝原因从"信用不足"被覆盖为"资料不全"
