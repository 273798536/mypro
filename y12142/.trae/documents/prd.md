## 1. 产品概述

电池热失控预警系统——面向储能站运维人员的一体化监控看板，解决电芯温度、柜号、维修记录跨系统对账困难，以及传感器漂移、阈值版本错、缺采样等异常被忽视的问题。

- 核心目的：将 3D 电池柜可视化、趋势监测、阈值校验说明、维修回看整合在同一画面，拖动/筛选/时间轴播放后所有面板联动更新
- 目标用户：储能站运维工程师、安全主管

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 运维工程师 | 浏览预警、筛选柜号/电芯、回看维修记录、播放时间轴 |
| 安全主管 | 查看阈值版本、校验结果、全局预警统计 |

### 2.2 功能模块

1. **预警总览页**：3D 电池柜模型 + 趋势监测面板 + 阈值校验面板 + 维修记录面板 + 时间轴 + 筛选栏

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 预警总览页 | 3D 电池柜可视化 | 展示电池簇/柜/电芯层级，选中电芯高亮，异常电芯着色预警；拖动旋转、缩放；点击电芯联动其他面板 |
| 预警总览页 | 筛选栏 | 按柜号、簇号、电芯ID、预警等级筛选；切换阈值版本；筛选变更后所有面板联动刷新 |
| 预警总览页 | 趋势监测面板 | 展示选中电芯的温度/电压时序曲线，叠加阈值线；支持时间轴拖动播放；标注传感器漂移区间和缺采样段 |
| 预警总览页 | 阈值校验面板 | 显示当前阈值版本、阈值参数、校验结果；对传感器漂移和阈值版本错给出文字说明；版本切换后重新校验 |
| 预警总览页 | 维修记录面板 | 按电芯/柜号关联历史维修记录，含维修日期、类型、结果；时间轴播放时同步高亮对应维修事件 |
| 预警总览页 | 时间轴 | 全局时间轴，可拖动/播放；拖动后 3D 模型着色、趋势图、阈值校验、维修记录全部更新 |

## 3. 核心流程

用户打开页面 → 3D 电池柜默认展示当前异常状态 → 点击/筛选某电芯 → 趋势监测显示该电芯温度/电压曲线 → 阈值校验面板解释当前预警依据（正常/传感器漂移/阈值版本错/缺采样）→ 拖动时间轴 → 所有面板同步更新到对应时间点状态 → 查看维修记录回溯历史处理

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰/近黑背景 (#0D1117)，配合琥珀色 (#F59E0B) 作为预警主色，红色 (#EF4444) 为严重预警，青绿 (#10B981) 为正常
- **辅助色**：冷灰边框、半透明面板底色
- **按钮风格**：小圆角、扁平化，预警等级按钮带颜色指示
- **字体**：JetBrains Mono 用于数值/代码，Noto Sans SC 用于中文正文
- **布局**：左侧 3D 视图占主体，右侧三面板（趋势、阈值、维修）纵向堆叠，底部时间轴横贯全宽，顶部筛选栏
- **图标风格**：线性图标，简洁工业风

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 预警总览页 | 3D电池柜 | 深色背景、电芯方格矩阵、异常渐变着色、选中高亮描边、hover 浮窗显示温度/电压 |
| 预警总览页 | 筛选栏 | 顶部固定栏，下拉选择柜号/簇号/电芯ID，预警等级色块按钮，阈值版本切换 |
| 预警总览页 | 趋势监测 | 折线图+阈值虚线+漂移区间阴影+缺采样断点标记，暗色图表风格 |
| 预警总览页 | 阈值校验 | 卡片式，当前阈值版本号、参数表格、校验结果标签（正常/漂移/版本错/缺采样），文字说明 |
| 预警总览页 | 维修记录 | 时间线列表，维修事件卡片含日期/类型/结果，与时间轴联动高亮 |
| 预警总览页 | 时间轴 | 底部滑块+播放按钮，刻度标记预警/维修事件，拖动时实时联动 |

### 4.3 响应式

- 桌面优先（1920×1080 最佳），宽屏下 3D + 右侧面板并列；窄屏下面板折叠为 tab 切换

### 4.4 3D 场景指引

- **环境**：暗色工业风 HDRI，微弱环境光，突出电芯发光效果
- **灯光**：顶部冷白平行光 + 电芯自发光（正常青绿/预警琥珀/严重红色）
- **相机**：45° 俯视等距视角，OrbitControls 允许拖动旋转和缩放
- **构图**：电池柜居中，电芯矩阵排列，选中电芯放大/描边
- **交互**：点击电芯选中联动，hover 显示浮窗，拖动旋转/缩放
- **后处理**：Bloom 发光效果用于预警电芯，微弱景深
- **资产**：程序化生成电池柜/电芯几何体，无外部模型依赖
