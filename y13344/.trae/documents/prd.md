## 1. 产品概述

排班推荐指标看板是一个面向 AI 产品经理和数据分析人员的评测质量监控工具。核心解决三个问题：同一样本被重复评测时链路不清晰、人工修正与原始数据混在一起无法溯源、阈值漂移混在正常指标里不易发现。看板要求筛选条件、统计数字、明细表和接口返回全部从同一套结果生成，确保数据一致性。

- 目标用户：AI 产品经理、数据标注老师、排班算法评测人员
- 核心价值：让评测全链路可追溯、异常可标记、版本可对比，新接手的人不用问也能知道哪里放材料、哪里看异常、哪里重新导出

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 产品经理 | 查看看板、对比版本、查看接口返回 | 全部查看权限、触发重跑、导出 |
| 数据标注老师 | 查看明细、录入人工修正、标记异常 | 查看明细、录入修正、导出 |
| 算法评测人员 | 筛选指标、分析阈值漂移、导出数据 | 全部查看权限、筛选、导出 |

### 2.2 功能模块

1. **指标看板主页**：筛选条件区、统计卡片区、样本明细表、快速操作入口
2. **样本评测链路页**：单条样本的完整评测链路、人工修正记录、阈值漂移标记
3. **版本对比页**：前一版 vs 当前版的指标变化、样本差异、阈值偏移对比
4. **使用说明页**：样例演示、重跑操作、查看接口返回三件事讲清楚

| 页面名称 | 模块名称 | 功能描述 |

## 3. 核心流程

**主流程**：用户进入看板主页 → 设置筛选条件 → 查看统计卡片和明细表 → 发现异常样本（人工修正标记/阈值漂移标记）→ 点击进入评测链路页 → 查看完整评测链路、人工修正记录、接口返回 → 必要时触发重跑或导出数据

**版本对比流程**：选择前一版和当前版 → 查看指标概览差异 → 下钻到样本差异和阈值偏移 → 检查人工修正变化 → 导出对比结果

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1e293b) 为底，搭配青蓝 (#06b6d4) 作为强调色，暖橙 (#f97316) 标记异常/阈值漂移
- **辅助色**：翠绿 (#10b981) 表示正常/通过，琥珀 (#f59e0b) 表示警告，玫红 (#f43f5e) 表示严重异常
- **按钮风格**：圆角微阴影，主要操作用实色填充，次要操作用描边
- **字体**：标题用 Source Han Sans / Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据数字用 JetBrains Mono
- **布局风格**：左侧固定导航栏 + 右侧内容区，内容区内使用卡片网格布局
- **图标风格**：线性图标 (Lucide)，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 指标看板主页 | 筛选条件区 | 顶部横条，下拉选择器 + 日期范围 + 开关（有人工修正/有阈值漂移），毛玻璃背景 |
| 指标看板主页 | 统计卡片区 | 5张统计卡片横排，深色卡片 + 大号数字 + 底部趋势迷你图，hover 微上浮 |
| 指标看板主页 | 样本明细表 | 全宽表格，表头固定，行hover高亮，异常行左侧橙色竖条标记，阈值漂移行红色竖条标记 |
| 指标看板主页 | 快速操作 | 右上角操作按钮组，导出/重跑/查看接口返回，下拉菜单展开 |
| 样本评测链路页 | 评测链路时间线 | 左侧垂直时间线，每个节点显示版本号+时间+指标值，连线动画入场 |
| 样本评测链路页 | 人工修正记录 | 对比卡片，左原始值右修正值，中间箭头，底部灰色小字注明修正人和时间 |
| 样本评测链路页 | 阈值漂移标记 | 红色/橙色标签徽章，hover 显示漂移幅度和当前阈值 |
| 版本对比页 | 指标概览对比 | 双列卡片，左前一版右当前版，差异值用颜色区分增减 |
| 版本对比页 | 样本差异列表 | 三段Tab（新增/删除/变化），列表项含样本ID和指标差异值 |
| 使用说明页 | 全页面 | 三段式布局（样例/重跑/接口返回），代码块用深色背景，步骤用数字标记 |

### 4.3 响应式

- 桌面优先设计，最小支持 1280px 宽度
- 1920px 以上统计卡片可增至一行6张
- 1280px 以下明细表横向滚动
- 移动端暂不作为主要适配目标
