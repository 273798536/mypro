# 公交港湾方案比选

面向城市规划师的方案比选留痕系统。把「靠人记」变成「系统留痕」，让每条巡检材料与比选结论的因果关系可追溯。

## 快速开始

```bash
npm install
npm run dev
```

## 两三步操作

1. **打开首页** → 左栏筛选容量超限/材料不齐的方案，点卡片进入详情
2. **详情页操作栏** → 「补录照片」新增巡检材料、「重跑比选」重算结论、「导出报告」下载 ZIP
3. **下方 Tab 切换** → 查看附件材料 / 原因链说明 / 历史时间线

## 坏材料来了该看哪里

| 问题 | 查看位置 | 视觉标记 |
|------|----------|----------|
| 容量超限 | 方案卡片右上角 / 详情页概览 / 材料卡片 | 红色 `容量超限` 标签、红色虚线边框 |
| 晚到附件 | 原因链面板 / 材料卡片 / 时间线 | 红色 `晚到附件` 标签 + 原因链节点加粗红框 |
| 原始脏数据 | 材料卡片右上角 / 导出 `flags.json` | 深色 `原始数据` 标签（文件名不清洗、缩略图不调优） |
| 最近补录改了什么 | 地图点位脉冲圈 / 历史时间线 | 琥珀色脉冲动画 + 时间线 diff 对比 |

## 导出内容

`导出报告` 生成的 ZIP 包含：
- `方案名-比选报告.md`：含原因链、异常标记汇总、时间线
- `manifest.json`：完整原始数据
- `flags.json`：超限/晚到/脏数据计数（便于脚本二次处理）

## 说明

所有操作（补录/改结论/重跑/导出）均写入历史时间线，不可删除，永久留痕。
