## 1. 产品概述

仓单质押价格预警系统是面向供应链金融风控人员的业务工具，解决质检降级、重复仓单、价格缺口等风险场景下手工对账效率低、易遗漏的问题。系统通过仓单档案、质检报告、质押合同"三档对齐"，实现风险自动识别、全链路追溯和复核留痕。

- 解决问题：风控人员需同时查看多份文档人工比对，易遗漏风险且无法追溯
- 目标用户：供应链金融风控专员、复核主管
- 核心价值：风险自动识别、数据不丢失、全链路可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 风控专员 | 系统分配 | 查看预警、筛选、复核操作、导出数据 |
| 复核主管 | 系统分配 | 审核复核结果、查看全量数据、导出报表 |

### 2.2 功能模块

1. **预警列表页**：多维度筛选、数据刷新不丢状态、批量复核、导出
2. **预警详情页**：三档对齐视图（仓单档案/质检报告/质押合同）、风险追溯链路、复核记录
3. **数据看板**：风险类型统计、预警趋势、复核进度

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 预警列表页 | 筛选区 | 按预警类型（质检降级/重复仓单/价格缺口）、仓单编号、客户名称、预警等级、时间范围筛选 |
| 预警列表页 | 列表区 | 展示预警概览、支持刷新（保留筛选条件）、点击进入详情 |
| 预警列表页 | 操作区 | 批量复核、单条复核、导出Excel、重置筛选 |
| 预警详情页 | 三档对齐区 | 并排展示仓单档案、质检报告、质押合同核心字段，差异高亮 |
| 预警详情页 | 风险追溯区 | 从预警结果 → 押品估值 → 额度重算 → 仓单状态的完整链路 |
| 预警详情页 | 复核操作区 | 填写复核意见、选择处理结果（确认风险/排除风险/待补充材料） |

## 3. 核心流程

```mermaid
flowchart LR
    A["风控专员登录"] --> B["查看预警列表"]
    B --> C["筛选/搜索预警"]
    C --> D["点击预警进入详情"]
    D --> E["查看三档对齐数据"]
    E --> F["追溯押品估值/额度/状态"]
    F --> G["填写复核意见"]
    G --> H["提交复核结果"]
    H --> I["系统更新预警状态"]
    I --> J["导出复核报告"]
```

### 关键业务场景说明

1. **质检降级场景**：质检报告等级低于质押合同约定等级 → 触发预警 → 追溯押品估值下调 → 额度重算 → 建议补保证金或追加质押
2. **重复仓单场景**：同一仓单编号对应多笔质押合同 → 触发预警 → 追溯各笔合同额度 → 提示重复质押风险
3. **价格缺口场景**：当前市场价格×质押率 < 剩余未还本金 → 触发预警 → 追溯价格波动历史 → 建议追加质押物

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：专业深蓝色（#1e3a5f），代表金融风控的严谨性
- **辅助色**：预警红（#dc2626）、警告橙（#f59e0b）、正常绿（#16a34a）、信息蓝（#2563eb）
- **中性色**：深灰（#1f2937）、中灰（#6b7280）、浅灰（#f3f4f6）
- **字体**：标题使用"Noto Sans SC"，正文使用"PingFang SC"，数字使用等宽字体"JetBrains Mono"
- **按钮风格**：直角、2px边框、hover状态深色填充，体现专业严谨
- **布局风格**：卡片式布局，清晰的区域分隔，数据密集型表格为主
- **图标**：使用lucide-react线性图标，保持简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 预警列表页 | 筛选区 | 下拉选择器、日期范围、搜索框、重置按钮，紧凑排列 |
| 预警列表页 | 列表区 | 斑马纹表格、预警等级徽章、状态标签、hover高亮行 |
| 预警详情页 | 三档对齐区 | 三栏等宽布局、差异字段红色高亮边框、数据对齐线 |
| 预警详情页 | 追溯链路区 | 时间轴样式、箭头连接、关键节点可展开 |
| 预警详情页 | 复核区 | 文本域、单选按钮组、提交按钮、历史复核记录时间线 |

### 4.3 响应式

- 桌面端优先设计（1440px及以上）
- 平板端（768-1440px）：三档对齐改为上下堆叠，表格支持横向滚动
- 移动端（<768px）：简化为卡片列表，核心数据优先展示

### 4.4 动画与交互

- 页面加载：骨架屏渐入，数据行错位延迟显示
- 刷新操作：按钮旋转动画，数据更新时行高轻微变化
- 风险高亮：差异字段脉冲动画提示
- 追溯链路：节点点击时展开动画
