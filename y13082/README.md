# 码头危险品库碰撞预审系统 (WHARF-DSS)

面向方案经理的码头危险品库三维点位碰撞预审管理系统。支持批次列表、详情可视化、人工改判、历史追溯、异常队列集中处理、视图条件保存与 CSV 导出。所有点位坐标**保留原始脏数据**，不做自动清洗。

---

## 快速开始（方案经理小赵必读）

### 第一步：启动服务

```bash
npm install   # 首次运行需安装依赖
npm run dev   # 同时启动前端(5173)和后端(3001)
```

启动后浏览器访问：**http://localhost:5173**

### 第二步：先看哪份异常队列

1. 打开首页后，点击顶部导航的 **「异常队列」**（右上角带 LIVE 红色标记的那个）
2. 页面加载后默认展示所有异常。如果想快速看到最棘手的 **「对象重叠」** 案例：
   - 点击顶部 **「已保存视图」** 按钮 → 选择 **「重叠异常优先」**
   - 这是预置的小赵同事留下的视图，会把对象重叠的异常排在最前面
3. 或者点 **「异常类型」** 筛选 → 勾选 **「对象重叠」**，即可单独过滤
4. 要导出当前看到的异常 → 点击右上角 **「导出 CSV」**，导出内容和页面筛选状态**完全一致**

> 💡 试跑提示：种子数据中的 `WH-2026-0610-01`（3号危险品库甲类）和 `WH-2026-0612-03`（12号储罐区B区）都埋了对象重叠案例，点位坐标完全重合，进「碰撞预审」点进去就能看到。

## 现场材料数据包说明

首次启动会自动生成 SQLite 数据库并写入现场材料样例（位于 `data/wharf_collision.db`），包含以下真实场景脏数据：

| 异常类型 | 说明 | 所在批次 |
|---------|------|---------|
| 🟥 对象重叠 | 两个化学品桶/储罐坐标完全相同，必现碰撞 | 3号甲类库、12号储罐B区 |
| 🟧 坐标缺失 | 原始值为空字符串或 null | 所有批次均有 |
| 🟨 格式异常 | 原始值为 "N/A"、"--"、"???"、"未录入"、"TBD" 等非数字文本 | 所有批次均有 |
| 🟠 越界坐标 | 点位超出仓库边界（X[0,40] / Y[0,20] / Z[0,5]） | 所有批次均有 |

### 点位数据字段设计（保留原始痕迹）

| 字段 | 作用 | 脏数据示例 |
|-----|------|-----------|
| `rawX/rawY/rawZ` | **原始值**，字符串或 null，**永远不修改** | `"N/A"`, `"--"`, `""`, `null` |
| `parsedX/parsedY/parsedZ` | 解析后的数值，解析失败为 null | `null` |
| `isDirty` | 是否为脏数据（原始值无法解析或缺失） | `true` / `false` |
| `source` | 数据来源：激光扫描 / 人工录入 / 系统导入 | 用于追溯脏数据来源 |

## 功能模块

### 1. 碰撞预审列表 `/batches`
- 所有预审批次总览，统计卡片显示异常总数、待审核、已改判、已完成
- 按状态筛选（待审核/已改判/已完成），关键词搜索批次号或仓库名
- 点击批次进入详情

### 2. 预审详情 `/batches/:id`
- **点位可视化**：Canvas 3D 模拟（等距/正视/侧视/俯视四种视角），支持缩放、点击点位
- **原始坐标表**：双列对比显示「原始值」与「解析值」，脏数据行高亮橙色，永远保留原始痕迹
- **碰撞/异常列表**：列出系统判定的所有异常，支持单条改判，改判理由和改判人写入历史

### 3. 改判操作
- 改判结果：确认碰撞 / 排除误报 / 待复核
- 必填理由，操作人自动填入当前登录名（方案经理-小赵）
- 所有改判自动写入历史记录表，可追溯

### 4. 改判历史 `/history`
- 时间线展示所有改判记录，显示操作人、前后状态、改判理由、时间戳
- 支持按批次 ID 筛选

### 5. 异常队列 `/anomalies`（核心）
- 所有批次异常集中处理，4列卡片网格展示
- 支持按异常类型、判定状态筛选，按发现时间排序
- **视图条件保存**：保存当前筛选、排序、视角参数，一键恢复（接手同事的核心功能）
  - 预置视图：「小赵常用视图」、「重叠异常优先」
- **导出 CSV**：导出文件内容与页面当前筛选状态完全一致，含异常ID、批次、类型、状态、描述、改判信息
- 右侧详情预览面板：点击卡片即可查看异常详情并快速改判

### 6. 接手同事操作指引
1. 打开「异常队列」
2. 点击顶部 **「已保存视图」** → 选择小赵同事保存的视图条件
3. 异常卡片即按原筛选/排序条件展示
4. 点击异常卡片，右侧面板切换视角（等距/正视/侧视/俯视）→ 截图留档

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | React 18 + TypeScript + Vite 6 + TailwindCSS 3 + Zustand + React Router 7 + Lucide Icons |
| 后端 | Express 4 + TypeScript + better-sqlite3 |
| 数据库 | SQLite（文件存储 `data/wharf_collision.db`，开箱即用） |
| 3D 可视化 | Canvas 2D + 等距/正交投影（轻量无 three.js 依赖） |

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/batches` | 获取预审批次列表，支持 `status` 和 `keyword` 查询 |
| GET | `/api/batches/:id` | 获取批次详情（含点位和碰撞结果） |
| GET | `/api/batches/:id/points` | 获取批次原始点位坐标 |
| GET | `/api/batches/:id/collisions` | 获取批次碰撞结果 |
| POST | `/api/collisions/:id/rejudge` | 改判碰撞/异常结果 |
| GET | `/api/history` | 获取改判历史，支持 `batchId` 筛选 |
| GET | `/api/anomalies` | 获取异常队列，支持 `types`、`status`、`sortBy`、`sortOrder` |
| GET | `/api/anomalies/export` | 导出异常队列 CSV（与筛选条件一致） |
| GET | `/api/views` | 获取已保存视图条件列表 |
| GET | `/api/views/:id` | 获取单个视图条件 |
| POST | `/api/views` | 保存当前视图条件 |

## 重置现场材料

如需清空数据库并重新生成种子数据：

```bash
rm -rf data/
npm run dev   # 重启服务后自动重新建库并写入样例
```
