## 1. 产品概述
地铁客流疏散模拟游戏——面向站务培训场景的轻量Web原型
- 主要目标：帮助站务主管培训员工在闸机故障、临时封站等紧急情况下的客流疏导能力，通过游戏化模拟提供可量化的操作反馈
- 目标用户：地铁运营站务主管、站务培训专员

## 2. 核心功能

### 2.1 功能模块
1. **游戏主界面**：站厅地图、实时人流、闸机状态、操作面板
2. **人流模拟**：乘客自动行走、拥堵检测、疏散计时
3. **广播系统**：预设广播选项、自定义广播内容、广播记录
4. **路线管理**：封闭区域设置、闸机启停控制、通道引导
5. **评分系统**：实时分数计算、操作评分、事件响应评分
6. **报告导出**：处置报告生成、操作记录回放、失败原因分析

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主界面 | 站厅地图 | SVG绘制的站厅平面图，显示乘客位置、闸机状态、出口方向 |
| 游戏主界面 | 乘客流模拟 | Canvas动画模拟乘客行走，拥堵时颜色变红 |
| 游戏主界面 | 操作面板 | 闸机控制按钮、广播选择下拉、区域封闭开关 |
| 游戏主界面 | 分数面板 | 实时分数、时间倒计时、事件触发提示 |
| 游戏主界面 | 操作记录 | 玩家每步操作日志，含行号和来源追踪 |
| 结束报告 | 处置报告 | 总分、各维度得分、操作时间线、失败原因列表 |
| 结束报告 | 回放模式 | 可拖动时间轴回看关键事件节点 |
| 结束报告 | 导出功能 | 导出JSON格式的处置报告 |

## 3. 核心流程

### 3.1 游戏流程
```mermaid
flowchart TD
    "开始游戏" --> "加载关卡配置"
    "加载关卡配置" --> "初始化站厅地图"
    "初始化站厅地图" --> "乘客流开始"
    "乘客流开始" --> "触发紧急事件"
    "触发紧急事件" --> "玩家选择操作"
    "玩家选择操作" --> "执行操作"
    "执行操作" --> "更新分数"
    "更新分数" --> "记录操作轨迹"
    "记录操作轨迹" --> "检查游戏状态"
    "检查游戏状态" --> "是否游戏结束"
    "是否游戏结束" --> "继续游戏"
    "继续游戏" --> "乘客流继续"
    "乘客流继续" --> "触发紧急事件"
    "是否游戏结束" --> "生成处置报告"
    "生成处置报告" --> "查看回放"
    "查看回放" --> "导出报告"
```

### 3.2 评分逻辑
- 疏散效率分：乘客疏散时间越短得分越高
- 秩序维护分：拥堵次数越少得分越高
- 响应及时性分：事件触发后操作越快得分越高
- 广播有效性分：正确广播类型与时机得分
- 路线规划分：封闭区域合理性得分

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝(#1a365d) + 橙色(#e67e22) 作为紧急事件提示
- 辅助色：灰色(#2d3748) + 绿色(#48bb78) 作为正常状态
- 按钮风格：圆角矩形，悬停有阴影效果
- 字体：使用等宽字体(Courier New)用于数据显示，宋体用于中文说明
- 布局：三栏布局(左：操作面板 / 中：站厅地图 / 右：信息面板)
- 图标：使用SVG图标，紧急事件使用闪烁动画

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|---------|
| 游戏主界面 | 站厅地图 | 深色背景，乘客用小圆点表示，拥堵区域红色高亮 |
| 游戏主界面 | 操作面板 | 卡片式按钮分组，闸机状态用开关组件 |
| 游戏主界面 | 分数面板 | 大数字实时显示，分数变化有动画效果 |
| 结束报告 | 处置报告 | 表格形式展示得分明细，操作时间线用甘特图 |
| 结束报告 | 回放模式 | 时间轴滑块，可拖动定位到任意时间点 |

### 4.3 响应式设计
- 桌面优先设计，最低支持1280x720分辨率
- 站厅地图使用SVG自适应缩放
- 操作面板在小屏幕折叠为抽屉

## 5. 错误追踪设计

### 5.1 操作记录格式
```
[行号:42] [来源:广播面板] 玩家选择广播: "请从A出口疏散"
[行号:43] [来源:闸机控制] 玩家关闭闸机B2
[行号:44] [来源:区域管理] 玩家封闭区域: 站厅北侧
```

### 5.2 错误提示格式
```
[警告] [来源:客流引擎] 闸机B2拥堵！乘客等待时间超过30秒
[错误] [来源:广播系统] 广播漏发！紧急事件触发后60秒未广播
[提示] [来源:路线规划] 路线绕远！乘客A123绕行距离增加50%
```

### 5.3 报告导出格式
- JSON格式，包含完整操作记录、得分明细、事件时间线
- 每条记录保留原始行号和来源模块
