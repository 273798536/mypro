## 1. 产品概述

音乐节舞台排期赛是一款面向活动统筹培训的模拟游戏。玩家在时间轴上为艺人安排演出时段，同时管理舞台设备调度和观众流向，每次操作都会真实改变局面并影响最终报告。

- 解决问题：纸质排班一天改十几版、换场超时结论模糊、设备冲突和人流拥堵无法溯源
- 目标用户：活动统筹人员培训、音乐节运营团队新人
- 核心价值：让统筹在模拟环境中练习排期决策，每个冲突都能指回艺人时段或舞台设备的具体位置

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 玩家（活动统筹） | 单一角色，执行排期决策 |

### 2.2 功能模块

1. **排期主界面**：时间轴拖拽排期、艺人卡片池、舞台轨道、冲突实时提示
2. **天气卡与观众热度面板**：天气事件触发、观众热度变化、对排期的影响解读
3. **冲突检测与溯源面板**：换场超时精确结论、设备冲突溯源、人流拥堵溯源
4. **暂停/重开/复盘控制台**：时间轴回放拖拽、操作历史、冲突提示影响追溯
5. **最终报告页**：排期总评、分数图表、与艺人时段/舞台设备关系解释

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 排期主界面 | 时间轴轨道 | 多轨道（主舞台/副舞台/小舞台）时间轴，支持拖拽艺人时段到轨道上，显示换场间隔 |
| 排期主界面 | 艺人卡片池 | 展示待安排的艺人卡片，包含艺人时段、设备需求、观众热度标签 |
| 排期主界面 | 冲突提示浮层 | 实时检测并在时间轴上标红冲突位置，点击可查看具体冲突原因与溯源 |
| 排期主界面 | 天气卡区域 | 随机触发天气事件卡片（暴雨/大风/高温），显示对当前排期的影响 |
| 排期主界面 | 观众热度面板 | 显示各时段观众热度分布，热度变化与艺人时段安排的关系说明 |
| 冲突溯源面板 | 换场超时详情 | 显示"艺人A（主舞台 18:00-18:45）→ 艺人B（主舞台 18:45-19:30）：换场需20分钟，实际仅0分钟，超时20分钟" |
| 冲突溯源面板 | 设备冲突详情 | 显示"音响系统：艺人A（主舞台 18:00-18:45）与艺人C（副舞台 18:30-19:15）共用，时段重叠15分钟" |
| 冲突溯源面板 | 人流拥堵详情 | 显示"18:30-19:00：主舞台（艺人A散场）与副舞台（艺人C开场）观众流交汇，预计拥堵等级：高，源自艺人A时段与艺人C时段的相邻安排" |
| 暂停/重开/复盘 | 控制栏 | 暂停游戏、重新开始、进入复盘模式 |
| 暂停/重开/复盘 | 时间轴回放 | 复盘模式下可拖拽时间轴到任意时刻，查看当时的排期状态和冲突 |
| 最终报告页 | 排期总评 | 综合评分、换场超时次数、设备冲突次数、人流拥堵次数 |
| 最终报告页 | 分数图表 | 柱状图/雷达图显示各维度得分，旁边解释与艺人时段、舞台设备的关系 |
| 最终报告页 | 冲突时间线 | 所有冲突事件按时间排列，点击可跳转到对应艺人时段位置 |

## 3. 核心流程

玩家进入游戏后，看到空白时间轴和艺人卡片池。拖拽艺人到时间轴轨道上安排演出时段，系统实时检测冲突并提示。天气卡随机触发改变局面。观众热度随艺人安排变化。游戏结束后生成最终报告。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色系（#0F1419 深夜蓝黑底色）+ 霓虹橙（#FF6B35）作为强调色，模拟音乐节夜间氛围
- 次色调：电子青（#00E5FF）用于信息提示，热力红（#FF2D55）用于冲突警告
- 按钮风格：圆角矩形，微发光边框效果
- 字体：显示字体用 Orbitron（科技感标题），正文字体用 Noto Sans SC（中文可读性）
- 布局：左侧艺人卡片池 + 中间时间轴轨道 + 右侧信息面板
- 图标风格：线性图标（lucide-react），配合霓虹发光效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 排期主界面 | 时间轴轨道 | 横向时间轴（10:00-23:00），3条舞台轨道，拖拽放置区域，换场间隔色带 |
| 排期主界面 | 艺人卡片池 | 竖向卡片列表，每张含艺人名/时段/设备/热度标签，拖拽手柄 |
| 排期主界面 | 冲突提示 | 时间轴上红色标记，点击弹出溯源面板，含艺人时段定位链接 |
| 排期主界面 | 天气卡 | 顶部横幅式天气事件卡片，带动画效果 |
| 冲突溯源面板 | 换场超时 | 精确到分钟的结论文本，高亮涉及的艺人时段与舞台 |
| 冲突溯源面板 | 设备冲突 | 设备名+两个艺人时段的重叠区间，可点击跳转 |
| 冲突溯源面板 | 人流拥堵 | 拥堵等级+涉及艺人时段+流向示意 |
| 最终报告页 | 分数图表 | 雷达图+柱状图，旁注解释与艺人时段/舞台设备关系 |

### 4.3 响应式

- 桌面端优先设计（培训场景主要在电脑上操作）
- 最小宽度 1024px，确保时间轴可读性

| 舞台 | 可用设备 | 换场时间 |
|------|----------|----------|
| 主舞台 | 重型音响、标准音响、灯光矩阵、简单灯光、LED屏、烟火装置 | 20分钟 |
| 副舞台 | 标准音响、舞蹈灯光、LED屏、烟雾机 | 15分钟 |
| 小舞台 | 原声乐器、麦克风 | 10分钟 |

### 5.3 天气卡

| 天气卡 | 触发时机 | 效果 |
|--------|----------|------|
| 暴雨预警 | 安排3个艺人后 | 小舞台设备暂停使用30分钟，观众热度-20% |
| 高温橙色 | 安排5个艺人后 | 观众热度+15%，但连续演出超60分钟的艺人需减10分钟 |
| 大风蓝色 | 安排4个艺人后 | 烟火装置禁用，LED屏需加固（换场+5分钟） |
| 天晴好日 | 安排6个艺人后 | 所有舞台换场-5分钟，观众热度+10% |

### 5.4 观众热度规则

- 艺人安排在黄金时段（18:00-21:00）：热度×1.3
- 同一时段相邻舞台有高热度艺人：人流拥堵风险+50%
- 天气卡直接影响热度系数
- 连续同舞台安排：疲劳衰减-10%/场
