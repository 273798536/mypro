# 港口堆场箱位三维图 - 使用说明

## 一、启动

### 1.1 环境
- Node.js v16+
- Chrome/Edge 90+、Firefox 88+、Safari 14+（需支持 WebGL 2.0）

### 1.2 启动步骤
1. 安装依赖：`npm install`
2. 启动：`npm run dev`
3. 浏览器打开 http://localhost:5173

### 1.3 首次打开
首次打开自动加载示例数据，无需先造表即可操作。

## 二、导入数据

### 2.1 支持格式
- Excel（.xlsx, .xls）
- CSV（.csv）
- JSON（.json）

### 2.2 数据字段
必需字段：`name`, `x`, `y`, `z`, `width`, `height`, `depth`

### 2.3 导入步骤
1. 点击右上角「导入数据」
2. 选择文件
3. 系统自动解析并检测异常
4. 异常结果显示在左侧列表

## 三、查看异常

### 3.1 异常列表
左侧面板列出所有异常，包含：
- 异常类型（模型重叠、相机视角丢失、尺寸超限、位置偏移）
- 严重程度（高危/中危/低危）
- 处理状态（待处理/处理中/已处理/已复核）
- 风险备注摘要

### 3.2 筛选
点击「筛选」按钮，可按异常类型、严重程度、处理状态多选筛选。

### 3.3 查看详情
点击异常记录，右侧显示详情：
- 基本信息
- 来源信息（导入批次、源文件、导入时间）
- 风险备注（含变更历史）
- 处理意见（含变更历史）
- 完整处理历史追溯

### 3.4 三维联动
- 点击异常后，三维视图高亮相关箱位
- 可旋转、缩放、平移查看
- 三维视图右上角可导出场景截图

## 四、处理异常

### 4.1 状态流转
待处理 → 处理中 → 已处理 → 已复核

每步变更都需填写操作原因，系统自动记录。

### 4.2 填写信息
在异常详情中可：
- 添加/修改风险备注
- 填写/修改处理意见

每次修改会记录变更前内容、变更后内容、操作人和原因。

## 五、历史追溯

### 5.1 进入历史追溯
点击右上角「历史追溯」按钮。

### 5.2 查询
- 搜索：操作人、原因、异常ID
- 筛选：按操作人、操作类型筛选

### 5.3 追溯内容
每条记录显示：
- 谁改的（操作人 + 角色）
- 什么时候改的（时间）
- 改了什么（变更前 → 变更后）
- 为什么改（操作原因）

### 5.4 跳回异常详情
历史记录中关联异常的，点击「查看异常详情」可直接跳回。

## 六、导出结果

### 6.1 导出异常报告（PDF）
点击右上角「导出报告」，生成所有异常的 PDF 报告，含风险备注、处理意见和处理记录。

### 6.2 导出场景截图（PNG）
三维视图右上角「导出场景截图」，截图同时生成处理记录和历史日志。

### 6.3 导出单条异常追溯报告（PDF）
异常详情顶部「导出追溯报告」，导出该异常的完整追溯链。

### 6.4 数据一致性
界面明细、截图、报告共用同一批处理记录，不会各算各的。

## 七、相机视角丢失

### 7.1 检测
系统自动检测以下情况：
- 视角参数全为 0
- 视角坐标超出范围
- 缩放比例异常

### 7.2 处理
1. 在异常列表找到「相机视角丢失」
2. 开始处理，在三维视图中手动调整视角
3. 标记已处理，复核确认

## 八、数据存储
所有数据存在浏览器本地（IndexedDB），换浏览器或清除数据会丢失。
