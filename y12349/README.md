# 电池循环衰减分析3D可视化平台

专为新能源实验员设计的电池循环测试数据可视化分析工具，通过交互式3D场景与详细数据面板联动，解决传统数据复核中信息压缩、风险笼统等问题。

## 功能特性

### 3D可视化
- 实时3D电池模型，根据容量衰减率动态变色（绿→黄→红）
- 异常事件时红色脉冲发光效果
- 播放动画时电池自动旋转
- 支持鼠标拖拽旋转、缩放、平移

### 数据面板
- **循环记录**: 查看每次循环的详细数据（容量、倍率、温度、效率）
- **衰减曲线**: 容量变化趋势图 + 指数衰减拟合曲线
- **异常事件**: 所有异常事件列表，支持快速定位

### 时间轴控制
- 拖动滑块快速跳转到指定循环
- 播放/暂停动画自动遍历
- 0.5x/1x/2x/4x 四档速度调节

### 异常详情
点击异常事件可查看完整信息：
- **中断重启**: 原因分析 + 处理建议
- **倍率切换**: 实验方案说明 + 监测建议  
- **温度漂移**: 根本原因 + 校正方法
- 数据来源追溯标签，便于复核验证

### 分析工具
- 数据筛选：按充电倍率范围、温度区间过滤
- 批次对比：多组实验数据对比分析
- CSV导出：完整循环数据 + 拟合参数
- 寿命预测：基于拟合模型预计EOL（80%容量）次数

## 技术栈

- **框架**: React 18 + TypeScript
- **构建**: Vite 5
- **3D渲染**: Three.js + @react-three/fiber + @react-three/drei
- **状态管理**: Zustand 4
- **图表**: Recharts 2
- **样式**: Tailwind CSS 3
- **图标**: Lucide React

## 数据说明

### 模拟数据包含
- 500次循环测试数据
- 4个异常事件（第127/200/350/412次循环）
- 3种异常类型：中断重启、倍率切换、温度漂移
- 完整的原因分析和处理建议

### 拟合算法
采用指数衰减模型：`f(x) = a * exp(-b * x) + c`
使用梯度下降法进行参数拟合，计算R²拟合优度
