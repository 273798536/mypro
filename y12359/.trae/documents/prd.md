## 1. 产品概述

频谱仪校准复盘系统——为实验室管理员提供数据驱动的校准复盘能力，解决复盘报告中口径不一致、异常归因笼统、溯源信息缺失的问题。系统将标准信号、读数记录、设备编号、环境修正等关键数据解耦展示，确保筛选条件变更时图表与明细同步，并支持补录设备编号后自动标注受影响明细，使复盘报告可交付、可复核。

- 目标用户：实验室管理员、质量复核人员
- 核心价值：将"凭感觉解释"变为"有据可查"，让标准过期、温漂异常、读数缺口各自独立可说明

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 实验室管理员 | 默认进入 | 创建复盘、配置筛选、补录设备编号、导出报告 |
| 复核人员 | 只读链接 | 查看复盘详情、查看溯源关系、下载报告 |

### 2.2 功能模块

1. **复盘总览页**：筛选面板、统计图表、异常分类汇总、快捷导出
2. **复盘详情页**：校准偏差步骤、环境修正步骤、异常解释步骤、溯源关系面板、补录影响标注

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 复盘总览页 | 筛选面板 | 按时间范围、设备编号、标准信号类型、异常类别筛选；筛选条件变更时图表和明细表格同步刷新 |
| 复盘总览页 | 异常分类汇总卡片 | 三张独立卡片分别展示：标准过期、温漂异常、读数缺口，各自给出数量、占比、严重等级，不合并为笼统风险 |
| 复盘总览页 | 统计图表区 | 偏差趋势折线图（按校准批次）、异常类别分布饼图、环境修正幅度柱状图；均随筛选联动 |
| 复盘总览页 | 明细表格 | 标准信号、设备编号、复盘报告各占独立列，每行可展开查看溯源来源；补录设备编号的行有醒目标注 |
| 复盘总览页 | 快捷导出 | 导出当前筛选条件下的复盘报告（含对应关系），导出内容与页面筛选状态一致 |
| 复盘详情页 | 校准偏差步骤 | 展示实测值 vs 标准值偏差、偏差方向、偏差百分比、可接受阈值区间，以步骤条形式呈现 |
| 复盘详情页 | 环境修正步骤 | 展示温度/湿度实测值、修正系数、修正前后对比、温漂贡献度分析 |
| 复盘详情页 | 异常解释步骤 | 分别列出标准过期说明、温漂异常说明、读数缺口说明，各自独立可编辑 |
| 复盘详情页 | 溯源关系面板 | 展示标准信号→读数记录→报告导出的三级对应关系，每级标明来源与时间戳 |
| 复盘详情页 | 补录影响标注 | 若设备编号为补录，自动标注"补录"标签，并列出该编号影响的所有明细记录 |

## 3. 核心流程

用户打开系统后进入复盘总览页，通过筛选面板缩小范围，图表与明细表格实时联动。发现异常后点击明细行进入复盘详情页，依次查看校准偏差、环境修正、异常解释三步，每步独立展示数据与结论。在溯源关系面板中可追溯标准信号、读数记录、报告导出的对应关系。若设备编号为后补录，系统自动标注受影响明细。确认无误后返回总览页导出复盘报告。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 #1B2A4A，辅以冷钢灰 #4A5568；强调色用琥珀橙 #E8913A 标注异常与补录
- 按钮风格：微圆角（4px）、扁平化，主操作用实底靛蓝，异常操作用琥珀橙描边
- 字体：标题用 JetBrains Mono 体现仪器感，正文用 Noto Sans SC 保证中文可读性
- 布局风格：左侧固定筛选面板 + 右侧主内容区，卡片式模块分区
- 图标风格：线性描边图标，2px 线宽，统一感强

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 复盘总览页 | 筛选面板 | 固定左侧栏，多选下拉框+日期范围选择器+异常类别复选组，筛选后显示当前条件标签 |
| 复盘总览页 | 异常分类汇总卡片 | 三张并排卡片，各自有图标、计数、迷你环形进度条，颜色区分（红=过期、橙=温漂、灰=缺口） |
| 复盘总览页 | 统计图表区 | 三个图表横排：折线图、饼图、柱状图，深色背景浅色数据线 |
| 复盘总览页 | 明细表格 | 可展开行，标准信号列带来源链接、设备编号列补录行显示橙色"补录"徽章、复盘报告列带导出图标 |
| 复盘总览页 | 快捷导出 | 右上角固定按钮，点击弹出导出选项弹窗（PDF/Excel） |
| 复盘详情页 | 校准偏差步骤 | 步骤条横向排列，当前步高亮，偏差柱状对比图 + 阈值区间阴影带 |
| 复盘详情页 | 环境修正步骤 | 温度/湿度仪表盘 + 修正前后对比表，温漂贡献度环形图 |
| 复盘详情页 | 异常解释步骤 | 三个独立折叠面板，各自有编辑区域，保存后显示最后修改时间 |
| 复盘详情页 | 溯源关系面板 | 三级树形结构（标准信号→读数记录→报告导出），每级节点显示来源与时间戳 |
| 复盘详情页 | 补录影响标注 | 橙色虚线边框区域，列出受影响明细编号列表，每条可点击跳转 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1280px
- 筛选面板在 1024px 以下折叠为顶部下拉
- 图表区在窄屏下纵向堆叠
- 表格支持横向滚动
