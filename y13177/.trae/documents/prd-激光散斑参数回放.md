## 1. 产品概述

激光散斑参数回放是一款面向质量复核场景的轻量审计追踪工具，解决"图表结论藏在设备铭牌后、异常点无法追溯来源、后补材料静默覆盖历史判断"的交接痛点。

- 目标用户：项目助理（小宋）、质量复核人
- 核心价值：让参数曲线、异常标注、版本变更、原始材料在同一页面完成闭环复核

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心诉求 |
|------|---------|---------|
| 项目助理（小宋） | 日常录入、交接、补材料 | 快速放样例、重跑、生成摘要，交接不丢上下文 |
| 复核人 | 审计追溯 | 从图表异常点一路点回材料，看到参数版本和处理解释 |

### 2.2 功能模块

1. **参数回放主页面**：散斑参数曲线图 + 时间轴回放 + 异常点高亮
2. **异常点追溯面板**：点击异常点弹出影响范围、来源行号、对应材料证据
3. **版本时间线**：每次参数/材料变更留痕，后补标注"补充"不覆盖早先判断
4. **页面摘要区**：参数版本、异常点清单、处理结论三段式摘要
5. **操作工具栏**：放样例、重跑计算、导出摘要

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 参数回放主页 | 顶部工具栏 | 放样例按钮、重跑按钮、查看摘要按钮 |
| 参数回放主页 | 散斑参数曲线图 | 多参数曲线叠加，极端值/噪声用特殊标记，悬停显示数值与来源 |
| 参数回放主页 | 异常点标记层 | 红色圆点标注异常，点击打开追溯抽屉 |
| 参数回放主页 | 版本时间线 | 垂直时间线显示每次参数/材料变更，区分"初始""补充""修正" |
| 参数回放主页 | 追溯抽屉 | 异常点详情：影响范围、来源行、对应设备铭牌/材料片段 |
| 参数回放主页 | 摘要浮层 | 参数版本、异常点列表、处理结果三段式摘要 |

## 3. 核心流程

复核人打开回放页面 → 浏览参数曲线发现异常红点 → 点击异常点查看影响范围和来源行 → 在追溯抽屉中跳转至对应材料证据 → 切换版本时间线对比早先判断与后补材料 → 查看页面摘要确认最终处理结论。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 `#1e3a5f` 作为专业基底，配合警示橙 `#ff6b35` 标注异常，苔绿 `#2d6a4f` 标记正常
- 字体：标题使用思源宋体 SC 增强专业感，正文使用思源黑体 SC 保证可读性
- 布局：左侧曲线图主区域，右侧异常/版本双面板可折叠切换
- 动效：异常点脉冲呼吸动效提示复核人，抽屉滑入采用弹性缓动

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|---------|---------|---------|
| 参数回放主页 | 曲线图 | 深靛蓝背景 + 发光曲线 + 橙/绿异常点 + 脉冲呼吸 |
| 参数回放主页 | 追溯抽屉 | 右侧滑入，卡片式来源证据，行号高亮 |
| 参数回放主页 | 版本时间线 | 垂直左侧，节点带状态色标，悬停展开变更摘要 |
| 参数回放主页 | 工具栏 | 顶部胶囊式按钮，放样例/重跑/摘要三个主操作 |
| 参数回放主页 | 摘要浮层 | 居中毛玻璃卡片，三段式信息分区展示 |

### 4.3 响应式

桌面端优先（≥1280px），侧栏常驻；平板端侧栏可折叠；移动端曲线图自适应宽度。
