## 1. 产品概述

桥隧检修平台碰撞预审系统，面向桥梁隧道工程现场的检修作业调度场景，解决多源CAD图层拼接、碰撞检测复核、操作历史追溯等核心痛点。系统以"真实现场节奏"为设计原则，不追求过分干净的演示效果，而是还原工程现场材料断断续续、坐标系混杂、撤回调整频繁的真实工作状态。

- **目标用户**：现场调度（阿宁）、项目负责人、交接班工程师
- **核心价值**：碰撞检测结果可追溯、可复核、可还原现场判断过程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 现场调度（阿宁） | 日常导入CAD图层、调整判断、标记异常 | 导入图层、修改判断、标记撤回、生成报告 |
| 项目负责人 | 复核异常、确认挂起项、最终审核 | 查看全部、确认挂起、导出报告 |
| 交接班工程师 | 查看历史记录、了解前序判断过程 | 只读查看、筛选历史 |

### 2.2 功能模块

1. **CAD图层视图**：多图层叠加展示、主线拼接、坐标系标记
2. **碰撞检测面板**：异常点列表、点击定位到CAD图层
3. **时间轴组件**：检测时段展示、缺段挂起标记
4. **操作历史面板**：全部操作记录、撤回记录高亮、判断变更追踪
5. **视图快照**：保存当前视图条件、视角切换、截图
6. **Markdown报告**：生成预审报告、记录变化说明

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 预审主界面 | CAD图层视图区 | SVG绘制桥隧主线、检修平台、碰撞点，支持缩放平移 |
| 预审主界面 | 图层控制栏 | 图层显隐切换、坐标系标识、透明度调节 |
| 预审主界面 | 异常列表面板 | 碰撞异常列表、类型标签、严重程度、关联图层 |
| 预审主界面 | 时间轴组件 | 检测时段条、缺段警示、挂起状态标记 |
| 预审主界面 | 操作历史面板 | 时间线式操作记录、撤回记录高亮、操作人标注 |
| 预审主界面 | 视图快照面板 | 已保存视图列表、快速切换、视角参数展示 |
| 预审主界面 | 报告生成区 | Markdown预览、一键导出、变化说明 |

## 3. 核心流程

用户按第二天复盘前的真实节奏使用系统：先导入旧材料（已有CAD图层和历史检测结果），再补一条撤回记录（模拟现场调度阿宁的调整），最后查看Markdown报告是否说清变化。

```mermaid
flowchart LR
    A["导入旧材料<br/>（历史CAD图层 + 检测结果）"] --> B["材料加载完成<br/>展示主线拼接状态"]
    B --> C["发现问题<br/>补一条撤回记录"]
    C --> D["系统更新检测结果<br/>标记坐标系不一致风险"]
    D --> E["时间轴出现缺段<br/>自动挂起等待确认"]
    E --> F["负责人定位异常对象<br/>换视角截图保存"]
    F --> G["生成Markdown报告<br/>包含变更历史说明"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰底（#1a2332）+ 警示橙（#ff6b35）+ 安全绿（#2ecc71）+ 挂起黄（#f1c40f）
- **辅助色**：坐标系蓝（#3498db）、撤回红（#e74c3c）、历史灰（#7f8c8d）
- **按钮风格**：直角微圆角（2px）、工业风边框、按压有凹陷感
- **字体**：JetBrains Mono（代码/数据）+ 思源黑体（正文）
- **布局风格**：多面板拼接、可拖拽分割线、左侧图层栏+中央画布+右侧信息面板
- **图标风格**：线性图标、工程风格、避免卡通化

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 预审主界面 | CAD图层视图 | 深色画布背景、网格线、桥梁用蓝色线条、隧道用灰色填充、碰撞点用橙色脉冲动画 |
| 预审主界面 | 图层控制栏 | 复选框列表、颜色标识点、透明度滑块、坐标系状态标签 |
| 预审主界面 | 异常列表 | 卡片式列表、严重程度色条、类型标签、点击高亮联动 |
| 预审主界面 | 时间轴 | 横向时间条、分段色块、缺段用虚线+警示图标、挂起项黄色闪烁 |
| 预审主界面 | 操作历史 | 垂直时间线、不同操作类型不同颜色标记、撤回记录有删除线+红色标注 |
| 预审主界面 | 视图快照 | 缩略图网格、名称标签、当前视图高亮 |
| 预审主界面 | 报告预览 | Markdown渲染、代码块风格、变化部分高亮 |

### 4.3 响应式

桌面端优先设计，最低支持1280px宽度。右侧面板可折叠，移动端切换为上下布局。

### 4.4 交互细节

- CAD图层支持鼠标滚轮缩放、拖拽平移
- 点击异常点时，画布自动居中定位并高亮闪烁
- 时间轴缺段处有呼吸灯效果，提醒负责人确认
- 操作历史支持展开/收起详情，撤回记录有明显视觉区分
- 视图快照保存时自动捕获当前缩放比例、中心点、可见图层
