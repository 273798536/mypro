多面体截面练习馆 - 说明文档
========================

启动方式
--------
1. 本项目为单文件应用，无需构建。
2. 用浏览器直接打开 index.html 即可。
   - 本地文件协议 (file://) 可正常运行，Three.js 从 CDN 加载。
   - 如遇 CDN 加载问题，可启动本地 HTTP 服务器：
     python3 -m http.server 8080
     然后访问 http://localhost:8080

样例位置
--------
样例数据内嵌于页面底部"样例记录"选项卡中，共 6 条记录：

  #1  正方体 / 水平切    — 完整记录，无异常
  #2  正方体 / 对角切    — 缺 screenshotReady 和 remark 字段
  #3  正四面体 / 过中点  — 截线断裂(顶点重合)，areaEstimate 缺失，晚补
  #4  正八面体 / 偏移切  — 平面越界，备注已修改
  #5  正方体 / 斜切      — 越界+顶点重合叠加，截线断裂分三段，晚补+备注改
  #6  正十二面体 / 对角切 — 缺 remark 字段

点击记录行可弹出详情，断裂说明在详情和导出中均可查看。

平面越界的触发办法
------------------
方法一：点击侧边栏"触发平面越界"按钮。
  - 将平面偏移 d 设为 2.50，使截面平面完全超出多面体范围。
  - 视口中会出现紫色越界区域标识，信息栏显示"平面越界"标签。

方法二：手动拖动"平面偏移 (d)"滑块至 ±1.5 以外。
  - 当前多面体的顶点分布在 d ≈ [-1.5, 1.5] 范围内，
    超出此范围即触发越界。

方法三：调整法向量使平面接近与多面体相切。
  - 当法向量与偏移配合使平面仅与多面体一两条棱相交时，
    截线不封闭，也会标记为越界状态。

顶点重合的触发办法
------------------
当截面平面恰好经过多面体某个顶点时触发顶点重合。
例如：正方体下选"对角切"方案 (n=(1,1,0), d=0)，
平面经过顶点 B(-1,1,1) 和 D(1,-1,1)，信息栏显示顶点重合。

方案切换说明
------------
侧边栏"方案选择"卡片可切换预设方案。切换后：
  - 3D 场景中的截面平面和截线立即更新
  - 面积估算和截面形状自动重新计算
  - 截图导出和 JSON 导出内容随方案变化
  - 底部"截面详情"和"导出预览"选项卡同步更新

截图导出
--------
点击"截图导出 (当前方案)"按钮，自动下载当前 3D 视口的 PNG 截图。
文件名包含多面体名和方案名。导出内容反映当前方案状态。

颜色图例
--------
  浅蓝 (#4fc3f7) — 多面体面与棱
  琥珀 (#f0a500) — 截面平面
  红色 (#ff6b6b) — 截线 / 断裂线段
  青绿 (#00d4aa) — 顶点与标签
  紫色 (#e040fb) — 越界区域标识
