# 代码审查标准 v1.1

版本：v1.1

## 审查规则

### 引用要求
所有审查结论必须引用对应的规范条款或需求文档。
缺少引用的审查记录视为不完整。
*v1.1更新：缺引用但结论明确的记录可标记为待补充，不再直接判为不通过*

### 通过标准
- 代码符合规范要求
- 有明确的引用依据
- 无重大风险

### 不通过标准
- 存在明显违规
- 缺少必要引用且结论存疑
- 存在重大安全隐患

### 待处理标准
- 缺少引用但结论明确
- 需要补充材料
- 存在争议待讨论
