## 1. 产品概述

"基金回撤生存赛"是一款面向个人投资者的投教模拟游戏，玩家在多回合市场回撤场景中做出调仓决策，体验手续费、行业集中、恐慌卖出等真实风险约束，最终生成可审计、可追溯的通关报告。
- 核心目标：让玩家在操作中亲身感受"回合调仓"与"回撤结算"之间的取舍，而非简单点击得分
- 目标用户：基金投教产品经理、个人投资者、金融培训学员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 玩家 | 直接开始游戏 | 操作调仓、查看报告、导出报告 |
| 复核者 | 通过报告链接 | 查看基金卡-新闻事件-结果追溯链 |

### 2.2 功能模块
1. **游戏主界面**：基金卡牌区、风险槽区、新闻事件区、操作面板、回合信息栏
2. **回合结算界面**：回撤结算明细、手续费计算明细、规则匹配反馈
3. **通关报告界面**：分项风险说明、追溯链路、导出功能

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 基金卡牌区 | 展示玩家持有的基金卡片，每张卡显示名称、类型、行业、当前净值、回撤幅度、手续费率，点击可查看详情追溯 |
| 游戏主界面 | 风险槽区 | 三个独立风险槽：行业集中度（红）、手续费漏扣（橙）、恐慌卖出（紫），各自显示当前等级和触发原因 |
| 游戏主界面 | 新闻事件区 | 当前回合的市场新闻事件，标注事件ID，事件与基金卡的关联关系可追溯 |
| 游戏主界面 | 操作面板 | 调仓操作（买入/卖出/持有）+ 手续费预览 + 确认提交，操作前展示回合调仓规则提示 |
| 游戏主界面 | 回合信息栏 | 当前回合数、市场整体回撤率、剩余生存指标 |
| 回合结算界面 | 回撤结算明细 | 按基金卡逐条展示回撤金额、触发新闻事件ID、适用规则条目 |
| 回合结算界面 | 手续费计算明细 | 每笔调仓操作对应的手续费，标注是否漏扣及漏扣原因 |
| 回合结算界面 | 规则匹配反馈 | 玩家操作与规则的匹配结果，错误操作标注具体违反的规则条目（如"回合调仓规则第3条：单回合卖出超过3只基金触发恐慌卖出"） |
| 通关报告界面 | 分项风险说明 | 行业集中、手续费漏扣、恐慌卖出三个维度独立说明，各自列出触发回合、涉及基金、关联新闻 |
| 通关报告界面 | 追溯链路面板 | 双向追溯：基金卡→结算结果→新闻事件，点击任一节点可跳转详情 |
| 通关报告界面 | 导出与复核 | 导出完整报告（含基金卡-新闻事件-结果对应关系表），复核者可从任一入口反查 |

## 3. 核心流程

玩家进入游戏后，每回合经历：新闻事件发布 → 调仓决策（含手续费预览）→ 提交操作 → 回撤结算 → 风险槽更新 → 规则匹配反馈。所有回合结束后生成通关报告，支持双向追溯和导出。

```mermaid
    "风险槽更新" --> "规则匹配反馈"

    "追溯链路构建" --> "报告导出"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深墨绿（#0A1F1C）+ 金色强调（#D4A843），传达金融严肃感与竞技紧张感
- 辅色：风险槽专属色——行业集中（#E63946 红）、手续费漏扣（#F4A261 橙）、恐慌卖出（#7B2D8E 紫）
- 按钮：3D立体感按钮，调仓确认按钮带金色边框，普通操作为墨绿底
- 字体：标题用 Noto Serif SC（衬线体，庄重），正文用 Noto Sans SC（清晰可读），数字用 JetBrains Mono（等宽对齐）
- 布局：三栏式——左侧基金卡牌区、中间新闻事件与操作区、右侧风险槽与回合信息
- 图标：线性图标配合点状装饰，金融主题（折线图、盾牌、天平等）

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主界面 | 基金卡牌区 | 竖向卡牌列表，每张卡含迷你净值折线、行业标签、回撤进度条，悬浮展开详情追溯面板 |
| 游戏主界面 | 风险槽区 | 三个独立条形槽，各自填充动画，悬浮显示触发原因和涉及基金卡 |
| 游戏主界面 | 新闻事件区 | 卡片式新闻条目，带事件ID徽章，点击展开受影响基金列表 |
| 游戏主界面 | 操作面板 | 拖拽式调仓（拖基金卡到买入/卖出区），实时手续费计算，规则提示气泡 |
| 游戏主界面 | 回合信息栏 | 顶部横条，回合计数器+市场回撤仪表盘+生存指标 |
| 回合结算界面 | 回撤结算明细 | 分组表格（按基金卡），每行：基金名|回撤金额|新闻事件ID|规则条目 |
| 回合结算界面 | 手续费计算明细 | 分组表格（按操作），每行：操作类型|基金名|手续费|是否漏扣|漏扣原因 |
| 回合结算界面 | 规则匹配反馈 | 错误操作红色高亮，标注违反规则条目；正确操作绿色通过标记 |
| 通关报告界面 | 分项风险说明 | 三列卡片布局，每列一个风险维度，内含触发回合时间线和涉及基金清单 |
| 通关报告界面 | 追溯链路面板 | 可视化链路图（基金卡→结算结果→新闻事件），节点可点击展开详情 |
| 通关报告界面 | 导出与复核 | 导出按钮+对应关系表（基金卡ID-新闻事件ID-结算结果ID） |

### 4.3 响应式设计
- 桌面优先设计，三栏布局在 ≥1280px 下展开
- 平板（768-1279px）下风险槽移至底部
- 手机（<768px）下单栏滚动，基金卡横向滑动

### 4.4 动效设计
- 基金卡悬浮：3D倾斜 + 阴影加深
- 风险槽填充：弹性缓动动画，触发时脉冲闪烁
- 回撤结算：数字滚动计数
- 规则匹配反馈：错误条目从左侧滑入，正确条目渐显
- 追溯链路：节点连线逐步绘制
