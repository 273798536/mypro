## 1. 产品概述

债券现金流3D瀑布图可视化工具，为资管经理提供债券持仓在不同利率情景下的交互式分析能力。
- 解决的问题：债券现金流数据口径不一致、来源混乱、日期错位、情景重复、负现金流隐藏等问题
- 目标用户：资管经理、投资组合分析师
- 核心价值：将债券持仓、现金流日期、利率情景、评级、久期等多维度数据统一到可交互3D瀑布图中，保留来源和修正痕迹，异常数据清晰标记不隐藏

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 资管经理 | 本地使用 | 上传数据、调整情景、查看3D瀑布图、标记异常、导出图表、查看修正历史 |

### 2.2 功能模块
1. **主页面（3D瀑布图）**：核心3D可视化区域，展示债券现金流在不同时间和利率情景下的分布
2. **数据导入面板**：支持上传债券持仓、现金流日期、利率情景、评级、久期、对比报告等数据文件
3. **情景切换面板**：快速切换不同利率情景，实时更新3D瀑布图
4. **异常标记系统**：检测日期错位、情景重复、负现金流隐藏等问题，保留原始行号提示
5. **明细联动面板**：点击3D柱状图查看该债券/时间点/情景的详细数据
6. **图表导出模块**：支持导出PNG截图、CSV数据、修正历史报告

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 3D瀑布图区域 | Three.js渲染的交互式3D柱状瀑布图，支持旋转/缩放/平移，柱子代表不同债券在不同时间点的现金流，高度代表金额，颜色代表评级 |
| 主页面 | 左侧数据导入面板 | 文件上传区域（拖拽支持），数据预览表格，数据验证反馈（显示原始行号） |
| 主页面 | 顶部情景切换栏 | 利率情景下拉选择、情景参数微调（利率偏移滑块）、当前情景统计摘要 |
| 主页面 | 右侧明细联动面板 | 点击柱子后显示该条数据的详细信息（债券代码、名称、日期、现金流金额、利率、评级、久期、数据来源、修正历史） |
| 主页面 | 底部异常提示栏 | 滚动显示所有检测到的数据异常，可点击定位到3D瀑布图中对应位置，保留原始行号/来源位置 |
| 主页面 | 导出工具栏 | 导出PNG（3D场景截图）、导出CSV（当前情景数据）、导出报告（含修正历史和异常标记） |

## 3. 核心流程

用户上传债券数据文件 → 系统进行数据验证（检查日期错位、情景重复、负现金流等）→ 显示验证结果和异常提示（保留原始行号）→ 用户确认数据或修正异常 → 系统加载数据到3D瀑布图 → 用户切换利率情景、调整参数 → 点击柱子查看明细 → 导出图表或报告

```mermaid
flowchart TD
    "A[上传数据文件]" --> "B[数据验证引擎]"
    "B" --> "C{存在异常?}"
    "C" --> "|是|" "D[显示异常提示（原始行号）]"
    "C" --> "|否|" "E[加载3D瀑布图]"
    "D" --> "F[用户修正/确认]"
    "F" --> "E"
    "E" --> "G[切换利率情景]"
    "G" --> "H[实时更新瀑布图]"
    "H" --> "I[点击柱子查看明细]"
    "I" --> "J[导出图表/报告]"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色金融风格，底色#0D1117（深蓝黑），卡片#161B22，强调色#00D4AA（青绿）和#FF6B6B（异常红）
- 辅助色：#0366D6（蓝）、#8957E5（紫）用于评级梯度
- 按钮风格：圆角4px，悬停微亮，点击有反馈
- 字体：标题使用Roboto Mono（数据感），正文使用Inter
- 布局：三栏式（左数据面板+中3D场景+右明细面板），顶部工具栏，底部异常栏
- 图标：lucide-react线性图标

### 4.2 页面设计总览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 3D瀑布图 | 深色背景环境光、柱子发光效果、鼠标悬停高亮、点击选中标记 |
| 主页面 | 数据导入面板 | 拖拽上传区、数据预览表格（斑马纹）、异常行红色标记 |
| 主页面 | 情景切换栏 | 下拉选择器、滑块控件、实时统计数字 |
| 主页面 | 明细联动面板 | 卡片式布局、键值对展示、修正历史时间线 |
| 主页面 | 异常提示栏 | 滚动列表、红色标记、可点击定位 |

### 4.3 响应式设计
桌面优先，1200px以上最佳体验。支持触控板手势操作3D场景，触控设备可双指缩放旋转。

### 4.4 3D场景指南
- 环境/氛围：深色科技感背景，使用雾效（Fog）营造深度感
- 光照：AmbientLight（低强度环境光）+ DirectionalLight（主光源，45度投射阴影）+ 柱子自发光（Emissive）
- 相机设置：PerspectiveCamera，初始角度45度俯视，支持OrbitControls自由旋转
- 构图：X轴为时间（债券现金流日期），Y轴为现金流金额，Z轴为不同债券/情景
- 交互：鼠标悬停显示浮层信息、点击选中、拖拽旋转、滚轮缩放
- 动画：柱子高度动画过渡、情景切换时平滑过渡、异常柱子脉冲闪烁
- 后期处理：Bloom发光效果增强柱子视觉层次
- 资源：程序化生成几何体（BoxGeometry），无需外部模型资源
