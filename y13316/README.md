# 工业视觉灰度对比系统

## 系统架构

```
┌─────────────────────────────────────────────────────────────────┐
│                     统一数据源 (ReportData)                       │
│  筛选条件 ◄───┬───► 统计数字 ◄───┬───► 明细表 ◄───┬───► Markdown报告 │
└───────────────┴─────────────────┴───────────────┴───────────────┘
                                ▲
                                │
┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  坏数据检测  │  │ 阈值漂移检测 │  │ 晚到附件关联 │  │  人工改判   │
└─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘
```

## 核心特性

### ✅ 数据一致性
- **筛选条件、统计数字、明细表、Markdown报告** 全部从同一套 `ReportData` 生成
- 避免了多数据源导致的数据不一致问题

### ✅ 晚到附件关联
- 自动识别晚于判定时间上传的附件
- 将晚到附件与对应样本的结论关联
- 支持48小时内的晚到附件检测

### ✅ 阈值漂移检测与挂起机制
- 使用统计方法（均值±标准差）检测阈值漂移
- **宁可挂起让运营主管确认，也不给假稳定结论**
- 漂移样本自动标记为 `SUSPENDED` 状态
- 明确提示需要运营主管审核

### ✅ 变更拆解分析
报告中可明确区分三种变更类型：
1. **样本变化** - 样本本身特征变化导致判定变更
2. **阈值变化** - 阈值配置或漂移导致判定变更
3. **人工改判** - 人工干预修改模型判定结果

### ✅ 坏数据追踪
- 检测6种坏数据类型：无效分数、低置信度、缺失字段、异常值、不一致预测、重复样本
- 坏数据记录包含 **模型输出原始行号** 和 **具体对象引用**
- 不影响整体统计，单独列出供排查

## 关键设计决策

### 1. 统一数据源设计
**问题**：以前靠模型输出硬拼，不同模块可能使用不同数据
**解决方案**：所有输出从 `ReportData` 单一数据源生成
- `apply_filters()` - 筛选
- `calculate_statistics()` - 统计
- `generate_detail_rows()` - 明细
- `MarkdownReportGenerator.generate()` - 报告

### 2. 阈值漂移挂起机制
**问题**：阈值漂移时给出假稳定结论，误导决策
**解决方案**：
- 漂移幅度超过配置（默认0.15σ）时自动挂起
- 状态设为 `SUSPENDED`，不参与 PASS/FAIL 统计
- 报告中明确提示"需运营主管确认"
- 只有人工确认后才能解除挂起

### 3. 晚到附件与结论关联
**问题**：晚到附件与最终结论脱节
**解决方案**：
- `LateAttachmentLinker` 自动识别晚于判定时间的附件
- 附件标记 `is_late_arrival = True`
- 变更类型设为 `LATE_ATTACHMENT`
- 报告中专门章节展示关联关系

### 4. 坏数据可溯源
**问题**：坏数据带偏分析，无法定位根源
**解决方案**：
- `BadDataRecord` 记录 `model_output_line`（原始行号）
- 记录 `model_object_ref`（具体对象引用）
- Markdown中生成可点击的行号链接
- 坏数据单独统计，不污染主数据

## 扩展定制

### 修改筛选条件
在 `main.py` 中修改 `filter_conditions`：
```python
filter_conditions = {
    "product_line": "PL-A",
    "category": "电子元件",
    "batch_number": "B20240601",
    "status": JudgmentStatus.FAIL,
    "has_threshold_drift": True,
    "date_from": datetime.now() - timedelta(days=7),
}
```

### 调整阈值漂移灵敏度
```python
drift_detector = ThresholdDriftDetector(
    drift_sensitivity=0.20,      # 调整灵敏度
    min_samples_for_drift=10,    # 调整最小样本数
    lookback_window_hours=48,    # 调整历史窗口
)
```

### 添加新的坏数据检测规则
在 `BadDataDetector.detect_bad_data()` 中添加新规则即可。
