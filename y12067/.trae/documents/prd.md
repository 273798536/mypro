## 1. 产品概述

商场消防疏散局是一款面向物业培训师的消防疏散模拟小游戏。玩家扮演商场疏散指挥官，在火警场景中做出操作决策（广播通知、电梯管控、出口引导），每个操作即时影响人流模拟结果。游戏核心价值：让员工在交互中理解电梯停用、人群回流、出口拥堵的真实后果，而非仅背诵疏散路线。

- 目标用户：物业培训师、商场安保人员、新入职员工
- 核心问题：传统疏散演练只背路线，员工不处理电梯停用和人群回流；培训师无法给出可操作的修正建议

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 玩家（培训学员） | 直接操作游戏 | 广播、电梯管控、出口引导 |
| 回看者（培训师） | 局后分析操作记录 | 查看步骤回放、评分溯源、修正建议 |

### 2.2 功能模块

1. **场景启动页**：选择预设场景（含脏数据），查看场景简介
2. **游戏主界面**：楼层地图 + 人流可视化 + 操作面板 + 实时事件日志
3. **结算回放页**：胜负判定 + 操作步骤回放 + 评分溯源 + 可操作修正建议

### 2.3 页面详情

| 页面 | 模块 | 功能说明 |
|------|------|----------|
| 场景启动页 | 场景卡片列表 | 展示可用场景，标注数据异常（缺字段出口、备注信息、晚到人流） |
| 场景启动页 | 场景详情预览 | 点击展开场景楼层地图缩略图、出口数量、预估人数 |
| 游戏主界面 | 楼层地图画布 | 渲染楼层平面图，标注出口、电梯、楼梯、火源位置；显示人群粒子流动 |
| 游戏主界面 | 人流模拟面板 | 实时显示各区域人数、出口流量、拥堵度进度条 |
| 游戏主界面 | 操作面板 | 广播按钮（按区域）、电梯管控开关、出口引导方向选择 |
| 游戏主界面 | 事件日志 | 滚动显示触发的模拟事件（如"3F电梯仍有人使用""1F北出口拥堵加剧"） |
| 游戏主界面 | 计时器与评分 | 当前用时、已疏散人数、扣分明细 |
| 结算回放页 | 胜负判定 | 明确显示"通过/失败"及核心原因（如"2F电梯误用导致14人被困"） |
| 结算回放页 | 步骤回放 | 时间轴，点击任一步骤查看当时人流快照 |
| 结算回放页 | 评分溯源 | 每项扣分对应的具体操作步骤和模拟反馈 |
| 结算回放页 | 修正建议 | 针对电梯误用、广播漏发、出口拥堵给出可操作修正（如"应在第3步对B区发广播"） |

## 3. 核心流程

玩家从场景启动页选择预设场景进入游戏。游戏加载时处理脏数据（补全缺失出口字段、解析备注、注册晚到人流）。进入主界面后，玩家按时间步操作：发广播、关电梯、引导出口。每步操作触发人流模拟重新计算，人流状态实时反映在地图粒子和数据面板上。事件日志记录关键模拟结果。计时结束或全部疏散完成后进入结算。

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：工业指挥台 / 调度中心风格，深色背景搭配紧急红橙色调
- **主色**：深灰 #1a1a2e 为底，紧急橙 #ff6b35 为强调色，安全绿 #00c853 为正向反馈
- **辅助色**：拥堵红 #d32f2f、电梯黄 #fbc02d、信息蓝 #4fc3f7
- **按钮风格**：圆角 6px，略带 3D 凸起感，操作按钮有按下反馈
- **字体**：标题用 Noto Sans SC Bold，数据面板用 JetBrains Mono 等宽字体
- **布局**：左大右小——左侧 70% 楼层地图，右侧 30% 操作面板 + 数据面板
- **图标**：使用 lucide-react 紧急/建筑/人流类图标

### 4.2 页面设计概览

| 页面 | 模块 | UI 要素 |
|------|------|---------|
| 场景启动页 | 场景卡片 | 深色卡片，顶部缩略地图，数据异常角标，hover 放大+阴影 |
| 游戏主界面 | 楼层地图 | Canvas 绘制，网格底图，出口/电梯/楼梯图标，人群用小圆点粒子流动 |
| 游戏主界面 | 操作面板 | 紧急橙按钮组，电梯开关为 toggle，出口引导为下拉选择 |
| 游戏主界面 | 事件日志 | 左下角半透明滚动条，新事件入场动画 |
| 游戏主界面 | 计时评分 | 顶栏右侧，数字等宽字体，扣分项红色闪烁 |
| 结算回放页 | 步骤时间轴 | 水平时间轴，节点可点击，选中节点高亮+展开快照 |
| 结算回放页 | 修正建议 | 卡片列表，每条含问题类型标签+具体操作建议+预期效果 |

### 4.3 响应式

- 桌面优先设计（1920×1080 为基准）
- 最小支持 1280px 宽度
- 移动端暂不适配（培训场景以 PC 为主）

### 4.4 动效

- 人流粒子：沿路径流动，拥堵时变密变红
- 操作反馈：按钮按下时微震动，广播发出时波纹扩散动画
- 事件日志：新条目从左滑入
- 结算页：胜负结果放大渐入
