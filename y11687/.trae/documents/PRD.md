# 航空科普3D航线规划系统 - PRD

## 1. 产品概述

航空科普活动3D航线规划交互系统，面向学生用户，提供沉浸式的航线规划学习体验。通过3D地球场景，让学生直观理解航线规划中的气象规避、空域限制、燃油管理等核心概念。

- **解决的核心问题**：传统表格和截图教学方式抽象，学生难以直观理解三维空间中的航线规划决策过程
- **目标用户**：航空科普活动参与者（中学生/大学生）、航空讲师
- **核心价值**：将抽象的航空知识转化为可交互、可验证、可复盘的三维可视化学习体验

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限描述 |
|------|----------|
| 学生用户 | 创建/编辑航线、运行碰撞检测、查看油耗估算、导出飞行报告、查看历史记录 |
| 讲师用户 | 预置场景数据、审核学生方案、导出汇总报告（v2功能） |

### 2.2 功能模块

1. **3D地球场景模块**：三维地球渲染、地形展示、昼夜效果
2. **航线编辑模块**：航点添加/删除/拖拽、航线可视化
3. **障碍物管理模块**：雷暴云团展示、禁飞区展示、备降机场标记
4. **碰撞检测模块**：航线穿云检测、禁飞区侵入检测
5. **油耗估算模块**：燃油消耗实时计算、超限预警
6. **历史记录模块**：操作痕迹保留、版本对比
7. **报告导出模块**：飞行报告生成、PDF/JSON导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主场景页 | 3D地球渲染 | 展示地球表面、地形、大气层效果 |
| 主场景页 | 航线编辑器 | 航点管理面板、航线绘制交互 |
| 主场景页 | 障碍物图层 | 雷暴云团、禁飞区、机场标记 |
| 主场景页 | 信息面板 | 实时状态显示、警告提示 |
| 主场景页 | 工具栏 | 保存、重置、导出、历史记录按钮 |
| 历史记录页 | 历史列表 | 展示所有操作版本记录 |
| 历史记录页 | 版本对比 | 两版本航线差异可视化 |
| 报告预览页 | 报告详情 | 完整飞行参数、违规项、优化建议 |

## 3. 核心流程

```mermaid
flowchart TD
    A["进入应用"] --> B["加载预置场景"]
    B --> C["查看预设航点/云团/禁飞区"]
    C --> D["编辑航线（添加/删除/拖拽航点）"]
    D --> E["实时碰撞检测"]
    E --> F{检测结果}
    F -->|航线穿云/侵入禁飞区 --> G["红色警告标记 + 提示信息]
    F -->|正常 --> H["绿色安全提示"]
    G --> D
    H --> I["油耗估算"]
    I --> J{油耗状态}
    J -->|超限 --> K["橙色警告 + 建议备降]
    J -->|正常 --> L["蓝色正常提示"]
    K --> D
    L --> M["检查备降机场"]
    M -->|未选择备降场 --> N["黄色提示 + 建议添加"]
    N --> D
    M -->|已选择 --> O["保存航线方案"]
    O --> P["生成飞行报告"]
    P --> Q["导出报告/查看历史"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空蓝 `#0a1628` 作为背景，科技感航空蓝 `#1e40af` 作为主色
- **辅助色**：警告红 `#dc2626`、注意橙 `#f59e0b`、安全绿 `#10b981`、信息蓝 `#3b82f6`
- **字体**：展示字体使用 Orbitron（科技感无衬线）、正文字体使用 Inter（清晰易读）
- **布局**：左侧工具栏 + 中央3D场景 + 右侧信息面板
- **视觉风格**：赛博航空风，HUD风格UI元素，半透明毛玻璃面板
- **图标风格**：线性图标，航空主题图标集

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 主场景页 | 3D地球 | 深蓝色星球、大气层辉光、地形凹凸贴图 |
| 主场景页 | 航线 | 发光路径、航点球体标记、动画流动光效 |
| 主场景页 | 云团 | 半透明体积云、动态扰动效果 |
| 主场景页 | 警告标记 | 闪烁红色边框、警告图标浮动 |
| 主场景页 | 信息面板 | 毛玻璃背景、实时数据更新、警告列表 |
| 主场景页 | 工具栏 | 圆角按钮、图标+文字、悬停动效 |

### 4.3 响应式设计

- 桌面端优先（1280px及以上）：左侧工具栏（280px）+ 中央场景 + 右侧面板（320px）
- 平板端：折叠面板可收起，工具栏转顶部
- 移动端：单列布局，面板抽屉式

### 4.4 3D场景指导

- **环境**：深空背景 + 星空粒子背景，地球表面使用蓝绿色调
- **光照**：环境光 + 方向光模拟太阳光，地球边缘大气散射效果
- **相机**：轨道控制器，可旋转缩放，限制俯仰角避免翻转
- **交互**：点击选中航点高亮，拖拽调整位置，双击添加航点
- **动画**：航线流动光效、云团缓慢飘动、警告标记脉冲动画
- **后期处理**：Bloom效果增强发光感、轻微色差提升科技感
- **性能预算**：总面数控制在50万以内，帧率稳定60fps

## 5. 数据管理要求

### 5.1 数据来源追溯

所有预置数据必须标记来源：
- 航点数据：标注机场IATA代码、经纬度、海拔
- 雷暴云团：标注预报时间、影响范围、移动趋势
- 禁飞区：标注空域类型、高度限制、有效时间
- 油耗参数：标注机型、巡航高度、燃油消耗率

### 5.2 操作痕迹保留

每次修改操作记录：
- 操作时间戳
- 修改前/后数据快照
- 修改类型（添加/删除/移动航点）
- 碰撞检测结果变化
- 操作人标识
