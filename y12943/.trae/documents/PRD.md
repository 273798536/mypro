# 产品需求文档：知识库切片质量检查工具

## 1. 产品概述

知识库切片质量检查工具是一款面向安全审核员与模型评审会的切片质检与溯源平台。它能从知识库切分产物中拎出"脏样本重复""安全规则漏配"等坏记录，提供分布统计、样本去重、模型日志溯源与一致导出，确保同一批材料只产生一份结论。

- 目标用户：安全审核员（日常质检）、模型评审会（课前/月底集中复核）、研发对接人（导入补录）。
- 解决问题：坏记录难定位、重复导入产生多份结论、导出与界面摘要不一致、溯源断链、通用样例无法证明"真跑了眼前这批材料"。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 安全审核员 | 工作台账号登录 | 查看分布统计、拎坏记录、导出、查模型日志溯源 |
| 评审会成员 | 工作台账号登录 | 查看复核轮次、复核批次结论、溯源到来源与处理记录 |
| 研发对接人 | 工作台账号登录 | 导入切片、补录、处理重复导入冲突 |

### 2.2 功能模块

1. **分布统计页（日常入口）**：质检总览、好坏样本分布、坏记录分类计数、去重可解释性卡片。
2. **切片质检页**：切片记录列表，坏记录优先拎出（脏样本重复 / 安全规则漏配），含正常/边界/明显坏样本三类样例。
3. **复核轮次页**：把评测题库、切分清单、脏样本重复放入同一轮复核，展示"本轮处理的是眼前这批具体材料"。
4. **日志溯源页**：以模型日志为线索，从一条安全规则漏配记录倒查到来源切片与处理记录。
5. **导入导出页**：空目录首跑引导、依赖安装/启动命令/首份样例位置；重复导入与补录冲突处理；导出与摘要对账。

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分布统计 | 质检总览卡 | 总切片数、通过/待确认/坏记录计数，月底可解释 |
| 分布统计 | 坏记录分类 | 脏样本重复、安全规则漏配、边界异常等计数与占比 |
| 分布统计 | 去重可解释卡 | 去重条数、被去重样本来源、是否可清楚解释 |
| 切片质检 | 坏记录拎取 | 默认按"坏记录优先"排序，一键筛选三类坏样本 |
| 切片质检 | 样例三件套 | 正常样本、边界样本、明显坏样本各展示一条 |
| 复核轮次 | 批次材料清单 | 评测题库/切分清单/脏样本重复同轮展示 |
| 复核轮次 | 结论归一 | 同一事不出现两份结论，补录后以最新为准 |
| 日志溯源 | 倒查链路 | 结果 → 处理记录 → 来源切片 → 原始导入批次 |
| 日志溯源 | 模型日志线 | 单条安全规则漏配记录的可点击溯源路径 |
| 导入导出 | 空目录首跑 | 依赖安装、启动命令、首份样例文件路径提示 |
| 导入导出 | 重复导入处理 | 识别重复导入，提示冲突，保留单一结论 |
| 导入导出 | 导出对账 | 导出文件内容与界面摘要字段逐项对齐 |

## 3. 核心流程

日常质检流程：安全审核员从分布统计进入 → 系统拎出坏记录（脏样本重复/安全规则漏配）→ 审核员查看三类样例确认工具真跑 → 进入复核轮次把评测题库/切分清单/脏样本重复同轮复核 → 月底前查看去重可解释性。

溯源验收流程：评审会取一条安全规则漏配记录 → 沿模型日志线倒查 → 结果回到处理记录 → 回到来源切片 → 回到原始导入批次，全链路不断链。

重复导入流程：研发导入切片 → 系统检测重复 → 提示冲突并给出补录策略 → 归一为单一结论 → 导出文件与界面摘要对账一致。

```mermaid
    "C" --> "D: 复核轮次(评测题库+切分清单+脏样本重复)"
    "D" --> "E: 去重可解释性检查"
    "E" --> "F: 月底/课前复核"
    "G: 取安全规则漏配记录" --> "H: 模型日志倒查"
    "H" --> "I: 处理记录"
    "I" --> "J: 来源切片"
    "J" --> "K: 原始导入批次"
    "L: 重复导入/补录" --> "M: 冲突检测"
    "M" --> "N: 归一单一结论"
    "N" --> "O: 导出对账一致"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主题：暗色"取证控制台"风，深暖炭灰底，强调精准与可追溯。
- 主色：藏红花/琥珀 `#e0a82e`（警戒/坏记录拎取色）。
- 辅色：翠绿 `#3fa66b`（通过/溯源链路），砖红 `#d65446`（安全规则漏配/危险）。
- 字体：标题用 Fraunces（高对比衬线，档案感），正文用 IBM Plex Sans，数据/日志/切片内容用 IBM Plex Mono。
- 布局：左侧固定导航 + 主区数据密集表格，卡片化模块，状态色边条。
- 图标：lucide-react，线性风格，状态点用色块。

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 分布统计 | 质检总览卡 | 大号数字 + 状态色徽标，入场错位动画 |
| 分布统计 | 坏记录分类 | 横向条形占比，琥珀/砖红高亮 |
| 切片质检 | 坏记录拎取 | 表格首行坏记录置顶，左侧色条，hover 浮起 |
| 切片质检 | 样例三件套 | 三栏卡片，正常(绿)/边界(琥珀)/坏(砖红) |
| 复核轮次 | 批次材料清单 | 分组列表 + 本轮材料来源标签 |
| 日志溯源 | 倒查链路 | 纵向时间轴节点，可点击跳转 |
| 导入导出 | 空目录首跑 | 代码块风格提示，命令可复制 |

### 4.3 响应式

桌面优先（审核员日常在桌面工作），平板自适应收窄表格，移动端折叠为卡片堆叠。

### 4.4 3D 场景

不适用。
