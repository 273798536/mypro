## 1. 产品概述

古琴指法谱系检索——面向民乐研究者的指法异名归一、版本对比与证据溯源工具。解决指法异名、段落错位、版本混用等难题，让曲谱文本、指法标注与研究备注导入后可一路溯源回原始材料，确保模型结论不脱离材料。

- 核心价值：把"指法归一→片段检索→证据导出"三条链路跑稳，而非堆叠设置项
- 目标用户：民乐研究员、古琴谱版本学研究者
- 验收标准：修改一条指法标注后重跑，系统保留前后差别并清晰呈现；曲谱/标注/报告三者对应关系可复核

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 研究员 | 本地使用 | 导入材料、归一指法、版本对比、片段检索、导出证据 |

### 2.2 功能模块

1. **材料总览页**：导入与展示曲谱文本、指法标注、研究备注三类材料，支持溯源链接
2. **指法归一页**：指法异名映射表、归一操作、变更历史追踪
3. **版本对比页**：多版本并排对比、段落错位标注、版本混用标记
4. **片段检索页**：跨版本关键词/指法检索、结果高亮与溯源跳转
5. **证据导出页**：对比报告生成、对应关系详情、变更前后差异保留

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 材料总览 | 材料列表 | 展示已导入的曲谱文本、指法标注、研究备注，每条可点回来源 |
| 材料总览 | 导入面板 | 批量导入三类材料，自动解析并建立内部关联 |
| 材料总览 | 溯源面板 | 点击任一材料条目，展示其来源文件、关联标注、涉及版本 |
| 指法归一 | 异名映射表 | 列出所有指法异名组，显示归一后的标准名与各版本异名 |

## 3. 核心流程

用户导入材料后，系统自动解析并建立曲谱文本、指法标注、研究备注之间的关联。用户可在指法归一中处理异名，在版本对比中识别错位与混用，在片段检索中定位关键段落，最终通过证据导出生成可溯源的报告。修改标注后重跑，变更差异自动保留。

```mermaid
    "证据导出" --> "对应关系详情"

    "重新归一/对比" --> "变更差异保留"
    "变更差异保留" --> "证据导出"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：墨黑 (#1a1a2e) + 古铜 (#c9a96e) 为品牌色，宣纸米 (#f5f0e8) 为背景，营造书斋感
- 辅助色：朱砂红 (#c0392b) 标记差异/错位，靛蓝 (#2c3e7a) 标记归一/溯源
- 按钮风格：圆角矩形，古铜色描边，hover 时宣纸色填充
- 字体：正文用 Noto Serif SC（宋体感），标题用 Ma Shan Zheng（行楷感）
- 布局：左侧导航栏 + 右侧内容区，卡片式模块，固定高度容器内滚动
- 图标：使用 lucide-react，线条风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 材料总览 | 材料列表 | 卡片网格，每卡片显示类型图标+标题+来源标签，点击展开溯源面板 |
| 材料总览 | 导入面板 | 顶部工具栏，上传按钮+拖拽区域，导入进度条 |
| 指法归一 | 异名映射表 | 表格布局，标准名列+异名列（多值）+归一状态徽章 |
| 指法归一 | 变更历史 | 时间轴布局，每条显示操作类型+时间+影响范围 |
| 版本对比 | 双栏对比 | 左右分栏，差异行用朱砂红/靛蓝底色高亮，同步滚动 |
| 版本对比 | 错位标注 | 行内标记，错位处显示↕图标与tooltip |
| 片段检索 | 检索输入 | 居中搜索框，支持筛选器（版本/类型） |
| 片段检索 | 结果列表 | 列表项展示匹配片段+上下文，关键词高亮 |
| 证据导出 | 报告预览 | 文档式排版，章节清晰，可折叠的对应关系表格 |
| 证据导出 | 变更差异 | 左右对照，删除线+红底/下划线+蓝底标记增删 |

### 4.3 响应式

桌面优先设计，内容区最小宽度 1024px。版本对比双栏在窄屏时切换为上下堆叠。
