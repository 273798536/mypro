# 作文批改证据复核工具 - 使用说明

## 📋 功能概述

针对标注负责人周姐的需求，实现了完整的"作文批改证据复核"处理链：

1. **CLI输出统计**：坏行、跳过行、已处理行、待补材料、人工改判、挂起记录分开统计
2. **引用检查**：检测模型输出中是否缺少原文引用证据，缺引用时明确报告需补录的内容
3. **重复评测挂起**：遇到同一作文多次评测时，宁可挂起等待负责人确认，也不给出假稳定结论
4. **旧误判样本解释**：放入旧模型误判样本时，自动解释改判原因
5. **接口返回分类**：清晰区分已处理、待补材料、人工改判三类结果

## 🚀 运行方式

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行测试脚本
```bash
python3 test_review.py
```

### 3. CLI命令方式

#### 基本复核（文本输出）
```bash
python3 -m cli review test_data.jsonl
```

#### 复核（JSON格式输出）
```bash
python3 -m cli review test_data.jsonl --format json
```

#### 复核并自动确认挂起
```bash
python3 -m cli review test_data.jsonl --auto-confirm
```

#### 确认挂起的重复评测
```bash
python3 -m cli confirm essay_004 test_data.jsonl
```

#### 仅查看统计
```bash
python3 -m cli stats test_data.jsonl
```

## 🔍 核心功能详解

### 1. 引用检查机制

检查模型输出中是否包含以下引用模式：
- `第X段` / `原文第X句`
- `文中提到` / `根据...所述`
- `如...所言` / `引用...的观点`

### 2. 重复评测检测

同一 `essay_id` 出现以下情况时触发挂起：
- 模型版本不同
- 得分差异 > 0.5
- 反馈内容不同

### 3. 旧误判识别

`essay_id` 包含 `_old` 后缀时，自动匹配改判解释库：
```python
MISJUDGMENT_EXPLANATIONS = {
    "essay_003_old": "旧模型误判原因：1) 未识别出原文第3段的反证论据...",
    "essay_007_old": "旧模型误判原因：1) 对文言文引用的语义理解偏差...",
}
```

## 📋 负责人走查流程

### 步骤1：查看统计报告
确认各分类数量是否合理

### 步骤2：检查异常行
- 坏行：查看原始数据，判断是否需要修复后重跑
- 跳过行：确认是否为预期的空行/注释行

### 步骤3：处理待补材料
为缺引用的作文补录原文引用证据

### 步骤4：确认挂起记录
对比重复评测的两个版本，确认使用哪一个结果

### 步骤5：查看人工改判
确认人工改判原因是否合理
