# 节拍火车调度员 - 使用说明

## 快速开始

### 1. 启动项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

启动后在浏览器中访问显示的地址（通常是 http://localhost:5173）

### 2. 样例数据位置

样例曲目数据位于：`src/data/sampleTracks.ts`

包含5首样例曲目：
- `basic-4-4` - 基础4/4拍练习（简单）
- `syncopation-intro` - 切分音入门（普通）
- `syncopation-challenge` - 切分音挑战（困难）
- `dirty-data-demo` - 脏数据演示（普通）
- `advanced-combo` - 连击训练（困难）

## 游戏操作

### 基本操作

| 按键 | 功能 |
|------|------|
| D / 1 | 调度到1号轨道（蓝色） |
| F / 2 | 调度到2号轨道（绿色） |
| J / 3 | 调度到3号轨道（紫色） |
| K / 4 | 调度到4号轨道（粉色） |
| 空格 | 暂停 / 继续游戏 |
| ESC | 暂停游戏 |

也可以直接点击底部的调度按钮进行操作。

### 游戏控制

- **暂停**：点击暂停按钮或按空格键
- **重开**：点击重新开始按钮，从头开始当前曲目
- **结算**：随时点击结算按钮查看当前成绩
- **返回**：点击左上角返回主菜单

## 切分音漏拍触发机制

### 什么是切分音？

切分音是改变常规节奏重音位置的音符，在游戏中：
- 🚂 **黄色闪烁**的火车是切分音
- 判定窗口比普通音符**缩小20%**，需要更精准的节奏
- 切分音得分是普通音符的**1.5倍**

### 如何触发切分音漏拍检测？

1. **选择包含切分音的曲目**：
   - "切分音入门" - 基础切分音练习
   - "切分音挑战" - 高密度切分音练习
   - "连击训练" - 穿插切分音的快速练习

2. **在切分音判定时出现以下情况会触发错因分析**：
   - 时间偏差 > 100ms
   - 判定为 early（抢拍）
   - 判定为 late（慢拍/漏拍）
   - 完全错过（miss）

3. **触发后在结算页会显示**：
   - 错误类型："切分音漏拍"
   - 具体描述：抢拍/慢拍 + 偏差毫秒数
   - 展开可查看4条具体的修正建议

## 游戏机制详解

### 节奏判定等级

| 判定 | 时间窗口（普通模式） | 得分 |
|------|---------------------|------|
| Perfect | ±50ms | 100分 |
| Great | ±100ms | 75分 |
| Good | ±200ms | 50分 |
| Early/Late | >±200ms | 25分 |
| Miss | 完全错过 | 0分 |

**切分音惩罚**：所有窗口 × 0.8

### 难度设置

在主菜单点击"游戏设置"可调整：

1. **判定灵敏度**
   - 简单：窗口宽松（Perfect ±80ms）
   - 普通：标准判定（Perfect ±50ms）
   - 困难：严格判定（Perfect ±30ms）

2. **显示备注**：开启/关闭音符上方的备注信息

3. **容错模式**：预留功能（暂未完全实现）

### 错因分析类型

结算页会自动分析以下5种错误类型：

| 错误类型 | 触发条件 |
|----------|----------|
| 🟡 切分音漏拍 | 切分音节奏偏差较大 |
| 🟠 速度突变 | 连续3拍偏差同向且逐渐增大 |
| 🔴 连击误判 | 连击>5后出现小偏差失误 |
| 🟣 调度错误 | 选择了错误的轨道 |
| ⚪ 数据异常 | 遇到脏数据（延迟/缺失字段） |

每种错误都配有**可操作的修正建议**，点击错误项可展开查看详情。

### 脏数据处理

游戏支持处理"不完美"的真实教学数据：

- **备注（remark）**：音符上方显示黄色提示框，不影响判定
- **延迟到达（delayed）**：音符实际出现时间偏移，系统自动记录数据异常
- **缺失字段（missingField）**：使用默认值填充，显示警告标识⚠️

选择"脏数据演示"曲目可体验此功能。

## 自定义曲目

### 添加新曲目

在 `src/data/sampleTracks.ts` 中添加新的曲目数据：

```typescript
{
  id: 'your-track-id',
  name: '曲目名称',
  bpm: 100,
  difficulty: 3, // 1-5
  hasDirtyData: false,
  description: '曲目描述',
  notes: [
    {
      id: 'note-1',
      time: 1000, // 时间点（毫秒）
      type: 'normal', // normal / syncopated
      track: 1, // 1-4
      isSyncopated: false, // 是否切分音
      // 可选脏数据字段
      remark: '备注信息',
      delayed: true,
      delayAmount: 150,
      missingField: false
    },
    // ... 更多音符
  ]
}
```

### 时间计算

根据BPM计算节拍时间：
```
1拍时间（毫秒）= 60000 / BPM
```

例如：BPM=100 时，1拍 = 600ms

## 常见问题

### Q: 火车移动太快/太慢怎么办？
A: 在主菜单调整"判定灵敏度"，简单模式有更大的判定窗口。

### Q: 切分音总是打不准怎么办？
A: 
1. 先从"切分音入门"曲目开始练习
2. 结算页查看"切分音漏拍"的修正建议
3. 尝试用脚打拍，感受切分的律动

### Q: 如何触发速度突变检测？
A: 连续3次判定都越来越快（偏差负数增大）或越来越慢（偏差正数增大），且最后一次偏差>80ms。

### Q: 如何触发连击误判检测？
A: 保持5连击以上，然后出现一个非Perfect/Great的判定，但偏差又小于50ms（通常是紧张导致的小失误）。
