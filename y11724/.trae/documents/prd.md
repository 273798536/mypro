## 1. 产品概述
无人机电池续航试算交互可视化工具，面向航拍团队出外景前的快速评估。输入无人机型号、电池参数、载重、风速、航线等条件，实时计算能耗并在3D视图中可视化飞行轨迹与电池状态。核心目标：防止逆风漏算、载重超限、返航余量不足导致的安全隐患，提供清晰告警而非静默叠加。保留数据来源和每次修正痕迹，支持记录保存与导出清单。

- **主要用途**：外景前电池续航快速评估，辅助飞行决策
- **目标用户**：航拍团队队长、飞手、现场调度
- **市场价值**：消除外景电池焦虑，降低因续航判断失误造成的设备损失和拍摄延误

## 2. 核心功能

### 2.1 功能模块
1. **主页面**：3D飞行场景可视化 + 参数控制面板 + 续航明细侧边栏
2. **记录管理**：历史试算记录浏览、对比、导出

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 3D飞行场景 | 无人机模型、航线轨迹、风场可视化、电池状态颜色编码 |
| 主页面 | 参数控制面板 | 无人机型号选择、电池容量输入、载重滑块、风速滑块、航线距离输入 |
| 主页面 | 续航明细侧边栏 | 分段能耗拆解、返航余量计算、告警列表、数据来源标注 |
| 主页面 | 记录保存 | 当前试算参数快照保存、修正痕迹记录 |
| 主页面 | 导出清单 | CSV格式导出本次试算的完整明细 |

## 3. 核心流程
用户打开页面后，默认加载一个示例场景（如 DJI M300 + TB60电池 + 2kg载重 + 5m/s逆风 + 3km航线）。用户通过滑块或输入框调整参数，3D视图和侧边明细实时同步更新。系统持续监控三个关键风险：逆风导致的额外能耗、载重超限、返航余量不足。一旦触发阈值，侧边栏以醒目颜色和图标展示告警，并保留原始输入行号。用户可保存当前试算为记录，或导出完整明细为CSV。

## 4. 用户界面设计
### 4.1 设计风格
- **主色调**：深空蓝（#0A1628）为主背景，青色（#00D4FF）为强调色，琥珀橙（#FF9500）为警告，红色（#FF3B30）为危险
- **按钮样式**：扁平圆角，hover时轻微亮度提升，点击有微缩放反馈
- **字体**：系统默认无衬线字体，数值使用等宽字体
- **布局**：三栏布局——左侧参数控制、中央3D视图、右侧续航明细
- **图标**：lucide-react 图标库，风格统一为线性图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|---------|
| 主页面 | 3D飞行场景 | 深空背景带星点粒子、半透明航线轨迹、风场箭头粒子、无人机简化模型 |
| 主页面 | 参数控制面板 | 卡片式分组（无人机/电池/环境/航线）、滑块带实时数值气泡、下拉选择器 |
| 主页面 | 续航明细侧边栏 | 分段能耗进度条、告警卡片（带行号来源）、返航余量仪表盘 |
| 主页面 | 记录保存 | 底部浮层按钮、保存时记录时间戳和参数快照 |
| 主页面 | 导出清单 | 导出按钮生成CSV，包含所有参数和计算过程 |

### 4.3 响应式
桌面端优先，主视图宽度≥1200px时三栏并排；平板端右侧侧边栏折叠为抽屉；移动端中央3D视图自适应全屏，控制和明细改为上下滑动。

### 4.4 3D场景指引
- **环境**：深空蓝渐变背景，微弱星点粒子营造科技感
- **光照**：顶部半球光 + 定向光，无人机模型使用自发光材质
- **相机**：透视投影，默认俯视45°，支持鼠标拖拽旋转、滚轮缩放
- **交互**：参数变化时，无人机模型沿航线轨迹做插值动画，风场粒子方向和速度实时变化
- **后期处理**：轻微泛光效果，使强调色元素更醒目
