
## 1. 产品概述
工业机器人臂展校验系统，解决剖切面越界、离群点处理、历史追溯等问题，提高校验效率和准确性。
- 主要面向工业质量控制工程师、物理老师等用户
- 通过可视化工具和完整的历史记录，降低校验复杂度

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 工程师 | 系统注册 | 数据录入、剖切查看、复核确认、历史查询 |
| 审核员 | 系统注册 | 复核离群点、查看历史变更 |

### 2.2 功能模块
1. **数据仪表盘**：数据概览、剖切面越界记录列表
2. **计算工具**：越界计算、公式展示、失败原因分析
3. **剖切查看器**：剖面图展示、前后对比、明细联动
4. **离群点复核**：复核操作、变更记录、历史追溯
5. **历史记录**：变更日志、并排对比、审计追踪

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据仪表盘 | 数据概览 | 统计展示待处理、已复核、异常数据数量 |
| 数据仪表盘 | 记录列表 | 剖切面越界记录表格，支持筛选和排序 |
| 计算工具 | 越界计算 | 输入参数，自动计算并展示公式、单位、适用范围 |
| 剖切查看器 | 剖面图展示 | 可视化展示剖切面，支持缩放和平移 |
| 剖切查看器 | 前后对比 | 并排显示修改前后的剖面图和结论 |
| 离群点复核 | 复核操作 | 确认/拒绝离群点，填写变更原因 |
| 历史记录 | 变更日志 | 展示谁、什么时候、为什么修改的完整记录 |

## 3. 核心流程
用户从数据仪表盘开始，查看剖切面越界记录，使用计算工具分析问题，通过剖切查看器对比前后差异，完成离群点复核后，所有变更都会记录在历史记录中。

```mermaid
flowchart TD
    A[数据仪表盘] --&gt; B{选择记录}
    B --&gt; C[计算工具分析]
    B --&gt; D[剖切查看器]
    C --&gt; E[离群点复核]
    D --&gt; E
    E --&gt; F[历史记录保存]
    F --&gt; A
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝 (#2563eb)、警示橙 (#f59e0b)、成功绿 (#10b981)
- **按钮风格**：微立体、圆角、悬停动画
- **字体**：Inter 用于正文，Roboto Mono 用于代码/公式展示
- **布局风格**：卡片式布局，左侧导航，右侧内容区
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据仪表盘 | 数据概览 | 统计卡片网格、渐变背景、微动画 |
| 数据仪表盘 | 记录列表 | 数据表格、状态标签、操作按钮 |
| 计算工具 | 越界计算 | 表单输入、公式展示区、结果高亮 |
| 剖切查看器 | 剖面图展示 | Canvas/SVG 绘图区、工具栏、对比面板 |
| 历史记录 | 变更日志 | 时间线布局、用户头像、变更详情 |

### 4.3 响应性
桌面优先设计，平板自适应，移动端优化触控操作。

### 4.4 数据真实性
样例数据模拟真实场景：包含轻微越界、明显异常、测量误差等常见问题。
