# 数据库分片拓扑星图 - 工程评审工具规格文档

## 1. 项目概述

### 项目名称
数据库分片拓扑星图工程评审工具（DBShardTopologyStarMap）

### 核心功能定位
面向工程评审员的数据库分片拓扑结构可视化与评审工具，支持关卡式评审流程、时间回放、异常追踪和报告生成。

### 目标用户
- 工程评审员（主要用户）
- 数据库架构师
- 项目管理人员

## 2. 功能需求

### 2.1 数据分片拓扑星图可视化

#### 核心节点类型
- **中心节点**：主数据库/协调节点
- **一级分片节点**：数据分片主节点
- **二级分片节点**：数据分片从节点
- **边界节点**：跨分片连接点

#### 拓扑连接类型
- **星型连接**：中心节点与一级节点
- **网状连接**：一级节点之间
- **边界连接**：跨分片事务连接

#### 坐标系支持
- 二维平面坐标系
- 三维立体坐标系
- 坐标系单位：像素、厘米、英寸
- 坐标系混用检测和记录

### 2.2 关卡式评审系统

#### 关卡结构设计
- **关卡数量**：最少3关，最多10关
- **每关目标**：完成特定的拓扑验证任务

#### 关卡类型要求
1. **基础关卡**：分片识别和连接验证
2. **边界关卡**：必须包含至少一次边界失败场景
3. **复杂关卡**：多层级分片拓扑评审
4. **结算关卡**：综合评审结果展示

#### 必需功能
- **边界失败场景**：模拟分片边界条件下的失败案例
- **撤销功能**：支持单步撤销和批量撤销
- **重开功能**：支持重新开始当前关卡
- **结算页面**：清晰展示评审结果，包含：
  - 通过/失败状态
  - 问题列表
  - 建议改进项
  - 评审耗时统计

### 2.3 视角保存和时间回放系统

#### 视角管理
- 自动保存当前视图位置和缩放比例
- 支持视角重置和恢复
- 视角切换动画平滑

#### 时间回放功能
- 基于同一批处理记录的操作回放
- 支持播放、暂停、速度调节（0.5x, 1x, 2x, 4x）
- 支持跳转到指定时间点
- 处理记录包含：
  - 操作类型
  - 操作时间戳
  - 操作人
  - 操作参数
  - 操作结果

#### 共用记录机制
- 界面操作和报告生成使用同一批处理记录
- 确保数据一致性
- 支持记录导出和导入

### 2.4 示例数据和首次加载

#### 示例数据要求
- 首次打开时自动加载示例数据
- 示例数据包含完整的拓扑结构
- 示例数据覆盖主要场景：
  - 正常分片拓扑
  - 边界失败案例
  - 坐标系混用案例

#### 数据规模
- 节点数量：5-20个
- 连接数量：10-50条
- 历史记录：50-200条

### 2.5 报告生成系统

#### 报告内容要求
1. **项目信息**
   - 项目名称
   - 评审日期
   - 评审人员
   - 评审版本

2. **普通话解释区域**
   - 面向非技术人员的通俗解释
   - 可直接复制给同事使用
   - 包含关键发现和建议

3. **技术细节**
   - 分片拓扑结构描述
   - 性能指标分析
   - 问题清单和解决方案

4. **附件**
   - 拓扑截图
   - 处理记录详情
   - 修改历史

#### 报告格式
- 支持导出为PDF和HTML格式
- 包含可编辑的文本区域
- 自动生成目录和页码

### 2.6 历史追踪和时间轴同步

#### 修改记录要求
- 记录每个修改的操作人
- 记录修改时间（精确到秒）
- 记录修改原因和说明
- 支持修改记录的查询和过滤

#### 时间轴同步管理
- 实时同步所有客户端的时间轴
- 检测时间轴不同步情况
- 记录时间轴同步历史：
  - 同步发起人
  - 同步时间
  - 同步前后的差异
  - 同步状态（成功/失败）

#### 复核流程
- 时间轴不同步时触发复核流程
- 记录复核历史：
  - 复核人
  - 复核时间
  - 复核意见
  - 复核结论

### 2.7 异常追踪系统

#### 异常类型
- 坐标系混用
- 单位换算错误
- 连接冲突
- 性能瓶颈

#### 异常追踪要求
- 记录异常产生的时间
- 记录异常产生时的上下文
- 支持异常的根因分析

#### 三维模型关联
- 异常记录关联三维模型
- 支持从异常跳转到相关三维模型
- 支持在三维模型中标注问题点

#### 处理意见追踪
- 记录每个异常的处理意见
- 处理意见包含：
  - 处理人
  - 处理时间
  - 处理方法
  - 处理结果
- 支持处理意见的编辑和更新

## 3. 技术架构

### 3.1 前端框架
- React 18+
- TypeScript 5+
- 使用Vite作为构建工具

### 3.2 可视化库
- D3.js 用于拓扑图绘制
- Three.js 用于三维模型展示

### 3.3 状态管理
- Zustand 用于全局状态管理
- 处理记录存储在IndexedDB中

### 3.4 数据持久化
- IndexedDB 用于本地数据存储
- 支持数据导出和导入
