## 1. 产品概述
音乐会志愿者排班检查系统，解决剧院运营中培训记录滞后导致的排班约束判断难题。系统支持两阶段数据导入，可清晰追踪培训记录补入前后的变化，自动分类正常、边界和异常样本，提供手动修正入口和新旧结果并排对比功能。

- 核心价值：确保排班决策的可追溯性和一致性，避免因培训记录滞后导致的排班混乱
- 目标用户：剧院运营管理人员、排班负责人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营管理员 | 本地登录 | 数据导入、排班检查、手动修正、历史对比 |

### 2.2 功能模块

1. **数据导入面板**：志愿者名单导入、入口岗位导入、培训记录补录
2. **排班检查引擎**：约束检查、样本分类（正常/边界/异常）、幂等性保证
3. **变化追踪中心**：两阶段对比、变更日志、差异高亮
4. **边界样例库**：岗位冲突、培训缺失、临时请假场景
5. **手动修正工作台**：岗位调整、新旧结果并排对比、候补调度联动
6. **调度历史**：通知记录、候补变动、操作审计

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 状态概览 | 展示当前排班状态、样本分布统计、待处理事项 |
| 数据导入 | 导入向导 | 分两阶段导入数据，支持文件上传和手动录入 |
| 排班检查 | 检查结果 | 分类展示正常、边界、异常样本，每条标注具体原因 |
| 变化对比 | 前后对比 | 培训记录补入前后的排班结果并排对比，差异高亮 |
| 边界样例 | 场景测试 | 预设岗位冲突、培训缺失、临时请假等边界场景 |
| 手动修正 | 修正工作台 | 调整入口岗位，实时重新计算，新旧结果并排展示 |
| 调度历史 | 历史记录 | 候补调度变动、通知发送历史、操作日志 |

## 3. 核心流程

```mermaid
flowchart LR
    A["第一阶段导入<br/>志愿者名单+入口岗位"] --> B["第一次排班检查"]
    B --> C["生成初始结果<br/>正常/边界/异常分类"]
    C --> D["培训记录补到<br/>(晚半天)"]
    D --> E["第二次排班检查"]
    E --> F["生成变化报告<br/>高亮差异项"]
    F --> G["运营人员审核"]
    G --> H{"需要修正?"}
    H -->|是| I["手动修正入口岗位"]
    I --> J["新旧结果并排对比"]
    J --> K["候补调度联动更新"]
    K --> L["通知历史同步"]
    H -->|否| M["确认排班结果"]
    M --> N["生成最终排班表"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海军蓝 #0A2463（专业、稳重），搭配酒红色 #9E2B25（警示、异常）
- **辅助色**：森林绿 #3E885B（正常）、琥珀橙 #F4A261（边界）、深灰 #2B2D42（文本）
- **按钮风格**：直角微圆角（4px），扁平设计，状态变化时微妙阴影
- **字体**：标题用 Playfair Display（典雅剧院风格），正文用 Lato（清晰易读）
- **布局风格**：左右分栏，左侧导航+右侧内容，卡片式分组，严谨的网格系统
- **图标风格**：线性图标，统一2px描边，专业克制

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|----------|
| 仪表盘 | 状态概览 | 统计卡片带趋势箭头，样本分布环形图，待处理列表 |
| 数据导入 | 导入向导 | 进度条指示当前阶段，拖拽上传区域，数据预览表格 |
| 排班检查 | 检查结果 | 三栏标签页（正常/边界/异常），每条记录带状态标签和原因说明 |
| 变化对比 | 前后对比 | 左右分栏对比布局，差异行背景高亮，变更图标标注 |
| 手动修正 | 修正工作台 | 上半部分旧结果，下半部分新结果，中间可编辑岗位表格 |
| 调度历史 | 历史记录 | 时间线布局，通知状态标签，操作人信息 |

### 4.3 响应性
- 桌面优先设计，最小支持1280px宽度
- 平板端自适应调整为上下布局
- 关键表格支持横向滚动
- 按钮最小触控尺寸44x44px

### 4.4 动效设计
- 数据加载时骨架屏渐入
- 状态变化时背景色微妙过渡（300ms ease）
- 差异高亮时脉冲动画一次
- 标签切换时内容淡入淡出
