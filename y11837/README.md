# 机器人仓库拣货赛

浏览器端教学模拟游戏，训练仓储新人的电量和堵塞意识。

## 启动

```bash
npm install
npm run dev
```

浏览器打开后默认进入游戏主界面 `/`。

配置合并页面在 `/merge`。

## 样例场景

默认场景在 `src/config/defaultScenario.ts`：

- 10×8 仓库网格，3 台机器人（阿尔法/贝塔/伽马）
- 16 个货架位，2 个充电桩，2 个发货点
- 2 处堵塞货道（(4,1) 和 (7,5)）
- 每 8 tick 生成新订单，同时最多 5 单在队

机器人配置覆盖样例在 `sampleRobotOverrides`，货架配置覆盖样例在 `sampleShelfOverrides`——两者与默认场景有差异，可在 `/merge` 页面对比。

## 怎样看到路径相撞

1. 点击 **开始**，等订单出现
2. 把两个订单分别分配给两台机器人，让它们的路径有交叉（比如目标货架相邻）
3. 当一台机器人试图进入另一台机器人当前占据的格子时：
   - 网格上对应位置变红
   - 右侧状态栏显示"堵塞"或"碰撞恢复"
   - 得分扣 50 分
4. 结算面板和复盘面板都会统计碰撞次数，复盘时可以看到 💥 碰撞标记

## 操作说明

- **派单**：在右侧订单队列点击机器人名称按钮，把订单分配给该机器人
- **开始/暂停/继续**：控制面板按钮
- **重开**：重置所有状态
- **速度**：1x/2x/3x 三档
- **结算**：所有订单完成或时间到后自动弹出，显示得分和评级
- **复盘**：结算后可进入逐帧回放，拖动进度条查看碰撞/超时/充电事件
