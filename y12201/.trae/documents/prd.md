## 1. 产品概述

跨境电商VAT预提工具，面向欧洲站点跨境财务团队，解决订单、退货和VAT税率按国家拆分后月末预提与平台账单差异追踪问题。核心价值：将数据来源、判断逻辑和计算结果串联成可审计链路，异常不混入正常明细，人工改动留痕可追溯，历史记录持久不丢失。

- 目标用户：跨境电商欧洲站财务人员
- 核心痛点：预提与账单差异无法解释、退货晚到覆盖已有判断、国家错配混入正常流水、人工改动无痕迹、重启后数据丢失

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 财务操作员 | 直接使用 | 导入数据、确认/处理异常、手动调整国家归集、导出报表 |
| 财务主管 | 直接使用 | 审核确认、查看审计日志、审批异常处理结果 |

### 2.2 功能模块

1. **总览仪表盘**：按国家/期间展示VAT预提汇总、差异概览、异常待处理数量
2. **订单与退货管理**：导入订单流水和退货单，按国家自动归集，支持补录不覆盖
3. **平台账单对账**：导入平台账单，与预提自动比对，标记差异
4. **待确认与异常清单**：税率跨期、退货晚到、国家错配自动进入异常队列
5. **审计追踪**：所有人工改动（尤其是国家归集调整）记录完整变更链路
6. **报表与导出**：生成含差异解释和改动影响的报表，支持CSV/PDF导出

## 3. 核心流程

### 3.1 VAT预提主流程

财务操作员按期间导入订单流水 → 系统根据国家+税率自动计算预提VAT → 按国家归集汇总 → 导入退货单时追加调整（不覆盖） → 导入平台账单 → 系统自动比对预提与账单差异 → 差异自动分类（税率跨期/退货晚到/国家错配/其他） → 异常条目进入待确认队列 → 操作员确认处理 → 生成含差异解释的报表

```mermaid
flowchart TD
    "A[导入订单流水]" --> "B[自动匹配国家+税率]"
    "B" --> "C[计算预提VAT并归集]"
    "C" --> "D[导入退货单]"
    "D" --> "E[追加退货调整(不覆盖)]"
    "E" --> "F[导入平台账单]"
    "F" --> "G[自动比对预提vs账单]"
    "G" --> "H{差异是否超阈值?}"
    "H" -->|"是"| "I[进入异常队列]"
    "H" -->|"否"| "J[标记为正常差异]"
    "I" --> "K[操作员确认处理]"
    "K" --> "L[生成含差异解释的报表]"
    "J" --> "L"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 #1B2A4A，传达专业、可信赖的财务工具感
- 辅助色：琥珀橙 #E8913A 用于异常预警和重要操作
- 成功色：翡翠绿 #2D9D78 用于确认和正常状态
- 错误色：珊瑚红 #E05252 用于异常和错误状态
- 按钮风格：圆角8px，主按钮填充色，次要按钮描边
- 字体：标题使用 DM Serif Display，正文使用 IBM Plex Sans
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- 图标：Phosphor Icons 线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 总览仪表盘 | VAT汇总卡片 | 白色卡片，左侧国家旗帜+名称，右侧金额右对齐，差异用色块标识 |
| 总览仪表盘 | 异常预警区 | 橙色/红色背景卡片，数字突出，右侧箭头引导 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 表格在窄屏下支持横向滚动
- 移动端暂不作为主要适配目标，但保证核心功能可用

## 5. 数据持久化与一致性要求

- 所有数据使用SQLite持久化存储，服务重启后数据不丢失
- 订单、退货、账单记录使用唯一业务ID去重，二次导入不产生重复
- 预提计算结果与源数据关联，源数据变更时重新计算而非覆盖
- 退货调整记录独立于原始预提记录，保留完整调整链路
- 审计日志不可删除，仅可追加
