# 航天器姿态可视化系统

用于航天科普教学的姿态可视化工具。重点解决万向节锁（Gimbal Lock）的演示和教学问题。

---

## 快速启动

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

启动后访问：http://localhost:5173

### 3. 构建生产版本
```bash
npm run build
```

## 样例数据位置

样例数据文件位于两个位置（内容相同）：

- **源代码位置**：`src/data/*.json`
- **可访问位置**：`public/data/*.json`（运行时通过HTTP加载）

### 4个样例场景

| 文件名 | 说明 | 用途 |
|--------|------|------|
| `sample-normal.json` | 正常姿态数据 | 演示正常的三轴姿态控制 |
| `sample-gimbal-lock.json` | 包含万向节锁场景 | **教学演示万向节锁的核心样例** |
| `sample-dirty.json` | 脏数据（缺字段、坐标轴晚到） | 演示数据容错处理能力 |
| `sample-axis-reverse.json` | 坐标轴反向数据 | 演示方向错误检测和修正建议 |

### 加载样例数据的方法

1. 启动应用后，点击右侧控制面板的「数据选择」区域
2. 点击对应样例按钮即可加载
3. 也可以点击「上传本地文件」加载自己的JSON数据

## 怎样触发万向节锁

万向节锁是欧拉角表示法的固有问题，当俯仰角（Pitch）接近 ±90° 时发生。

### 方法1：使用样例数据（推荐）

1. 加载 `sample-gimbal-lock.json` 样例
2. 点击播放按钮，时间轴推进到 **第5秒** 附近
3. 观察以下现象：
   - 航天器模型闪烁红色
   - 出现红色「万向节锁」标记球
   - 偏航轴（绿Y）和滚转轴（蓝Z）开始同步闪烁
   - 左上角自由度显示从「3DOF」变为「2DOF」
   - 左侧诊断面板出现万向节锁警告和原理说明

### 方法2：手动拖动滑块

1. 在右侧控制面板找到「姿态调整」区域
2. 拖动「俯仰角（Pitch）」滑块到 **85° ~ 95°** 之间
3. 立即触发万向节锁可视化效果
4. 滑块上的红色区域表示万向节锁警戒区（85°~95°）

### 万向节锁判定规则

- **警戒区**：俯仰角绝对值 > 85° 且 < 95°
- **严重程度**：0 ~ 1，越接近90°越严重
- **视觉标记**：红色半透明球体，中心在万向节旋转中心

## 数据格式说明

### 输入JSON格式

```json
{
  "spacecraft": {
    "name": "航天器名称",
    "dimensions": {
      "length": 4,
      "width": 2,
      "height": 1.5
    },
    "remark": "备注信息，会显示在界面上"
  },
  "frames": [
    {
      "timestamp": 0,
      "pitch": 0,
      "yaw": 0,
      "roll": 0,
      "remark": "单帧备注（可选）"
    }
  ]
}
```

### 角度定义

| 轴 | 名称 | 颜色 | 旋转方向 |
|----|------|------|----------|
| Pitch | 俯仰角 | 红色X轴 | 绕X轴旋转 |
| Yaw | 偏航角 | 绿色Y轴 | 绕Y轴旋转 |
| Roll | 滚转角 | 蓝色Z轴 | 绕Z轴旋转 |

旋转顺序：Y-X-Z（先偏航，再俯仰，最后滚转）

## 截图友好设计

所有标注都配有文字说明，不依赖颜色区分：

1. **角度标签**：每个坐标轴旁都有角度数值，单位为度
2. **时间戳**：左上角显示当前时间、帧号、自由度
3. **万向节锁警告**：红色边框 + 文字说明，不只是颜色变化
4. **诊断面板**：每个警告都有可复制的修正步骤
5. **数据质量徽章**：显示当前数据的完整度百分比

截图建议：使用系统截图工具（如Mac的Cmd+Shift+4）框选整个窗口。

## 修正建议说明

系统会自动检测以下问题并给出可操作的修正建议：

### 1. 万向节锁
- **现象**：俯仰角接近±90°，偏航和滚转轴重合
- **修正建议**：
  - 短期：调整俯仰角避开85°~95°区域
  - 长期：使用四元数代替欧拉角表示姿态

### 2. 角度越界
- **现象**：角度超过 ±180°
- **修正建议**：点击「自动修正」按钮使用 `normalizeAngle()` 函数归一化

### 3. 坐标轴反向
- **现象**：某轴角度单帧变化超过180°
- **修正建议**：检查传感器安装方向，对该轴角度取反或加/减360°

### 3.5 趋势反转
- **现象**：某轴角度从递增趋势突变为递减（或反之），方向突变但不一定超过180°
- **修正建议**：检查传感器安装方向是否正确，对该轴取负值或加/减360°修正

### 4. 数据缺失
- **现象**：某帧缺少某个角度字段
- **修正建议**：系统已自动用前3帧加权预测值填充，建议补全原始数据

### 5. 坐标轴晚到
- **现象**：某轴数据延迟一帧到达
- **修正建议**：检查数据采集系统的时序同步

## 常见问题

**Q: 为什么万向节锁时模型会闪烁？**
A: 这是刻意设计的视觉提示，用于在截图中清晰标记问题发生的位置。

**Q: 数据缺字段时显示的是什么值？**
A: 系统使用前3帧的线性加权预测值填充，权重分别为0.5、0.3、0.2。

**Q: 可以导出修正后的数据吗？**
A: 目前版本只显示修正建议，导出功能可以后续添加。

**Q: 为什么使用欧拉角而不是四元数？**
A: 本工具的教学目的就是演示欧拉角的万向节锁问题。实际航天工程中建议使用四元数。
