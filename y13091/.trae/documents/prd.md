## 1. 产品概述

桥隧检修平台时序回放系统，面向桥隧检修接手同事与方案经理，提供传感器检修记录的时间轴回放与异常排查能力。核心解决三个问题：筛选条件离开页面就说不清、时间轴缺段记录被揉进正常结果、接手同事无法分清已处理/待补/人工改判状态。

- 目标用户：桥隧检修方案经理、接手同事
- 核心价值：让时序回放的筛选条件、人工备注、接口返回三方一致；异常记录可追溯、可交接

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 方案经理 | 配置筛选条件、标注人工改判、导出接口返回 |
| 接手同事 | 浏览时序回放、查看明细与3D高亮、补录材料 |

### 2.2 功能模块

1. **时序回放主页面**：时间轴、筛选面板、侧边明细、3D桥隧模型高亮、接口返回分类面板

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 时序回放主页面 | 筛选面板 | 筛选条件持久化（刷新不丢失），支持传感器类型/时间范围/状态筛选，筛选条件始终可见 |
| 时序回放主页面 | 时间轴 | 传感器时序可视化，缺段时间单独标记为异常段，切换段落后联动侧边明细与3D高亮 |
| 时序回放主页面 | 侧边明细 | 当前选中记录的完整信息：传感器名称、采集时间、数值、状态、人工备注；名称不一致的记录标黄提示 |
| 时序回放主页面 | 3D桥隧模型 | 根据当前选中传感器位置高亮对应构件，切换时间轴段落后同步高亮 |
| 时序回放主页面 | 接口返回面板 | 分三类展示：已处理（绿色）、待补材料（橙色）、人工改判（紫色），每条返回附带筛选条件快照 |

## 3. 核心流程

**流程一：顺利记录回放**
方案经理进入页面 → 筛选面板自动恢复上次条件 → 时间轴展示正常传感器段 → 点击某段 → 侧边明细+3D高亮同步 → 接口返回标记为"已处理"

**流程二：补录记录回放**
接手同事进入页面 → 筛选面板显示条件 → 时间轴出现缺段标记 → 点击缺段 → 侧边明细提示"待补材料" → 接口返回标记为"待补材料" → 补录后状态更新为"已处理"

**流程三：异常记录回放**
方案经理发现名称不一致记录 → 侧边明细标黄提示 → 标记为"人工改判" → 接口返回标记为"人工改判" → 人工备注同步写入

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰蓝 (#1a2332) 工业/监控风格
- 辅助色：青绿 (#00e5a0) 用于正常状态高亮，琥珀 (#f59e0b) 用于异常/待补，紫罗兰 (#a855f7) 用于人工改判
- 按钮风格：圆角4px，扁平化，hover时微发光
- 字体：思源黑体/Noto Sans SC，标题18px加粗，正文14px常规，数据12px等宽
- 布局风格：左筛选面板 + 中央时间轴+3D + 右侧明细，底部接口返回面板
- 图标风格：线性图标，2px描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 时序回放主页面 | 筛选面板 | 左侧固定面板，深色背景，筛选条件标签式展示，始终可见，刷新后条件自动恢复 |
| 时序回放主页面 | 时间轴 | 中央水平时间轴，正常段青绿色块，缺段琥珀色虚线框，当前选中段发光边框，hover显示时间戳 |
| 时序回放主页面 | 侧边明细 | 右侧面板，卡片式布局，名称不一致时顶部黄色警告条，人工备注可编辑文本域 |
| 时序回放主页面 | 3D桥隧模型 | 中央上方，半透明桥隧线框模型，选中传感器位置脉冲发光，切换段落时高亮平滑过渡 |
| 时序回放主页面 | 接口返回面板 | 底部水平面板，三列分类卡片（已处理/待补/人工改判），每条显示传感器名+时间+筛选条件快照标签 |

### 4.3 响应式

- 桌面优先设计（1920×1080为主要分辨率）
- 侧边明细可折叠，3D模型可全屏
- 底部接口返回面板可展开/收起

### 4.4 3D场景指引

- 环境：工业灰暗环境光，模拟桥隧内部照明
- 光照：顶部偏冷白光（模拟隧道灯），底部偏暖橙色环境光
- 相机：默认45度俯视，可旋转缩放，切换传感器时相机平滑移动到对应位置
- 高亮效果：选中传感器位置使用脉冲发光（Emissive+动画），未选中构件半透明
- 后处理：Bloom发光效果增强高亮感知
