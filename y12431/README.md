# 品牌联名授权回款分析系统

专门为品牌商务财务设计的智能分析系统，解决保底抵扣、退货跨期、渠道漏报等反复出现的问题。

## 核心特性

### 1. 异常检测与追溯
- **保底抵扣**：精确计算每笔保底差额，明确截止周期、累计金额、需补收金额
- **退货跨期**：检测退货报告日期与结算周期不匹配，提供调整建议
- **渠道漏报**：自动识别缺失渠道数据，提醒补报
- **保证金异常**：监控超额核销、长期未核销等问题
- **分成计算错误**：对比预期与实际授权费，精确定位差异

### 2. 全链路追溯
每条判断都能追溯到原始材料，包括：
- 来源文件名
- 工作表名称
- 具体行号
- 材料类型（授权合同/保证金记录/回款报告）

### 3. 可视化分析
- 按品牌汇总图表
- 按周期趋势图
- 异常分类筛选
- 明细表格展示

### 4. 数据一致性
图表、明细表、导出Excel三者数据完全一致，避免手工核对。

## 快速开始

```bash

```

## 使用说明

### 数据格式要求

系统支持自动识别以下类型的Excel文件：

**授权合同** 必需列：
- 品牌名称/品牌
- 合作方/客户
- 合同编号
- 保底金额/保底
- 分成比例/费率
- 开始日期、结束日期

**保证金记录** 必需列：
- 合同编号
- 金额
- 到账日期
- 是否核销/核销状态
- 核销金额

**回款报告** 必需列：
- 合同编号
- 周期/月份
- 渠道/平台
- 销售额/销售金额
- 退货额/退货金额
- 授权费/分成金额

### 分析流程

1. 上传一个或多个Excel文件（支持拖拽上传）
2. 点击"开始分析"
3. 查看分析结果：
   - 总体概览卡片
   - 品牌/周期图表
   - 异常详情（可按类型筛选）
   - 授权分成明细表
4. 导出Excel报告（包含所有明细和追溯信息）

## 异常类型说明

| 异常类型 | 说明 | 修正建议 |
|---------|------|---------|
| 保底不足 | 累计授权分成未达合同保底 | 在当期回款中补收差额 |
| 退货跨期 | 退货计入周期与实际发生不符 | 调整对应周期销售数据 |
| 渠道漏报 | 缺少预期渠道的销售数据 | 向合作方索要缺失数据 |
| 保证金不匹配 | 核销超额或长期未核销 | 核对核销记录，及时办理核销 |
| 授权分成计算错误 | 实际授权费与计算值有差异 | 联系合作方确认计算依据 |
