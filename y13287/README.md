# 菜场卸货投诉回放

Web3D 可视化工具，回溯菜场卸货区投诉事件全链路，解决审批台账地点名称混乱、历史记录被覆盖、补录证据无法追溯三大痛点。

## 快速开始

```bash
npm install
node node_modules/vite/bin/vite.js --host
# 浏览器打开 http://localhost:5173
```

## 两步操作

1. **点选 3D 场景中的地点标记** → 右侧时间线和底部筛选面板自动联动该地点事件
2. **在时间线点击事件卡片** → 切到「审批台账溯源」标签，查看审批原文、照片补录、版本变更对比

## 坏材料来了看哪里

| 问题 | 查看位置 | 怎么判断 |
|------|----------|----------|
| 地点名称写法不统一 | 底部「地点名称归一对照」 | 查别名列表是否归一到同一规范名 |
| 旧方案被新意见覆盖 | 「审批台账溯源」面板展开「审批内容变更」 | 看新旧值对比和变更原因 |
| 补录照片改了什么 | 「审批台账溯源」面板顶部「现场照片补录」 | 看照片下方说明和补录日期 |
| 哪些投诉还需补证据 | 底部「处理状态」面板的「待补证据」 | 红色数字大于0即需补 |
| 时间范围筛选 | 时间线顶部「1-12月」按钮 | 点击单月或「全年」切换 |

## 数据来源

所有数据为 Mock，位于 [src/data/mockData.ts](src/data/mockData.ts)，包含：
- 4 个卸货地点（每个含规范名+别名列表）
- 10 条投诉事件（4种类型、3种状态）
- 13 条审批记录（3种来源类型）
- 4 条历史快照（含旧值/新值/变更原因）
- 5 条照片补录（含照片说明和补录日期）
