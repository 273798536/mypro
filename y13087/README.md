# 博物馆展柜灯光碰撞预审

月底封账前用的 Web3D 灯光碰撞评审工具。

## 快速开始

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173`。

## 三步操作

### 1. 看页面摘要

左侧三张卡片：**已处理**（绿）、**待补材料**（橙）、**人工改判**（粉）。
点卡片自动筛选对应状态的灯光点位，3D 场景里其他的会变暗。

### 2. 点选灯光点位

在 3D 场景中点击发光的小球，右侧面板显示：
- 点位基本信息和空间坐标（XYZ）
- 该阶段的评审批注
- 状态流转按钮（可改判）

鼠标拖拽旋转视角，滚轮缩放。

### 3. 导出结果

右上角「导出」按钮：
- **导出截图**：保存当前视角的 3D 场景画面
- **导出预审报告**：生成文本格式的状态统计与明细

底部时间轴可切换评审阶段（初评 / 复核 / 终审），批注和状态会跟着变。

## 坏材料来了看哪里

遇到坐标混乱、数据不对的情况，按这个顺序查：

### 一、先看「相邻点位异常专区」

页面中上方红色警示卡片，专门放**相邻点位合错**的记录。
- 悬浮某条记录，3D 场景里两个点位同时变红
- 点击记录直接定位到对应点位
- 这些记录不会混入正常结果，单独拎出来了

### 二、再看「人工改判」状态

左侧粉色卡片，点进去看所有被人工改判过的点位。
每条都有批注记录为什么改，改了什么。

### 三、最后核对坐标

选中点位后，右侧明细里有 **XYZ 空间坐标**（红/绿/蓝三色对应）。
场景左下角也有 XYZ 坐标轴辅助线，确认坐标系方向没搞反。

标注、侧边明细、报告用的是同一套数据，不会出现三套说法。

## 状态说明

| 状态 | 颜色 | 含义 |
|------|------|------|
| 已处理 | 翠绿 | 评审通过，无问题 |
| 待补材料 | 琥珀橙 | 缺少检测报告或证明材料 |
| 人工改判 | 玫红 | 人工干预改判，需特别留意 |
