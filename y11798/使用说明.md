## 📊 参数说明（造数指南）

### 1. 活塞参数
- **小活塞面积 (A₁)**：推荐范围 1 - 50 cm²
- **大活塞面积 (A₂)**：推荐范围 10 - 500 cm²
- **面积比 = A₂ / A₁**：决定力的放大倍数

### 2. 运动参数
- **输入力 (F₁)**：推荐范围 100 - 5000 N
- **输入行程 (S₁)**：推荐范围 5 - 50 cm

### 3. 系统参数
- **效率 (η)**：推荐 0.85 - 0.95（实际液压系统）
- **材料来源**：选填，用于标注题目/实验来源

### 快速示例（预设数据）
1. **教材例题**：基础教学案例
2. **工程案例**：工业应用场景
3. **大型系统**：大吨位液压设备

## 🎯 主要操作流程

### 正常计算路径
1. **加载预设** → 点击「快速示例」选择预设数据
2. **调整参数** → 直接修改输入框或拖动效率滑块
3. **播放动画** → 点击「播放动画」观察活塞联动
4. **查看结果** → 右侧面板自动更新计算结果
5. **导出保存** → 截图导出 / 生成报告 / 保存记录

### 动画联动说明
- 小活塞向下压 → 大活塞向上顶
- 活塞大小按面积比例显示
- 力的箭头大小随计算结果变化
- 行程距离与计算值联动

## ⚠️ 异常路径（错误处理）

### 错误类型与提示

| 错误场景 | 系统行为 | 修正建议 |
|---------|---------|---------|
| **效率 > 100%** | 🔴 红色高亮 + 计算暂停 | 效率必须 ≤ 1，实际系统必有能量损失 |
| **面积 = 0 或负数** | 🔴 红色高亮 + 计算暂停 | 输入正值，物理上不可能为负 |
| **输入力 = 0** | 🔴 红色高亮 + 计算暂停 | 力必须大于0才能产生效果 |
| **面积单位不一致** | 🟡 黄色警告 + 自动转换 | 建议统一单位便于比较 |
| **面积比 < 1** | 🟡 黄色警告 | 大活塞应大于小活塞才能放大 |
| **面积比 > 100** | 🟡 黄色警告 | 比例过大实际难以实现 |
| **效率 < 50%** | 🟡 黄色警告 | 实际系统通常效率在80%以上 |

### 修正痕迹
- 所有参数修改都会记录
- 历史记录可回溯查看
- 支持一键加载历史记录

## 💡 课堂实验建议

### 实验一：验证帕斯卡定律
1. 固定面积比 = 10:1
2. 输入力分别取 100N, 200N, 500N
3. 观察输出力是否按比例放大

### 实验二：理解行程代价
1. 固定输入行程 = 10cm
2. 面积比分别取 5:1, 10:1, 20:1
3. 记录输出行程变化
4. 总结：力放大N倍，行程缩小N倍

### 实验三：效率影响分析
1. 固定所有输入参数
2. 效率分别取 0.5, 0.8, 0.95, 1.0
3. 观察能量损失变化
4. 讨论：永动机为什么不可能？

### 实验四：常见错误练习
1. 故意输入错误值（效率=150%）
2. 观察系统提示
3. 理解为什么这些值是错误的

## 🔧 核心计算公式

**帕斯卡定律**：`P = F₁/A₁ = F₂/A₂`
**输出力**：`F₂ = F₁ × (A₂/A₁) × η`
**行程关系**：`S₂ = S₁ × (A₁/A₂) × η`
**能量守恒**：`W₁ = W₂ + W_loss`
