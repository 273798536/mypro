# 售后备件领用异常回执状态机 API

## 项目概述

本项目是一个企业级的售后备件领用异常回执状态机服务，用于管理维修单、备件扫码、客户签收照等数据的状态流转。

## 核心功能

1. **状态机管理**：批次创建、附件补传、复核改判、冻结结算、撤回归档
2. **权限控制**：录入、复核、主管、只读查看四种角色
3. **脏记录处理**：缺字段、跨日、改名、金额或数量冲突的识别与修正
4. **追溯复盘**：退回件和报废件混淆后的完整追溯
5. **导出汇总**：服务经理视图，包含冻结前后状态、人工理由

## 技术栈

- NestJS 10.x
- TypeScript 5.x
- TypeORM 0.3.x
- SQLite 数据库
- Swagger API 文档

## 快速开始

### 安装依赖

```bash
npm install
```

### 初始化数据

```bash
npm run seed
```

### 启动服务

```bash
npm run start:dev
```

### 运行验收测试

```bash
npm run test:acceptance
```

## API 文档

启动服务后访问：http://localhost:3000/api
