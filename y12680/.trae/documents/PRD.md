# 药物结合口袋浏览器 - 产品需求文档

## 1. 产品概述

### 1.1 产品定位
药物结合口袋浏览器是面向仿真工程师的数据审查工具，用于管理和审查药物结合口袋分析结果。重点解决三维模型和点云切片数据冲突后的解释与追溯问题。

### 1.2 核心价值
- 数据溯源：任何结论都能追溯到原始材料
- 异常识别：快速筛选出异常数据
- 评审支持：区分可直接使用和需要复核的记录

## 2. 功能需求

### 2.1 数据导入与管理
- 支持CSV/Excel格式导入药物结合口袋分析数据
- 自动识别数据字段（蛋白名称、口袋坐标、亲和力、来源文件等）
- 保留原始行号和文件名作为追溯标识
- 检测重复导入并提示用户处理

### 2.2 异常数据筛选
- **相机视角丢失**：标注相机视角参数异常或缺失的记录
- **数据冲突**：识别三维模型与点云切片参数不一致的记录
- **格式异常**：检测数据格式错误或缺失必填字段
- 异常记录高亮显示并附带异常原因说明

### 2.3 明细联动与来源追溯
- 点击任意记录可查看完整详情
- 详情页展示：来源材料、处理意见、原始行号、图片文件名
- 支持从结论跳转回原始数据位置
- 处理意见字段支持手动录入和修改

### 2.4 参数联动与视角保存
- 修改关键参数时自动联动相关字段
- 保存当前相机视角状态到记录
- 支持视角状态的一键恢复
- 参数修改历史可追溯

### 2.5 评审状态管理
- 三种状态标签：
  - **可直接使用**（绿色）：数据完整、无异常
  - **待复核**（黄色）：存在轻微异常，需工程师确认
  - **不可用**（红色）：严重异常，无法使用
- 状态切换需要填写原因说明
- 支持批量状态更新

### 2.6 测试场景支持
- 内置重复导入测试场景
- 验证工具在多次导入下的稳定性
- 检测数据覆盖和合并逻辑正确性

```
│ 顶部工具栏：导入 | 导出 | 筛选器 | 视图保存             │
├─────────────────────────────────────────────────────────┤
│ 数据表格（支持排序、筛选、批量选择）                    │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ 状态 | 原始行号 | 蛋白名 | 口袋坐标 | 异常标记 | ... │ │
│ ├─────────────────────────────────────────────────────┤ │
│ │  ●   | 001      | CDK2  | (x,y,z) | 无异常        │ │
│ │  ◐   | 002      | CDK6  | (x,y,z) | 视角丢失       │ │

├─────────────────────────────────────────────────────────┤
│ 详情面板（选中记录时展开）                               │

│ 相机视角：[保存/恢复按钮]                               │
└─────────────────────────────────────────────────────────┘
```

### 3.2 视觉规范
- 清晰的状态色：绿色(可用)、黄色(待复核)、红色(不可用)
- 表格行悬停效果
- 异常记录红色边框高亮
- 简洁专业风格，适合评审会展示

## 4. 数据模型

### 4.1 记录结构
```typescript
interface PocketRecord {
  id: string;                    // 唯一标识
  originalRowNumber: number;     // 原始行号
  sourceFile: string;            // 来源文件名
  proteinName: string;           // 蛋白名称
  pocketCoordinates: {x: number, y: number, z: number};
  affinity: number;              // 亲和力
  cameraAngle?: {                // 相机视角（可选）
    azimuth: number;
    elevation: number;
    distance: number;
  };
  anomalyType?: 'camera_lost' | 'data_conflict' | 'format_error';
  anomalyNote?: string;          // 异常说明
  reviewStatus: 'usable' | 'pending' | 'unusable';
  reviewNote?: string;           // 评审意见
  processingOpinion?: string;    // 处理意见
  createdAt: Date;
  updatedAt: Date;
}
```

## 5. 验收标准

### 5.1 功能验收
- [ ] 能成功导入CSV/Excel文件
- [ ] 异常数据能被正确识别和标注
- [ ] 点击记录能显示完整详情和来源
- [ ] 相机视角能保存和恢复
- [ ] 参数修改后能正确联动
- [ ] 重复导入时能正确处理（不覆盖原有数据）

### 5.2 评审会验收
- [ ] 一眼能区分可用/待复核/不可用记录
- [ ] 不可用记录能追溯到原始材料和原因
- [ ] 测试场景能验证工具稳定性

### 5.3 数据完整性验收
- [ ] 原始行号和文件名始终保留
- [ ] 所有修改都有操作记录
- [ ] 导出数据包含完整溯源信息
