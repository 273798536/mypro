## 1. 产品概述

期货基差口径对账管理后台，面向清算运营人员（阿禾）的专业金融对账工具。解决银行流水税费汇率混列、后补材料覆盖早先判断、回款多行混淆、月底复核状态不清、重启数据丢失等核心痛点。

- 核心用户：清算运营专员
- 核心价值：将混乱的银行流水转化为可追溯、可复核、可导出的标准化对账流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 清算运营专员 | 默认登录 | 导入材料、人工改判、导出对账、添加备注与截图说明、月底复核 |

### 2.2 功能模块

1. **对账列表页**：数据表格、多维度筛选、状态标签（已确认/待补件/退回）、回款多行标记、批量操作
2. **对账详情页**：人工改判面板、历史备注时间线、截图说明区、状态变更日志、税费汇率分列展示
3. **材料导入页**：银行流水文件上传、税费汇率自动分列解析、导入预览与确认、数据去重与合并
4. **导出中心**：对账数据导出、筛选口径快照、导出记录留存

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 对账列表页 | 顶部筛选栏 | 按状态、日期范围、期货合约、回款标记筛选，筛选条件实时保留 |

## 3. 核心流程

清算运营阿禾的典型日操作流程：先导入分批到齐的银行流水材料→系统自动拆分税费和汇率→人工确认解析结果并逐条对账→遇到问题记录添加备注和截图说明→对存疑记录做人工改判→月底按状态（已确认/待补件/退回）分类复核→导出对账结果（含筛选口径快照）。

```mermaid
flowchart LR
    A["导入银行流水"] --> B["税费汇率自动分列"]
    B --> C["人工确认解析结果"]
    C --> D{"数据已存在?"}
    D -->|是| E["合并补充，保留历史判断"]
    D -->|否| F["新增对账记录"]
    E --> G["对账列表浏览"]
    F --> G
    G --> H{"需要改判?"}
    H -->|是| I["人工改判 + 必填理由"]
    H -->|否| J{"需要补充说明?"}
    I --> J
    J -->|是| K["添加备注 + 截图说明"]
    J -->|否| L["状态流转"]
    K --> L
    L --> M["月底复核：已确认/待补件/退回"]
    M --> N["导出：数据 + 筛选口径快照"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深炭灰背景（#0F1419），配合琥珀金（#D4A853）作为强调色——营造金融终端的专业沉稳感
- **辅色调**：翡翠绿（#10B981）= 已确认、琥珀黄（#F59E0B）= 待补件、朱砂红（#EF4444）= 退回
- **按钮风格**：直角方切，2px 边框，hover 时边框发光，禁用时透明度 50%
- **字体**：标题用 "Noto Serif SC"（思源宋体）体现专业感，数字用 "JetBrains Mono" 等宽字体确保对齐，正文用 "Noto Sans SC"
- **布局风格**：顶部导航栏 + 左侧筛选抽屉 + 主内容数据表格，卡片式信息区，细线分割
- **视觉细节**：全局 1px 极细边框，低对比度噪点纹理背景，表格斑马纹用极淡色，状态标签带内阴影

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 对账列表页 | 顶部导航 | 宋体大标题 + 面包屑 + 操作员信息 + 导出按钮（琥珀金边） |
| 对账列表页 | 筛选抽屉 | 左侧滑出，分组筛选器，底部"重置/应用"按钮 |
| 对账列表页 | 数据表格 | 固定表头，斑马纹，状态列彩色标签，回款行左侧琥珀色竖条标记 |
| 对账详情页 | 双栏布局 | 左侧：基础信息 + 税费汇率拆分；右侧：历史时间线 + 截图说明 |
| 对账详情页 | 人工改判区 | 固定在页面底部的操作条，状态选择 + 理由输入框 + 确认按钮 |
| 材料导入页 | 上传区 | 虚线边框上传框，拖拽高亮，文件列表带解析进度 |
| 材料导入页 | 预览表格 | 拆分前后对比，原始列灰显，拆分后新列高亮绿色边框 |

### 4.3 响应性

桌面端优先设计，最小支持 1280px 宽度。表格区域内部横向滚动，侧边筛选抽屉可折叠。不做移动端适配。

### 4.4 微交互

- 表格行 hover：左侧出现 3px 琥珀色高亮边
- 状态变更：标签颜色渐变过渡 + 轻微缩放
- 历史时间线：逐条淡入加载，带 80ms 延迟差
- 导出按钮：点击后出现环形进度，完成后变对勾
- 筛选器展开/收起：高度过渡动画 200ms ease-out
