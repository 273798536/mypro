## 1. 产品概述

疫苗抗体滴度复核看板——面向生信分析师的专业复核工具，以试剂批号为主线，解决物种名同义歧义与污染样本混入两大痛点，提供图表、明细、导出一体化工作流。

- 核心目标：让生信分析师在复核抗体滴度时，不再因物种名同义和污染样本而反复卡住；一条顺利记录、一条待确认记录、一条明显坏数据即可验证全部流程
- 目标用户：生信分析师、实验室质控人员、带教学生

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 生信分析师 | 直接使用 | 复核、补录样本、导出报告 |
| 带教学生 | 只读查看 | 查看图表与明细、下载报告 |

### 2.2 功能模块

1. **复核看板页**：试剂批号筛选、抗体滴度图表 + 明细解释、样本清单表格、状态标注
2. **样本补录页**：追加样本记录、自动触发同义名检测与污染判断、实时刷新图表与报告
3. **导出报告页**：运行版本区分、报告内容包含拦截原因说明、文件名含批次与时间戳

### 2.3 页面明细

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 复核看板页 | 试剂批号筛选栏 | 按批号筛选当前复核范围，切换批号后图表与明细同步刷新 |
| 复核看板页 | 滴度分布图 | 柱状图展示各样本滴度值，旁边附明细解释面板，标注异常样本 |
| 复核看板页 | 样本清单表格 | 列出全部样本：物种名、滴度值、状态（通过/待确认/坏数据）、拦截原因 |
| 复核看板页 | 同义名提示卡片 | 当物种名命中同义表时，展示"标准名→同义名"映射与拦截理由 |
| 样本补录页 | 补录表单 | 录入样本ID、物种名、滴度值、批号；提交后自动检测同义名与污染 |
| 样本补录页 | 补录结果反馈 | 提交后即时显示检测结果：通过/待确认/坏数据，并同步到看板 |
| 导出报告页 | 报告预览 | 展示完整复核报告，包含图表截图、明细表格、拦截原因说明段落 |
| 导出报告页 | 下载按钮 | 文件名格式：titer_review_{批号}_{YYYYMMDD_HHmmss}.xlsx，内容含运行标识列 |

## 3. 核心流程

1. 生信分析师选择试剂批号，进入该批次的复核看板
2. 看板展示滴度分布图（带明细解释）与样本清单表格
3. 系统自动检测物种名同义问题，在图表旁展示拦截说明
4. 系统自动检测污染样本混入，标注为"坏数据"
5. 分析师可补录新样本，补录后图表与明细实时刷新
6. 分析师导出报告，报告内含拦截原因（学生仅看报告即可理解为何被拦截）
7. 多次运行通过文件名时间戳与内容运行标识区分

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1B2A4A) + 琥珀色强调 (#E8A838)，实验室仪器面板感
- 辅助色：通过-翡翠绿 (#34D399)、待确认-琥珀 (#FBBF24)、坏数据-朱砂红 (#EF4444)
- 按钮：微圆角（4px）、扁平化、hover 时底部亮线指示
- 字体：显示字体用 JetBrains Mono（数据/代码感），正文用 Noto Sans SC
- 布局：左侧批号筛选+概览面板，右侧主内容区图表+明细双栏
- 图标：线性风格，实验室/医学主题

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 复核看板页 | 试剂批号筛选栏 | 下拉选择器、当前批号高亮标签、样本总数/通过/待确认/坏数据统计卡片 |
| 复核看板页 | 滴度分布图 | 柱状图（颜色按状态区分）、右侧明细解释面板（文字+箭头指向异常柱） |
| 复核看板页 | 样本清单表格 | 条纹表格、状态徽章、同义名列高亮、点击行展开拦截详情 |
| 复核看板页 | 同义名提示卡片 | 卡片式，标准名与同义名对比展示，拦截规则说明 |
| 样本补录页 | 补录表单 | 紧凑表单、物种名输入时实时联想、提交后内联反馈 |
| 样本补录页 | 补录结果反馈 | 三态图标（✓/⚠/✗）+ 文字说明，自动刷新看板提示 |
| 导出报告页 | 报告预览 | 模拟A4纸样式，含标题/批号/日期/图表/明细/拦截原因段落 |
| 导出报告页 | 下载按钮 | 主按钮，文件名预览，运行标识说明 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 侧边栏可折叠，窄屏时切换为顶栏导航
- 图表在小屏下切换为简化视图

### 4.4 三维场景

不适用，本项目以二维图表+明细面板为主。
