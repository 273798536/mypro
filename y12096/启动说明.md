# 微积分旋转体教具 - Three.js Web3D

## 项目简介

专为数学教师设计的微积分旋转体可视化教学工具，基于Three.js实现Web3D交互。支持函数曲线绕轴旋转的3D可视化、体积实时计算、参数审核流程和双向追溯查询。

## 快速启动

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 构建生产版本
npm run build

# 4. 预览生产构建
npm run preview

# 5. 类型检查
npm run check
```

启动后访问 `http://localhost:5173` 即可使用。

## 核心功能

### 1. 3D主视图
- **视角控制**：左键旋转、滚轮缩放、右键平移
- **旋转体渲染**：实时根据参数生成3D旋转体
- **切片显示**：可切换显示/隐藏切片分层
- **视角保存**：保存当前视角，支持一键恢复

### 2. 参数面板（左侧）
- **函数曲线输入**：支持 `x^2`, `sin(x)`, `sqrt(1-x^2)` 等表达式
- **旋转轴选择**：X轴、Y轴、自定义轴（带偏移量）
- **区间端点**：[a, b] 区间设置，自动检测区间反向
- **切片数量**：滑块调整1-100片，过少时自动预警
- **计算方法**：圆盘法 / 壳层法切换
- **体积计算**：实时显示计算结果和步骤

### 3. 记录明细（右侧）
- **记录列表**：展示所有保存的计算记录
- **双向追溯**：
  - 按函数表达式追溯
  - 按旋转轴追溯
  - 按体积结果追溯
- **修改痕迹**：展示参数修改历史，新旧值对比
- **审核操作**：通过/驳回待审核记录

### 4. 审核规则引擎

| 异常类型 | 触发条件 | 处理方式 | 核对人 |
|---------|----------|----------|--------|
| 区间反向 | a > b | 标记"待确认"，走审核分支 | 李老师（教研组长） |
| 轴线混淆 | 函数含x,y且选自定义轴 | 标记错误，强制人工核对 | 王教授（数学系） |
| 切片过少 | 切片数 < 10 | 预警提示，建议增加 | 张实验员 |

所有修改自动留痕，补录切片数量后可查看哪些结论被改动。

## 使用流程

### 标准工作流
1. **录入材料**：依次输入函数曲线 → 选择旋转轴 → 设置区间端点
2. **补录切片**：后续补充切片数量，自动触发审核校验
3. **查看改动**：保存记录后可在"修改历史"中查看参数变化
4. **异常处理**：
   - 区间反向 → 自动标记待确认 → 提交李老师核对
   - 轴线混淆 → 提示联系王教授
   - 切片过少 → 建议联系张实验员确认
5. **保存记录**：点击"保存记录"存储当前配置和结果
6. **双向追溯**：
   - 从函数 → 结果：输入函数表达式查询相关记录
   - 从结果 → 旋转轴：输入体积数值反查旋转轴配置

## 函数表达式支持

支持的数学函数：
- 基本运算：`+`, `-`, `*`, `/`, `^` (幂)
- 三角函数：`sin(x)`, `cos(x)`, `tan(x)`
- 指数对数：`e^x`, `log(x)`, `ln(x)`
- 其他：`sqrt(x)` (开方), `abs(x)` (绝对值), `pi` (π)

示例：
- 抛物线：`x^2`
- 圆：`sqrt(1-x^2)`
- 正弦曲线：`sin(x)`
- 指数衰减：`e^(-x)`

## 数据持久化

所有数据存储在浏览器 LocalStorage 中：
- `rotation_solid_records` - 计算记录
- `rotation_solid_views` - 保存的视角
- `rotation_solid_params` - 最后使用的参数

## 快捷键

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 双击空白：重置视角
- 顶部菜单按钮：切换左右侧边栏

## 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite 6
- **3D引擎**：Three.js + @react-three/fiber + @react-three/drei
- **状态管理**：Zustand
- **数学计算**：math.js
- **公式渲染**：KaTeX
- **样式方案**：Tailwind CSS 3
- **图标**：Lucide React
