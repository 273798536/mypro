# 复杂曲面法线练习 - 本地 Web 工作台

## 概念与愿景

这是一个面向舞台制作质量控制的专用工作台，专注于复杂曲面法线检测结果的审查与管理。系统围绕"截图清单"这一核心线索展开，帮助评审会快速定位问题、理解透明遮挡误读的判定逻辑，并生成可追溯的月度交接报告。界面采用工业检测风格，信息密度高但层次分明，让操作者一目了然地知道"哪些记录不能用"。

## 设计语言

### 美学方向
工业质检风格：深色主题减少视觉疲劳，数据可视化清晰明了，关键状态用颜色和文字双重标注。

### 色彩系统
- **主色**: #1890ff (信息蓝 - 待处理/进行中)
- **成功色**: #52c41a (通过绿 - 合格记录)
- **警告色**: #faad14 (警示黄 - 需复核)
- **危险色**: #ff4d4f (阻断红 - 不合格/误读)
- **背景色**: #141414 (深色背景), #1f1f1f (卡片背景)
- **边框色**: #303030 (分割线), #434343 (悬停)
- **文字色**: #ffffff (标题), #cccccc (正文), #666666 (辅助)

### 字体
- 主字体: "PingFang SC", "Microsoft YaHei", -apple-system, sans-serif
- 数据字体: "SF Mono", "Consolas", monospace
- 字号: 标题 18px, 正文 14px, 辅助 12px

### 空间系统
- 基础单位: 8px
- 卡片内边距: 16px
- 区块间距: 24px
- 圆角: 6px (卡片), 4px (按钮), 2px (标签)

### 动效哲学
- 状态切换: 200ms ease-out
- 面板展开: 300ms cubic-bezier(0.4, 0, 0.2, 1)
- 数据加载: 骨架屏 + 渐显
- 禁止花哨动画，一切服务于效率

## 功能与交互

### 核心功能

#### 1. 记录列表
- 支持多维度筛选: 时间范围、状态、严重程度、设备编号
- 列表项显示: 记录ID、设备坐标、状态标签、关键指标预览、时间
- 悬停显示快速操作: 查看、修正、导出
- 点击选中，高亮当前记录

#### 2. 详情面板
- **记录头部**: ID、设备编号、采集时间、操作员、状态
- **三维视图**:
  - WebGL 点云渲染
  - 法线方向彩色编码 (红/绿/蓝对应 XYZ)
  - 鼠标交互旋转、缩放、平移
  - 剖切平面控制 (X/Y/Z轴切片)
- **剖切控制**:
  - 拖动滑块调整剖切位置
  - 实时显示切片数据
  - 点云切片补录后自动刷新视图
- **透明遮挡误读说明**:
  - 误读原因文字解释
  - 相关截图高亮标注
  - 判定依据列表

#### 3. 截图清单
- 完整截图列表，可点击放大
- 每张截图标注: 采集时间、设备坐标、问题区域
- 透明遮挡区域自动框选标注
- 支持截图对比查看

#### 4. 修正流程
- 选择误读类型: 透明遮挡、角度偏差、设备误差、其他
- 填写修正说明 (必填)
- 上传修正证据
- 提交后记录历史版本

#### 5. 历史版本
- 时间线展示所有版本
- 版本对比: 高亮差异字段
- 可回滚到任意版本
- 每次修改记录操作人和时间

#### 6. 导出报告
- 生成 PDF/Excel 报告
- 报告内容: 统计摘要、不合格清单、透明遮挡误读明细
- 支持自定义时间范围
- 报告预览后再下载

### 时间回放
- 时间轴控制点云采集进度
- 支持播放/暂停/拖动
- 切片视图随时间同步更新
- 回放过程中可随时截取新截图

### 状态说明
- **待处理**: 蓝色标签，新采集记录
- **已通过**: 绿色标签，法线检测合格
- **需复核**: 黄色标签，存在疑问需人工确认
- **不合格**: 红色标签，透明遮挡误读等原因

## 技术方案

### 架构
- 单文件 HTML 应用 (便于本地部署)
- 原生 JavaScript (无框架依赖)
- WebGL (Three.js) 实现三维点云渲染
- LocalStorage 存储本地数据
- IndexedDB 存储大量点云数据

### 数据模型
```javascript
Record {
  id: string,
  deviceCode: string,
  coordinates: {x, y, z},
  captureTime: timestamp,
  operator: string,
  status: 'pending' | 'passed' | 'review' | 'failed',
  normalData: PointCloudData,
  screenshots: Screenshot[],
  transparentOcclusion: OcclusionInfo,
  history: Version[],
  createdAt: timestamp,
  updatedAt: timestamp
}

PointCloudData {
  points: Float32Array,
  normals: Float32Array,
  colors: Float32Array,
  bounds: {min, max}
}

OcclusionInfo {
  detected: boolean,
  reason: string,
  severity: 'low' | 'medium' | 'high',
  affectedArea: BoundingBox,
  relatedScreenshots: string[]
}
```

### 关键实现
- 点云渲染: Three.js Points + 自定义 Shader
- 剖切平面: Shader 实现实时裁剪
- 历史版本: Immutable 更新 + diff 算法
- 报告导出: html2canvas + jsPDF
